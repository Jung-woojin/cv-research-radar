## 2. OccludeBench — reasoning과 도구를 늘려도 물리 단서 추출 실패가 남는다

**공식 출처:** [논문](https://arxiv.org/abs/2610.13790) · [HTML 결과](https://arxiv.org/html/2610.13790) · [공식 데이터](https://huggingface.co/datasets/afs07fda89sdfas90/data)

### 실패 조건

완전히 가려진 객체를 그림자·반사 같은 직접 물리 단서로 복원할 때 VLM이 장면 문맥으로 추론하는 경우보다 일관되게 낮은 정확도를 보인다. 실패는 단서를 보지 못해서가 아니라 전체 이미지 안에서 단서가 나타내는 객체를 꺼내지 못하는 단계에 집중된다.

### 모델·데이터·설정

- 378개 수동 선별 이미지: direct 197, inferential 181
- GPT-5.4, Claude Opus 4.6, Gemini 3.1 Pro, Qwen 3 VL 8B, Llama 4 Maverick
- 평균 direct/inferential 정확도: 42.7/62.7%; 인간: 63.4/68.5%
- 모델별 direct/inferential: GPT-5.4 37.6/62.4, Claude Opus 4.6 51.8/75.1, Gemini 3.1 Pro 71.6/87.8, Qwen 3 VL 8B 20.9/46.4, Llama 4 Maverick 31.6/42.0
- open-ended 응답을 GPT-5.4와 Claude Opus 4.6 judge 중 하나가 수용하면 정답으로 처리; 저자 gold와 98% 일치

### 공식 인정과 재현 근거

저자는 모든 모델에서 direct가 inferential보다 낮다고 보고했다. OccludeTrace에서 실패/성공 예의 정확도는 cue detection 99/100%, crop recognition 79/88%, source mapping 85/82%, full-image highlighted-region recovery 50/91%다. 추가 reasoning은 모델별 방향이 달랐고, 도구 사용 시 GPT-5.4 direct accuracy는 51.8%에서 46.7%로 하락했다. GPT-5.4는 5-call budget을 소진한 179개 trace에서 45% 정확도였으며, Claude Opus 4.6은 도구 호출이 2회에서 5회로 늘수록 62%에서 28%로 떨어졌다.

독립 커뮤니티 재현은 확인되지 않았다. 데이터와 prompt가 공개돼 재현 가능성은 높지만, 폐쇄형 모델 버전과 LLM judge의 시점 의존성이 남는다.

### 의심 원인과 기존 주장과의 충돌

- **확인된 진단:** projection을 crop하면 읽고 source도 찾지만, 전체 장면 안에 있을 때 관련 객체를 추출하지 못한다.
- **가설:** 전역 문맥 prior가 국소 물리 단서보다 강하게 작동해 evidence selection을 덮는다.
- 일반 VLM benchmark의 높은 reasoning score와 충돌하는 것은 능력 전체가 아니라, 그 점수가 물리 단서 사용 여부를 보장한다는 해석이다.
- inpaint-then-confront는 GPT-5.4 격차를 24.8%p에서 8.1%p, Gemini를 16.2%p에서 5.6%p로 낮췄지만 생성 기능이 있는 두 모델에만 적용돼 범용 해결책으로 볼 수 없다.

### 후속 최소 실험

1. 해무·야간 해상 영상에서 direct-cue 50장과 context-inference 50장을 만든다.
2. 기본, crop, steering, inpaint-confront 네 조건을 동일 model revision과 세 seed로 비교한다.
3. answer accuracy, direct–inferential gap, cue-region grounding, tool-call 수를 함께 기록한다.
4. **GO:** crop/inpaint가 direct 정확도를 10%p 이상 회복하고 grounding도 함께 상승.
5. **KILL:** 격차가 judge나 seed에 따라 사라지거나, 정답만 오르고 cue grounding은 개선되지 않음.

**평가:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 3. G-RSVQA/AESP — 정답이 맞아도 grounding evidence가 답을 지지하지 않는다

**공식 출처:** [논문](https://arxiv.org/abs/2610.13636) · [공식 evaluator](https://github.com/pingggg516/AESP-Evaluation)

### 실패 조건

grounded remote-sensing VQA에서 답 문자열은 맞지만 모델이 제시한 box 수·class·관계가 그 답을 논리적으로 지지하지 않는 사례가 발생한다. counting에서 “10개”라고 답하면서 9개 box만 내거나, comparison에서 동일한 box 수를 내고 “A가 더 많다”고 답해도 기존 localization F1은 높을 수 있다.

### 모델·데이터·설정

- G-RSVQA 15,027 samples, 163,399 related-object annotations
- DIOR 11,714, NWPU VHR-10 800, SODA-A 2,513
- existence 8,592, counting 4,275, comparison 2,160
- 7개 grounded VLM 평가
- 공식 evaluator 지표: Answer Accuracy, Loc-P/R/F1, Evidence Support-Overall, Evidence Support-Correct Answers, Joint Success
- answer extraction은 고정 Qwen3-14B revision을 사용하며 invalid answer는 incorrect·unsupported로 유지

### 공식 인정과 재현 근거

저자 abstract는 evidence-evaluation subset에서 올바른 답 중 최대 50.82%가 제시된 grounding evidence로 지지되지 않았다고 명시한다. evaluator는 입력·출력·extractor identifier와 환경을 run manifest로 남긴다. 공식 코드는 공개됐지만 독립 재현 결과는 확인되지 않았다.

세 원천 데이터의 class distribution과 split이 다르고 SODA-A polygon은 horizontal box로 바뀐다. 50.82%는 가장 나쁜 모델/조건의 최대값이며, 7개 모델의 평균 실패율로 읽으면 안 된다. answer extractor 자체의 parsing 오류와 29.6GB BF16 checkpoint 비용도 재현 변수다.

### 의심 원인과 기존 주장과의 충돌

- **확인된 사실:** answer accuracy와 localization F1은 answer–box consistency를 직접 측정하지 않는다.
- **가설:** language prior가 답을 만들고 vision branch가 별개의 plausible box를 내는 late-fusion 분리가 원인이다.
- 높은 answer accuracy와 높은 box F1이 “증거 기반 정답”을 뜻한다는 기존 평가 해석과 직접 충돌한다.
- 원격탐사 small-object counting에서는 box 하나의 누락이 의미를 바꾸므로 일반 VQA보다 위험도가 크다.

### 후속 최소 실험

1. existence/counting/comparison 각 100개를 stratified sample한다.
2. 같은 output에 대해 AA, Loc-F1, ES-correct, JS를 계산한다.
3. 답을 고정하고 box를 shuffle하는 조건과 box를 oracle로 바꾸는 조건을 추가한다.
4. **GO:** AA–JS gap이 10%p 이상이고 oracle box가 JS를 유의하게 회복.
5. **KILL:** extractor 교체 후 unsupported-correct 비율이 대부분 사라져 모델이 아니라 parsing 문제로 판명.

**평가:** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 4. MVGraph — thinking의 큰 이득 뒤에도 perception과 edge alignment가 붕괴한다

**공식 출처:** [논문](https://arxiv.org/abs/2610.12961) · [HTML 표](https://arxiv.org/html/2610.12961) · [공식 저장소](https://github.com/AAAndy-Zhu/MVGraph)

### 실패 조건

2~8개의 시각 graph view에서 정보를 합쳐야 할 때 non-thinking 모델은 거의 실패하고, thinking을 켜도 multi-view 구조를 정확히 복원하지 못한다. 일부 최종 task의 높은 점수는 작은 answer space가 만드는 metric artifact일 수 있다.

### 모델·데이터·설정

- 37 tasks, 72,000 instances: end-to-end 8,000, perception 36,000, alignment 10,000, composition 8,000, reasoning 10,000
- non-thinking 평균 1.9~6.4%; 논문 본문의 6개 주 모델 범위는 2.6~6.4%
- thinking 최고: GLM-5.3-Flash 52.4%, Qwen3.8-Flash 50.4%; 최고 local model Gemma-4-12B-it 20.5%
- Qwen3.8-Flash는 2.6→50.4%로 상승하지만, API thinking budget은 다른 모델과 동일 compute가 아님
- thinking에서도 모든 모델의 multi-view graph exact match가 47% 이하; Node F1이 Edge F1보다 높음

### 공식 인정과 재현 근거

저자는 end-to-end 점수만으로 perception·alignment·composition·reasoning 병목을 구분할 수 없다고 명시한다. non-thinking에서는 topological sorting과 stable topological sorting이 전 모델 0점이며, maximum-flow change는 작은 선택 공간 때문에 계산 능력을 과대평가할 수 있다고 경고한다. 코드·데이터는 공개됐지만 독립 재현은 확인되지 않았다.

### 의심 원인과 기존 주장과의 충돌

- **확인된 진단:** node보다 edge triple 추출이 어렵고, relation-level alignment와 temporal composition에서 오류가 누적된다.
- **가설:** thinking은 graph algorithm을 회복하기보다 출력 형식·탐색을 보정하며, 잘못 추출된 edge는 후단 reasoning으로 복구하지 못한다.
- “test-time reasoning을 늘리면 multi-image reasoning이 해결된다”는 일반화와 충돌한다. Qwen의 큰 상승은 사실이지만 최고 평균도 절반 수준이고 모델 간 회복 폭이 크게 다르다.
- 자연영상이 아닌 합성 graph이므로 실제 RGB multi-view로의 절대 성능 일반화는 금지한다.

### 후속 최소 실험

1. RGB/thermal/AIS 세 view의 해상 장면 30개에 object identity와 relation edge gold를 만든다.
2. raw image, oracle node, oracle edge, oracle composed graph 네 조건으로 최종 질의를 평가한다.
3. exact match, node/edge F1, final accuracy, reasoning token budget을 기록한다.
4. **GO:** oracle edge가 oracle node보다 최종 정확도를 10%p 이상 더 회복.
5. **KILL:** edge oracle의 회복이 작고 오류가 최종 temporal reasoning에 집중됨.

**평가:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 5. MMStar audit — benchmark leakage 비율도 null correction 없이 과장될 수 있다

**공식 출처:** [논문](https://arxiv.org/abs/2610.13548) · [공식 audit layer와 artifacts](https://github.com/avos-rnd/vlm-bench)

### 실패 조건

이미지가 필수라고 설계된 MMStar에서도 full과 image-blind run의 aggregate accuracy gain이 0인 문항이 나타난다. 동시에 단순히 그 비율을 leakage라고 부르면 permutation null이 설명하는 우연 일치까지 포함해 과장된다.

### 모델·데이터·설정

- VLMEvalKit의 기존 per-question prediction·correctness·metadata를 후처리
- 6개 detector와 visual input을 제거한 text-only rerun 1개
- MMStar, 3-model fixed pool
- zero aggregate image gain: 20.2%
- item-matched permutation null: 17.0%; corrected excess +3.2%p, permutation p=0.001
- parseable 응답에서 모든 모델이 같은 non-gold option을 고른 후보 134개
- judge를 exact string matching으로 바꿔도 결론 유지; discrepancy는 parser가 읽지 못한 한 모델의 free-form answer에 집중

### 공식 인정과 재현 근거

저자는 +3.2%p excess가 mathematics와 science에 집중되지만 “지식이 시각 증거를 대체했다”는 메커니즘 확정에는 item-level review가 필요하다고 제한한다. binary yes/no benchmark에서는 detector calibration이 측정 가능하게 나빠진다고 scope boundary도 공개했다. 코드와 artifacts는 공개됐지만 독립 재현은 확인되지 않았다.

### 의심 원인과 기존 주장과의 충돌

- **확인된 사실:** image indispensability를 표방하는 benchmark에도 image-free excess와 공통 non-gold consensus가 남는다.
- **가설:** 일부 문항은 언어·지식 shortcut, annotation error, parser fragility가 섞여 있다.
- MMStar 전체가 20.2% leakage라는 해석은 null correction과 category localization 때문에 성립하지 않는다.
- benchmark audit의 detector 역시 model pool과 answer format에 의존하므로 audit 점수를 새로운 절대 진실로 쓰면 같은 오류가 반복된다.

### 후속 최소 실험

1. 해상 VQA validation 500개를 full, image-removed, shuffled-image 세 조건으로 실행한다.
2. paired bootstrap CI와 item-matched permutation null을 계산한다.
3. 공통 오답 문항을 annotation error, language shortcut, parser failure로 이중 검수한다.
4. **GO:** corrected image-free excess가 3%p 이상이고 특정 category에 재현.
5. **KILL:** model pool 또는 parser를 바꾸면 excess의 부호·category가 불안정.

**평가:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 6. Beyond the Snowflakes — weather bin의 AP 상승이 robustness를 뜻하지 않는다

**공식 출처:** [논문](https://arxiv.org/abs/2610.13891) · [HTML 실험](https://arxiv.org/html/2610.13891) · [WADS-3D 공식 데이터](https://digitalcommons.mtu.edu/wads-3d/)

### 실패 조건

snow intensity가 높아질수록 다섯 LiDAR detector의 AP가 오르는 역설이 나타난다. weather-only stratification이 객체의 point count·intensity를 통제하지 않아, 더 쉬운 객체가 severe bin에 많이 들어간 결과를 robustness로 오해할 수 있다.

### 모델·데이터·설정

- WADS-3D 4,100 labeled frames, 30,104 cars; CADC 7,000 frames
- SECOND-IoU, Voxel R-CNN, PointPillars, PV-RCNN, Part-A2
- WADS-3D는 KITTI pretrained model을 직접 평가; CADC는 32-channel sensor에 맞춰 50:50 fine-tune/eval
- WADS-3D snow filtering 평균 +6.72% AP; CADC 이득은 미미
- WADS snow bin–object point count: r=0.820, p=3.70e-3
- CADC point count: r=0.733, p=1.86e-3; mean intensity: r=0.694, p=4.12e-3

### 공식 인정과 재현 근거

저자는 object point count가 counter-intuitive performance의 통계적 주원인이라고 결론 내고, surface accumulation·scene smoothing·point inflation은 검증되지 않은 물리 가설로 구분한다. WADS와 CADC는 센서·학습 protocol이 달라 절대 AP 비교는 not strictly apples-to-apples다. 독립 재현은 확인되지 않았다.

### 의심 원인과 기존 주장과의 충돌

- **확인된 진단:** severe snow bin의 차량은 평균 point count와 intensity가 높아 탐지가 쉬웠다.
- **가설:** snow accumulation과 annotation volume 안의 snow return이 작은 객체의 형상을 인위적으로 키운다.
- weather severity별 raw AP를 곧바로 robustness로 해석하는 관행과 충돌한다.
- filtering이 WADS에서 평균 AP를 올려도 severity trend가 남으므로 snow noise 제거만으로 confound가 해소되지 않는다.

### 후속 최소 실험

1. 해무·비·야간 데이터에서 severity × object size × range × contrast cell을 구성한다.
2. cell별 최소 30개를 matching하고 raw AP와 matched AP를 함께 계산한다.
3. object recall에 대한 SHAP 또는 mixed-effects model로 weather와 object meta-factor를 분리한다.
4. **GO:** matching 후 robustness 순위가 2단계 이상 바뀌거나 weather effect가 유의하지 않게 됨.
5. **KILL:** meta-factor를 통제해도 severity effect와 모델 순위가 안정적으로 유지.

**평가:** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 7. 오늘의 실패 패턴 3개

1. **Answer–Evidence Gap:** 정답 문자열과 box F1은 실제 증거 사용을 보장하지 않는다. OccludeBench와 AESP가 서로 다른 방식으로 같은 분리를 드러냈다.
2. **Stage masking:** 최종 점수와 thinking gain은 perception·edge alignment·composition의 붕괴를 숨긴다. oracle intermediate가 없으면 원인 위치를 찾기 어렵다.
3. **Evaluation confound:** image-free null, answer-space 크기, object point count처럼 benchmark 구성 변수가 모델 능력처럼 보일 수 있다.

## 8. 논문 아이디어로 연결 가능한 빈틈

- **Evidence-Calibrated Remote-Sensing VQA:** answer·box·count consistency를 joint objective로 학습하고 unsupported-correct risk를 직접 최소화한다.
- **Physical-Cue VLM for Maritime Safety:** wake·reflection·shadow를 전역 문맥과 분리하는 direct-cue encoder와 hypothesis-confront decoder를 설계한다.
- **Stagewise Multi-View Maritime Benchmark:** RGB/thermal/AIS의 perception→alignment→composition→reasoning을 oracle intervention으로 분해한다.
- **Confound-Matched Adverse-Weather Evaluation:** weather severity와 object area·range·contrast를 matching한 robust AP와 raw AP를 함께 보고한다.
- **Null-Corrected Benchmark Audit:** image-blind·shuffled-image detector에 model-pool sensitivity와 permutation excess를 기본 지표로 포함한다.

## 9. 직접 재현해볼 최소 실험

| 우선순위 | 실험 | 예상 예산 | 핵심 측정 | 판정 |
|---|---|---:|---|---|
| 1 | 자체 VQA 300개에 AESP 적용 | 낮음 | AA, Loc-F1, ES-correct, JS | AA–JS gap 10%p 이상 여부 |
| 2 | VQA 500개 full/blind/shuffled audit | 낮음 | corrected excess, common-wrong, parser failures | excess 3%p 이상과 category 집중 여부 |

| 5 | RGB/thermal/AIS oracle edge 실험 | 중간 | node/edge F1, final accuracy recovery | edge oracle가 최대 회복을 만드는지 |

## 10. 증거 구분과 한계

- **확인된 사실:** 논문 표·abstract·공개 evaluator에서 직접 확인한 수치와 protocol.
- **저자 주장:** evidence selection, answer-grounding inconsistency, edge bottleneck, benchmark confound, point-count confound에 대한 저자 해석.
- **이 레이더의 가설:** global context dominance, late-fusion 분리, reasoning의 formatting 보정, annotation-volume point inflation.
- 다섯 사례 모두 독립 커뮤니티 재현이 아직 확인되지 않아 재현 신뢰도는 최대 4/5로 제한했다.
- 폐쇄형 VLM과 API thinking mode는 버전·compute budget이 달라 모델 간 수치가 strictly apples-to-apples가 아니다.
- 원격탐사·합성 graph·자동차 LiDAR의 절대 결과를 해상 영상으로 직접 일반화하지 않고, 최소 실험의 평가 설계만 이전한다.
