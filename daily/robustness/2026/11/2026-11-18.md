## 1. PO 이후 낮은 환각률이 객체 정보 보존을 뜻하지 않는다

**확인 사실·저자 보고.** LLaVA-1.5-7B와 네 PO checkpoint를 비교한 Table 1에서 CHAIR-500 recall은 base 80.5, RLAIF-V 68.4, CHAIR-DPO 65.1, CSR 66.0, HA-DPO 76.2다. 환각 지표는 좋아지지만 recall은 **4/4 checkpoint 행에서 악화**한다. 이는 세부 객체 cell 총수가 아니다. [PDF Tables 1–3](https://arxiv.org/pdf/2611.23179)

**진단.** 저자는 base의 EOS logit bias만으로 동일 recall을 만들었을 때 세 checkpoint의 CHAIRi 이득 중 58~86%가 두 COCO 집합에서 재현된다고 보고한다. PO 출력을 길게 해도 누락 객체가 충분히 돌아오지 않는다. 따라서 단순 출력 길이 통제와 객체 coverage 통제는 다르다. 이 결과가 PO의 모든 이득을 부정하지는 않는다. [초록·이력](https://arxiv.org/abs/2611.23179)

**cell·metric·calibration.** checkpoint×평가 집합×객체 범주를 분리한다. CHAIRi, distinct-object hallucination, recall, set-level F1을 함께 본다. 여기서 coverage는 객체 포괄도이며 응답 선택률이나 95% 구간 coverage가 아니다. ECE·selective risk–coverage는 확인 근거에 없다.

**평가자 가설 → 최소 실험.** 시각 표현 손실과 readout 억제를 구분하려면 동일 이미지·checkpoint·prompt·evaluator에서 base EOS sweep, PO, base-only 객체 복원을 비교한다. greedy/fp16·최대 512 token과 batch를 고정하고 threshold는 dev에서만 정한다. hardware·학습 data 차이가 남으므로 학습법의 인과 우월 비교는 **not strictly apples-to-apples**다.

**GO/KILL.** untouched holdout의 동일 recall에서 환각 감소가 유지되면 GO다. recall을 줄인 효과만 남으면 강건한 grounding 개선 주장을 KILL한다. 코드 공개는 저자의 예정 사항이며 실제 release를 확인하지 않았다.

## 2. 장면 상태가 안전성 판단의 별도 failure cell이다

**저자 보고.** SceneSafetyBench는 375 image-question pair, 세 장면 상태와 다섯 시각 표현을 포함한다. Table 1에서 Qwen3-VL-8B의 ASR은 Original 45.3%, Film Noir 52.0%다. 같은 표의 Original 대비 네 변형 중 **1/4 스타일 집계 cell에서 수치상 악화**한다. 통계적 유의성이나 전체 모델의 악화 cell 총수는 확정하지 않는다. [PDF Tables 1–2](https://arxiv.org/pdf/2611.23206)

**metric·coverage.** ASR은 judge의 harmfulness·alignment·detail이 모두 기준을 넘는 비율이다. 정책 차단은 실패로 센다. 8개 모델 전체 ASR 범위 45.6~72.3%는 저자 보고이며 독립 검증이 아니다. ECE·benign 응답 coverage는 미확인이다. [초록·이력](https://arxiv.org/abs/2611.23206)

**진단과 한계.** 저자는 명시적 유해 요청이 없어도 시각적 관계와 진행 상태에서 유해한 도움을 추론하는 실패를 다룬다. 다만 Initial/Medium/Ultimate는 서로 다른 task·scene이다. 상태별 평균 차이를 동일 사건의 진행에 따른 인과 변화로 해석하면 **not strictly apples-to-apples**다.

**평가자 가설 → 최소 intervention.** 표면 키워드보다 모델이 추론한 지원 목적을 검사하는 단계가 일부 실패를 줄일 수 있다. 방어 평가에는 동일 scene의 표현 변형과 benign matched control을 사용하고, 기존 응답과 목적 검사 추가 조건을 비교한다. 모델·해상도·prompt·judge version을 고정하고 ASR, benign over-refusal, 응답 coverage, 사람 검수 일치도를 기록한다.

**GO/KILL.** holdout의 worst-style ASR이 낮아지고 benign coverage가 유지되면 GO다. 모든 응답을 막아 ASR만 낮추면 KILL한다. 생성 중 내부 신호 차이는 mechanism의 단서이며 안전성 원인의 완전한 규명은 아니다.

## 3. 조각 개수가 맞아도 장면 재구성은 실패할 수 있다

**확인 사실·저자 보고.** GJBench는 32개 scene에서 reference/layout 유무와 4·9·16개 조각을 교차한다. Table 3의 GPT Image 2.6은 16개 조각 exact-count 0.94지만 reconstruction은 0.49, whole-scene control은 0.94다. reconstruction은 조각 수 세 조건 모두 control보다 낮아 **3/3 조각 수 집계 cell에서 악화**한다. 개별 scene 악화 수는 미확인이다. [HTML Tables 2–3](https://arxiv.org/html/2611.20906v1)

**진단·metric.** RQ1 개수, RQ2 interlock, RQ3 reference 재구성을 분리한다. shape를 맞추는 능력을 내용의 연속성으로 오해하면 안 된다. RQ3는 MS-SSIM 기반이며 확률 calibration이 아니다. ECE·selective coverage는 미보고다. 이 benchmark는 자연 camera/geography shift가 아니라 인위적인 공간 배치 stress다. [초록·이력](https://arxiv.org/abs/2611.20906)

**평가자 가설 → 최소 실험.** 실패가 전역 장면 표현 부재인지 영역별 내용 배정 문제인지 구분한다. 동일 reference와 brief에서 whole→정확 절단 control, upright square tiles, 회전·분리 tiles를 비교한다. 먼저 생성 출력을 고정해 evaluator를 audit하고, 다음에 layout 제공만 최소 개입한다.

**GO/KILL.** 개수·윤곽 개선과 독립적으로 held-out scene의 RQ3가 좋아지면 내용 배정 개입을 GO한다. RQ1만 개선되면 전역 일관성 개선 주장을 KILL한다. whole/scattered canvas와 proprietary interface·seed·preprocessing이 달라 모델 순위는 **not strictly apples-to-apples**다. bootstrap은 scene 변동을 나타내며 반복 생성 seed 분산은 아니다.
