## 1. SpatialChain SFT — 내부 개선과 외부 성능 저하

**실패 조건·구성:** Qwen3-VL-4B를 SpatialChain으로 SFT한 뒤 ERQA와 EmbSpatial-Bench에서 평가한다. 저자는 내부 정확도가 78.4→82.2%로 개선되지만, ERQA는 45.3→38.0%, EmbSpatial-Bench는 79.1→75.7%로 하락했다고 보고한다. v1 제출은 10월 5일 23:29:54 KST다. [제출 이력](https://arxiv.org/abs/2610.06413), [본문 §6.4·부록 I.3](https://arxiv.org/html/2610.06413v1)

**공식 인정·재현 근거:** 저자가 직접 보고한 negative transfer다. 독립 community reproduction은 확인하지 못했다. 논문은 동일 외부 추론 설정의 checkpoint별 평가를 제시한다. 학습은 NF4 4-bit·LoRA rank 16·2 epochs·seed 3407·이미지 긴 변 640px이며 A100 80GB를 사용했다. 공식 저장소의 학습·평가 안내는 확인했으나, 배포 checkpoint와 논문 실행의 immutable revision 일치는 검증하지 않았다. [공식 코드](https://github.com/spatialchain/SpatialChainBenchmark)

**진단·충돌:** “SFT가 공간 추론 전반을 개선한다”는 일반화와 충돌한다. 저자는 출력 형식의 특화를 원인으로 해석한다. **추론:** 스타일 변화, 지식 망각, decoding 민감도가 함께 작용할 가능성을 열어둬야 한다. 서로 다른 평가셋의 절대 점수 비교는 **not strictly apples-to-apples**이며, 같은 셋의 base/FT 비교가 진단 대상이다.

**가설→최소 개입→실험:** 동일 외부 샘플에서 base/FT × 기본/간결 답변 지시를 비교한다. 해상도·seed·토큰 예산·답 파서를 고정하고 accuracy, 잘린 응답률, 길이, 형식 빈도를 기록한다. FT만 지시 변경으로 회복하면 형식 민감성 가설을 지지하지만 지식 보존을 확정하지는 못한다. 변화가 없으면 스타일만으로 설명하는 가설을 약화한다.

**점수:** 심각도 4/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 4/5.

## 2. Readout Blindness — 높은 정확도와 낮은 이미지 기여의 공존

**실패 조건·구성:** VALSE actant-swap의 Qwen3.6 likelihood 평가에서 저자는 원본 정확도 93.99%, 다른 이미지로 교체한 null 정확도 88.41%를 보고한다. 원본 이미지의 추가 기여는 약 5.6%p다. direction-balanced VG-Relation에서는 같은 모델의 gain이 약 25.5%p여서, “모델이 이미지를 전혀 쓰지 않는다”로 일반화할 수 없다. v1 제출은 10월 5일 22:36:45 KST다. [제출 이력](https://arxiv.org/abs/2610.06324), [표 1과 평가 정의](https://arxiv.org/html/2610.06324v1)

**공식 인정·재현 근거:** 저자가 제시한 metric artifact·readout 진단이며 독립 재현은 미확인이다. 공식 ADR 저장소에 real/null 설정과 샘플 목록이 있다. 원본 이미지는 별도 준비해야 하고 `--limit`은 null 풀도 바꾼다. VSR의 일부 비교는 real/null 각각 oracle threshold를 사용한다. [공식 평가 도구](https://github.com/GarryLarry010131/ADR)

**진단·충돌:** 높은 accuracy를 곧바로 시각 grounding의 증거로 읽는 해석과 충돌한다. **저자 해석:** 언어·세계 지식 prior가 점수를 올린다. **추론:** 이 null은 이미지-문장 결합 효과를 측정하는 대조군이지 grounding의 완전한 인과적 측정은 아니다. 모델·readout 간 비교는 **not strictly apples-to-apples**다.

**가설→최소 개입→실험:** 동일 frozen CLIP과 caption에서 원본/무관 이미지 × deployed/ADR을 비교한다. source image가 같은 null 짝을 배제하고 전체 목록을 고정한다. real/null accuracy, gain과 paired bootstrap 신뢰구간을 산출한다. null에서도 높은 점수가 유지되면 원본 accuracy 중심의 판단을 보류한다. 같은 encoder의 ADR gain 개선은 readout 병목 가설을 검토하는 근거가 된다.

**점수:** 심각도 4/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 5/5.

## 3. BabelFake — 정상 오디오가 유지될 때 영상 조작 탐지 취약

**실패 조건·구성:** BabelFake의 identity-disjoint 70/10/20 split에서 cross-dataset detector를 평가한다. SpeechForensics는 전체 AUC 79.79지만 KeySync + real audio에서 43.75다. metric은 AUC이며 고정 threshold 정확도가 아니다. v1 제출은 10월 5일 22:42:34 KST다. [제출 이력](https://arxiv.org/abs/2610.06339), [평가 §6.1–6.2·표 3](https://arxiv.org/html/2610.06339v1)

**공식 인정·재현 근거:** 저자가 직접 보고한 조건별 실패다. SpeechForensics는 LRS3·VoxCeleb2로 학습한 시청각 동기화 기반 모델이다. 독립 재현과 벤치마크 evaluator revision은 미확인이다. 논문 §7은 기관 확인·데이터 이용 동의 및 비상업 연구 라이선스를 통한 접근을 명시한다. 공개 다운로드가 확인되지 않는 점을 단순 링크 누락으로 해석하면 안 된다.

**진단·충돌:** 전체 AUC의 강점을 모든 조작 조건에 확장하는 해석과 충돌한다. **저자 해석:** 정상 오디오 조건에서의 저하는 동기화 단서 의존을 시사한다. **추론:** 생성기·압축·identity 차이도 대안 원인이다. 전체와 한 subset의 점수 차이는 오디오만의 인과 효과가 아니며 **not strictly apples-to-apples**다.

**가설→최소 개입→실험:** 데이터 접근 후 동일 생성기·identity·언어를 맞춘 real/fake audio 조건을 비교한다. 동일 detector·frame budget·전처리·score 방향을 고정하고 조건별 AUC와 identity 단위 bootstrap을 기록한다. matched 조건에서도 차이가 유지돼야 오디오 shortcut 가설을 강화할 수 있다. 43.75를 보고 score 부호를 임의로 뒤집어 성능 개선으로 제시하지 않는다.

**점수:** 심각도 4/5 · 재현 신뢰도 2/5 · 연구 아이디어 가치 4/5.

## 오늘의 실패 패턴 3개

1. **학습 데이터에 맞춘 개선의 외부 전이 실패:** 내부 점수와 외부 유지 성능을 함께 측정한다.
2. **시각 근거 없이 유지되는 높은 점수:** 원본 이미지 accuracy와 이미지 교체 gain을 분리한다.
3. **한 modality의 단서에 의존한 조건별 붕괴:** 통합 점수와 matched 조건별 평가를 함께 기록한다.

## 논문 아이디어로 연결 가능한 빈틈

우선 빈틈은 **공간 SFT의 외부 저하를 출력 형식 민감성과 지식 변화로 분해하는 진단**이다. 오늘 Benchmark의 readout 진단과 구분해, training으로 생긴 전이 실패를 대상으로 한다. 기본 출력의 악화만으로 forgetting을 단정하지 않고 답변 지시 개입과 checkpoint 추이를 함께 본다.

학습 없이 시작할 수 있지만, 이미 논문이 스타일 특화를 제안했으므로 관찰 반복만으로 novelty는 낮다. 대안 원인을 반증하고 다른 checkpoint·평가셋에서도 성립하는 경계를 찾아야 연구 가치가 생긴다.

## 직접 재현해볼 최소 실험

첫 실험은 기존 base/FT 예측 파일을 확보해 공통 answer parser로 accuracy와 잘린 응답률을 다시 집계하는 것이다. 다음에 외부 두 평가셋에서 사전 고정한 각 50개 진단 샘플로 2×2 지시 개입을 수행한다. 이 소규모 결과는 전체 벤치마크 재현이나 논문급 효과 추정으로 보고하지 않는다.

**GO:** FT의 저하가 지시 개입으로 선택적으로 줄어들고 다른 평가셋에서도 같은 방향이다. **KILL/수정:** 파서 차이만으로 결과가 사라지거나 지시 개입 효과가 base와 동일하다. 예측 파일·checkpoint 접근이 어려우면 frozen CLIP real/null 평가로 전환한다. 8GB에서의 적합성과 속도는 실행 전에 측정하며 가능하다고 단정하지 않는다.
