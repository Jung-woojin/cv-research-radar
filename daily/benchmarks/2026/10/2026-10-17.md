## 1. Digital Typhoon Dataset V3 — 다중분광 추가보다 split·basin·강도 편향이 더 큰 변수

**무엇이 바뀌었나.** 공식 저장소는 Dataset V3를 2026-10-16 공개 버전으로 명시한다. 약 50년의 태풍 중심 위성 영상에 다중분광 입력을 추가하고, 북반구 WP와 남반구 AU 데이터를 별도로 평가한다. 이는 단순 데이터 증량보다 장기 시계열·반구·spectral channel을 함께 통제하는 benchmark revision이다.

**확인된 사실.** 공식 저장소는 V3가 WP와 AU를 포함하며 CC BY 4.0, DOI `10.20783/DIAS.664`로 배포된다고 밝힌다. 논문은 data split 전략, image type, spectral channel, architecture를 비교한다.

**저자 주장.** 현재 구성과 실험 조건에서 pressure regression은 multi-channel이 single-channel을 명확히 이기지 못했다. 단일 채널에서는 ResNet-18, full-resolution image, Channel 1이 대체로 가장 좋았다. WP는 pressure RMSE가, AU는 wind RMSE가 더 낮았고, 강한 태풍 강도를 과소추정하는 체계적 편향은 inverse-density weighting을 포함한 imbalance-aware weighting으로 충분히 제거되지 않았다.

**동일 조건 비교.** channel 수만 다른 실험이라도 basin, target, image type, resolution이 같아야 한다. WP pressure와 AU wind 결과를 하나의 “더 좋은 dataset” 순위로 합치면 안 된다. V1용 Hugging Face weight는 공식 README가 obsolete로 표시하므로 V3 재현의 동일 checkpoint로 간주할 수 없다.

**진단 → 가설 → 최소 실험.**

- 진단: 평균 RMSE가 강한 태풍 tail의 과소추정을 숨기며, channel 추가 효과가 split/basin 차이보다 작을 수 있다.
- 가설: 강도 구간별 calibration과 temporal context를 함께 쓰면 단순 density weighting보다 tail bias를 줄인다.
- 최소 실험: 동일 ResNet-18·resolution·split에서 Channel 1, all-channel early fusion, late fusion을 비교한다. 전체 RMSE와 함께 intensity decile별 bias, strongest 10% MAE, WP→AU 교차-basin 성능을 보고한다.
- GO/KILL: strongest 10% bias가 줄면서 전체 RMSE 악화가 2% 이내면 계속하고, 평균만 좋아지고 tail bias가 유지되면 중단한다.

**판정.** 해양·기상 CV에 직접적인 강한 신호다. 핵심 변화는 “채널 추가=SOTA”가 아니라 장기 자료의 조건별 편향을 benchmark의 일부로 드러낸 점이다.

- 공식 원문: https://arxiv.org/abs/2610.21654
- 공식 저장소: https://github.com/kitamoto-lab/digital-typhoon
- 공식 데이터 페이지: https://agora.ex.nii.ac.jp/digital-typhoon/dataset/

## 2. RLDF — 전체 얼굴 deepfake에서 부분 영역 조작으로 평가 단위 이동

**무엇이 바뀌었나.** RLDF는 full-face swap·fully synthesized face 중심의 기존 deepfake 평가를 eye, nose, mouth, eyebrow와 composite region을 포함한 부분 조작으로 확장한다. 세 개 evaluation protocol에서 12개 detector를 다섯 개 표준 cross-dataset evaluation, DF40, RLDF에 걸쳐 감사한다.

**확인된 사실.** 논문은 8개 face-swapping method로 200만 장 이상의 partial face-swap image를 생성했다고 밝힌다. 공식 GitHub에는 sample data와 evaluation/test split만 공개돼 있다. README는 전체 benchmark가 약 1TB이며 full dataset, training split, preprocessing pipeline, complete resources는 acceptance 이후 공개한다고 명시한다.

**저자 주장.** 기존 detector는 region-level evaluation에서 전체적으로 AUC 10.5%p, accuracy 10%p가 하락했다. mask-guided cross-attention을 baseline으로 제시한다.

**동일 조건 비교.** 이 하락치는 저자가 정의한 protocol 안에서의 aggregate다. detector별 backbone·학습 데이터가 달라 raw accuracy 순위를 architecture 우열로 읽으면 안 된다. 공개 test split으로 평가는 가능하지만, full training data와 preprocessing이 아직 없으므로 end-to-end 재현 가능성은 제한적이다. 따라서 “dataset·code·checkpoint 공개”라는 논문 문구는 오늘의 실제 저장소 상태와 완전히 일치하지 않는다.

**진단 → 가설 → 최소 실험.**

- 진단: global pooling 기반 detector가 작은 조작 영역의 signal을 배경·미조작 얼굴에 희석한다.
- 가설: area-normalized regional scoring 또는 multi-scale P2 feature가 작은 facial region에서 recall을 높인다.
- 최소 실험: 공개 evaluation split에서 full-face와 각 region별 AUROC, 5% FPR TPR, calibration error를 측정한다. detector score를 region area로 층화하고 global baseline과 mask-guided crop ensemble을 비교한다.
- GO/KILL: 작은 영역 quartile의 TPR이 5%p 이상 개선되고 full-face 성능 손실이 1%p 이내면 확장한다.

**판정.** small/tiny-object와 유사한 “signal dilution” 문제를 deepfake 평가에서 명확히 드러낸다. 다만 현재는 partial release이므로 leaderboard 성능보다 공개 범위와 protocol version을 함께 기록해야 한다.

- 공식 원문: https://arxiv.org/abs/2610.21438
- 공식 저장소: https://github.com/RLDF-Dataset/RLDF
- 공개 sample/evaluation split: https://huggingface.co/datasets/RLDF/RLDF-benchmark/tree/main

## 3. VELD-QA — 장문서 VQA를 검색 실패와 시각 해석 실패로 분리

**무엇이 바뀌었나.** VELD-QA는 5,859개 실제 PDF, 372,445쪽, 15,000개 human-authored QA pair에 supporting page와 visual evidence element annotation을 붙인다. chart, table, complex layout을 포함하며 retrieval과 interpretation을 별도로 평가한다.

**확인된 사실.** 논문은 9개 VLM을 네 가지 evidence setting으로, 7개 retrieval-augmented/agentic system을 평가한다. arXiv가 연결한 공식 GitHub `oracle-samples/veld-qa`는 확인 시 404를 반환했다. 따라서 code availability는 현재 공개 접근 상태에서 확인되지 않았다.

**저자 주장.** retrieval system은 ground-truth supporting page를 주는 oracle보다 크게 낮고, full-document access도 격차를 닫지 못했다. oracle accuracy의 최고값도 81.7%이며, visual-element annotation을 입력에 추가하면 격차가 17–24% 좁아졌다.

**동일 조건 비교.** retrieval, full-document, oracle은 접근 가능한 evidence와 context budget이 다르므로 한 줄 leaderboard로 섞으면 안 된다. “17–24%”가 absolute percentage point인지 relative improvement인지 abstract만으로 확정할 수 없어 본 보고서는 원문 표현을 유지한다. evaluator와 모델별 context/frame budget도 동일해야 직접 비교가 가능하다.

**진단 → 가설 → 최소 실험.**

- 진단: Answer–Region Gap은 supporting page를 찾는 단계와 그 안의 chart/table을 해석하는 단계에 동시에 존재한다.
- 가설: page retrieval 뒤 element-level crop과 citation-constrained answer를 쓰면 정답률보다 먼저 evidence precision이 개선된다.
- 최소 실험: 200문항에서 full document, top-5 pages, oracle page, oracle visual element 네 조건을 동일 VLM로 비교한다. answer accuracy, supporting-page recall, element IoU/precision, citation faithfulness를 따로 기록한다.
- GO/KILL: oracle page→oracle element에서 정확도가 크게 오르면 element localization 연구를 계속하고, 차이가 작으면 reasoning bottleneck을 우선한다.

**판정.** evidence-grounded VQA에 매우 강한 신호다. 그러나 오늘은 공식 code URL이 접근되지 않으므로 dataset schema와 evaluator를 직접 재현 가능한 상태로 간주하지 않는다.

- 공식 원문: https://arxiv.org/abs/2610.20964
- arXiv 연결 코드 URL: https://github.com/oracle-samples/veld-qa

## 4. ViSiP-Bench — “이미지 없이 맞힌 정답”을 제거한 language-prior 평가

**무엇이 바뀌었나.** ViSiP-Bench는 rare-but-real scenario를 여섯 prior category로 구성하고, model-aware dynamic prior induction과 세 가지 연속 metric으로 시각 증거가 언어 prior를 이기는지를 측정한다.

**확인된 사실과 저자 주장.** 저자는 모델 간 prior agreement가 80% 미만이며, 15%가 넘는 문항은 이미지 없이도 정답을 맞힐 수 있어 기존 accuracy가 prior resistance를 과대평가한다고 보고한다. 24개 모델 평가에서는 prior adherence가 널리 나타났고 scale 증가로 일관되게 개선되지 않았다.

**동일 조건 비교.** 동적 prior induction은 모델별로 다른 prior를 측정하므로 동일 고정 문항 accuracy와 목적이 다르다. 기존 VQA leaderboard와 직접 합치면 `not strictly apples-to-apples`다. MAPS fine-tuning 효과 역시 모델별 strongest prior를 사용하므로 data mixture와 training budget을 맞춰야 한다.

**진단 → 가설 → 최소 실험.**

- 진단: 정답률은 모델이 이미 알고 있던 prior로 우연히 맞힌 경우와 실제 image evidence를 사용한 경우를 구분하지 못한다.
- 가설: image ablation, counter-prior image, evidence crop을 함께 평가하면 “정답은 맞지만 근거는 틀린” 사례를 분리할 수 있다.
- 최소 실험: 동일 100문항에 image, blank image, contradictory image, evidence crop 네 조건을 넣고 accuracy와 answer flip rate, region-grounding score를 함께 측정한다.
- GO/KILL: 정확도는 유지되는데 evidence crop에 대한 민감도가 낮고 blank-image 성능이 높으면 grounding-aware training으로 확장한다.

**판정.** Answer–Region Gap 연구에 바로 연결되는 metric signal이다. 큰 모델의 평균 accuracy 상승을 시각 grounding 향상으로 자동 해석하지 말아야 한다.

- 공식 원문: https://arxiv.org/abs/2610.21902

## 5. FusionAudit / PaRMA — 단일 adversarial score에서 공격 경로별 위험으로 이동

**무엇이 바뀌었나.** PaRMA는 image-level intervention을 pixel perturbation과 rendered-text insertion의 두 pathway로 나누고, native multimodal architecture가 각 경로에 보이는 blind spot을 평가한다. FusionAudit은 MANTIS와 Nat-Evid라는 진단 기반 공격을 추가한다.

**확인된 사실과 저자 주장.** 논문은 18개 open-weight VLM을 nativeness taxonomy에 따라 평가했다. 저자는 legacy single-attack ranking, 특히 PGD 중심 순위가 native model에서 불안정하며, diagnostic-driven attack이 standard benchmark가 놓친 residual risk를 더 크게 드러낸다고 주장한다. native VLM이 typographic overlay를 강하게 attend하면서도 시각적으로는 거부하는 `see-but-not-deceived` signature와, deep-fusion model의 encoder-level/answer-level objective mismatch도 보고한다.

**동일 조건 비교.** pixel attack과 semantic text insertion은 threat model, perturbation budget, 성공 정의가 다르므로 하나의 scalar로 평균내면 안 된다. 18개 모델의 architecture와 tokenizer·resolution도 다르며, 동일 epsilon·query budget·answer evaluator가 확인되지 않으면 model 순위 비교는 제한적이다.

**진단 → 가설 → 최소 실험.**

- 진단: 같은 “robustness” 점수라도 visual encoder를 흔드는 공격과 rendered instruction으로 answer pathway를 흔드는 공격은 다른 실패다.
- 가설: evidence-grounded answer constraint는 semantic insertion에는 효과가 있지만 pixel-level perturbation에는 제한적이다.
- 최소 실험: 2개 open-weight VLM에 clean, PGD-like pixel, plain overlay, host-congruent overlay를 동일 100개 image-QA sample로 적용한다. clean accuracy, attack success, evidence-region consistency, answer confidence를 pathway별로 보고한다.
- GO/KILL: defense가 한 pathway만 개선하고 다른 경로를 악화시키면 단일 robustness score를 폐기하고 pathway profile을 유지한다.

**판정.** leaderboard보다 audit protocol의 이동이 핵심이다. VLM 안전성과 grounding을 연구할 때 공격 종류를 섞은 평균 점수 대신 pathway-conditioned matrix가 필요하다.

- 공식 원문: https://arxiv.org/abs/2610.21667

## 오늘의 benchmark signal 3개

1. **평균값을 slice로 분해하라.** 태풍 강도, 얼굴 조작 영역, evidence 위치처럼 운영상 중요한 tail이 평균 RMSE·AUC·accuracy에 가려진다.
2. **정답과 근거를 분리하라.** VELD-QA와 ViSiP-Bench는 answer correctness만으로 시각 근거 사용을 증명할 수 없음을 보여준다.
3. **공개 상태를 benchmark 점수와 함께 기록하라.** RLDF는 부분 공개이고 VELD-QA의 연결 코드 URL은 접근되지 않았다. 재현 가능성은 논문 문구가 아니라 실제 artifact 상태로 판정해야 한다.

## 내 연구에 바로 연결되는 포인트

- 해무·해양 CCTV 및 위성 자료에서 평균 성능과 함께 visibility/intensity decile별 bias를 보고한다. 강한 해무·강한 태풍 같은 tail을 별도 calibration 대상으로 둔다.
- small-object detection은 object size·visible area별 AP와 5% FPR TPR을 함께 사용해 signal dilution을 확인한다. RLDF의 region-area slice를 그대로 응용할 수 있다.
- VQA는 answer accuracy, supporting-frame/page recall, region overlap, citation faithfulness를 분리한다. oracle evidence 조건을 추가해 retrieval과 reasoning 병목을 구분한다.
- VLM robustness는 pixel corruption, text overlay, contradictory context를 별도 pathway로 평가한다. 하나의 평균 robustness 점수로 합치지 않는다.
- RTX 5060 Ti 8GB 최소 실험은 대규모 학습 없이 공개 sample을 이용한 slice audit로 제한한다. image ablation·crop ensemble·calibration 분석부터 수행한다.
