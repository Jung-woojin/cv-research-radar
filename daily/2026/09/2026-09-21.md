1. **Adaptation을 할지 말지 자체가 학습 문제가 되고 있다.** Should This Case Be Adapted?는 평균 TTA 성능이 비슷해 보여도 개별 sample 절반 이상을 악화시킬 수 있음을 보여줬다.

5. Edge/system 연구는 큰 foundation model을 직접 deploy하기보다 **semantic teacher → small specialist**와 task-oriented communication으로 이동하고 있다.

# CV / DL-CV 핵심

## 1. Should This Case Be Adapted? Prediction Fragmentation Controls Test-Time Adaptation
**v1: 2026-09-17**

Cross-vendor cardiac MRI에서 평균 Dice 변화는 거의 0에 가깝지만, 실제로는 **58.7%의 individual case가 adaptation 이후 악화**됐다.

저자들은 source prediction과 adapted prediction 간 spatial disagreement geometry를 **prediction fragmentation**으로 정의하고, case-level로 adaptation을 accept/reject한다.

결과:
- harmful accepted area 감소
- harmed case 비율 58.7% → 약 20%
- gradient norm 기반 controller보다 가벼운 판단 비용

핵심 메시지:
> TTA의 핵심 질문은 “몇 step adapt?” 이전에 “이 sample을 adapt해야 하나?”다.

연구 연결:
- fog/night CCTV selective adaptation
- streaming detection commit/rollback
- adaptation harm diagnosis

## 2. SenseFuse: Label-Free Fusion of Image and Shape Encoders for Open-Vocabulary 3D Instance Segmentation
**v1: 2026-09-17**

2D image encoder와 3D shape encoder의 **오류가 서로 다르다는 점**을 활용.

큰 fusion network를 학습하는 대신 scene마다 label-free scalar mixing weight를 계산한다.

주요 결과:
- 22개 instance-AP setting 중 21개 개선
- oracle fusion gain의 median 약 93% 회수
- pre-extracted feature 제공
- core table은 CPU PyTorch만으로도 재현 가능한 수준

핵심 finding:
> 가장 정확한 두 encoder보다 **서로 다르게 틀리는 두 encoder**가 fusion에 더 가치 있을 수 있다.

## 3. PointEvent: Rethinking Event-based Tiny Object Detection via Serialized Motion Evidence Accumulation
**v1: 2026-09-17**

Tiny UAV event detection의 문제를 **spatiotemporal receptive-field dilemma**로 정의.

- spatial neighborhood를 크게 하면 clutter 증가
- 작게 하면 시간에 흩어진 target evidence가 끊김

해결:
- spatial-temporal order
- timestamp order

두 sequence로 serialize한 뒤 Mamba-style state-space scan으로 evidence를 누적.

EV-UAV:
- IoU 75.56
- ACC 81.61
- detection probability 91.75
- 0.06M params
- 29.7ms

Ablation:
- random serialization < timestamp-only < spatial-temporal-only < dual-order full model

핵심 메시지:
> Small-object context는 반드시 더 큰 spatial RF일 필요가 없다.

## 4. Cross-Architecture Foundation-Model Distillation for Edge Flood Segmentation
**v1: 2026-09-17**

300M Prithvi-EO-2.0 teacher → 0.7M EfficientViT-B0 student.

252 manual labels에 teacher pseudo-label을 더해 약 2,500 Sentinel-2 scene까지 확대.

결과:
- Sen1Floods11 student IoU 약 0.787 vs teacher 0.822
- INT8 TensorRT
- 약 1.5MB
- Jetson Xavier NX에서 512×512 약 5.57ms
- device memory 약 14MB

중요한 점은 일부 clean benchmark에서 **고정 MNDWI threshold가 경쟁력 있다는 control/negative result**도 숨기지 않았다는 것.

## 5. A Smaller Transformer in Your Transformer
**v1: 2026-09-17 · BMVC 2026**

DINOv2/DINOv3/DeiT-III intermediate representation을 보면 여러 layer가 실제로는 비슷한 computational phase를 반복한다는 관찰.

TWT는 contiguous layer group을 하나의 learned surrogate Transformer layer로 합친다.

핵심 의미:
> depth가 늘어난다고 모든 layer가 새로운 abstraction을 만들지는 않을 수 있다.

CNN에도 residual blocks가 redundant computational phase로 collapse 가능한지 묻는 후속 연구가 가능하다.

## 6. Task-Oriented Semantic Feature Transmission for Multi-Task Satellite Remote Sensing over Low-SNR Channels

# 1위 미니 리뷰 요약

Should This Case Be Adapted?의 핵심은 평균 TTA gain이 individual harm를 숨길 수 있다는 점.

기존:
```
M0 -> M1 -> M2 -> ... -> MK
```

질문을:
1. adaptation이 필요한가?
2. 필요하면 몇 step인가?

로 분리한다.

Detection으로 옮기면:
- box birth/death
- IoU correspondence break
- class drift
- confidence redistribution
- spatial cluster fragmentation

으로 adapted prediction의 위험을 GT 없이 추정하는 연구가 가능하다.
