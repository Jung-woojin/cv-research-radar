### 3.1 Rethinking the Design Space of Vanilla Pixel Diffusion Transformers

- **날짜/상태:** arXiv:2610.23854v1, 2026-10-16.
- **확인된 사실:** MFlow는 PCA 방향마다 clean-image prediction과 velocity prediction 사이의 연속 gain을 학습한다. 모델 용량이 커질수록 velocity 쪽 선호가 증가하며, JiT 계열의 0.5–0.7 radial frequency 결손을 별도 진단한다. ConvRefiner는 backbone을 고정한 채 전체 학습량의 약 5%에 해당하는 post-hoc 학습으로 고주파 통계를 복원하면서 FID를 유지했다고 보고한다.
- **저자 주장:** 예측 parameterization과 고주파 복원은 서로 보완적이며 ImageNet, UCF-101, 대규모 text-to-image에 일반화된다.
- **평가/재현성:** ImageNet·UCF-101·text-to-image를 사용하고 hyperparameter/ablation 부록과 프로젝트 페이지를 제공한다. 다만 ConvRefiner의 perceptual·adversarial loss가 실제 texture 충실도보다 지각적 sharpness를 선호할 수 있다.
- **추론:** pixel-space 생성의 병목은 `latent 유무` 한 축이 아니라 target conditioning과 local-frequency pathway의 결합 문제다.
- **최소 실험:** 같은 JiT checkpoint에서 x0/u/MFlow를 고정 compute로 비교하고 FID와 RAPS 0.5–0.7 대역 오차를 동시에 기록한다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.23854), [프로젝트](https://soumik-kanad.github.io/mflow-diffusion/)

### 3.2 Diversity Without Labels: Task-Agnostic Coreset Selection Across Perception and Action

- **날짜/상태:** arXiv:2610.23642v1, 2026-10-16.
- **확인된 사실:** proxy training이나 라벨 없이 pretrained feature 분포의 coverage와 fidelity로 coreset을 고른다. image classification, semantic segmentation, metric depth, end-to-end driving, imitation learning을 포함한 7개 dataset-task 조합과 5,265개 과거 run으로 선택 통계의 예측력을 분석했고, 실제 학습은 3 seeds로 수행했다.
- **저자 주장:** 한 task에 맞춘 점수보다 분포 다양성을 보존하는 통계가 여러 perception/action 과업에 공통으로 쓸 수 있다.
- **재현성:** 세부 설정과 pseudocode는 제공하지만 코드는 acceptance 후 공개 예정이라 현재 즉시 재현성은 중간 수준이다.
- **의심/한계:** foundation feature의 편향이 coreset 정의에 그대로 들어간다. 드문 class나 safety-critical tail이 feature-space coverage에서 충분히 보존되는지 별도 확인이 필요하다.
- **최소 실험:** 데이터 10% budget에서 random, k-center, 제안법을 동일 iteration으로 학습하고 평균 성능뿐 아니라 rare-class recall을 비교한다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.23642), [프로젝트](https://coredna.cs.uni-freiburg.de/)

### 3.3 Stereo LWIR–RGB Automatic Labeling for Low-Light Camera-Based VRU Detection

- **날짜/상태:** arXiv:2610.23621v1, 2026-10-16.
- **확인된 사실:** 저조도 RGB에서 직접 라벨을 만들기 어려운 문제를 stereo LWIR detector의 box를 RGB로 옮겨 해결한다. 1,440-frame/1,173-instance test sequence에서 YOLOv11l 기준 수동 441-frame fine-tuning의 mAP@50 0.188 대비 자동 라벨 51,483-frame 학습이 0.282를 기록했다. 반면 mAP@50-95는 0.097에서 0.124로만 증가해 localization 정밀도는 제한적이다.
- **저자 주장:** 최적 설정은 confidence 0.25, pedestrian-height threshold 2%였고, mAP@50에서 자기 수동 baseline보다 41.7%, 최고 baseline보다 38.2% 높았다.
- **한계:** 카메라 동기화와 cross-modal label transfer 오차가 localization을 제한한다. 단일 rig/sequence split의 일반화도 미확인이다.
- **추론:** label volume이 작은 정밀 라벨을 이길 수 있지만, detection과 localization 지표를 분리해야 이득을 과장하지 않는다.
- **최소 실험:** 2%, 4% height filter 두 조건에서 temporal alignment 보정 전후 mAP@50과 mAP@50-95를 함께 측정한다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.23621)

### 3.4 Learning to Discriminate Scene Structures Makes Self-Supervised Depth Learning Scalable

- **날짜/상태:** arXiv:2610.23600v1, 2026-10-16.
- **확인된 사실:** MaSS는 self-supervised monocular depth가 여러 dataset을 함께 학습할 때 dataset-specific scene structure를 암기해 최적화 충돌을 만드는 문제를 다룬다. 150K에서 TartanAir 50K를 추가한 200K 설정은 challenging OOD(DIML, DIODE)에서 평균 Abs Rel 4.3%, δ1 3.0% 개선을 보였지만, 원 학습 도메인 변화는 +1.5%/+0.2% 수준이었다.
- **평가:** KITTI, DDAD, NYUv2, nuScenes를 학습에 사용하고 Waymo, DrivingStereo, Cityscapes, DIML, iBims, SUN-RGBD, 7-Scenes, DIODE로 zero-shot을 본다. 예를 들어 200K 모델은 DIML Abs Rel 0.087/δ1 0.929를 기록했다.
- **저자 주장:** 구조 판별을 통해 다양한 self-supervised data를 추가할 때의 충돌을 완화한다.
- **한계:** 저자도 200K가 supervised depth foundation model 규모보다 훨씬 작아 scalability 증거가 예비적이라고 명시한다. 일부 유사 OOD 지표는 소폭 악화됐다.
- **최소 실험:** 두 도메인만 섞은 작은 실험에서 gradient cosine conflict와 zero-shot Abs Rel을 같이 기록해 구조 분리 모듈의 원인을 검증한다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.23600)

### 3.5 MaskMerge: Structure-aware Token Merging for Efficient Instance Segmentation

- **날짜/상태:** arXiv:2610.22921v1, 2026-10-16.
- **확인된 사실:** similarity-only merging이 서로 붙은 동종 인스턴스의 token을 합치는 `cross-instance fusion`을 진단하고, intermediate coarse mask로 같은 instance 안에서만 merge한다. PanNuke에서 ALGM 대비 mAP 30.1→32.1, 229→153 GFLOPs, 121.5→142.8 images/s; iSAID에서 33.1→36.2 mAP, 198→182 GFLOPs, 168.8→206.9 tiles/s를 보고한다. Cityscapes는 19.8 AP를 유지하면서 347→298 GFLOPs다.
- **평가/ablation:** PanNuke, iSAID, Cityscapes; DINOv2/MAE pretraining과 Mask2Former 확장을 확인했다. 동일 token budget에서 cross-instance merge는 ALGM보다 각각 5.7배, 2.9배 적었다.
- **한계:** coarse mask가 틀리면 merge constraint도 틀린다. throughput은 FP16, batch 4의 특정 환경 값이라 다른 hardware에서 재측정해야 한다.
- **추론:** 효율화 기준은 feature redundancy가 아니라 task-level equivalence여야 한다.
- **최소 실험:** crowded nuclei subset에서 cross-instance merge rate와 mAP를 token budget별로 그려 causal link를 확인한다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.22921)

- **출처:** [arXiv 원문](https://arxiv.org/html/2610.23125)

### 4.1 Not Every Mention Is a Claim: Rethinking Object Hallucination Detection in VLMs

- **날짜/상태:** arXiv:2610.23610v1, 2026-10-16; 데이터 공개.
- **확인된 사실:** NAME-Bench는 COCO 이미지에 5개 VLM이 생성한 caption의 25,497 object mentions를 concrete, hallucinated, non-assertive로 구분하고 후자를 depictive/purpose/negation/hedged로 세분한다. 기존 detector들은 non-assertive mention의 14–80%를 hallucination으로 판정했다. newer VLM에서 이 문제를 교정하려면 LLaVA-1.5보다 5–10배 많은 데이터가 들고 real hallucination recall이 감소했다.
- **평가 한계:** COCO 80 categories, 단일 prompt, open models 5개, 최대 128 tokens에 한정된다. GPT-4o usage label을 사람 250건으로 검증해 90.9% agreement, κ=0.79를 보고하지만 약 45%의 non-assertive mention은 subtype에서 제외됐다.
- **추론:** hallucination 평가는 object grounding만이 아니라 문장의 entailment/claim status를 포함해야 한다.
- **최소 실험:** 기존 caption evaluator 앞에 assertion classifier를 붙이고 CHAIR score와 사람 판정 precision 변화를 측정한다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.23610), [데이터/코드](https://github.com/lab-flair/NAME_Bench)

### 4.2 Execution Before Memory: Diagnosing Memory Failures in Video World Models

- **날짜/상태:** arXiv:2610.23542v1, 2026-10-16; 프로젝트와 코드 공개.
- **확인된 사실:** MIST는 setup, leakage, requested action, visible reveal, final-state match를 나눠 평가한다. Wan TI2V-5B, 43 cases의 baseline에서 41개가 아예 뚜껑을 열지 않았고 reveal score는 0.147이었다. M3-Agent가 실패 동작과 마지막-frame evidence를 재작성하자 kept-clip reveal은 0.492로 증가했다. WRBench T는 0.452→0.570(+26.1%, n=40), MBench-T U는 0.292→0.446(+52.7%, n=30)이다.
- **중요한 제한:** best-of-K 후보는 reporting scorer로 선택하므로 deployable critic 성능이 아니라 oracle coverage estimate다. 마지막 frame이 맞아도 hidden state가 실제로 저장됐다는 증거는 아니다. 저자도 이를 명시한다.
- **재현성:** protocol card, seed, judge, budget을 분리해 공개하며 official score와 internal score를 섞지 않는다.
- **추론:** 낮은 memory 점수를 곧바로 long-term state failure로 해석하면 intervention target을 잘못 잡을 수 있다.
- **최소 실험:** 기존 비디오 생성 30개를 setup/action/visibility/match 네 gate로 재라벨하고, prompt rewrite가 어느 gate만 개선하는지 본다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.23542), [프로젝트](https://hku-mmlab.github.io/MIST/), [코드](https://github.com/HKU-MMLab/MIST)

### 4.3 When Evidence Vanishes: Distilling Visual-Evidence Dependency in Medical VLMs

- **날짜/상태:** arXiv:2610.23469v1, 2026-10-16.
- **확인된 사실:** ECDD는 원영상과 관련 evidence를 제거한 matched control 사이에서 teacher의 gold-answer margin이 얼마나 떨어지는지를 student에게 distill한다. RoboSurg-VQA Q8에서 ECDD는 최고 original accuracy 73.00%를 유지하면서 instrument evidence gap 39.33, positive margin drop 1.811, evidence-minus-random response 0.738을 기록했다. DME Qwen-3B lesion presence에서는 target-minus-random response가 KD 0.786에서 2.023으로 늘고 original accuracy는 80.50%와 80.39%로 비슷했다.
- **평가:** DME, RoboSurg-VQA, PathVQA; seeds 7/17/27 및 paired bootstrap 일부를 제공한다.
- **한계:** control image가 새 clinical ground truth를 갖는 것은 아니므로 gap은 causal correctness가 아니라 behavioral dependency diagnostic이다. masking artifact 자체 반응은 matched-random control로만 부분 제거된다.
- **추론:** VLM distillation 목표에 정답 분포뿐 아니라 `관련 시각 증거가 사라질 때 확신도도 내려가야 한다`는 조건을 넣을 가치가 크다.
- **최소 실험:** ROI mask와 same-area random mask를 쌍으로 만들어 accuracy, gold-margin drop, evidence-random gap을 동시에 기록한다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.23469)

### 4.4 Query-adaptive Recurrent Tokenization

- **날짜/상태:** arXiv:2610.22957v1, 2026-10-16.
- **확인된 사실:** QART는 image-query pair마다 관련 patch를 찾고 reconstruction coverage가 충분할 때까지 recurrent slot을 추가한다. 729 SigLIP2 patch에서 평균 약 29 token을 사용한다. VQAv2에서 76.37%로 dense 81.4%의 93.8%를 24.8배 적은 token으로 유지했고, Visual7W pointing은 29 tokens에서 81.96%로 DART 59.86%보다 22.1 points 높았다. end-to-end throughput은 1.53배 개선했다고 보고한다.
- **평가:** CORE, GeneCIS, PODS, Winoground, VQAv2, Visual7W. QART와 LLM은 frozen이고 VQA에서는 lightweight projector만 학습한다.
- **한계:** 일부 pruning baseline은 vision tower가 달라 absolute comparison보다 relative accuracy를 봐야 한다. reconstruction adequacy threshold가 실제 answer sufficiency와 항상 일치하는지도 미확인이다.
- **추론:** dynamic token budget은 이미지 난이도가 아니라 질문에 필요한 evidence 양을 기준으로 정해야 한다.
- **최소 실험:** 같은 이미지에 localization/counting/global 질문을 바꿔 token 수, answer accuracy, relevant-region coverage가 함께 변하는지 본다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.22957)

## 5. LLM / Agent / Reasoning / Inference Systems 2선

### 5.1 Sink-Sparse Hybrid Attention for Efficient Inference in T2I/T2V Diffusion Transformers

- **날짜/상태:** arXiv:2610.22975v1, 2026-10-16.
- **확인된 사실:** 4 prompts × 2 noise seeds의 작은 offline calibration으로 layer/head별 high-mass sink mask를 얻고 pooled-KV branch로 누락 정보를 보완한다. 재학습 없이 weights와 sampling schedule을 유지한다.
- **정량:** Wan2.1-T2V-1.3B, A800 80GB, 832×480/81 frames/50 steps에서 dense 164.80s 대비 quality 설정은 106.73s(1.54×), VBench 8-dim 평균 0.659 대 dense 0.656이다. speed 설정은 94.57s(1.74×), 0.647이다. Z-Image-Turbo 2048²/8 steps는 23.39→14.88s(1.57×), Soft-TIFA GM 16.38→15.21이다.
- **한계:** backbone별 mask calibration이 필요하고 단일 A800 측정이다. 정적 sink가 prompt/domain shift에서 깨지는지 추가 검증이 필요하다.
- **최소 실험:** calibration prompt 수 1/4/16과 도메인 외 prompt에서 attention-mass recall, latency, VBench를 같이 비교한다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.22975)

### 5.2 M3-Agent를 일반 agent 관점에서 보기

- **확인된 사실:** M3-Agent는 model weight나 memory module을 바꾸지 않고 마지막 frame을 읽어 실패 동작을 분류한 뒤, actor/object/order는 고정하고 실패 operation과 evidence clause만 수정한다. 원 후보를 candidate set에 남겨 악화된 rewrite를 거부할 수 있다.
- **agent 의미:** 자유 형식 self-reflection보다 `관측 가능한 gate → 국소 진단 → 제한된 수정 → 동일 scorer로 재검증`의 폐쇄 루프가 더 감사 가능하다.
- **주의:** scorer를 선택에도 쓰면 test-time selection bias가 생긴다. 배포용 critic과 최종 evaluator를 분리한 실험이 필요하다.
- **최소 실험:** evaluator-blind critic으로 후보를 선택한 결과와 oracle scorer 선택 상한의 간격을 측정한다.
- **출처:** [arXiv 원문](https://arxiv.org/html/2610.23542)

## 6. 새 모델·코드·데이터·벤치마크·프레임워크

1. **MIST + M3-Agent:** video world-model memory를 stage-resolved로 측정하는 benchmark/protocol과 코드가 공개됐다. [프로젝트](https://hku-mmlab.github.io/MIST/) · [GitHub](https://github.com/HKU-MMLab/MIST)
2. **NAME-Bench:** 25,497 object mentions와 assertion-aware label을 공개했다. [GitHub](https://github.com/lab-flair/NAME_Bench)
3. **MFlow/ConvRefiner:** pixel diffusion의 adaptive target parameterization과 high-frequency refiner를 한 프로젝트에 묶었다. [프로젝트](https://soumik-kanad.github.io/mflow-diffusion/)
4. **QART:** query-conditioned variable-length visual tokenizer. 원문에는 상세 구현이 있으나 이번 확인 범위에서 공식 code repository는 확인되지 않았다.
5. **MaskMerge/RCA-MOT/Coreset:** 구현 세부는 충분하지만 MaskMerge와 RCA-MOT의 공개 코드, coreset 코드의 즉시 공개는 확인되지 않았거나 acceptance 이후로 명시됐다.

## 7. 오늘의 중요한 발견 3개

1. **최종 점수는 원인 변수가 아니다.** MIST의 memory score, NAME-Bench의 hallucination score, ECDD의 accuracy 모두 서로 다른 실패 원인을 합쳐 버릴 수 있다. 평가를 gate나 intervention으로 분해해야 올바른 개선 대상을 찾는다.
2. **압축에서 보존할 것은 feature similarity가 아니라 의사결정에 필요한 구조다.** MaskMerge의 instance identity, QART의 query evidence, Sink-Sparse의 high-mass attention이 같은 방향을 가리킨다.
3. **신뢰도는 fusion 전에 사라지면 안 된다.** RCA-MOT는 모달별 reliability를 association과 memory update에 남겨 identity metric을 개선했다. 이는 RGB–thermal뿐 아니라 multi-sensor perception 전반에 적용 가능한 설계 원칙이다.

## 8. 과대해석 주의 2개

1. **M3-Agent의 best-of-K 향상을 ‘기억 능력 향상’으로 부르면 안 된다.** 결과는 frozen generator의 실행 가능 범위와 oracle selection 상한을 보여주며, hidden state 저장을 입증하지 않는다.
2. **효율화 숫자는 hardware·resolution·operator stack에 종속된다.** Sink-Sparse의 1.54–1.57×와 MaskMerge의 throughput은 강한 신호지만, 다른 GPU·batch·compiler에서 그대로 재현된다는 보장은 없다.

## 9. 오늘의 Top 3

1. **Execution Before Memory** — 평가 설계를 바꾸면 병목과 intervention이 함께 바뀐다는 점을 가장 명확히 증명했다.
2. **Not Every Mention Is a Claim** — hallucination detector의 label ontology 자체를 교정하며 데이터도 공개했다.
3. **MaskMerge** — token efficiency를 과업 구조 보존 문제로 바꾸고 accuracy·GFLOPs·throughput을 동시에 검증했다.

## 10. Top 1 미니 리뷰 — Execution Before Memory (5–10분)

### 문제

비디오 월드모델의 기억 벤치마크는 장면 설정, 요청 동작 실행, 카메라 복귀, 마지막 상태 표시를 하나의 점수로 묶는다. 최종 상태가 없을 때 `기억하지 못했다`고 해석하지만, 실제로는 요청 동작이 한 번도 실행되지 않았을 수 있다.

### 진단

MIST는 세 개의 5초 shot에서 setup, gap leakage, reveal action, visible last frame, target match를 분리한다. 43개 baseline 중 41개가 reveal action 자체를 하지 않았다. 따라서 이 subset의 낮은 점수는 memory retention을 측정하기 전에 이미 무너진다.

### 가설

실패한 동작을 구체적으로 재서술하고 마지막 frame에 보여야 할 증거를 명시하면, frozen model도 숨겨진 상태를 더 자주 표출할 수 있다.

### 최소 개입

M3-Agent는 마지막 frame을 관찰해 no action/wrong binding/occlusion 등을 분류하고, task card의 actor·object·target·순서는 유지한 채 실패 operation만 수정한다. 한 후보가 나빠질 수 있으므로 원 clip도 candidate set에 남긴다.

### 결과

one-kept-clip 기준 reveal 0.147→0.492, correct 1→13, never-open 41→20이다. 공식 benchmark에서도 WRBench T가 0.452→0.570, MBench-T U가 0.292→0.446으로 증가했다. 다만 scorer가 후보 선택에 사용된 결과는 oracle coverage estimate다.

### 실무 적용

우리의 VLM/video benchmark도 `입력 이해 → 필요한 동작 → 증거 가시화 → 정답 일치`로 로그를 분리해야 한다. 모델 교체 전에 prompt rewrite와 evaluator 분리만으로 어느 단계가 병목인지 확인할 수 있다.

### 판정

- **근거 강도:** 중상. stage-separated protocol, paired counts, official/internal score 분리를 제공한다.
- **재현성:** 높음. 코드·프로젝트·protocol card 공개.
- **남은 위험:** 작은 case 수, 특정 video generators, judge/selection 결합, memory storage의 직접 증거 부재.

## 11. 후속 연구 질문과 최소 실험

### Seed A — VLM 환각 평가에 assertion gate를 넣으면 순위가 바뀌는가?

- **질문:** object mention 중 실제 존재 주장을 하는 문장만 CHAIR류 평가에 넣으면 모델 순위가 달라지는가?
- **가설:** 설명형 문장을 많이 쓰는 모델의 false-positive penalty가 감소해 기존 순위 일부가 뒤집힌다.
- **최소 실험:** 3개 open VLM × COCO 500 images에서 assertion classifier 전/후 CHAIR precision과 human agreement 비교.
- **데이터/기준선:** COCO, NAME-Bench; 기존 CHAIR와 rule-based hedge filter.
- **성공 기준:** 사람 판정 precision +10 points 이상, 실제 hallucination recall 감소 3 points 이하.
- **실패 기준:** precision 개선 없이 recall만 감소하거나 모델 순위가 annotation convention에 과민하게 변함.

### Seed B — 인스턴스 구조 기반 token merge가 해무/저조도에서 더 강한가?

- **질문:** feature similarity가 불안정한 악천후에서 coarse-mask constraint가 cross-instance fusion을 줄이는가?
- **가설:** visibility가 낮을수록 similarity-only merge의 identity collapse가 증가하고 mask constraint의 상대 이득이 커진다.
- **최소 실험:** Cityscapes-C 또는 해무 데이터의 차량 밀집 crop에서 ALGM vs MaskMerge를 3개 token budget으로 비교.
- **데이터/기준선:** Cityscapes-C/자체 해무 subset; full-token EoMT, ToMe, ALGM.
- **성공 기준:** 같은 GFLOPs에서 crowded-region AP +2 points 이상 및 cross-instance merge 30% 이상 감소.
- **실패 기준:** coarse mask 오류로 boundary AP가 하락하거나 merge 감소가 latency 이득을 상쇄.

### Seed C — evidence dependency distillation이 일반 VQA에도 통하는가?

- **질문:** ROI를 제거했을 때 confidence가 내려가도록 학습하면 OOD VQA calibration이 좋아지는가?
- **가설:** matched random control을 사용하면 language prior는 줄고 evidence-specific margin response는 늘어난다.
- **최소 실험:** VQAv2/IV-VQA 5K subset에서 KD와 ECDD를 동일 LoRA budget으로 3 seeds 비교.
- **데이터/기준선:** VQAv2, IV-VQA; SFT, KD, random-mask KD.
- **성공 기준:** original accuracy ±1 point 이내, evidence-minus-random margin +20% 이상, ECE 개선.
- **실패 기준:** masking artifact에만 반응하거나 original accuracy가 2 points 이상 하락.

### Seed D — query-adaptive token budget의 중단 기준을 task loss로 보정할 수 있는가?

- **질문:** reconstruction coverage 대신 answer uncertainty를 함께 쓰면 counting/localization에 더 적절한 token 수를 선택하는가?
- **가설:** reconstruction-only 중단은 미세 count evidence를 놓치며 uncertainty gate가 이를 보완한다.
- **최소 실험:** 같은 이미지에 global, count, localization 질문을 주고 QART token count와 error type을 분석한 뒤 entropy 보정 gate를 추가.
- **데이터/기준선:** VQAv2 number subset, Visual7W; fixed-32 Q-Former, 원 QART.
- **성공 기준:** 평균 token 증가 10% 이하에서 number accuracy +2 points 이상.
- **실패 기준:** uncertainty가 언어모델 편향만 반영하거나 token 증가 대비 정확도 개선 없음.

## 12. 오늘은 읽지 않아도 되는 것

- 전일 보고서에서 이미 다룬 Gen4P, DaTMe, SoftCache, Dense4D, ARC-SORT, TRACE, SparK-SAR, DK-VLM, MaLoW, recurrent VLM retrofit, ViSiP-Bench, LEASH, DropKV는 중복을 피하기 위해 제외했다.
