## 1. Orbia — 월드 모델 평가가 “보기 좋은 영상”에서 revisit 기반 3D 일관성으로 이동

**무엇이 바뀌었나.** Orbia는 interactive video world model을 입력 장면 보존, 모델이 새로 생성한 영역의 재방문 지속성, 전체 경로의 3D 자기일관성으로 분해한다. 각 사례는 시작점, cross-view query, 처음 본 영역, 재방문, 정확한 시작 자세 복귀를 포함한다.

**확인된 사실.** 공식 project와 dataset card는 720개 사례를 제공한다. 480개는 22초·357 frame, 240개는 60초·961 frame이며 16 FPS, 1280×720으로 구성된다. 6개 exploration/revisit protocol과 27개 모델을 평가하고, 입력 image·caption·camera trajectory, RGB-D reference, anchor mask, evaluation region을 공개한다. 데이터는 접근 조건 동의가 필요한 공개 repository이며 총 약 5.77 GB다. [논문](https://arxiv.org/abs/2610.20693), [프로젝트·leaderboard](https://orbia-bench.github.io/), [코드](https://github.com/worldbench/Orbia), [데이터](https://huggingface.co/datasets/Orbia/Orbia)

**저자 주장.** 공식 leaderboard에서 SolarWM-H3가 overall 76.32로 1위지만, 모든 평가 tier를 한 모델이 지배하지 않는다. project는 frame quality와 3D consistency, camera control과 geometry consistency, 입력 복원과 생성 콘텐츠 기억이 서로 다른 능력이라고 보고한다.

**동일 조건 비교.** 모든 모델이 같은 경로를 받지만 native interface가 camera, action, image+text로 다르다. interface adapter와 생성 길이 처리 방식도 달라 overall 순위를 순수 architecture 우열로 읽으면 안 된다. evaluator가 DA3/DA3 Streaming으로 camera와 depth를 복원하므로 evaluator 편향도 결과에 포함된다.

**진단 → 가설 → 최소 실험.**

- 진단: 첫 장면 복원과 높은 시각 품질은 모델이 새로 만든 물체·구조를 기억한다는 증거가 아니다.
- 가설: 장기 rollout에서 input preservation보다 generated-content persistence가 먼저 무너진다.
- 최소 실험: 공개 short case 12개를 세 interface group에서 각각 1개 모델로 실행하고, return-frame similarity, revisit feature consistency, regional depth-scale agreement를 별도 기록한다.
- GO/KILL: revisit consistency가 short→long에서 10%p 이상 하락하지만 return score는 유지되면 memory module 실험으로 확장한다.

**판정.** 월드 모델 연구에서 단일 FVD·VLM quality score를 대체할 강한 protocol signal이다. 해양 CCTV에서도 선박이 잠시 가려졌다 다시 나타나는 revisit trajectory로 직접 변환할 수 있다.

## 2. WorldCast — 단일 미래 image에서 다단계 world-state sequence로 이동

**무엇이 바뀌었나.** WorldCast는 multimodal observation과 heterogeneous reference를 받아 연속된 미래 상태를 생성하는 L3–L4 과제를 평가한다. 320개 수작업 사례, 1,352개 요청 visual state, 8개 category, 12개 image/video system으로 구성된다.

**확인된 사실.** 공식 프로젝트는 모든 모델이 같은 state-sequence protocol을 따르지만 native output interface는 interleaved, grid, video, plan-and-iterate로 다르다고 명시한다. baseline table과 agentic enhancement 결과도 분리한다. [논문](https://arxiv.org/abs/2610.20731), [프로젝트·leaderboard](https://teal024.github.io/WorldCast/)

**저자 주장.** baseline에서 GPT-Image-2.5 System은 72.8, Nano Banana Pro는 42.8, 최고 open-source model은 20.1을 기록했다. L4에서 GPT-Image-2.5는 71.6을 유지했지만 SenseNova-U1은 L3 24.4에서 L4 15.0으로 하락했다. Nano Banana Pro에 별도 language-model enhancer를 결합하면 overall이 42.8에서 61.2로 올랐다고 보고한다.

**동일 조건 비교.** 사례와 평가 protocol은 공통이지만 output interface, underlying language model, proprietary version, agentic enhancement 유무가 다르다. 따라서 72.8 대 20.1은 동일 backbone·compute 조건의 model 비교가 아니다. baseline과 enhanced system을 같은 leaderboard 행처럼 해석하면 안 된다.

**진단 → 가설 → 최소 실험.**

- 진단: single-frame plausibility가 높아도 조립 순서, 물리 변화, reference identity를 여러 단계에 걸쳐 유지하지 못한다.
- 가설: 최종 결과만 평가하는 metric보다 단계별 state delta와 불변 요소 보존 점수가 failure를 더 빨리 찾는다.
- 최소 실험: 50개 사례에 대해 각 단계의 action compliance, unchanged-region similarity, object-count conservation, final-state correctness를 분리한다.
- GO/KILL: final score가 비슷한 모델 사이에서 state-delta error가 15%p 이상 벌어지면 sequence-aware evaluator를 채택한다.

**판정.** 생성 모델 benchmark가 “좋은 최종 그림”에서 계획과 상태 전이를 포함한 process evaluation으로 이동하는 신호다.

## 3. TEAL — semantic segmentation을 이미지당 1 pixel budget까지 내린 동일-backbone 평가

**무엇이 바뀌었나.** TEAL은 ViT token lattice에서 representative candidate를 고른 뒤 decoder grid에서 uncertainty refinement를 수행하는 pixel-level active learning protocol이다. CamVid, Cityscapes, ADE20K, Pascal Context에서 이미지당 1·10 labeled pixel의 극저예산 조건을 평가한다.

**확인된 사실.** 논문은 frozen ViT backbone을 사용하고, token embedding을 dense pixel resolution으로 보간해 생기는 artifact를 피하기 위해 native token lattice에서 selection을 수행한다고 설명한다. 모든 baseline을 같은 DINOv3 backbone으로 다시 구성한 통제도 포함한다. [논문](https://arxiv.org/abs/2610.20881)

**저자 주장.** 가장 강한 baseline 대비 이미지당 1 pixel에서 최대 +24.36 mIoU, 10 pixel에서 fully supervised 성능의 최대 97%에 도달했다고 보고한다. 이 수치는 네 dataset 전체의 보편적 평균이 아니라 조건별 최대 개선치다.

**동일 조건 비교.** 같은 dataset·DINOv3·decoder·label budget·round 수에서만 직접 비교할 수 있다. “fully supervised의 97%”는 dataset별 absolute mIoU와 annotation unit을 함께 봐야 하며, 1 pixel 선택 과정의 초기 seed와 반복 횟수가 다르면 variance가 커질 수 있다.

**진단 → 가설 → 최소 실험.**

- 진단: sparse annotation에서는 backbone 표현력보다 query 위치와 decoder-scale mismatch가 성능을 지배할 수 있다.
- 가설: 해무·선박 segmentation에서도 boundary보다 class prototype을 잘 대표하는 interior token을 먼저 고르면 1–10 pixel budget 효율이 높다.
- 최소 실험: 동일 DINO 계열 frozen encoder로 random, pixel uncertainty, token diversity, token-diversity+uncertainty를 1·5·10 pixel/image에서 5개 seed로 비교한다.
- GO/KILL: 5 pixel에서 random 대비 평균 +5 mIoU 이상이고 seed 표준편차가 개선량의 절반 이하이면 확장한다.

**판정.** annotation 효율을 주장할 때 backbone 향상과 sampling policy 향상을 분리한 좋은 control 사례다. tiny-object에는 전체 mIoU와 함께 small-region recall을 반드시 병기해야 한다.

## 4. PolyText-Bench/TextDART — whole-image reward에서 text-region별 결함 평가로 이동

**무엇이 바뀌었나.** TextDART는 각 text region을 찾아 의미 정확성과 glyph 품질을 독립적으로 평가한다. SCANNER는 그 regional judgment를 해당 latent token에 배분하며, 새 PolyText-Bench와 기존 benchmark에서 visual text generation을 평가한다.

**확인된 사실.** 공식 프로젝트는 recognition 결과를 다섯 challenging text scene에서 비교하고, generation 결과를 다섯 benchmark에 걸쳐 FLUX.1-dev와 Qwen-Image-2512의 영어·중국어 조건으로 나눠 보고한다. 공개 페이지의 Code, Model, Dataset, PolyText-Bench 링크는 확인 시 실제 URL이 연결되지 않은 표시 상태여서, 오늘은 완전한 재현 artifact 공개로 판정하지 않는다. [논문](https://arxiv.org/abs/2610.20794), [프로젝트](https://sujiehu.github.io/textdart-scanner/)

**저자 주장.** TextDART와 SCANNER가 기존 benchmark와 PolyText-Bench에서 text accuracy와 glyph fidelity의 SOTA를 달성했다고 보고한다. abstract와 공개 페이지에서 sample count와 evaluator agreement의 구체 수치는 확인되지 않아 본 보고서에 임의 수치를 넣지 않았다.

**동일 조건 비교.** backbone, language, reward model, RL algorithm, OCR evaluator가 같은 행 안에서만 직접 비교해야 한다. method가 사용한 reward model과 평가 metric이 강하게 결합되면 evaluator overfitting 위험이 있으므로 human glyph judgment 또는 별도 OCR로 교차검증해야 한다.

**진단 → 가설 → 최소 실험.**

- 진단: whole-image scalar가 잘 만든 단어와 깨진 한 글자를 평균내어 localized defect를 숨긴다.
- 가설: region-level semantic/glyph score가 OCR accuracy보다 작은 글자·부분 왜곡 실패에 민감하다.
- 최소 실험: 100개 생성 image에 clean, missing-letter, malformed-glyph, extra-text perturbation을 만들고 TextDART 계열 score, 독립 OCR CER, 사람 2인의 region judgment 상관을 비교한다.
- GO/KILL: region score가 네 defect에서 human judgment와 Spearman 0.7 이상이고 whole-image score보다 일관되게 높은 상관을 보이면 채택한다.

**판정.** Answer–Region Gap과 같은 평가 철학이 생성 모델에도 적용된 사례다. 전체 정답보다 어느 region이 왜 틀렸는지를 metric이 직접 보존한다.

## 5. Decision-FLIP — pruning을 parameter count가 아니라 실제 decision·latency·memory로 평가

**무엇이 바뀌었나.** Decision-FLIP은 Gaussian occupancy model의 persistent row를 제거했을 때 voxel argmax decision이 얼마나 바뀌는지로 중요도를 측정하고, log-score 분포의 guarded Otsu split으로 survivor 수를 자동 결정한다. 선택된 row는 실제 작은 checkpoint로 compile된다.

**확인된 사실.** 평가는 4개 Gaussian-bank model–dataset 설정과 1개 persistent-query transfer에서 수행된다. same-K random removal과 supervised Taylor ranking을 control로 두고, one-epoch recovery 조건을 맞춘다. [논문](https://arxiv.org/abs/2610.20917)

**저자 주장.** eligible row의 12–79%를 제거해 bank/query-dependent latency를 7–45%, whole-model primary endpoint를 최대 8.0%, peak memory를 최대 16.6% 줄였으며 semantic mIoU 변화는 최대 0.18 point라고 보고한다. same-K control 다섯 설정에서는 label-free Mean-FLIP이 supervised Taylor와 같거나 더 좋았다고 주장한다.

**동일 조건 비교.** 12–79%와 7–45%는 서로 다른 model–dataset 설정의 범위이며 하나의 평균 개선치가 아니다. 전체 latency에는 image·voxel·sensor module의 fixed cost가 포함되므로 component latency와 end-to-end latency를 구분해야 한다. 같은 K, 같은 recovery epoch, 같은 hardware·batch·precision에서만 ranking method를 직접 비교할 수 있다.

**진단 → 가설 → 최소 실험.**

- 진단: parameter 감소가 실제 latency 감소로 이어지지 않으며, magnitude가 작은 row도 voxel decision을 바꿀 수 있다.
- 가설: detection·occupancy의 deployment pruning에서는 weight magnitude보다 output-decision flip count가 작은 구조를 더 안전하게 찾는다.
- 최소 실험: 고정 validation 200 sample에서 동일 K의 random, magnitude, decision-flip pruning을 비교하고 end-to-end latency, peak VRAM, per-class IoU, tiny-object recall을 측정한다.
- GO/KILL: VRAM 10% 이상 절감, latency 5% 이상 개선, tiny-object recall 하락 1%p 이내를 동시에 만족하면 compile 경로로 확장한다.

**판정.** RTX 5060 Ti 8GB 환경에 직접적인 signal이다. FLOPs·parameter 수보다 실제 compiled checkpoint와 end-to-end profile을 benchmark의 필수 결과로 둬야 한다.

| PolyText-Bench | 같은 backbone·language·reward·evaluator | reward model과 결합된 점수를 독립 품질로 간주 | paper·project 확인, artifact 링크 미연결 |
| Decision-FLIP | 같은 K·recovery·hardware의 pruning ranking | component latency와 whole-model latency, 설정별 범위의 평균화 | paper 확인, 공개 code는 확인되지 않음 |

## 오늘의 benchmark signal 3개

1. **시간축을 평가에 넣어라.** Orbia와 WorldCast는 한 장의 품질보다 재방문 지속성과 단계별 상태 전이가 더 어려운 병목임을 드러낸다.
2. **평가 단위를 실패가 발생하는 곳까지 줄여라.** TEAL은 pixel budget, TextDART는 text region, Decision-FLIP은 voxel decision 단위로 평균값을 해체한다.
3. **효율은 실제 실행 결과로 검증하라.** parameter·row 감소만 보고하지 말고 compiled checkpoint의 latency, VRAM, tail-class 성능을 함께 측정해야 한다.

## 내 연구에 바로 연결되는 포인트

- 해양 CCTV에서 선박이 안개·가림 뒤 다시 나타나는 구간을 `first visit → occlusion → revisit` protocol로 구성하고 ID·depth·appearance persistence를 분리한다.
- VQA와 생성 평가에 region-level evidence를 유지한다. 전체 answer/image score 옆에 작은 글자, 선박, 부표, 위험 영역별 오류를 기록한다.
- 해무·선박 segmentation annotation은 1·5·10 pixel/image budget으로 시작하고 동일 frozen encoder에서 sampling policy만 바꿔 비교한다.
- 8GB GPU용 pruning은 parameter 수 대신 end-to-end latency, peak VRAM, tiny-object recall의 3중 gate를 사용한다.
- 첫 실험은 대규모 학습보다 공개 case 50–200개 규모의 evaluator audit로 제한해, metric이 실제 failure를 분리하는지 먼저 확인한다.
