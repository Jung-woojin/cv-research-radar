### C2. Forehead ROI Localization under Real-World Imaging Degradations via Cross-View Pseudo-Labeling

**진단·후속:** “validated”가 실제 도구 실행 성공을 전부 보장하는지는 validation 계약을 읽어야 한다. 형식 오류·잘못된 tool 선택·잘못된 argument·다중 turn 상태 오류를 분리한다. source dataset·tool schema 중복을 제거한 held-out 평가를 우선한다. source-agnostic은 별도 loader가 필요 없다는 뜻이 아니다. [논문](https://arxiv.org/abs/2611.26722) · [생성기](https://github.com/tum-ai/toumaii-gen)

### S3. Run One, Get Two: Near-Free Streaming Safety Checks for Local LLMs

**날짜·분류:** v1 2026-11-20 UTC. 최근 발표분 후속 조사.

**방법·저자 보고:** ToRA는 generation과 guard를 decode의 두 row로 처리해 weight·KV cache와 memory read를 공유한다. Qwen3-0.6B에서 17개 benchmark 중 12개에서 dedicated guard 이상 F1, token당 추가 latency 4% 미만을 보고한다.

**주의:** 단일 사용자·memory-bound decode라는 조건이 핵심이다. 고동시성·compute-bound·긴 context에서 같은 비용을 보장하지 않는다. token latency와 unsafe 응답을 차단하기까지의 detection delay는 별개다.

**후속:** baseline guard·probe·ToRA를 같은 hardware에서 context length×batch로 비교하고 latency·peak memory·검출 지연·F1을 함께 기록한다. 커널 실행·새 측정은 하지 않았다. [공식 원문](https://arxiv.org/abs/2611.26975)

FoVT·ConRef·FlowScope·RoSci·TheaterBench·DepThink·ToRA의 완전한 code/weights/data bundle은 이번 조사에서 확인하지 못했다. “미확인”은 “미공개”와 다르다. 전체적으로 parameter 수·FLOPs·VRAM·GPU 시간·seed variance·정확한 split·pretraining overlap을 모두 채운 독립 재현 감사는 아니며, 위에서 직접 확인한 조건 이외의 수치는 보충하지 않았다. 비교 조건이 미확인인 headline 간 순위를 만들지 않았다.

## 6) 중요한 Finding 3개

1. **계산 선택과 정보 공급을 분리해야 한다.** FoVT의 선택 이득과 확대 이득은 같은 변수가 아니다. SCATR-ITS의 압축도 작은 instance의 증거를 지우면 query를 늘려도 복구할 수 없다는 것이 후속 가설이다. [FoVT](https://arxiv.org/html/2611.27788v1) · [SCATR-ITS](https://arxiv.org/abs/2611.26715)
2. **평가 기준이 바뀌면 모델을 고치지 않아도 결론이 바뀐다.** ConRef는 reference의 불확실성을, RoSci는 답변 가능한 전제인지를 문제 삼는다. 둘을 일반적인 annotation 오류 하나로 묶으면 안 된다. [ConRef](https://arxiv.org/html/2611.26758v1) · [RoSci](https://arxiv.org/abs/2611.27750)
3. **읽을 수 있는 정보와 사용하는 정보는 다르다.** FlowScope의 probe 분석과 TheaterBench의 증거 충돌은 정보 보유·의존·정답 사용을 각각 검사하게 한다. 이는 논문 간 종합 추론이며 공통 기제를 검증한 결과는 아니다. [FlowScope](https://arxiv.org/html/2611.26865v1) · [TheaterBench](https://arxiv.org/abs/2611.26972)

## 7) 과대평가를 경계할 두 가지

- **FoVT의 효율 headline:** MAC 감소와 실시간 가속을 동일시하지 않는다. 자세한 조건은 다음 미니 리뷰에 적었다.
- **INCISE의 training-free headline:** 참조 주석과 target appearance 접근은 여전히 비용·정보다. fine-tuning baseline과 label 비율만 맞추는 것으로 공정성이 완성되지 않는다. [공식 원문](https://arxiv.org/abs/2611.26734)

## 8) 오늘 바로 읽을 Top 3

1. **FoVT:** 최소한의 선택적 확대와 비용·통계 대조를 함께 읽기 좋다.
2. **ConRef:** 새 architecture 없이 평가 결론을 감사하는 연구 설계가 강점이다.
3. **FlowScope:** representation probe와 실제 행동 성능의 연결을 읽되 인과 해석의 경계를 확인할 가치가 있다.

이 순서는 연구 적합성에 대한 정성 판단이다.

## 9) Top 1 — FoVT 5~10분 미니 리뷰

**Blind spot:** 어떤 sample이 확대를 필요로 하는가와 어디를 확대할 것인가는 다르다. 실패 원인을 모듈 수로 설명하지 않는 점이 중요하다.

**실험 논리:** random/attention, feature reuse, confidence gate, loss를 맞춘 uniform 모델을 순서대로 대조한다. 비유의 차이는 동등성 증명이 아니다.

**실용적 경계:** A100·batch 32·BF16의 batch-normalized forward time은 K=64에서 0.56ms/image, uniform 448은 0.75, uniform 336은 0.43이다. 단일 요청 지연이 아니며 gate 절감도 포함하지 않는다. 원본 이미지의 세부정보가 부족한 경우에는 확대가 새 관측을 제공하지 못한다.

**가져올 점:** tiny detection에 바로 구조를 이식하기보다 아래 A의 정보량 대조부터 시작한다. code 공개·checkpoint·외부 domain 재현은 아직 확인하지 못했다. [공식 실험·한계](https://arxiv.org/html/2611.27788v1)

## 10) 후속 연구 씨앗 3개

아래는 미실행 제안이다. Compute cost는 1이 가볍고 5가 무겁다는 정성 추정이다.

### A. 선택 실패인가, 확대해도 정보가 없는 것인가?

**Observation → Diagnosis:** 선택 영역이 맞아도 분류가 좋아지지 않을 수 있다. 선택 정확도와 원본 detail의 가용성을 교차해야 한다.

**Hypothesis:** 원본 고주파 정보가 충분할 때만 attention 대비 random 선택 차이가 확대 효용으로 이어진다.

**최소 개입·실험:** CUB·NABirds·Aircraft에서 동일 crop의 native detail과 downsample→upsample 버전을 만든다. attention/random/동일 면적 oracle-box 선택을 동일 token·연산 budget으로 비교한다. 원래 source resolution·객체 크기별로 층화하고 고정 checkpoint와 같은 sample을 사용한다.

**GO/KILL:** native-detail 조건에서만 selection×detail 상호작용과 held-out 이득이 반복되면 GO. 선택법만으로 설명되거나 degradation이 전부를 설명하면 정보 부족 기제는 KILL한다. 새로운 수치는 미리 약속하지 않는다.

**비용·novelty:** 추론 MVP 2/5. 원문도 resolution headroom과 원본 해상도 가능성을 논의하므로 단순 반복은 신규성이 낮다. 기여 후보는 같은 이미지의 정보량 개입과 다른 domain에서의 사전 예측 검증이다. [근거](https://arxiv.org/html/2611.27788v1)

### B. Reference 불확실성 구간에서는 어떤 성능 순위가 유지되는가?

**Observation → Diagnosis:** 기준 pose 변경이 성공 판정을 바꾼다는 보고가 있다. 한 개의 새 기준으로 교체하는 것보다 순위 안정성을 묻는다.

**Hypothesis:** 작은 오차 차이의 일부는 reference 허용범위 안에서 순위가 뒤집히며, 외부 view 잔차가 안정적인 방법은 덜 뒤집힌다.

**최소 개입·실험:** 접근 가능한 DeepFluoro·Femur 예측을 고정하고 original/ConRef/불확실성 범위 perturbation에서 success·rank flip을 계산한다. leave-one-view-out 대조와 phantom 독립 기준을 둔다. 필요한 원격 예측·데이터 접근은 확보되지 않았으므로 먼저 artifact 확인이 필요하다.

**GO/KILL:** 독립 근거에서 안정성 지표가 기존 점수보다 결론을 잘 보존하면 GO. 합리적 perturbation에서 순위가 유지되면 불안정성 가설은 KILL하며 audit의 적용 경계를 얻는다.

**비용·novelty:** 저장된 예측 분석 1~2/5, registration 재실행은 증가한다. reference 감사 자체는 원논문의 기여다. 불확실성에 강건한 순위 보고와 외부 benchmark 전이가 있어야 차별화된다. [근거](https://arxiv.org/html/2611.26758v1)

### C. 모순 영상의 실패는 증거 통합 문제인가, 질문 의도 문제인가?

**Observation → Diagnosis:** 영상이 상식을 위반할 때 무엇을 답해야 하는지 자체가 애매할 수 있다.

**Hypothesis:** 관찰 기술과 물리적 가능성 판단을 분리하면 polarization의 일부는 줄지만, 실제 evidence integration 실패는 남는다.

**최소 개입·실험:** TheaterBench에서 같은 clip의 “보이는 사건”/“현실적 가능성” 질문과 RoSci식 clean/오류/누락 조건을 분리한다. 동일 backbone, 길이·답 형식을 맞춘 prompt, human rubric을 baseline으로 둔다. 관찰 정확도·가능성 판단·과잉 거절·paraphrase 안정성을 별도 측정한다. 공개 data 접근과 이용 조건부터 확인한다.

**GO/KILL:** 의도 명시 뒤 관찰은 회복되지만 가능성 판단은 달리 움직이면 과제 혼합 설명을 지지한다. 둘 다 회복되지 않으면 질문 모호성만의 설명은 KILL한다. 전체 점수 대신 문항 단위 paired 결과와 seed-family bootstrap을 쓴다.

**비용·novelty:** 작은 video VLM subset 추론 2/5. 기존 benchmark의 prompt ablation과 겹칠 위험이 높다. 의도 rubric의 인간 일치도와 task 간 전이를 확보해야 한다. [TheaterBench](https://arxiv.org/abs/2611.26972) · [RoSci](https://arxiv.org/abs/2611.27750)

**첫 실행:** A의 native-detail 대조. **가벼운 분석:** B의 저장된 예측 감사. **장기 확장:** C의 증거·상식·질문 의도 분리 평가. 모두 아직 결과가 없는 연구 제안이며 4~8주 논문화 가능성은 artifact 접근과 기존 연구 중복 조사 후 판단해야 한다.

## 11) 오늘 안 읽어도 되는 것과 후보 제외 기록

검토한 15편 중 위 12편을 남기고 다음 3편은 우선순위를 낮췄다.

- [Model the Annotation, Not the Noise: Semantic Annotation-Channel Prompt Learning against Noisy Labels](https://arxiv.org/abs/2611.26702), v1 11월 19일: annotation generation과 latent label을 분리하는 SACP는 관련성이 있으나, 오늘은 reference 감사와 정보 공급 대조에 집중했다. SOTA 문구를 독립 검증하지 않았다.
- [Decomposing images in a PRISM: A Single-Source Multi-View Framework for Image Representation](https://arxiv.org/abs/2611.26726), v1 11월 19일: 고정 feature budget의 complementary view 결과는 흥미롭지만 7개 dataset의 범위를 넘어 universal backbone 결론으로 확장하기 어렵다.
- [SparseHPS: A Unified Model for Human Pose and Shape across Depth Cameras and LiDARs](https://arxiv.org/abs/2611.26730), v1 11월 19일: sensor 통합과 causal memory는 유용하지만 10개 training dataset의 supervision 통일과 temporal 조건을 더 읽어야 공정한 진단 질문이 된다.

오늘의 새 논문 수를 늘리기 위해 생성 모델·의료 응용을 임의로 추가하지 않았다. 이 보고서의 결론은 공식 문헌 조사이며 설치·데이터 다운로드·실험·재현 성공을 뜻하지 않는다.
