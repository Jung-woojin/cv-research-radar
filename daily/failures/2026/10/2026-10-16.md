## 1. Open-o3-Video-v2 — 도구를 써도 70%의 오류가 근거 선택·미세 지각에 잔존

**실패 조건.** 긴 비디오에서 모델이 스스로 구간을 자르고 객체를 grounding해도, 비슷한 사건이 가까운 시간에 반복되거나 카메라 이동 중 유사 인스턴스를 다시 식별해야 하면 오답이 발생한다.

**모델·데이터·설정.** Qwen3-VL-4B/8B 기반 Open-o3-Video-v2이며, 저자 failure audit는 LVBench 오답을 분류한다. 대표 사례는 public figure 식별, 카메라 pan 중 인원 계수, 여러 득점 장면 중 game-ending event 선택이다.

**확인된 사실.** 저자 분석에서 정확한 시간 근거 회수와 사건 선택이 오답의 약 **43%**, 객체 grounding과 세밀 지각이 **27%**, 지식 관련 오류가 약 **6%**였다. 나머지는 reasoning inconsistency 또는 단일 원인으로 분류하기 어려운 사례다. [공식 failure analysis](https://arxiv.org/html/2610.17656#S12.SS2) · [공식 구현](https://github.com/Multimedia-Semantic-Analytics-Lab/Open-o3-Video-v2)

**커뮤니티 재현 / 재현 근거.** 독립 재현은 확인하지 못했다. 현재 근거는 저자 오답 분류와 공개 코드·checkpoint·데이터다. 공개 trace가 모든 LVBench 오답 분류를 재구성하는지는 실행 전 확인이 필요하다.

**진단 → 메커니즘 → 가설.** 관찰은 도구가 관련 구간을 찾고 박스를 남겨도 정답이 보장되지 않는다는 것이다. 진단은 retrieval과 association이 분리되지 않았다는 점이다. 메커니즘은 각 crop에서 얻은 객체 identity가 persistent track으로 유지되지 않고, 비슷한 사건의 국소 적합도가 질문의 종결 조건을 압도하는 것이다. **가설:** track-consistency와 event-terminal predicate를 별도 검증하면 43%·27% 오류군이 선택적으로 감소한다.

**최소 실험.** LVBench 오답 중 공개 가능한 50개를 시간 선택, instance association, knowledge, 기타로 재라벨링한다. 기존 trace, trace+track table, trace+track table+event-terminal verifier 세 조건을 같은 crop budget으로 비교한다. **GO:** 두 보조 모듈이 해당 오류군 정확도를 10점 이상 높이고 비대상 오류군 손실이 2점 이하다. **KILL:** 개선이 crop 횟수 증가로만 설명되거나 오류 분류자 간 Cohen's κ가 0.6 미만이다.

**기존 주장과 충돌 여부.** 전체 benchmark 개선 주장과 직접 충돌하지 않는다. 다만 `verifiable evidence`가 곧 identity·event-level correctness를 뜻하지 않는다는 범위를 명확히 제한한다.

## 2. Urbex — 원거리 landmark와 같은 클래스 밀집에서 active search가 단계적으로 붕괴

**실패 조건.** 도시 규모 3D grounding에서 target–landmark 거리가 커지거나, target 반경 50m 안에 같은 클래스 객체가 많을 때 지역 탐색과 국소 구분이 각각 실패한다.

**모델·데이터·설정.** Urbex agent가 CityRefer ND/NO와 STPLS3D-Refer에서 landmark query, zoom, oblique view를 호출한다. 저자는 regional-search success와 local-disambiguation success를 별도로 분석했다.

**확인된 사실.** landmark 거리가 50m 미만일 때 지역 탐색 성공률은 ND/NO/STPLS3D에서 40.0/34.3/42.2%였으나, 200m 이상이면 14.3/22.5/10.0%였다. 주변 같은 클래스가 없을 때 local disambiguation은 64.7/56.7/29.5%였지만, 10개 이상이면 25.1/14.4/0.0%였다. missing/incorrect landmark는 NO Hit@1을 10점 넘게 낮췄고 10m 좌표 noise는 1.2점 하락에 그쳤다. [공식 진단 표](https://arxiv.org/html/2610.18356#A1.SS4.SSS6) · [공식 구현](https://github.com/AMAP-ML/Urbex)

**저자·maintainer 인정.** 저자는 위 수치가 query group 간 연관이며 거리·밀도의 인과 효과를 분리하지 못했고 bin별 불확실성도 보고하지 않았다고 명시했다. BEV rendering·view-to-world calibration·landmark 신뢰성 의존도도 한계로 적었다.

**커뮤니티 재현 / 재현 근거.** 독립 재현은 확인하지 못했다. 코드·모델·데이터는 공식 저장소에 공개되어 있다.

**진단 → 메커니즘 → 가설.** 관찰은 실패가 한 번에 발생하지 않고 `region miss → local confusion → oversized box`로 전파된다는 것이다. 메커니즘은 qualitative landmark relation이 거리에 따라 search prior로서 평평해지고, dense same-class region에서 현재 view가 identity를 구분하지 못하는데도 agent가 commit하는 것이다. **가설:** distance-aware crop 확대와 distractor-count 기반 abstention을 분리하면 두 단계의 실패를 독립적으로 줄일 수 있다.

**최소 실험.** 각 거리 bin과 distractor bin에서 30 query씩 고정하고 기본 policy, distance-aware initial crop, distractor-aware extra-view gate를 비교한다. regional success, local success, direct IoU, tool calls를 기록한다. **GO:** crop은 원거리 regional success를 8점 이상, gate는 ≥10 distractor local success를 8점 이상 높이며 평균 tool call 증가는 25% 이하다. **KILL:** 개선이 GT landmark distance를 입력할 때만 나타나거나 bin bootstrap CI가 크게 겹친다.

**기존 주장과 충돌 여부.** CityRefer 전체 Hit@1 우위와 충돌하지 않는다. 평균값이 숨긴 조건부 실패이며, STPLS3D dense bin은 특히 일반화 주장의 범위를 제한한다.

**평가:** 심각도 **5/5** · 재현 신뢰도 **4/5** · 연구 아이디어 가치 **5/5**

## 3. FramePack-U — 더 많은 프레임이 작은 VLM을 방해하고 constant memory가 wall-clock을 숨김

**실패 조건.** 동일 메모리 안에 더 다양한 프레임을 pack해도 작은 Qwen 계열 VLM에서는 visual evidence 통합 능력이 부족해, frame budget 증가가 benchmark별로 불안정한 이득 또는 하락을 만든다. 극장편 비디오에서는 후보 frame decode가 I/O 병목이 된다.

**모델·데이터·설정.** FramePack-U는 query relevance와 diversity로 프레임을 고르고 프레임별 해상도를 달리한다. LongVideoBench, MLVU, Video-MME와 Qwen 계열 여러 크기를 평가했다.

**확인된 사실.** 저자는 작은 Qwen 모델에서 packed frame 수를 늘리면 LongVideoBench는 개선되지만 MLVU 또는 Video-MME가 소폭 하락하는 경우를 보고했다. Qwen3.6-27B의 3,600초 영상에서는 FramePack-U가 1 FPS 후보를 위해 최대 3,600 frame을 decode하지만 vanilla는 GPU 제약으로 224 frame까지만 읽어, 전체 latency 비교가 동일 조건이 아니다. [공식 limitations](https://arxiv.org/html/2610.16118#S6) · [공식 구현](https://github.com/ZelD0n/framepack-U)

**저자·maintainer 인정.** 저자는 추가 프레임이 작은 모델에 useful evidence가 아니라 distraction이 될 수 있으며, grid-based video encoder에는 개별 frame resolution 변경이 plug-and-play가 아니라고 밝혔다.

**커뮤니티 재현 / 재현 근거.** 독립 재현은 확인하지 못했다. 공식 코드는 공개됐지만 benchmark 영상 decode·CLIP feature 준비를 포함한 end-to-end 재현 비용은 별도로 측정해야 한다.

**진단 → 메커니즘 → 가설.** 관찰은 memory budget과 reasoning capacity가 다른 병목이라는 것이다. 메커니즘은 selector가 relevance를 높여도 base VLM의 cross-frame attention이 잡음을 억제하지 못하고, decode 비용은 GPU memory 표에서 사라지는 것이다. **가설:** 모델별 evidence saturation point를 넘으면 marginal frame utility가 음수가 되며, 이 지점은 attention entropy와 정답 logit margin으로 예측할 수 있다.

**최소 실험.** 4B/8B 두 모델, 32/64/128/256 frame, 동일 1 FPS candidate decode로 고정한다. accuracy, attention entropy, 정답 margin, decode/inference latency, peak VRAM을 분리 기록한다. **GO:** validation으로 고른 early-stop rule이 고정 256-frame 대비 정확도 손실 1점 이내에서 latency를 20% 이상 줄인다. **KILL:** saturation point가 dataset마다 뒤집혀 공통 예측 신호 AUROC가 0.6 미만이다.

**기존 주장과 충돌 여부.** constant-memory 주장은 유지된다. 다만 latency와 accuracy가 monotonic하게 개선된다는 해석은 성립하지 않으며, 다른 fps·decode 수 비교는 **not strictly apples-to-apples**다.

**평가:** 심각도 **4/5** · 재현 신뢰도 **4/5** · 연구 아이디어 가치 **5/5**

## 4. AReA — 구조가 무너진 이미지도 Aesthetic·CLIP에서 높은 점수를 받음

**실패 조건.** FLUX.1을 4096×4096으로 확장하면서 Phase II attention window를 고정 64로 두면 이미지가 서로 불일치하는 영역으로 깨진다. 반대로 pooling factor를 고정하면 subject fusion 또는 duplication이 생긴다.

**모델·데이터·설정.** training-free high-resolution diffusion에서 fixed window/fixed factor와 adaptive global→local schedule을 비교한다.

**확인된 사실.** 저자는 fixed window 64 결과가 unusable하다고 판정했지만 Aesthetic와 CLIP처럼 layout error에 둔감한 metric에서는 여전히 높은 점수를 받았다고 보고했다. 실패는 낮은 ImageReward·PickScore와 높은 FID에서 더 잘 드러났다. fixed factor 4는 경계 없는 fused subject, factor 2는 흩어지거나 중복된 content를 만들었다. [공식 failure 분석](https://arxiv.org/html/2610.17227#S4.SS3) · [공식 구현](https://github.com/KooroshRH/AReA)

**저자·maintainer 인정.** 위 metric sensitivity와 fixed schedule의 두 실패 모드는 저자가 직접 설명했다.

**커뮤니티 재현 / 재현 근거.** 독립 재현은 확인하지 못했다. 공식 구현이 공개됐으며 실패 조건은 window/factor 변경만으로 재현 가능한 ablation 형태다.

**진단 → 메커니즘 → 가설.** 관찰은 semantic similarity와 local aesthetics가 global layout 붕괴를 벌점화하지 못한다는 것이다. 메커니즘은 CLIP/Aesthetic가 객체 존재·국소 품질에 민감하지만 객체 수, 경계, 공간 관계 위반에는 둔감한 점이다. **가설:** object-count consistency와 relation graph edit distance를 추가하면 human unusable 판정과의 합의가 높아진다.

**최소 실험.** 30 prompt×4 schedule로 120장을 생성하고 human usable label 3인 majority, CLIP, Aesthetic, ImageReward, PickScore, detector count error, VLM relation error를 비교한다. **GO:** count+relation 조합이 human label AUROC 0.80 이상이고 기존 최고 단일 metric보다 0.10 이상 높다. **KILL:** prompt category를 분리하면 개선 CI가 0을 포함하거나 VLM relation judge order flip이 20%를 넘는다.

**기존 주장과 충돌 여부.** AReA 개선 주장과 충돌하지 않는다. 오히려 일부 자동 지표만으로 schedule을 선택하면 명백한 실패를 우수 결과로 고를 수 있다는 평가 경고다.

**평가:** 심각도 **4/5** · 재현 신뢰도 **4/5** · 연구 아이디어 가치 **5/5**

## 5. X-Ragent — 모든 도구 호출과 policy-routed measurement가 선택적 게이트보다 낮음

**실패 조건.** 흉부 X-ray QA에서 모든 auxiliary tool을 매 질문에 강제 호출하거나, 정량 measurement tool 선택을 1단계 policy에 맡기면 불필요하거나 잘못 누락된 근거가 생긴다.

**모델·데이터·설정.** Qwen3-VL-8B 기반 X-Ragent, ChestAgentBench·CheXbench. 동일 checkpoint에서 inference module을 끄거나 routing만 바꾸는 ablation이다.

**확인된 사실.** learned routing은 ChestAgentBench 71.7이었고, 모든 auxiliary tool 정적 호출은 71.0이었다. learned policy는 질문의 53.2%에서만 도구를 호출했다. 모든 evidence module 제거는 67.4, objective measurement만 제거는 70.8이었다. independent validity gate는 ChestAgent/CheXbench 71.7/77.3, policy routing+validity gate는 71.0/76.1이었다. [공식 ablation](https://arxiv.org/html/2610.16811#A1.SS5)

**저자·maintainer 인정.** 저자는 measurement가 적용 가능한 입력에만 backend가 노출되도록 policy routing과 분리했고, static all-tool이 learned routing보다 낮음을 보고했다. measurement의 31% withholding rate도 명시했다.

**커뮤니티 재현 / 재현 근거.** 독립 재현과 공식 코드·checkpoint 링크는 검색 시점에 확인하지 못했다. 따라서 수치는 저자 ablation에 한정하며 재현 신뢰도를 낮춘다.

**진단 → 메커니즘 → 가설.** 관찰은 tool availability, validity, usefulness가 한 routing score로 합쳐지면 오류가 난다는 것이다. 메커니즘은 policy가 측정 가능성까지 예측하면서 false-negative gate를 만들고, all-tool은 무관한 evidence를 추가한다. **가설:** deterministic applicability와 learned utility를 분리한 two-gate routing이 단일 policy보다 안정적이다.

**최소 실험.** 100문항에서 oracle applicability, backend validity, policy utility를 각각 기록하고 independent gate, policy-only, two-gate를 비교한다. accuracy, missing-valid-measurement rate, irrelevant-call rate, calls/question을 본다. **GO:** two-gate가 policy-only의 missing-valid rate를 절반 이하로 줄이고 learned routing 정확도 이상을 유지한다. **KILL:** 독립 gate label 오류가 5%를 넘거나 two-gate 이득이 call 수 증가만으로 설명된다.

**기존 주장과 충돌 여부.** X-Ragent의 설계를 지지하는 ablation이지만, `tool augmentation` 일반론을 제한한다. 도구를 더 쓰는 것과 근거가 좋아지는 것은 같은 명제가 아니다.

**평가:** 심각도 **4/5** · 재현 신뢰도 **3/5** · 연구 아이디어 가치 **4/5**

## 6. EventLens — 인접·반복 사건은 남고 효율 수치는 전체 teacher 비용을 포함하지 않음

**실패 조건.** 시각 상태가 점진적으로 변하는 인접 사건, 여러 번 반복되는 유사 행동, 장기 narrative dependency에서 event segmentation·relation reasoning이 혼동된다.

**모델·데이터·설정.** Qwen3-VL-4B/8B와 Qwen2.5-VL 기반 EventLens. TimeLens-100K·ET-Instruct-164K로 task-specialized GRPO teacher를 만든 뒤 MT-OPD student로 통합한다.

**확인된 사실.** 저자는 adjacent gradual events, high-level activity가 여러 fine action을 포괄하는 query, visually similar repeated actions을 남은 실패로 적었다. broad Video QA 변화는 작고 non-monotonic하므로 모든 benchmark가 개선된다는 근거로 쓰지 않는다고 명시했다. 또한 `약 1/3 training time` 효율 곡선은 MT-OPD student stage를 측정하며 teacher 학습과 teacher-distribution query 비용은 전체 계산에 추가된다. [공식 failure/limitations](https://arxiv.org/html/2610.16172#S4.SS4) · [공식 프로젝트](https://lostgreen.github.io/EventLens/)

**저자·maintainer 인정.** 자동 event chain의 coverage·granularity·semantic accuracy가 supervision 품질을 결정하고, 현재 construction audit가 model-assisted이며 timestamp perturbation은 100-step pilot이라고 밝혔다.

**커뮤니티 재현 / 재현 근거.** 독립 재현은 확인하지 못했다. 프로젝트는 공개됐지만 전체 teacher+student compute를 같은 hardware에서 다시 계측해야 한다.

**진단 → 메커니즘 → 가설.** 관찰은 local boundary 학습이 long-range identity와 narrative state를 자동 해결하지 않는다는 것이다. 메커니즘은 반복 clip의 appearance가 유사하고 proxy task window가 짧아, 사건 간 persistent entity/state가 supervision에 포함되지 않는 점이다. **가설:** entity-state ledger를 teacher target에 추가하면 repeated-action relation만 선택적으로 개선된다.

**최소 실험.** 반복 행동 50개와 비반복 control 50개를 구성하고 기본 EventLens, event ID, entity-state ledger 세 조건을 같은 frame budget으로 비교한다. relation accuracy, boundary mIoU, identity-switch, 전체 teacher+student GPU-hours를 기록한다. **GO:** ledger가 반복 subset 정확도를 8점 이상 높이고 control 손실이 2점 이하이며 identity-switch를 25% 줄인다. **KILL:** event ID만으로 같은 효과가 나거나 total compute가 direct mixed RL보다 낮지 않다.

**기존 주장과 충돌 여부.** targeted temporal gain과 충돌하지 않는다. 효율 주장은 student stage 기준이며 end-to-end compute 효율로 확대 해석하면 안 된다.

**평가:** 심각도 **4/5** · 재현 신뢰도 **3/5** · 연구 아이디어 가치 **5/5**

## 오늘의 실패 패턴 3개

1. **evidence acquisition과 evidence use가 분리된다.** Open-o3는 관련 crop을 찾은 뒤 identity/event를 틀리고, Urbex는 올바른 지역에 도달한 뒤 같은 클래스를 구분하지 못한다.
2. **용량을 늘리면 새로운 병목이 나타난다.** FramePack-U의 추가 프레임은 작은 모델에 distraction이 되고, EventLens의 teacher ensemble은 student-stage 효율 수치 밖에 비용을 남긴다.
3. **평가기와 routing이 실패를 숨긴다.** Aesthetic·CLIP은 layout 붕괴를 놓치고, X-Ragent의 all-tool/policy routing은 근거의 적용 가능성과 효용을 혼동한다.

## 논문 아이디어로 연결 가능한 빈틈

- **Evidence-stage error decomposition:** retrieval, association, terminal-event 판단을 독립 label과 verifier로 분해해 agentic video model의 오류 전파를 측정한다.
- **Density-aware active grounding:** 원거리 landmark uncertainty와 same-class density를 추정해 crop 규모·추가 view·abstention을 결정한다.
- **Capacity-aware frame budgeting:** base VLM의 evidence saturation을 online으로 감지해 프레임을 더 넣을지 중단할지 결정한다.
- **Layout-sensitive generative evaluation:** 객체 수와 spatial relation graph를 기존 perceptual metric에 결합해 사람이 unusable로 보는 구조 붕괴를 탐지한다.
- **Applicability–utility factorized routing:** deterministic validity gate와 learned value-of-information을 분리해 도구 누락과 과호출을 동시에 줄인다.
- **End-to-end post-training accounting:** teacher 생성·학습·student distillation·inference를 모두 포함한 capability-gain-per-GPU-hour 지표를 만든다.
