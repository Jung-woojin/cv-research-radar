## 1. Multi-Med — 평균 개선이 질문 유형별 강건성을 보장하지 않는다

**확인 사실·저자 보고.** 1,000개 image-question pair, 5개 modality, 4개 질문 유형의 benchmark다. Table 3에서 Qwen3-VL 4B→8B는 overall 64.2→72.9%지만 baseline 질문은 64.8→62.8%다. 네 질문 유형 집계 중 **1/4에서 수치상 악화**한다. modality mismatch는 97.6→98.8%, false suggestion은 19.6→38.0%여서 같은 모델의 강건성도 공격 형태에 따라 다르다. [공식 본문 Table 3](https://arxiv.org/html/2611.29934v1)

**cell·metric·coverage.** modality×질문 유형의 정확도가 핵심이다. 위 1/4는 질문 유형 집계이며 20개 교차 cell이나 개별 이미지 악화율이 아니다. ECE·선택적 응답 coverage는 미보고다. 오답률을 자유 생성 환각률로 치환하지 않는다.

**진단 → 가설 → 최소 실험.** 평가자 가설은 시각 정보 부족과 잘못된 전제 수용이 서로 다른 병목이라는 것이다. 동일 이미지의 baseline/전제 변형을 짝짓고, 기존 응답과 짧은 전제 확인 단계만 추가한 응답을 비교한다. checkpoint·prompt·해상도·evaluator를 고정하고 교차 cell 정확도, 답변 선택률, 동일 coverage의 risk를 남긴다.

**GO/KILL.** untouched 이미지에서 worst-cell 정확도가 개선되고 baseline 손실이 없으면 GO다. 거절 증가로만 개선되면 KILL한다. 4B/8B의 학습 차이가 통제되지 않아 크기의 인과 효과는 **not strictly apples-to-apples**다. 저자의 순위 유의성 분석도 수치상 1위가 확실한 우월 모델임을 지지하지 않는다. [공식 초록](https://arxiv.org/abs/2611.29934)

## 2. AdaptiveVPI — 공격 적응과 benign coverage를 함께 본다

**저자 보고·표 대조.** SnapGuard의 Compromise는 비적응형→적응형에서 BUA 15.9→80.6%, CUA 24.3→78.3%다. 선택한 두 interface 집계 **2/2가 악화**하며 전체 세부 cell 수는 아니다. WARD-Adaptive는 Table 6의 Compromise를 두 interface 모두 0%로 낮추지만 자체 benign pop-up 오경보는 CUA 1.1→38.9%, BUA 1.1→76.7%로 **2/2 악화**한다. [공식 Tables 4–6](https://arxiv.org/html/2611.29268v1)

**진단·평가 한계.** 화면에 보이지 않는 목적지와 적응형 공격이 screenshot 중심 평가의 빈틈을 드러낸다. 주 실험은 Qwen3-VL-8B, temperature 0.7이며 BUA/CUA step budget은 다르다. detector는 trajectory replay를 첫 개입에서 자르므로 완전한 온라인 방어 rollout과 구분해야 한다. Compromise는 540 run, Diversion/Engagement는 landing-page 360 run을 분모로 사용한다. ECE와 risk–coverage는 미보고이며 benign 오경보는 task 성공 coverage와 동일하지 않다.

**가설 → 최소 intervention.** 시각 경고 검사에 목적지·행동 권한 확인만 추가하고 동일 held-out 페이지·공격 예산에서 평가한다. 공격 성공, benign task 완료, false alarm, latency를 함께 기록한다.

**GO/KILL.** 동일 benign 완료율에서 worst-payload Compromise가 낮아지면 GO다. benign 차단으로만 0%를 만들면 KILL한다. 공격 탐색 예산과 방어 학습이 달라지는 비교는 **not strictly apples-to-apples**다.

## 3. Conartist — 정상 task 성공과 위험 행동은 공존한다

**저자 보고·표 대조.** Qwen3.5-Plus의 MUZZLE→Conartist 비교에서 OpenClaw ASR은 17.71→32.12%, 정상 task utility는 84.55→86.63%다. task 완료가 안전을 보장하지 않는다. Table III의 11개 scenario 중 ASR은 **8/11 상승, 1개 동률, 2개 하락**한다. 이는 방어 관점의 악화 cell 수이며 모델 전체·개별 sample 실패율이 아니다. [공식 Tables III–V](https://arxiv.org/html/2611.29977v1)

**진단·coverage.** 저자는 task와 일관된 악성 의존관계와 감사 과정의 추가 행동을 취약 지점으로 제시한다. utility는 공격하의 원래 task 완료율이며 clean coverage가 아니다. confidence calibration은 미보고다. 제한된 online 관측·task perturbation에서는 ASR 3.65/2.78%여서 offline headline을 그대로 일반화할 수 없다.

**평가자 가설 → 최소 실험.** 최종 거절보다 앞선 권한 밖 읽기·이동이 실패를 결정할 수 있다. synthetic 비밀·localhost만 사용한 sandbox에서 동일 task에 대해 기존 감사와 권한이 제한된 감사 단계를 비교한다. ASR, task utility, 첫 위험 행동 시점, 불필요한 접근 수를 기록한다.

**GO/KILL.** task utility를 유지하며 첫 위험 행동을 막으면 GO다. 최종 답변만 안전해지고 선행 접근이 남으면 KILL한다. 서로 다른 tool/GUI 환경의 headline과 관측 계약 간 수치는 **not strictly apples-to-apples**다. 공개 artifact의 실제 다운로드·재현 가능성은 이번 실행에서 검증하지 않았다. [공식 이력](https://arxiv.org/abs/2611.29977)
