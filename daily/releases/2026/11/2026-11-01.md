## 1. MoSE3 — evaluator까지 포함한 inference release

**[사실]** 공식 저장소는 Oct 2026에 inference code와 model weights, HO3D·iTACO·YCBInEOAT용 evaluation code, Art-Kubric generation code와 dataset release를 알린다. Python 3.10·PyTorch 2.6.0/CUDA 12.6 tested 환경과 weight download command를 제공한다. Checklist에서 training code는 미체크다. Code는 BSD 3-Clause, model weights는 π³ weights를 포함해 CC BY-NC 4.0이라고 명시한다.  
출처: https://github.com/mose3-tracker/MoSE3

**[release–claim gap]** inference/evaluation artifact는 있으나 full training reproduction은 아직 범위 밖이다. `--num_ref_pts`와 deformable surface용 `--se3_dist_weight`/`--se3_sigma_px` 같은 inference policy가 결과를 바꿀 수 있다.

**진단 → 가설 → 최소 실험:** 제공된 checkpoint로 40-frame example을 실행하고 evaluator에서 benchmark별 metric을 기록한다. model/dataset revision, `num_ref_pts`, input resolution, CUDA/PyTorch version을 manifest에 고정한다.

## 2. FlashVSR — weights는 공개, dataset은 미완료

**[사실]** 공식 저장소는 inference code와 v1/v1.1 model weights를 Hugging Face Git LFS로 제공하고, full/tiny/long-video inference script를 둔다. README는 v1.1을 권장한다. VSR-120K dataset release는 TODO로 남아 있다. Block-Sparse Attention backend는 A100·A800에서 ideal acceleration, H200에서는 limited acceleration을 보였고 RTX 40/50·H800은 compatibility/performance unknown이라고 명시한다.  
출처: https://github.com/OpenImagingLab/FlashVSR

**[저자 주장]** FlashVSR는 single A100에서 768×1408 video 약 17 FPS, 기존 one-step diffusion VSR 대비 최대 약 12× speedup을 낸다.

**[release–claim gap]** community implementation 일부는 LCSA를 빼고 dense attention으로 fallback해 high-resolution quality가 저하될 수 있다고 maintainer가 경고한다. 따라서 third-party deployment score를 official result로 취급할 수 없다. Training data artifact도 아직 공개 완료 상태가 아니다.

**진단 → 가설 → 최소 실험:** official repository·v1.1 weights·official LCSA backend로 동일 768×1408 input을 실행한다. GPU, backend commit, script variant, resolution, p50/p95 latency, FPS, peak VRAM, output checksum을 기록하고 LCSA-off 대비를 별도로 둔다.

## 3. R2R — evaluation release와 training gap

**[사실]** 공식 저장소는 Oct 2026에 inference/evaluation code와 R2R-Qwen3-VL-8B·4B checkpoints를 공개했으며 training code와 data-preparation script는 coming soon이라고 명시한다. VSI-Bench·ReVSI·3D-Point-QA의 download 및 eval script를 제공하고, paper setting으로 8B의 VSI-Bench 128 frames·ReVSI 64 frames, 4B의 16 frames를 기재한다. Repository license는 Apache-2.0이다.  
출처: https://github.com/yuqunw/R2R

**[release–claim gap]** evaluator와 checkpoints가 있어 inference comparison은 가능하지만 data construction·training from scratch는 검증할 수 없다. VGGT is downloaded on first use, FlashAttention, CUDA 13.0-oriented setup, frame count가 결과를 바꿀 조건이다.

**진단 → 가설 → 최소 실험:** 8B checkpoint로 official script를 실행하고 benchmark, checkpoint/base-model revision, `NUM_FRAMES`, GPU count, raw predictions와 metric JSON을 함께 보존한다. 16/32/64/128-frame sweep은 main score와 분리한다.

## 결론

세 release는 “다운로드 가능한 inference/evaluation”까지는 전진했지만 full training, data preparation, official backend parity가 모두 완결된 것은 아니다. 다음 실행에서는 release tag, model revision/hash, evaluator commit, training data license가 추가되었는지 먼저 점검한다.
