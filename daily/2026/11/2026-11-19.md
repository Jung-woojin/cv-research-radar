### C1. A tiny object detection dataset for high-altitude open-water search and rescue

**날짜·분류:** v1 11월 17일 14:08 UTC. 최근 신규 preprint. **저자 보고:** TinyWOD는 11,359장·19,505개 구명환 instance이며 평균 equivalent side length는 12.7 pixels다. [논문](https://arxiv.org/abs/2611.22825)

**방법·프로토콜:** 영상 단위로 train/val/test를 분리한다. APtiny는 원본 좌표에서 √(wh)<15인 객체의 AP다. 원문은 축소 구명환이 고고도에서의 크기를 모사하지만 외형 전이까지 보장하지 않는다고 명시한다. 따라서 제목만 보고 실제 1.5~2.0km 촬영 데이터로 소개하면 안 된다. [분할·수집·한계](https://arxiv.org/html/2611.22825v1)

**진단·제안:** 새 P2 branch부터 붙이기 전에 크기를 맞춘 실제 person-in-water와 구명환 간 feature/readout 전이를 측정한다. 같은 video 분할은 지켜도 장소 전이까지 독립적인지는 별도 확인이 필요하다. annotation 1~2 pixel 차이가 작은 box IoU에 미치는 영향도 감사한다. pretrained data overlap·seed variance·전체 학습 비용은 미확인이다.

### C2. Event-Based Person Detection for Maritime UAV Search

**날짜:** v1 11월 17일 17:11 UTC. **저자 보고:** MOBDrone 영상에 v2e로 합성 event를 생성하고 기존 annotation을 유지했다. held-out recording의 843 sample, 100ms 합성 노출에서 RVT-T의 person AP50:95는 15.63%, YOLOv8n은 6.89%, RT-DETR-R18은 9.44%다. Orin Nano에서 약 136ms·2.02J/sample을 보고한다. [논문](https://arxiv.org/abs/2611.23088)

**진단·제안:** synthetic blur에 견딘다는 결론과 실제 event sensor가 우수하다는 결론을 구분한다. modality와 architecture가 함께 달라 **not strictly apples-to-apples**다. 같은 recording·시간창에서 짧은 노출 RGB, 합성 event, 가능하면 실제 event를 비교한다. 반사·파도·카메라 motion별 false alarms도 분리한다. onboard 수치는 event 생성·전송까지 포함하는지 확인 전 전체 시스템 비용으로 사용하지 않는다. code/weights·실제 센서 전이·seed variance는 미확인이다.

### C3. Diagnosing and Correcting Skin-Tone Color Casts in Ultra-Lightweight Photo Retouching Networks

**진단·제안:** 개선 대상인 signed hue error와 전체 색 정확도를 분리한다. 같은 architecture에 합성 supervision/실제 expert pair를 교차하고 clean-input identity 검사를 추가한다. 사용자 tiny-object 연구에도 “전체 loss가 희귀 영역 오류를 숨기는가”라는 진단 방식이 유용하다. 다만 피부 실험의 효과를 detection 개선 근거로 가져오면 안 된다. skin mask 품질·인구집단별 외적 타당성·공개 artifact·전체 비용은 추가 확인 대상이다.

### C4. Wrong Input, Wrong Threshold: Re-evaluating Adversarial Facial Privacy

**날짜:** v1 11월 16일 21:37 UTC. **저자 보고:** 얼굴 사진을 실제 pipeline의 detect-align-crop으로 다시 처리하면 기존 privacy 결과가 달라진다. 원인은 단순 crop 외부 perturbation 손실보다 resampling mismatch로 분석하며, whole-image 조건에서는 기존 threshold가 nominal 1% 대신 2.3~5.4% false-accept를 허용한다. [논문](https://arxiv.org/abs/2611.21923)

**진단·제안:** 저장 이미지는 고정하고 전처리와 calibration을 각각 바꿔 representation 변화와 판정선 변화를 분리한다. **진단·제안:** 실패 원인을 prompt 반응 부족·부정 처리·시간 배치로 나눠 같은 개입의 유효 범위를 정한다는 점이 좋다. seed·prompt·생성 횟수를 고정한 guidance sweep과 재생성 baseline이 필요하다. 다른 generator로 threshold가 이동하는지 시험하고, 한 모델의 규칙을 일반 생성 법칙으로 확대하지 않는다. code/weights·cross-model 재현·총 생성 GPU 비용은 미확인이다.

**진단:** box가 올바른 위치에 있다는 것만으로 그 box가 답의 필수 증거라는 결론은 성립하지 않는다. 시간적으로 반복된 증거를 남겨 놓은 개입도 “모델이 영상을 무시한다”는 증거가 되지 않는다. 원문이 이미 entity-track 대조를 수행하므로 그 자체를 새 아이디어로 제시하지 않는다. 아래 mini-review에서 supervision·redundancy의 미분리 부분을 다룬다.

### V2. M$^3$-Test: Coverage Gaps in Joint-Perturbation Testing of Visual Question Answering

**날짜:** v1 11월 17일 07:27 UTC. **저자 보고:** 네 VLM의 260만 응답을 정렬된 교란 grid로 평가했다. 40개 단일 모달 테스트를 모두 통과한 Qwen 질문 중 26~29%가 결합 교란에서 실패하지만, 전체 joint record 실패율은 0.6% 미만이다. archived failure 재실행의 약 90%가 재현된다고 보고한다. [논문](https://arxiv.org/abs/2611.22329)

## 4) LLM / Agent / Training / System 변화 3편

### L1. Ambient LLMs: Data-Efficient Supervised Fine-tuning via Temperature Matching

**날짜:** v1 11월 17일 18:59 UTC, work in progress. **저자 보고:** frozen pretrained model의 고온 conditional distribution을 noisy teacher로 삼아 SFT의 tail forgetting을 완화한다. temperature가 teacher 신뢰도를 조절하며 standard SFT 대비 최대 21% 평균 상대 개선을 주장한다. [논문](https://arxiv.org/abs/2611.23229)

**진단·제안:** 21 percentage points로 바꾸어 쓰지 않는다. 같은 학습 token·optimizer·checkpoint에서 SFT, distillation, Ambient를 비교하고 domain gain과 일반 능력 보존을 별도 평가한다. vision adaptation에서도 teacher 보존이 이로운 조건을 묻는 출발점이지만 CV에서 검증된 결과는 아니다. frozen teacher의 추가 forward·memory를 포함한 비용, 코드·세부 seed variance는 미확인이다.

### S1. GridDriver: On-Board BEV-Based Language Planning and Reasoning

**날짜:** v1 11월 16일 21:39 UTC. **저자 보고:** spatial BEV token과 비동기 language generation을 결합한 shared checkpoint가 NAVSIM 87.9% PDMS, nuScenes-QA 57.6% accuracy를 기록한다. standalone planning 32.7ms와 ROS 2 pipeline 9.4 plans/s를 별도로 보고하며 차량 실험은 open-loop다. [논문](https://arxiv.org/abs/2611.21924)

**진단·제안:** 두 latency 수치는 측정 경계가 다르다. structured token의 geometric information 이득과 scheduling 이득을 분리하고 QA가 길어질 때 planning deadline miss를 측정한다. open-loop 결과를 closed-loop 안전성으로 확장하지 않는다. UAV 관측·질의 동시 수행과 연결 가능하나 별도 실험이다. hardware·배포 weights·full pipeline peak memory는 추가 확인 대상이다.

### S2. Spool: Low-Latency Streaming Inference for Hybrid Vision-Language Models

**날짜:** v1 11월 17일 18:59 UTC. **저자 보고:** recurrent update의 affine transformation을 frame별 cache하고 결합해 sliding window를 유지한다. 다섯 hybrid VLM×네 benchmark에서 빠른 vLLM baseline 대비 p95 TTFT의 기하평균 6.6배 단축·평균 accuracy +2.3 points를 보고한다. [논문](https://arxiv.org/abs/2611.23228)

**한계·제안:** layer 내 제거가 exact여도 전체 network에서 과거 정보가 완전히 소거된 것은 아니다. earlier-layer cached input에 잔여 영향이 남는다. 9B 사례의 추가 cache는 4.8GiB로 제시돼 작은 GPU 배포에서는 중요하다. full replay와 동일 window/frame budget으로 latency·peak memory·expired cue 의존성을 함께 측정한다. TTFT가 전체 답변 latency는 아니다. [설계·비용·expiry fidelity](https://arxiv.org/html/2611.23228v1)

## 6) 연구적으로 중요한 Finding 3개

1. **증거 위치와 증거 사용을 분리해야 한다.** 올바른 citation, human-like gaze, retrieval 포함만으로 답이 해당 증거에 의존함을 보장하지 않는다. 이는 세 논문의 결과를 연결한 **추론**이다. [Citation](https://arxiv.org/abs/2611.21940) · [Gaze](https://arxiv.org/abs/2611.23209) · [Retrieval](https://arxiv.org/abs/2611.23127)
2. **평균 지표의 보존은 실패 단위의 보존이 아니다.** 피부 영역 오류와 request별 joint vulnerability는 집계 지표의 denominator·slice가 결론을 바꿀 수 있음을 보여준다. [Skin-tone](https://arxiv.org/abs/2611.22106) · [M3-Test](https://arxiv.org/abs/2611.22329)
3. **좋은 대리 실험과 실제 배포 주장은 구분된다.** 축소 표적·합성 event·layer-local expiry·open-loop planning은 각각 유효 범위가 있다. 이 경계를 맞추는 것이 추가 architecture보다 먼저다. [TinyWOD 한계](https://arxiv.org/html/2611.22825v1) · [Event](https://arxiv.org/abs/2611.23088) · [Spool](https://arxiv.org/abs/2611.23228) · [GridDriver](https://arxiv.org/abs/2611.21924)

## 7) 과대평가 가능성 / 주의할 연구

- **TinyWOD:** tiny 구명환 검출은 실제 고고도 사람 검출의 보증이 아니다. 실제 고도보다 apparent-size matching, 객체 외형·지역·야간 비중의 범위를 함께 읽는다. [원문 한계](https://arxiv.org/html/2611.22825v1)
- **Spool:** “expired frame 제거가 exact”를 시스템 전체의 완전한 망각으로 읽으면 과장이다. accuracy 보존과 금지된 과거 cue의 비의존성은 서로 다른 검사다. [설계 한계](https://arxiv.org/html/2611.23228v1)

## 8) 오늘 바로 읽을 Top 3

1. **Does the Model Use What It Cites?** — grounding의 관측과 인과적 의존성을 구분하는 실험 논리가 가장 직접적이다.
2. **TinyWOD** — 사용자 해상 tiny-object 연구에 맞으며 데이터의 대리성부터 감사할 가치가 크다.
3. **Spool** — streaming VLM의 지연·상태·기억 경계를 함께 다룬다.

이 순서는 연구 활용도에 대한 조사자의 판단이며 측정된 순위가 아니다.

## 9) 1위 논문 5~10분 미니 리뷰

**왜 중요한가:** 설명을 검증 가능한 box와 연결하는 것과, 답이 그 증거에 기대는 것은 별도 주장이다. 이 논문은 정답률보다 그 사이의 간극을 측정한다. 모델이 스스로 고른 box를 쓰므로 새로운 gold annotation 없이 시작할 수 있다. [논문](https://arxiv.org/abs/2611.21940)

**실험 논리:** 첫 실행에서 citation을 고정하고, cited masking과 같은 크기·같은 시각의 control masking으로 정답→오답 전환 차이를 본다. 영상을 모두 가리는 blind 대조, gold evidence·object/entity track 제거로 대안 설명을 검사한다. NExT-QA에서는 증거가 다른 frame에 계속 보이므로 작은 box gap만으로 visual reasoning 부재를 결론 내릴 수 없다. [실험 설계](https://arxiv.org/html/2611.21940v1)

**남은 blind spot:** benchmark 간 evidence redundancy·citation format·supervision이 함께 다르다. 원문도 이를 완전히 분리하지 못했다고 인정한다. NExT-QA는 한 base 중심이며, 두 seed는 일부 arm뿐이다. bootstrap item interval은 training variance가 아니다. pseudo-label과 검증 detector의 공통 편향도 남는다. [한계](https://arxiv.org/html/2611.21940v1)

**진짜 활용점:** 새 모듈보다 먼저 “인용 영역 제거가 충분했는가”와 “control이 비슷한 semantic damage를 주는가”를 검사한다. 사용자의 tracking 연구에서는 identity를 유지한 전체 시간축 intervention으로 확장할 수 있다. 다만 entity-track 검사는 이미 선행연구의 기여다. 신규성은 아래 crossed supervision 실험과 오류 조건의 일반화에서 확보해야 한다. 공개 repo에는 아직 weights와 item output이 없어 즉시 완전 재현 가능한 상태로 보지 않는다. [공식 구현 상태](https://github.com/JugalGajjar/CausalSight)

## 10) 후속 연구 씨앗 3개

### 씨앗 1. Citation 의존성을 결정하는 것은 supervision인가, 시간적 중복인가?

- **Observation→Diagnosis:** V1의 benchmark 간 cite gap에는 supervision·format·redundancy가 함께 변한다.
- **가설:** citation이 sparse frame으로 제한될 때 반복 증거가 작은 cite gap을 만들며, track-level supervision은 답의 증거 의존성에 별도 효과를 낸다.
- **최소 개입·dataset·baseline:** CLEVRER에서 exact/pseudo chain과 sparse/track citation을 교차한다. 먼저 동일 checkpoint·동일 질문의 box/track/random masking으로 시작하고, 이후 필요한 arm만 학습한다.
- **통제:** entity의 보이는 frame 수, mask 면적·시간 길이, 질문 유형·답 option·decode seed를 맞춘다. 검증 detector를 바꾸거나 소규모 사람 annotation으로 교차 확인한다.
- **GO/KILL:** redundancy를 통제해도 supervision 효과가 반복되면 GO. 차이가 사라지면 새 reasoning mechanism 주장을 KILL하고 annotation format의 평가 효과로 정리한다.
- **비용·신규성:** 추론 감사 cost 2/5, 교차 학습 4/5의 계획상 판단이다. 이미 원문이 제안한 crossed design과 겹치므로 단순 실행만으로 novelty는 낮다. 실제 영상까지 일반화되는 실패 예측 기준이 필요하다. 4~8주에는 저장 출력 감사와 제한된 교차 실험을 우선한다.

### 씨앗 2. TinyWOD의 tiny 성능은 크기 정보인가, 구명환 외형에 대한 전문화인가?

- **Observation→Diagnosis:** C1은 apparent size를 모사했지만 실제 고고도 외형 전이는 미검증이다.
- **가설:** 같은 픽셀 크기에서도 형상·contrast·배경 차이가 성능을 좌우하며, frozen feature의 정보 부족과 readout 부적합이 다르게 나타난다.
- **최소 실험:** TinyWOD와 이용 가능한 MOBDrone의 크기를 맞춘 slice를 만들고 frozen encoder+linear readout, 원 detector, 제한된 head adaptation을 비교한다. category가 다르므로 raw AP 직접 비교로 전이를 정의하지 않는다.
- **통제·metric:** recording/location split, 객체 크기·contrast 층화, 원본/인위 resize 구분, center error와 APtiny·recall·false alarms를 함께 기록한다. 1~2px box perturbation은 annotation 민감도 진단용이다.
- **GO/KILL:** feature probe는 되지만 head가 실패하면 readout 개입 GO. probe·oracle도 약하면 “head만 바꾸면 해결” 가설을 KILL한다. 실제 고고도 자료가 없으면 크기 모사 domain 간 연구로 범위를 제한한다.
- **비용·신규성:** frozen inference cost 2/5, adaptation 3/5 추정. 단순 dataset 간 비교보다 외형·크기·annotation을 분리해야 기여가 된다. negative result도 대리 benchmark의 전이 한계를 제공한다.

### 씨앗 3. Streaming cache가 만료시킨 증거를 답에서 실제로 잊었는가?

- **Observation→Diagnosis:** S2는 layer 내부 expiry와 network 전체 residual influence를 구분한다.
- **가설:** 평균 정확도는 유지돼도 만료 구간에만 존재한 강한 단서가 특정 질의에서 답을 바꿀 수 있다.
- **최소 실험·baseline:** 짧은 합성 영상에서 window 이전 구간에만 답 cue를 놓고, 동일 현재 window의 full replay/Spool/persistent state를 비교한다. 현재 window에 답이 있는 정상 대조군과 답이 없는 abstention 대조군을 둔다.
- **Metric·통제:** expired cue 유무에 따른 답 전환율, 현재 증거 정확도, p95 TTFT·전체 latency·peak memory. 동일 frame 수·해상도·query·checkpoint·GPU에서 비교한다.
- **GO/KILL:** full replay 대비 cue 의존성이 반복되면 cache 경계 진단 GO. 차이가 없으면 해당 조건의 expiry fidelity 근거를 남기고 leakage 주장을 KILL한다.
- **비용·신규성:** GPU 추론 cost 3/5의 계획 추정이며 8GB 실행을 보장하지 않는다. 원문에도 expiry fidelity 평가가 있어 일반 accuracy 재측정은 중복이다. adversarial temporal cue·abstention·회복 조건을 추가해야 4~8주 연구 후보가 된다.

**오늘 먼저 할 일:** 씨앗 1의 저장 citation과 mask-control 구성 감사. 공개 weights가 없어 막히면 이미 접근 가능한 모델·적법한 영상으로 작은 진단 pilot을 만들고 원문 재현과 구분한다. 작은 GPU 전 단계에서는 split·annotation·mask area/time·citation parser를 CPU로 검증한다.
