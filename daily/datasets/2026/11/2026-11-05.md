## 1. Label Studio

- **사실:** HumanSignal은 Label Studio를 standardized output format의 multi-type labeling tool로 설명하며 repository가 2026-11-04에 update됐다.
- **확인되지 않음:** annotation guideline, taxonomy, export schema의 실제 diff.
- **진단→가설:** tool update가 기존 label correction을 뜻하지 않는다. schema/export provenance 미보존이 label shift를 model gain으로 보이게 할 수 있다.
- **최소 audit:** export 두 버전의 schema JSON hash, task/image ID 수, label count, annotator metadata를 비교한다.
- **GO/KILL:** 네 값과 revision을 저장하면 GO; provenance 없는 legacy export는 model comparison용으로 KILL.

## 3. Perception Test 2026

- **사실:** report는 city-scale KilometerAudio/KilometerVision track을 설명하며 winning solution이 expensive agentic pipeline을 사용했고 standalone multimodal model은 여전히 어렵다고 적는다.
- **저자 주장:** city-scale reasoning에서 agentic pipeline이 경쟁력 있다.
- **진단→가설:** direct model과 agent pipeline은 retrieval/tool calls/GPU seconds가 달라 accuracy-only 비교는 공정하지 않다.
- **최소 audit:** split, external retrieval, tool calls, latency, GPU seconds, failure slice를 함께 기록한다.
- **GO/KILL:** evaluator·compute manifest가 있으면 GO; hidden-test score만 있고 pipeline budget이 없으면 comparison으로 KILL.
- **출처:** https://arxiv.org/abs/2610.12081
