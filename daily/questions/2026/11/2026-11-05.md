## Q1. video VLM의 시간 오답은 reasoning failure가 아니라 prompt metadata failure인가?

1. **문제 정의:** video-VLM의 time-QA 오답을 visual temporal reasoning 실패와 입력 timestamp injection 실패로 분리한다.
2. **왜 지금 가치가 있는가 / 직접 근거:** vLLM MiMo-V2.6 issue는 150초 clip이 기본 32-frame sampling 뒤 prompt에서 00:00~00:30으로 label되는 재현을 공개했다.  
   출처: https://github.com/vllm-project/vllm/issues/65523
3. **Gap:** 기존 time-QA는 answer correctness를 보지만, model이 받은 label과 실제 sampled frame seconds의 정합성을 거의 평가하지 않는다.
4. **핵심 가설:** prompt timestamp error와 cited-frame error를 분리하면, answer 오류 중 metadata-induced failure를 별도로 귀속할 수 있다.
5. **MVP:** 7/30/150/194초 synthetic clip을 25/29.97 fps로 만들고, 32-frame sample의 실제 second·prompt label·time-QA answer를 수집한다.
6. **기준선·데이터:** MiMo 또는 timestamp를 노출하는 video processor, metadata-corrected processor, timestamp-free prompt; synthetic clip + 공개 time-QA subset.
7. **성공/실패 metric:** mean/max timestamp error, cited-frame seconds error, time-QA EM, abstention calibration. duration과 무관하게 30초 endpoint가 나오면 metadata path는 KILL이다.
8. **Ablation:** clip duration, FPS, number of frames, uniform/adaptive sampling, timestamp precision(BF16/FP32), label 유무.
9. **compute 난이도:** 2/5. **novelty:** 4/5. **feasibility:** 5/5. **compute efficiency:** 5/5. **publication potential:** 4/5.
10. **negative result 가치 / 4–8주:** corrected metadata가 score를 안 바꿔도 어떤 task가 label 오류에 둔감한지 확인할 수 있다. 4주 audit, 6주 multi-model matrix, 8주 error taxonomy가 가능하다.

## Q2. pixel input과 precomputed embedding은 같은 visual evidence를 보존하는가?

1. **문제 정의:** 같은 image/video를 pixel 또는 precomputed embedding으로 주었을 때, execution success뿐 아니라 visual answer와 evidence가 같은지 측정한다.
2. **왜 지금 가치가 있는가 / 직접 근거:** vLLM issue #65531은 enable_mm_embeds=True와 encoder CUDA graph 조합에서 InternVL3-1B 재현 request가 engine을 죽이고, 다수 VLM family의 image/video embedding graph path가 실패한다고 보고했다.  
   출처: https://github.com/vllm-project/vllm/issues/65531
3. **Gap:** production retrieval/cache/encoder-disaggregation path는 embedding을 쓰지만, VLM 평가의 기본 smoke test는 pixel path에 편중돼 있다.
4. **핵심 가설:** crash가 없는 경우에도 pixel-vs-embed 출력 차이는 preprocessing, tile grouping, metadata propagation 또는 encoder precision 차이를 드러낸다.
5. **MVP:** 이미지·짧은 video 각 50개에서 pixel/embedding × eager/graph 조건을 실행하고 engine survival, answer, cited region/frame을 비교한다.
6. **기준선·데이터:** InternVL 또는 Qwen-VL 계열, pixel-only eager baseline; RefCOCO-style region 질문과 document/video evidence 질문.
7. **성공/실패 metric:** request success, engine survival, answer agreement, region/frame agreement, latency, peak memory. crash/empty spec/KeyError는 해당 cell KILL이다.
8. **Ablation:** encoder model, image tile 수, embedding dtype, cache source, graph on/off, image/video modality.
9. **compute 난이도:** 3/5. **novelty:** 4/5. **feasibility:** 4/5. **compute efficiency:** 4/5. **publication potential:** 4/5.
10. **negative result 가치 / 4–8주:** 모든 cell이 동등하면 minimal regression matrix와 safe compatibility boundary를 제시할 수 있다. 4주 harness, 6주 three-model audit, 8주 evidence parity analysis가 가능하다.

## Q3. long-video routing 최적화는 visual answer를 보존하면서 TTFT를 줄이는가?

1. **문제 정의:** multimodal prefix mask가 실제로 필요한 layer와 그렇지 않은 layer를 분리 routing할 때 long-video latency 절감이 visual fidelity를 해치지 않는지 검증한다.
2. **왜 지금 가치가 있는가 / 직접 근거:** vLLM issue #65513은 Gemma 4 long-video workload에서 media span 존재만으로 full-attention group도 Triton kernel을 타는 경로를 보고했고, H100의 한 workload에서 routing prototype의 TTFT 감소를 제시했다. issue는 아직 open이며 작성자도 더 넓은 eval이 필요하다고 명시한다.  
   출처: https://github.com/vllm-project/vllm/issues/65513
3. **Gap:** token-identical output 또는 단일 throughput 수치만으로 kernel swap의 visual grounding·time reasoning fidelity를 판정하기 어렵다.
4. **핵심 가설:** layer-group mask necessity를 routing key로 사용하면, causal full-attention layer의 비용을 줄이면서 cited-frame consistency를 유지할 수 있다.
5. **MVP:** 8/32/66 clip prompt에서 stock과 alternate routing/attention backend를 비교한다.
6. **기준선·데이터:** Gemma 4 또는 유사 prefix-LM VLM, stock backend, text-only length-matched prompt; 긴 공개 video-QA 100개.
7. **성공/실패 metric:** TTFT, prefill time, prompt-logprob drift, answer EM, cited-frame agreement, short-clip regression. evidence/time answer가 바뀌면 KILL이다.
8. **Ablation:** video length, resolution, frame count, KV dtype, hardware/backend, sliding/full attention group 비율.
9. **compute 난이도:** 5/5. **novelty:** 4/5. **feasibility:** 3/5. **compute efficiency:** 2/5. **publication potential:** 4/5.
10. **negative result 가치 / 4–8주:** TTFT 이득이 evidence drop과 함께 나타나면 routing safety metric의 필요성을 강하게 보일 수 있다. 소규모 8/32 clip pilot은 4주 안에, full matrix는 8주 이상이다.

## Q4. 정답 + 근거 frame이 실제 시간에 맞는가를 채점하는 video evidence metric은 가능한가?

1. **문제 정의:** 모델이 정답 텍스트와 cited frame/index를 함께 내더라도, 해당 frame의 실제 timestamp와 답변의 시간 주장이 일치하는지 자동으로 평가한다.
2. **왜 지금 가치가 있는가 / 직접 근거:** MiMo 사례는 prompt time label이 real frame time과 달라질 수 있음을 보였고, PAI-AV 공개 data card는 temporally aligned human-refined reasoning labels를 제공한다고 설명한다.  
   출처: https://github.com/vllm-project/vllm/issues/65523  
   출처: https://huggingface.co/datasets/nvidia/PhysicalAI-Autonomous-Vehicles/blob/main/README.md
3. **Gap:** answer EM과 text similarity는 temporal evidence의 alignment를 직접 채점하지 않는다.
4. **핵심 가설:** answer correctness × temporal evidence overlap의 두 축은 language shortcut, wrong-time right-answer, true visual temporal reasoning을 구분한다.
5. **MVP:** 50개 action/event clip에 human keyframe interval을 붙이고, model의 cited frame 또는 timestamp를 interval과 비교한다.
6. **기준선·데이터:** answer-only prompting, cite-then-answer prompting, oracle timestamp prompt; PAI-AV 공개 val 또는 라이선스 확인된 driving/video subset.
7. **성공/실패 metric:** answer EM, temporal IoU, mean absolute time error, evidence-conditioned risk-coverage, annotation agreement.
8. **Ablation:** evidence output format, interval width, frame sampling rate, oracle/estimated timestamp, event rarity.
9. **compute 난이도:** 3/5. **novelty:** 4/5. **feasibility:** 4/5. **compute efficiency:** 4/5. **publication potential:** 5/5.
10. **negative result 가치 / 4–8주:** cited-frame가 답 품질과 상관없어도 existing temporal benchmark의 blind spot을 정량화할 수 있다. 4주 annotation pilot, 8주 benchmark/multi-model analysis가 가능하다.

## Q5. visual deployment에서 지원 조합을 검증하는 최소 regression matrix는 무엇인가?

1. **문제 정의:** model, modality, feature source, timestamp policy, graph/backend, input duration의 조합 중 어떤 최소 set이 visual production failure를 가장 많이 잡는지 측정한다.
2. **왜 지금 가치가 있는가 / 직접 근거:** 오늘의 vLLM issues는 video timestamp metadata, precomputed embeddings with encoder graph, long-video attention routing처럼 서로 다른 configuration interaction에서 발생했다.  
   출처: https://github.com/vllm-project/vllm/issues/65523  
   출처: https://github.com/vllm-project/vllm/issues/65531  
   출처: https://github.com/vllm-project/vllm/issues/65513
3. **Gap:** VLM release test는 model-level happy path 중심이라 metadata·duration·feature source의 interaction coverage를 명시하지 않는 경우가 많다.
4. **핵심 가설:** pairwise covering array에 visual invariant(시간 label, engine survival, answer/evidence parity)를 붙이면 exhaustive grid보다 적은 비용으로 high-severity failure를 찾는다.
5. **MVP:** 5 factors의 2~3 level covering array를 만들고 30~60 cell을 run한다.
6. **기준선·데이터:** one-factor-at-a-time smoke test, full factorial의 작은 subset; 20 image, 20 short/long video probe set.
7. **성공/실패 metric:** 발견한 unique failure 수/cell, 실행 시간, false alarm, coverage, rerun determinism.
8. **Ablation:** factor 제거, pairwise vs 3-wise, invariant 종류, pixel-only vs multimedia suite.
9. **compute 난이도:** 3/5. **novelty:** 3/5. **feasibility:** 5/5. **compute efficiency:** 5/5. **publication potential:** 3/5.
10. **negative result 가치 / 4–8주:** low interaction rate도 VLM CI의 최소 regression budget을 정하는 실증 근거가 된다. 4주 probe set, 6주 coverage comparison, 8주 open harness가 가능하다.
