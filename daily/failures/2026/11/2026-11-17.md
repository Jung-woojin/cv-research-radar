## 1. 고해상도 box-local mask의 dtype 변환이 좌표와 출력 dtype을 손상

**확인 사실:** #27232는 조회 시 미병합이다. diff는 ROI를 요청 dtype으로 변환하지 않고 device만 옮기며, dense 출력은 crop의 dtype으로 할당한다. 자동 리뷰는 있지만 사람 maintainer의 독립 재현은 확인하지 않았다. [공식 PR](https://github.com/ultralytics/ultralytics/pull/27232) · [diff](https://github.com/ultralytics/ultralytics/pull/27232/files)

- **실패 조건·구성:** `yolo26n-seg.pt`, `bus.jpg`를 3840×2880으로 resize, CPU, `retina_masks=True`. `result.to(dtype=torch.float16).masks.data` 접근 시 예외가 보고됐다. float32 변환에서는 dense 결과가 uint8로 돌아오는 별도 계약 위반이 있다.
- **작성자 재현·community 수준:** 원문은 base `ef512bfc2`에서 slice 크기 불일치, 수정에서 통과를 보고한다. PyTorch 2.14.1 CPU 및 RTX 3050·PyTorch 2.6.0+cu124의 실제 모델 검사도 기재했다. 외부 독립 community 재현은 미확인이고 전체 suite도 미실행이라고 명시했다.
- **진단 → 메커니즘:** 결과 변환이 mask 값과 정수 ROI 메타데이터를 같은 변환 함수에 넣었다. 좌표를 half로 바꿨다가 정수로 되돌려도 이미 생긴 반올림은 회복되지 않는다. 별도로 uint8 고정 할당이 요청 dtype을 지웠다.
- **가설 → 최소 개입:** 좌표는 int64로 유지하고 mask pixel만 변환하면 sparse 저장의 메모리 이점을 유지하면서 dense tensor 변환과 같은 의미를 보장할 수 있다.
- **최소 실험:** 정밀도 경계 주변의 홀수 좌표를 가진 비대칭 합성 ROI와 binary crop을 만든다. 고정 base와 PR head `b48d79b4888afa2eb4e5f7aa4537a891da7b1886`에서 float16·float32·uint8·bool·int64 변환 후 좌표 동일성, dtype, dense 기준과 pixel equality를 검사한다. 빈 mask와 낮은 해상도를 대조군으로 두고, 그다음 원문의 실제 모델 입력으로 확대한다.

## 3. LiteRT INT8 분류의 logit 포화가 top-1 동점을 만듦

**확인 사실:** #27225는 `95d2e2a72ff002e81228ea1074d59fb69baa175d`로 main에 병합됐다. diff는 FP32 head 출력 규칙을 `Classify`까지 확장하고 linear weight를 dynamic INT8로 유지한다. Maintainer glenn-jocher는 기존 main에서 tied logits를 재현하고 수정 후 사라졌다고 명시했다. [공식 PR·재현 댓글](https://github.com/ultralytics/ultralytics/pull/27225) · [diff](https://github.com/ultralytics/ultralytics/pull/27225/files)

- **실패 조건·구성:** 분류 모델의 `format=litert`, `quantize=8` export. 기존 classify head의 INT8 logit 범위 상단에서 여러 class가 clipping되면 동점이 생기고 낮은 index가 선택될 수 있다.
- **저자 측 보고:** ImageNet val 50,000장 CPU 평가와 calibration 조건별 결과가 제시됐다. 이번 watch는 원자료를 재평가하지 않았고 maintainer도 전체 50k 결과를 검증하지 않았다고 밝혔다.
- **Maintainer 재현:** Apple M5 Pro CPU, torch 2.14.1, litert-torch 0.10.0, ai-edge-litert 2.3.0, ai-edge-quantizer 0.10.1에서 imagenette160 val 3,925장을 1,000 class 대상으로 평가했다. calibration shuffle을 꺼 순서를 맞췄다.

## 논문 아이디어로 연결 가능한 빈틈

**추론:** 고해상도 aerial/UAV·maritime segmentation에서는 sparse mask 최적화와 후처리 변환의 의미 보존을 함께 평가할 여지가 있다. 같은 예측을 dense/sparse로 저장하고 dtype·device·접근 순서만 바꾸는 metamorphic 검사로 모델 오류와 시스템 오류를 분리할 수 있다. 다만 알려진 PR을 재현하는 것만으로 논문 신규성이 생기지는 않는다. 여러 구현에서 재발하는 변환 계약과 task 영향까지 입증해야 한다.

FastSAM은 prompt grounding 평가에 요청 격리 검사를 더할 근거다. 입력 영상이 고정되어도 다른 요청을 예약하는 것만으로 결과가 달라지면 temporal reasoning 실패로 해석하기 전에 실행 상태부터 진단해야 한다. INT8은 calibration 크기뿐 아니라 logit 동점·포화·class index 편향을 함께 보는 진단 가설을 제공한다.

## 직접 재현해볼 최소 실험

첫 실험은 CPU 합성 ROI의 dtype 변환 검사다. 좌표·crop을 고정하고 FP16 변환 전후 정수 좌표와 dense pixel parity를 비교한다. 이어 실제 3840×2880 YOLO26n-seg 결과, FastSAM 두 stream, 고정 calibration의 INT8 분류 순으로 확대한다.

합성 검사는 GPU 학습이 필요 없다. 실제 고해상도 `masks.data` 접근은 dense 할당을 발생시키므로 객체 수와 메모리를 기록해야 한다. 이번 조사에서는 실행시간·VRAM을 측정하지 않았으며 RTX 5060 Ti 8GB에서 전체 조건이 실행된다고 보장하지 않는다.

**공통 GO:** 고정 base에서 조건부 실패가 발생하고 최소 개입 후 사라지며 대조군이 유지된다. **공통 KILL/축소:** 재현이 안 되면 revision·호출 경로·입력 표현을 먼저 확인하고 모델 능력에 대한 결론을 보류한다. 점수는 실측 성능이나 발생 확률이 아닌 조사자의 우선순위 판단이다.
