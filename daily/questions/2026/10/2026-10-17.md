## Q1. 출력 정확도 변화 없이도 내부 shortcut을 조기에 탐지하는 “evidence-path drift” 지표를 만들 수 있는가?

### 1. 문제 정의
의료 영상 모델이 높은 정확도를 유지하면서 병변 대신 영상 모서리의 문자 주석을 읽는다면, 출력 기반 검증은 위험한 근거 경로를 놓친다. 목표는 counterfactual edit 전후의 attention·logit·representation 변화를 묶어 shortcut을 조기에 경고하는 지표를 만드는 것이다.

### 2. 왜 지금 가치가 있는가
최근 연구는 ViT-Base/16의 특정 head가 200개 COVID-19 영상 중 62%에서 주석을 읽고, full fine-tuning 후에도 기존 spurious 이미지의 98.4%가 남았다고 보고했다. 단일·다중 head ablation의 출력 평가는 유의한 변화를 잡지 못했다는 점이 특히 중요하다.

### 3. 직접 근거와 Observation → Gap
- **확인된 저자 주장:** 문자 inpainting 후 폐 영역 attention이 1.52배 늘었고, NIH ChestX-ray14·DeiT-Base·ViT-Large에서도 유사 회로가 관찰됐다.
- **Gap:** 현행 validation은 prediction correctness를 보지만, 같은 정답을 내는 잘못된 근거 경로의 이동을 표준화해 측정하지 않는다.
- **출처:** [Spurious Attention Heads, arXiv:2610.21638](https://arxiv.org/abs/2610.21638)

### 4. 핵심 가설
원본/주석 삭제/주석 위치 이동에서 class logit은 안정적이어도 attention mass와 intermediate representation의 변화량은 domain-shift 실패를 예측한다.

### 5. 최소 실험(MVP)
흉부 X-ray 100장에 세 counterfactual 조건을 만들고, ViT-B/16 한 모델의 layer별 attention mass, CLS cosine drift, logit drift를 기록한다. shortcut score를 훈련 데이터 일부에서 정한 뒤 보지 않은 annotation style에 적용한다.

### 6. baseline과 dataset
- Dataset: NIH ChestX-ray14의 문자 주석 포함 표본 또는 공개 가능한 동등 subset
- Baseline: accuracy/AUROC만 사용, Grad-CAM overlap, attention rollout
- Ablation: 문자 삭제 대 단순 luminance/edge-matched patch

### 7. 성공/실패 판정 metric
Primary는 unseen-style shortcut AUROC와 lung-region attention ratio다. **제안 GO 기준:** accuracy 변화가 1%p 이내인데 shortcut AUROC ≥0.75. **KILL 기준:** counterfactual 종류를 바꾸면 AUROC가 0.60 아래로 붕괴.

### 8. compute 난이도
**2/5.** frozen ViT 추론과 feature hook 중심이라 RTX 5060 Ti 8GB에서 가능하다.

### 9. novelty 위험요인
attention을 설명으로 해석하는 한계가 크다. novelty는 “attention 시각화”가 아니라 원인 개입과 예측 가능한 drift score에 달려 있다.

### 10. 4~8주 내 논문화 가능성
**중상.** 데이터 전처리와 두 architecture 교차검증까지 완료하면 diagnostic short paper로 가능하다.

### 11. negative result여도 얻는 결론
내부 지표가 domain failure를 예측하지 못하면 attention 기반 안전감사의 한계를 정량화하고 causal representation probe 필요성을 보여준다.

- **평가:** novelty **4/5** · feasibility **5/5** · compute efficiency **5/5** · publication potential **4/5**

## Q2. 불균형 미세조정 뒤의 희귀 클래스 지식은 사라진 것인가, 아니면 prompt가 접근 경로를 잠근 것인가?

### 1. 문제 정의
희귀 클래스 recall이 zero-shot보다 낮아졌을 때 이를 catastrophic forgetting으로 부르기 전에, 다른 descriptive prompt가 지식을 다시 꺼낼 수 있는지 분리해야 한다.

### 2. 왜 지금 가치가 있는가
Cross-Prompt Inference 연구는 학습 prompt를 그대로 쓰는 matched condition이 다른 descriptive prompt보다 희귀 클래스 recall을 낮출 수 있다고 보고했다. 이는 OVD vocabulary expansion과 unseen-class adaptation에서도 “지식 소실” 진단을 다시 보게 한다.

### 3. 직접 근거와 Observation → Gap
- **저자 주장:** 다양한 VLM·6개 데이터셋에서 cross-prompt가 희귀 클래스 recall을 회복했지만 frequent-class trade-off가 있었다.
- **Mechanism 단서:** TuCo 분석은 cross-prompt가 finetuning-induced computation 의존을 줄이고 pretrained component 쪽으로 이동시킨다고 제안한다.
- **Gap:** prompt로 복구 가능한 suppression과 실제 representation forgetting을 분리하는 실용 진단법이 부족하다.
- **출처:** [Cross-Prompt Inference, arXiv:2610.21470](https://arxiv.org/abs/2610.21470)

### 4. 핵심 가설
희귀 클래스의 linear-probe separability는 유지되지만 matched prompt의 text-image margin만 줄어든다면, 실패는 forgetting보다 access-path suppression이다.

### 5. 최소 실험(MVP)
10:1과 50:1 불균형으로 CLIP 계열 모델을 parameter-efficient fine-tuning하고, 12개 의미 보존 prompt의 head/tail recall, embedding margin, frozen linear probe를 비교한다.

### 6. baseline과 dataset
- Dataset: CIFAR-100-LT 또는 iNaturalist 소형 subset
- Baseline: zero-shot, matched prompt, prompt ensemble, logit adjustment
- 사용자 관심 확장: OVD의 seen/unseen class split에 동일 진단 적용

### 7. 성공/실패 판정 metric
Tail recall, head-tail gap, prompt recovery rate, representation probe accuracy. **GO:** probe 성능은 2%p 이내 유지되면서 best cross-prompt가 matched tail recall을 ≥5%p 회복. **KILL:** recovery가 prompt quality score만으로 설명되거나 seed 3개 중 2개에서 재현되지 않음.

### 8. compute 난이도
**3/5.** 작은 backbone과 LoRA로 8GB에서 축소 실험 가능하다.

### 9. novelty 위험요인
prompt sensitivity 자체는 잘 알려져 있다. “forgetting vs accessibility”를 representation과 inference interaction으로 분해해야 신규성이 생긴다.

### 10. 4~8주 내 논문화 가능성
**상.** 분류에서 진단을 확립한 뒤 OVD로 확장하면 논문 서사가 명확하다.

### 11. negative result여도 얻는 결론
prompt 복구가 없으면 rare-class suppression이 실제 representation 손실임을 지지하고, inference-only 교정의 한계를 보여준다.

- **평가:** novelty **4/5** · feasibility **4/5** · compute efficiency **4/5** · publication potential **5/5**

## Q3. 시각적 “권위 스타일”을 제거하는 것이 VLM 사실성 개선인가, 단순 decision-threshold 이동인가?

### 1. 문제 정의
동일한 인용문을 장식적·권위적 레이아웃으로 보여줬을 때 오답을 VALID로 수용한다면, de-bias prompt의 효과가 진짜 discrimination 향상인지 INVALID 쪽 threshold 이동인지 구분해야 한다.

### 2. 왜 지금 가치가 있는가
Visual Sanad는 100개 영어 Qur'an 구절의 4개 factual state와 6개 visual condition으로 2,400장을 구성했다. 저자는 일부 open-weight VLM이 대부분을 VALID로 답하고, de-biased prompt가 false acceptance를 낮추면서 반대 방향 bias를 만들 수 있다고 보고했다.

### 3. 직접 근거와 Observation → Gap
- **확인 사실:** 논문은 source-check와 human audit를 거친 통제 렌더링을 사용한다.
- **저자 주장:** 시각 프레이밍만으로 false acceptance가 달라지며, prompt correction이 discrimination을 반드시 높이지 않는다.
- **Gap:** factual sensitivity와 response bias를 분리하는 multimodal calibration protocol이 부족하다.
- **출처:** [Visual Sanad, arXiv:2610.22009](https://arxiv.org/abs/2610.22009), [공식 저장소](https://github.com/NiazTahi/Visual-Sanad)

### 4. 핵심 가설
style counterfactual consistency와 balanced accuracy를 함께 최적화하면 false-VALID rate를 낮추면서 false-INVALID 증가를 억제할 수 있다.

### 5. 최소 실험(MVP)
검증 가능한 일반 지식 인용 50쌍을 plain/ornate/seal/official-template 네 스타일로 렌더링하고, base prompt·de-bias prompt·style-invariant self-consistency를 비교한다.

### 6. baseline과 dataset
- Dataset: Visual Sanad 공개 아티팩트 + 도메인 중립 citation subset
- Baseline: base prompt, “ignore visual style” prompt, majority threshold calibration
- 모델: 1개 open-weight VLM과 1개 API VLM

### 7. 성공/실패 판정 metric
Balanced accuracy, expected calibration error, false-VALID/false-INVALID rate, style flip rate. **GO:** style flip ≥30% 감소와 balanced accuracy ≥3%p 개선을 동시에 달성. **KILL:** false-VALID 개선이 false-INVALID 증가로 전부 상쇄.

### 8. compute 난이도
**1/5.** 추론 전용이며 8GB open-weight 소형 모델 또는 API로 가능하다.

### 9. novelty 위험요인
특정 종교 텍스트에만 머물면 범위가 좁다. 법률·의료·공공기관 양식으로 일반화해야 한다.

### 10. 4~8주 내 논문화 가능성
**중상.** benchmark 확장과 calibration 분석이 핵심 기여가 된다.

### 11. negative result여도 얻는 결론
style-invariant prompting이 threshold만 옮긴다면, prompt-based safety correction의 구조적 한계를 분명히 보여준다.

- **평가:** novelty **4/5** · feasibility **5/5** · compute efficiency **5/5** · publication potential **4/5**

## Q4. 문화적 시각 도메인의 default-label collapse는 representation 부족인가, label prior 과잉인가?

### 1. 문제 정의
Arabic calligraphy 6-way 분류에서 한 라벨이 33~63%를 차지하는 붕괴가 나타날 때, 원인이 시각 feature 분리 실패인지 prompt/label prior인지 진단한다.

### 2. 왜 지금 가치가 있는가
12개 VLM 평가에서 최고 numeric-prompt accuracy가 폐쇄형 60.9%, open-weight 47.2%였고, 8/12 모델이 Thuluth를 기본 라벨로 삼았다는 저자 보고는 모델 규모만으로 해결되지 않는 편향을 시사한다.

### 3. 직접 근거와 Observation → Gap
- **저자 주장:** GPT-4o는 실제 18.1%인 Thuluth를 52.9%로 예측했다. visual-cue prompt는 일부 모델을 10%p 넘게 움직였지만 다른 모델은 악화시켰다.
- **공식 아티팩트:** runner, scoring, prompt variants가 공개됐다.
- **Gap:** cultural-domain failure에서 representation·label semantics·prompt order의 기여가 분리되지 않았다.
- **출처:** [When Models Misread Ink, arXiv:2610.22018](https://arxiv.org/abs/2610.22018), [공식 저장소](https://github.com/NiazTahi/When-Models-Misread-Ink)

### 4. 핵심 가설
이미지 embedding의 class separability가 낮고 text prototype 간 margin도 작을 때 label-order perturbation이 default class를 결정한다. prototype을 비의미 토큰으로 치환하면 prior 성분을 분리할 수 있다.

### 5. 최소 실험(MVP)
이미지 300장을 사용해 label order shuffle, numeric label, nonsense token, expert visual cue 네 조건을 5 seed로 평가하고, frozen embedding k-NN과 VLM generation을 비교한다.

### 6. baseline과 dataset
- Dataset: 공식 1,195-image benchmark의 공개 가능 subset
- Baseline: majority class, CLIP zero-shot, frozen k-NN, VLM numeric prompt
- Ablation: 라벨 순서·설명 길이·Diwani foregrounding

### 7. 성공/실패 판정 metric
Macro-F1, label occupancy entropy, classwise recall, order-induced flip rate. **GO:** label token 치환으로 collapse가 ≥20% 감소하지만 k-NN separability는 유지. **KILL:** 모든 조건에서 embedding separability 자체가 낮아 prompt 개입 효과가 없음.

### 8. compute 난이도
**2/5.** frozen inference 중심이라 8GB 가능하다.

### 9. novelty 위험요인
단순 prompt engineering으로 보일 위험이 있다. 문화 도메인에서 representation과 prior를 인과적으로 분리해야 한다.

### 10. 4~8주 내 논문화 가능성
**중.** 다른 서예·문자 스타일 도메인까지 확장하면 강해진다.

### 11. negative result여도 얻는 결론
prompt 조작이 collapse를 못 고치면 데이터와 encoder representation 부족이 지배적이라는 실증 근거가 된다.

- **평가:** novelty **4/5** · feasibility **5/5** · compute efficiency **5/5** · publication potential **3/5**

## Q5. RL을 시작하기 전에 perception headroom을 측정하면 “학습 예산을 어디에 쓸지” 예측할 수 있는가?

### 1. 문제 정의
같은 benchmark 오류라도 어떤 모델은 지각이, 다른 모델은 추론이 병목이다. RL 전 oracle crop/description으로 recoverable error를 측정해 RL, perception adapter, data curation 중 최적 개입을 선택한다.

### 2. 왜 지금 가치가 있는가
PARA 연구는 4개 VLM·17개 benchmark에서 지각 headroom이 클수록 기존 RL gain이 작고, reasoning headroom이 클수록 gain이 커지는 관계를 보고했다.

### 3. 직접 근거와 Observation → Gap
- **저자 주장:** reward/token-level signal은 visual attention에 간접적으로만 작용한다.
- **저자 제안:** GRAD는 best rollout의 visual attention으로 weaker rollout을 직접 지도해 2개 scale·7개 benchmark에서 개선됐다.
- **Gap:** 학습 전의 싼 probe가 후속 학습법의 ROI를 예측하는지 검증되지 않았다.
- **출처:** [Perception or Reasoning?, arXiv:2610.21380](https://arxiv.org/abs/2610.21380)

### 4. 핵심 가설
소량 validation의 oracle-crop recovery rate가 RL gain보다 perception-targeted intervention gain과 더 강하게 상관한다.

### 5. 최소 실험(MVP)
두 VLM과 세 benchmark에서 원본/oracle crop/oracle text description/stronger reasoner 네 조건을 먼저 측정한다. 이후 각 benchmark에 LoRA-SFT 또는 소규모 RL과 visual adapter를 동일 GPU-hour로 적용한다.

### 6. baseline과 dataset
- Dataset: TextVQA, ChartQA, MathVista의 500-sample subset
- Baseline: 무진단 동일 RL 예산, random intervention allocation
- 비교 조건: GPU-hour와 train sample 수를 맞춘다.

### 7. 성공/실패 판정 metric
Intervention gain per GPU-hour, headroom–gain Spearman correlation, selection regret. **GO:** 진단 기반 선택이 random allocation 대비 regret을 ≥25% 줄임. **KILL:** 모델·benchmark가 바뀌면 correlation 부호가 불안정.

### 8. compute 난이도
**4/5.** 전체 RL은 무겁지만 LoRA와 subset으로 축소 가능하다. 8GB 단일 GPU에는 추론 진단까지만 적합하다.

### 9. novelty 위험요인
PARA의 단순 재현에 머물 수 있다. 핵심 신규성은 headroom을 실제 resource allocation policy로 연결하는 것이다.

### 10. 4~8주 내 논문화 가능성
**중.** 진단은 빠르지만 공정한 학습 예산 비교가 병목이다.

### 11. negative result여도 얻는 결론
headroom이 학습 gain을 예측하지 못하면 oracle diagnostic의 외적 타당성 한계와 최적화 동역학의 독립성을 보여준다.

- **평가:** novelty **5/5** · feasibility **3/5** · compute efficiency **2/5** · publication potential **5/5**

## Q6. Teacher completion reliability를 사전 측정해 OPD와 filtered SFT를 자동 선택할 수 있는가?

### 1. 문제 정의
on-policy distillation은 student trajectory에 맞는 supervision을 주지만, teacher가 그 상태에서 답을 완성하지 못하면 실패 행동까지 상속한다. teacher reliability로 학습법을 고르는 gate를 연구한다.

### 2. 왜 지금 가치가 있는가
최근 통제 비교에서 teacher completion 99%인 ChartQA는 10% 데이터 OPD가 full-data SFT와 1.4점 차이였지만, teacher가 22% 미완료한 Geometry3K에서는 OPD가 SFT보다 7.9점 낮았다고 저자가 보고했다.

### 3. 직접 근거와 Observation → Gap
- **저자 주장:** Geometry3K 격차 대부분은 incomplete response로 설명됐다.
- **Gap:** teacher reliability를 학습 전 probe로 사용하거나, 불안정 상태만 SFT/abstention으로 우회하는 hybrid policy가 부족하다.
- **출처:** [Do As I Do, Not As I Say, arXiv:2610.20989](https://arxiv.org/abs/2610.20989)

### 4. 핵심 가설
student-state teacher completion이 특정 임계값 아래인 sample만 filtered SFT로 보내는 hybrid가 순수 OPD와 순수 SFT보다 안정적이다.

### 5. 최소 실험(MVP)
Geometry3K subset에서 teacher completion을 100/90/80/70%로 synthetic masking하고 OPD, filtered SFT, reliability-gated hybrid를 동일 token budget으로 비교한다.

### 6. baseline과 dataset
- Dataset: Geometry3K와 ChartQA subset
- Baseline: OPD, filtered SFT, confidence threshold gate
- Ablation: completion-only, answer correctness-only, 둘의 결합

### 7. 성공/실패 판정 metric
Student accuracy, completion rate, token efficiency, worst-bin accuracy. **GO:** hybrid가 두 baseline 중 최선보다 ≥2%p 높고 completion 저하 없음. **KILL:** gate 이득이 synthetic masking에만 나타나고 자연 teacher failure에서 사라짐.

### 8. compute 난이도
**3/5.** 작은 student와 offline teacher cache를 쓰면 8GB에서도 축소 가능하다.

### 9. novelty 위험요인
mixture/gating 자체는 흔하다. on-policy state별 teacher failure를 사전 진단하고 학습법 선택으로 연결해야 한다.

### 10. 4~8주 내 논문화 가능성
**상.** 명확한 대조 실험과 실용적인 decision rule을 만들 수 있다.

### 11. negative result여도 얻는 결론
completion rate만으로 OPD 성패를 예측하지 못하면 teacher calibration·error type·trajectory coverage가 더 중요한 변수임을 밝힌다.

- **평가:** novelty **4/5** · feasibility **4/5** · compute efficiency **4/5** · publication potential **4/5**

## Q7. 강한 태풍의 과소추정은 label imbalance보다 “조건부 시각 불확실성” 문제인가?

### 1. 문제 정의
Digital Typhoon V3에서 강한 태풍 intensity가 체계적으로 과소추정되고 inverse-density weighting으로도 bias가 사라지지 않았다. 단순 빈도 보정과 영상 조건별 불확실성을 분리한다.

### 2. 왜 지금 가치가 있는가
V3는 거의 50년의 다분광 자료와 북·남반구 split을 제공한다. 저자는 현 설정에서 multi-channel이 pressure regression의 single-channel을 명확히 이기지 못했고, 강한 태풍 과소추정은 imbalance-aware weighting 후에도 남았다고 보고했다.

### 3. 직접 근거와 Observation → Gap
- **확인 사실:** V3는 2026-10-16 공개됐고 WP/AU 데이터를 포함하며 CC BY 4.0이다.
- **저자 주장:** ResNet-18·full resolution·Channel 1이 일반적으로 가장 좋은 single-channel pressure 결과를 냈다.
- **Gap:** rare-label density와 cloud morphology·sensor era·basin 같은 조건부 관측 난이도의 기여가 분리되지 않았다.
- **출처:** [Digital Typhoon V3, arXiv:2610.21654](https://arxiv.org/abs/2610.21654), [공식 저장소](https://github.com/kitamoto-lab/digital-typhoon)

### 4. 핵심 가설
강한 태풍 bias의 상당 부분은 label density보다 sensor-era·basin·cloud-structure별 heteroscedastic uncertainty에서 온다. group-conditional calibration이 global reweighting보다 tail bias를 줄인다.

### 5. 최소 실험(MVP)
ResNet-18 frozen feature 또는 경량 fine-tuning으로 pressure regression을 재현하고, plain MSE·inverse-density weighting·quantile loss·group-calibrated residual correction을 비교한다.

### 6. baseline과 dataset
- Dataset: Digital Typhoon V3의 공식 WP/AU split
- Baseline: single Channel 1, full resolution이 부담되면 공식 downsample protocol
- Group: basin, satellite era, intensity bin, cloud morphology proxy

### 7. 성공/실패 판정 metric
Overall RMSE, strongest-decile MAE, signed bias, calibration slope, cross-basin gap. **GO:** overall RMSE 악화 ≤2%에서 strongest-decile absolute bias ≥15% 감소. **KILL:** 개선이 특정 basin/era에만 나타나거나 split 변경 시 반전.

### 8. compute 난이도
**3/5.** 전체 full-resolution 학습은 무겁지만 frozen features와 subset으로 8GB MVP가 가능하다.

### 9. novelty 위험요인
일반적인 long-tail regression 재적용으로 보일 수 있다. 장기 센서 변화와 basin shift를 원인 분해에 포함해야 한다.

### 10. 4~8주 내 논문화 가능성
**중상.** 공개 데이터·명확한 safety relevance·diagnostic framing이 강점이다.

### 11. negative result여도 얻는 결론
조건부 calibration도 실패하면 영상만으로 강도 tail을 추정하는 식별 한계 또는 best-track label noise 가능성을 정량화할 수 있다.

- **평가:** novelty **4/5** · feasibility **4/5** · compute efficiency **4/5** · publication potential **4/5**
