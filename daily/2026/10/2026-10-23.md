## 3. CV 핵심

### 3.1 ALPS: Visual State Encoders for World Models

- **사실:** 2026-10-21 arXiv v1. ViT-B/16을 정지 이미지·텍스트로 처음부터 학습하고, 언어 정렬·픽셀 복원·dense correspondence 뒤 cross-view self-distillation을 적용한다.
- **저자 결과:** 고정 토큰 기반 LIBERO 평균 성공률은 자체 text tower 사용 시 85.5%다. 세 번의 평가와 task당 50 rollout 평균이다. BERT 사용 시 83.4%였고 SigLIP2는 자체 tower에서 84.8%였다.
- **상태·계획:** state-probe 상대 오차 0.829로 ViT-B 중 최저이며 3.5배 큰 V-JEPA2-L과 같았다. PushT/Wall 성공률은 90%/92%, Granular Chamfer는 Stage 1의 0.324에서 0.176으로 줄었다.
- **공개:** PyTorch inference, JAX/PyTorch training code, 가중치와 8개 LIBERO policy를 공개했다.
- **제약:** 상호작용 비디오 없이도 상태 표현이 생겼다는 주장은 강하지만, 정책·planner head와 데이터 규모의 영향은 완전히 분리되지 않았다. LIBERO 밖 실제 로봇 전이는 미확인이다.
- **최소 실험:** 해무 장면 3개 visibility bin에서 ALPS·DINOv3·SigLIP2의 frozen probe를 동일 10k step으로 학습한다. `GO`: ALPS가 모든 bin에서 위치 오차를 10% 이상 줄이고 깨끗한 조건 손실이 3%p 이하. `KILL`: 개선이 한 bin에만 있거나 decoder capacity를 늘리면 사라짐.
- **출처:** [arXiv](https://arxiv.org/abs/2610.30120), [프로젝트](https://ucsc-vlaa.github.io/ALPS/), [코드](https://github.com/UCSC-VLAA/ALPS)

### 3.2 VoxProg: 3D Spatial Reasoning through Voxel Programming

- **사실:** 언어 지시를 local voxel view 위 evidence program과 6-DoF pose program으로 변환한다. VoxProg-Bench는 71개 배치 과제다.
- **저자 결과:** IA Rank 83.10, Physical Validity 95.8%로 Direct Mesh 48.59/87.3%, GenSim2-kPAM 42.72/77.5%, GenManip 25.59/73.2%를 앞섰다. 모든 방법은 GPT-5.6-Sol을 동일 설정으로 사용했다.
- **절제:** Direct Mesh→Mesh Evidence에서 IA 26.76→56.34, voxel view 추가 시 66.90으로 증가했다. Physical Validity는 87.3→95.8→95.8%였다.
- **외부 과제:** RoboCasa 19개에서 IA 87.72, validity 94.7%; Open6DOR v2 13개에서 IA 61.54, validity 92.3%를 보고했다.
- **제약:** 최종 상태 배치가 중심이며 로봇 접근 경로·접촉력·perception noise를 포함한 실행 성공률은 아니다. IA는 비교 방법 pool 안의 순위형 지표다.
- **최소 실험:** mesh pose noise 0/1/3cm와 voxel 해상도 3단계를 교차한다. `GO`: 1cm 잡음에서도 collision-free가 85% 이상. `KILL`: 성능이 IA만 유지되고 실제 motion planning 성공이 Direct Mesh와 유사.
- **출처:** [arXiv](https://arxiv.org/abs/2610.30127), [프로젝트](https://voxprog.github.io/)

### 3.3 Plausible but Unimplantable

- **사실:** 공개 shape-completion pretrained model 3종을 210개 합성 결손과 29개 실제 craniectomy, 총 239건에 zero-shot 적용했다.
- **저자 결과:** 세 모델 모두 implantable 결과가 0/239였고 2,868개 model-arm-skull 조합 중 1mm 기준 collision-free가 하나도 없었다. task-specific volumetric 기준선은 238/239에서 implantable이었다.
- **중요한 음성 결과:** 실제 29건에서 MGPC는 no-op보다 24/29에서 나았지만 충돌 때문에 임상 배치 가능성은 0이었다. 모양 점수 향상과 안전성은 분리됐다.
- **표현 한계:** 6,144 point skull의 평균 최근접 간격은 2.56mm로, 3mm plate의 양면을 안정적으로 분리해 두께를 표현하기 어렵다고 분석했다.
- **추론:** foundation model audit은 Chamfer/시각 plausibility보다 task-specific feasibility constraint를 먼저 두어야 한다.
- **최소 실험:** point completion 뒤 signed-distance collision projection을 붙이고 추가 재료량·1mm clearance·surface thickness를 동시에 측정한다. `GO`: 200개 이상에서 implantable 90% 이상, no-op 대비 재료량 양수. `KILL`: 형상 유사도만 좋아지고 clearance가 0인 사례가 5% 초과.
- **출처:** [arXiv](https://arxiv.org/abs/2610.30035)

### 3.4 DewHand

- **사실:** egocentric video에서 손과 카메라를 metric world coordinate로 공동 예측하며, occlusion을 conditional flow matching으로 다룬다. 두 번의 sampling step을 사용한다.
- **저자 결과:** rigid-aligned world-space error는 StableHand 대비 HOT3D 32.9→28.4mm, ARCTIC 76.2→36.2mm다. HOT3D clip의 약 2/3에서 camera scale을 10% 이내로 복원했다.
- **zero-shot:** HoloAssist·H2O·TACO에서 가장 낮은 WA-MPJPE를 보고했다.
- **효율:** 150-frame HOT3D clip, 단일 A100에서 12.0초이며 비교 SLAM pipeline 31.4~44.9초보다 2.6~3.7배 빠르다. 다만 model loading·JPEG decode는 제외했다.
- **제약:** hand detector와 VGGT-Ω feature에 의존하고, 실제 online latency와 긴 영상 drift는 별도 검증이 필요하다.
- **최소 실험:** 동일 clip에서 hand observation을 0/25/50% 가리고 regression과 2-step flow의 error·jitter·runtime을 비교한다. `GO`: 50% 가림에서 WA-MPJPE 15% 이상 감소, runtime 15초 이하. `KILL`: 여러 sample 평균이 없으면 결과가 불안정하거나 scale error가 20% 초과.
- **출처:** [arXiv](https://arxiv.org/abs/2610.29936)

### 3.5 CausalAlign

- **사실:** Wan2.2 denoising layer에서 ego-motion decodability와 causal intervention을 함께 측정한 뒤, 연속 프레임의 변화만 담는 128D delta token에 representation을 정렬한다.
- **저자 결과:** Wan2.2 대비 reprojection 8.4→6.5px, epipolar 2.9→2.1px, smoothness 0.71→0.88, jerk 0.182→0.151. 7개 지표 모두 base보다 개선됐고 6개에서 비교 최고였다.
- **embodied 전이:** Fast-WAM의 RoboCasa365 평균 성공률은 43.5→54.2%, Atomic Seen은 59.1→78.1%였다. Composite Unseen은 33.2→40.6%였다.
- **절제:** 128D partition은 ego-motion 64D, geometry 40D, visual 24D다. unpartitioned matched-width보다 6개 readout 지표에서 좋았다.
- **제약:** 생성기·3D foundation model·WAM이 결합된 결과여서 어느 개선이 정책 성공에 필요한지 분리하기 어렵다. 다른 camera motion 분포 전이는 미확인이다.
- **최소 실험:** alignment target을 motion/geometry/visual만 각각 켜는 2×2×2 절제로 generator metric과 policy success를 동시에 측정한다. `GO`: motion region만으로 unseen composite가 5%p 이상 향상. `KILL`: visual quality 개선 없이 policy도 움직이지 않거나 다른 camera path에서 역전.
- **출처:** [arXiv](https://arxiv.org/abs/2610.29915)

## 4. VLM/Video 핵심

### 4.1 CADRE: Rethinking Video Autoencoders for Interactive World Models

- **사실:** 7개 spatio-temporal compression의 causal diffusion representation autoencoder와 동일 world model을 manipulation·navigation 각 2개 환경에서 비교했다.
- **평가:** 환경당 2,048 held-out sample, 40 real frame 뒤 96 frame을 생성하고 마지막 16 frame을 FID/FVD/PSNR/LPIPS와 ARR(action recoverability ratio)로 측정했다.
- **저자 결과:** CADRE는 48개 비교 중 42개에서 MIRA·Wan2.2·Cosmos·LTX-2보다 같거나 빠르면서 지표가 2% 넘게 좋았다. 1-step diffusion decoder는 MIRA보다 FVD를 1.4~2.5배 낮췄다.
- **운영 신호:** 한 H100에서 20fps, 230ms 미만 반응을 보고한다. 고정 카메라 manipulation은 temporal compression, 이동 카메라 navigation은 spatial compression이 유리했다.
- **제약:** 20fps/latency는 특정 H100 pipeline 조건이며 decoder 외 전체 serving overhead·동시 요청·장기 안정성은 별도다. 비교 모델의 pretraining 규모도 다르다.
- **최소 실험:** 해무 CCTV(고정)와 선박 camera(이동)에 동일 tokenizer를 적용해 temporal/spatial compression grid를 측정한다. `GO`: 고정 카메라에서는 4× temporal이 FVD 열화 10% 이내, 이동 카메라에서는 1× temporal+spatial compression이 ARR 0.8 이상. `KILL`: end-to-end p95 latency가 230ms를 넘거나 압축 축별 우위가 재현되지 않음.
- **출처:** [arXiv](https://arxiv.org/abs/2610.30129), [공식 공개 페이지](https://kyutai.org/blog/2026-10-21-cadre/)

### 4.2 ProactEgoMem

- **사실:** Daily 300 clip/1,000 QA, Science 100 clip/500 QA로 Information Capture·State Tracking·Location Tracking을 평가한다. Notification과 start-to-stop Intervention을 분리한다.
- **저자 결과:** 13개 baseline 중 최고 Notification F1은 19.0%(Qwen3.6-27B, ST), 최고 Intervention mIoU는 17.2%(Gemma4-31B, ST), 최고 strict Start@0.2는 28.8%(VideoLLaMA3-7B, LT)였다.
- **진단:** general VLM은 coverage가, streaming model은 timing이 상대적으로 좋았지만 둘을 동시에 만족한 모델은 없었다.
- **공개:** 공식 GitHub·Hugging Face·leaderboard를 연결한다.
- **제약:** synthetic/curated opportunity 정의와 LLM judge가 실제 wearable user utility를 완전히 대변하지 않는다. privacy·배터리·실시간 메모리 비용도 포함되지 않는다.
- **최소 실험:** 30분 해양 관측 stream에서 안개 시작/종료·선박 진입/이탈 event 50건을 주석하고 offline VLM과 streaming trigger를 결합한다. `GO`: event F1 0.6 이상, median start error 3초 이하. `KILL`: recall을 올릴 때 시간당 false notification이 2회를 초과.
- **출처:** [arXiv](https://arxiv.org/abs/2610.30089), [코드](https://github.com/mayhugotong/ProactEgoMem)

### 4.3 Asking a Multimodal LLM Whether Someone Fell

- **사실:** Gemini 3.8 Flash를 temperature 0으로 32×24 열화상 공개 데이터의 438 staged fall·563 non-fall window, 그리고 160×120+audio 가정환경 76시간에 평가했다.
- **저자 결과:** held-out subject 민감도 69%, 499개 non-fall에서 false positive 0. 가정환경에서는 395 ordinary clip에서 false call 0, 보이는 staged fall 9개 중 4개 탐지였다.
- **prompt 절제:** “화면 밖으로 나가면 낙상이 아니다” 문장을 제거하면 held-out 민감도 69→83%, 가정환경 4/9→9/9가 됐지만 deliberate lie-down을 낙상으로 불렀다.
- **강건성:** 8×6에서 민감도 34%, 동일 요청 불일치 4%. conventional detector 두 종은 실험실 fall을 거의 다 찾았으나 집에서는 하루 14.2·23.9회 false alarm을 냈다.
- **제약:** 단일 가정환경·소수 staged fall·특정 proprietary 모델이라 일반화가 제한적이다. zero false call을 안전 보장으로 해석하면 안 된다.
- **최소 실험:** prompt 문장, 해상도, audio 유무를 factorial design으로 반복 5회씩 평가한다. `GO`: subject별 bootstrap 95% 하한 민감도 80%, false alarm/day 상한 1 이하. `KILL`: prompt 한 문장에 민감도가 10%p 이상 흔들리거나 반복 불일치 2% 초과.
- **출처:** [arXiv](https://arxiv.org/abs/2610.29913)

## 5. LLM/Agent/System 변화

### 5.1 Agent Behavior Maps

- **사실:** shared reference trajectory의 centered action log-likelihood로 LLM-harness 조합을 좌표화한다. 새 target agent의 environment rollout 없이 행동 유사성을 추정한다.
- **저자 결과:** 8개 cross-scored model에서 step distance와 실제 trajectory KL의 Pearson/Spearman 상관은 0.90/0.95, trajectory version은 0.86/0.94였다. 100 LLM·4환경, ALFWorld reference 500개를 사용했다.
- **의미:** 성공률이 비슷해도 tool 순서·반복·경로가 다른 agent를 분리할 수 있다.
- **제약:** log-likelihood 접근이 필요하고 reference trajectory가 다루지 않는 상태에서는 좌표가 행동을 보장하지 않는다. trajectory version의 RMSE는 step version보다 한 자릿수 규모 더 컸다.
- **최소 실험:** 같은 coding task 100개에서 기존 agent와 새 harness의 map distance를 구하고 실제 tool-sequence KL·성공률 변화를 비교한다. `GO`: Spearman 0.8 이상이면서 rollout 비용 70% 절감. `KILL`: out-of-domain task에서 상관 0.5 미만.
- **출처:** [arXiv](https://arxiv.org/abs/2610.30014)

### 5.2 UserSWE

- **사실:** 20,859개 개발 session으로 persona transition을 보정하고, 42개 repo의 72 task에서 11개 agent를 1~8 turn으로 평가한다. 매 turn test를 실행하고 서로 다른 model family의 judge/reviewer가 증거를 gate한다.
- **저자 결과:** 1-turn 최고는 Claude Fable 5.1 31.9%, 8-turn 최고는 GPT-6-Astra 81.9%. 길이 할인 LDPR 최고는 Claude Opus 5 0.640이었다. 95% bootstrap interval은 겹침이 크다.
- **평가 신호:** 상위 4개 agent는 8개 budget에서 6개 순서를 만들었다. static하고 명확·정확한 persona가 5 turn 유지되는 실제 session은 전체의 0.72%였다.
- **제약:** persona calibration data가 내부 상용 assistant에서 왔고 benchmark·scaffold·judge model 영향이 섞여 있다. release는 “will be released” 상태라 현재 즉시 재현 가능하다고 보지 않았다.
- **최소 실험:** 같은 30개 issue를 complete prompt와 5-turn progressive disclosure로 비교한다. `GO`: 최종 해결률 차이와 turn-cost curve가 agent 선택을 바꿈. `KILL`: task 난이도 bootstrap 후 순위 차이가 신뢰구간 안에서 사라짐.
- **출처:** [arXiv](https://arxiv.org/abs/2610.29822)

## 6. 모델/Repo/Dataset release

### BatchBench

- **구성:** JUMP-CP 13개 source 중 9개 public, 4개 private test source. 2,000 compound, 5-channel Cell Painting image를 분류한다.
- **기준선:** 3 seed 평균에서 no-adaptation ResNet18 전체 0.175, AdaBN 0.244, TENT 0.249, ARM-BN 0.260. 하지만 REST는 최고 0.004, TARGET은 최고 0.035였다.
- **해석:** test-time adaptation은 강한 phenotype의 POSCON을 주로 개선했으며 희귀 compound의 배치 이동은 거의 해결하지 못했다.
- **공개:** container submission, 개발용 200×200 subset, baseline code와 Hugging Face leaderboard를 제공한다.
- **출처:** [arXiv](https://arxiv.org/abs/2610.30104), [baseline 코드](https://github.com/ml-jku/batchbench-baselines/)

오늘 확인된 주요 공개물은 ALPS 코드·가중치·정책, ProactEgoMem 코드·데이터·leaderboard, CADRE 모델·demo, BatchBench baseline·leaderboard다. VoxProg와 DewHand는 공식 프로젝트는 있으나 이번 실행에서 독립 설치 재현까지 수행하지 않았다.

## 7. 오늘의 중요한 Finding 3개

### Finding 1 — 좋은 latent는 압축률보다 ‘무엇을 보존하는가’로 평가해야 한다

- **확인된 사실:** ALPS는 같은 frozen-token protocol에서 state·language·pixel interface를 함께 유지했고, CADRE는 동일 world model에서도 temporal/spatial compression 위치에 따라 ARR와 latency가 달라졌다.
- **추론:** 상태 encoder와 autoencoder를 독립 부품으로 보고 PSNR만 최적화하면 action-relevant motion을 잃을 수 있다.
- **검증:** latent reconstruction, future-state probe, action recoverability를 하나의 Pareto plot에 둔다.

### Finding 2 — 평균 점수는 배치 실패를 숨긴다

- **확인된 사실:** BatchBench의 최고 전체 정확도는 0.260이지만 REST는 0.004였고, 두개골 completion은 시각적으로 plausible해도 implantable 0/239였다.
- **추론:** 배포에서 중요한 rare subset·feasibility constraint를 전체 평균 뒤에 두면 실제 사용 불가능한 모델이 상위에 오른다.
- **검증:** 최악 subgroup와 hard constraint를 primary metric으로 승격한다.

### Finding 3 — 멀티모달 agent의 다음 병목은 시간적 개입이다

- **확인된 사실:** ProactEgoMem의 최고 notification F1 19.0%, intervention mIoU 17.2%이며, 낙상 VLM은 한 문장 prompt 절제로 민감도가 14%p 움직였다.
- **추론:** 장면 이해 성능이 높아도 start/stop policy와 prompt rule이 취약하면 실제 알림 시스템은 실패한다.
- **검증:** 동일 backbone에 semantic classifier와 temporal trigger를 분리하고 각 error budget을 보고한다.

## 10. 1위 논문 mini-review — ALPS

ALPS의 핵심 문제 설정은 world model용 visual encoder가 단순한 image embedding이 아니라 **상태를 읽고, 언어 지시와 맞추고, 다시 픽셀로 검사할 수 있는 공통 인터페이스**여야 한다는 것이다. 기존 self-supervised encoder는 상태·공간에는 강하지만 text tower가 없고, image-text encoder는 언어에는 강하지만 픽셀·세부 상태가 약하며, reconstruction encoder는 의미 정렬이 약하다.

방법은 두 단계다. Stage 1에서 ViT-B/16 patch token 하나에 contrastive alignment, captioning, reconstruction, dense correspondence를 함께 건다. Stage 2에서는 변형 crop의 student가 clean view의 frozen teacher patch를 geometry query로 맞추는 cross-view self-distillation을 한다. 비디오나 action supervision 없이도 상태 정보를 강화한다는 점이 흥미롭다.

근거는 비교적 잘 설계되어 있다. 15개 public encoder를 공통 probe·decoder·policy protocol에서 고정 비교한다. Stage 2는 state-probe error를 17% 줄이면서 image-text retrieval 변화를 0.5 point 이내로 유지했다. 같은 refinement를 CLIP·SigLIP2에 적용하면 state는 좋아져도 언어 지표가 4~12 point 하락했다. 따라서 ‘refinement 자체’보다 처음부터 다목적 토큰을 만든 것이 language retention에 중요하다는 저자 주장이 생긴다.

다만 정책 성공률은 encoder만의 순수 효과가 아니다. 자체 text tower, projection, downstream policy recipe가 결합되어 있으며 실제 로봇과 낮은 가시성 domain은 검증되지 않았다. 픽셀 복원도 공통 decoder를 별도 학습한 결과라 토큰에 정보가 있다는 증거이지, world model이 그 정보를 실제 의사결정에 쓴다는 인과 증거는 아니다.

가장 작은 재현은 전체 pretraining을 다시 하는 것이 아니다. 공개 가중치를 고정하고 해무 영상에서 세 가지 probe를 동일 예산으로 학습한다: (1) 객체/수평선 위치, (2) 1~3초 미래 visibility, (3) fog density와 무관한 instance consistency. DINOv3·SigLIP2와 비교해 세 축 모두 좋아질 때만 해양 환경에 유효한 state encoder라고 판단한다.

## 11. 후속 연구 씨앗

### 씨앗 A — Camera-Regime-Aware Maritime Tokenizer

- **진단:** 해안 CCTV는 고정 카메라, 선박·드론은 이동 카메라인데 동일 video compression을 쓰면 한쪽에서 motion을 잃을 수 있다.
- **가설:** 고정 카메라는 temporal compression, 이동 카메라는 spatial compression을 높이는 적응형 tokenizer가 같은 latency에서 더 높은 ARR를 낸다.
- **최소 실험:** 100개 고정/100개 이동 clip에 1×/2×/4× temporal, 8×/16×/32× spatial grid를 적용한다.
- **GO/KILL:** p95 230ms 이하에서 fog event F1·camera-motion error Pareto가 고정 tokenizer보다 10% 이상 개선되면 GO; 한 regime에서 5% 이상 악화되면 KILL.

### 씨앗 B — Fog BatchBench

- **진단:** 항만·센서·계절별 영상은 biomedical source와 유사한 강한 batch effect를 가진다.
- **가설:** plate-wise AdaBN류 적응은 큰 항만에서는 좋아져도 희귀 농무·야간 subgroup에는 거의 도움이 없을 것이다.
- **최소 실험:** 항만 4곳 중 1곳을 held-out source로 순환하고, visibility·야간·sensor subgroup 정확도를 따로 측정한다.
- **GO/KILL:** 최악 subgroup 10%p 개선과 전체 성능 하락 2%p 이하이면 GO; 평균만 좋아지고 농무 recall이 그대로면 KILL.

### 씨앗 C — Proactive Fog Event Memory

- **진단:** 현재 시스템은 clip 단위 분류는 가능해도 안개가 언제 시작·강화·해제됐는지 기억 수명주기를 다루지 못한다.
- **가설:** semantic detector와 start/stop controller를 분리하면 알림 F1과 event mIoU를 동시에 높일 수 있다.
- **최소 실험:** 10시간 stream에 event 100개를 주석하고 notification·intervention 두 수준을 평가한다.
- **GO/KILL:** F1 0.6, mIoU 0.5, 시간당 false alert 1회 이하이면 GO; 어느 하나라도 20% 상대 하락하면 controller 설계를 재검토한다.

### 씨앗 D — Feasibility-First 3D Completion

- **진단:** point-cloud similarity가 높아도 충돌·두께·지지 조건을 위반하면 출력은 사용할 수 없다.
- **가설:** SDF clearance와 minimum-thickness constraint를 생성 중 hard projection하면 시각 점수 감소를 작게 유지하면서 배치 가능성을 크게 높인다.
- **최소 실험:** VoxProg 배치와 cranial completion의 두 domain에서 동일 constraint layer를 시험한다.
- **GO/KILL:** collision-free 95% 이상, task score 하락 5% 이하이면 GO; constraint 후 no-op보다 유효 재료·배치가 줄면 KILL.

## 12. 오늘 안 읽어도 되는 것

- 단일 FID·PSNR만으로 interactive world model의 우열을 말하고 latency·ARR를 보고하지 않는 논문.
- 공개 코드·데이터가 없고, 강한 평균 점수만 있으며 subgroup·seed·실패 사례가 없는 leaderboard 홍보.
- prompt 한두 문장에 민감한 안전 시스템을 반복 실행·subject split 없이 배포 가능하다고 주장하는 결과.
- 3D placement의 final-state render만 보여주고 collision·support·path feasibility를 측정하지 않는 demo.
- 성공률 하나로 coding/GUI agent를 비교하면서 turn budget·tool sequence·judge evidence를 공개하지 않는 순위표.
