6. **V-Thinker**는 MIT code와 MIT-tagged 8B BF16 safetensors model, 세 dataset/benchmark 링크를 공개했다. 다만 exact GPU/VRAM, immutable evaluator revision, data license/manifest는 아직 별도 검증이 필요하다.
7. 이번 실행에서는 설치·checkpoint download·GPU inference를 하지 않았다. 점수는 운영 우선순위 판단이며 실측 성능이 아니다.

## 1. Supervision 0.31.6 — 결과 표현·tracking 회귀 수정

- **사실:** `0.31.6`은 empty video frame의 `KeyPoints` filter `TypeError`, Grounding DINO/RF-DETR segmentation 결과 로딩, OWLv2 class-name 처리, grayscale/BGRA/palette image annotation 및 integer box/mask-shift 문제를 수정한 patch다.
- **사실:** release는 unconfirmed track를 평균 box 하나로 합치지 않도록 `DetectionsSmoother` 동작도 바꾼다.
- **주의:** release가 “drop-in upgrade”라고 쓰지만 stored output 비교와 일부 migration point 검토를 권한다. 이는 과거 output compatibility가 자동으로 보장된다는 뜻이 아니다.
- **license / weights / install:** Supervision은 코드 라이브러리이며 새 pretrained weight는 없다. Python package install surface와 CV model adapter가 핵심이며 GPU/VRAM은 adapter/model별로 달라 원문만으로 고정할 수 없다.
- **진단 → 가설 → 최소 실험:** grayscale, empty frame, unconfirmed track가 섞인 고정 10-frame fixture에서 old/new version을 비교한다. detection tensor, track ID, rendered image, exception 여부를 따로 기록한다.
- **GO/KILL:** empty-frame exception이 사라지고 confirmed track output이 허용 오차 내면 GO. stored output/track identity가 바뀌는데 migration rationale를 확인하지 못하면 KILL·보류.
- **평가:** 실험 가치 4/5, 재현성 4/5, 신규성 3/5, 실용성 5/5.

## 2. NVIDIA ModelOpt 0.47.1 — NVFP4/Triton 호환성 fix

- **사실:** `0.47.1`은 Triton 3.9 및 PyTorch 26.11 container 조합에서 compute capability 8.9 이상 GPU의 `NVFP4_DEFAULT_CFG` 등 NVFP4 fake quantization이 `NotImplementedError`로 실패하던 문제를 고쳤다.
- **사실:** 공식 release에는 package assets가 있으나 이번 확인에서 새 CV checkpoint·dataset·benchmark result는 확인하지 못했다.
- **license / install surface:** ModelOpt repository는 Apache-2.0 계열 프로젝트다. PyTorch/Triton/CUDA와 target GPU capability가 실행 조건이며, native/GPU stack을 고정하지 않으면 결과 비교는 not strictly apples-to-apples다.
- **진단 → 가설 → 최소 실험:** release tag와 고정된 PyTorch/Triton container에서 1개 작은 tensor의 NVFP4 calibration path만 실행해 exception 여부와 quantizer config serialization을 점검한다. 전체 detector quantization 또는 latency benchmark는 하지 않는다.
- **GO/KILL:** target GPU에서 fake-quant path가 complete되면 GO. GPU capability/driver/container가 다르거나 shape·accuracy regression이 확인되면 KILL.
- **평가:** 실험 가치 4/5, 재현성 3/5, 신규성 3/5, 실용성 3/5.

## 3. Transformers 5.22.2 — VLM dependency security/distributed pin

- **사실:** `v5.22.2`는 Jinja sandbox hardening과 NCCL에서만 `device_id`를 설정하는 distributed fix를 포함한다.
- **해석:** 이는 CV/VLM model architecture, new weight, benchmark uplift가 아니라 production/research dependency update다. Grounding DINO 등 Transformers-backed model을 쓰더라도 release note만으로 output parity를 가정할 수 없다.
- **license / weights / install surface:** Transformers는 Apache-2.0 코드 package이고, 이 tag 자체는 model weight를 배포하지 않는다. model별 processor, PyTorch/CUDA, remote code 옵션이 별도 surface다.
- **진단 → 가설 → 최소 실험:** isolated environment에서 기존 VLM smoke input 하나를 같은 model revision·processor revision으로 실행해 import, tokenizer/processor load, CPU single forward까지 확인한다. distributed launch·remote code는 이 smoke test에서 제외한다.
- **GO/KILL:** non-distributed baseline output schema와 load path가 유지되면 GO. model/processor가 revision drift를 만들거나 remote-code policy가 달라지면 KILL·pin 유지.
- **평가:** 실험 가치 3/5, 재현성 4/5, 신규성 2/5, 실용성 4/5.

## 4. Ultralytics 8.4.208 — serving default가 바뀐 release

- **사실:** `v8.4.208`은 prediction/tracking에서 미지정 NMS IoU default를 `0.7`에서 `0.5`로 바꾸고, validation default는 `0.7`로 유지한다.
- **사실:** YOLOE visual prompt의 default confidence는 `0.05`가 되며, release는 TensorRT 11 FP16 NMS-free export가 조건부로 최대 3% 빨라질 수 있다고 쓴다. 새 model architecture는 도입하지 않는다.
- **license / weights / install surface:** repository는 AGPL-3.0이다. 새 pretrained weight가 release에 포함된 것은 확인하지 못했다. TensorRT 성능 주장은 GPU, engine, shape, batch, precision, warm-up이 같지 않으면 not strictly apples-to-apples다.
- **진단 → 가설 → 최소 실험:** 동일 checkpoint·image set에서 old/new package를 비교하고 `iou`를 명시하지 않은 predict/tracking과 validation을 분리 저장한다. box count, duplicate box, track ID, explicit `iou=0.7` parity를 확인한다.
- **GO/KILL:** explicit config에서 output parity가 유지되면 GO. default-only 변화가 production count/track regression을 만들면 KILL 및 explicit config pin.
- **평가:** 실험 가치 4/5, 재현성 4/5, 신규성 3/5, 실용성 4/5.

## 5. V-Thinker — code·8B weight·interactive dataset surface

- **사실:** V-Thinker repository는 MIT license, `pip install -e .` quick start, training/evaluation script와 V-Interaction-400K·V-Perception-40K·VTBench 링크를 제시한다.
- **사실:** [official model card](https://huggingface.co/We-Math/V-Thinker)는 MIT, safetensors, Qwen2.5-VL family, BF16, 8B parameters로 표기한다. hosted inference provider는 없다고 표시한다.
- **저자 주장:** model card/repository는 interactive image thinking과 VTBench의 상대 성능을 주장한다. 독립 재현 또는 checkpoint checksum은 이번 실행에서 확인하지 못했다.
- **의존성 / hardware:** repository는 Python 3.10 conda environment와 vLLM evaluation update를 안내한다. exact GPU/VRAM, model file hash, immutable evaluator revision은 공식 페이지에서 확인되지 않아 수치를 만들지 않는다.
- **진단 → 가설 → 최소 실험:** clone 후 학습·weight download 없이 requirements와 evaluator import graph, dataset path contract만 검사한다. 이후에야 fixed model revision으로 VTBench record 1개를 processor→input build 단계까지 dry-run한다.
- **GO/KILL:** model/dataset/evaluator revision 및 license가 manifest에 고정되면 GO. code license를 dataset license로 오인하거나 image/code artifacts를 검증 없이 실행해야 하면 KILL·보류.
- **평가:** 실험 가치 4/5, 재현성 2/5, 신규성 4/5, 실용성 3/5.

2. **Ultralytics 8.4.208** — 이미 YOLO serving/tracking을 쓰는 경우에만 config-pinned A/B로 검토한다. 라이선스 검토가 전제다.
3. **V-Thinker** — image-interaction reasoning 관심이 있고 evaluator/data manifest를 먼저 감사할 여력이 있을 때만 제한적으로 clone한다.

## 운영 체크리스트

- release tag/commit, Python package, processor/model revision을 한 manifest에 고정한다.
- output·latency·accuracy를 한 측정으로 섞지 않는다.
- native/GPU package는 container, CUDA/Triton/TensorRT, GPU capability까지 기록한다.
- code license, model license, dataset license를 독립적으로 확인한다.
- 공개 score는 저자 주장으로 보관하고 독립 재현 전 baseline으로 승격하지 않는다.
