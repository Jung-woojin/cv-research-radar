## 1. CellTrack-Bench — 현미경 세포 추적을 VLM의 원자적 연결 결정으로 평가

### 확인된 사실

- 15개 표준 세포 추적 데이터셋, 4개 영상 modality, 1,537개 문제, 9,041개 cell-linking 결정으로 구성된다.
- 서로 다른 알고리즘 추적기가 공통으로 실패한 사례를 이용해 hard subset을 만들었다.
- 9개 폐쇄형 frontier 모델과 13개 open-weight 모델을 평가했으며, 코드·저장된 모델 출력·원천 데이터로부터 benchmark를 재생성하는 pipeline이 공개돼 있다.
- hard-test에서 renderer, prompt, tool implementation, parser, token budget, decoding configuration을 동결한 `c1` harness를 사용한다.
- 이 조건에서 GPT-5.6(sol)은 Link F1 0.811, Repair F1 0.815, Inspect F1 0.631, 세 점수 평균 0.752를 기록했다. Claude Fable 5는 평균 0.758로 더 높지만 Link F1은 0.790이며, 세부 과제별 우열이 다르다.
- nearest-centroid graph의 graph-edit score `LNK_sub`는 0.493이고, GPT-5.6(sol)은 0.767로 +0.274의 margin을 보였다.

### 저자 주장

저자들은 일반 VLM이 전문적인 생물영상 추적 작업에서 어느 정도 유용한지, 그리고 단순 근접성 shortcut을 넘어 graph repair와 inspection에 기여하는지를 benchmark가 분리해 보여준다고 주장한다.

### 해석과 비교 조건

- 핵심 이동은 “추적 결과 전체를 한 점수로 비교”하는 방식에서 **link·repair·inspect와 graph utility를 분리**한 것이다.
- 평균 점수만 보면 Claude Fable 5가 0.758, GPT-5.6(sol)이 0.752지만, Link/Repair/Inspect의 가중 목적이 다르면 순위가 바뀐다. 따라서 단일 우승 모델을 선언하기보다 사용 시나리오별 Pareto 비교가 맞다.
- 모델 비교가 의미 있으려면 반드시 동일한 frozen c1 harness, 동일 test split, 동일 token budget과 decoding 조건을 사용해야 한다.
- 코드가 공개됐다는 사실과 모든 외부 API 모델을 장기간 동일 버전으로 재현할 수 있다는 것은 별개다. API 모델 drift는 추후 leaderboard 안정성 위험이다.

### 최소 재현 실험

공개 저장 출력에서 동일 hard subset 100문제를 뽑아 Link F1, Inspect F1, `LNK_sub`를 재계산한다. 이후 nearest-centroid graph와 한 개 open-weight VLM을 동일 c1 harness로 실행해 모델 성능이 단순 공간 근접성보다 얼마나 남는지 확인한다. 합격 기준은 공개 값과 각 지표 절대 오차 0.01 이내다.

- 논문: https://arxiv.org/abs/2610.31566
- 코드·산출물: https://github.com/royerlab/celltrack-bench

## 2. GigaBench — gigapixel 표현 평가를 품질·크기·학습·복원 비용의 다축 문제로 전환

### 확인된 사실

- gigapixel 이미지에서 implicit, hybrid, explicit learnable representation을 압축과 super-resolution 과제로 비교한다. 데이터는 과학·문화·산업 도메인을 포함하며 WACV 2027 accepted로 명시돼 있다.
- 압축 평가는 PSNR, Compression Ratio(CR), Compression Time(CT), Inference Time(IT)을 함께 보고한다.
- hybrid 계열의 MetricGrids(T=24)와 I-NGP(T=24)은 평균 PSNR 33.59 dB와 33.19 dB를 기록하지만 구조적으로 약 5~16배의 낮은 압축률 범위에 묶인다.
- I-NGP는 평균 2분 미만, 더 구체적으로 비교 구간에서 1.7분 미만에 fitting한 반면 MetricGrids는 최대 약 19분이 걸렸다. 저자들은 CUDA custom kernel과 PyTorch 구현 차이가 비용 비교에 영향을 준다고 명시한다.
- SmartSplat은 CR=15에서 평균 PSNR 30.40 dB, CT 98.48분, IT 3.36초다. CR=3000에서도 24.05 dB를 유지한다.
- 큰 implicit 구성은 압축에 최대 206분, 전체 gigapixel 복원에 약 7~11분이 걸릴 수 있다.

### 저자 주장

저자들은 moderate compression에서는 hybrid, 특히 I-NGP가 품질–시간 균형이 좋고, extreme compression에서는 implicit과 SmartSplat이 후보이며, latency-sensitive downstream에는 SmartSplat의 빠른 복원이 유리하다고 정리한다.

### 해석과 비교 조건

- 가장 중요한 변화는 최고 PSNR 경쟁이 아니라 **동일 압축률에서의 품질과 전체 파이프라인 시간**을 같이 보는 것이다.
- I-NGP와 MetricGrids의 CT 차이는 표현 자체뿐 아니라 CUDA/PyTorch 구현 최적화가 섞여 있다. 따라서 알고리즘 우위로 일반화하면 안 된다.
- CR=15의 SmartSplat 30.40 dB와 CR≈5~16의 hybrid 33 dB대는 비슷한 압축 구간에서 참고할 수 있지만, 이미지별 분산과 정확한 parameter budget을 맞춘 뒤 비교해야 한다.
- gigapixel 하류 과제에서는 전체 영상을 복원하지 않고 tile/feature를 직접 소비할 수 있다. 현재 IT는 full-raster decode 기준이므로 실제 segmentation/detection latency와 같지 않다.

### 최소 재현 실험

해양 위성 또는 해무 mosaic 한 장을 1-gigapixel 수준으로 구성하고 I-NGP, SmartSplat, bicubic+lossless baseline을 CR 15와 100에 맞춘다. PSNR/SSIM, peak VRAM, CT, full decode IT, 그리고 downstream fog segmentation IoU를 함께 측정한다. 이 실험은 “좋은 복원 수치가 downstream 성능을 보존하는가”를 직접 검증한다.

- 논문: https://arxiv.org/abs/2610.31644
- 프로젝트: https://matteofusconi.github.io/GigaBench/

## 3. Sensorimotor Alignment(S²) — VLA 성공률의 훈련 없는 오프라인 proxy

### 확인된 사실

- S²는 감각 표현 공간의 geometry와 실제 motion trajectory geometry를 정렬하는 training-free offline metric이다.
- 12개 fine-tuned VLA와 SimplerEnv-WidowX 성공률 비교에서 기본 설정의 Pearson 상관은 `r=+0.717`, model-bootstrap 95% CI는 `[+0.436, +0.912]`, one-tailed `p=0.0043`이다.
- neighbor 수, trajectory normalization, rotation distance, pooling과 component weight를 바꾼 민감도 분석에서 다수 설정이 양의 상관을 유지했다. 기본 이웃 수 변화에서는 r이 +0.644~+0.717 범위다.
- matched bimanual ALOHA reference로 3개 WAM 모델을 평가하면 성공률 순서를 `r=+0.999`로 복원했지만, mismatched single-arm DROID reference에서는 `r=+0.246`, `p=0.421`로 떨어졌다.
- text-only feature는 유의한 양의 상관을 보이지 않았고, LLM-output vision-text feature가 기본 최고 상관을 냈다.

### 저자 주장

저자들은 representation이 행동의 물리적 구조를 얼마나 반영하는지가 embodied policy success의 유용한 사전 지표가 될 수 있다고 주장한다.

### 해석과 비교 조건

- 이 결과는 12개 모델 내 상관이며, 새로운 family·로봇·task에 대한 인과적 예측 정확도를 증명하지 않는다.
- matched/mismatched embodiment 실험이 보여주듯 reference trajectory 선택이 metric의 일부다. reference가 바뀌면 leaderboard 순위도 바뀔 수 있다.
- 성공률 대신 S²만 최적화하면 proxy gaming 위험이 있다. S²는 rollout 비용을 줄이는 screening metric으로 쓰고, 최종 선택은 동일 task success와 safety failure로 확인해야 한다.

### 최소 재현 실험

동일 로봇/동일 task의 3개 정책 checkpoint에 대해 S²를 먼저 계산하고, 30회씩 실제 또는 simulator rollout 성공률을 측정한다. matched reference와 deliberately mismatched reference를 모두 사용해 순위 보존율과 Kendall tau를 비교한다. matched 조건에서만 순위가 유지되면 metric을 model selection 전처리로 제한한다.

- 논문: https://arxiv.org/abs/2610.31670
- 코드: https://github.com/yunfeixie233/sensorimotor-alignment
- 프로젝트: https://yunfeixie233.github.io/s2/

## 4. PhysTrace — 물리 일관성 평가를 이진 분류에서 시간 구간 localization으로 확장

### 확인된 사실

- MLLM이 과거 관측으로부터 다음 상태를 서술하고, 실제 video window와의 alignment 변화를 추적해 위반 시점을 찾는 training-free 방식이다.
- violation interval annotation을 포함한 IntPhys2-Timing을 제안한다.
- IntPhys2-Timing에서 PhysTrace의 전체 Hit Rate는 Continuity 63.2%, Immutability 70.7%, Permanence 56.6%, Solidity 69.6%다.
- V-JEPA2 기반 VoE baseline은 공개 표에서 Continuity 전체 61.8%를 기록한다. 속성별 난이도에 따라 두 방법의 우열이 달라질 수 있어 전체 최고값만으로 모든 속성 우위를 주장할 수 없다.
- 저자들은 기존 IntPhys2의 possible/impossible 구분에서도 비교 방법보다 높은 overall accuracy를 보고하지만, 오늘 보고서에는 표에서 직접 확인된 localization 수치만 정량 근거로 사용한다.
- 공식 저장소는 MIT license로 코드가 공개돼 있다.

### 저자 주장

저자들은 단순히 비디오가 물리적으로 이상한지 판정하는 것을 넘어, 어느 temporal window에서 어떤 속성이 깨졌는지를 해석할 수 있다고 주장한다.

### 해석과 비교 조건

- benchmark 이동은 binary accuracy에서 **temporal diagnosis**로의 이동이다. 이는 생성 비디오 평가뿐 아니라 추적·예측 모델의 failure localization에도 적용 가능하다.
- MLLM이 만든 예상 서술과 embedding alignment를 사용하므로, 실제 물리 이해와 language prior가 섞일 수 있다.
- Hit Rate는 violation interval 정의와 window stride에 민감하다. 서로 다른 window/threshold 설정끼리 수치를 직접 비교하면 안 된다.

### 최소 재현 실험

IntPhys2-Timing의 네 속성에서 각 25개 clip을 stratified sample하고 공개 기본 threshold/window로 Hit Rate를 재계산한다. 이어 threshold를 ±20%, stride를 절반/두 배로 바꿔 속성별 순위가 유지되는지 본다. robustness 조건은 각 설정에서 속성별 Hit Rate 변화가 5%p 이내인 것이다.

- 논문: https://arxiv.org/abs/2610.31429
- 코드: https://github.com/PhysTrace/PhysTrace

## 5. DuoCook — 시각 계획·중앙집중형 2-agent coordination의 미포화 benchmark

### 확인된 사실

- Unreal Engine 기반 20개 맵, 5개 범주에서 한 VLM이 top-down 시각 관측을 보고 두 플레이어의 high-level action을 함께 선택한다.
- score, order completion, delivery precision, action acceptance, API cost를 동시에 측정한다.
- gpt-6-astra는 평균 score 25.6, 주문 완료율 26.2%, delivery precision 93.8%(delivery가 있었던 n=16 맵), action acceptance 64.6%, episode당 API 비용 5.18달러를 기록했다.
- 다른 세 모델의 주문 완료율은 8.8~11.2%다. Claude Opus 5의 delivery precision 100%는 delivery가 있었던 5개 맵에 한정되므로 20개 맵 전체의 완성도와 동일하게 읽으면 안 된다.
- shared self-authored notebook ablation에서도 양쪽 조건에 최근 6개 응답의 action history는 유지했다. notebook은 Claude/Qwen의 평균 score에는 양의 차이, GPT/Gemini에는 음의 차이를 보였고 모든 모델의 평균 API 비용을 늘렸다.

### 저자 주장

저자들은 이 benchmark가 changing terrain, equipment contention, handoff dependency에서 시각 기반 planning과 coordination을 함께 드러낸다고 본다.

### 해석과 비교 조건

- 최고 완료율이 26.2%라 ceiling이 아니라 floor 근처의 모델 차이를 재는 단계다. 작은 prompt/interface 변경이 순위를 크게 흔들 수 있다.
- precision의 분모가 delivery 성공 맵에 한정되므로 completion과 반드시 함께 봐야 한다.
- notebook 유무 비교는 “기억 전체 유무”가 아니라 self-authored notebook 추가 효과다. 6-response history가 양쪽에 남아 있다.
- 비용까지 포함한 Pareto 관점에서는 gpt-6-astra의 성능 우위와 높은 API 비용을 함께 평가해야 한다.

### 최소 재현 실험

가장 어려운 changing-terrain+shared-equipment 4개 맵에서 각 모델을 5회 반복한다. fixed decoding, 동일 action history로 notebook on/off를 비교하고 completion, invalid action rate, handoff failure count, cost를 기록한다. notebook 채택 기준은 completion +5%p 이상이면서 비용 증가가 20% 이하인 경우로 둔다.

- 논문: https://arxiv.org/abs/2610.31511

## 오늘의 benchmark signal 3개

1. **평가 단위가 더 작아진다.** 전체 accuracy 대신 cell link, violation interval, action acceptance처럼 실패가 발생한 원자 단위를 기록해야 개선 방향이 보인다.
2. **성능과 운영 비용을 분리할 수 없다.** GigaBench의 CT/IT, DuoCook의 API 비용처럼 품질과 latency·비용을 같은 표에 둬야 실제 선택이 가능하다.
3. **harness와 reference가 leaderboard의 일부다.** CellTrack의 frozen c1, S²의 embodiment-matched reference가 보여주듯 모델만 고정해서는 재현 가능한 비교가 되지 않는다.

## 내 연구에 바로 연결되는 포인트

- 해무 분류/탐지에서는 frame-level accuracy 외에 `발생 시작·소멸 시점 localization`, 작은 해무 영역의 link consistency, false-alarm inspection utility를 추가한다.
- 위성·CCTV 고해상도 입력은 GigaBench 방식으로 `압축률–복원 품질–전체 decode 시간–downstream IoU`를 한 번에 측정한다. PSNR만으로 전처리 방식을 고르지 않는다.
- multi-frame 또는 sensor fusion 모델은 CellTrack의 frozen harness 원칙을 따라 prompt, crop, resize, temporal window, threshold를 평가 전에 고정한다.
- embodied/해양 로봇으로 확장할 때 S²류 offline proxy는 후보 정책 screening에만 쓰고, matched platform의 실제 rollout 성공률과 함께 보고한다.
- 생성형 video augmentation은 PhysTrace 방식으로 물리 위반 여부뿐 아니라 위반 프레임을 저장해 학습 데이터 필터와 오류 분석에 연결한다.
