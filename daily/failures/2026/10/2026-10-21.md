## 1. POPE의 yes/no token 집합이 환각 완화 성능보다 큰 교란을 만든다

**대상:** *Token-Set Choice Confounds POPE: A Systematic Audit of Yes/No Extraction in VLM Hallucination Evaluation*  
**실패 조건:** POPE에서 LLaVA-1.5-7B의 첫 생성 token을 `yes=3582`, `no=1217` 두 ID로만 읽는 경우  
**모델·데이터·설정:** LLaVA-1.5-7B, POPE adversarial/popular/random 각 split, greedy decoding 9,000문항, 저자 공개 구현은 4-bit NF4 조건과의 차이도 별도 제한으로 남김

### 확인된 사실

- 공개 companion repository에는 두-token rule과 여덟-token rule, 9,000개 문항별 prediction record, diagnostic script가 포함돼 있다.
- 저자 기록에서 ID 3582와 1217은 9,000회 생성에서 한 번도 나오지 않았다. 실제 출력은 공백이 붙은 ` Yes`(3869), ` No`(1939)였다.
- adversarial F1은 두-token 0.7608, 여덟-token 0.8221로 0.0613 차이였다. 여덟-token F1은 popular 0.8498, random 0.8713으로 보고됐다.
- tokenizer family가 다른 네 VLM에 복사한 LLaVA ID는 vocabulary가 겹치지 않는 두 모델에서 F1 0.00을 만들었고, tokenizer로부터 도출한 readout은 0.80–0.92 범위였다.
- 고정한 baseline에 적용한 추론 시점 보정 아홉 개는 baseline을 넘지 못했다. 3,000문항 probe에서는 오답의 image attention이 정답보다 더 컸다(Cohen's d=-0.46, p=1.4e-24).

### 저자 인정·재현 상태

- **저자 주장:** 6.13점 차이는 조사한 여섯 논문 중 다섯 논문의 보고 이득보다 크며, 해당 논문들은 readout을 공개하지 않았다.
- **저자 인정:** 원 참조 설정이 4-bit NF4였으므로, readout과 precision을 동시에 맞추기 전에는 모든 차이를 token 집합 하나로 귀속할 수 없다.
- **공동체 재현:** 공개 직후라 독립 재현은 확인되지 않았다. 다만 코드, PyPI 패키지, 9,000개 prediction record가 공개돼 재현 가능성은 높다.

### 진단 → 가설 → 최소 실험

- **진단:** 평가기가 실제 생성 token이 아닌 vocabulary 항목을 읽어 모델 예측을 왜곡한다.
- **가설:** 일부 POPE 기반 decoding method의 작은 이득은 모델 개선보다 readout·quantization·prompt suffix 상호작용에 민감하다.
- **최소 실험:** 동일 logits를 저장한 뒤 (a) 논문 원 ID, (b) tokenizer-derived surface forms, (c) 생성 문자열 normalization으로 각각 F1을 다시 계산한다. NF4와 BF16을 교차해 순위가 유지되는지도 본다.
- **GO:** 방법 순위와 절대 이득이 세 readout 및 두 precision에서 유지된다.
- **KILL:** 순위가 뒤집히거나 방법 이득이 readout 차이보다 작다.

**평가:** 심각도 5/5 · 재현 신뢰도 5/5 · 연구 아이디어 가치 5/5

## 2. AV-LLM은 국소 증거를 찾고도 전체 영상에서 시간 관계를 조합하지 못한다

**대상:** *Local Evidence, Global Failure: Diagnosing Speech-Vision Temporal Composition in Audio-Visual Language Models*  
**실패 조건:** narration이 가리키는 동작의 시점과 실제 영상 동작 시점이 어긋난 full-video 질의  
**모델·데이터·설정:** Qwen3-Omni-30B-A3B, Qwen2.5-Omni-7B, VideoLLaMA2.1-7B-AV, video-SALMONN 2+ 7B; SVHalluc TA 368, TF 276, CMTB 339개; greedy direct decoding; TED는 5개 uniform audio-free window와 ASR utterance interval 사용

### 확인된 사실

- full-video Temporal Forecasting 정확도는 네 backbone에서 29.35%, 33.70%, 30.80%, 33.33%였다. 3-way chance는 33.3%다.
- 같은 frozen backbone의 국소 window를 query-conditioned verifier로 쓰고 ASR 시점을 기준으로 aggregation한 TED는 80.43%, 79.35%, 79.35%, 82.25%였다.
- TA와 CMTB에서도 네 모델 모두 TED가 direct보다 높았다. 실패·미완성·abstention은 전체 평가에서 오답으로 유지됐다.
- TED는 TA/TF 항목당 ASR 외에 10번의 local call을 사용한다. 따라서 계산량과 inference interface가 direct와 다르며, 단순한 공정 성능 비교는 **not strictly apples-to-apples**다.
- query replacement, shuffled anchor, physical isolation, timing shortcut control을 두어 transcript 내용과 utterance timing이 각각 회복에 기여하는지 점검했다.

### 저자 인정·재현 상태

- **저자 주장:** backbone 내부에 locally recoverable visual evidence가 있으나, full-video speech-relative decision에서 이를 조합하는 단계가 실패한다.
- **저자 인정:** TED는 inference interface를 의도적으로 바꾸며, local score는 calibrated event probability가 아니라 비교 증거다. SigLIP 2는 transcript를 64 token으로 자른다.
- **공동체 재현:** 독립 재현과 공개 코드 링크는 확인하지 못했다. 현재 근거는 저자 원문과 세부 표에 한정된다.

### 진단 → 가설 → 최소 실험

- **진단:** 음성 내용, 발화 시점, 시각 evidence를 한 번에 처리하는 전역 조합이 국소 인식보다 약하다.
- **가설:** 긴 multimodal context의 attention dilution과 audio-visual temporal binding 실패를 분리하면 오류의 상당 부분을 설명할 수 있다.
- **최소 실험:** TF 50개를 층화 표집해 direct, 5-window TED, 동일 call budget의 full-video interval prompting을 비교한다. local score가 맞는데 direct가 틀린 비율을 핵심 지표로 둔다.
- **GO:** 최소 두 backbone에서 local-correct/direct-wrong 비율이 반복되고, matched-call full-video가 local window보다 낮다.
- **KILL:** call budget을 맞추면 차이가 사라지거나 ASR timing만으로 같은 정확도가 나온다.

**평가:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 3. 이미지 harmonization test의 25%가 train과 같은 원본 사진에서 파생됐다

**대상:** *Only Means Only: Auditing Construction-Level Leakage in Image Harmonization Benchmarks*  
**실패 조건:** composite 파일명이나 byte hash만 비교해 train/test가 분리됐다고 판단하는 경우  
**모델·데이터·설정:** 표준 image harmonization train/test, construction identity 기준 감사, 세 방법의 end-to-end 재채점

### 확인된 사실

- 저자 감사에서 train과 test에 함께 쓰인 원본 사진이 1,399개 발견됐다. 그 사진에서 만든 composite는 test의 25%였다.
- composite 자체는 서로 다른 파일이어서 filename 또는 byte-level duplicate 검사로는 잡히지 않는다.
- 평가한 세 방법 모두 공유 원본 구간의 오차가 나머지 test보다 2–5배 낮았다.
- 저자는 이 차이의 대부분이 train 공유 자체보다 composition/source collection 효과라고 분석했다. 같은 collection 안에서의 격차는 약 1.5배였다.
- 저자는 train에 construction identity가 없는 5,581개 composite의 clean test list와 확인된 near-duplicate pair 네 쌍을 공개했다. 재학습 없이 재채점하는 감사다.

### 저자 인정·재현 상태

- **저자 주장:** 공식 단일 점수는 난도가 다른 두 population을 혼합하면서 그 mixture를 공개하지 않아 모델 일반화 해석을 흐린다.
- **저자 인정:** 관찰 연구이므로 원본 사진 공유 자체가 학습을 개선했다는 인과 효과는 확정하지 못한다. source collection이 강한 교란이다.
- **공동체 재현:** Zenodo 부속 자료가 공개됐지만 독립 재현은 확인되지 않았다.

### 진단 → 가설 → 최소 실험

- **진단:** 파일 중복이 아니라 **construction provenance 중복**이 분할 경계를 통과한다.
- **가설:** harmonization 외의 합성 CV benchmark도 원본 이미지·mask·prompt·render seed 단위 provenance를 추적하지 않으면 비슷한 난도 혼합을 가진다.
- **최소 실험:** 원본 사진의 perceptual hash와 metadata graph로 test를 shared-source, same-collection-clean, cross-collection-clean으로 나눠 기존 checkpoint만 재채점한다.
- **GO:** 방법별 순위·오차가 source strata 사이에서 유의하게 달라지고 clean subset에서 결론이 바뀐다.
- **KILL:** 세 strata의 paired bootstrap interval이 크게 겹치고 방법 순위가 안정적이다.

## 4. Open-Vocabulary HOI 의미 채점이 잘못된 동작과 역할 반전까지 보상한다

**대상:** *Auditing Semantic and Relational Reliability in Open-Vocabulary Human-Object Interaction Evaluation*  
**실패 조건:** free-text HOI prediction을 lexical/semantic similarity만으로 정답 triplet에 맞추는 경우  
**모델·데이터·설정:** HICO-DET, 여섯 시스템, official category·identity control·lexical normalization·graded semantic credit·strict propositional equivalence의 다섯 평가 view

### 확인된 사실

- category scoring은 올바른 paraphrase를 거절할 수 있고, semantic similarity는 틀린 action이나 agent/object 역할 반전을 받아들일 수 있다.
- 같은 prediction을 고정한 채 평가 view만 바꿨는데 official에서는 GEN-VLKT, SHOE에서는 SL-HOI, strict equivalence에서는 다시 GEN-VLKT가 선두였다.
- semantic scoring의 증가는 1.6–20.3 mAP이었다. AgentHOI는 propositional equivalence를 강제하면 이 증가분의 절반 미만만 유지했다.
- 저자는 의미 보존 변환과 의미 파괴 변환의 controlled pair, 그리고 natural prediction blinded audit를 함께 사용했다.

### 저자 인정·재현 상태

- **저자 주장:** recovered semantic credit를 interaction understanding 향상으로 바로 해석하면 안 되며 relational validity와 paired uncertainty를 함께 보고해야 한다.
- **저자 인정:** 현재 arXiv v1이며 WACV 2027 심사 중이다. 공개 코드·독립 재현은 확인되지 않았다.
- **충돌 지점:** open-vocabulary 평가가 vocabulary mismatch를 줄인다는 장점은 유지되지만, predicate와 role을 보존하지 않으면 category 평가보다 더 관대한 다른 오류가 생긴다.

### 진단 → 가설 → 최소 실험

- **진단:** text similarity가 `person rides horse`와 `horse rides person`의 관계 구조를 충분히 보존하지 않는다.
- **가설:** HOI뿐 아니라 referring relation, scene graph, visual relation detection의 LLM judge도 lexical semantic 점수와 propositional validity가 분리된다.
- **최소 실험:** HICO-DET prediction 300개에 paraphrase, predicate swap, role swap 세 변환을 만들고 기존 semantic scorer의 accept rate와 strict triplet checker의 accept rate를 비교한다.
- **GO:** paraphrase recall을 유지하면서 predicate/role swap false accept를 절반 이하로 줄이는 rule 또는 judge가 나온다.
- **KILL:** stricter checker가 paraphrase recall을 같은 폭으로 잃어 순효과가 없다.

**평가:** 심각도 4/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 5/5

## 5. 산림 LiDAR place recognition은 검색보다 fine matching에서 무너진다

**대상:** *TNVD-SC: Diagnosing Scan Context Failures in Forests with Terrain-Normalized Vertical Distributions*  
**실패 조건:** 반복 식생과 비평탄 지형에서 max-height scalar를 쓰는 Scan Context가 후보 검색 뒤 fine reranking을 수행하는 경우  
**모델·데이터·설정:** standardized TreeLoc++ Wild-Places protocol, Venman·Karawatha, Top-25 candidate, SC ring key/SC matcher와 TNVD support/TNVD matcher의 교차 분해

### 확인된 사실

- TNVD support key의 valid-location R@25는 Venman 98.89%, Karawatha 98.76%였지만, 같은 후보를 conventional SC matcher로 재정렬한 R@1은 57.20%, 66.47%, 평균 61.84%였다.
- SC candidate budget을 K=250까지 늘려도 candidate recall은 97.45%, 98.47%에 도달하는 반면 최종 R@1은 약 40–50%에 머물렀다.
- 동일 raw-SC Top-25 후보에서 terrain normalization은 max-height cell에 +1.21점, vertical-distribution cell에 +19.72점이었다.
- full TNVD-SC는 standardized Wild-Places mean R@1 91.83%, NCLT 네 session mean R@1 85.14%를 보고했다. TreeLoc++는 mean MR, MF1, AUC에서 더 강했다.

### 저자 인정·재현 상태

- **저자 주장:** coarse retrieval과 fine discrimination은 대체할 수 없는 별도 병목이며, 지형 정규화의 이득은 뒤따르는 cell representation에 조건부다.
- **저자 인정:** vertical distribution, terrain normalization, probability divergence 각각을 새로운 요소로 주장하지 않는다. 통제 실험은 candidate recall ceiling의 제약을 받는다.
- **공동체 재현:** 독립 재현과 공개 코드 링크는 확인되지 않았다. 현재 수치는 저자 구현의 stage-wise audit에 기반한다.

### 진단 → 가설 → 최소 실험

- **진단:** max-height 압축이 understory·stem·canopy의 내부 층 구조를 지워 구조적 aliasing을 만든다.
- **가설:** 산림뿐 아니라 해안 안개·농경지·창고처럼 반복 수직 구조가 있는 3D 환경에서도 candidate recall보다 cell statistic이 오차를 지배한다.
- **최소 실험:** 동일 Top-25 candidate를 고정하고 max-height, height histogram, terrain-normalized histogram 세 matcher만 교체한다. R@25와 R@1을 분리 기록한다.
- **GO:** 후보 recall은 거의 고정된 채 distribution matcher가 두 장소·두 계절 이상에서 R@1을 일관되게 높인다.
- **KILL:** 개선이 한 site 또는 terrain estimator 하나에만 나타난다.

**평가:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 4/5

## 오늘의 실패 패턴 3개

1. **평가기가 만든 가짜 차이:** POPE와 OV-HOI는 모델 출력을 고정해도 token readout이나 의미 credit 규칙만으로 절대 점수와 순위가 달라진다.
2. **국소 성공·전역 실패:** AV-LLM과 산림 LiDAR 모두 필요한 후보나 증거는 확보했지만, 시간 조합 또는 fine matching에서 최종 결정이 무너졌다.
3. **분할 이름보다 생성 계보가 중요:** harmonization의 train/test 파일이 서로 달라도 같은 원본 사진에서 파생되면 난도와 일반화 해석이 섞인다.

## 논문 아이디어로 연결 가능한 빈틈

### A. Evaluation Contract Checker for VLM Benchmarks

- tokenizer에서 실제 생성 가능한 label surface form을 자동 열거하고, prompt suffix별 tokenization을 기록한다.
- string parsing, token-set logit, constrained decoding의 결과 일치도를 표준 audit로 만든다.
- **핵심 기여 후보:** 방법 이득보다 평가 불확실성이 큰 benchmark를 자동 검출하는 `evaluation sensitivity interval`.

### B. Evidence-Available / Decision-Failed 분해 benchmark

- 전체 입력 오답을 evidence absence, evidence retrieval failure, aggregation failure로 나눈다.
- video temporal reasoning과 LiDAR coarse-to-fine recognition에 같은 stage-wise protocol을 적용한다.
- **핵심 기여 후보:** 모델 accuracy 대신 각 단계의 recoverability와 ceiling을 함께 보고하는 진단 지표.

### C. Construction-Lineage Split Auditor

- 원본 이미지, crop, mask, composite, caption, render seed를 graph로 묶어 connected component 단위로 split한다.
- exact duplicate, near duplicate, same-source derivative를 별도 위험 수준으로 분리한다.
- **핵심 기여 후보:** 합성·증강 기반 CV dataset에서 파일 독립성과 construction 독립성의 차이를 정량화한다.

## 출처와 해석 한계

- 최근 arXiv v1 논문이므로 peer review와 장기 공동체 재현이 끝나지 않았다.
- 공개 코드와 prediction record까지 확인된 것은 POPE 사례다. 다른 네 사례는 원문 세부 표·부속 자료를 교차 확인했지만 독립 재현은 확인하지 못했다.
- POPE의 6.13점, AV-LLM의 TED 개선, harmonization의 2–5배, OV-HOI의 1.6–20.3 mAP, TNVD-SC의 R@1은 서로 다른 task·metric이므로 직접 크기 비교를 하지 않았다.
- 평점은 연구 우선순위용 정성 판단이며 측정된 성능 지표가 아니다.
