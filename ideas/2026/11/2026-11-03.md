## 후보 A — SpheriGraph-Cal

### Calibrating Panoramic Scene-Graph Relations Under Projection Shift

1. **문제/가치:** ERP panorama에서 object mask가 맞아도 seam·polar region에서 relation과 containment가 흔들릴 수 있다. navigation·robotics에서는 node mIoU만으로 충분하지 않다.
2. **빈틈:** PanoGraphGS는 view-consistent hierarchy를, spherical PSGG는 projection-aware fusion을 다루지만 relation confidence가 projection 위치에 따라 calibration되는지 연결하지 않는다.
3. **가설:** spherical overlap·angular distance·관측 수를 이용한 relation confidence는 ERP pixel-space confidence보다 seam/polar failure를 더 잘 예측한다.
4. **방법:** 동일 3D Gaussian graph에 ERP/view fusion 두 조건을 두고, edge별 spherical coverage와 projection position을 입력으로 calibration head만 추가한다.
5. **비교군:** pixel-space fusion, temperature scaling, per-relation threshold, oracle spherical coverage.
6. **데이터/지표:** NaviGS 또는 공개 panoramic scene graph, synthetic ERP rotation; relation mR@K, hierarchy consistency, ECE, seam/polar subgroup error.
7. **Ablation:** spherical area, seam duplication, view count, camera latitude, geometry-only/text-feature-only confidence.
8. **실패/negative result:** 충분한 multi-view coverage가 있으면 projection 위치가 더 이상 유의하지 않을 수 있다. 이는 view consistency가 이미 효과적이라는 유용한 반증이다.
9. **Novelty 위험/방어:** 단순 ERP augmentation으로 보일 위험이 있다. 핵심은 평균 mR 향상이 아니라 projection-conditioned calibrated abstention이다.
10. **4–8주 MVP:** 1–2주차 ERP rotation과 subgroup audit, 3–4주차 confidence calibration, 5–6주차 graph-edge abstention, 7–8주차 cross-scene test.
11. **성공 기여:** projection-aware relation calibration, panoramic failure-cell benchmark, risk–coverage evaluation.
12. **제목 후보:** *SpheriGraph-Cal* / *Where Panoramic Relations Break* / *Calibrated Scene Graphs Beyond the Seam*.
13. **Abstract 개요:** ERP distortion → average metric 한계 → spherical coverage-conditioned confidence → subgroup calibration과 selective graph prediction.
14. **Introduction 논리:** panorama 사용 증가 → pixel distortion → relation failure의 비용 → current fusion의 confidence gap → proposed audit.
15. **Related Work:** panoramic perception / scene graphs / uncertainty calibration / 3D Gaussian semantics.
16. **Method:** projection partition → coverage features → calibrated edge predictor → selective hierarchy assembly.
17. **표/그림:** seam·latitude별 mR/ECE 표, risk–coverage curve, ERP rotation consistency figure, failure montage.

**평가:** Novelty 4.2 / Feasibility 4.0 / Compute 2.5 / Publication potential 4.2.  
**첫 실험:** 동일 panorama를 longitude-shift해 edge score와 ECE 변화만 측정한다. GO는 spherical feature가 seam/polar error를 예측할 때, KILL은 subgroup gap이 없을 때다.

## 후보 B — ContainmentCounterfactual

### Does Hierarchical Scene-Graph Accuracy Reflect Geometry or Containment Shortcuts?

1. **문제/가치:** floor–room–object hierarchy의 높은 node accuracy가 실제 object evidence가 아니라 room prior·frequent co-occurrence를 이용한 결과일 수 있다.
2. **빈틈:** PanoGraphGS는 계층 identification 결과를 보고하지만 containment prior와 local geometric evidence의 기능적 필요성을 분리하지 않는다.
3. **가설:** object prediction 일부는 local geometry를 제거해도 유지되고, room/floor label을 교체하면 급격히 변한다면 hierarchy score가 geometry-grounded understanding을 과대평가한다.
4. **방법:** frozen scene-graph pipeline에 local object geometry masking, room/floor context swap, semantically matched but geometry-mismatched context 개입을 적용한다. 새 backbone은 만들지 않는다.
5. **비교군:** 원본, random masking, object-only graph, context-only graph, matched-visibility crop, oracle object mask.
6. **데이터/지표:** Replica·NaviGS 등 공개 scene graph; object-node accuracy, containment consistency, counterfactual flip rate, local-evidence retention score.
7. **Ablation:** masking radius, object frequency, room category, view count, panoptic mask quality, object scale.
8. **실패/negative result:** local geometry만으로도 모든 object node가 유지되면 shortcut 가설은 기각된다. context가 필요한 물체는 shortcut이 아니라 합리적 relational reasoning일 수 있다.
9. **Novelty 위험/방어:** 단순 bias audit으로 끝날 수 있다. causal claim 대신 controlled functional intervention이며, semantic plausibility control을 필수로 둔다.
10. **4–8주 MVP:** 1주차 graph export·masking, 2주차 random/matched control, 3주차 context swap, 4주차 taxonomy, 5–6주차 multiple scenes, 7–8주차 mitigation.
11. **성공 기여:** hierarchy shortcut diagnostic, geometry/context necessity matrix, evaluation protocol for scene-graph evidence.
12. **제목 후보:** *ContainmentCounterfactual* / *Does a Scene Graph See the Object?* / *Hierarchy Is Not Evidence*.
13. **Abstract 개요:** 계층 accuracy의 해석 문제 → controlled scene intervention → geometry/context necessity 측정 → shortcut taxonomy 및 mitigation.
14. **Introduction 논리:** graph hierarchy의 실용성 → aggregate accuracy 한계 → context shortcut 가능성 → 개입 기반 평가.
15. **Related Work:** 3D scene graphs / causal vision evaluation / shortcut learning / counterfactual representations.
16. **Method:** intervention generator → visibility controls → necessity/sufficiency score → error taxonomy.
17. **표/그림:** 원본·개입 accuracy 표, class별 flip heatmap, geometry–context Pareto, 정성 counterfactual panels.

**평가:** Novelty 4.6 / Feasibility 4.7 / Compute 2.0 / Publication potential 4.6.  
**첫 실험:** object mask 주변의 geometry만 가리는 intervention과 무작위 동일 면적 intervention을 비교한다. GO는 object-specific masking이 random control보다 의미 있게 flip을 유발할 때다. KILL은 모든 변화가 visibility artifact로 설명될 때다.

## 후보 C — StateBound-Nav

### Binding Process Evidence to 3D Scene-Graph Actions

1. **문제/가치:** VPAC-Bench는 VLM이 근거를 인지하고도 행동에 반영하지 못할 수 있음을 보인다. 3D scene graph가 추가되어도 action boundary와 연결되지 않으면 같은 실패가 남을 수 있다.
2. **빈틈:** scene graph는 static hierarchy, process benchmark는 stage transition을 강조한다. object–relation–process-state가 행동 선택을 실제로 제약하는지 검증한 protocol이 부족하다.
3. **가설:** action 전 object evidence와 transition-relevant graph substructure를 명시적으로 align하면 ambiguous navigation/action 사례의 over-commitment가 줄어든다.
4. **방법:** VLM action head 앞에 state-relevant subgraph selector와 boundary verifier를 둔다. selector가 고른 object/relation을 숨기거나 대체한 counterfactual로 action dependence를 점검한다.
5. **비교군:** direct VLM, chain-of-thought, full scene graph prompt, random subgraph, oracle transition label.
6. **데이터/지표:** VPAC-Bench process families와 scene graph가 가능한 indoor navigation subset; action accuracy, evidence–action consistency, ambiguous over-commitment, abstention quality.
7. **Ablation:** graph/no graph, selector/no selector, boundary type, object visibility, prompt order, oracle state.
8. **실패/negative result:** static graph가 dynamic transition을 제공하지 않아 full graph prompting만으로는 개선이 없을 수 있다. 이는 static graph의 한계를 명확히 보이는 결과다.
9. **Novelty 위험/방어:** prompt engineering으로 보이지 않도록 evidence removal/replacement counterfactual과 same-token budget control을 둔다.
10. **4–8주 MVP:** 1–2주 VPAC subset에 object/relation annotation 연결, 3주 selector, 4주 counterfactual, 5–6주 navigation transfer, 7–8주 calibration.
11. **성공 기여:** evidence-to-action consistency metric, transition-relevant subgraph selection, ambiguity-aware action policy.
12. **제목 후보:** *StateBound-Nav* / *Seeing a Scene Graph Is Not Acting on It* / *Boundary-Aware Graph Evidence for Vision Agents*.
13. **Abstract 개요:** perception–action gap → static graph의 한계 → state-bound evidence selection → counterfactual action audit.
14. **Introduction 논리:** VLM evidence contradiction → scene graph promise → decision-boundary mismatch → proposed causal audit.
15. **Related Work:** VLM agents / visual process reasoning / scene graphs / selective prediction / embodied navigation.
16. **Method:** state evidence representation → subgraph selector → verifier → counterfactual dependency audit.
17. **표/그림:** direct vs graph vs state-bound action table, over-commitment plot, evidence-removal flip matrix, navigation case studies.

**평가:** Novelty 4.7 / Feasibility 3.6 / Compute 3.5 / Publication potential 4.7.  
**첫 실험:** VPAC-style ambiguous cases에서 relevant object/relation을 제거·교체했을 때 action이 적절히 변하는지 본다. GO는 action consistency가 direct VLM보다 개선될 때이며, KILL은 selector가 visual evidence와 무관한 text prior를 반복 선택할 때다.

## 최우선 추천 — ContainmentCounterfactual

가장 먼저 검증할 후보는 **ContainmentCounterfactual**입니다. PanoGraphGS의 높은 hierarchy 성능을 부정하는 것이 목적이 아니라, 그 정확도가 local geometric evidence와 room/floor context 중 무엇에 기능적으로 의존하는지 구분하는 것입니다. 첫 2주에는 새 모델 학습 없이 intervention audit과 엄격한 random/visibility control만으로 GO/KILL을 판별할 수 있습니다.

**첫 실험:** NaviGS 또는 Replica 한 subset에서 object-local geometry mask, 동일 면적 random mask, room-context swap을 적용하고 object-node accuracy·containment consistency·counterfactual flip rate를 비교합니다.  
**GO:** object-specific 개입의 효과가 random visibility control을 넘고, class·room별 반복 패턴이 보일 때.  
**KILL/PIVOT:** 효과가 random masking과 구분되지 않으면 scene-graph shortcut 주장을 철회하고, view coverage 또는 panoptic mask quality 진단으로 방향을 전환합니다.
