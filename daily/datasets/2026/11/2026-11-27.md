## 1. BRDFusion — normal 수정과 장면 교체를 분리한다

**확인 사실.** 고정 revision은 `595e2b6d2a70bc0c94fac6147740aa1b72198021`이다. 이력에는 구 static scene·Waymo archive 제거와 `synthetic_s1`~`synthetic_s6` ZIP 추가가 있다. 이번 신규성은 6월 논문의 재발견이 아니라 11/26 배포 변경이다. [고정 card](https://huggingface.co/datasets/Shigon/BRDFusion_data/blob/595e2b6d2a70bc0c94fac6147740aa1b72198021/README.md)

**배포자 보고 — 규모·task·split.** 구판은 static scene이며 잘못된 rendering setting으로 normal map이 틀렸다고 명시한다. 신판은 보행자·차량이 움직이는 6개 driving sequence다. 각 sequence는 front camera, 1920×1280, 100프레임·10fps이며 training light 하나와 test light 네 개를 제공한다. 기본 평가는 0~50프레임을 960×640에서 사용하고 10·20·30·40·50을 학습에서 제외하며 non-sky 영역을 채점한다. night light는 0~50프레임이다. 이는 장면 재구성과 relighting 평가이며 독립 장소 일반화 split과 같지 않다.

**Annotation·입력 경계.** normal은 camera-space에서 z를 반전해 저장하고 loader가 복원한다. `gt_sky_mask`는 평가용이고 학습에는 SegFormer sky mask를 사용한다. `lidar`는 실제 LiDAR 시뮬레이션이 아니라 front-camera GT depth를 매 4번째 pixel에서 역투영한 자료다. 따라서 센서 noise·occlusion이 있는 실측 LiDAR와 동등하게 취급할 수 없다. [배포자 규약](https://huggingface.co/datasets/Shigon/BRDFusion_data/blob/595e2b6d2a70bc0c94fac6147740aa1b72198021/README.md)

**License·bias·호환성.** HF card의 license는 `other`이며 합성 asset 전체의 재사용 조건을 이번에 확정하지 못했다. HDRI의 CC0 설명만으로 전체 scene을 CC0로 간주하지 않는다. 소수 합성 장면·front view·동일 geometry의 조명 변형에 집중돼 있다. 검색에 남은 구 GitHub 설명은 static path와 shifted path 구조를 사용하므로 새 `synthetic_s*` 경로와 자동 호환된다고 가정하지 않는다. [공식 코드 저장소](https://github.com/shigon255/BRDFusion)

**진단 → 가설 → 최소 실험 — 제안.** 구판 대비 점수 변화에는 normal correction, static→dynamic 교체, lighting·입력 정책 변화가 섞일 수 있다. 우선 한 장면의 좌표계·z 부호·depth 유효 영역을 검증하고, loader에 평가용 mask·test frame·GT depth가 학습 입력으로 섞이지 않는지 검사한다. normal correction 효과만 주장하려면 같은 geometry·camera·light를 유지한 구/신 normal 쌍이 필요하다. 그런 쌍이 없으면 분리 불가로 기록한다.

**GO:** 좌표계·manifest·입력 whitelist 감사. **KILL:** 신판 점수를 구판 표와 바로 비교해 모델 향상으로 해석하기. 두 버전은 **not strictly apples-to-apples**다. normal 오류 크기나 점수 영향은 독립 측정하지 않았다.

## 2. Synthetic Fine Print — 두 문서의 정답 충돌 수정부터 감사한다

**확인 사실·revision.** 현재 card revision은 `174194cf84585fddf2ca9e0f3ea11fd456a1a8e5`지만 최신 두 commit은 suite 링크 추가다. 실제 수정은 `4c389341757e3d59a6bf8710046d9be0fd76bc4f`의 11/25 15:23:47 UTC 변경이다. 직전 `33707f90b3f36c2d64c6f63f396ac69d1f391fc7`와 현재 JSONL을 ID 기준으로 비교하면 변경 record는 `fp-0021`, `fp-0091`이다. 현재 두 record의 본문 payment term과 fine-print payment clause는 모두 수령 즉시 결제로 맞는다. [현재 metadata](https://huggingface.co/datasets/hyperbots-inc/synthetic-fine-print/resolve/174194cf84585fddf2ca9e0f3ea11fd456a1a8e5/data/test/metadata.jsonl), [수정 전 metadata](https://huggingface.co/datasets/hyperbots-inc/synthetic-fine-print/resolve/33707f90b3f36c2d64c6f63f396ac69d1f391fc7/data/test/metadata.jsonl)

**직접 수행한 최소 audit.** 현재 JSONL은 100행, QA 392개, 중복 ID 그룹 0이다. size level은 small 40·tiny 30·micro 30행이다. 이 결과는 metadata 내부 집계이며 JPEG의 실제 text·bbox·가독성 검증은 아니다. 이미지·generator 수정까지 전수 diff한 것은 아니다.

**배포자 보고 — task·split·license·bias.** 1240×1754 문서의 작은 약관을 읽는 OCR·document QA용 test set이다. 데이터는 CC BY 4.0, generator는 MIT로 안내한다. 고정 template의 영문 clean render이고 약관은 항상 하단 근처다. 배포자는 학습용으로 쓰지 말 것을 권고한다. class별 QA 수와 document별 QA 수가 같지 않아 단순 QA micro 평균은 자주 등장하는 clause의 영향을 더 받는다. [고정 card·changelog](https://huggingface.co/datasets/hyperbots-inc/synthetic-fine-print/blob/174194cf84585fddf2ca9e0f3ea11fd456a1a8e5/README.md)

**진단 → 가설 → 최소 실험 — 제안.** 작은 글자 인식 실패, 문서 내부의 정답 충돌, reading order, 숫자 normalization을 구분한다. 변경된 두 페이지는 이미지와 정답이 함께 달라질 수 있어 구판 frozen prediction의 재채점만으로 수정 효과 전체를 설명하지 못한다. 먼저 구/신 JPEG·metadata hash를 대응시키고, 같은 모델·prompt·해상도·입력 budget으로 수정 페이지를 다시 추론한다. 나머지 페이지는 고정 대조군으로 유지한다.

입력은 image와 question만 허용하고 `ocr_text`, `labels`, `fine_print`, `clauses`, QA answer를 전달하지 않는다. full page와 약관 crop은 별도 조건으로 비교하고, size level·clause type·column crossing별 결과를 낸다. 복합 답변은 숫자와 기간을 모두 채점한다. crop의 추가 pixel 비용도 기록한다.

**GO:** 두 수정 문서의 image–label 정합성 검사와 입력 whitelist. **KILL:** 제공된 정답 OCR을 모델 입력에 넣고 image-only 성능으로 보고하기. 실제 leakage나 OCR 성능 저하는 이번에 측정하지 않았다.

## 3. Time-Lapse Artifacts — OOD source와 파생 window를 같은 그룹으로 묶는다

**확인 사실·시점.** 고정 revision은 `2ec2ff325edffc171e942148c8123b00940f7a32`다. 11/26 media·manifest 업로드가 있었으며 v2.1.0 manifest/card commit은 `7f1808a998d97030dee6c8c5bb0b2c1887a9465c`, 23:00:37 UTC다. 2012~2014는 촬영 시기이고 2026년 배포 시기와 다르다. 11/27 최신 commit은 LICENSE와 추가 허용 문서를 분리했다. [고정 card](https://huggingface.co/datasets/maxwellinked/time-lapse-artifacts/blob/2ec2ff325edffc171e942148c8123b00940f7a32/README.md)

**직접 확인한 규모·artifact.** 공개 CSV를 읽으면 take manifest 50행, physical reference 46행, RT window 150행이다. 첫 window의 `duration_seconds`는 60.093367로, 카드의 “60초”는 byte-level로 모두 정확히 60.0초라는 의미가 아니다. 영상 decoding이나 checksum 재계산은 수행하지 않았다. [take CSV](https://huggingface.co/datasets/maxwellinked/time-lapse-artifacts/resolve/2ec2ff325edffc171e942148c8123b00940f7a32/Manifests/ood_2012_2014_takes_v21.csv), [reference CSV](https://huggingface.co/datasets/maxwellinked/time-lapse-artifacts/resolve/2ec2ff325edffc171e942148c8123b00940f7a32/Manifests/ood_2012_2014_physical_refs_v21.csv), [window CSV](https://huggingface.co/datasets/maxwellinked/time-lapse-artifacts/resolve/2ec2ff325edffc171e942148c8123b00940f7a32/Manifests/ood_2012_2014_rt_windows_v21.csv)

**배포자 보고 — task·split·bias.** 단일 작가의 과정·temporal understanding·forensics 연구 자료다. 기존 canonical baseline은 1,388개 recording·442개 작품이고 신판 OOD는 historical take와 실시간 window·reference를 추가한다. canonical card의 `archive`는 train/test 구분이 아니며, 파생 저장소는 work-ID 분리 benchmark split을 안내한다. OOD cohort는 sensor·연도·interlacing·pixel aspect·recording mode가 함께 바뀌므로 내용 일반화와 acquisition shift가 혼재한다.

**권리 정책 — 원문 확인.** 영상은 CC BY-NC 4.0, 비복원 metadata·manifest는 CC BY 4.0, tools는 MIT로 나눈다. 별도 CC+ 문서는 공개 출판을 전제로 한 분석·평가 연구의 추가 허용을 명시하고 generative training·adapter·distillation 등을 그 추가 허용 밖에 둔다. 원문은 기본 CC 권리를 좁히거나 변경하지 않는다고 명시한다. 따라서 “모든 학습 금지” 또는 “기업 R&D면 모든 용도 허용”으로 단순화하지 않는다. 이는 배포자가 게시한 조건의 요약이며 독립 법률 판단이 아니다. [LICENSE](https://huggingface.co/datasets/maxwellinked/time-lapse-artifacts/blob/2ec2ff325edffc171e942148c8123b00940f7a32/LICENSE), [ADDITIONAL_PERMISSIONS](https://huggingface.co/datasets/maxwellinked/time-lapse-artifacts/blob/2ec2ff325edffc171e942148c8123b00940f7a32/ADDITIONAL_PERMISSIONS.md)

**진단 → 가설 → 최소 실험 — 제안.** 동일 take의 RT window·TL proxy·reference를 독립 sample로 무작위 split하면 identity 단서가 공유될 수 있다. 먼저 `work_id → record_id → window_id` join과 split 교집합을 검사하고 같은 작품의 모든 파생물을 한 그룹으로 묶는다. 그 다음 frozen encoder로 원본과 aspect-corrected/deinterlaced 입력을 비교한다. acquisition 처리를 바꿨을 때만 회복되는 오류와 처리 후에도 남는 오류를 분리한다. RT와 TL의 재생 시간·sampling rate를 맞추지 않은 temporal 점수는 **not strictly apples-to-apples**다.

**GO:** identity join·split·권리 tier 감사. **KILL:** 단일 작가·선별 OOD를 일반적 human-versus-synthetic 탐지 benchmark로 확대 해석하기. 실제 중복률·identity overlap·OOD 성능은 독립 측정하지 않았다.

## 오늘의 우선순위와 검증 한계

1. **우선 GO — Fine Print:** 바뀐 두 문서의 JPEG와 정답을 짝지어 검사하고 image-only 입력을 고정한다.
2. **다음 GO — BRDFusion:** normal 부호·평가 mask·GT depth 입력 경계를 확인한 뒤 장면 교체 효과를 분리한다.
3. **조건부 GO — Time-Lapse:** work/take/window 단위 split과 acquisition shift를 통제한다.
4. **KILL — 날짜 착시:** 최근 소개 기사나 suite 링크 수정만으로 신규 dataset release를 만들지 않는다.

이번 실행은 공식 텍스트·이력·소형 JSONL/CSV 조회와 metadata 감사까지 수행했다. 대형 ZIP·영상 다운로드, 이미지 전수 시각 검사, loader·evaluator·모델 실행, near-duplicate 검사, 학습은 하지 않았다. 제안 실험의 GPU·시간·비용은 미측정이다. 후속 비교는 backbone, pretraining/data, split, resolution, hardware, precision, batch, TTA, evaluator와 annotation revision을 함께 고정·기록해야 한다.
