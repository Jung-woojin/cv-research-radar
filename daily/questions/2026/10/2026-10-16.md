## Q1. 정답을 유지한 채 인용 증거를 지웠을 때 성능이 무너지지 않는다면, evidence-grounded reasoning은 실제로 증거를 사용한 것인가?

**직접 근거:** [Open-o3-Video-v2 논문](https://arxiv.org/abs/2610.17656) · [공식 프로젝트](https://msalab-pku.github.io/projects/Open-o3-Video-v2)

### 1. 문제 정의

영상 VLM이 제시한 timestamp·bounding box가 정답을 실제로 유발한 원인인지, 정답을 이미 언어 prior로 결정한 뒤 그럴듯한 증거를 붙인 것인지 판별한다. cited evidence 삭제·교체·시간 이동을 가한 counterfactual intervention으로 **answer–evidence causal dependence**를 측정한다.

### 2. 왜 지금 가치가 있는가

Open-o3-Video-v2는 seek–ground–reason을 하나의 trajectory로 통합했지만, 정답 정확도와 근거의 인과적 사용은 동일하지 않다. 안전·감시·해양 영상에서는 박스가 그럴듯한 것보다, 해당 장면이 없으면 결론도 바뀌는지가 더 중요하다.

### 3. Observation과 Gap

- **확인된 사실:** 4B 모델은 V-STaR에서 40.4% mAM, 56.3% mLGM을 기록했고 Qwen3-VL-4B보다 각각 8.5점, 12.6점 높았다.
- **확인된 사실:** 저자의 LVBench 오답 분석에서 약 43%는 temporal evidence retrieval/event selection, 27%는 object grounding/fine-grained perception, 6%는 knowledge 관련이었다.
- **확인된 사실:** 학습 trajectory는 tool call, 반환 frame, timestamp, object box, answer를 함께 포함한다.
- **Gap:** 답이 맞은 표본에서 인용 frame/box를 제거하거나 정답과 무관한 evidence로 바꿨을 때 답과 confidence가 얼마나 변하는지 보고되지 않았다.

### 4. 핵심 가설

진짜 evidence-grounded 표본은 cited evidence를 제거하면 정답 확률이 크게 낮아지고, 같은 길이의 무관 clip로 교체하면 근거 일관성도 함께 무너진다. 답은 유지되는데 근거만 바뀌는 표본은 post-hoc rationalization일 가능성이 높다.

### 5. 최소 실험(MVP)

V-STaR 또는 접근 가능한 100개 표본에서 네 조건을 동일 decode 설정으로 비교한다: 원본, cited interval mask, 시간 이동 interval, 동일 객체의 다른 instance box.

- **GO:** 정답 표본의 60% 이상에서 cited-evidence mask가 정답 log-probability를 유의하게 낮추고, 무관 evidence보다 원본 evidence의 consistency가 10%p 이상 높음.
- **KILL:** mask·swap 후에도 답과 confidence가 거의 변하지 않거나, 변화가 random-frame mask와 구분되지 않음.

### 6. baseline과 dataset

Open-o3-Video-v2-4B 또는 공개 checkpoint, Qwen3-VL-4B, V-STaR/Charades-TimeLens의 공개 가능한 subset, random evidence·nearest-time evidence·oracle evidence baseline.

### 7. 성공·실패 판정 metric

Answer flip rate, Δlog-probability, evidence sufficiency/comprehensiveness, grounding IoU, timestamp IoU, answer–grounding consistency, intervention별 calibration error.

### 8. compute 난이도

**2.5/5.** 공개 checkpoint inference와 100개 counterfactual 재실행이 중심이며 재학습은 필요 없다.

### 9. novelty 위험요인

NLP rationale faithfulness와 겹칠 수 있다. novelty는 **영상의 시간·공간 증거를 직접 조작**하고 answer, timestamp, box를 공동 평가하는 데 둬야 한다.

### 10. 4~8주 내 논문화 가능성

2주에 intervention harness, 4주에 3개 evidence perturbation, 6주에 일반 video VLM 비교, 8주에 maritime incident clip로 외부 검증이 가능하다.

### 11. negative result의 가치

대부분의 답이 evidence 삭제에 둔감하면 현재 grounded trace가 설명 가능성은 높여도 인과적 신뢰성을 보장하지 못한다는 명확한 진단 결과가 된다.

**평가:** Novelty **4.5/5** · Feasibility **4/5** · Compute efficiency **4/5** · Publication potential **4.5/5**

## Q2. “한 번 더 관찰할지”를 불확실성으로 결정하면 city-scale grounding의 같은 종류 distractor 실패를 줄일 수 있는가?

**직접 근거:** [Urbex 논문](https://arxiv.org/abs/2610.18356) · [공식 코드](https://github.com/AMAP-ML/Urbex)

### 1. 문제 정의

active spatial search agent가 첫 zoom/oblique view 뒤 바로 box를 확정하지 않고, same-class 후보 간 margin이 작을 때만 추가 view나 crop을 요청하는 **uncertainty-triggered verification** 정책을 설계한다.

### 2. 왜 지금 가치가 있는가

도시·항공·해양 장면은 차량, 건물, 선박처럼 같은 종류 객체가 조밀하게 반복된다. 더 많은 turn을 항상 허용하면 latency가 늘고, 무조건 멈추면 잘못된 행·구역에 box를 확정한다.

### 3. Observation과 Gap

- **확인된 사실:** 도구가 없는 전역 map 조건은 Hit@3 10.5, 2D IoU 2.1이었고 zoom+landmark+oblique 8-turn 조건은 36.9와 14.6이었다.
- **확인된 사실:** 7-turn은 Hit@3 34.8/IoU 11.0, 9-turn은 36.8/13.2로 8-turn보다 더 낫지 않았다.
- **확인된 사실:** 저자 failure trajectory에는 target을 crop 밖으로 제외하는 search failure와, target이 보이지만 다른 parking row를 고르는 disambiguation failure가 모두 존재한다.
- **저자 제한:** distractor bin별 sample count와 error bar가 없어 밀도와 실패의 인과효과는 확인되지 않았다.
- **Gap:** turn budget을 고정하지 않고 uncertainty와 예상 정보이득으로 재관찰을 결정하는 비교가 없다.

### 4. 핵심 가설

same-class 후보의 box-score margin, view 간 위치 일치도, landmark relation 충돌을 결합한 uncertainty가 높을 때만 추가 oblique view를 요청하면 고밀도 subset Hit@1을 높이면서 평균 tool call은 유지할 수 있다.

### 5. 최소 실험(MVP)

CityRefer의 150개 query를 distractor 수와 target–landmark 거리로 층화한다. fixed 7/8/9-turn, confidence threshold, learned stop classifier를 같은 최대 9-turn 아래 비교한다.

- **GO:** dense subset Hit@1 +5%p, 평균 call 증가 ≤0.5, 전체 latency 증가 ≤15%.
- **KILL:** uncertainty AUROC가 0.65 미만이거나, 재관찰이 search miss를 복구하지 못하고 잘못된 후보만 강화함.

### 6. baseline과 dataset

CityRefer NO/ND, Urbex 공개 policy, fixed-turn baselines, entropy/margin heuristic, oracle stop. 후속에는 STPLS3D-Refer와 항공·항만 객체를 사용한다.

### 7. 성공·실패 판정 metric

Hit@1/3, BEV IoU, dense-bin worst-group, search-miss/disambiguation error, expected calibration error, 평균 call 수, wall-clock latency.

### 8. compute 난이도

**2.5/5.** 기존 trajectory replay와 작은 stop classifier가 중심이다.

### 9. novelty 위험요인

일반적인 early exit로 보일 수 있다. **공간 검색 단계별 실패 taxonomy와 view-specific information gain**을 함께 제시해야 한다.

### 10. 4~8주 내 논문화 가능성

2주에 error taxonomy·confidence 추출, 4주에 heuristic stop, 6주에 learned stop, 8주에 항만/선박 scene transfer가 가능하다.

### 11. negative result의 가치

uncertainty가 실패를 예측하지 못하면 현재 agent score가 calibration되지 않았거나, 실패가 observation 부족보다 region proposal 오류에서 발생한다는 경계가 선명해진다.

**평가:** Novelty **4/5** · Feasibility **4/5** · Compute efficiency **4/5** · Publication potential **4/5**

## Q3. 작은 VLM에는 더 많은 프레임이 오히려 방해가 되는가, 그리고 모델 용량에 맞춰 frame budget을 자동 조절할 수 있는가?

**직접 근거:** [FramePack-U 논문](https://arxiv.org/abs/2610.16118) · [공식 프로젝트](https://zeld0n.github.io/framepack-U/)

### 1. 문제 정의

고정 token budget 안에서도 packed frame 수와 frame당 해상도를 조절해, 모델 용량별로 최적의 **temporal breadth–spatial detail** 지점을 찾는다. 단순히 많은 프레임을 pack하는 정책과 capacity-aware controller를 비교한다.

### 2. 왜 지금 가치가 있는가

constant memory는 입력 길이 폭증을 막지만, 작은 모델이 많은 관찰을 통합할 수 있다는 뜻은 아니다. 장기 영상에서 작은 VLM은 distractor와 저해상도 detail 때문에 오히려 성능이 불안정할 수 있다.

### 3. Observation과 Gap

- **확인된 사실:** 저자는 Qwen3.5-35B-A3B, 128-frame budget에서 공식 모델 대비 LongVideoBench +12.9점, MLVU +10.6점, Video-MME +9.7점을 보고했다.
- **저자 제한:** 더 큰 memory budget에서 작은 모델은 늘어난 visual observation을 통합하지 못해 gain이 불안정할 수 있다.
- **확인된 사실:** 3600초 영상에서 FramePack-U는 최대 3600 frame을 decode하지만 vanilla 27B는 메모리 제한으로 224 frame만 decode한다. 따라서 해당 end-to-end latency는 strictly apples-to-apples하지 않다.
- **Gap:** 질문 난이도·모델 크기·객체 크기를 보고 packed frame 수를 동적으로 선택하는 controller가 없다.

### 4. 핵심 가설

작은 모델에서는 semantic similarity가 낮은 후보를 더 넣는 순간 성능이 하락하며, query entropy와 selected-frame redundancy로 budget을 줄이는 controller가 fixed maximum packing보다 정확도/지연 Pareto를 개선한다.

### 5. 최소 실험(MVP)

1개 4B/7B급 VLM과 LongVideoBench 100개 subset에서 32/64/128-frame equivalent token budget을 만든다. frame 수·해상도 조합과 query-conditioned budget predictor를 비교한다.

- **GO:** controller가 fixed-128 대비 정확도 손실 없이 decode frame 30% 이상 감소하거나, 같은 decode cost에서 정확도 +3%p.
- **KILL:** 최적 budget이 query/모델과 무관하게 항상 최대값이거나 controller overhead가 절감 latency를 상쇄함.

### 6. baseline과 dataset

FramePack-U, uniform sampling, CLIP top-k, diversity-only, LongVideoBench/MLVU 공개 subset. 모든 latency 비교는 동일 decoded-frame 수와 storage 조건을 별도로 보고한다.

### 7. 성공·실패 판정 metric

Accuracy, long-duration bin accuracy, small-object subset, decoded frames, visual tokens, peak VRAM, preprocessing/VLM/end-to-end latency, energy proxy.

### 8. compute 난이도

**3/5.** 학습 없이 sweep 가능하지만 장기 영상 decode I/O가 필요하다. 8GB GPU에서는 4B quantized model과 100개 subset으로 제한한다.

### 9. novelty 위험요인

adaptive frame selection 연구와 겹친다. novelty는 **고정 token 예산 안의 frame 수–해상도–모델 용량 상호작용**과 동일 I/O 회계에 둔다.

### 10. 4~8주 내 논문화 가능성

2주에 sweep, 4주에 capacity curve, 6주에 controller, 8주에 small-object/해양 장기 영상 외부 검증이 가능하다.

### 11. negative result의 가치

작은 모델에서도 최대 frame이 항상 유리하면 병목은 integration capacity가 아니라 selection 품질이며, controller보다 better ranking에 집중해야 한다는 결론이 남는다.

**평가:** Novelty **4/5** · Feasibility **3.5/5** · Compute efficiency **3.5/5** · Publication potential **4/5**

## Q4. patch permutation으로 고해상도 생성 metric의 “전역 배치 맹점”을 자동 측정할 수 있는가?

**직접 근거:** [AReA 논문](https://arxiv.org/abs/2610.17227) · [공식 프로젝트](https://kooroshrh.github.io/area/)

### 1. 문제 정의

같은 local texture를 유지하면서 큰 영역의 위치·순서·중복만 바꾸는 counterfactual image를 만들고, Aesthetic·CLIP·ImageReward·PickScore·FID가 전역 layout 파괴에 얼마나 민감한지 측정한다.

### 2. 왜 지금 가치가 있는가

고해상도 diffusion은 local quality가 높아도 신체·건물·텍스트의 전역 구조가 깨질 수 있다. metric이 local texture에 치우치면 사용할 수 없는 결과가 높은 점수로 선택되어 방법 비교가 왜곡된다.

### 3. Observation과 Gap

- **확인된 사실:** AReA의 fixed window size 64 ablation은 inconsistent region으로 분해되어 저자가 unusable하다고 평가했지만 Aesthetic와 CLIP은 여전히 높았다.
- **확인된 사실:** global-KV bridge 제거는 subject duplication을 만들었고, 대부분 metric 변화는 작았지만 FID는 148.5에서 161.3으로 악화됐다.
- **확인된 사실:** 저자는 fixed-window 실패가 ImageReward·PickScore·FID에서 더 잘 드러난다고 설명한다.
- **Gap:** metric마다 어떤 종류의 전역 오류에 반응하는지 통제된 stress test와 human failure label로 검증되지 않았다.

### 4. 핵심 가설

block permutation, subject duplication, long-range seam, count violation을 독립적으로 주입한 stress suite에서 Aesthetic/CLIP은 낮은 sensitivity를 보이고, relation-aware VLM judge+FID 계열 ensemble은 human unusable 판정과 더 잘 일치한다.

### 5. 최소 실험(MVP)

Aesthetic-4K 또는 공개 50개 image에 네 오류×세 강도를 합성한다. local patch statistics가 최대한 보존되도록 intervention하고 5개 metric과 human 3인 판정을 비교한다.

- **GO:** 제안 layout-sensitivity score의 human error AUROC ≥0.80, Aesthetic/CLIP 대비 Kendall τ +0.15.
- **KILL:** 합성 artifact 자체가 너무 쉬워 실제 fixed-window failure로 transfer되지 않거나 human agreement κ<0.5.

### 6. baseline과 dataset

Aesthetic-4K 50장, AReA 공개 example, Aesthetic, CLIP, ImageReward, PickScore, FID/FIDp, relation-aware open VLM judge.

### 7. 성공·실패 판정 metric

Perturbation sensitivity curve, human AUROC, Kendall τ, category worst-group, order-flip rate, inter-rater agreement, clean-image false-positive rate.

### 8. compute 난이도

**1.5/5.** 생성 모델 재학습 없이 image intervention과 평가만 수행한다.

### 9. novelty 위험요인

기존 metric benchmark의 축소판으로 보일 수 있다. high-resolution에서 **local quality 보존 + global layout만 파괴**하는 controlled intervention과 공개 suite가 핵심이다.

### 10. 4~8주 내 논문화 가능성

2주에 perturbation generator, 4주에 human audit, 6주에 metric ensemble, 8주에 여러 DiT 방법의 ranking 재평가가 가능하다.

### 11. negative result의 가치

기존 metric이 실제로 layout 오류에 충분히 민감하다면 AReA 사례는 특정 setting의 예외이며, 새 metric보다 protocol·sample 수 개선이 우선이라는 결론이 된다.

**평가:** Novelty **4.5/5** · Feasibility **5/5** · Compute efficiency **5/5** · Publication potential **4.5/5**

## Q5. 값싸고 검증 가능한 도구는 policy가 선택하게 하지 않고 validity gate로 자동 공급하는 편이 일반적으로 더 나은가?

**직접 근거:** [X-Ragent 논문](https://arxiv.org/abs/2610.16811)

### 1. 문제 정의

agent tool을 **선택적·비용형 evidence tool**과 **값싸고 deterministic한 measurement tool**로 분리하고, 후자는 applicability만 통과하면 자동 공급하는 hybrid routing 원칙을 의료 밖의 시각 agent에도 검증한다.

### 2. 왜 지금 가치가 있는가

learned router는 유용한 도구를 누락할 수 있고, 모든 도구를 항상 켜면 비용과 distraction이 늘어난다. 선박 거리·heading·pixel size처럼 조건만 맞으면 안정적으로 계산되는 신호는 semantic search와 다른 정책이 필요하다.

### 3. Observation과 Gap

- **확인된 사실:** ChestAgentBench에서 learned routing은 71.7%, 모든 auxiliary tool을 항상 호출하면 71.0%였고 learned policy는 질문의 53.2%에서만 tool을 호출했다.
- **확인된 사실:** 독립 validity gate는 ChestAgent/CheXbench 71.7/77.3, measurement까지 policy가 route하면 71.0/76.1이었다.
- **확인된 사실:** 모든 evidence module 제거는 67.4였고, measurement 제거는 70.8이었다.
- **저자 해석:** policy routing은 조건이 맞아 유용한 measurement도 누락할 수 있다.
- **Gap:** 이 분리가 medical-specific heuristic인지, 도구의 비용·검증가능성·실패위험으로 일반화되는 설계 원칙인지 미확인이다.

### 4. 핵심 가설

tool의 deterministic verifiability와 marginal cost가 높을수록 policy routing이 유리하고, 검증 가능하며 싼 tool은 independent applicability gate가 더 높은 recall과 calibration을 제공한다.

### 5. 최소 실험(MVP)

maritime image QA 또는 synthetic vessel scene에서 crop/knowledge search는 policy-routed, pixel-length·horizon·bearing proxy는 validity-gated로 둔다. all-off, all-on, all-policy, hybrid 네 조건을 비교한다.

- **GO:** hybrid가 all-policy보다 accuracy +2%p 또는 measurement omission 50% 감소, all-on보다 평균 tool cost 30% 감소.
- **KILL:** validity gate false admission이 5%를 넘거나, 자동 measurement가 language reasoning을 오히려 편향함.

### 6. baseline과 dataset

X-Ragent 공개 ablation 재현 가능 subset, synthetic maritime QA 200개, rule-based applicability, learned router, static all-tools, no-tools baseline.

### 7. 성공·실패 판정 metric

Answer accuracy, tool precision/recall, omission/false-admission rate, calibration, calls/query, latency, cost-weighted utility, domain worst-group.

### 8. compute 난이도

**2/5.** 작은 synthetic benchmark와 inference routing 실험으로 시작할 수 있다.

### 9. novelty 위험요인

의료 agent 설계의 단순 도메인 전이로 보일 수 있다. **tool taxonomy와 routing decision rule을 여러 도메인에서 검증**해야 일반 연구 기여가 된다.

### 10. 4~8주 내 논문화 가능성

2주에 tool taxonomy·maritime simulator, 4주에 4-way routing ablation, 6주에 두 번째 도메인, 8주에 cost/validity Pareto 분석이 가능하다.

### 11. negative result의 가치

hybrid가 이득이 없으면 measurement 자체가 deterministic이어도 해석은 semantic context에 의존하며, 자동 공급보다 joint uncertainty가 필요하다는 결과가 된다.

**평가:** Novelty **4.5/5** · Feasibility **4.5/5** · Compute efficiency **4.5/5** · Publication potential **4.5/5**

## Q6. 점진적 경계와 반복 행동에서 event hierarchy의 불확실성을 직접 예측하면 temporal grounding이 더 안정적인가?

**직접 근거:** [EventLens 논문](https://arxiv.org/abs/2610.16172) · [공식 프로젝트](https://lostgreen.github.io/EventLens/)

### 1. 문제 정의

event boundary를 단일 timestamp/interval로 강제하지 않고 phase–event–action 계층별 boundary distribution과 “ambiguous transition” label을 예측한다. 반복 행동은 appearance 대신 앞뒤 context로 instance를 구분한다.

### 2. 왜 지금 가치가 있는가

실제 영상의 사건은 명확히 끊기지 않는다. 항만 진입, 접안, 하역처럼 점진적 변화가 겹치며 동일 행동이 반복된다. 단일 hard boundary supervision은 annotation noise와 모델 오류를 구분하지 못한다.

### 3. Observation과 Gap

- **확인된 사실:** EventLens는 event segmentation, progression, multi-event relation의 세 task family를 deterministic reward로 학습한다.
- **확인된 사실:** 4B에서 VinoGround는 base 37.0에서 45.0으로 올랐지만, broad QA의 MVBench는 62.55에서 63.90으로 변화가 작고 SFT baseline 64.70보다 낮았다.
- **확인된 사실:** 저자는 점진적 visual state, 고수준 activity가 여러 fine action을 덮는 경우, visually similar repeated action을 남은 실패로 명시했다.
- **확인된 사실:** 20% timestamp perturbation에서도 6개 metric이 base보다 높았지만, 해당 실험은 100-step pilot이었다.
- **Gap:** boundary ambiguity를 오류로만 취급하지 않고 distribution·hierarchy로 모델링한 calibration 실험이 없다.

### 4. 핵심 가설

soft boundary distribution과 hierarchy consistency loss는 hard interval보다 gradual-transition subset의 mIoU와 calibration을 높이고, context-aware instance ID는 repeated-action order 오류를 줄인다.

### 5. 최소 실험(MVP)

TimeLens/E.T. Bench에서 100개 clip을 clear/gradual/repeated로 수동 분류한다. hard boundary, Gaussian soft label, hierarchy-consistent label, context-aware repeated-event head를 비교한다.

- **GO:** gradual subset mIoU +5점, boundary ECE 20% 감소, repeated-action accuracy +5%p, clear subset 손실 ≤1%p.
- **KILL:** soft label이 경계를 과도하게 넓혀 overall IoU를 낮추거나 human boundary agreement 자체가 너무 낮아 target을 정의할 수 없음.

### 6. baseline과 dataset

EventLens/Qwen3-VL-4B 공개 설정, TimeLens-100K/E.T. Bench의 접근 가능한 subset, hard interval, label smoothing, multi-scale hierarchy baseline.

### 7. 성공·실패 판정 metric

mIoU, Recall@0.5, boundary calibration error, interval width calibration, repeated-event order accuracy, clear/gradual worst-group, human agreement.

### 8. compute 난이도

**3.5/5.** full RL 대신 frozen feature 또는 LoRA로 시작하면 8GB 근처에서도 작은 subset 실험이 가능하지만 시간축 입력 때문에 비용이 있다.

### 9. novelty 위험요인

temporal action localization의 soft boundary 연구와 겹칠 수 있다. VLM event reasoning에서 **hierarchy, repeated instance, calibration을 공동 평가**해야 한다.

### 10. 4~8주 내 논문화 가능성

2주에 100-clip taxonomy, 4주에 soft boundary, 6주에 hierarchy consistency, 8주에 반복 행동·maritime narrative 전이가 가능하다.

### 11. negative result의 가치

soft hierarchy가 이득이 없으면 병목은 annotation granularity가 아니라 visual state representation 또는 장기 memory이며, EventLens teacher objective를 바꿔야 한다는 결론이 남는다.

**평가:** Novelty **4.5/5** · Feasibility **3.5/5** · Compute efficiency **3.5/5** · Publication potential **4.5/5**

## 증거와 제한

- 모든 수치는 저자 원문 결과이며 이번 레이더가 모델을 실행해 재현한 값이 아니다.
- Open-o3-Video-v2의 오답 비율은 LVBench incorrect prediction 내부 분류이며 전체 dataset의 실패율이 아니다.
- Urbex의 distractor·거리 bin에는 표본 수와 error bar가 없어 인과효과로 해석하지 않았다.
- FramePack-U의 3600-frame 대 224-frame latency는 decoded input 수가 달라 strictly apples-to-apples하지 않다.
- AReA의 “unusable”은 저자 정성 판정이다. Q4는 이를 human annotation으로 검증하려는 제안이다.
- X-Ragent는 의료 영상 결과이므로 maritime/tool-agent 일반화는 아직 추론이다.
- EventLens의 13시간 대 37시간 비교는 student stage 기준이며 teacher training과 teacher query 비용을 포함하지 않는다.
- GO/KILL 문턱과 연구 점수는 측정값이 아니라 실행 가능한 우선순위 기준이다.
