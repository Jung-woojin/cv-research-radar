## 2. 재난 피해 분류: 사건이 바뀌면 GFM 표현의 성능이 무너진다

### 실패 조건

같은 재난 사건의 이미지가 학습과 평가에 함께 들어가는 무작위 이미지 분할에서는 높은 성능이 나오지만, 평가 사건을 통째로 제외하는 leave-one-event-out(LOEO)에서는 성능이 크게 하락한다.

### 모델·데이터·설정

- **모델:** TerraMind, Prithvi-EO-2.0, DOFA, DINOv3 임베딩과 선형 분류기.
- **데이터:** xView2 `9,168`개 사전/사후 영상 쌍·19개 사건, BRIGHT `3,029`개 쌍·11개 사건.
- **평가:** 무작위 damage-stratified split과 LOEO를 비교하고, 메타데이터·건물 수·사전/사후 영상 셔플·표현 변환을 감사했다.
- Prithvi는 원래 다중분광 입력 대신 표시용 RGB를 HLS 범위에 맞춰 사용한 out-of-domain 설정임을 저자가 명시했다.

### 확인된 사실

- xView2 평균 balanced accuracy: `0.807 → 0.638`.
- BRIGHT 평균 balanced accuracy: `0.818 → 0.568`.
- 영상 없이 사건 ID와 사건별 클래스 사전확률만 쓴 AUC가 xView2 `0.821`, BRIGHT `0.715`였다.
- 건물 수만 사용한 balanced accuracy도 xView2 `0.629`, BRIGHT `0.653`이었다.
- xView2에서 정상 사전/사후 쌍 `0.638`, 사후 영상을 섞은 쌍 `0.617`.
- BRIGHT에서 정상 쌍 `0.568`, 섞은 쌍 `0.552`, 사전 영상만 사용한 설정 `0.571`이었다.
- 원천 사건으로 학습한 PCA와 SupCon은 일부 개선했지만, cross-event SupCon이 일관되게 우월하지 않았다. xView2 raw/PCA/SupCon balanced accuracy는 `0.638/0.654/0.664`, BRIGHT는 `0.568/0.594`였다.

저자들은 재난 ID, 건물 밀도, 배경 문맥을 shortcut으로 지목하고 무작위 분할 성능이 미지 사건 일반화를 과대평가한다고 결론 내렸다. [공식 논문](https://arxiv.org/abs/2610.13766)과 [공식 코드](https://github.com/alishibli97/gfm-shortcut-learning)가 공개되어 있으며, README에는 논문과 동일 표본·분할을 만드는 명령과 감사 스크립트가 제공된다. 독립 제3자 재현은 확인하지 못했다.

### 진단 → 가설 → 최소 실험

- **진단:** 사후 변화 신호를 읽어야 하는 과제에서 사전 영상만으로도 BRIGHT 전체 쌍보다 높은 점수가 나왔다.
- **가설:** 모델은 피해 변화보다 사건 배경, 건물 밀도, 지형·센서 특성을 더 쉽게 학습한다.

## 3. 비디오 VLM: 평균 점수가 가린 방향 클래스의 완전 붕괴

### 실패 조건

카메라나 객체의 이동 방향을 묻는 최소 대조 비디오에서 특정 방향을 항상 선택해 반대 방향 recall이 `0%`가 되는 클래스 붕괴가 발생한다.

### 모델·데이터·설정

- **모델:** VideoLLaMA2, Qwen2-VL, Qwen2.5-VL, Qwen3-VL, InternVL 3.5, MiniCPM-V 4.5.
- **합성 데이터:** CARLA 비디오 `1,200`개, 6개 motion class, 클래스당 200개.
- **실영상:** 클래스당 10개, 총 60개.
- **입력 예산:** 일부 모델은 8프레임, Qwen 계열은 10초 영상당 약 20프레임을 사용해 모델 간 직접 비교에는 입력 예산 차이가 남는다.

### 확인된 사실

- 표준 프롬프트에서 여섯 모델 모두 `forward 100% / backward 0%`.
- Qwen2-VL과 Qwen2.5-VL은 `left 100% / right 0%`.
- InternVL 3.5의 left/right 평균은 `67%`지만 클래스별 recall은 `39%/95%`였다.
- 합성-실영상 클래스별 상관은 `r=0.957`이었으나, 저자도 작은 실영상 표본과 공통 붕괴 패턴이 상관을 부풀릴 수 있다고 경고했다.
- action-pair 400개 비디오의 80/20 분할, LoRA rank 16, 3 epoch 적응으로 여러 과제에서 거의 완전한 점수가 나왔다.
- 단일 프레임·프레임 순서 셔플 대조군은 보고되지 않았다.

### 공식 인정·재현 근거

저자는 높은 LoRA·probe 정확도가 진짜 시간 단서를 사용했다는 증거가 아니며, 공개 벤치마크가 방향별 붕괴를 숨길 수 있다고 명시했다. [공식 논문](https://arxiv.org/abs/2610.12575)은 확인했으나 공식 코드와 독립 재현은 확인하지 못했다.

### 진단 → 가설 → 최소 실험

- **진단:** 이진 방향 쌍의 평균 정확도는 50%처럼 보이지만 한 클래스는 완전히 실패한다.
- **가설:** 언어 prior, 시작·끝 프레임 편향, 샘플링 순서가 실제 optical flow보다 강한 신호다.
- **최소 실험:** 동일 동영상에 `정방향 / 역재생 / 프레임 셔플 / 첫 프레임 반복 / 마지막 프레임 반복`을 적용하고 클래스별 recall과 예측 반전율을 기록한다.  
  **GO:** 역재생 시 정답이 `≥80%` 반전되고, 셔플·반복 입력에서 성능이 chance 수준으로 하락.  
  **KILL:** 역재생에도 예측이 유지되거나 한 방향 recall이 `≤20%`이면 temporal reasoning 주장 대신 prior 교정·프레임 샘플링 연구로 전환한다.

## 4. SquintBench: 고주파 텍스트는 모델보다 입력 경로가 먼저 실패한다

### 실패 조건

문자가 배경에 정상적으로 섞여 있어 사람이 눈을 가늘게 뜨거나 축소하면 더 잘 읽을 수 있는 이미지에서, 범용 MLLM은 원본 고해상도 입력의 숨은 텍스트를 거의 읽지 못한다.

### 모델·데이터·설정

- **운영 데이터:** 프로덕션 moderation 이미지 `1,076`개. 접근 승인이 필요한 gated portion이 포함된다.
- **통제 데이터:** presence 500쌍, 중국어 glyph 500쌍, Latin glyph 500쌍, strength 200 scene, open-vocabulary read 200개.
- **방법:** Qwen3.5-9B 기반 OPSD와 원본 입력, 추가 `1/8` 축소 view, 저역통과 입력, glyph-token replacement를 비교했다.

### 확인된 사실

- 원본 SquintBench에서 off-the-shelf MLLM의 ANLS는 `8.33–24.44`.
- Qwen3.5-9B base `26.50`, OPSD `88.61`.
- base 모델에 `1/8` 추가 view만 제공해도 `58.96`.
- 원본 token budget에서 저역통과 처리는 `26.4→39.3`, 64 token에서는 `29.2→67.0`.
- OPSD의 glyph token을 바꾸면 정확도 `90.5→71.5`; 같은 넓이의 임의 배경 token을 바꾸면 `90.5→91.0`.
- 특화 후 일반 문서 성능이 AI2D `86.66→85.33`, DocVQA `95.93→92.98`, OCRBench `879→833`으로 하락했다.

### 공식 인정·재현 근거

저자는 고주파 간섭과 spatial readout 병목을 원인으로 제시하고, 단순 축소 view도 큰 효과가 있음을 보였다. 이는 저자 해석이며 모든 모델에 대한 인과 증명은 아니다. [공식 논문](https://arxiv.org/abs/2610.13465)은 확인했지만 운영 데이터의 gated 특성과 미확인 공식 코드 때문에 재현 범위가 제한된다. 독립 재현은 확인하지 못했다.

### 진단 → 가설 → 최소 실험

- **진단:** 모델 크기보다 입력의 스케일·주파수 변환이 성능을 더 크게 바꾼다.
- **가설:** 비전 인코더의 patch/token 압축이 glyph와 배경의 국소 차이를 지우며, 저역통과·축소가 오히려 판독 가능한 전역 대비를 만든다.
- **최소 실험:** OCR이 필요한 해양 표지·계기판 이미지에 `원본 / 1/2 / 1/4 / 1/8 / Gaussian low-pass` view를 동일 token budget으로 투입하고 ANLS·latency·일반 OCR 정확도를 측정한다.  
  **GO:** 다중 스케일 view가 원본 대비 ANLS `≥15`점 개선하고 일반 OCR 하락 `≤2`점.  
  **KILL:** 개선이 특정 생성 패턴에만 나타나거나 일반 OCR 하락이 `>5`점이면 모델 특화 대신 전처리 라우터만 채택한다.

## 5. 목재 종 분류: 이미지 분할 점수와 개체 일반화 사이의 0.176 격차

### 실패 조건

같은 나무 개체에서 얻은 이미지가 학습과 평가에 함께 들어가면 높은 점수가 나오지만, tree ID를 완전히 분리하면 성능이 낮아진다. 경계 영역만으로도 높은 점수가 나와 촬영 문맥 shortcut 가능성도 남는다.

### 모델·데이터·설정

- **데이터:** 38종 `4,875`장·303개 나무; 주 분석 20종 subset은 `3,406`장·214개 나무.
- **분할:** duplicate-aware image split(B1)과 tree-ID-disjoint split(B2).
- **모델:** ConvNeXt-Tiny, frozen DINOv2 등.
- **반복:** B2는 3개 outer fold와 5 seed. 논문은 표준편차를 기술 통계로 사용하고 신뢰구간으로 해석하지 않았다.

### 확인된 사실

- ConvNeXt-Tiny 이미지 수준 macro-F1은 B1 `0.9736±0.0226`, B2 `0.7979±0.0260`.
- 두 설정은 데이터 구성과 과제 조건이 완전히 동일하지 않아 `0.1757` 차이를 순수 누수 효과로 인과 해석할 수는 없다.
- B2 tree-level ConvNeXt-Tiny `0.8621±0.0317`.
- frozen DINOv2 tree-level `0.9000±0.0722`; 저자는 paired inferential superiority를 주장하지 않았다.
- border-only B2 tree-level 성능도 `0.8428±0.0798`이었다.

### 공식 인정·재현 근거

저자는 specimen-disjoint 평가의 필요성과 경계·촬영 문맥 신호의 가능성을 직접 논의한다. [공식 논문](https://arxiv.org/abs/2610.12676)은 확인했으나 독립 재현과 공개 실행 코드는 확인하지 못했다.

### 진단 → 가설 → 최소 실험

- **진단:** 이미지 단위 분할이 개체 고유 무늬를 공유하고, border-only 성능은 배경·준비 방식 신호가 충분할 수 있음을 보인다.
- **가설:** 모델이 종의 해부학적 특징과 함께 specimen·촬영 세션·경계 처리 특징을 학습한다.
- **최소 실험:** 같은 backbone에 `image-random / tree-disjoint / acquisition-session-disjoint` 분할을 적용하고 `center-only / border-only / background-only` 입력을 비교한다.  
  **GO:** tree-disjoint center-only가 border-only보다 macro-F1 `≥0.10` 우세하고 세션 분리에서도 유지.  
  **KILL:** border/background-only가 전체 입력과 `0.05` 이내이면 생물학적 특징 주장보다 수집 프로토콜 교정을 먼저 한다.

### 판정

| 항목 | 점수 | 근거 |
|---|---:|---|
| 심각도 | 4/5 | 현장 배치 성능을 이미지 분할이 크게 과대평가할 수 있다. |
| 재현 신뢰도 | 3/5 | 반복 실험은 충실하지만 공개 코드·독립 재현을 확인하지 못했다. |
| 연구 가치 | 5/5 | 그룹 분리와 문맥 제거는 해무·선박·환경 영상에도 그대로 적용된다. |

## 6. 극희소 사멸 세포: “희귀하니 이상치일 것”이라는 가정의 실패

### 실패 조건

사멸 세포가 전체의 약 `0.37%`라는 이유로 정상 세포만 학습한 anomaly detector를 적용하면, 사멸 세포가 정상 분포와 겹쳐 거의 검출되지 않는다. 지도학습 최선 모델도 자동화에 충분한 수준에 도달하지 못했다.

### 모델·데이터·설정

- **데이터:** 258개 주석 이미지, 65,527개 세포/핵, 매핑된 사멸 세포 243개.
- 원래 사멸 라벨 330개 중 87개는 Cellpose mask와 연결되지 않았다. 나머지 mask 65,284개는 살아 있는 세포로 간주됐다.
- **평가:** 80/20 분할과 threshold 선택용 group-aware 5-fold CV; 테스트 양성은 53개.
- **방법:** 휴리스틱, LR/RF/XGBoost/LightGBM, ResNet-18/EfficientNet-B0, Isolation Forest/one-class SVM/PCA, convolutional autoencoder/Deep SVDD.

### 확인된 사실

- 최선 ResNet-18 64px unpadded: dead-cell F1 `0.617`, macro-F1 `0.808`.
- XGBoost 최선 F1 `0.608`.
- PCA reconstruction 최선 F1 `0.361`.
- convolutional autoencoder F1은 설정에 따라 `0.041–0.155`.
- Deep SVDD는 32px padded에서 F1 `0.018`, 나머지 여러 설정에서 `0.000`; macro-F1도 약 `0.498–0.507`.
- 저자는 완전 자동 검출보다 human-in-the-loop 후보 우선순위화가 현실적이라고 결론 내렸다.

### 공식 인정·재현 근거

저자는 segmentation 오류, 염색 변화, debris·비특이 신호, 극단적 클래스 불균형이 누적된다고 설명하며, 사멸 세포가 단순 통계적 이상치가 아니라고 명시했다. [공식 논문](https://arxiv.org/abs/2610.13780)과 논문이 연결한 [공식 코드](https://github.com/pv-is-nrt/pub-dead-cell-detection)를 확인했다. 다만 현재 GitHub API에서 저장소 내용을 읽지 못해 실행 가능 상태는 검증하지 못했고, 독립 재현도 확인하지 못했다.

### 진단 → 가설 → 최소 실험

- **진단:** 희소성은 anomaly separability를 보장하지 않으며, 일부 양성은 upstream segmentation 단계에서 이미 사라진다.
- **가설:** 지도 신호 부족보다 먼저 `양성→mask 매핑 실패`와 “미주석=정상” 가정이 성능 상한을 낮춘다.
- **최소 실험:** 테스트 53개 양성을 `정상 mask / merged mask / missing mask`로 감사하고, classifier 평가는 검출 가능한 양성과 전체 양성을 모두 분모로 보고한다. 이어서 불확실 표본만 전문가가 재검토하는 active-learning 1회차를 수행한다.  
  **GO:** 재검토 후 양성 label precision `≥0.95`, 전체 pipeline recall `≥0.70`, 검토량이 전체의 `≤5%`.  
  **KILL:** segmentation 단계 missing 양성이 `>20%`면 분류기 튜닝을 중단하고 instance segmentation·annotation 연결부터 수정한다.

### 판정

| 항목 | 점수 | 근거 |
|---|---:|---|
| 심각도 | 5/5 | 극소수 양성에서 누락과 오탐 모두 실사용 비용이 크다. |
| 재현 신뢰도 | 3/5 | 상세 수치와 코드 링크는 있으나 저장소 실행 상태·독립 재현이 미확인이다. |
| 연구 가치 | 4/5 | 희귀 해양 이상·결함 탐지의 라벨 감사와 cascade 설계에 직접 연결된다. |

## 7. 오늘의 실패 패턴 3개

1. **그룹 누수가 평균 점수를 만든다.** 재난 사건과 나무 개체처럼 동일 그룹의 문맥이 train/test에 공유되면 실제 배치보다 높은 점수가 나온다.
2. **평균이 클래스 붕괴를 숨긴다.** 비디오 방향 쌍에서 100/0 recall이 평균 50으로 보이듯, macro 지표와 클래스별 혼동행렬을 함께 보지 않으면 실패를 놓친다.
3. **입력·주석 파이프라인이 모델보다 먼저 병목이 된다.** SquintBench의 축소 view, 사멸 세포의 mask 매핑, 목재 영상의 border-only 결과는 backbone 교체 전에 입력 경로와 라벨 계보를 감사해야 함을 보여준다.

## 8. 연구 공백

- **그룹 계층 평가:** 사건·개체·촬영 세션을 동시에 분리하는 nested split과 불확실성 보고가 부족하다.
- **시간 추론의 인과 검증:** 역재생, 셔플, 정지 프레임 대조군을 표준 비디오 벤치마크에 포함할 필요가 있다.
- **주파수·스케일 라우팅:** OCR/VLM이 입력별로 원본·저역통과·축소 view를 선택하는 비용 인식형 라우터가 필요하다.
- **희귀 사건의 end-to-end recall:** segmentation 이후 분류 점수만 보고하지 않고 원본 객체에서 최종 검출까지 누락을 추적해야 한다.
- **shortcut 예산:** full input 성능과 metadata/background/pre-only 성능의 차이를 하나의 감사 지표로 관리할 필요가 있다.

## 9. 바로 실행할 최소 실험

| 우선순위 | 실험 | 최소 자원 | 핵심 측정값 | 중단 조건 |
|---|---|---|---|---|
| P0 | 재난 피해 random split 대 LOEO + pre-only | 공개 임베딩 또는 1개 GFM, 선형 분류기 | balanced accuracy, per-event AUC | pre-only가 full pair와 `0.02` 이내 |
| P0 | 비디오 역재생·셔플 대조군 | 6클래스×20개 짧은 영상, 1개 VLM | 클래스 recall, 예측 반전율 | 한 방향 recall `≤20%` |
| P1 | 해양 OCR 다중 스케일 view | 표지·계기판 200장, 기존 VLM | ANLS, latency, 일반 OCR 하락 | 일반 OCR `>5`점 하락 |
| P1 | tree/session-disjoint + 입력 마스킹 | 기존 backbone 1개 | macro-F1, center-border gap | border-only가 full과 `0.05` 이내 |
| P0 | 희귀 양성 mask 연결 감사 | 테스트 양성 53개 | upstream miss rate, end-to-end recall | missing mask `>20%`면 분류 중단 |

## 10. 근거의 한계

- **확인된 사실:** 위 수치는 각 공식 논문의 표·본문과 확인 가능한 공식 저장소 설명에서 가져왔다.
- **저자 주장:** shortcut, 고주파 간섭, 정상·사멸 분포 중첩 등 원인 해석은 저자 주장으로 취급했다.
- **추론:** GO/KILL 기준과 해양 CV 적용 방향은 오늘의 최소 검증을 위한 운영 가설이다.
- 독립 커뮤니티 재현은 5건 모두 확인되지 않았다. 코드가 있어도 데이터 접근권한, 모델 checkpoint, 환경 차이로 동일 수치가 보장되지는 않는다.
- 서로 다른 데이터 구성·입력 예산의 수치를 직접적인 모델 순위나 인과 효과로 해석하지 않았다.
