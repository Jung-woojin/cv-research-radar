# CV Paper Idea Radar — 2026-10-12

- 조사 범위는 **2026-10-05~2026-10-11 KST**이며, arXiv cs.CV 최신 후보 12편을 검토해 후속 연구 질문이 선명한 7편을 남겼다.
- 이번 회차의 공통 모순은 “더 많은 데이터·토큰·깊이”가 평균 품질은 높여도 **작고 인과적으로 중요한 evidence**를 반드시 보존하지는 않는다는 점이다.
- 30,000시간 ego video 연구는 agent motion보다 manipulated-object fidelity가 훨씬 느리게 개선됨을 보였고, BudgetPix는 토큰을 줄이면서도 품질을 유지하지만 entropy가 실제 task utility인지는 묻지 않는다.
- Slot3R은 같은 공간 주소에 여러 feature state를 보존하면 장기 3D stream의 정확도와 OOM 경계를 개선할 수 있음을 보여준다.
- OTTER는 referent 정보가 modifier에만 있지 않고 contextualized noun 등 여러 token에 분산됨을 보였으며, DVD는 box·mask·3D box를 compact vector token으로 출력한다.
- 두 결과를 연결하면 압축된 구조 출력이 맞는지 **내부 visual evidence로 검증하고 abstain/refine하는 장치**가 새 연구 빈틈이 된다.
- 이번 proposal은 **① CausalBudget, ② VectorVerify, ③ StateBank-WM** 세 가지다.
- 1순위는 **CausalBudget**이다. 공개 detection dataset과 frozen backbone만으로 2주 안에 “entropy가 아니라 marginal task gain이 high-resolution compute를 배분해야 한다”는 핵심 가설을 반증할 수 있다.

## 1. 조사 기준과 후보 압축

- **확인된 사실:** 원문에 명시된 v1 날짜, protocol, metric, 공개 상태다.
- **저자 주장:** 저자가 보고한 결과이며 이 실행에서 독립 재현하지 않았다.
- **추론/제안:** 논문 간 빈틈을 연결해 만든 연구 가설이다.
- 서로 다른 backbone, pretraining, resolution, hardware, split의 수치는 **not strictly apples-to-apples**로 표시했다.
- 12개 후보 중 WOVEN, GenIA, WorldAlign, Multi-Agent Egocentric World Model, ContiLNN은 흥미롭지만 이번 4~8주 진단형 proposal의 최소 반증 실험과 연결이 상대적으로 약해 제외했다.
- 2026-10-09 보고서의 ConfusionScope Tracking, ReferenceGuard Segmentation, ResidualTrust Fusion은 반복하지 않았다. 이번 아이디어는 compute utility, structured-output verification, multi-state dynamics 보존이라는 새 빈틈에서 출발한다.

## 2. 연결 가치가 높은 최신 논문 7편

### 1) What 30,000 Hours of Ego-centric Video Does Not Teach

- **공개:** arXiv v1, 2026-10-08.
- **문제:** 대규모 ego-centric video가 agent motion과 agent가 물체에 가하는 효과를 같은 속도로 학습시키는가.
- **방법:** Cosmos 3 계열을 300~30,000시간 nested data ladder에서 학습하고, OOD 150 clips에서 agent/object Structural Consistency Score를 분리한다. skeleton conditioning과 object-centric adaptive noise schedule도 비교한다.
- **확인된 결과:** standard conditioning의 agent SCS는 300→3k 시간에서 +0.12, 3k→30k에서 +0.06으로 포화하며 추정 asymptote가 0.811이다. 300시간 skeleton-conditioned Nano가 standard 약 15k시간의 agent fidelity에 도달해 약 50배 data 차이를 상쇄한다.
- **저자 주장:** object fidelity는 agent fidelity보다 낮고 느리게 개선되며, tested intervention 중 object-centric adaptive noise scheduling만 convergence level을 올렸지만 큰 gap이 남는다.
- **중요 limitation:** 150개의 선별 clip, 17-frame prediction, segmentable object 조건이다. Edge와 Nano는 initialization·architecture가 달라 순수 capacity 비교가 아니다.
- **공개 상태:** [논문](https://arxiv.org/abs/2610.12464), [공식 프로젝트](https://fidelity-gap.github.io/). 평가셋은 공개 예정으로 표기된다.
- **연결 이유:** pixel mass·predictability 중심 objective가 causal object evidence를 과소배분한다는 직접 진단을 제공한다.

### 2) BudgetPix: Compute-Adaptive Tokenization for Pixel-Space Image Diffusion

- **공개:** arXiv v1, 2026-10-08.
- **문제:** uniform patch가 평탄 영역과 복잡 영역에 같은 계산을 써 inference budget을 낭비한다.
- **방법:** entropy-guided quadtree, multi-scale encoder/decoder, variable-token training으로 한 checkpoint를 여러 token budget에서 실행한다.
- **확인된 결과:** PixelDiT-T2I 1024²의 25% token budget에서 BudgetPix는 GenEval 0.725, DPG-Bench 83.7; base model의 100% budget은 0.721, 84.8이다. 동일 25% budget base는 0.323, 55.1이다.
- **중요 limitation:** backbone을 그대로 줄이는 것이 아니라 별도 fine-tuning과 encoder/decoder가 필요하다. entropy는 image complexity의 proxy이지 object utility나 downstream importance가 아니다.
- **공개 상태:** [논문](https://arxiv.org/abs/2610.12307), [공식 프로젝트](https://karaozgur.com/BudgetPix/). 프로젝트 페이지의 code는 “soon”이다.
- **연결 이유:** high-resolution/P2 compute를 어디에 쓸지 다루지만, “복잡한 곳”과 “task에 중요한 곳”을 구분하지 않는다.

### 3) Slot3R: Set-Associative Spatial Memory for Streaming 3D Reconstruction

- **공개:** arXiv v1, 2026-10-08.
- **문제:** spatial proximity를 memory address와 feature identity에 동시에 사용하면 같은 위치의 서로 다른 surface/view state가 조기 평균된다.
- **방법:** frozen Point3R에 K-way set-associative memory, confidence-aware update, 640-token sparse readout, global anchors를 붙인다.
- **확인된 결과:** 7Scenes 500 frames에서 Acc 0.0745→0.0275, NC 0.5510→0.5790, 평균 FPS 16.77→19.17이다. 저자 환경에서 600~1000 frames를 약 19 FPS로 완료했으며 Point3R과 InfiniteVGGT는 800 frames 이상에서 OOM이었다.
- **중요 limitation:** runtime은 RTX 4090 24GB, fused RoPE3D, data loading·metric 제외 조건이다. persistent memory 자체는 scene coverage와 함께 성장할 수 있다.
- **공개 상태:** [논문](https://arxiv.org/abs/2610.12282), [공식 프로젝트·코드 링크](https://ashleyxyz.github.io/Slot-3R/).
- **연결 이유:** 한 위치에 한 state만 남기는 평균화가 장기 memory의 정보 손실 원인일 수 있다는 최소 intervention 사례다.

### 4) From What to Which: Decoding Modifier Grounding in Frozen MLLMs

- **공개:** arXiv v1, 2026-10-08.
- **문제:** “banana”를 찾는 object grounding과 “왼쪽의 노란 banana”를 고르는 instance grounding 사이에 어떤 token evidence가 쓰이는가.
- **방법:** frozen MLLM 위에 OTTER probe를 학습해 generated token과 visual region을 optimal transport로 정렬하고 counterfactual referent·image·context perturbation을 수행한다.
- **확인된 결과:** RefCOCO-MOD Soft-IoU에서 OTTER는 noun 0.310, spatial modifier 0.304, attribute 0.285다. natural counterfactual pair의 target preference는 modifier 0.776, noun 0.779로 referent 정보가 modifier에만 국한되지 않는다. learned projection mIoU는 0.458, raw cosine은 0.130이다.
- **저자 주장:** instance identity는 contextualized token states에 분산되며, learned token-visual mapping이 필요하다.
- **중요 limitation:** OTTER는 RIS supervision을 받은 probe라 frozen representation에 바로 쓸 수 있는 grounding geometry가 이미 존재한다고 증명하지 않는다. deletion은 model relevance의 근거이지 완전한 causal account가 아니다.
- **공개 상태:** [논문](https://arxiv.org/abs/2610.12305). 원문에서 독립 공식 code repo는 확인하지 못했다.
- **연결 이유:** output token 하나의 confidence보다 여러 token에 분산된 referential evidence의 합의가 구조 출력 검증에 더 적합할 수 있다.

### 5) DVD: Dynamic Vector Decoding for Efficient MLLM-based Perception

- **공개:** arXiv v1, 2026-10-08.
- **문제:** text coordinate는 output token이 길고, fixed coordinate vocabulary는 3D의 범위·정밀도를 제한한다.
- **방법:** 2D box, mask, 3D box를 1D vector sequence로 바꾸고 shared autoencoder/codebook의 compact discrete token으로 출력한 뒤 de-tokenizer로 복원한다.
- **확인된 결과:** DVD-2B는 SUN-RGBD/Hypersim/nuScenes AP3D@15 40.0/15.7/19.8, RefCOCOg val Precision 89.9, cIoU 70.4를 보고한다. DVD-8B는 40.3/18.4/24.4와 88.7/73.4다.
- **중요 limitation:** 8B가 모든 dataset에서 2B보다 높지 않다. 예를 들어 ARKitScenes 62.1 대 62.4, KITTI 28.7 대 31.4다. codebook compression error와 calibration은 핵심 표에서 충분히 진단되지 않는다.
- **공개 상태:** [논문](https://arxiv.org/abs/2610.12266). 별도 공식 repo는 원문에서 확인하지 못했다.
- **연결 이유:** 구조 출력을 짧게 만들었지만, 잘못된 discrete code를 언제 거부하거나 더 세밀하게 decode할지라는 후속 질문이 남는다.

### 6) One Block, Multiple Depths: Recurrent Vision Transformers with Depth-Programmed Experts

- **공개:** arXiv v1, 2026-10-08.
- **문제:** 깊이별 block을 저장하지 않고도 depth-specific computation을 유지할 수 있는가.
- **방법:** 하나의 recurrent Transformer block과 normalized-depth conditioned FFN expert mixture를 사용하고, 추론 깊이를 resample한다.
- **확인된 결과:** 같은 training recipe의 B/16 비교에서 reViT는 23.6M params, 34.3 GFLOPs, 83.0% Top-1; DeiT III는 86.6M, 33.9 GFLOPs, 82.8%다. L/16은 40.9M/83.8% 대 304.4M/84.1%다.
- **중요 limitation:** S/16은 78.2%로 DeiT III 79.9%보다 낮다. DINOv2/Raptor transfer 비교는 distillation target이 달라 not strictly apples-to-apples다. FLOPs는 latency·energy를 보장하지 않는다.
- **공개 상태:** [논문](https://arxiv.org/abs/2610.12448). 원문에서 공식 repo는 확인하지 못했다.
- **연결 이유:** spatial token budget과 recurrent depth를 독립 조절하면 small-object evidence가 resolution 병목인지 iterative processing 병목인지 진단할 수 있다.

### 7) Is In-Domain Training Enough for Fine-Grained Industrial Anomaly Understanding?

- **공개:** arXiv v1, 2026-10-08.
- **문제:** industrial anomaly MLLM의 fine-grained perception gap이 in-domain training으로 해결되는가.
- **방법:** frozen MLLM agents, reference-based defect expert, evidence-weighted reliability controller를 결합한 SiGMA를 제안한다.
- **확인된 결과:** MMAD 39,670 questions에서 SiGMA 평균 85.2%, JUDO 81.2%다. anomaly detection/localization은 SiGMA 82.6/79.6, JUDO 65.0/73.0, OmniAD 68.8/75.5다.
- **중요 limitation:** 저자는 team·hyperparameter를 MMAD answers로 선택했고 controller를 evaluation predictions에 transductive fit했다. baseline 결과는 원 연구에서 가져와 prompt/reference/parser 조건이 동일하지 않을 수 있으므로 headline 비교는 not strictly apples-to-apples다.
- **공개 상태:** [논문](https://arxiv.org/abs/2610.12310). 독립 공식 repo는 확인하지 못했다.
- **연결 이유:** 큰 모델의 holistic perception 대신 normal-reference expert가 특정 evidence를 제공할 때 성능이 오르는 현상은 “어디에 compute를 쓸지”를 task utility로 정의할 근거다.

# Proposal 1 — CausalBudget

## Expected Evidence Gain Routing for Tiny-Object and Anomaly Perception

1. **문제 정의와 가치**  
   Uniform high-resolution inference는 비싸고 entropy routing은 texture가 복잡한 곳을 우선한다. 그러나 tiny object나 defect는 낮은 entropy·작은 면적이어도 task 결정에 중요하다. 지금 필요한 것은 “복잡한 patch”가 아니라 **추가 고해상도 관측이 예측을 얼마나 바꾸는 patch**를 찾는 것이다.

2. **기존 연구의 빈틈**  
   BudgetPix는 entropy로 token을 배분하고, 30k-hour 연구는 pixel mass가 object dynamics를 과소가중할 수 있음을 보인다. SiGMA는 외부 defect evidence가 perception gap을 줄인다고 보고하지만, compute allocation 문제로 정식화하지 않는다.

3. **핵심 가설**  
   저해상도 feature에서 추정한 patch별 expected evidence gain이 entropy·confidence·objectness보다 high-resolution/P2 rerun의 실제 AP gain을 더 잘 예측한다.

4. **구조 / 모듈**  
   저해상도 backbone 1회 → patch candidate 생성 → frozen teacher counterfactual로 marginal gain target 구성 → 경량 gain predictor → budgeted top-k 또는 differentiable knapsack → 선택 patch만 high-resolution crop/P2로 재처리 → late fusion. 첫 논문은 새 backbone 대신 frozen detector와 router만 학습한다.

5. **Baseline / 비교군**  
   uniform full-resolution, low-resolution only, random-k, entropy-k, confidence-k, objectness-k, BudgetPix식 quadtree proxy, oracle marginal-gain upper bound.

6. **데이터셋 / 지표**  
   VisDrone, AI-TOD-v2, TinyPerson; domain transfer로 SeaShips 또는 공개 maritime detection set. AP, APs, recall@100, false positives/km², FLOPs, peak VRAM, median/p95 latency, energy/image, calibration error.

7. **필수 ablation**  
   gain target 정의(loss delta, logit delta, localization delta), router input layer, crop scale, budget 10/25/50%, teacher 없이 self-distillation, fusion 위치, entropy와 gain 상관, object size별 결과.

8. **예상 실패 모드 / negative result**  
   저해상도 pass에 tiny-object evidence가 전혀 없으면 router가 후보를 못 찾는다. high-res crop boundary가 context를 자를 수 있다. gain label 생성 비용이 실제 절감보다 클 수 있다.

9. **Novelty risk와 방어**  
   dynamic resolution·active perception과 겹칠 수 있다. 방어점은 routing score를 saliency가 아니라 **동일 sample의 counterfactual task improvement**로 정의하고, entropy/objectness가 놓치는 case를 causal intervention으로 분리하는 것이다.

10. **4~8주 MVP**  
    1주: YOLO/RT-DETR 저해상도 baseline과 crop rerun 구축. 2주: 5k images에서 oracle marginal gain 생성. 3주: 작은 router 학습. 4주: VisDrone factorial budget 평가. 5~6주: AI-TOD transfer와 energy/latency. 7~8주: maritime stress·ablation.

11. **성공 contribution 3개**  
    (a) patch compute utility의 counterfactual 정의, (b) tiny-object budget routing benchmark, (c) 동일 AP에서 high-resolution compute 절감 또는 동일 budget에서 APs 개선.

12. **예상 제목**  
    - CausalBudget: Routing High-Resolution Compute by Expected Evidence Gain  
    - Spend Pixels Where They Change the Decision  
    - Beyond Entropy: Counterfactual Compute Allocation for Tiny Objects

13. **Abstract 개요**  
    uniform/entropy routing의 문제 → counterfactual gain 정의 → 경량 predictor와 selective rerun → tiny-object·maritime 평가 → compute-accuracy Pareto 및 실패 조건.

14. **Introduction 흐름**  
    high-resolution 필요성 → 전역 비용 문제 → existing heuristic의 task mismatch → oracle 분석 → CausalBudget → 결과·기여.

15. **Related Work 구조**  
    dynamic token/resolution, tiny-object detection/P2, saliency/uncertainty, active perception, counterfactual attribution.

16. **Method 구조**  
    problem and budget → gain label → predictor → constrained routing → fusion → training objective.

17. **Experiment 표/그림**  
    Fig1 entropy와 gain이 다른 사례, Fig2 pipeline, Table1 main AP-cost, Table2 router baselines, Fig3 budget Pareto, Table3 ablation, Fig4 maritime failure taxonomy.

18. **첫 실험과 GO/KILL**  
    VisDrone-val 1k images에서 각 image의 16개 grid crop을 하나씩 고해상도 rerun해 true ΔAP surrogate를 계산하고 entropy/objectness와 Spearman correlation을 비교한다. **GO:** learned predictor가 entropy 대비 top-25% patch recall을 ≥10pp 높이고 low-res 대비 APs ≥2pp 개선, full-res latency의 ≤55%. **KILL/PIVOT:** oracle top-25% 자체가 APs +1pp 미만이면 routing보다 missing-evidence acquisition 문제로 전환한다.

**평가:** Novelty 4.5/5 · Feasibility 4.5/5 · Compute cost 2/5 · Publication potential 4.5/5

# Proposal 2 — VectorVerify

## Evidence-Calibrated Structured Decoding with Refine-or-Abstain

1. **문제 정의와 가치**  
   DVD처럼 box·mask·3D box를 compact code로 출력하면 빠르지만, codebook error가 조용히 구조 오류로 복원될 수 있다. 모델 내부의 distributed referential evidence와 최종 구조가 일치하는지 확인해 잘못된 구조를 거부하거나 추가 decode해야 한다.

2. **기존 연구의 빈틈**  
   OTTER는 token별 visual evidence를 복구하지만 결과 생성과 연결하지 않는다. DVD는 efficient output representation을 제안하지만 selective risk, code uncertainty, visual-evidence consistency를 중심 평가하지 않는다. SiGMA는 evidence weighting을 answer aggregation에만 사용한다.

3. **핵심 가설**  
   compact vector code의 확률만 보는 것보다 noun·modifier·visual patch 간 transport agreement와 decoded geometry의 overlap을 결합한 verifier가 localization error를 더 잘 예측한다.

4. **구조 / 모듈**  
   frozen MLLM/Dynamic vector decoder → token-patch lightweight projection → noun/modifier evidence maps → decoded box/mask와 evidence overlap score → code entropy·transport dustbin mass와 결합한 risk head → accept, one-step higher-resolution refine, abstain 중 선택.

5. **Baseline / 비교군**  
   DVD 원형, text-coordinate generation, max token probability, sequence entropy, self-consistency sampling, box confidence, OTTER-only overlap, oracle selective predictor.

6. **데이터셋 / 지표**  
   RefCOCO/+/g, RefCOCO-MOD counterfactual pairs, Omni3D의 SUN-RGBD/Hypersim. Precision@0.5, cIoU, AP3D@15, invalid structure rate, risk-coverage AUC, ECE, output tokens, latency.

7. **필수 ablation**  
   noun only vs modifier only vs all tokens, learned projection vs raw cosine, OT vs softmax, dustbin 유무, code entropy 유무, refine 해상도, wrong/blank image control, same-category distractor 수.

8. **예상 실패 모드 / negative result**  
   probe가 RIS label shortcut을 학습할 수 있다. verifier가 base model과 같은 visual error를 공유하면 confidently wrong 상태가 남는다. refine 비용이 compact decoding 이득을 상쇄할 수 있다.

9. **Novelty risk와 방어**  
   confidence calibration이나 hallucination detection으로 보일 수 있다. 방어점은 generic confidence 대신 **decoded geometry와 distributed referential evidence의 구조적 일치**를 측정하고, same-category counterfactual switching으로 검증하는 것이다.

10. **4~8주 MVP**  
    공식 DVD code가 없으면 Qwen2.5-VL 2B의 quantized box token proxy로 시작한다. 1~2주 decoder/probe, 3주 evidence overlap, 4주 selective evaluation, 5주 counterfactual controls, 6~8주 3D 확장.

11. **성공 contribution 3개**  
    (a) structured MLLM output의 evidence-consistency verifier, (b) referent-aware selective prediction protocol, (c) fixed budget에서 refine-or-abstain으로 risk 감소.

12. **예상 제목**  
    - VectorVerify: Grounded Verification for Compact Perception Tokens  
    - Does the Box Match the Evidence?  
    - Refine or Abstain: Selective Structured Decoding for MLLMs

13. **Abstract 개요**  
    compact decoding 효율과 silent error 문제 → distributed grounding signal → verifier·policy → counterfactual/2D/3D 평가 → selective-risk 개선.

14. **Introduction 흐름**

# Proposal 3 — StateBank-WM

## Multi-State Object Memory for Interaction-Faithful Video World Models

1. **문제 정의와 가치**  
   대규모 ego video world model은 손·몸의 움직임을 잘 그려도 접힘, 미끄러짐, 가림 뒤 상태 같은 object consequence를 틀린다. single latent state에 관측을 평균하면 가능한 object state가 조기 소실될 수 있다.

2. **기존 연구의 빈틈**  
   30k-hour 연구는 object fidelity gap과 object-centric supervision 효과를 보였지만 memory representation은 단일 trajectory다. Slot3R은 같은 공간 주소에 여러 state를 보존하지만 reconstruction에만 적용하며 future interaction dynamics를 다루지 않는다.

3. **핵심 가설**  
   contact 주변 object token을 K개 latent state로 유지하고 action evidence가 충분할 때만 merge하면, 평균화된 single-state memory보다 occlusion·deformation 이후 object SCS와 multimodal future coverage가 높아진다.

4. **구조 / 모듈**  
   pretrained small video diffusion/latent world model → object/contact masks → location-indexed K-state bank → confidence·feature agreement로 insert/fuse/replace → action-conditioned sparse readout → base denoiser에는 residual adapter만 추가. 첫 단계는 backbone을 frozen으로 유지한다.

5. **Baseline / 비교군**  
   base world model, larger context, FIFO memory, EMA single-state memory, Slot3R식 bank without action gate, object-centric loss only, oracle ground-truth contact mask.

6. **데이터셋 / 지표**  
   공개 ego manipulation subset이 확보되면 해당 benchmark를 사용하고, 초기 MVP는 Something-Something V2의 state-changing classes와 BridgeData/RT-1 공개 clips를 쓴다. object SCS, agent SCS, LPIPS control, contact-region IoU, future diversity/coverage, memory tokens, latency.

7. **필수 ablation**  
   K=1/2/4/8, merge threshold, action gate, contact prior, sparse readout size, residual adapter 유무, object-centric noise schedule와 조합, occlusion length별 결과.

8. **예상 실패 모드 / negative result**  
   segmentation/tracking error가 state bank를 오염시킬 수 있다. K states가 미래 mode가 아니라 viewpoint duplicates만 저장할 수 있다. small public model에서는 generation quality가 낮아 SCS 측정이 불안정할 수 있다.

9. **Novelty risk와 방어**  
   object-centric world model·memory bank와 유사해질 수 있다. 방어점은 **co-location과 state identity를 분리**하고, merge intervention이 interaction fidelity에 미치는 causal effect를 K=1 대 K>1로 직접 측정하는 것이다.

10. **4~8주 MVP**  
    1주 state-changing clip subset, 2주 frozen feature bank, 3주 action/contact gate, 4주 next-frame/short-horizon predictor, 5~6주 occlusion stress, 7~8주 generative rollout과 SCS.

11. **성공 contribution 3개**  
    (a) object-state averaging failure 진단, (b) training-light set-associative dynamics memory, (c) agent/object fidelity와 memory 정책을 연결한 benchmark.

12. **예상 제목**  
    - StateBank-WM: Preserve Alternatives Before Predicting Interaction  
    - One Location, Multiple Futures  
    - Stop Averaging the Object: Set-Associative Memory for World Models

13. **Abstract 개요**  
    scaling 후에도 남는 object fidelity gap → single-state averaging 가설 → action-gated K-state memory → occlusion/deformation benchmark → fidelity·memory trade-off.

14. **Introduction 흐름**  
    world model scaling → agent/object 비대칭 → objective 개선의 한계 → memory overwrite 가설 → set-associative intervention → 기여.

15. **Related Work 구조**  
    video world models/scaling, object-centric dynamics, streaming memory/3D reconstruction, multimodal future prediction, interaction metrics.

16. **Method 구조**  
    object address → state bank operations → action-conditioned readout → residual generation adapter → training losses.

17. **Experiment 표/그림**  
    Fig1 paper-folding state collapse, Fig2 bank, Table1 object/agent SCS, Fig3 occlusion length curve, Table2 K/readout ablation, Fig4 memory-latency Pareto, failure gallery.

18. **첫 실험과 GO/KILL**  
    state-changing 500-clip subset에서 frozen DINO feature의 K=1 EMA와 K=4 bank를 비교해 occlusion 후 correct-state nearest-neighbor retrieval을 측정한다. **GO:** K=4가 K=1 대비 retrieval ≥8pp, downstream object-mask prediction ≥3 IoU points 개선, memory ≤3×. **KILL/PIVOT:** oracle object tracks에서도 차이가 <3pp면 averaging보다 supervision/objective가 주원인으로 보고 CausalBudget의 object-centric loss 실험으로 통합한다.

**평가:** Novelty 4.5/5 · Feasibility 2.5/5 · Compute cost 4/5 · Publication potential 4.5/5

## 3. Proposal 비교와 이번 주 선택

| 제안 | 핵심 진단 | Novelty | Feasibility | Compute cost | Publication potential | 첫 반증까지 |
|---|---|---:|---:|---:|---:|---|

| VectorVerify | compact code와 visual evidence 불일치 | 4.0 | 3.5 | 3 | 4.0 | 2~3주 |
| StateBank-WM | single-state averaging이 dynamics를 삭제 | 4.5 | 2.5 | 4 | 4.5 | 2~4주 |

### 이번 주 1순위: CausalBudget

선정 이유는 세 가지다.

1. 사용자 핵심 관심인 tiny object·P2·expected gain 기반 compute allocation과 직접 맞는다.
2. 공식 새 코드가 없어도 기존 detector와 counterfactual crop rerun으로 핵심 가설을 먼저 죽일 수 있다.
3. 성공과 실패가 모두 해석 가능하다. 성공하면 learned routing 논문으로, 실패하면 “저해상도 representation에 후보 evidence 자체가 없다”는 active acquisition 문제로 전환된다.

### 바로 실행할 MVP

- **Day 1–2:** VisDrone-val 1k images, low/full resolution detector prediction cache.
- **Day 3–5:** 4×4 grid의 single-crop intervention으로 patch별 Δclassification·Δlocalization target 생성.
- **Week 2:** entropy, objectness, uncertainty, learned gain predictor의 top-k utility 비교.
- **최소 산출물:** budget-AP curve, APs, top-k oracle gap, p95 latency, 대표 성공/실패 사례 20개.
- **GO:** 25% selected area에서 low-res 대비 APs +2pp 이상, entropy router보다 +1pp 이상, full-res p95 latency의 55% 이하.
- **KILL:** oracle 25% crop도 +1pp 미만. 이 경우 compute routing을 중단하고 low-res에서 evidence가 사라지는 시점을 feature layer·input sampling 관점에서 진단한다.

- 위 수치는 각 저자 원문에서 확인한 보고값이며 독립 재현값이 아니다.
