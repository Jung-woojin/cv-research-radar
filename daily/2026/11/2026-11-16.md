## 2) CV / DL-CV 핵심 5편

### C1. Objects as Addresses: Instance Binding in Vision Transformer Attention

**시점:** 최근 발표분. v1 11월 12일 UTC, 발표 목록 11월 13일.

**사실·저자 보고:** 여덟 pretrained ViT에서 instance 분리 신호가 value/residual similarity보다 선택된 Q/K·attention 관계에 강하게 나타난다. 같은 객체의 다른 patch가 읽는 공통 영역을 attention address로 해석하며, query의 spatial request를 교환하는 개입으로 해당 head의 읽는 위치를 바꾼다. [논문](https://arxiv.org/abs/2611.17240)

**진단과 한계:** 객체가 feature clustering에서 합쳐지는 현상을 곧바로 encoder의 정보 소실로 해석하면 안 된다. 다만 특정 head의 routing 제어가 downstream identity·detection 개선을 뜻하지는 않는다. **추론:** frozen encoder를 교체하기 전에 Q/K readout을 점검할 가치가 있다.

**최소 실험 제안:** 동일 frozen DINOv2에서 residual·value·query·attention 기반 same-instance 판별을 비교한다. head 선택과 반경 조정은 development split에서 끝내고 COCO로 고정 전이한다. 자세한 protocol과 반증은 미니 리뷰에 적었다.

### C2. Consensus Capture in Reference-Based UAV Video Stabilization: A Benchmark on Dynamic Urban Scenes

**시점:** 최근 발표분. v1 11월 12일 UTC, 발표 목록 11월 13일.

**사실·저자 보고:** 차량들이 함께 움직이면 서로 일관된 correspondence가 robust homography를 차량 운동 쪽으로 끌어갈 수 있다. 저자는 real-time dynamic pairs에서 unmasked ORB의 capture를 304쌍 중 28쌍으로 보고하며, capture 사례의 median corner error는 18.8 px인데 일반적인 inlier 통계로는 드러나지 않는다고 설명한다. [논문](https://arxiv.org/abs/2611.17190)

**평가 설계:** static protocol은 site-disjoint tuning, 동일 resolution·feature budget을 사용한다. dynamic protocol은 수동 ground-control point로 감사한 pseudo-ground-truth와 object position error 등을 사용한다. pseudo-GT를 완전한 GT로 부르지 않는다. [평가 원문](https://arxiv.org/html/2611.17190v1)

**추론·최소 실험:** 고정 UAV 영상에서 foreground mask 유무만 바꾸고 inlier ratio, background error, 객체 위치 오차를 함께 기록한다. 움직이는 객체 비율과 운동 방향 일치도로 slice한다. 지표가 서로 어긋나는 구간이 진단 대상이다. UAV·maritime 영상 정합에 직접 유용하지만 저고도 도시 결과의 해상 환경 전이는 미검증이다.

### C3. FLEX-LBP: Learning Local Binary Patterns with Exact Binary Inference for Texture Classification

**시점:** 최근 발표분. v1 11월 12일 UTC, 발표 목록 11월 13일.

**사실·저자 보고:** forward에서는 hard binary code와 histogram을 유지하고 backward에 straight-through estimator를 사용해 LBP geometry·threshold 등을 학습한다. 저자는 90개 learnable parameter와 여섯 texture benchmark의 ablation을 보고한다. nearest-neighbor readout에서 고정 descriptor 대비 평균 3.55 percentage points 개선을 다섯 seed로 보고하지만, linear discriminant readout에서는 이득 양상이 달라진다. [논문](https://arxiv.org/abs/2611.17302)

**진단:** descriptor와 readout의 기여를 분리할 수 있다는 점이 중요하다. ImageNet ResNet feature와의 비교를 일반적인 표현력 우위로 확장하면 **not strictly apples-to-apples**다.

**추론·최소 실험:** 동일 texture split에서 fixed/learned descriptor × NN/linear readout을 교차하고 noise·illumination 변화에 따른 순위 변동을 기록한다. 낮은 parameter 수가 측정 latency나 메모리 우위를 보장하지 않는다. UAV/해상 texture로의 cross-domain 효과는 미확인이다.

### C4. TTB: Test-time Baking for Efficient Rendering of Decoder-only View Synthesis Models

**시점:** 최근 발표분. v1 11월 12일 UTC, 발표 목록 11월 13일. 별도 코드 최초 공개일은 미확인.

**사실·저자 보고:** cross-view attention의 input-output mapping을 scene별 fast-weight MLP로 학습한다. context의 camera-only 입력과 image-content target을 분리해 novel-view rendering과의 modality mismatch를 줄인다. 최대 23배 rendering speedup은 저자 조건의 주장이다. [논문](https://arxiv.org/abs/2611.17331)

**진단:** 핵심 질문은 “attention이 불필요한가”보다 “scene 정보가 작은 mapping으로 충분히 압축되는가”다. 공식 프로젝트에 code·model card·demo 연결이 존재한다. [프로젝트](https://test-time-baking.github.io/)

**추론·최소 실험:** 원본 decoder와 baking 버전을 동일 scene·view path에서 비교해 baking 시간, 첫 frame까지 시간, 이후 frame latency, 품질·VRAM을 기록한다. 총비용이 역전되는 rendered-view 수를 계산한다. 장면 전환이 잦은 서비스와 정적 scene viewer의 효율 결론은 다를 수 있다.

### C5. BrickFlow: Connectivity-Guided Brick Reconstruction

**시점:** 최근 발표분. v1 11월 12일 UTC, 발표 목록 11월 13일.

**사실·저자 보고:** 알려진 LEGO part inventory와 완성 이미지로 각 부품의 pose를 복원한다. SE(3) flow가 global structure를 학습해도 connectivity가 보장되지 않으므로 analytic connectivity-field guidance를 추가한다. 공식 페이지는 frozen DINOv3 기반 image conditioning과 procedural pretraining을 설명한다. [논문](https://arxiv.org/abs/2611.17321), [공식 프로젝트](https://kulits.github.io/BrickFlow/)

**진단:** 시각적으로 비슷한 복원과 조립 가능한 구조는 서로 다른 목표다. 알려진 inventory·connector라는 강한 prior가 있으므로 일반 open-world reconstruction 성능으로 해석하지 않는다.

**추론·최소 실험:** 동일 sample에서 guidance on/off로 pose error와 연결 component 수·collision을 따로 측정한다. 연결성만 좋아지고 image alignment가 나빠지면 constraint와 observation의 trade-off가 드러난다. 사용자 관점에서는 object-level correctness metric 설계가 주요 읽을거리다.

## 3) VLM / Multimodal / Video 핵심 3편

### V1. Unbundling Multimodal Vision Encoding

**시점:** 최근 발표분. v1 11월 12일 18:59:54 UTC. 오늘 revision으로 확인되지 않았다.

**사실·저자 보고:** 같은 데이터·학습 recipe와 lifetime compute 조건에서 visual prior, vision-only capacity, pre-fusion 배치를 분리한다. scratch encoder는 같은 데이터로 pretrained된 encoder와 비슷하고, shared backbone 확대는 시각 전용 capacity의 대체가 되지 않으며 early in-fusion이 pre-fusion과 비슷하다고 보고한다. [논문](https://arxiv.org/abs/2611.17334), [공식 해설](https://unbundling.github.io/)

**한계:** dense backbone 최대 6.4B, multimodal training의 224×224 이미지, 제한된 데이터·mixture 조건이다. 더 많은 외부 데이터로 학습된 released encoder의 이득, 고해상도 OCR, video·interleaved data까지 부정하지 않는다. [한계 원문](https://arxiv.org/html/2611.17334v1)

**추론·최소 실험:** 즉시 encoder를 버리기보다 equal-budget 조건에서 early vision-only branch와 shared branch를 비교한다. OCR·chart와 일반 VQA, text retention을 분리한다. 소규모 adapter 실험은 원 논문의 joint-training 결과를 직접 재현하는 실험이 아님을 명시해야 한다.

### V2. Back to Pixels: Lifting Latent Video Diffusion into Pixel Space

**시점:** 최근 발표분. v1 11월 12일 UTC, 발표 목록 11월 13일.

**사실·저자 보고:** PixVid는 pretrained latent video DiT를 유지하면서 VAE decoder 대신 convolutional head로 pixel frame을 출력한다. clean-video prediction과 noise shift를 조정하며 Wan2.1-14B에서 fine-tuning한다. 같은 per-frame token 수로 더 높은 해상도와 frame 단위 반응을 보고한다. [논문](https://arxiv.org/abs/2611.17336), [프로젝트](https://chenshuo20.github.io/PixVid/)

**진단·주의:** temporal VAE block이 만드는 제약과 visual reasoning 실패는 다르다. token 수가 같아도 출력 head·activation·전체 latency가 같은 것은 아니다.

**추론·최소 실험:** 동일 action-change timestamp에서 첫 반응 frame, fast-motion depth alignment, 실제 VRAM·latency를 비교한다. motion consistency 이득을 일반 temporal reasoning 이득으로 해석하지 않는다.

### V3. Consistent Video-to-Video Translation via Explicit Correspondences

**시점:** 최근 발표분. v1 11월 12일 UTC, 발표 목록 11월 13일. ECCV 표기를 최초 공개일의 증거로 쓰지 않았다.

**사실·저자 보고:** vid2vid-long은 input video의 patch correspondence로 이전 output patch를 검색하고 correspondence cross-attention에 제공한다. 고정 causal window 밖의 이력을 다시 활용하는 방식이다. [논문](https://arxiv.org/abs/2611.17298), [프로젝트](https://www.cs.cmu.edu/~vid2vid-long/)

**진단:** context-window 밖 정보의 부재와 retrieval 실패를 구분할 수 있다. 잘못된 correspondence가 과거의 오류를 지속시키는 위험도 함께 검사해야 한다.

**추론·최소 실험:** occlusion 뒤 재등장·반복 texture 구간에서 retrieval on/off와 shuffled-correspondence control을 비교한다. 장기 일관성·identity drift·latency를 측정한다. 생성 결과의 appearance 유지가 tracking identity의 정확성을 보장하지는 않는다.

## 4) LLM / Agent / 학습·System 변화 2편

### L1. Actor, Judge, or Teacher? Understanding Decision Models in Long-Horizon Agents

**시점:** 최근 발표분. v1 11월 12일 UTC, HF 11월 13일 목록 확인.

**사실·저자 보고:** decision model의 actor·judge·RL teacher 역할을 분리한다. trajectory 전체를 보는 judge는 행동 당시 보이지 않던 결과를 활용할 수 있다. 저자는 Qwen2.5-1.5B policy에서 GRPO 대비 ALFWorld 72.8→82.9%, WebShop 56.8→71.4% success를 보고한다. [논문](https://arxiv.org/abs/2611.17167)

**진단:** poor actor를 poor evaluator로 동일시하면 안 된다. 반대로 미래 trajectory를 보는 judge와 online actor 비교는 정보 조건이 다르므로 **not strictly apples-to-apples**다.

**추론·최소 실험:** 동일 trajectory의 prefix-only/full-trajectory judge를 비교해 action-helpfulness 예측과 policy gain을 분리한다. CV tool-agent에도 적용 가능한 질문이지만 robot control로의 전이는 미검증이다. [공식 코드](https://github.com/ZJU-REAL/decision-agents)

### L2. Factored One-sided Adam-Moment for Practical and Scalable SOAP

**시점:** 최근 발표분. v1 11월 12일 UTC, HF 11월 13일 목록 확인.

**사실·저자 보고:** FOAM은 input-side preconditioning과 factored second moment로 SOAP의 상태·eigendecomposition 비용을 줄인다. 124M–760M LLM pretraining에서 validation loss와 optimizer 효율을 평가한다. optimizer state 절반이라는 결과는 total training VRAM 절반을 뜻하지 않는다. [논문](https://arxiv.org/abs/2611.16905)

**artifact 교차검증:** 논문은 code 링크를 제공하지만, 공식 저장소 README는 **internal review 중이며 추후 공개**라고 명시한다. 현재 실행 가능한 공개 구현으로 추천하지 않는다. [공식 저장소](https://github.com/naver-ai/foam)

**추론·최소 실험:** 코드 공개 뒤 동일 token·batch·precision·hardware에서 loss-vs-step뿐 아니라 loss-vs-wall-clock과 peak memory를 비교한다. ViT·VLM로의 최적화 이득은 별도 검증이 필요하다.

**공통 재현성 감사:** 모든 항목을 설치·실행하지 않았다. 별도 명시한 경우 외에는 FLOPs·실측 latency·VRAM·GPU 시간·seed variance·checkpoint/data license·전체 split·pretraining overlap을 이번 조사에서 확정하지 못했다. 미확인 항목을 0이나 “문제없음”으로 취급하지 않는다. FLEX-LBP의 다섯 seed, Objects as Addresses의 고정 development/test 선택, UAV 연구의 site-disjoint protocol은 각각 해당 논문의 증거이며 다른 논문에 전용하지 않는다.

## 6) 오늘의 중요한 Finding 3개

1. **관측 위치가 실패 진단을 바꾼다.** Objects as Addresses는 residual clustering 실패와 routing의 instance 신호가 공존할 수 있음을 보여준다. 다음 단계는 더 큰 encoder보다 readout·head 선택 통제다. [근거](https://arxiv.org/abs/2611.17240)
2. **내부 일관성은 task 정답의 충분조건이 아니다.** UAV inlier는 움직이는 집단에 합의할 수 있다. 해석 가능한 외부 background·object error를 함께 두는 것이 중요하다. [근거](https://arxiv.org/abs/2611.17190)
3. **효율 claim에는 사용 패턴이 들어가야 한다.** TTB의 scene별 baking, PixVid의 출력 연산, FOAM의 optimizer-state 절감은 서로 다른 비용이다. 이를 단일 speedup 순위로 합치지 않는다. [TTB](https://arxiv.org/abs/2611.17331), [PixVid](https://arxiv.org/abs/2611.17336), [FOAM](https://arxiv.org/abs/2611.16905)

## 7) 과대평가 가능성 / 주의할 연구

- **Unbundling:** 같은 데이터로 pretraining 효과를 통제한 결과를 “released visual encoder는 불필요”로 확대하면 안 된다. 외부 데이터 이점·고해상도·video는 남은 질문이다. [저자 한계](https://arxiv.org/html/2611.17334v1)
- **Objects as Addresses:** foreground patch의 FG-ARI와 선택 head의 intervention은 full instance segmentation AP나 지속적 identity의 증거가 아니다. test mask·head 선택·clustering radius가 어디서 사용됐는지를 확인해야 한다. [평가 protocol](https://arxiv.org/html/2611.17240v1)

## 8) 오늘 바로 읽을 Top 3

1. [Objects as Addresses](https://arxiv.org/abs/2611.17240) — representation/readout 진단과 작은 frozen-model 실험으로 연결하기 좋다.
2. [UAV Consensus Capture](https://arxiv.org/abs/2611.17190) — 사용자 UAV 관심사와 외부 지표 기반 failure diagnosis에 직접 연결된다.
3. [Unbundling Multimodal Vision Encoding](https://arxiv.org/abs/2611.17334) — 학습 prior·capacity·placement를 분리하는 통제 실험 설계를 읽을 가치가 크다.

순위는 연구 적합성에 대한 판단이며 실측 점수가 아니다.

## 9) Top 1 미니 리뷰 — Objects as Addresses

**왜 중요한가:** 같은 범주의 두 객체가 마지막 feature에서 비슷해지는 것은 semantic representation의 자연스러운 성질일 수 있다. 이 논문은 객체 구분이 native attention의 읽는 관계에 더 잘 남는지 묻는다. 새 block을 제안하기 전에 정보의 위치를 찾는 연구다.

**실험 논리:** category와 patch 간 displacement를 맞춘 same-instance pair test로 단순한 위치 차이를 통제한다. VOC development 102장으로 component를 선택하고 held-out VOC 101장, COCO 1,414장, ADE20K 530장에 고정 전이한다. clustering용 COCO 1,587장은 별도 조건을 충족한 집합이다. 이 숫자들을 독립 replication 수로 합산하면 안 된다. [설계 원문](https://arxiv.org/html/2611.17240v1)

**메커니즘 증거:** 동일 이미지에서 source query의 spatial request만 donor 객체 쪽으로 바꾸고, 같은 크기의 random-direction control과 비교한다. attention 이동을 관찰하므로 단순 correlation보다 강한 증거다. 그러나 저자가 직접 강조하듯 **이 head가 어디를 읽는지**를 제어한 것이지 network 전체 identity를 제어한 것은 아니다. [개입 원문](https://arxiv.org/html/2611.17240v1)

**진짜 기여와 metric 경계:** 저자는 foreground-only grouping에서 request의 FG-ARI .615, final patch feature .289를 보고한다. 이는 같은 clustering 규칙하의 instance assignment 차이다. GT foreground가 주어진 조건이므로 background 분리·mask 품질·detection AP로 확대하지 않는다. [결과](https://arxiv.org/abs/2611.17240)

**사용자 연구에 가져오기:** frozen encoder의 detection·tracking 실패를 볼 때 마지막 layer만 probe하지 말고 Q/K와 selected attention head를 함께 점검한다. 먼저 routing readout으로 실패 slice가 회복되는지 관찰하고, 회복이 있을 때만 작은 head 또는 routing intervention을 설계한다.

**재현상 주의:** low-resolution patch grid에서 작은 객체가 label 기준을 충족하지 못할 수 있다. 따라서 tiny-object 실패를 곧바로 readout bottleneck으로 단정하지 말고 객체별 유효 patch 수를 보고한다. 원 논문의 model input은 patch-14에 196px, patch-16에 224px로 14×14 grid를 맞춘다. 해상도 sweep은 별도 실험이다. 공개 timm checkpoint 사용은 확인했지만 이번 조사에서 독립 실행은 하지 않았다. [입력·재현 protocol](https://arxiv.org/html/2611.17240v1)

## 10) 후속 연구 씨앗 3개

아래 threshold·표본수는 **제안된 실험 계획**이며 관측 결과가 아니다.

### A. Routing에 남은 instance 정보가 작은 객체에서도 유효한가?

- **관측 → 진단:** 마지막 feature가 같은 범주 객체를 합쳐도 routing에 구분 신호가 남는다는 C1의 결과.
- **가설:** 유효 patch가 충분한 객체에서는 routing 우위가 유지되지만, 극소 객체는 tokenization 단계에서 먼저 실패한다.
- **최소 실험:** frozen DINOv2, VOC development에서 head 고정 → COCO test. residual/value/QK/attention readout을 같은 pair protocol로 비교하고 크기·유효 patch 수별 AUC를 기록한다. 이후 해상도만 바꾼다.
- **baseline·판정:** final-feature readout과 displacement-matched control. image-bootstrap CI에서 routing 이득이 재현되고 특정 patch-count 경계에서 사라지면 가설 지지. 위치 통제 후 이득이 사라지면 spatial shortcut 가능성을 우선한다.
- **negative result 가치:** tiny-object 병목이 readout보다 sampling에 있다는 범위 제한을 얻는다. GPU 시간은 미측정이며 우선 frozen inference만 수행한다.

### B. UAV stabilization의 inlier 신뢰도는 foreground coherence에 따라 깨지는가?

- **관측 → 진단:** C2의 consensus capture는 서로 맞는 moving correspondence가 잘못된 camera motion을 만들 수 있다.
- **가설:** foreground의 비율보다 집단 운동의 coherence가 capture 위험을 더 잘 설명한다.
- **최소 실험:** 논문의 released dynamic benchmark를 우선 확보하고 ORB와 강한 classical baseline을 같은 feature·time budget으로 실행한다. no-mask / foreground-mask와 stationary control을 비교한다.
- **dataset·판정:** background alignment, GCP 기반 corner error, object-position error, capture rate를 motion coherence별로 기록한다. site-disjoint 조건에서 coherence의 설명력이 유지되는지 확인한다.
- **반증·가치:** mask가 배경 feature까지 제거해 악화되거나 coherence가 설명력을 추가하지 않으면 mask 품질·foreground coverage 가설로 전환한다. UAV 결과를 maritime로 옮기기 전 별도 영상 검증이 필요하다.

### C. Early vision-only capacity의 이득은 OCR readout에 집중되는가?

- **관측 → 진단:** V1은 shared parameter 확대와 vision-only capacity가 동등하지 않다고 보고한다.
- **가설:** equal-budget early branch의 이득이 일반 지식 VQA보다 OCR·chart evidence 추출에서 크게 나타난다.
- **최소 실험:** 동일 backbone·학습 data·token budget에서 early vision-only / early shared / late vision-only branch를 비교한다. 작은 pilot은 구조 민감도 검사로 취급하고 원 논문의 scratch pretraining 재현이라 부르지 않는다.
- **dataset·baseline:** TextVQA·ChartQA와 일반 VQA, text-only retention; 접근 가능한 split·license·overlap을 먼저 확인한다. branch 없는 모델과 parameter-matched shared branch를 기준으로 한다.
- **판정·반증:** 동일 held-out protocol에서 slice별 이득과 text 손실을 함께 보고한다. seed 간 방향이 불안정하거나 shared branch가 같으면 전용 capacity 가설을 축소한다. 학습비가 커질 수 있어 A·B 다음 순서다.

## 11) 오늘 안 읽어도 되는 것과 후보 선별 기록

**실제 검토 14편 → 핵심 10편.** 핵심은 C1–C5, V1–V3, L1–L2다. CV 5편, VLM/Video 3편, Agent/Training 2편이며 Systems 성격의 TTB·FOAM과 공개물 점검을 중복 집계하지 않았다. 세부 섹션의 권장 편수는 검증 깊이를 위해 축소했다.

보류한 네 편도 원문을 읽고 이유를 남긴다.

- [K2V: Generative Keyframing For Physically Plausible Video Generation](https://arxiv.org/abs/2611.17324) — v1 11월 12일. keyframe reasoning과 interpolation 분리는 흥미롭지만 오늘은 routing·UAV 진단을 우선한다. physics benchmark SOTA 주장은 조건 검증 전 채택하지 않았다.
- [Spatial Foundry: A Multimodal Dataset for Spatial Intelligence](https://arxiv.org/abs/2611.17318) — v1 11월 12일이지만 [공식 소개](https://ranolabs.com/Blog/spatial-foundry)는 October 2026 표기다. 새 논문과 새 dataset release를 동일시하지 않았다. 공개 다운로드·license를 확정하기 전 training에 편입하지 않는다.
- [eDMD: Endpoint Distribution Matching for Few-Step Diffusion Distillation](https://arxiv.org/abs/2611.17194) — v1 11월 12일. endpoint와 intermediate distribution의 불일치 진단은 유용하지만 사용자 우선 실험과 거리가 있어 보류했다.
- [Learning the Task or Learning the Verifier? Rethinking Criteria Exposure in Embodied Self-Improvement](https://arxiv.org/abs/2611.08318) — HF 11월 13일 목록에 있으나 실제 v1은 **11월 5일**이고 후속 revision은 확인되지 않았다. 최신 연구로 재포장하지 않았다.

**오늘의 실행 선택:** A의 frozen ViT readout 진단부터 시작한다. 결과가 없더라도 유효 patch 수·크기별로 정보 부재와 readout 실패를 분리한 기록을 남기는 것이 목표다.
