## Q1. Temporal correction의 이득은 motion alignment보다 context를 보존하는 위치에서 결정되는가?

### 문제 정의와 Observation

Temporal Residual Bottleneck 논문의 CoBEVFlow 재현 진단에서 공개 hard ROI mask 경로는 DAIR-V2X AP@0.7 0.597이었다. mask 제거, identity warp, background-preserving ROI blend는 모두 0.611이었다. 저자들은 hard mask가 degradation의 주원인이라고 보고했고, mask를 고친 뒤 flow warp는 identity를 넘지 못했다. [공식 원문](https://arxiv.org/html/2610.10090v1)

### Gap과 왜 지금 가치가 있는가

비동기 collaborative perception 연구는 correspondence·flow 정확도에 집중하지만, correction을 적용하는 과정이 detector가 쓰는 static/background context를 얼마나 삭제하는지는 별도 축으로 다루지 않는 경우가 많다. 해양·항만 환경에서는 물결·안개·부표 주변 context가 작은 표적 판단에 중요하므로 이 인터페이스 문제가 더 커질 수 있다.

### 핵심 가설

`추론` deployable flow의 평균 품질보다 **원 feature를 보존하는 residual/blend interface**가 전체 AP와 calibration을 더 크게 좌우한다. flow 이득은 고속 moving-object subset에서만 나타나고 static object에서는 identity가 충분할 것이다.

### MVP·baseline·dataset·ablation

- DAIR-V2X의 공개 checkpoint 또는 보유 multi-camera/maritime feature cache를 사용한다.
- 같은 checkpoint에서 hard mask, no mask, identity warp, background-preserving blend, confidence-weighted residual을 inference-only로 비교한다.
- baseline은 stale feature, pose-only warp, oracle box/flow다.
- moving/static, near/far, small/large object subset을 사전에 정의한다.
- ROI dilation과 background floor를 별도 ablation해 mask 면적 효과와 blend 효과를 분리한다.

### Metric과 성공·실패 판정

AP@0.5/0.7, scale·motion bin별 AP, calibration error, ROI 밖 feature energy, per-object paired gain, latency·VRAM을 기록한다.

**GO:** background-preserving 방식이 두 split에서 hard mask보다 일관되게 높고, flow가 identity보다 나은 subset이 motion magnitude로 예측된다.  
**KILL/수정:** oracle flow도 identity를 이기지 못하거나 ROI 밖 context 지표와 AP 변화가 무관하면 temporal correction보다 fusion head·evaluator를 연구 대상으로 바꾼다.

### 예상 기여·compute·위험·4–8주 가능성

예상 기여는 temporal alignment를 “얼마나 잘 옮겼는가”와 “얼마나 원 정보를 보존했는가”로 분리하는 context-preservation audit이다. negative result여도 flow 기반 correction이 필요한 motion regime의 경계를 제시한다.

- **Compute cost:** 3/5
- **8GB 가능성:** cached feature 또는 축소 grid의 inference audit은 가능성이 있다. 원 논문의 전체 PointPillars pipeline 재현은 실제 peak VRAM 확인 전 미확인이다.
- **Novelty 위험:** 단순 mask bug report로 보일 수 있다. motion/scale별 causal intervention과 maritime transfer를 포함해야 논문 가치가 생긴다.
- **4–8주 논문화:** 공개 checkpoint·cache가 있으면 진단 논문 형태로 가능하다.

**점수:** novelty 4/5 · feasibility 4/5 · compute efficiency 4/5 · publication potential 4/5

## Q2. 실제 ID switch 분포를 모사한 corruption이 uniform augmentation의 negative transfer를 줄이는가?

### 문제 정의와 Observation

MOTIP2는 training context의 ID를 uniform하게 섞으면 PersonPath22 swap의 94%가 non-overlapping long-range가 되고 HOTA가 no-augmentation 59.5보다 낮은 56.1이 된다고 보고했다. GIoU 기반 spatial corruption은 long-range 31%, HOTA 61.6이었다. 저자들은 동시에 proximity prior의 예상 최난점으로 같은 위치의 동시 exit/entry를 명시했다. [공식 원문](https://arxiv.org/html/2610.10391v1)

### Gap과 왜 지금 가치가 있는가

현재 spatial sampler는 uniform보다 현실적이지만 실제 baseline ID switch의 거리·GIoU·가림 시간·entry/exit 분포를 직접 맞춘 것은 아니다. drone–bird, 선박 교차, 군중 tracking처럼 외형이 비슷한 대상에서는 같은 위치 교체가 중요한데, proximity만 강화하면 오히려 이전 ID를 새 객체에 넘길 수 있다.

### 핵심 가설

`추론` augmentation의 총 swap 수보다 실제 inference failure distribution과의 divergence가 HOTA/AssA를 더 잘 예측한다. empirical distribution matching은 long-range hallucinated swap을 줄이지만, same-location exit/entry에는 appearance-change 또는 re-entry cooldown이 추가로 필요하다.

### MVP·baseline·dataset·ablation

- DanceTrack 또는 PersonPath22 validation에서 baseline IDSW 직전 pair를 수집한다.
- distance, GIoU, occlusion length, detector confidence, track age, border entry/exit를 feature로 만든다.
- uniform, GIoU sampler, empirical histogram sampler, learned sampler를 같은 swap budget으로 비교한다.
- baseline은 no corruption, MOTIP2 spatial prior, `N_init=1/2/3`이다.
- same-location 교체 synthetic clips와 실제 border-entry subset을 별도 test로 둔다.

### Metric과 성공·실패 판정

HOTA, AssA, IDF1, IDSW, long-range IDSW, distribution JS divergence, same-location swap rate, calibration을 기록한다.

**GO:** empirical sampler가 두 scene type에서 GIoU sampler보다 낮은 distribution divergence와 높은 AssA를 보이고, appearance gate가 same-location 실패를 줄인다.  
**KILL/수정:** detector false positive가 IDSW 대부분을 설명하거나 distribution matching 뒤 이득이 사라지면 association augmentation보다 detector calibration을 우선한다.

### 예상 기여·compute·위험·4–8주 가능성

예상 기여는 tracking corruption을 arbitrary noise가 아니라 measured failure distribution으로 설계하는 protocol이다. negative result여도 geometric prior가 효과적인 장면과 해로운 장면을 분리한다.

- **Compute cost:** 3/5
- **8GB 가능성:** inference log 분석과 소형 model fine-tuning은 가능성이 있으나 full MOTIP2 training은 미확인이다.
- **Novelty 위험:** hard-negative sampling의 변형으로 보일 수 있다. same-location counterexample와 cross-dataset transfer가 필요하다.
- **4–8주 논문화:** 기존 tracker log·checkpoint가 있으면 축소 연구가 가능하다.

**점수:** novelty 4/5 · feasibility 4/5 · compute efficiency 4/5 · publication potential 4/5

## Q3. One-shot segmentation의 큰 이득은 reference choice보다 background subspace의 rank로 예측되는가?

### 문제 정의와 Observation

One-Shot Adaptive Segmentation은 single annotated reference에서 DINOv3 background direction을 추정해 feature를 orthogonalize한다. 공식 초록은 pool-boiling에서 strongest baseline 대비 mIoU 78.62% relative improvement를 보고하지만 chest radiograph에서는 comparable performance라고 명시한다. 본문 표에서는 chest X-ray mIoU가 제안법 0.3960, SAM2 0.3962였고, pool-boiling 평가는 20 frames에 기반했다. [arXiv](https://arxiv.org/abs/2610.10306) · [공식 HTML](https://arxiv.org/html/2610.10306v1)

### Gap과 왜 지금 가치가 있는가

한 reference로 추정한 background direction이 대표성을 갖는지, 성능이 reference selection에 얼마나 민감한지 보고되지 않았다. artifact가 단일 방향으로 모이는 pool-boiling과 anatomy가 복잡한 X-ray의 차이는 domain label보다 feature covariance 구조로 설명될 수 있다.

### 핵심 가설

`추론` 개선량은 domain 이름보다 background covariance의 top-eigenvalue concentration과 reference–target subspace alignment로 예측된다. rank-1 artifact domain에서는 reference가 달라도 안정적이지만 multi-directional background에서는 순위가 쉽게 뒤집힐 것이다.

### MVP·baseline·dataset·ablation

- 공개 가능한 pool-boiling 유사 영상, Montgomery X-ray, 소형 microscopy dataset에서 reference 10개를 교체한다.
- zero/one/three/five background directions 제거를 비교한다.
- baseline은 SAM2, cosine localization without orthogonalization, Gaussian-noise projection, prototype averaging이다.
- reference mask 크기와 class prevalence를 맞춘 controlled selection을 추가한다.
- target을 sequence/patient 단위로 분리해 reference leakage를 막는다.

### Metric과 성공·실패 판정

per-image IoU/Dice, reference 간 표준편차·worst-case, covariance spectrum, subspace angle, calibration, bootstrap CI를 사용한다.

**GO:** spectral concentration이 reference variance와 improvement를 두 domain 이상에서 예측하고, 필요한 projection rank가 사전 추정된다.  
**KILL/수정:** reference mask 품질이나 SAM prompt geometry가 대부분을 설명하면 background-subspace 가설을 버리고 prompt sensitivity 연구로 전환한다.

### 예상 기여·compute·위험·4–8주 가능성

예상 기여는 one-shot adaptation을 평균 최고점이 아니라 reference sensitivity와 subspace rank로 평가하는 저비용 diagnostic이다. negative result여도 “한 장이면 충분한” 조건의 경계를 정량화한다.

- **Compute cost:** 2/5
- **8GB 가능성:** cached DINO feature 또는 소형 encoder로 충분히 시작할 수 있다. DINOv3 대형 variant의 exact reproduction은 미확인이다.
- **Novelty 위험:** support-set sensitivity는 few-shot 문헌에 존재한다. artifact rank와 training-free projection의 연결을 명확히 해야 한다.
- **4–8주 논문화:** 데이터 접근만 되면 오늘 질문 중 가장 빠르다.

**점수:** novelty 4/5 · feasibility 5/5 · compute efficiency 5/5 · publication potential 4/5

## Q4. Human tactile data의 시간보다 contact diversity가 robot transfer를 더 잘 설명하는가?

### 문제 정의와 Observation

TouchScale은 human visual–tactile mid-training으로 robot manipulation 평균 성공률을 22.5%에서 57.5%로 높였다고 보고했다. 그러나 future-tactile Train Top-10은 데이터 20%에서 2.87%, 100%에서 3.31%로 0.44%p만 늘었고, tactile prediction error와 action error의 상관은 `r=0.119`였다. 저자들은 한 robot platform·네 task 제한과 future-tactile prediction의 역할이 열린 문제임을 인정했다. [공식 원문](https://arxiv.org/html/2610.10288v1)

### Gap과 왜 지금 가치가 있는가

시간 기준 scaling은 contact type, object material, force regime, viewpoint diversity를 함께 늘린다. 현재 결과만으로 500시간의 가치가 반복 관측량에서 오는지 rare-contact coverage에서 오는지, future-tactile objective가 인과 매개인지 알기 어렵다.

### 핵심 가설

`추론` 20% 이후의 평균 tactile retrieval은 포화하지만, rare contact type의 coverage가 특정 manipulation success를 높인다. 동일 시간에서 diversity를 늘린 subset이 무작위 100%보다 compute-efficient할 수 있다.

### MVP·baseline·dataset·ablation

- 공개 후 TouchScale metadata에서 contact embedding 또는 material/task proxy로 cluster를 만든다.
- 동일 총 frame/시간의 random, diversity-maximized, frequency-balanced subset을 구성한다.
- 20%와 100% checkpoint를 같은 robot demonstrations·seed·post-training budget으로 비교한다.
- baseline은 no mid-training, visual-only mid-training, future-tactile head 제거, shuffled tactile pairing이다.
- 처음에는 robot control 대신 frozen embedding linear probe와 held-out tactile retrieval로 screening한다.

### Metric과 성공·실패 판정

contact-cluster coverage, future-tactile Top-10/MRR, action error, task success와 confidence interval, compute-hours당 gain, rare-contact subset success를 기록한다.

**GO:** diversity-matched 20%가 random 20%와 100% 일부 조건을 넘고 rare-contact task 이득을 예측한다.  
**KILL/수정:** subset 간 차이가 없고 future-tactile head 제거 후에도 robot gain이 유지되면 objective attribution을 버리고 generic representation warm-start로 재해석한다.

### 예상 기여·compute·위험·4–8주 가능성

예상 기여는 embodied scaling을 hours에서 contact coverage로 바꾸는 data-centric 분석이다. negative result여도 500시간 scaling의 이득이 초반 데이터에 집중되는지 밝힌다.

- **Compute cost:** 4/5 full post-training, 2/5 frozen screening
- **8GB 가능성:** metadata·embedding 분석은 가능하다. 원 VLA post-training과 실제 robot evaluation은 8GB 범위를 벗어날 가능성이 높다.
- **Novelty 위험:** diversity sampling 일반론으로 보일 수 있다. tactile-specific contact taxonomy와 downstream mediation을 보여야 한다.
- **4–8주 논문화:** 공개 embedding/checkpoint가 있으면 screening 논문은 가능하고 full robot 검증은 일정 위험이 크다.

**점수:** novelty 4/5 · feasibility 3/5 · compute efficiency 3/5 · publication potential 4/5

## Q5. Long-context Video VLM의 temporal grounding 실패는 identity memory와 evidence retrieval 중 어디에서 시작되는가?

### 문제 정의와 Observation

HeiCo-FOCUS는 긴 수술 영상에서 ten frontier VLM을 평가했다. SEGMENT track temporal grounding 평균은 26.9%, PROCEDURE track은 12.6%였다. FRAME에서는 절반의 모델만 text-only baseline을 명확히 넘었고, 장기 event aggregation과 duration estimation에서 human rater도 각각 35%, 40%였지만 각 20문항뿐이었다. [공식 원문](https://arxiv.org/html/2610.10156v1) · [공식 코드](https://github.com/IMSY-DKFZ/orena-focus)

### Gap과 왜 지금 가치가 있는가

최종 accuracy만으로는 모델이 foreign-object identity를 잊었는지, 해당 시간 구간을 retrieval하지 못했는지, evidence를 봤지만 duration/count reasoning에 실패했는지 분리할 수 없다. 이는 수술뿐 아니라 장시간 해양 감시·항만 안전 Video VLM에도 같은 문제다.

### 핵심 가설

`추론` procedure-length degradation은 token budget 자체보다 persistent identity state의 corruption과 event-boundary retrieval 누락으로 설명된다. oracle identity ledger 또는 oracle timestamp를 제공하면 서로 다른 질문 유형이 선택적으로 회복될 것이다.

### MVP·baseline·dataset·ablation

- HeiCo-FOCUS 공개 subset 또는 timestamp annotation을 사용할 수 있을 때 100–200문항을 capability별로 표본화한다.
- full video, uniform frames, retrieval-selected clips, oracle timestamps, oracle identity ledger를 비교한다.
- baseline은 text-only, image-only, short segment, full-context VLM이다.
- video 길이와 visual token 수를 독립 조절하고, 동일 증거로 질문 wording만 바꾸는 paired set을 만든다.
- maritime adaptation은 AIS/event log가 있는 소규모 항만 영상으로 후속 검증한다.

### Metric과 성공·실패 판정

answer accuracy, temporal IoU, identity consistency, event count/duration error, evidence recall, text-only gap, length별 slope, cost·latency를 기록한다.

**GO:** oracle timestamp와 identity ledger가 서로 다른 오류 subset을 회복하고, 이 분해가 두 모델 이상과 긴 해양 영상에서 반복된다.  
**KILL/수정:** oracle evidence를 줘도 성능이 회복되지 않으면 retrieval/memory보다 language reasoning·annotation ambiguity를 주제로 전환한다.

### 예상 기여·compute·위험·4–8주 가능성

예상 기여는 long-video failure를 identity memory, evidence retrieval, post-evidence reasoning으로 분해하는 diagnostic protocol이다. negative result여도 long context를 늘리는 것만으로 해결되지 않는 capability를 밝힌다.

- **Compute cost:** 4/5
- **8GB 가능성:** 소형/quantized VLM과 cached API outputs의 분석은 가능성이 있으나 frontier model 비교와 full-hour video inference는 어렵다.
- **Novelty 위험:** retrieval ablation만으로는 약하다. persistent identity와 temporal boundary를 독립 조작하고 안전 domain transfer를 보여야 한다.
- **4–8주 논문화:** 공개 data 접근과 API 예산이 있으면 축소 diagnostic은 가능하다.

**점수:** novelty 5/5 · feasibility 3/5 · compute efficiency 2/5 · publication potential 5/5

**오늘 가장 먼저 테스트할 질문:** Q3. reference 10개를 바꾸고 background covariance의 첫 고유값 비율, subspace angle, per-image IoU를 저장한다. 재학습 없이 하루 안에 reference sensitivity 가설을 반증할 수 있다.

**RTX 5060 Ti 8GB에서도 가능한 질문:** Q3가 가장 적합하다. Q1은 cached feature가 있을 때, Q2는 log 분석 단계까지 가능하다. Q4·Q5의 full pipeline은 8GB 적합성을 확인하지 못했다.

**장기 박사주제로 키울 질문:** Q5. identity memory–evidence retrieval–reasoning 분해를 수술, 항만 감시, maritime safety VQA로 확장하면 Answer–Region/Reasoning Gap과 long-context failure를 하나의 evidence-state 연구축으로 연결할 수 있다.

## 공통 실험 원칙과 검색 결론

모든 MVP는 code/model/data revision, split, backbone·pretraining·외부 데이터, 해상도·TTA, inference framework, frame/token/compute budget, seed를 기록한다. 결과를 본 뒤 threshold·subset을 바꾸지 않고 paired unit을 먼저 고정한다.

오늘 확인한 흐름은 더 큰 모델보다 **원 정보를 보존하는 개입, 실제 failure와 맞는 training noise, reference·data diversity에 대한 민감도, 긴 영상에서의 evidence state**를 직접 측정하는 방향이다. 단일 headline score가 좋아도 원인 분해가 없으면 배포 조건과 연구 기여를 판단하기 어렵다.
