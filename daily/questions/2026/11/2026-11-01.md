## Q1. 보이는 장면을 잘 읽는 VFM은 이동 후에도 객체 상태를 유지하는가?

**Observation — [사실]** *Probing Spatial State Representations in Visual Foundation Models*은 static indoor streaming observations에서 10개 representation을 frozen probe로 평가했다. 저자들은 visible-scene readout이 강해도 object persistence·future-feature retrieval·actionability가 보장되지 않으며, task/layer/prefix length에 따라 capability profile이 달라진다고 보고한다. [arXiv](https://arxiv.org/abs/2610.40636)

**Gap**  
기존 VLM/grounding 평가는 단일 프레임의 정답률을 중심으로 하므로, 같은 객체가 camera motion 뒤에 다시 등장할 때 identity·relative location·goal relevance가 얼마나 유지되는지 분리하기 어렵다.

**Hypothesis — [추론]**  
단일-frame localization이 높은 encoder도 prefix가 길어질수록 “존재 기억”보다 “마지막 관측의 시각적 유사성”에 의존하며, 작은 객체·부분 가림·급격한 viewpoint change에서 이 차이가 더 커진다.

**Experimental Design**  
- 데이터: 공개 egocentric indoor sequence 또는 정적 scene의 합성 camera trajectory.
- baseline: DINO 계열, CLIP 계열, video/VLM encoder의 frozen feature와 linear probe.
- ablation: prefix 1/4/8/16, visible/occluded/re-entry, small/large object, true/perturbed camera pose.
- metric: current-frame localization, re-entry identity F1, persistent-state accuracy, goal-conditioned retrieval success, prefix별 latency/memory.
- 최소 실험: 20개 scene, object identity·relative direction만 annotation한 subset부터 시작.

**Expected Contribution**  
“읽을 수 있음”과 “유지·예측·행동에 쓸 수 있음”을 분리한 failure map과 camera-motion-controlled benchmark protocol.

**Risk**  
논문의 네 capability 축과 중복될 수 있다. 따라서 모바일/드론 시점의 small-object·partial-occlusion 조건, 그리고 goal-conditioned retrieval을 명시적으로 추가해야 한다.

**GO/KILL**  
re-entry identity F1이 current-frame localization과 15%p 이상 벌어지고 control보다 pose perturbation에서 더 크게 하락하면 GO; 모든 encoder에서 gap이 작으면 독립 benchmark 기여는 KILL.

## Q2. VQA는 ‘보이는 수’가 아니라 ‘물리적 개체 수’를 언제 복원하는가?

**Observation — [사실]** *PhysCount*는 546 real-world images, 4,595 human-written questions, 651 target-specific groups로 appearance 수와 physical entity 수를 구분한다. 저자들은 40개 MLLM에서 appearance counting이 identity recovery보다 훨씬 쉽고, strongest model도 모든 관련 질문을 맞힌 group이 13.36%라고 보고한다. [arXiv](https://arxiv.org/abs/2610.40530)

**Gap**  
정답만 보는 counting benchmark는 reflection·glass·screen·multi-view에서 모델이 실제 object identity graph를 만들었는지, shortcut으로 수를 맞혔는지 구별하지 못한다.

**Hypothesis — [추론]**  
모델의 entity-count 오류는 visual resolution보다 observation mode 전환(reflection→direct, direct→through-glass)에 더 민감하며, related questions를 jointly answer하게 하면 rationale-consistency는 늘지만 visual grounding은 반드시 개선되지 않는다.

**Experimental Design**  
- 데이터: PhysCount의 네 question family를 사용하고 observation mode와 appearance multiplicity로 strata를 나눈다.
- baseline: 공개 MLLM 2–3종, direct answer와 joint-answer prompt.
- ablation: single vs joint question, cropped entity evidence vs full image, resolution 2단계, mode-pair별 평가.
- metric: entity-count accuracy, group-complete accuracy, appearance–entity correspondence F1, rationale–evidence consistency.
- 최소 실험: 100 groups를 direct/reflection/through-glass로 균형 표본화해 manual evidence check.

**Expected Contribution**  
counting을 “number prediction”이 아닌 appearance graph→entity graph 추론으로 재정의하고, 정답률과 evidence consistency가 갈라지는 failure cell을 제시한다.

**Risk**  
PhysCount의 annotation과 task 정의에 의존할 수 있다. independent annotation audit와 out-of-domain imagery가 없으면 일반화 주장은 제한해야 한다.

**GO/KILL**  
joint-answer가 group-complete accuracy는 올리지만 correspondence F1을 올리지 못하면 GO(답-근거 gap); 두 지표가 함께 동일하게 개선되면 독립 failure claim은 KILL.

## Q3. 항공 해상도 예산은 mapping과 cross-view localization 중 어디에 먼저 써야 하는가?

**Observation — [사실]** *KITScenes Aerial*은 onboard sensor·vehicle pose·Lanelet2 map과 aerial imagery를 결합한 데이터셋을 제안한다. 저자들은 53-class mapping에서 항공 context가 fine-grained·extended-range mapping에 특히 유리하고, 높은 항공 해상도가 4.3 mAP(+24%)를 더한다고 보고한다. geographically disjoint cross-view localization에서 adapted feature matching baseline의 mean translation error는 5.13 m라고 서술한다. [arXiv](https://arxiv.org/abs/2610.40455)

**Gap**  
해상도 이득이 road topology, fine-grained class, long-range coverage, cross-view localization 중 어느 요인에서 발생하는지와, 동일 storage/compute budget에서 task별 최적 배분은 아직 분리되어 있지 않다.

**Hypothesis — [추론]**  
고해상도는 rare small map element에는 큰 이득을 주지만, geographically disjoint localization에는 scale/season/appearance shift 때문에 같은 비율로 전이되지 않는다.

**Experimental Design**  
- 데이터: KITScenes Aerial의 3-class/53-class mapping 및 cross-view localization split.
- baseline: aerial-only, ground-only, simple late fusion; 동일 backbone·training step·input coverage.
- ablation: aerial resolution 3단계 × mapping extent 2단계 × 3/53 classes × geographic split.
- metric: per-class mAP, rare-class recall, translation/rotation error, GFLOPs, peak VRAM, tile storage, inference latency.
- 최소 실험: 53-class validation subset에서 traffic light·lane marking 등 small/fine-grained classes만 먼저 분석.

**Expected Contribution**  
“higher resolution helps”를 class scale·geographic shift·resource budget별 conditional Pareto frontier로 바꾼다.

**Risk**  
데이터 접근과 aerial tile preprocessing 비용이 높다. 공개 baseline 재현이 어려우면 controlled downsampling study로 범위를 축소해야 한다.

**GO/KILL**  
고해상도가 rare-class recall을 5%p 이상 올리고 geographic localization error를 악화시키지 않으면 GO; 이득이 one split 또는 storage-unconstrained setting에만 있으면 제한적 분석 결과로 KILL.

## Q4. 단일-pass zero-shot anomaly localization은 작은 이상과 prompt shift에서 유지되는가?

**Observation — [저자 주장]** *RADIOlogy*는 standard CLIP의 CLS attention·spatial patch pooling이 subtle localized anomaly를 놓친다고 진단하고, multi-head attention pooling과 contrastive prompt scoring으로 dense sliding window 없이 단일-pass zero-shot anomaly detection/localization을 수행한다고 주장한다. 저자들은 medical domain 적용과 code 공개도 명시한다. [arXiv](https://arxiv.org/abs/2610.40580)

**Gap**  
단일-pass 결과가 attention pooling 자체의 spatial evidence 때문인지, prompt set·image resolution·dense refinement의 조합 때문인지는 초록만으로 분리되지 않는다. 따라서 다른 baseline과의 수치 비교는 **not strictly apples-to-apples**다.

**Hypothesis — [추론]**  
single-pass advantage는 large/high-contrast anomaly에서 유지되지만, tiny anomaly·unseen prompt wording·resolution downsampling에서 localization calibration이 빠르게 무너진다.

**Experimental Design**  
- 데이터: 공개 industrial 또는 medical anomaly benchmark 한 개를 선택하고 object size strata를 만든다.
- baseline: frozen CLIP/RADIO feature, global pooling, attention pooling, windowed inference.
- ablation: anomaly area 4구간, prompt template 5개, input resolution 3단계, refinement on/off.
- metric: pixel AUROC, PRO 또는 region F1, image AUROC, expected calibration error, p50 latency, VRAM.
- 최소 실험: 200 images로 size×prompt grid를 먼저 만들고, failure cell만 dense annotation 검증.

**Expected Contribution**  
zero-shot anomaly localization을 average AUROC가 아닌 size·prompt·compute-conditioned calibration으로 평가하는 protocol.

**Risk**  
공개 code와 exact prompt/configuration을 확보하지 못하면 재현이 어렵다. code release의 commit/config를 먼저 고정해야 한다.

**GO/KILL**  
attention pooling이 windowed baseline 대비 tiny-anomaly region F1을 유지하면서 latency를 30% 이상 낮추면 GO; 이득이 prompt 하나 또는 dense refinement에만 의존하면 method claim은 KILL.
