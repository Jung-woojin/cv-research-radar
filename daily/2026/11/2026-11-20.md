### C1. Does the Action Matter? Probing Action-Conditioned Semantic Forecasting as a World Model for Autonomous Driving

**최근 신규, v1 11/18.** 과거 segmentation과 ego action으로 미래 semantic map을 예측한다. 같은 U-Net에서 no-action·input concat·FiLM을 비교하고 action을 shuffle·stop·zero-yaw·mean으로 바꾼다. **저자 보고:** Cityscapes mid-term mIoU는 no-action 57.02, FiLM 59.47이지만 shuffled action에서는 FiLM이 23.17 points 하락한다. [논문](https://arxiv.org/abs/2611.24840)

**진단:** 정상 action의 작은 이득과 잘못된 action의 큰 손실은 공존한다. 교란은 입력 의존성을 측정하며 올바른 대체 미래를 예측했는지는 증명하지 않는다. **제안:** action 오차의 크기와 history 양립 가능성을 맞춘 robustness curve를 먼저 본다. 새 block보다 조건 신뢰도의 진단이 우선이다. 자세한 한계와 비용은 아래 mini-review에 기록했다. [실험·한계](https://arxiv.org/html/2611.24840v1)

### C4. NativeSeg: Native Vision Language Segmentation of 3D Computed Tomography via Spatial Visual Tokens and Verified Local Zoom

**최근 신규, v1 11/18.** Qwen3.8-27B에 LoRA를 적용하고 2D spatial token과 five-slice U-Net 경로로 mask를 읽는다. presence gate·error gate·local zoom을 사용한다. **저자 보고:** adult-only 학습으로 adult DSC 86.81%, zero-shot pediatric 87.04%를 제시한다. [논문·설계](https://arxiv.org/html/2611.24443v1)

**진단·제안:** empty slice가 많은 평가에서는 gate의 평균 비용 절감과 target-present slice의 누락을 따로 봐야 한다. “오류 예측이 낮아졌을 때만 update 수락”도 실제 DSC 단조 증가를 보장하는지 검증해야 한다. 같은 backbone의 readout 비교는 유용하지만 specialist와의 전체 비교는 학습·구성 조건 확인 전 **not strictly apples-to-apples**다. 코드 README는 단일 Stage-B 실행과 논문 표용 stage-decoupled 실행을 구분한다. full training recipe는 단계별 8/6/4/1 GPU 구성을 보존한다. [공식 구현](https://github.com/step-out/NativeSeg)

UAV에서는 PSNR 외에 tiny-object recall을 고정 detector로 검사할 가치가 있다. 학습된 복원이 표적을 지우는지 보려는 제안이며 논문이 확인한 결과가 아니다. **진단·제안:** prefill의 visual help와 decoding 간섭을 분리하는 것이 기여다. 모든 모델·데이터에서 개선하지는 않는다. token 길이·질문 순서·문항 의미·region overlap을 맞춘 채 repair/damage 전환표를 보고, mask가 실제 backend에서 적용됐는지 먼저 검사한다. training-free는 무비용이 아니다. 공개 코드·checkpoint·실측 VRAM은 이번 조사에서 확정하지 않았다. [기전·개입](https://arxiv.org/html/2611.24785v1)

### V4. The Elephant in the Question: Unified Models Picture the Concepts Behind Their Answers

## 4) LLM / Agent / Training / System 변화 3편

### L1. Multi-Agent Memory Inconsistency: Where Factual Conflicts Disappear in LLM Agents

**최근 revision, v1 11/17·v2 11/18.** Harvey LAB 문서 검토에 통제된 factual conflict를 넣고 evidence flow를 추적한다. **저자 보고:** 세 모델의 비슷한 generation spending 조건에서 delegation은 양쪽 claim 검색을 50.2→68.7%로 높이지만 conflict detection은 16.2→13.2%로 낮춘다. retrieved pair 중 양쪽을 worker가 보고한 비율은 35.2%다. [논문](https://arxiv.org/abs/2611.22245)

**진단·제안:** 검색 성공과 report completeness를 별도로 본다. 한 worker가 양쪽을 읽는 조건과 worker 사이에 분산된 조건을 구분한다. 모든 multi-agent architecture가 나쁘다는 증거가 아니다. 동일 retrieved evidence를 고정하고 provenance가 있는 양쪽 claim 전달만 개입하면 handoff 병목을 분리할 수 있다. 공식 benchmark의 공개 artifact·API 비용·v2 변경점은 미확인이다.

### L2. Language Models Can Rewrite Their Own Weights

**최근 revision, v1 11/16·v2 11/18.** 27B open model에 weights·graded answers·self-execution을 제공해 gradient 없이 weight edit를 제안·시험·선택한다. **저자 보고:** 미관측 문제에서 +6.6 points, 연속 여덟 session에서 개선을 보고한다. [논문](https://arxiv.org/abs/2611.21885)

**진단·제안:** gradient-free가 search-free·supervision-free·compute-free를 뜻하지 않는다. practice feedback, edit 후보 수, 실패한 후보, validation 선택량을 budget-matched random/structured edit와 비교해야 한다. benchmark leakage·반복 selection·다른 task 손상 검사 전 일반적 self-improvement로 확대하지 않는다. 이번에는 독립 성능이나 code·weight 배포·총 추론 비용을 확인하지 못해 실험 우선순위는 낮췄다.

### L3. MIRAGE: A Framework for Multi-hop Reasoning under Dynamic Knowledge Injection

**최근 신규, v1 11/18.** NEXUS는 기존 기억과 충돌하는 정보와 완전히 새 정보를 나눠 평가한다. MIRAGE는 hop별 P(True) routing과 template corrector로 source-trust·구조 오류를 다룬다. 네 LLM family·두 benchmark의 개선은 **저자 주장**이며 이번 조사에서 표 수치는 확정하지 않았다. [논문](https://arxiv.org/abs/2611.24058)

**진단·제안:** hop 정답률과 최종 정답률, confidence calibration을 분리한다. 모델이 확신하는 옛 지식이 틀린 slice에서 route가 악화되는지 검사한다. VLM의 image/text trust 문제와 연결할 수 있지만 multimodal에서 검증한 결과는 아니다. code·dataset 실제 배포와 추가 호출 비용·seed variance는 미확인이다.

## 6) 연구적으로 중요한 Finding 3개

1. **유용성과 의존성은 다른 축이다.** C1의 action gain/drop과 V1의 repair/damage는 추가 정보의 순이득만으로 실패 비용을 알 수 없음을 보여준다. 이는 두 연구를 연결한 **추론**이다. [Action](https://arxiv.org/abs/2611.24840) · [Co-asking](https://arxiv.org/abs/2611.24785)
2. **읽고 찾았다는 것과 결론에 통합했다는 것은 다르다.** V2의 figure mention과 L1의 양쪽 claim retrieval을 각각 진단·전달과 구분해야 한다. [Figure verification](https://arxiv.org/abs/2611.24353) · [Memory inconsistency](https://arxiv.org/abs/2611.22245)
3. **표현·readout·정보 유효성의 병목을 분리할 수 있다.** C2의 통제 baseline, C4의 spatial readout, C5의 memory-validity 구분은 architecture 추가 전 비교 계약과 입력 정보부터 점검할 근거다. 보편적 동일 기전을 주장하는 것은 아니다. [Motion statistics](https://arxiv.org/abs/2611.24792) · [NativeSeg](https://arxiv.org/abs/2611.24443) · [Stereo memory](https://arxiv.org/abs/2611.24848)

## 7) 과대평가 가능성 / 주의할 연구

- **Self-rewriting:** “no training”을 “추가 최적화 비용 없음”으로 읽지 않는다. graded practice·self-test·edit selection을 포함한 전체 budget과 held-out 절차를 먼저 읽는다. [원문](https://arxiv.org/abs/2611.21885)

## 9) Top 1 mini-review — Does the Action Matter?

**왜 읽는가:** “조건을 넣어 정확도가 올랐다” 다음에 “그 조건이 틀리면 어떻게 되는가”를 묻는다. 사용자의 representation/readout 진단 선호와 맞는다.

**실험 논리:** FiLM·concat·no-action을 비교하고 synthetic positive/negative control로 개입의 작동을 점검한다. 실제 데이터에서는 정상 예측과 action 대체에 대한 변화를 분리한다. 이 구조는 action을 거의 사용하지 않는 모델과 지나치게 민감한 모델을 구별하는 출발점이다. [논문](https://arxiv.org/abs/2611.24840)

**기여와 한계:** dependence 크기는 correctness가 아니다. 원문도 shuffled/stop action이 관측 history와 모순돼 OOD 효과를 섞을 수 있다고 명시한다. BDD100K target은 SegFormer pseudo-label이며 camera·환경·frame rate·GPS action 품질이 함께 달라진다. 단일 front camera·짧은 horizon의 compact semantic forecaster 결과를 대형 world model·planning 안전성으로 일반화하지 않는다. [Discussion](https://arxiv.org/html/2611.24840v1)

**비용·가져올 점:** 저자 표의 FiLM은 13.07M, 256×512 FP32 batch 1 V100-32GB에서 한 step 200.2 GFLOPs·20.5ms다. 이는 전체 perception pipeline 수치가 아니다. UAV에서도 먼저 action reliability별 frozen evaluation을 만들고 필요성이 확인될 때 gating을 도입한다. 원문이 이미 similar-history intervention과 object-level extension을 언급하므로 그것만으로 새 contribution이라 주장하지 않는다. 센서 오차 구조·독립적인 causal target 검증이 추가돼야 한다.

## 10) 후속 연구 씨앗 3개

모두 **제안**이며 이번 실행에서 실험하지 않았다. GO/KILL은 사전 설계 기준이고 관측된 성과가 아니다.

### S1. action 신뢰도에 따른 조건 이득–손실 곡선

**질문·진단:** 큰 action drop은 유효한 조건 의존성인가, history와 양립 불가능한 입력의 충격인가?  
**가설:** 같은 오차 크기라도 현실적인 sensor noise와 history-compatible 대체는 random shuffle과 다른 오류 곡선을 만든다.  
**최소 실험:** 공개 C1 모델 확보 후 동일 Cityscapes/BDD sample에서 정상·동일 크기 perturbation·history-matched action·no-action을 paired 평가한다. yaw/speed 오차와 scene motion을 별도로 통제하고, 가능하면 action-dependent synthetic 환경의 정답 미래로 correctness를 검사한다. 첫 단계에 새 architecture는 없다.  
**지표·GO/KILL:** mIoU·moving-object IoU·오차 크기별 degradation과 matched/unmatched 차이를 seed별 기록한다. 교란 크기를 맞춘 뒤에도 차이가 지속되면 GO. matched support가 부족하거나 변화가 오차 크기로만 설명되면 가설을 축소한다.  
**비용·novelty:** checkpoint evaluation부터 시작하는 cost 2/5의 계획 판단. 학습 재현은 더 무겁다. 원문이 matching을 이미 제안했으므로 sensor-noise calibration·독립 correctness 검증 없이 novelty를 주장하지 않는다. negative result는 OOD보다 action 오차 자체가 지배적인 조건의 경계가 된다.

### S2. co-asking의 visual help는 잘못된 선행 질문에도 유지되는가?

**질문·진단:** 선행 질문이 잘못된 전제를 가진 경우 shared prefill은 유용한 visual search인가, 잘못된 concept의 주입인가?  
**가설:** answer isolation은 decoding 간섭을 줄여도 prefill에서 이미 주입된 false premise는 제거하지 못한다.  
**최소 실험:** DCI/GQA의 같은 이미지·target 질문을 고정하고 선행 stem을 grounded·존재하지 않는 객체 전제·길이/어휘를 맞춘 중립 질문으로 바꾼다. single question, plain co-asking, 논문 mask를 baseline으로 둔다. 소형 지원 모델 하나에서 mask 소비부터 확인한다.  
**지표·GO/KILL:** clean-correct→wrong, error→correct, false-premise 수용률·target localization·질문 순서 민감도를 분리한다. 길이·순서를 맞춘 후 prefill 오염이 반복되면 GO. 효과가 어휘·길이로 설명되면 KILL/축소한다.  
**비용·novelty:** 소형 inference 계획 cost 2/5이나 실제 8GB 가능성은 미확인이다. 원문의 question-order·overlap 대조와 겹치므로 false-premise 조건이 선행연구와 독립적인지 추가 검색이 필요하다. negative result는 해당 mask의 robustness 경계를 제공한다.

### S3. agent의 evidence handoff는 conflict를 보존하면서도 오경보를 억제할 수 있는가?

**질문·진단:** claim 두 개를 전달하는 것만으로 모순 판정이 회복되는가, 출처·시점·대상 정합이 필요한가?  
**가설:** provenance 없는 강제 pair 전달은 진짜 conflict recall과 가짜 conflict를 함께 늘릴 수 있다.  
**최소 실험:** L1의 controlled documents를 확보해 retrieved set을 고정한다. 자유 summary·claim pair·pair+source/date/entity schema를 같은 token budget으로 비교한다. 진짜 충돌 외에 시점/대상이 다른 비충돌 pair를 대조군으로 넣는다. API 호출 전에는 저장된 worker report의 전달 누락 감사부터 시작한다.  
**지표·GO/KILL:** evidence 전달 완전성·conflict precision/recall·false accusation·근거 위치 일치를 기록한다. 진짜 conflict 회복과 비충돌 precision 보존이 함께 나타나면 GO. 전달 완전성만 늘고 진단이 그대로면 통합 단계 병목으로 이동한다.  
**비용·novelty:** 정적 감사 cost 1/5, 실제 재실행 3/5의 계획 판단이며 API 금액은 미확인이다. 원문 profiler와 겹치므로 provenance의 필요 조건·비충돌 대조가 추가돼야 한다. negative result도 retrieval과 integration의 병목을 분리한다.

## 11) 오늘 안 읽어도 되는 것과 후보 장부

16편 중 아래 3편은 공식 초록까지 확인했지만 본문 우선순위에서 제외했다.

- [Unified Law for Visual Tasks (The Four Laws of Computer Vision)](https://arxiv.org/abs/2611.24917): 1,000개 이상 input–output mapping을 다룬다는 저자 주장은 크지만, 범위가 넓어 오늘의 작은 진단 실험과 연결하려면 task 독립성·비교 계약의 추가 검토가 필요하다.
- [Jeveration: System One Models Now Generate](https://arxiv.org/abs/2611.24738): frozen VLM·shared random state·parallel generation이 흥미롭지만 오늘은 생성 품질 최적화보다 실패 진단을 우선했다.
- [$Z$-sight: Unifying Vision-Language-Action and Latent World Modeling](https://arxiv.org/abs/2611.24940): native visual token의 미래·action 공동 생성은 중요하다. 다만 robot/human-video 학습과 실제 robot 재현 부담이 커 후속 독서로 남긴다.

선정 13편은 C1~C6, V1~V4, L1~L3다. 제외는 연구의 질에 대한 판정이 아니다. 오늘 가장 먼저 할 일은 S1의 비교 계약을 작성하고 checkpoint·데이터 확보 여부를 확인하는 것이다.
