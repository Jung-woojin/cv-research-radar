# 핵심 트렌드 7. ViT vs CNN 논쟁보다 task-structured architecture choice로 이동 — 구조 변화

현재 흐름은 “어떤 family가 승자인가?”가 아니다.

```
Spatial locality          → CNN
Global dense semantics    → ViT / foundation encoder
Long temporal recurrence  → SSM / recurrent state
Open-vocab semantics      → frozen vision/text encoder
Edge deployment           → compact CNN / EfficientViT
Complex multimodal task   → hybrid
```

PointEvent는 SSM을 긴 temporal evidence에 사용하고, small edge student는 CNN/hybrid를 쓴다.

즉 ViT dominance가 끝난 것이 아니라 **모든 문제를 ViT 하나로 푸는 사고가 약해지고 있다.**

# Architecture / 학습 / 추론 변화

## Architecture
- ViT/foundation encoder → semantic representation
- SSM → long sequential evidence
- CNN/EfficientViT → edge specialist
- DETR → detection interface
- explicit memory/state → temporal continuity

## 학습
Feature equality distillation보다 relation/structure preservation이 증가.

Noise2Noise Revisited가 보여준 것처럼 loss보다 training pair distribution이 더 큰 inductive bias를 만들 수 있다.

## 추론
```
Input
→ cheap diagnostic
→ route / skip / adapt / fuse
→ expensive compute only if needed
```

## 시스템
Low precision도 dtype만 바꾸는 문제가 아니라 kernel / quantization / dataflow 전체 설계 문제로 이동.
