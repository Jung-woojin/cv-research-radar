## 2. CuRSE-Bench — 라벨의 문화적 조건과 접근 가능성을 분리한다

**확인 사실·저자 보고.** v1은 11/16 10:05:19 UTC다. 논문은 문화 특화 prompt 10,709개와 일반 control 2,648개, 6개 지역·10개 harm 축을 기술한다. 문화적 유해성을 문서화된 출처에 귀속한 판단으로 한정하며 보편적 문화 정답이라고 주장하지 않는다. [제출 이력·규모](https://arxiv.org/abs/2611.20821)

**task·split·license·artifact.** T2I 안전성 평가용 prompt benchmark다. 논문은 기관 연구자의 서명 agreement와 비상업 연구용 gated 접근을 명시하고 생성모델 학습·미세조정을 금지한다. rendered image는 배포하지 않으며 공개 preview와 gated 설명 필드가 다르다. 실제 corpus 다운로드와 train/val/test membership은 확인하지 못했다. [접근 정책](https://arxiv.org/html/2611.20821v1#Sx3)

**annotation·bias.** 저자는 vector별 복수 출처 검증, contested 항목 제외, rationale cluster 단위 분석을 설명한다. 부록의 중복 제거는 정규화 문자열 일치이며 embedding 기반 의미 중복 제거가 아니다. 영어 중심 출처와 지역 집계가 만드는 bias도 인정한다. 이는 독립 검수 결과가 아닌 **저자 보고**다. [codebook·통계·구현 원문](https://arxiv.org/html/2611.20821v1)

**진단 → 가설 → 최소 실험.** 같은 의미 vector의 paraphrase를 독립 표본처럼 취급하면 불확실성을 과소평가할 수 있다는 **추론**이다. 승인된 접근 후 vector/rationale/locale ID로 group manifest를 만들고 item 평균과 cluster 평균을 병기한다. 같은 judge·rubric에서 문화 persona만 바꾸며, 허용된 자료를 문화권 검수자가 blind 확인한다. 다른 안전성 benchmark와의 단일 순위 비교는 **not strictly apples-to-apples**다.

**GO/KILL.** 접근 조건과 cluster 단위 분석 설계는 GO. corpus를 이미 받았다고 표현하거나 라벨을 문화 전체의 합의로 해석하는 것은 KILL.

**bias·호환성.** 저자는 야외 NIR 감도가 red-channel Stokes에 영향을 줄 수 있다고 밝힌다. 일반 RGB 환경맵과 비교하면 조명 정보 자체가 달라 **not strictly apples-to-apples**다. [논문 한계](https://arxiv.org/html/2611.21334v1) · [공식 프로젝트](https://yongheeoh.github.io/PolarimetricEnvironmentMap/)

**진단 → 가설 → 최소 실험.** 측정 좌표계·유효 mask·미측정 S3를 혼동하면 representation 실패처럼 보일 수 있다는 **추론**이다. collection+scene ID를 키로 쓰고 빈 경로를 제외한 manifest를 만든다. 같은 장면·material·renderer에서 full-Stokes와 S0-only만 바꾸고 유효 영역의 결과를 비교한다. 같은 장소·날짜의 장면은 묶어서 분리한다.

**GO/KILL.** 공개량·측정 여부·mask 감사는 GO. 100행을 다운로드 가능한 full-Stokes 100장으로 세거나 미측정 S3를 정답 0으로 학습하는 것은 KILL.
