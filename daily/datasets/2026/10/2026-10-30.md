## 1) Egocentric Tennis — 동기화된 시점·접촉 주석이 있는 동적 스포츠 데이터

- **확인된 사실**: 저자들은 ego video와 다섯 개 allocentric video, 추정 global position, labeled contact time, annotated stroke type을 동기화한 tennis dataset을 수집했다고 밝힌다. 예측 task는 2D ego player/3D ball localization, future trajectories, forehand/backhand anticipation, next-contact time과 그 시점의 3D ball position이다. v1은 2026-10-27 17:47 UTC다.
- **규모·task·split**: 논문 abstract와 공식 project page에서 sample/sequence 수와 train/validation/test split recipe는 확인하지 못했다. 따라서 이 단계에서 규모나 split-level generalization을 주장하지 않는다.
- **license / artifact**: project page에는 paper 정보만 있었고, dataset download, annotation schema, license, checksum, evaluation code의 공개는 확인하지 못했다.
- **저자 주장**: depth auxiliary information이 3D ball localization을 크게 개선하고, 긴 image history가 ball forecasting을 개선하지 않는다는 결과로 metric-depth와 scene-context의 중요성을 제시한다.
- **bias / 호환성**: 같은 경기·선수·코트가 train/test에 섞이면 ball trajectory와 camera context가 shortcut이 될 수 있다. ego-to-allocentric synchronization error도 temporal label error와 구분해야 한다.
- **진단 → 가설 → 최소 audit**: player·match·court를 group key로 두면 random split 이득 일부가 사라질 수 있다는 가설이다. match-group split으로 재평가하고, 100 contact에 대해 ego/allocentric timestamp offset 및 contact/stroke agreement를 이중 주석으로 확인한다.
- **GO/KILL**: match-group split에서도 depth auxiliary의 3D-ball 이득이 유지되면 sensor-fusion research를 GO; timestamp calibration과 split recipe가 없으면 leaderboard 인용은 KILL이다.

## 2) MCN — 영화 단위 leakage를 피해야 하는 character naming / first-occurrence annotation

- **확인된 사실**: Oxford 공식 페이지는 MCN이 character naming(CN)과 first occurrence(FO)를 주석한다고 설명한다. CN은 dialogue에서 name이 발화된 video segment와 ground-truth name-to-track mapping을 짝짓고, FO는 각 principal character의 첫 화면 등장 및 첫 이름 공개 시점을 기록한다. 407개 영화의 23,792개 multiple-choice CN instance와 20개 영화의 FO 주석을 제시한다. arXiv v1은 2026-10-27 17:20 UTC다.
- **task / split**: name-to-face track assignment와 online character-bank construction이다. 영화 단위 train/validation/test 분리, actor overlap 방지, subtitle/face-track 추출 recipe는 공식 페이지에서 확인하지 못했다.
- **license / artifact**: 공식 page에는 Code와 Dataset navigation이 있으나 이번 확인에서 직접 downloadable data, 영화 clip 재배포 권리, dataset license·manifest·checksum을 검증하지 못했다. page 자체의 CC BY-SA 표기는 project-page source license이지 film data license가 아니다.
- **저자 주장**: colour-permutation augmentation이 colour-frequency shortcut을 막는 데 중요하며, video와 dialogue를 합쳐 streaming character bank를 구축한다고 말한다.
- **bias / 호환성**: 같은 franchise/actor/film segment가 split을 넘으면 identity shortcut이 생길 수 있다. subtitle의 name mention 빈도와 face-track coverage가 task 난이도를 좌우할 수 있다.
- **진단 → 가설 → 최소 audit**: model gain 일부가 narrative inference보다 actor/film identity overlap에서 나온다는 가설이다. movie-level, franchise-level, actor-disjoint split을 나눠 CN 정확도를 비교하고, name frequency와 track length로 stratify한다.
- **GO/KILL**: actor-disjoint에서도 first-name-reveal 이전 구간의 성능이 유지되면 temporal identity inference 연구를 GO; film-level split이 확인되지 않으면 character-generalization claim은 KILL이다.

## 3) Soccer event spotting — 130개 수동 event의 작은 cross-dataset 검증

- **확인된 사실**: 원문은 full-length soccer broadcast 3개를 수동 주석해 130 event를 만들었고, overlapping clip·visual storyboard·aligned commentary transcript를 입력으로 사용한다고 적는다. best configuration은 F1@5s 72.0%를 보고하며, frame별 입력보다 storyboard가 inference cost를 72% 줄였다고 주장한다. v1은 2026-10-27 17:24 UTC다.
- **규모·task·split**: task는 zero-shot event detection/classification/temporal localization이다. train split은 없다고 설명하지만, 3경기 선정 기준, event taxonomy, annotator 수·agreement, public release와 license는 확인하지 못했다.
- **bias / 호환성**: 130 event는 event class·league·commentator style에 민감할 수 있다. SoccerNet-trained model과의 cross-dataset 비교는 annotation tolerance, broadcast source, evaluation protocol이 다르면 not strictly apples-to-apples다.
- **진단 → 가설 → 최소 audit**: headline event와 commentary phrase의 상관이 높다면 visual grounding 없이도 F1이 높아질 수 있다. transcript-only, storyboard-only, shuffled-commentary 조건을 동일 3경기에 적용하고 per-class confidence interval을 bootstrap한다.
- **GO/KILL**: shuffled-commentary에서 성능이 명확히 하락하고 visual-only보다 multimodal 이득이 유지되면 grounded event annotation을 GO; event taxonomy·temporal tolerance가 불명확하면 72.0%를 다른 dataset과 순위 비교하는 것은 KILL이다.

## 4) SceneFun3D / TopoField — field-to-instance evaluator의 coverage 분해

- **확인된 사실**: TopoField 기술 보고서는 functional segmentation에서 point-wise semantic field와 confidence-ranked discrete instance mask 사이의 field-to-instance gap을 다룬다. SceneFun3D validation 30 scene, 561 ground-truth instance에서 IoU-0.5-valid candidate existence 67.2%, top-1 coverage 20.0%, AP 28.286%, AP50 41.383%, AP25 47.558%을 보고한다. v1은 2026-10-27 13:29 UTC다.
- **task / split**: indoor point cloud의 knob/button/socket 등 interactive part instance segmentation이다. 이 보고서에서 SceneFun3D의 full split policy, point-cloud provenance, class taxonomy/license 또는 official evaluator commit은 확인하지 못했다.
- **저자 주장**: 13회 test-time forward pass consensus와 deterministic decoder가 candidate construction과 ranking gap을 분리해 challenge 성능을 높인다고 설명한다.
- **bias / 호환성**: 13-pass augmentation은 단일-pass system과 compute-equivalent 비교가 아니다. candidate existence와 top-1 coverage는 AP를 설명하는 보조 지표이지 대체 지표가 아니다.
- **진단 → 가설 → 최소 audit**: candidate recall의 병목과 ranking의 병목이 서로 다를 것이라는 가설이다. augmentation count 1/3/13, core/support threshold, class별 candidate recall을 분해하고 point identity cache의 coverage-normalization ablation을 수행한다.
- **GO/KILL**: 13-pass를 3-pass로 줄여도 candidate recall이 유지되면 low-cost consensus 연구를 GO; evaluator commit과 augmentation budget이 없으면 AP 단독 비교는 KILL이다.

## 오늘의 종합 진단

### Observation

새 데이터 신호의 공통점은 “무엇을 맞혔는가”보다 **언제/어떤 view에서/어떤 identity에** 맞혔는가를 주석과 evaluator에 넣는 데 있다. 그러나 split·license·download artifact의 공개 여부는 사례별로 불완전하다.

### Diagnosis

MCN은 영화·actor-level overlap, Tennis는 match/player-level overlap, Soccer는 transcript shortcut, SceneFun3D는 candidate generation–ranking coupling이 각각 가장 큰 측정 교란 요인이다.

### Mechanism 가설

세분화된 temporal/multiview annotation의 이득은 실제 causal understanding보다 group overlap, metadata cue, evaluation tolerance, multi-pass test-time budget에서 생길 수 있다.

### 최소 공통 실험

1. movie/match/player/league/scene의 group-disjoint split을 적용한다.
2. text-only·vision-only·shuffled text 또는 synchronized-view ablation으로 shortcut을 분리한다.
3. annotator agreement, timestamp offset, temporal tolerance를 기록한다.
4. 공개 artifact에는 license, manifest, checksum, evaluator commit, split recipe가 모두 있어야 comparative benchmark로 승격한다.

## 오늘의 GO / KILL

- **GO**: MCN의 actor-disjoint split과 Tennis의 match-group split은 적은 모델 변경으로 identity/context shortcut을 반증할 수 있다.
- **GO**: Soccer의 shuffled-commentary control은 multimodal grounding을 바로 검증한다.
- **KILL**: artifact·license·split recipe가 확인되기 전 세 dataset을 공개 재현 benchmark로 취급하지 않는다.
- **KILL**: TopoField의 13-pass 결과를 one-pass method와 compute-equivalent라고 부르지 않는다.
