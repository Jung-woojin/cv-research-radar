## 2. CV / DL-CV 핵심 논문 6개

### 2.1 Structure-Aware Matching for Robust UAV Thermal-to-Satellite Geo-Localization (SAMF)

- **문제:** 열화상 UAV query와 RGB satellite reference는 색·밝기·시점이 달라 appearance 중심 retrieval이 저조도·약한 texture에서 불안정하다.
- **방법:** Swin-T feature에 semantic-preserving, 8방향 response, low-frequency branch를 합친 DSEM을 적용하고, modality별 affine parameter를 쓰는 MARM으로 channel 통계를 정렬한다.
- **확인된 사실:** Thermal-UAV-Paired는 train/validation/test 7,886/1,407/2,350 쌍이며 코드와 dataset 링크가 [공식 저장소](https://github.com/YuxinWang879/SAMF)에 공개됐다.
- **저자 주장:** Boson-nighttime에서 R@1 93.6%, 512 m prior 내 평균 위치오차 12.3 m를 보고했다. Thermal-UAV-Paired에서는 R@1 97.0%, 위치오차 4.8 m다. 단독 DSEM이나 단독 MARM은 strong baseline을 안정적으로 넘지 못했고 결합 시 이득이 컸다.
- **주의:** paired satellite crop이 query 위치에서 생성되므로 실제 대규모 gallery의 지리·계절·고도 변화보다 쉬울 수 있다. 비행 단위 holdout과 geographic exclusion radius를 확인해야 한다.
- **진단→가설→최소 실험:** 해무 환경에서 texture가 사라질 때 오분류가 늘어난다 → 경계 방향과 저주파 layout은 상대적으로 남는다 → 기존 해무 classifier에 fixed Kirsch 8방향 branch와 5×5 low-pass branch만 추가하고 날짜·카메라 holdout의 macro-F1, ECE, blur 강도별 성능을 측정한다.
- **연관성:** 해무·야간·UAV·remote sensing 연구에 가장 직접적이다. [원문](https://arxiv.org/abs/2610.12835)

### 2.2 WoodBR-Cross: individual-tree-disjoint benchmark

- **문제:** 같은 나무에서 얻은 여러 절단면 이미지가 train/test에 함께 들어가면 species identification 점수가 과대평가될 수 있다.
- **방법:** 4,875장, 38개 taxonomic class, 303개 개체를 catalogue code로 연결하고, species subset에는 3,406장·20 class·214개 나무를 구성했다. B2 split은 같은 나무의 모든 이미지를 한 fold에 둔다.
- **저자 주장:** 3개 outer fold와 5개 seed로 평가했으며 B2 tree-level macro-F1은 ConvNeXt-Tiny 0.8621±0.0317, frozen DINOv2 feature 0.9000±0.0722였다.
- **해석:** 모델 비교보다 entity-disjoint split과 border-only/random-label control을 함께 둔 평가 설계가 핵심이다.
- **진단→가설→최소 실험:** 해무 데이터에서 연속 frame이 split을 가로지르면 배경을 외운다 → 날짜·카메라 단위 group split이 실제 성능을 낮추지만 일반화 추정은 더 정확하다 → image-random, burst-group, day-camera-group 세 split을 동일 DINOv2 linear probe로 비교한다.
- **연관성:** 최근 shortcut 진단을 해무 dataset protocol로 옮기는 가장 간단한 blueprint다. [원문](https://arxiv.org/abs/2610.12676)

### 2.3 Scaling Multi-Teacher Distillation for Digital Pathology (OMNI)

- **문제:** 여러 foundation teacher의 표현을 한 student token에 동시에 압축하면 teacher 수가 늘수록 충돌이 생긴다.
- **방법:** teacher-specific token, block-structured attention mask, tail MoE, 대조 손실로 각 teacher 공간을 따로 보존하고 downstream에서 평균 결합한다.
- **확인된 사실:** [공식 프로젝트](https://sofiene-boutaj.github.io/omni-projectpage/)에 code, 4개 model weight, embedding dataset 링크가 있고 10개 teacher와 39개 tile/slide task를 다룬다.
- **저자 주장:** OMNI-L은 tile F1 87.8%, slide balanced accuracy 63.5%를 보고했고, 큰 teacher보다 최대 10배 낮은 GFLOPs를 주장한다. 공식 페이지의 ablation에서는 attention mask, MoE tail, InfoNCE 제거가 각각 평균 score를 낮췄다.
- **주의:** pathology domain과 TCGA 기반 pretraining의 편향이 강하다. teacher diversity가 일반 자연영상에서도 같은 이득을 주는지는 미확인이다.
- **진단→가설→최소 실험:** CNN·ViT·SSM teacher를 한 CLS로 distill하면 inductive bias가 평균화된다 → teacher별 token을 유지하면 complementarity가 남는다 → CIFAR-100 또는 해무 데이터에서 3개 teacher의 shared-token/teacher-token distillation을 동일 student·step으로 비교하고 CKA와 OOD macro-F1을 기록한다.
- **연관성:** CNN/ViT/SSM hybrid 연구를 architecture 결합 대신 representation distillation으로 시험할 수 있다. [원문](https://arxiv.org/abs/2610.12574)

### 2.4 MemReg: Streaming Outdoor LiDAR Point Cloud Registration with Hybrid Memory Buffers

- **문제:** pair-wise registration은 sparse scan, 낮은 overlap, outlier가 있는 연속 LiDAR에서 과거 정보를 버린다.
- **방법:** implicit feature buffer와 explicit pose buffer를 함께 유지하고, dynamic history weighting으로 현재 scan과 과거 pose-related feature를 결합한다.
- **저자 주장:** KITTI, nuScenes, Apollo-Southbay에서 pair-wise method와 multi-frame SLAM을 넘고 3DMatch/3DLoMatch/ScanNet으로 전이된다고 보고한다.
- **재현성:** [공식 저장소](https://github.com/IRMVLab/MemReg)는 확인됐지만 실행 시점에는 README 한 파일과 1개 commit뿐이라 실제 code 공개로 간주하기 어렵다.
- **진단→가설→최소 실험:** 악천후 LiDAR에서 현재 scan overlap이 낮으면 pose가 튄다 → history의 feature와 pose를 분리해 관리하면 오염 전파를 통제할 수 있다 → nuScenes rain subset에서 memory length 0/2/4/8과 corruption frame 삽입 전후 RTE·RRE·recovery time을 측정한다.
- **연관성:** 해무·해양 센서 융합에서 memory의 이득과 stale-state 위험을 동시에 평가하는 후보이다. [원문](https://arxiv.org/abs/2610.12624)

### 2.5 MIRAGE: Reliability-Aware Gaussian Estimation from Feed-Forward Vision

- **문제:** feed-forward 3D prior는 시각 품질은 좋지만 metric scale과 장기 trajectory가 흔들리고, LiDAR–IMU는 metric motion은 좋지만 image consistency가 약하다.
- **방법:** feed-forward visual geometry를 LiDAR–IMU motion에 anchor하고 correspondence support와 cross-modal agreement로 online pose correction 강도를 조절한다.
- **저자 주장:** Oxford Spires, M2DGR, INS에서 metric trajectory와 Gaussian reconstruction을 함께 개선하고 COLMAP보다 나은 trajectory를 보고한다. long-horizon monocular reconstruction용 새 benchmark도 제시한다.
- **주의:** 초록에는 절대 오차, 처리 속도, sensor dropout 결과가 없다. LiDAR–IMU 의존성 때문에 monocular-only method와 계산·센서 조건을 맞춰야 한다.
- **진단→가설→최소 실험:** camera-only reconstruction drift가 누적된다 → 모든 frame을 강제 보정하기보다 cross-modal agreement가 높은 구간만 metric anchor로 써야 한다 → 3개 긴 sequence에서 correction always/on-confidence/off의 ATE, PSNR, failure recovery를 비교한다.
- **연관성:** 시계열 sensor fusion에서 신뢰도 기반 개입이라는 설계가 재사용 가능하다. [원문](https://arxiv.org/abs/2610.12568)

### 2.6 Zebra3D: Efficient Hybrid Foundation Models for Scalable 3D Reconstruction

- **문제:** unposed multi-view reconstruction의 global attention은 view 수가 늘면 제곱 비용이 든다.
- **방법:** early layer는 linear-centered attention, 민감한 middle/late layer는 tile-sparse attention을 쓰고 landmark summary로 선택되지 않은 context를 보존한다. pretrained model을 closed-form affine fitting으로 변환할 수 있다.
- **저자 주장:** 1,024 view에서 최대 7.1× end-to-end speedup, post-training Zebra3D-VGGT는 94% mean attention sparsity에서 RealEstate10K AUC@30 80.5%로 dense counterpart보다 1.1%p 낮다.
- **주의:** 고 view-count에서의 speedup이 GPU kernel·batch·memory 조건에 민감할 수 있다. training-free 변환과 post-training 결과를 분리해야 한다.
- **진단→가설→최소 실험:** 모든 layer를 같은 sparsity로 바꾸면 pose accuracy가 무너진다 → layer별 attention concentration이 sensitivity proxy다 → VGGT 작은 checkpoint에서 layer별 entropy를 측정해 early-only, late-only, uniform 50% sparsity의 AUC·latency·VRAM을 비교한다.
- **연관성:** CNN/linear attention과 Transformer를 어느 깊이에서 섞을지 결정하는 실험 설계를 제공한다. [원문](https://arxiv.org/abs/2610.12727)

### 3.1 Mind the Temporal Gap: Evaluating Video Models for Temporal Understanding in Driving

- **문제:** video-language model이 실제 temporal dynamics를 쓰는지, frame-level bias로 action label을 맞히는지 구분하기 어렵다.
- **방법:** controlled ego-motion task에서 standard/visual/few-shot/CoT prompting과 intermediate feature probe, LoRA를 비교한다.
- **저자 주장:** prompting은 model·task에 따라 불안정하고 class bias가 남지만, intermediate visual feature의 작은 probe와 LoRA는 motion-discriminative 성능을 회복한다.
- **해석:** 정보가 encoder에 없다는 결론보다 readout이 정보를 사용하지 못한다는 진단이 우선이다.
- **진단→가설→최소 실험:** 해무 video classifier가 정지 frame 배경으로 label을 맞힌다 → temporal cue는 중간 feature에 있으나 classifier head가 무시한다 → frame shuffle, reverse, motion-only input과 layerwise linear probe를 조합해 temporal sensitivity curve를 만든다.
- **연관성:** video VLM을 prompt만 바꿔 평가하지 말고 representation probe로 병목을 찾게 한다. [원문](https://arxiv.org/abs/2610.12575)

### 3.2 Feature Competition and Its Representational Origins in VLMs

- **문제:** 같은 image의 text와 color처럼 충돌하는 cue가 있을 때 VLM이 어느 feature를 우선하는지 알기 어렵다.
- **방법:** Stroop paradigm을 contrastive·generative VLM benchmark로 옮기고 행동 출력, embedding separability, steering 난이도를 함께 본다.
- **저자 주장:** text와 color가 충돌하면 text cue 쪽으로 치우치며, embedding에서 text가 더 강하게 분리되고 text 방향 steering도 더 쉽다.
- **주의:** 단순 색-단어 conflict가 자연영상의 복잡한 cue competition을 대표하는지는 미확인이다. OCR 능력 차이를 통제해야 한다.
- **진단→가설→최소 실험:** 해무 scene에서 overlay text·timestamp가 시각 evidence를 압도한다 → textual cue가 embedding에서 더 separable하다 → 동일 frame에 맞는/틀린 metadata를 합성하고 visual-only, text-only, conflict 조건의 logit과 layerwise probe를 측정한다.
- **연관성:** VLM이 기상·해양 overlay를 shortcut으로 쓰는지 검증하는 간단한 stress test다. [원문](https://arxiv.org/abs/2610.12650)

### 3.3 Shift-Aware Identity-Guided Latent Refinement for Referring Audio-Visual Segmentation (SAIL)

- **문제:** occlusion, acoustic fading, identity ambiguity가 생기면 Ref-AVS mask가 다른 객체로 이동한다.
- **방법:** frame dynamics token과 global semantic anchor를 분리하고 shift-aware refinement와 continuous memory decoder로 identity consistency를 유지한다.
- **저자 주장:** 두 Ref-AVS benchmark에서 AVS, Ref-VOS, Ref-AVS baseline을 유의하게 앞선다고 보고한다.
- **주의:** 초록에는 절대 점수·shift subset 규모가 없고 code는 publication 이후 공개 예정이라 현재 재현할 수 없다.
- **진단→가설→최소 실험:** fog/occlusion 구간에서 tracker mask가 비슷한 배로 이동한다 → local motion token과 long-term identity anchor를 분리하면 drift가 줄어든다 → 합성 occlusion 1/4/8초에 identity-switch, J&F, recovery frames를 측정한다.
- **연관성:** 해양 객체 tracking과 referring segmentation의 실패 지표를 identity switch 중심으로 바꾸는 데 유용하다. [원문](https://arxiv.org/abs/2610.12783)

### 3.4 TraceICL: Thread-Resolved Demonstration Curation for Multimodal ICL

- **문제:** interleaved image-text-answer demonstration은 image binding 오류, 중복 example, noisy answer 복사를 일으킨다.
- **방법:** per-sample thread boundary 복원, marginal influence 기반 selection/order, weak-model reconstruction confidence 기반 calibration을 frozen LVLM 앞에 둔다.
- **저자 주장:** 5개 benchmark의 4-shot setting에서 strongest same-setting baseline보다 평균 1.7 point, VizWiz 최대 2.4 point 향상하고 30% noisy demonstration에서도 이득 대부분을 유지했지만 latency overhead는 26%다.
- **주의:** 같은 논문 안에서 method 이름이 제목의 TraceICL과 초록의 AVA로 다르게 표기된다. 공식 code·project link도 확인되지 않아 artifact 성숙도는 낮다.
- **진단→가설→최소 실험:** multi-image prompt에서 demo와 image가 잘못 묶인다 → 명시적 sample boundary와 중복 제거가 성능을 좌우한다 → 동일 4-shot prompt에 boundary on/off × dedup on/off를 적용해 accuracy, visual grounding error, latency를 측정한다.
- **연관성:** 레이더 agent의 multimodal evidence prompt를 구성할 때 demonstration provenance를 강제하는 근거다. [원문](https://arxiv.org/abs/2610.12516)

## 4. Training / Inference / System 변화 2개

### 4.1 CORAL-KV: Cross-Layer Prediction and Residual Coding for Video KV Cache

- **문제:** autoregressive video diffusion의 KV cache가 길이에 따라 커지고 quantization error가 후반 frame에서 누적된다.
- **방법:** 현재 layer cache로 다음 layer key/value를 block-diagonal+low-rank predictor가 예측하고 residual만 양자화한다. reusable predictor와 per-video adaptation을 모두 제공한다.
- **저자 주장:** reusable 설정은 QVG-4 대비 HY-WorldPlay/MAGI-1 PSNR을 0.32/4.95 dB 높이면서 cache memory를 48%/37% 줄였고, adapted 설정은 QVG-Pro 대비 MAGI-1 PSNR +3.77 dB와 memory -33.7%를 보고했다.
- **주의:** PSNR과 cache memory가 전체 생성 quality·latency를 대표하지 않는다. 긴 horizon에서 identity·motion drift와 predictor fitting 비용을 따로 봐야 한다.
- **진단→가설→최소 실험:** long-video 후반 temporal discontinuity가 커진다 → cache value 자체보다 cross-layer residual의 quantization error가 누적된다 → 64/128/256 frame에서 QVG와 CORAL-KV의 cache GB, PSNR, LPIPS, temporal consistency, fitting time을 함께 기록한다.
- **연관성:** 영상 생성·world model serving의 memory traffic을 representation quality와 같이 보는 좋은 예다. [원문](https://arxiv.org/abs/2610.12514)

### 4.2 ForcingBooster: Adaptive Patch-wise Denoising for Fast Autoregressive Video Diffusion

- **문제:** static·easy patch와 dynamic·hard patch에 같은 denoising step을 쓰면 계산을 낭비하거나 어려운 영역이 덜 복원된다.
- **방법:** 가벼운 router가 patch별 종료 시점을 정해 easy patch는 일찍 멈추고 hard patch는 추가 refinement를 받는다.
- **저자 주장:** four-step baseline과 비슷한 시각 품질을 유지하면서 patch에 적용되는 총 denoising step을 약 50% 줄였다.
- **주의:** 총 step 감소가 실제 wall-clock speedup과 같지 않다. patch divergence가 GPU utilization을 떨어뜨릴 수 있으며 router 학습 비용도 포함해야 한다.
- **진단→가설→최소 실험:** fog boundary와 작은 객체 영역에서만 artifact가 남는다 → spatially uniform step이 문제다 → motion/edge magnitude로 만든 oracle router와 learned router를 비교해 FLOPs, latency, small-object fidelity를 측정한다.
- **연관성:** 작은 객체·해무 경계에 계산을 집중하는 adaptive compute 연구 씨앗이다. [원문](https://arxiv.org/abs/2610.12625)

## 6. 오늘의 연구적으로 중요한 Finding 3개

1. **저가시성에서 구조 prior는 단독 모듈보다 정렬 단계와 결합할 때 작동한다.** SAMF의 ablation은 DSEM 또는 MARM 하나만으로 R@1을 안정적으로 높이지 못했고, 두 단계 결합이 큰 개선을 냈다. 따라서 frequency/edge branch 추가만으로 끝내지 말고 modality-conditioned normalization을 함께 시험해야 한다.
2. **시간 정보의 존재와 사용은 다른 문제다.** Mind the Temporal Gap은 prompt가 실패해도 intermediate probe가 motion을 복원할 수 있음을 보여준다. video VLM 평가에는 output accuracy와 layerwise temporal probe가 함께 필요하다.
3. **일반화 평가는 sample보다 entity의 경계를 따라야 한다.** WoodBR-Cross의 tree-disjoint split은 해무 frame, 환자 slide, 비행 sequence처럼 강하게 연관된 sample을 하나의 group으로 취급해야 함을 보여준다.

## 7. 과대평가 가능성 / 주의해서 볼 논문 2개

1. **TraceICL:** 평균 1.7 point 이득은 흥미롭지만 method naming 불일치, code 부재, 26% latency overhead가 있다. artifact와 prompt template이 공개되기 전에는 우선순위를 낮춘다.
2. **ForcingBooster:** patch step 50% 감소를 실제 속도 2배로 읽으면 안 된다. 비동기 patch scheduling의 wall-clock, peak memory, hard-region quality를 같은 hardware에서 확인해야 한다.

## 8. 오늘 바로 읽을 논문 Top 3

1. **SAMF** — 저가시성 UAV·remote sensing과 직접 맞닿고, code/data 및 상세 ablation이 있으며 해무 연구로 옮길 최소 실험이 명확하다.
2. **Mind the Temporal Gap** — video model 실패를 prompt·encoder·readout으로 분리하는 진단 프레임이 실용적이다.
3. **WoodBR-Cross** — entity-disjoint split과 leakage control을 기존 데이터에 낮은 비용으로 적용할 수 있다.

## 9. Top 1 미니 리뷰 — SAMF

SAMF의 핵심은 열화상과 위성영상의 차이를 통째로 없애려 하지 않고, 두 modality에 상대적으로 공통인 구조를 먼저 고르는 데 있다. DSEM은 semantic-preserving branch, 8방향 filter branch, low-frequency branch를 adaptive weight로 합친다. 그 다음 MARM이 modality별 affine parameter로 구조 feature의 channel 통계를 맞춘다. 이 순서는 “무엇을 보존할지”와 “어떻게 정렬할지”를 분리한다.

가장 설득력 있는 부분은 ablation이다. Boson-nighttime에서 Swin-T의 R@1은 84.1%인데 DSEM 단독 82.8%, MARM 단독 83.3%로 오히려 낮다. 둘을 결합하면 93.6%가 되고, 512 m prior 위치오차는 26.5 m에서 12.3 m로 줄었다는 것이 저자 보고다. 즉 구조 enhancement와 statistical alignment는 독립적인 만능 모듈이 아니라 연속된 가설이다.

다만 Thermal-UAV-Paired가 위치 중심으로 crop된 one-to-one pair이고 기본 backbone도 R@1 90%대를 내므로, 실제 넓은 gallery와 지리적으로 격리된 split에서 같은 결론이 유지되는지 확인해야 한다. 또 논문의 low-visibility는 주로 야간 열화상 조건이다. 해무 산란과 동일한 degradation으로 간주할 수 없다.

Woojin의 데이터에는 더 작은 형태로 옮길 수 있다. 기존 classifier backbone을 고정하고 ① raw feature, ② directional+low-pass feature, ③ ②+camera-conditioned affine normalization 세 설정을 만든다. random split이 아니라 day-camera holdout을 쓰고 macro-F1, ECE, visibility-bin 성능을 3개 seed로 기록한다. ③이 저가시거리 bin에서만 개선되고 clear bin을 해치지 않으면 구조 prior 가설을 지지한다. [논문](https://arxiv.org/html/2610.12835v1) · [코드](https://github.com/YuxinWang879/SAMF)

## 10. 후속 연구 씨앗

1. **Fog-aware structure alignment**
   - 가설: 안개가 texture를 지워도 방향·저주파 layout은 남고, camera별 affine 정렬이 domain gap을 줄인다.
   - 최소 실험: fixed directional/low-pass branch × camera-conditioned normalization의 2×2 ablation, day-camera holdout, 3 seeds.
   - 지표: macro-F1, ECE, visibility-bin recall, latency.
2. **Temporal readout audit for maritime video**
   - 가설: motion cue는 encoder 중간층에 있지만 최종 head가 background shortcut을 선택한다.
   - 최소 실험: normal/shuffle/reverse/motion-only clip에 layerwise linear probe를 학습한다.
   - 지표: action accuracy, shuffle sensitivity, probe-depth curve, calibration.
3. **Entity-disjoint fog benchmark**
   - 가설: 연속 frame·같은 카메라가 split을 가로지르는 것이 기존 성능을 부풀린다.
   - 최소 실험: image-random, temporal-burst, day-camera split을 동일 frozen DINOv2 feature로 비교한다.
   - 지표: macro-F1 차이, class별 variance, nearest-neighbor leakage rate.
4. **Teacher-specific CNN–ViT–SSM distillation**
   - 가설: teacher별 token이 architecture 고유 bias를 보존해 OOD 성능을 높인다.
   - 최소 실험: shared-token과 3 teacher-token student를 같은 parameter·step으로 학습한다.
   - 지표: ID/OOD F1, teacher CKA, token ablation, GFLOPs.
5. **Patch-budgeted dehazing/video inference**
   - 가설: fog boundary와 작은 객체에만 추가 compute를 배정하면 평균 step을 줄이면서 recall을 유지할 수 있다.
   - 최소 실험: uniform 2/4 step, edge-oracle routing, learned routing을 같은 GPU에서 비교한다.
   - 지표: small-object AP, temporal consistency, wall-clock, peak VRAM.

## 11. 오늘 안 읽어도 되는 것

- **TerraAgent:** remote-sensing evidence audit는 흥미롭지만 frozen model 대비 2.6× cost이고, 오늘의 shortcut/evidence 주제는 최근 보고서와 겹친다.
- **Reference-Free Food Volume Estimation:** 5개 음식의 초기 결과라 scale-aware stereo pipeline의 일반성을 판단하기 이르다.
- **SAM 2.1 Building Segmentation:** domain fine-tuning의 개선은 유용하지만 building 42개와 11 class에 한정되고 새 방법적 통찰은 작다.
- **APEX:** extreme compression 주제는 중요하지만 오늘의 CV/VLM 연구 우선순위보다 낮아 후보군에 남겼다.
- code·data·split을 확인할 수 없고 leaderboard 향상만 주장하는 항목은 숫자를 보고서에 옮기지 않았다.

## 오늘의 실행 제안

- **30분:** 해무 dataset의 sample ID를 `camera/day/burst` group으로 재구성하고 현재 split의 group overlap을 계산한다.
- **2시간:** frozen backbone feature에 8방향 depthwise filter와 5×5 low-pass branch를 추가한 probe를 구현한다.
- **반나절:** random split과 day-camera holdout에서 baseline/structure/structure+conditional norm을 1 seed로 먼저 돌려 효과 크기와 실패 bin을 확인한다.
- **중단 기준:** 저가시거리 bin의 macro-F1이 개선되지 않거나 clear bin ECE가 악화되면 full training으로 확장하지 않는다.
