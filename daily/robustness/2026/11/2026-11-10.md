## 핵심 사례 — Grounding DINO prompt-segmentation shift

- **사실:** Transformers issue #50465는 v5 vectorized text-mask 코드에서 closing phrase delimiter가 position id 0으로 clamp되고, v4/original은 phrase length를 준다고 보고한다.
- **커뮤니티 재현:** 작성자는 Transformers 5.18.0, torch 2.14.1, macOS arm64 CPU, grounding-dino-tiny fixture에서 v5 logits difference와 delimiter/dtype/PIL processor 조합을 비교했다.
- **가설:** multi-phrase prompt에서 delimiter 수와 position mapping 차이가 phrase별 object score ranking 또는 threshold crossing을 바꿀 수 있다.
- **failure cell:** 짧은 phrase 하나보다 많은 phrase, 인접 delimiter, phrase order 변경, paraphrase, fast resize/PIL resize 차이에 더 민감할 수 있다.
- **최소 실험:** 동일 image·weights로 v4/v5 × default/PIL processor를 실행하고 phrase recall, per-phrase score, ranking correlation, box IoU, calibration을 prompt family별로 기록한다.
- **GO/KILL:** phrase-level ranking/recall이 모든 cell에서 tolerance 내로 유지되면 GO다. processor/version에 따라 ordering reversal 또는 recall drop이 나면 해당 deployment의 prompt template를 고정하고 version migration을 KILL한다.
- **한계:** issue는 open이고 작성자 patch의 CPU fixture 결과다. 실제 OOD·weather·camera shift 또는 adversarial prompt robustness를 직접 입증하지 않는다.
