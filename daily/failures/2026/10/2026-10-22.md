## 1. PsycheMME — 전체 adaptation 이득 속에서 Interaction Timing이 퇴행한다

**대상:** *PsycheMME: A Psychology-Informed Benchmark for Social Understanding and Interaction in Videos*  
**실패 조건:** Qwen3.5-4B를 benchmark task에 SFT한 뒤 capability별 성능을 분해할 때  
**모델·데이터·설정:** Qwen3.5-4B Base/SFT/SFT+GRPO, 1,000 questions·630 episodes, 8 capabilities, Raw와 rationale evidence·logic을 반영한 Verified score

### 확인된 사실

- 전체 macro Raw/Verified는 base 47.68/37.71에서 SFT 72.58/52.13, SFT+GRPO 73.19/52.62로 상승했다.
- Grounding과 Risk Raw는 SFT로 각각 27.96점, 27.40점 올랐다.
- 반대로 Interaction Timing Raw는 40.28에서 31.94로 8.34점 하락했고, GRPO 뒤에도 34.72로 base보다 5.56점 낮았다.
- SFT+GRPO의 Raw와 Verified 사이에는 20.57점 차이가 남았다. 답 점수 상승과 근거·논리 품질 상승이 일치하지 않았다.
- 별도의 72개 proprietary-model Timing single-choice 분석에서 best single model은 66.67%, 정답을 아는 oracle은 91.67%, plurality vote는 57.64%였다.
- 21문항에서 8개 중 최소 5개 모델이 같은 오답을 골랐고, 그중 18문항에는 다른 모델이 낸 정답 후보가 존재했다.
- 공식 저장소는 scorer·prediction·judgment replay와 adapter를 공개한다. 다만 replay는 저장된 판단을 재계산할 뿐 historical response를 독립적으로 다시 채점하지 않는다.

### 저자 인정·공동체 재현 상태

- **저자 인정:** task adaptation 뒤에도 temporal grounding과 rationale quality가 해결되지 않았고, simple voting은 올바른 minority answer를 안정적으로 찾지 못한다.
- **공개 재현 범위:** 공식 repository는 19,000 factor rows와 190 paper cells의 replay 경로를 제공한다. 전체 원본 media와 일부 provider control은 완전 공개가 아니며 새 GPU rerun을 인증하지 않는다.
- **공동체 재현:** 공개 직후라 독립 연구팀의 재현은 확인되지 않았다.

### 기존 주장과 충돌하는 지점

전체 macro 향상만 보면 SFT와 GRPO가 social reasoning을 전반적으로 개선한 것처럼 보인다. capability 분해에서는 Timing이 악화되므로 그 주장을 그대로 일반화할 수 없다. 같은 benchmark의 base와 adapted checkpoint 비교이므로 이 퇴행 자체는 직접 비교 가능하지만, proprietary model ensemble 분석과 Qwen adaptation 결과는 모델·subset이 달라 `not strictly apples-to-apples`다.

### 진단 → 가설 → 최소 실험

- **진단:** SFT가 쉽게 점수를 얻는 grounding·risk pattern에 맞춰지면서 intervention boundary를 결정하는 시간 표현을 손상시킬 수 있다.
- **가설:** aggregate reward가 capability imbalance를 숨기며, timing-specific pair와 rationale constraint가 없으면 GRPO도 퇴행을 복구하지 못한다.
- **최소 실험:** 동일 base에서 (a) 전체 SFT, (b) capability-balanced SFT, (c) Timing pair 20% 추가 SFT를 세 seed로 학습한다. Raw/Verified, Timing accuracy, calibration, 다른 7개 capability regression을 함께 기록한다.
- **GO:** Timing이 base보다 높고 다른 capability의 macro 하락이 1점 이내다.
- **KILL:** Timing 회복이 seed 하나에만 나타나거나 전체 macro를 3점 이상 희생한다.

**평가:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 2. DISTRACT — text-conditioned tracker가 문장의 의미를 행동에 쓰지 않거나, 올바른 text로 더 나빠진다

**대상:** *DISTRACT: Degradation-Indexed Study of Textual Reference Across Competing Targets*  
**실패 조건:** 동일 video·target·distractor에 correct, conflicting, neutral, blank text를 교차 적용하고 blur·noise·pixelation·compression severity를 올릴 때  
**모델·데이터·설정:** Molmo2, JointNLT, UVLTrack, MMTrack, DUTrack; MeViS·DanceTrack·SportsMOT·PersonPath22; 5개 tracker, 4개 dataset

### 확인된 사실

- UVLTrack, MMTrack, DUTrack은 tested setting에서 correct와 conflicting text의 directed behavioral effect가 FDR 보정 후 살아남지 않았다.
- 이 세 모델의 clean correct-text target accuracy는 62–68%여서 단순 floor 또는 ceiling만으로 무반응을 설명하기 어렵다.
- decision-near state의 correct-vs-conflicting text balanced accuracy는 Molmo2 0.574(q=.015), JointNLT 0.695(q=.002)였지만 UVLTrack 0.530(q=.174), MMTrack 0.488(q=.898), DUTrack 0.504(q=.506)였다.
- UVLTrack은 중간 25개 state 중 14곳에서 text condition이 decode됐지만 최종 pre-localization state에서는 FDR-significant하지 않았다. text 정보가 내부에 있어도 결정 경로까지 유지되지 않는 사례다.
- JointNLT의 SportsMOT clean-input에서 올바른 text가 blank 대비 target accuracy를 11.2%p 낮춘 유의한 사례가 있었다.
- clean-input target effect 14건 중 degradation endpoint가 최소 한 perturbation에서 유의하게 수축한 것은 4건뿐이었다. 나머지 10건은 “유지됐다”가 아니라 통계적으로 결론을 내릴 수 없었다.
- reproduction pipeline은 review supplementary에 anonymized 형태로 제공되며, 원 data·checkpoint 취득이 필요한 full study와 synthetic smoke test는 분리돼 있다.

### 저자 인정·공동체 재현 상태

- **저자 주장:** tracker가 text input을 받는다는 사실만으로 semantic content가 localization decision을 바꾼다고 볼 수 없다.
- **저자 인정:** 유의하지 않은 degradation 변화는 효과 유지의 증거가 아니다. selected stress subset과 원 source licensing도 재현 범위를 제한한다.
- **공동체 재현:** 독립 재현은 확인되지 않았다. public de-anonymized repository는 acceptance 이후 제공 예정이며 현재 full reproduction은 supplementary와 upstream artifact를 조합해야 한다.

### 기존 주장과 충돌하는 지점

“language-conditioned tracking”이라는 이름은 문장 의미가 추적 결정을 안정적으로 유도한다고 암시한다. 세 tracker에서는 최종 행동 효과가 유의하지 않았고, 한 조건에서는 올바른 text가 해로웠다. 다만 각 tracker의 native operation과 output geometry가 달라 절대 accuracy 비교는 `not strictly apples-to-apples`다. 핵심 비교는 각 모델 내부에서 text condition만 바꾼 matched intervention이다.

### 진단 → 가설 → 최소 실험

- **진단:** text encoding은 존재해도 fusion 뒤 localization head가 visual shortcut을 사용하거나, conflicting cue를 target switch 신호로 잘못 해석한다.
- **가설:** training 중 correct/conflicting/null triplet과 causal consistency loss를 넣으면 decision-near text sensitivity와 실제 target retention이 함께 개선된다.
- **최소 실험:** 해양 CCTV의 유사 선박 pair 100개에 correct vessel description, role-swapped/conflicting description, blank를 적용한다. clean·fog·compression에서 target retention, distractor capture, decision-near text probe를 기록한다.
- **GO:** correct–conflicting retention gap이 두 degradation 이상에서 FDR q<.05이고 blank 대비 harmful effect가 없다.
- **KILL:** probe accuracy만 오르고 행동 차이는 생기지 않거나 correct text가 distractor capture를 늘린다.

**평가:** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 3. Code2Video-Compass — 성공한 sample만 보면 모델 순위가 실행 실패를 숨긴다

**대상:** *Code2Video-Compass: A Comprehensive Benchmark for General-Purpose Code-Based Video Generation across T2V, I2V, and V2V*  
**실패 조건:** code-generated video의 render 성공분만 모아 subjective quality를 평균할 때  
**모델·데이터·설정:** 15 proprietary/open-weight MLLM, 9 families, T2V/I2V/V2V 2,104 tasks, shared backend와 resource limit

### 확인된 사실

- 성공적으로 render된 결과만 보면 GPT-6 Astra와 GPT-6.1 Sol의 mean holistic quality는 4.19와 4.15로 Claude Opus 5.5의 4.04보다 높았다.
- 실패 결과를 0으로 남긴 full-set mean에서는 두 모델이 3.62와 3.61로 내려갔고 Claude Opus 5.5가 3.87로 선두였다.
- 논문은 2,756 error cases를 분석했다.
- GPT-6 Astra 실패의 83.4%는 compilation error와 missing API/package였다.
- Qwen3.8-Max 실패의 59.7%는 missing API/package였고, Claude Opus 5.5 실패의 75.0%는 runtime exception이었다.
- construction과 dynamic animation complexity가 L1→L2로 갈 때 semantic fidelity는 score range 대비 14.38%, 12.82% 감소했다. state dependency는 L2→L3에서 더 큰 하락을 보였다.
- failed output을 non-operational metric의 분모에서 빼지 않고 0으로 두는 평가 규칙은 공식 원문에 명시돼 있다.

### 저자 인정·공동체 재현 상태

- **저자 주장:** 성공한 실행의 시각 품질과 완전한 pipeline reliability는 별개이며, 긴 multi-file code의 dependency·compile·runtime failure가 아직 주 병목이다.
- **공개 artifact:** 공식 project page는 논문에서 연결되지만 이번 조사 도구로 직접 열리지 않았다. arXiv HTML에는 task와 metric 정의, 결과가 공개돼 있다.
- **공동체 재현:** 독립 재현은 확인되지 않았다. proprietary API version과 backend environment를 고정하지 않으면 실패율이 달라질 수 있다.

### 기존 주장과 충돌하는 지점

“생성 품질 최고”라는 결론은 success-conditioned mean에서는 맞지만 end-to-end user outcome에는 맞지 않는다. 두 평균은 분모가 달라 직접 대체할 수 없으며 `not strictly apples-to-apples`다. 모델 비교에는 API version, package image, timeout, retry policy, token budget을 함께 고정해야 한다.

### 진단 → 가설 → 최소 실험

- **진단:** visual planner의 능력보다 dependency hallucination과 long-code execution 오류가 전체 성공률을 지배한다.
- **가설:** generate→static check→dependency repair→sandbox render의 1회 repair loop가 추가 sampling보다 full-set utility를 더 크게 높인다.
- **최소 실험:** 100개 task에서 single pass, same-token self-consistency, one repair loop를 비교한다. execution success, full-set quality, token·latency, error taxonomy를 측정한다.
- **GO:** repair loop가 full-set mean을 0.2 이상 높이고 token 증가가 30% 이내다.
- **KILL:** 성공률 증가는 있지만 visual fidelity가 감소하거나 runtime·token 비용을 포함한 utility가 개선되지 않는다.

**평가:** 심각도 4/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 4/5

## 4. EvaOmni — 정답을 맞혀도 audio·visual 근거를 동시에 찾지 못한다

**대상:** *EvaOmni: An Evidence-Grounded Benchmark for Audio-Visual Reasoning*  
**실패 조건:** multiple-choice answer correctness와 modality별 evidence interval을 함께 요구할 때  
**모델·데이터·설정:** 7 open-weight·17 proprietary Omni LLM, 392 videos·1,027 QA, 15 capabilities·3 levels

### 확인된 사실

- Gemini3.7-Flash는 overall accuracy 79.4%였지만 audio와 visual IoU가 모두 0.5 이상인 correct-and-grounded 비율은 41.8%였다.
- Qwen3.8-Omni-Flash는 accuracy 58.2%에서 correct-and-grounded 11.8%로 내려갔다.
- 7개 진단 모델 전체에서 정답 결과의 48.1–79.9%가 양 modality grounding threshold를 통과하지 못했다.
- grounding threshold를 통과했지만 답이 틀린 비율은 grounding-passing prediction 기준 12.2–32.6%였고, 전체 문항 기준으로는 8.8%를 넘지 않았다.
- MiMo-V2.5에서 Video+Audio는 accuracy/C.G./B.G. 56.8/48.4/20.5였고 Video+ASR은 48.7/38.1/11.6이었다. ASR은 native audio를 완전히 대체하지 못했다.
- Qwen3VL-8B와 A3B에 ASR을 더하면 accuracy는 각각 13.8→23.2, 8.5→19.3으로 올랐지만 B.G.는 1.9와 0.8에 머물렀다.
- 공식 repository는 runnable metric evaluator, prediction schema와 example을 제공하지만 provider별 inference adapter와 original prompt template은 향후 제공 예정이라고 명시한다.

### 저자 인정·공동체 재현 상태

- **저자 주장:** textual·unimodal shortcut으로 정답을 맞힐 수 있어 answer accuracy만으로 joint audio-visual reasoning을 증명할 수 없다.
- **저자 인정:** B.G.는 두 modality 중 약한 localization을 반영하며, 정확한 evidence interval prediction이 현재의 명확한 병목이다.
- **공동체 재현:** evaluator와 dataset은 공개됐지만 독립 model rerun은 확인되지 않았다. 일부 provider adapter가 없어 proprietary 결과의 exact reproduction은 아직 제한된다.

### 기존 주장과 충돌하는 지점

높은 answer accuracy를 근거 통합의 성공으로 해석하는 관행과 충돌한다. Accuracy, C.G., B.G.는 같은 prediction에서 계산되지만 서로 다른 조건을 측정한다. human baseline 또는 다른 preprocessing과의 수치 비교는 viewing condition이 달라 `not strictly apples-to-apples`다.

### 진단 → 가설 → 최소 실험

- **진단:** 모델이 option prior, transcript keyword 또는 한 modality만으로 정답을 맞히고 evidence timestamp는 사후적으로 생성할 수 있다.
- **가설:** answer loss와 evidence bottleneck loss를 분리하고 modality-drop counterfactual을 넣으면 correct-and-grounded 비율이 accuracy 손실 없이 오른다.
- **최소 실험:** 해무·선박 이벤트 100개에 audio-only, visual-only, joint, timestamp-shuffled 조건을 만들고 accuracy, audio/visual IoU, min-IoU@0.5를 기록한다.
- **GO:** joint min-IoU@0.5가 15%p 이상 오르고 answer accuracy 하락이 2%p 이내다.
- **KILL:** answer는 유지되지만 evidence interval이 shuffled control과 구분되지 않는다.

**평가:** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 5. MindView — view coverage가 늘어도 모든 generator가 성능을 잃는다

**대상:** *MindView: Benchmarking Generative Multi-View Spatial Intelligence*  
**실패 조건:** 같은 scene·query·target에서 context view를 6개에서 10개로 확장할 때  
**모델·데이터·설정:** 11 off-the-shelf generator와 BAGEL-SFT, 1,500 samples·513 indoor scenes·7 tasks, nested C3/C6/C10 context

### 확인된 사실

- target content coverage는 C3 57.6%, C6 88.4%, C10 92.0%로 증가했다.
- 그럼에도 11개 off-the-shelf generator와 BAGEL-SFT 모두 C10 overall이 C6보다 낮았다.
- BAGEL은 C6 40.0에서 C10 39.0, BAGEL-SFT는 64.4에서 63.2로 하락했다.
- 동일 view 수를 맞춘 random selection보다 query-guided MindCue가 BAGEL에서 1.6점, BAGEL-SFT에서 1.1점 높았다.
- MindCue는 평균 7.4개 view로 BAGEL 41.1, BAGEL-SFT 65.1을 기록해 C6와 C10 둘 다 넘었다.
- MindCue는 frozen VGGT와 semantics-dominant task에서 SAM 3를 사용한다. 따라서 “순수 context 삭제만의 효과”가 아니라 target-view hypothesis를 포함한 별도 inference pipeline이다.

### 저자 인정·공동체 재현 상태

- **저자 주장:** 더 많은 observation은 coverage를 늘려도 model이 query-relevant evidence를 선택하지 못하면 성능을 해친다.
- **저자 인정:** benchmark는 indoor scene과 현재 evaluator에 한정되며 MindCue는 별도 geometry/segmentation component에 의존한다.
- **공개 artifact:** 공식 project page는 benchmark·evaluation·training data·BAGEL-SFT checkpoint 공개를 명시하지만 이번 조사 도구로 직접 열리지 않았다. MindCue code의 공개 범위는 확인하지 못했다.
- **공동체 재현:** 독립 재현은 확인되지 않았다.

### 기존 주장과 충돌하는 지점

long-context 또는 multi-camera input에서 “더 많은 view가 항상 더 낫다”는 scaling 가정과 충돌한다. 같은 checkpoint·same sample의 C6/C10 paired comparison은 직접 비교 가능하다. MindCue와 fixed context는 추가 frozen component와 selection step이 있어 `not strictly apples-to-apples`다.

### 진단 → 가설 → 최소 실험

- **진단:** irrelevant·redundant view가 attention을 분산시키고 reference frame 또는 target camera inference를 충돌시킨다.
- **가설:** view 수보다 query-conditioned evidence density가 성능을 결정하며, selection confidence를 calibration하면 해양 multi-camera VLM에도 같은 효과가 나타난다.
- **최소 실험:** 같은 항만 event 100개를 3·6·10 camera로 구성하고 all-view, random top-3, query-conditioned top-3를 비교한다. accuracy·geometry consistency·target coverage·latency·token을 함께 측정한다.
- **GO:** query top-3가 all-view보다 accuracy 또는 geometry score를 3%p 이상 높이고 token을 40% 이상 줄인다.
- **KILL:** 개선이 indoor benchmark에만 나타나거나 selector의 geometry model 교체 시 사라진다.

**평가:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 오늘의 실패 패턴 3개

1. **Aggregate gain이 capability regression을 숨긴다.** PsycheMME의 전체 adaptation 이득은 Timing 하락을 가리고, Code2Video의 성공분 평균은 실행 실패를 가린다.
2. **정보가 입력되거나 내부에 decode된다고 행동에 쓰이는 것은 아니다.** DISTRACT의 tracker는 text를 받거나 중간 state에서 표현해도 localization decision에 안정적으로 반영하지 않았다.
3. **정답·coverage·context 양은 올바른 evidence use의 대용치가 아니다.** EvaOmni의 correct-but-ungrounded answer와 MindView의 more-view regression이 같은 경고를 준다.

## 논문 아이디어로 연결 가능한 빈틈

### A. Capability Regression Ledger for Multimodal Post-Training

- SFT/RL 전후 aggregate 점수 외에 temporal grounding, evidence support, calibration, minority failure를 자동 대조한다.
- seed별 paired bootstrap과 regression budget을 post-training acceptance criterion으로 둔다.
- **핵심 기여 후보:** “전체 향상”을 허용하면서도 critical capability의 퇴행을 차단하는 Pareto checkpoint selector.

### B. Information-Present / Decision-Used Causal Audit

- representation probe로 정보 존재를 확인하고, activation patching과 matched text intervention으로 실제 행동 사용을 분리한다.
- tracking, grounded VQA, multi-camera selection에 같은 audit contract를 적용한다.
- **핵심 기여 후보:** 입력 modality가 최종 decision에 미치는 causal utilization score.

### C. End-to-End Reliability Score with Failure Denominator

- compile/runtime/timeout/abstention을 제거하지 않고 0 또는 task-specific penalty로 유지한다.
- successful-only quality와 full-set utility를 동시에 보고해 ranking reversal을 정식 metric으로 만든다.
- **핵심 기여 후보:** generation model의 quality–execution Pareto frontier와 repair-budget-aware score.

### D. Query-Conditioned Evidence Bottleneck for Maritime VLM

- audio·visual timestamp와 multi-camera view를 하나의 evidence budget 아래에서 선택한다.
- answer accuracy, min-modality IoU, target-view coverage, token·latency를 공동 최적화한다.
- **핵심 기여 후보:** 해무·선박 안전 이벤트에서 “맞혔지만 근거가 틀린” 답을 차단하는 deployable confidence rule.

## 출처와 해석 한계

- 다섯 논문 모두 최근 arXiv v1이므로 peer review와 장기 공동체 재현이 완료되지 않았다.
- PsycheMME, EvaOmni는 공식 코드·데이터를 확인했다. DISTRACT는 anonymized supplementary pipeline을 설명하지만 de-anonymized public repository는 아직 공개 전이다.
- Code2Video-Compass와 MindView의 project page는 논문에서 공식 연결됐으나 이번 조사 도구로 직접 열리지 않았다. 해당 사실을 artifact 완전 검증으로 과장하지 않았다.
- proprietary model 이름·API와 실험 backend는 시간이 지나면 바뀔 수 있다. exact version, resource limit, prompt, retry policy 없이 수치를 재현했다고 볼 수 없다.
- 서로 다른 task의 퍼센트와 평점은 직접 비교하지 않았다. 평점은 이 레이더의 정성적 연구 우선순위다.
