## 2) CV / DL-CV 핵심 6개

### C1. Focus Only on What's Important: Training-Free Focus Maps for Frozen Vision Transformers in Long-Video Object Segmentation

**문제·방법:** frozen DINOv3와 학습된 Cutie head에서 객체 주변을 보존하고 나머지 token을 합친다. 직전 mask만 따르면 빠른 이동 뒤 객체를 배경으로 합쳐 복구를 막을 수 있어, 이동 예측·block matching·surprise check·fallback을 사용한다.

**저자 보고:** LVOS V2 valid, ViT-S 3 seeds에서 ALGM 대비 +2.76 J&F와 16% 적은 counted encoder FLOPs를 보고한다. 그러나 12-video 표본의 startup 포함 전체 step은 dense보다 빨라지지 않았다. **진단:** 계산량·encoder 시간·전체 지연을 구분해야 한다. **후속 가설:** 평균 이동보다 드문 급이동 후 복구 실패가 배포 효용을 좌우할 수 있다. [원문·실험·한계](https://arxiv.org/html/2611.34863v1)

### C2. Stranger Things: When Objects Appear Without Their Typical Neighbors

**문제·방법:** 객체 쌍의 NPMI로 typicality를 측정하고, 17개 sub-tier의 STRANGE-Bench와 비전형적 이웃을 늘리는 Anchor-Atypicality Sampling을 제안한다.

**저자 보고:** 다섯 모델 계열·세 과업에서 비전형적 조합의 격차가 5~11%p 남고 규모 증가로 일관되게 줄지 않는다. appendix의 partner masking은 합성 gap을 조금 줄이지만 COCO gap과 정확도를 악화시킨다. **진단:** 이웃을 지우는 것과 이웃 다양성을 늘리는 것은 다른 개입이다. 합성 렌더링·면적·가림 통제가 중요하다. **후속:** 자연 이미지에서 size·가림을 맞춘 뒤 어떤 오류가 남는지 확인하자. 원문에 masking·공간 배치 분석이 이미 있어 단순 재검사는 신규성이 낮다. [본문·대조 실험](https://arxiv.org/html/2611.34881v1)

### C3. Enhancing Maritime Domain Awareness using Latent Space Representations

**문제·방법:** 원본 Sentinel-1 대신 TerraMind의 압축 embedding을 linear/nonlinear probe로 읽어 데이터 이동 부담을 줄인다.

**저자 보고:** 선박 존재 ROC-AUC 0.95, 100m보다 긴 선박의 위치 중앙 오차 약 300m, 주요 AIS 선종 정확도 62%다. 선종은 길이와 높은 상관을 보인다. **진단:** 존재 검출 성과를 작은 선박의 정밀 검출로 읽을 수 없다. AIS 상업 선박·검수 표본의 선택 편향도 확인해야 한다. **후속:** 길이만의 baseline과 길이 구간을 맞춘 probe를 먼저 비교하자. 공간·선박 ID·시간 단위 split 누수 여부는 추가 감사가 필요하다. [공식 본문](https://arxiv.org/html/2611.34899v1)

### C4. Beyond Feature Fusion: Sensor-Grounded Semantic-Spiking Learning for Robust Object Detection

**문제·방법:** SPIRE는 하나의 spike stream에서 appearance와 누적 prefix의 rate·edge·차분을 구성한다. 관측 contrast와 예측 contrast의 residual로 fused pyramid에 제한된 보정을 준다.

**저자 보고:** simulated VOC/COCO의 네 노출 조건에서 strongest baseline 대비 AP50 +4.00~5.50, real PKU-Vidar-DVS에서 AP50 67.07·AP75 40.10, SPFD보다 MACs 50.4% 감소다. **주의:** simulated 개선량을 실제 센서의 같은 개선량으로 옮기지 않는다. 센서 관측 길이·노출·label·backbone 조건을 맞추기 전 비교는 `not strictly apples-to-apples`다. **후속:** residual이 오류 크기를 예측하는지, 같은 크기의 무작위 보정과 비교해 원인성을 검사하자. [공식 원문](https://arxiv.org/abs/2611.34828)

### C5. DynMF2: Rigid Motion Factorization by Expectation-Maximization for Monocular 4D Reconstruction and Motion Segmentation

**문제·방법:** 단안 동적 장면의 깊이 모호성을 소수의 rigid SE(3) trajectory와 점별 단일 motion 할당으로 제한한다. EM의 fitting에는 rendering을 쓰지 않으며 requery·merge·split으로 motion 구성을 수정한다.

**저자 보고:** mask 없이 iPhone/NVIDIA의 view synthesis, iPhone의 3D tracking에서 mask-based baseline을 앞선다. 초록에서 확정할 수 있는 동일 조건 정량 차이는 기록하지 않는다. **진단:** mask 의존성을 없애도 입력 trajectory·rigid 가정 의존성이 남는다. 작은 background mover 회수와 잘못된 motion 분리를 구분해야 한다. **후속:** track 품질을 고정하고 rigid/nonrigid·가림·작은 이동체별 실패를 나누자. code/weights·최저 VRAM은 이번 확인에서 확정하지 못했다. [공식 원문](https://arxiv.org/abs/2611.34931)

### C6. Probing Visual Idiosyncrasies in Text-to-Image Models

**문제·방법:** 생성 이미지의 출처 식별이 어떤 시각 단서에 의존하는지 texture·layout·depth·albedo·caption으로 분해한다.

**저자 보고:** 네 생성 모델을 구분하는 ResNet-50은 held-out prompt에서 100%를 기록한다. 사람의 62.61%는 **pairwise 과업**이므로 같은 난이도의 직접 비교가 아니다. texture 통계만의 작은 MLP도 강한 신호를 얻는다. **진단:** 이것은 선택된 네 출처의 식별이며 모든 생성/실사 판별의 해결이 아니다. export·압축·모델 버전 단서도 분리해야 한다. **후속:** 같은 codec·해상도·후처리에서 source signal을 다시 측정하고, 보지 않은 버전을 별도 시험하자. code/data/checkpoint는 미확인이다. [공식 원문](https://arxiv.org/abs/2611.34843)

## 3) VLM / Multimodal / Video 핵심 3개

### V1. Tracking Any Point with Agentic Visual Reasoning

**문제·방법:** AgenTAP은 point 좌표·visibility를 예측하고, 추가 관측을 골라 같은 물리적 점인지 확인·수정한다. 사라졌다 돌아온 점을 이어 EgoTAP-4D를 구성한다.

**저자 보고:** correspondence 전용 fine-tuning 없이 GPT-6 Astra 기반 agent가 expert tracker를 앞서고, 구축 데이터가 D4RT 학습에 도움을 준다. sampled reappearing points에서 human agreement에 접근한다는 주장이다. **주의:** sampled subset의 결과를 전 영상의 annotation 정확도로 확대하지 않는다. API snapshot·도구·총 image 호출·실패 retry가 비용과 재현성의 핵심이다. **후속:** 같은 추가 관측 budget에서 전문가 tracker+검증과 비교하고 identity swap·occlusion 복귀를 분리하자. [공식 원문](https://arxiv.org/abs/2611.34943)

### V2. BOP-Refer: Benchmark for Monocular 3D and 2D Object Grounding

**문제·방법:** 9개 BOP dataset의 3D model·6DoF pose로 2D/3D box를 얻고, VLM 생성 표현을 사람이 검증한다.

**저자 보고:** 17개 VLM 평가에서 best model은 AP_IoU2D 72.6%, AP_IoU3D 12.4%다. 3D threshold가 더 느슨하더라도 두 metric을 동일 과업의 60.2%p 손실로 해석하지 않는다. 영상상 중심은 맞지만 깊이가 객체 크기 이상 어긋나는 사례를 지적한다. **진단:** metric scale/size prior가 주요 원인이라는 저자 해석과, 모든 오류가 그것으로 설명된다는 결론은 다르다. **후속:** 정답 대상 ID·2D box를 제공한 뒤 깊이·크기 오차가 얼마나 남는지 보자. unseen instance·실제 물체 크기 prior 통제가 필요하다. [공식 원문](https://arxiv.org/abs/2611.34862)

### V3. ProbFaS: Probabilistic Video Frame Selection for MLLMs via Multi-Fidelity Calibration

**문제·방법:** 저렴한 image–text alignment와 일부 frame에 대한 MLLM yes/no probe를 co-kriging으로 결합하고 temporal DPP로 선택한다.

**저자 보고:** ITA 순위가 40% 넘는 질문에서 실제 효용과 음의 상관을 보인다. Video-MME·MLVU·LongVideoBench의 15개 설정 중 13개에서 가장 정확하며 최대 +3.1%p를 보고한다. **진단:** 32개 선택 frame이 많은 uniform frame을 대체해도 probe 호출은 무료가 아니다. alignment의 낮은 상관은 해당 모델·질문 분포의 결과다. **후속:** selection+probe+answer 전체 비용을 맞추고 짧은 사건·순서 질문의 누락률을 따로 재자. label-free와 validation 선택 부재도 동일하지 않다. [공식 본문](https://arxiv.org/html/2611.34903v1)

## 4) LLM / Agent / System 변화 3개

### S1. TASK Memory: Beyond Text-Only Memory with Activation Steering and Knowledge Editing against Memory Hallucination

**문제·방법:** 올바른 메모리를 검색한 뒤에도 무시·다른 대상 적용·이전 버전 혼동이 생긴다. text note, 제거 가능한 knowledge edit, query별 adoption을 조절하는 steering을 결합한다.

**저자 보고:** 다섯 open model에서 ignoring 최대 46%, misapplying 최대 24%, editing 결합 조건에서 49%, 구버전/신버전 공존 조건의 stale 답 53%를 보고한다. 조건별 수치를 합치거나 일반 사용자 오류율로 쓰지 않는다. **후속:** content·subject key·version만 교차 변경해 retrieval과 adoption을 분리하고 무관 질문의 손상을 함께 측정하자. code/weights·지원 architecture·비용은 미확인이다. [공식 원문](https://arxiv.org/abs/2611.34762)

### S2. HoMe: Toward Practical Harness Optimization of Memory Systems for AI Assistants

**문제·방법:** code·prompt·configuration으로 구성된 memory harness를 평가·수정한다. session version과 execution trace로 실패를 책임 component에 연결하고 smoke test·sampling·memory 재사용으로 탐색한다.

**저자 보고:** ReMe 기반 LongMemEval-S·BEAM에서 초기 full 평가 뒤 benchmark별 여섯 formal candidate evaluation으로 성능과 query-time token 사용을 개선한다. **진단:** 후보 평가 비용·실패 후보·오프라인 탐색을 query-time 비용과 합산해야 한다. **후속:** 같은 validation 예산의 random/local edit와 비교하고, 다른 benchmark에 frozen harness를 적용하자. 공식 링크는 ReMe 저장소로 연결되며 HoMe 전체 재현 entrypoint 확보 여부는 별도 확인이 필요하다. [공식 원문](https://arxiv.org/abs/2611.34624) · [연결된 repo](https://github.com/agentscope-ai/ReMe)

### S3. LiveVAE: Causal Window Attention Makes Efficient Streaming Video VAE

**문제·방법:** pretrained video VAE의 effective receptive field에서 지역성을 관찰하고 causal window attention과 distillation으로 encoder·decoder를 대체한다. bounded temporal KV를 사용한다.

**저자 보고:** MiniMax-H3에서 encoding 5.2~6.2배, decoding 3.0~3.3배, 전용 inference 최적화 결합 최대 13.4배 가속이다. **진단:** 마지막 수치는 window만의 효과가 아니다. 평균 ERF의 지역성이 모든 급이동·scene cut의 충분 관측 범위를 보장하지 않는다. **후속:** window 크기와 boundary artifact·급변 복구·장시간 cache를 함께 평가하자. repo는 inference code와 weights를 이후 추가한다고 명시한다. [공식 원문](https://arxiv.org/abs/2611.34912) · [공식 repo](https://github.com/MeiGen-AI/LiveVAE)

- 각 원문의 parameter·FLOPs·latency·VRAM·GPU·training recipe·split·pretraining·external data·ablation·seed 정보를 모두 독립 감사하지 않았다. 확인한 수치만 위에 제시했다. 나머지는 **미확인**이며 미공개 판정과 다르다.
- 비교할 때 dataset revision·source/scene/identity split, 입력 resolution·frame budget·TTA, backbone·pretraining·prompt, dtype·실제 hardware, evaluator·API snapshot을 고정한다. 다르면 `not strictly apples-to-apples`다.
- 코드 설치·weight 다운로드·유료 모델 호출·논문 재현은 수행하지 않았다. 공개 경로 확인과 논문 증거 검토까지가 이번 실행 범위다.

## 6) 중요한 Finding 3개

1. **관측 선택은 실패를 만드는 원인이 될 수 있다.** C1의 예측 기반 보존 영역과 V3의 유사도 기반 선택은 각각 중요한 대상을 놓칠 수 있다. 정보가 encoder에 없어진 문제를 readout 개선으로 해결할 수 있는지 먼저 구분해야 한다. 두 논문을 묶은 기전 해석은 추론이다.
2. **좋은 대리 지표가 목표 능력을 보장하지 않는다.** C3의 존재 ROC-AUC와 위치 정밀도, V2의 2D와 3D, C1의 FLOPs와 전체 지연은 서로 다른 계약이다. 하나의 숫자로 성공을 요약하면 다음 실험의 병목을 놓친다.
3. **맥락을 사용하는 것과 올바르게 사용하는 것은 다르다.** C2의 전형적 이웃, S1의 검색된 사실은 잘못된 의존이 될 수 있다. 맥락 제거가 항상 해법이라는 증거는 없으며, 대상을 고정한 맥락 변경 대조가 필요하다.

## 7) 과대평가 가능성 / 주의할 연구

- **AgenTAP:** “expert를 능가”는 해당 benchmark·tool·모델·관측 예산의 결과다. 같은 latency·추가 image 호출·검증 비용에서의 우월성은 별도 질문이다.
- **LiveVAE:** 최대 13.4배는 전용 최적화 결합이다. window attention 단독, 전체 diffusion pipeline, 모든 resolution에서의 가속으로 확장하지 않는다.
- **공통 경계:** STRANGE-Bench의 합성 조건과 자연 환경, SAR의 상업 선박과 작은 비협조 표적, memory의 구성된 충돌과 실제 세션은 다른 분포다. 이번에 독립 검증한 SOTA나 실사용 성능은 없다.

## 10) 후속 연구 씨앗 3개

아래는 모두 **미실행 제안**이다. 비용은 조사자의 상대 판단이며 실측치가 아니다. Compute cost /5는 낮을수록 가볍다.

### A. 관측을 놓친 손실과, 다시 봐도 못 읽는 손실을 분리할 수 있는가?

- **Observation → Diagnosis:** 과거 예측이 다음 관측 해상도를 결정하면 일시적 이탈이 지속 손실로 바뀔 수 있다.
- **Hypothesis → 최소 개입:** 짧은 dense 관측을 주었을 때의 회복 여부가 관측 병목과 memory/readout 병목을 나누는 단서가 된다. oracle 회복 자체를 배포 정책으로 주장하지 않는다.
- **첫 실험·baseline:** LVOS V2의 고정 clip·동일 head/checkpoint에서 dense, uniform merging, focus 정책을 비교한다. GT는 진단 시점 식별에만 쓰고, 이탈 뒤 정해진 길이의 dense burst를 삽입한다. 정상 구간의 같은 burst를 대조군으로 둔다.
- **Metric·GO/KILL:** 이탈 이후 recovery time·ID 유지·J&F·추가 FLOPs·startup 포함 시간을 기록한다. 별도 영상에서 burst가 복구하는 군과 못 하는 군을 일관되게 나누면 GO. GT 미래정보로만 보이는 효과거나 동일 예산 uniform 관측과 차이가 없으면 개입 가설 KILL이다.
- **Novely·negative result:** 원논문에 fallback·surprise가 이미 있어 신규성 위험이 크다. 회복 실패의 원인을 memory contamination까지 구분해야 확장 가치가 있다. 음성 결과는 추가 encoder 계산만으로 고칠 수 없는 조건을 규정한다.
- **계획·비용:** 1~2주 기존 trace 감사, 3~4주 paired 개입, 5~8주 held-out 복귀 검증. trace 감사 1/5, 추론 3/5. 8GB 실행은 미확인이다.

### B. 이웃 의존은 객체 크기가 줄 때 representation 손실과 어떻게 상호작용하는가?

- **Observation → Diagnosis:** 비전형 조합의 성능 차이가 작은 객체에서 커져도 맥락 의존인지 입력 정보 부족인지 분리되지 않는다.
- **Hypothesis → 최소 개입:** target pixel을 고정한 context 변경과 target 해상도 변경을 교차하면, 맥락 효과가 읽을 수 있는 시각 정보량에 따라 달라질 수 있다.
- **첫 실험·baseline:** STRANGE-Bench와 COCO의 허용 표본에서 target 면적·가림·위치·codec을 맞춘다. 동일 crop 유지/주변 변경 × target native/downsample 조건을 구성한다. frozen encoder의 linear probe와 기존 detector head를 비교한다.
- **Metric·GO/KILL:** size별 AP/recall·target crop probe·context 변경에 따른 confidence flip·typical accuracy 손상을 기록한다. 자연 표본에서도 size×context 상호작용이 유지되면 GO. 편집 seam·가림 차이로 설명되면 KILL이다.
- **Novelty·negative result:** 원논문에 masking·배치·augmentation이 이미 있다. 작은 객체의 정보 손실과 readout을 실제로 분리하지 못하면 신규성이 낮다. 음성 결과도 size를 맞춘 뒤 bias가 독립적으로 남는지 알려준다.
- **계획·비용:** 1~2주 paired 표본 감사, 3~4주 frozen probe, 5~8주 자연 조건 재검증. 감사 1/5, probe/추론 2~3/5. 현재 GPU 비용은 미측정이다.

### C. 선박 선종 probe는 길이를 읽는가, 길이 외 정보를 읽는가?

- **Observation → Diagnosis:** C3의 선종과 길이 상관은 representation의 세부 의미 정보에 대한 교란 요인이다.
- **Hypothesis → 최소 개입:** 길이 분포를 맞추고 ship identity·지역·시간을 분리하면 embedding의 추가 선종 정보가 줄거나 남을 수 있다.
- **첫 실험·baseline:** S1-single-ship 데이터에서 metadata와 split을 먼저 확인한다. 길이-only, embedding linear/MLP, 길이+embedding을 같은 train/val ID로 비교한다. 길이 annotation과 noisy AIS의 불일치도 층화한다.
- **Metric·GO/KILL:** macro-F1·class별 recall·길이 구간별 성능·group bootstrap CI와 길이-only 대비 추가 이득을 기록한다. held-out group에서도 추가 정보가 남으면 GO. 중복 선박·장면 또는 길이 불균형이 이득을 설명하면 세부 선종 정보 가설 KILL이다.
- **Novelty·negative result:** 원논문이 이미 길이 상관을 지적하므로 단순 length baseline은 새 기여가 아니다. compression 수준·probe 복잡도에 따른 추가 정보 소실 경계를 확보해야 한다. 음성 결과는 fine-grained 해양 인식에 필요한 원본 관측의 범위를 제한한다.
- **계획·비용:** 1~2주 metadata·누수 감사, 3~4주 cached probe, 5~8주 공간·시간 외삽 검증. cached audit 1/5, embedding 생성은 자원 미확인이다.

**오늘 첫 행동:** A의 기존 trace에서 이탈 시점·회복·실제 시간을 나란히 확인한다. 작은 GPU 없이 시작할 선택은 C의 metadata/split 감사다. 장기 주제는 관측·representation·memory·readout 사이의 손실을 개입으로 분해하는 진단 연구이며, 현재는 연구 방향 제안이다.

## 11) 오늘 안 읽어도 되는 것

선정에서 제외한 세 후보도 공식 초록을 확인했다.

- **AnyCam: Anything Can Represent Camera for Video Generation:** anchor object의 3D 재구성으로 카메라 제어를 표현한다. 생성 viewpoint control을 당장 연구하지 않는다면 오늘 진단 후보보다 후순위다. [공식 원문](https://arxiv.org/abs/2611.34944)
- **LuxAvatar: Real-Time Relightable Head Avatars via Causal Neural Shading of 3D Intrinsic Proxies:** portrait avatar·relighting·distillation의 가치가 있지만 사용자 탐지·관측 진단과의 직접성이 낮다. [공식 원문](https://arxiv.org/abs/2611.34940)
- **Do We Really Need an LLM for Weight-Space Programming? A Deterministic Forward-Only Paradigm and Its Capability Boundaries:** 결정론적 editing baseline은 흥미롭지만 subset 선택·token budget·backend 전이를 더 감사한 뒤 읽을 후보로 둔다. 오늘 architecture 대안으로 바로 채택할 근거는 부족하다. [공식 원문](https://arxiv.org/abs/2611.34612)
