## 2) CV / DL-CV 핵심 6편

### C1. Modern Self-Supervised Vision Transformers Are Pareidolic

**날짜:** v1 2026-11-23 UTC. 최근 공개분.

**문제·방법·저자 보고:** white noise에서도 공간적으로 정돈된 patch feature 방향이 나타난다. DINOv2/v3에서 이 subspace의 과도한 분산이 object emergence를 방해한다는 진단이다. PSC는 noise로 subspace를 추정하고 해당 방향을 축소한다. 객체 발견에서 최대 +31.7 CorLoc, saliency에서 +30.2 maxF, video segmentation에서 +59.9 J를 보고한다. 서로 다른 과제의 최대 증가량이며 하나의 공통 성능 향상률이 아니다.

**한계·후속:** 주 검증은 frozen feature와 training-free readout이다. supervised detector의 AP-small 향상이나 모델의 일반적인 “환각 감소”를 입증하지 않는다. 작은 물체와 복잡한 배경에서 보정 방향이 신호도 억제하는지 검사할 가치가 있다. 코드·weights bundle은 이번 조사에서 확인하지 못했다. [공식 초록](https://arxiv.org/abs/2611.31238) · [본문](https://arxiv.org/html/2611.31238v1)

### C2. TowerBridge: Bridging the Dual-Encoder Modality Gap via Weight-Space Programming

**날짜:** v1 2026-11-23 UTC. 최근 공개분.

**문제·방법·저자 보고:** CLIP의 modality gap 제거는 검사한 checkpoint 모두에서 retrieval을 악화시켰다. 저자는 정답 pair보다 hard negative에서 더 강하게 일치하는 방향을 약하게 감쇠한다. LLM agent가 weight edit를 탐색하고 이를 closed-form 보정으로 정리했다. labelled pair 25,000개로 계산하며 21개 CLIP checkpoint 평균 COCO RSUM +16.8, Flickr30k +6.6을 보고한다. ImageNet zero-shot 손실은 최대 0.5점이다.

**진단·후속:** gap의 크기 자체보다 잘못된 pair의 margin을 좁히는 방향이 중요할 수 있다. label-free 방법이 아니며 calibration pair와 평가 이미지·caption의 중복, agent가 본 모델과 unseen 모델의 분리를 확인해야 한다. OVD 전이를 보장하지 않는다. 동일 pair budget으로 centering·whitening·random 방향 감쇠와 비교하는 것이 첫 단계다. code 공개 상태는 미확인이다. [공식 원문](https://arxiv.org/abs/2611.31233)

### C3. LeJEPA Features Are Not Isotropic, and Should Not Be

**날짜:** v1 2026-11-23 UTC. 최근 공개분.

**문제·방법·저자 보고:** SIGReg가 목표 분포를 충분히 강제하지 못하며, magnitude와 direction의 독립성 목표도 alignment와 충돌한다고 분석한다. PolarReg는 두 marginal을 제어하면서 독립성을 강제하지 않는다. ImageNet-1k에서 기존 정확도 도달까지 4.7배 적은 epoch, 최종 정확도 +1.8점을 보고한다.

**주의·후속:** epoch 감소를 GPU 시간 4.7배 절감으로 읽지 않는다. 프로젝트 표의 frozen linear probe와 다른 downstream 성능도 구분해야 한다. 같은 augmentation·batch·optimizer에서 marginal 제어와 independence penalty를 교차하는 ablation이 핵심이다. 크기·방향의 결합이 배경 shortcut인지 유용한 uncertainty인지 domain별로 확인한다. 프로젝트의 Code/Paper 버튼은 이번 조회에서 실제 다운로드 대상으로 연결되지 않아 실행 bundle을 확정하지 못했다. [초록](https://arxiv.org/abs/2611.31216) · [본문](https://arxiv.org/html/2611.31216v1) · [저자 프로젝트](https://www.engineering.upenn.edu/~richeek/polarreg/)

### C4. Leakage-Safe Auditing of Attribution-Driven Data Curation in Medical Imaging

**날짜:** v1 2026-11-23 UTC. 최근 공개분.

**문제·방법·저자 보고:** CTA aneurysm candidate classifier를 patient-disjoint·ID 보존 조건으로 감사했다. positive patch 1,201개 중 raw-zero 232개를 발견했고, 위치 순서로 join한 과거 321개 attention-failure subgroup을 무효화했다. training positive 170개를 삭제한 5 paired seeds의 AUC는 0.9617±0.0044, 전체 데이터는 0.9652±0.0039다. 차이의 95% CI는 −0.0082~0.0007로 삭제의 개선을 뒷받침하지 않는다.

**기여·한계:** anomaly 발견과 삭제 이득을 분리한 negative result다. “오염 데이터를 유지하는 것이 언제나 낫다”는 결론이 아니다. 단일 candidate classifier이며 end-to-end 임상 탐지 성능이 아니다. deletion·repair·동일 수 random removal을 구분하고 크기별 민감도를 봐야 한다. 원시 임상 데이터 접근·실행 artifact는 미확인이다. [초록](https://arxiv.org/abs/2611.31096) · [감사 설계](https://arxiv.org/html/2611.31096v1)

### C5. Analyzing and Improving FlowMap Distillation of Autoregressive Video Models

**날짜:** v1 2026-11-23 UTC. 최근 공개분.

**진단·후속:** teacher 크기·증류 목표가 다른 비교는 `not strictly apples-to-apples`다. VBench 일치가 동일 diversity·추론 비용·긴 시간 identity 보존을 뜻하지 않는다. 정적 배경과 빠른 움직임을 층화하고 anti-drift와 motion guidance를 분리해 object identity 오류를 검사한다. 코드·weights·정확한 GPU 비용은 미확인이다. [공식 원문](https://arxiv.org/abs/2611.31164)

### C6. Pruning Autonomous Driving VLAs: What to Preserve for Reasoning and Action

**날짜:** v1 2026-11-23 UTC. 최근 공개분.

**방법·저자 보고:** Alpamayo-1.5-10B에서 reasoning과 trajectory loss의 중요도가 다르다는 관찰로 MoOP를 제안한다. 두 목적의 rank를 결합하고 expert MLP 중요도를 denoising step에 걸쳐 집계한다. 24.0% 전체 parameter 감소에서 dense LingoQA 점수의 94.0%를 유지한다. expert까지 줄인 39.4% 감소 모델은 end-to-end 1.37배 가속·peak memory 36.6% 감소를 보고한다. 두 budget의 결과를 섞지 않는다.

**사실·주의:** 공식 repo는 중요도 파일·sample list·평가 절차와 gated 기반 weights 요구를 명시한다. 중요도 재측정의 GPU 비결정성과 동률 정렬 민감성도 공개한다. open-loop error, closed-loop score, LingoQA를 각각 읽어야 하며 안전성 보장으로 해석할 수 없다.

**후속:** 같은 pruning budget에서 calibration 장면 조합과 rank 동률 처리를 바꾸어 reasoning/action의 최악 subset을 측정한다. [논문](https://arxiv.org/abs/2611.31240) · [공식 구현](https://github.com/cvlab-kaist/MoOP)

### S1. Language Models Steer on Injected Uncertainty Tokens, but Fail to Self-Monitor In Situ

**날짜:** v1 2026-11-23 UTC. 최근 공개분.

**방법·저자 보고:** 네 open-weight 모델의 수학 시도 15,200개와 counterfactual continuation 27,568개로 monitoring과 control을 분리한다. 오류 단계의 confidence 식별 AUROC는 0.500~0.561인데, 외부 low-confidence tag는 correction을 +3.7~+22.5점 높인다. 반대로 맞는 단계에 의심을 주입하면 solve rate가 최대 22.8점 하락한다.

**주의·후속:** oracle가 오류 위치를 아는 개입은 실제 자동 오류 감지 성능이 아니다. 모델의 capability frontier 내 수학 오류 결과를 VLM grounding에 그대로 일반화하지 않는다. 오류뿐 아니라 정상 단계의 손상 비용까지 포함해 trigger를 평가해야 한다. 수치 tag의 의미·형식 효과도 구분한다. 코드·실행 bundle은 미확인이다. [공식 원문](https://arxiv.org/abs/2611.31228)

### S2. Reducing Order Sensitivity in Decision Models

**날짜:** v1 2026-11-23 UTC. 최근 공개분.

**방법·저자 보고:** 10개 decision model에서 option 순서 민감도를 보고하고 완화법 8개를 비교한다. shared context에서 option을 병렬 branch로 처리하는 tree attention이 순서 불변성을 달성한다. 학습 때 쓰면 baseline 평균 정확도와 비슷하며, 재학습 없이 적용하면 정확도 손실 1.1점을 보고한다.

**주의·후속:** 순서 불변성과 정답률은 별개다. branch mask뿐 아니라 position ID·동률 처리·option 내용의 cross-option 상호작용을 확인해야 한다. 후보 수가 커질 때 worst-permutation accuracy와 latency를 함께 보자. VLM의 object list에도 적용할 수 있다는 것은 후속 가설이다. 코드·하드웨어별 지연은 미확인이다. [공식 원문](https://arxiv.org/abs/2611.31174)

### S3. LiveLoRA: Exact KV Cache Migration Across LoRA Updates for LLM Agents

**날짜:** v1 2026-11-23 UTC. 최근 공개분.

**방법·저자 보고:** lower decoder block과 K/V adapter down-projection을 고정해 final-block cache를 새 adapter로 재구성한다. adapter·cache·next-token logits를 함께 commit한다. Qwen2.5-3B-Instruct, 32 session×8K token에서 full re-prefill 대비 adapter publication 평균 68.98배 가속과 native cached decoding 대비 약 4.8% overhead를 보고한다.

**주의·후속:** exact arithmetic와 명시한 모델 제약 아래의 continuation equivalence다. 임의 layer 전체 LoRA 업데이트의 무손실 cache 변환도, 생성 전체 69배 가속도 아니다. finite precision·동시 update·중단 후 복구 조건에서 full re-prefill과 logits 및 실제 continuation을 비교해야 한다. 코드 공개·실제 kernel 실행은 이번에 미확인이다. [공식 원문](https://arxiv.org/abs/2611.31105)

## 6) 연구적으로 중요한 Finding 3개

1. **왜곡을 줄이는 것과 등방성을 강제하는 것은 다르다.** PSC는 과도한 특정 방향을 조절하고, TowerBridge는 gap을 보존하면서 해로운 방향을 조절하며, PolarReg는 불필요한 독립성 제약을 완화한다. 모든 feature whitening이 같은 해법이라는 결론은 나오지 않는다. [PSC](https://arxiv.org/abs/2611.31238) · [TowerBridge](https://arxiv.org/abs/2611.31233) · [PolarReg](https://arxiv.org/abs/2611.31216)
2. **실패를 식별해도 해결책의 효용은 따로 검증해야 한다.** 의료영상의 손상 확인은 deletion 이득을 입증하지 않았고, uncertainty tag의 correction 이득은 실제 오류 감지 능력을 입증하지 않았다. [데이터 감사](https://arxiv.org/abs/2611.31096) · [Monitoring/control](https://arxiv.org/abs/2611.31228)
3. **보유·탐색·보존·사용의 경계를 명시해야 한다.** ActSpace는 증거 획득과 추론을 나누고, Lyris는 관측과 생성 memory를 연결하며, LiveLoRA는 상태를 어느 모델 버전에 귀속하는지 다룬다. 이는 논문 간 종합 추론이며 공통 메커니즘을 검증한 결과는 아니다. [ActSpace](https://arxiv.org/abs/2611.31215) · [Lyris](https://arxiv.org/abs/2611.31239) · [LiveLoRA](https://arxiv.org/abs/2611.31105)

## 9) 1위 논문 미니 리뷰

PSC의 중요한 출발점은 “새 SSL 모델은 dense feature가 강한데 왜 객체가 저절로 분리되는 능력은 약해졌는가”라는 모순이다. noise를 넣어 모델 자체가 만드는 공간 template을 찾고, 자연 이미지의 객체 정보와 이 template의 경쟁을 검사한다. 새 block보다 관찰→방향 특정→감쇠→회복 순서로 진행한다. [공식 초록](https://arxiv.org/abs/2611.31238)

본문의 개입은 **최종 key feature**의 일부 방향 분산을 조절한다. noise 한 장의 forward와 SVD로 basis를 얻고 token마다 낮은 rank 연산을 추가한다. 보정은 가역적이므로 좌표 변환이 정보를 새로 생성하거나 완전히 삭제하는 조작은 아니다. 그러나 가역성만으로 모든 downstream readout의 성능 보존이 보장되지는 않는다.

평가는 TokenCut 계열이다. 객체 발견은 native resolution의 VOC07/12 trainval·COCO20K CorLoc, saliency는 bilateral solver 이후 metric, video는 320×576 frame과 RAFT flow·CRF를 포함한다. 따라서 video 증가량을 vision encoder 하나의 standalone segmentation 성능으로 읽지 않는다. 논문은 patch-level loss의 역할을 controlled training으로 조사하지만, foundation model 간 사전학습 데이터 차이까지 모두 제거한 보편 법칙으로 볼 수 없다. [방법·프로토콜](https://arxiv.org/html/2611.31238v1)

가져올 핵심은 noise basis 자체를 다시 제안하는 것이 아니라, **작은 객체·복잡 배경에서 무엇을 회복하고 무엇을 손상하는가**를 동일 조건으로 묻는 것이다. representation의 보존 여부, readout의 좌표 민감성, 실제 detection utility를 순서대로 검사해야 한다. 본문에 이미 다양한 task·ablation이 있어, PSC 재현만으로 신규 기여가 되기는 어렵다.

## 10) 후속 연구 씨앗 3개

### A. Noise subspace 보정은 작은 객체의 증거를 회복하는가, 유용한 위치 prior도 지우는가?

**관찰→진단:** PSC의 object emergence 회복은 tiny instance의 정보 보존을 직접 보장하지 않는다. **가설:** clutter·크기 조건에 따라 같은 방향이 nuisance와 유용한 spatial prior를 함께 담을 수 있다.

**최소 실험:** frozen DINOv2-S의 동일 key feature에서 raw·PSC·동일 rank random 방향 감쇠·자연 이미지 PCA 감쇠를 비교한다. 추가 readout 학습은 같은 예산으로 고정한다. 같은 이미지에 scale·translation을 적용해 객체 크기와 절대 위치를 교차한다.

**데이터·baseline·metric:** COCO val2017의 고정 개발 subset, box 면적별 CorLoc·object/background margin·위치별 오류, 동일 label budget의 linear readout을 사용한다. 전체 detection을 실행하지 않으면 AP-small을 보고하지 않는다.

**GO/KILL:** PSC가 동일 rank 대조군보다 작은 객체를 회복하고 큰 객체·위치 이동에서 손상을 늘리지 않으면 확장한다. 개선이 단순 global scaling이나 threshold 재조정으로 사라지면 독립 메커니즘 주장을 중단한다. negative result도 적용 경계를 남긴다.

**비용·신규성:** 계획상 cost 2/5. feature cache부터 시작하되 실제 VRAM은 미측정이다. 원 논문의 calibration·ablation과 중복 위험이 높아 tiny-size×position의 특이한 실패 경계가 있어야 한다. 4~8주 MVP는 가능성 판단이며 성과 보장이 아니다. [근거](https://arxiv.org/html/2611.31238v1)

### B. 손상 데이터 삭제의 효과는 손상 자체와 rare-positive 분포 변화 중 무엇에서 오는가?

**관찰→진단:** 의료영상 감사는 raw-zero 삭제의 평균 개선을 확인하지 못했다. **가설:** 손상 여부와 작은 병변·rare-positive 비율이 얽혀 삭제가 다른 분포 변화를 만든다. 원문은 이미 크기 연관과 random-removal을 조사하므로 그 재실행만으로 새롭지 않다.

**최소 실험:** 접근 가능한 lesion dataset의 원본을 보존하고 synthetic raw-zero를 주입한다. clean 전체·corrupt 유지·삭제·원본 복구·크기/빈도 matched random removal을 같은 split·초기화·update budget으로 비교한다. 합성 손상 실험을 자연 손상의 효과로 보고하지 않는다.

**데이터·metric·판정:** 공개 접근과 license를 확인한 DeepLesion 등에서 patient-disjoint가 가능한 subset을 먼저 확정한다. 접근이 안 되면 임상 전이를 주장하지 않는다. AUC뿐 아니라 작은 병변 recall·고정 FPR sensitivity·paired 차이를 기록한다. repair와 deletion 효과가 층별로 갈리면 GO, 평균 차이만 있고 분포 설명이 재현되지 않으면 인과 주장을 KILL한다.

**비용·신규성:** cost 3/5의 계획. 4~8주에는 작은 2D candidate classifier부터 가능하다. 원 논문의 삭제·random 대조와 겹치므로 손상 정도×희소성×repair의 반응 지도가 필요하다. 효과가 없으면 cleaning 정책의 제한을 남긴다. [근거](https://arxiv.org/html/2611.31096v1)

### C. 오류 수정 trigger의 가치는 회복률보다 정상 경로 손상 비용에 좌우되는가?

**관찰→진단:** oracle uncertainty는 잘못된 풀이를 고치지만 맞는 풀이도 망가뜨린다. **가설:** 드문 실제 오류 환경에서는 trigger의 false positive가 순이득을 지배할 수 있다.

**최소 실험:** 저장된 correct/error 단계에서 no-tag·형식 일치 높은 confidence·낮은 confidence·중립 재검토 지시를 교차한다. 같은 token budget을 맞추고 oracle trigger와 관측 가능한 trigger를 분리한다. 이후 별도 split에서 오류 prevalence를 바꾸되 실제 배포 빈도로 오인하지 않는다.

**데이터·baseline·metric:** 원문 계열 수학 benchmark의 개발 split과 같은 checkpoint를 우선한다. error recovery, correct-to-wrong, 최종 solve rate, 추가 token을 함께 보고한다. fixed false-positive budget에서 순 solve 이득이 유지되면 GO, oracle 위치에서만 효과가 나면 자동 self-monitoring 주장을 KILL한다.

**비용·신규성:** cost 2~3/5의 계획. 원문이 이미 정상 단계 손상을 보고하므로 단순 의심 주입은 신규성이 없다. 실제 trigger의 calibration과 prevalence 변화의 손익 경계를 4~8주 MVP로 삼는다. VLM 전이는 후속 가설이며 이번에 검증하지 않았다. [근거](https://arxiv.org/abs/2611.31228)

**오늘 먼저 할 것:** A의 feature cache와 동일 rank 대조군 설계. 작은 GPU에서는 학습보다 feature 추출·저장 후 CPU 통계부터 시작한다. 장기 방향은 데이터 이상·representation 왜곡·readout 실패를 같은 개입 언어로 분리하는 연구다.

## 11) 오늘 안 읽어도 되는 것과 후보 검토 기록

선정 12편 외에 다음 공식 초록 3편을 읽어 총 15편을 검토했다.
