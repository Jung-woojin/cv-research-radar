## artifact 재검증 — V-Thinker 공개물의 배포 경계

- **사실:** [V-Thinker repository](https://github.com/We-Math/V-Thinker)는 MIT code license와 V-Interaction-400K, V-Perception-40K, VTBench 및 Models 링크를 제시하고, 11월 7일에 preview dataset/benchmark 공개를 공지한다.
- **사실:** repository quick-start는 `pip install -e .`, benchmark image 배치, vLLM update와 model/dataset path 수정을 안내한다.
- **저자 주장:** repository 표의 V-Thinker-7B 결과와 data description은 저자 제공 정보다.
- **미확인:** 이번 재검토 범위에서 특정 model-weight revision/hash, weight checksum, dataset 자체 license, GPU/VRAM minimum, evaluator의 immutable revision을 확인하지 못했다.
- **진단:** code repository의 MIT license 및 설치 문서가 data/weight의 재사용 가능성과 재현 가능성을 대신하는 것처럼 보일 수 있다.
- **가설:** artifact manifest를 고정하지 않고 score table만 참조하면, 이후 data 또는 evaluator 교체를 model gain으로 오인할 위험이 있다.
- **10–30분 smoke test:** 다운로드·실행 전에 repository commit, Hugging Face dataset revision, 각 shard count, model file hash, evaluator dependency lock을 manifest로 수집한다. code field가 포함된 dataset은 임의 실행하지 않는다.
- **GO/KILL:** license·revision·checksum·evaluator contract가 모두 확보되면 subset evaluator 검토로 GO다. 하나라도 불명확하면 training/leaderboard comparison은 KILL·보류다.

## 오늘의 GO / KILL

- **GO:** 오늘은 신규 artifact를 만들지 않고 전일 기록의 manifest gap을 pending audit으로 유지한다.
- **GO:** package update에는 tag뿐 아니라 weight/data/evaluator revision을 분리해 기록한다.
- **KILL:** `v8.4.208`의 NMS default 변경을 새 YOLO weight·새 benchmark score로 서술하지 않는다.
- **KILL:** preview dataset, MIT code license, repository roadmap만으로 공개 weight·data license·reproducible checkpoint를 추정하지 않는다.
- **KILL:** 근거가 부족한 날 3~5개 항목을 채우기 위해 오래된 release를 “신규”로 재포장하지 않는다.
