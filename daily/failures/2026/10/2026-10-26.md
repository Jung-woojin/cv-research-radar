## 1. DuoCook — 강한 VLM도 동적 자원 공유와 인계에서 대부분의 주문을 끝내지 못한다

**실패 조건.** 한 VLM이 두 플레이어를 중앙집중 방식으로 제어하면서 제한 시간 안에 조리 순서, 장비 경합, 지형 변화, 분리된 작업 공간 사이의 인계를 함께 계획해야 할 때다.

**모델·데이터·설정.** 20개 Unreal Engine map, 5개 범주에서 qwen3.8-27b, gemini-3.5-flash-lite, claude-opus-5, gpt-6-astra를 비교했다. top-down 영상, prop legend, live-state JSON, legal operation list, 최근 6개 응답 이력이 제공되고 engine이 navigation을 수행한다. 모델·map 조합당 한 episode다.

**확인된 사실.** 주문 완료율은 Qwen 8.8%, Gemini 11.2%, Claude 8.8%, Astra 26.2%였다. Claude는 20개 map 중 15개, Qwen은 14개에서 아무 음식도 전달하지 못했다. 동적 지형과 공유 장비를 함께 쓰는 map에서는 네 모델 중 세 모델이 모든 map에서 0 delivery였고, 분리 작업 공간에서는 Claude와 Gemini의 8개 episode가 모두 0 delivery였다. Astra의 action acceptance도 64.6%라 합법 action 목록이 주어져도 약 3분의 1이 실행되지 않았다.

**공식 인정·공동체 재현.** 저자는 benchmark가 포화와 멀고 동적 공유 장비와 분리 공간이 가장 큰 장벽이라고 명시한다. 각 설정이 1회 실행뿐이어서 반응 변동성과 model ranking 안정성을 추정할 수 없다고도 인정한다. 공개 코드·환경 저장소는 원문에서 확인하지 못했고, 독립 재현도 확인되지 않았다.

**공유 memory의 음성 결과.** notebook을 추가하면 모든 모델의 평균 API 비용이 증가했다. Claude와 Qwen은 관측 평균 점수가 올랐지만 GPT와 Gemini는 낮아졌다. Gemini action acceptance는 notebook 없음 56.4%에서 있음 32.1%로, delivery는 21개에서 12개로 줄었다. Astra acceptance도 70.3%→64.6%로 내려갔다. 저자는 notebook이 attention과 경쟁할 가능성을 제시하지만 trajectory-level 증거가 없어 기전으로 확정하지 않는다.

**기존 주장과 충돌.** 장기 agent에서 self-authored memory가 상태 추적을 일관되게 개선한다는 일반적 기대와 충돌한다. 이 결과는 “memory의 존재”보다 쓰기·읽기 정책과 attention 비용, 오래된 상태 폐기가 중요함을 보여준다. 단, 모델당 1회/map이므로 효과 크기는 반복 실험 전 확정할 수 없다.

**진단 → 가설 → 최소 실험.** 진단은 notebook이 작업 상태를 구조화하지 못하고 이미 제공된 live state·action history와 중복돼 context 경쟁을 만든다는 것이다. 가설은 모든 관찰을 저장하는 memory보다 order-critical fact만 쓰고 완료·무효 상태를 즉시 폐기하는 event-sourced memory가 낫다는 것이다. 5개 고난도 map에서 no memory, 자유 notebook, schema memory를 각 5 seed로 비교한다. completion, acceptance, stale-read rate, tokens, USD/episode를 기록한다. schema memory가 no-memory 대비 completion +8%p 이상, stale read -50%, 비용 +20% 이내면 진행한다. seed 신뢰구간이 겹치거나 향상이 token 증가와 함께 사라지면 중단한다.

**평가.** 심각도 5/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 5/5.

## 2. AnyGameRenderer — 평균 개선 뒤에 실제 게임 실패와 evaluator 천장이 남는다

**실패 조건.** blockout이 아닌 실제 게임 영상에서 다수 entity의 출현·소멸·수량 변화를 유지하면서 스타일을 바꿀 때, 그리고 detector 기반 metric으로 그 결과를 판정할 때다.

**모델·데이터·설정.** MiniMax-H3 ref2va 33B에 LoRA를 적용하고 약 10k paired clip으로 학습했다. held-out benchmark는 59개 case와 753개 entity이며, 34개 multi-stream, 11개 two-stream, 14개 real-game case로 구성된다. 같은 seed, 20 sampling step, 같은 caption을 사용하고 SAM3와 Hungarian matching으로 entity를 평가한다.

**확인된 사실.** 전체 split에서 temporal match 50.9→62.9%, position 57.1→61.9%, hallucination 52.1→46.0%, missed count change 34.7→21.3%로 개선됐다. 그러나 real-game split은 temporal 46.5→51.1%, position 52.4→53.2%, hallucination 52.1→45.4%에 그쳤고 missed count change는 20.0%로 동일했다. unrendered rate는 real-game에서 2.6→2.9%로 소폭 악화했다.

**평가기 실패.** 동일 detector·matching pipeline을 ground-truth RGB 영상에 적용한 GT floor도 전체 temporal 80.9%, position 79.3%, hallucination 34.1%였다. real-game GT floor의 hallucination은 37.4%다. 즉 생성 모델의 45.4% hallucination 중 상당 부분은 evaluator의 오검출·matching 한계와 분리되지 않는다. 12 frame 미만 entity는 평가에서 제외되고, IoU≥0.3 또는 상대 centroid 조건으로 match하므로 작은·짧은 객체 실패를 과소평가할 수 있다.

**공식 인정·공동체 재현.** 저자 원문은 real recording에서 개선이 가장 작고 count-change miss가 그대로라고 명시한다. 공식 Apache-2.0 저장소에는 추론 코드와 LoRA가 공개됐지만 base weight 123GB, CPU RAM 128GB 이상, GPU peak 약 50GB, H100급에서 124-frame clip당 약 17분이 요구된다. 공개 직후이며 독립 재현은 확인되지 않았다.

**기존 주장과 충돌.** “모든 entity의 위치와 timing을 intact하게 유지한다”는 초록·README의 강한 서술은 전체 62.9% temporal match와 real-game 51.1%를 함께 읽어야 한다. 저자 비교 내 개선은 확인되지만, 절대 correspondence 보장이나 일반 게임 적용을 의미하지 않는다.

**진단 → 가설 → 최소 실험.** 진단은 실제 영상의 texture·effect·occlusion이 detector 오류와 생성 오류를 동시에 키운다는 것이다. 가설은 detector 한 개의 point estimate보다 사람 라벨 일부와 detector ensemble의 불확실성 구간을 함께 쓰면 실제 correspondence failure를 더 안정적으로 분리할 수 있다는 것이다. real-game 14 case 중 5개를 frame-level 수동 라벨링하고 SAM3 단독, detector 2종 합의, 사람 라벨을 비교한다. temporal/position/hallucination의 evaluator agreement, bootstrap CI, count-change recall을 측정한다. 사람 대비 hallucination 오차를 절반 이상 줄이고 model ranking이 유지되면 진행하며, ranking이 evaluator 선택에 따라 뒤집히면 현재 benchmark 결론을 보류한다.

**평가.** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5.

## 3. Progress Probes P² — 높은 AUROC가 충분히 빠른 안전 개입을 보장하지 않는다

**실패 조건.** VLA가 실행 중 궤도에서 이탈했을 때 low-FPR monitor가 피해 전에 경보해야 하는 조건이다. episode 종료 후 분류가 아니라 조기 탐지 시간이 핵심이다.

**모델·데이터·설정.** π0.5 내부 activation에 성공 demonstration만으로 선형 progress probe를 학습한다. simulation과 Franka Research 3의 6개 manipulation task를 평가했다. simulation에서 episode/state AUROC, 5% FPR의 시점별 TPR, detection time을 보고한다. hardware는 task당 20회, 총 120 rollout의 성공/실패 50:50 평가다.

**확인된 사실.** simulation episode/state AUROC는 0.909/0.788, unseen task는 0.900/0.794였다. 하지만 5% FPR에서 P²의 TPR은 episode 25% 시점 0.00, 50% 시점 0.19, 75% 시점 0.54, 종료 시점 0.64였다. 평균 탐지 시점은 episode fraction 0.60이다. all-task hardware의 Coffee Bean state AUROC는 0.26으로 task 간 편차도 컸다.

**공식 인정·공동체 재현.** 저자는 π0.5 한 계열과 VLM backbone activation에 집중했으며 GR00T·MolmoAct 및 continuous action expert 내부 신호로의 전이는 미검증이라고 명시한다. 공식 실행 코드 링크는 원문에서 확인하지 못했고 독립 재현도 확인되지 않았다.

**기존 주장과 충돌.** 0.9 수준 episode AUROC를 “안전한 runtime monitor”로 곧바로 해석하면 틀린다. 종료에 가까워져야 구분되는 실패는 통계적으로 잘 분류되더라도 실제 개입 여유가 없다. AUROC와 조기경보 utility는 같은 목표가 아니다.

**진단 → 가설 → 최소 실험.** 진단은 progress lag가 누적돼야 선형 probe가 실패를 구분하므로 초기의 급작스러운 접촉·spill 위험을 놓친다는 것이다. 가설은 progress residual과 action-distribution 변화, 접촉 proxy를 결합한 multi-timescale detector가 동일 5% FPR에서 조기 TPR을 높인다는 것이다. 공개 가능한 3개 simulation task에서 P², SAFE-LSTM, residual+action detector를 비교한다. TPR@25/50/75%, lead time, intervention success, false stops/hour를 측정한다. 50% 시점 TPR≥0.45, false stops/hour≤0.1, 개입 후 성공률 +10%p면 진행한다. AUROC만 오르고 lead time·개입 성공이 개선되지 않으면 중단한다.

**평가.** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5.

## 4. SpectralCanary — 높은 탐지율은 비밀성 의존 위협 모델 밖에서 보장되지 않는다

**실패 조건.** 공격자가 canary·verifier에 접근하거나, 보호 collection이 훨씬 큰 미보호 corpus에 섞이거나, 법적 귀속 판단에 고정 threshold를 그대로 사용하는 경우다.

**모델·데이터·설정.** 고정 canary image의 저주파 성분을 collection 전체에 혼합하고 ResNet-50 verifier로 T2I fine-tuning 흔적을 판별한다. 두 architecture family, 다섯 domain, LoRA와 full fine-tuning, 세 가지 adaptive spectral sanitization을 평가했다.

**확인된 사실.** 저자 설정에서 Pokemon 8개 test 평균 per-generation TPR@1% FPR은 91.1%, 30 generation의 fixed-threshold model-level accuracy는 94.8%였다. 다섯 domain SD3.5 평균 TPR은 92.4%이고 SSIM 0.989, LPIPS 0.022, 평균 ΔFID 0.05였다. 평가한 가장 강한 removal attack은 TPR을 clean baseline 쪽으로 내리려면 ΔFID 25 이상을 유발했다.

**경계 밖 음성 결과·공식 인정.** 저자는 canary image와 verifier가 비밀이라는 가정을 둔다. 공격자가 canary spectrum V, α, c를 알면 clipping·quantization 전에는 식을 정확히 역변환할 수 있다고 명시한다. 대형 미보호 corpus와의 혼합, collusion, learned removal, verifier-feedback 공격은 평가하지 않았다. SSIM·LPIPS·FID만으로 invisibility나 harmlessness를 입증하지 못하며, positive audit은 독립 증거 없는 무단 사용의 단독 증명이 아니라고 적었다.

**재현 상태.** 공식 MIT 저장소에는 실행 script, pinned third-party commit, 환경 설정이 공개됐다. 다만 SD3.5·SIREN weight의 별도 로컬 경로가 필요하고 저장소 공개 직후라 독립 연구팀 재현은 확인하지 못했다.

**기존 주장과 충돌.** 높은 closed-set TPR을 강한 provenance proof로 일반화하면 위협 모델을 벗어난다. 이 방법은 비밀 key를 가진 통계적 감사 도구이며 cryptographic watermark나 white-box 보장은 아니다.

**진단 → 가설 → 최소 실험.** 진단은 shared low-frequency signal의 학습 가능성과 제거 가능성이 같은 구조에 의존한다는 것이다. 가설은 per-release key rotation과 canary ensemble, clean-model calibration pool을 결합하면 단일 canary 노출과 domain-specific threshold 실패를 줄일 수 있다는 것이다. 보호 데이터 비율 100/20/5/1%, canary 공개/비공개, clean model 5개 조건에서 실험한다. TPR@1% FPR, model-level calibration error, ΔFID, cross-release false attribution을 측정한다. 5% 혼합에서 TPR≥80%, clean model 5개 모두 FPR≤1%, 한 key 노출 시 다른 release 영향 없음이면 진행한다. 혼합 20%에서 TPR<50%이거나 threshold가 domain마다 재보정돼야 하면 강한 귀속 주장을 중단한다.

**평가.** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 4/5.

## 오늘의 실패 패턴 3개

1. **평균 지표와 개입 가능성은 다르다.** DuoCook의 delivery precision은 delivery가 발생한 map만 계산되고, P²의 높은 AUROC는 늦은 탐지를 숨긴다.
2. **domain과 evaluator가 모델 실패를 재구성한다.** AnyGameRenderer는 synthetic/two-stream보다 real-game에서 훨씬 약하며 GT에도 높은 hallucination을 부여하는 evaluator를 사용한다.
3. **도구는 가정 안에서만 강하다.** notebook은 모델에 따라 해롭고, SpectralCanary는 비밀 canary·verifier와 제한된 공격군 안에서만 강하다.

## 논문 아이디어로 연결 가능한 빈틈

### A. Intervention-Aware Runtime Monitoring

- AUROC 대신 `경보 후 복구 가능한 시간`과 실제 intervention success를 공동 최적화한다.
- 진행 지연, action-distribution shift, 접촉 신호를 multi-timescale로 결합한다.
- **핵심 기여 후보:** 동일 FPR에서 lead-time utility를 직접 최적화하는 VLA monitor.

### B. Human-Calibrated Entity Consistency Evaluation

- detector 기반 entity metric의 GT floor를 오류 보정에 포함하고, 짧고 작은 객체의 제외 편향을 계층화한다.
- 실제 게임 split에서 사람 라벨·detector ensemble·생성 품질을 분리한다.
- **핵심 기여 후보:** evaluator uncertainty를 포함하는 generative video leaderboard.

### C. Costed Memory for Multi-Agent Visual Planning

- memory read/write를 무료 context가 아닌 행동 비용으로 취급한다.
- stale fact, duplicated state, partner contribution을 event-level로 추적한다.
- **핵심 기여 후보:** completion–cost–staleness Pareto 평가와 schema memory policy.

### D. Threat-Model Stress Test for Dataset-Use Auditing

- corpus dilution, key exposure, collusion, verifier feedback을 축으로 audit power를 측정한다.
- positive result를 법적 결론이 아닌 calibrated evidence로 제한한다.
- **핵심 기여 후보:** 공격 지식 수준별 provenance confidence calibration.

## 해석 한계

- 오늘의 수치는 직접 재실행하지 않았으며 저자 원문과 공개 저장소를 교차검증한 결과다.
- 네 사례 모두 공개 직후라 독립 커뮤니티 재현을 확인하지 못했다.
- DuoCook은 설정당 한 episode라 seed variance를 알 수 없고, P²는 π0.5 한 계열에 집중한다.

- 서로 다른 task·모델·metric 수치는 `not strictly apples-to-apples`이며 직접 순위 비교하지 않았다.
