## 1. CoBEVFlow reproduction — hard ROI mask가 flow 보정 효과를 가림

**자료:** [Temporal Residual Bottleneck 공식 원문](https://arxiv.org/html/2610.10090v1)  
**모델·데이터·구성:** CoBEVFlow 공개 경로의 DAIR-V2X 재현, PointPillars 기반 intermediate fusion, 표준 `p=0.3` 설정, AP@0.7 평가  
**공식 인정:** 비교 논문의 저자들이 부록 E에서 네 가지 inference variant를 직접 실행해 보고했다. 원 CoBEVFlow 팀의 별도 확인이나 community reproduction은 확인하지 못했다.

### 실패 조건과 재현 증거

`확인된 사실` 공개 구현의 hard ROI mask 경로는 AP@0.7 0.597이었다. ROI mask를 제거하거나, warp를 끄고 identity로 두거나, ROI 안에서만 warp하고 배경은 보존하는 blend를 쓰면 세 조건 모두 0.611이었다. AP@0.5도 hard mask 0.739에서 나머지 세 조건 0.760으로 회복했다.

`확인된 사실` 저자들은 hard mask가 재현 성능 저하의 주원인이라고 결론냈다. 그러나 mask를 고친 뒤 flow warp와 identity warp가 동일한 0.611이어서, 이 설정에서는 motion compensation 자체의 이득이 관찰되지 않았다. 메인 비교표에는 재현 규칙을 지키기 위해 공개 hard-mask 경로 0.597을 그대로 남겼다.

### 진단과 의심 메커니즘

`저자 주장` object box 바깥을 0으로 만드는 hard mask가 BEV fusion에 필요한 static/context evidence까지 제거한다. 배경을 보존하면 이 손실이 사라진다.

`추론` 실패는 flow estimator 하나의 품질보다 **feature transport와 context 보존 사이의 인터페이스 계약**에서 발생했을 가능성이 크다. ROI 내부의 warp가 실제로 맞더라도, detector가 학습 중 이용한 배경 통계를 inference에서 지우면 이득이 상쇄된다.

### 기존 주장과 충돌

“flow 기반 비동기 보정이 stale feature를 정렬해 성능을 높인다”는 일반적 기대와 충돌한다. 이 재현에서는 hard mask를 제거한 뒤에도 flow가 identity를 넘지 못했다. 다만 published CoBEVFlow와 이 in-framework reproduction은 backbone·training integration·evaluation stack이 완전히 같다고 볼 수 없으므로 **not strictly apples-to-apples**다.

### 가설 → 최소 개입 → 실험

**가설:** 성능 저하의 1차 원인은 부정확한 flow보다 ROI 밖 feature 삭제이며, flow 이득은 움직이는 객체 subset에서만 나타난다.

**최소 개입:** 새 학습 없이 동일 checkpoint에서 hard mask / no mask / background-preserving blend / identity warp를 paired inference한다.

**검증 실험:**

1. 동일 sample ordering과 evaluator로 전체 AP와 moving/static object AP를 분리한다.
2. ROI 밖 feature energy와 detection head logit 변화를 기록한다.
3. oracle box·oracle motion 조건을 추가해 correspondence headroom을 측정한다.
4. flow와 identity의 per-object paired AP 차이에 bootstrap 신뢰구간을 붙인다.

**GO:** background-preserving blend가 세 seed·두 split에서 hard mask보다 높고, flow 이득이 고속 이동 subset에서 identity 대비 일관되게 양수다.  
**KILL/수정:** oracle motion에서도 identity를 못 이기면 flow estimator보다 fusion/evaluator 구조를 먼저 수정한다.

**점수:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 4/5

## 2. MOTIP2 — 비현실적 ID corruption은 성능을 떨어뜨리고, proximity prior는 동시 교체에 취약

**자료:** [MOTIP2 공식 원문](https://arxiv.org/html/2610.10391v1)  
**모델·데이터·구성:** end-to-end MOTIP 계열, DanceTrack·PersonPath22; uniform identity swapping 대 GIoU 기반 spatial corruption; track confirmation `N_init` sweep  
**공식 인정:** 저자들이 augmentation failure와 예상되는 proximity-prior failure를 본문·부록에 직접 명시했다. 독립 community reproduction과 공식 코드 release는 이번 실행에서 확인하지 못했다.

### 실패 조건과 재현 증거

`확인된 사실` PersonPath22의 uniform corruption은 swap의 94%를 long-range로 만들고 평균 GIoU -0.65를 보였다. 그 결과 HOTA는 no corruption 59.5보다 낮은 56.1이었다. 공간적으로 가까운 box를 중심으로 고른 corruption은 long-range 31%, 평균 GIoU 0.15였고 HOTA 61.6을 기록했다.

`확인된 사실` DanceTrack에서도 uniform corruption은 long-range 85%, 평균 GIoU -0.40, HOTA 63.7이었다. spatial corruption은 26%, 0.20, HOTA 64.5였다. 저자들은 uniform shuffling이 실제 inference error와 다른 비현실적 장거리 swap을 만들어 학습을 불안정하게 한다고 보고했다.

`확인된 사실` `N_init=1→3`의 track confirmation은 ID switch를 PersonPath22에서 12.5%, DanceTrack에서 28.3% 줄였지만, accuracy는 `N_init=2`에서 사실상 plateau했다.

### 진단과 의심 메커니즘

`저자 주장` end-to-end tracker의 association error는 appearance보다 geometry에 크게 좌우되며, loss·representation·data 단계의 공간 prior가 먼 거리 ID jump를 억제한다.

`추론` uniform corruption은 “어려운 negative”가 아니라 support 밖의 label noise가 되어 classifier가 실전과 무관한 오류 분포를 학습하게 한다. 반대로 proximity prior는 같은 위치에서 한 사람이 나가고 새 사람이 들어오는 경우, 가까움 자체가 잘못된 ID 전달 신호가 될 수 있다. 논문도 이 동시 exit/entry를 가장 어려운 예상 failure case로 적었다.

### 기존 주장과 충돌

“corruption을 많이 넣을수록 association robustness가 좋아진다”는 단순 augmentation 기대와 충돌한다. PersonPath22에서는 uniform corruption이 no corruption보다 HOTA를 3.4 낮췄다. 동시에 “spatial prior가 ID switch를 해결한다”는 확대 해석도 제한해야 한다. 같은 위치의 동시 교체는 appearance·temporal absence·entry cue가 없으면 공간 prior가 오히려 오답을 강화할 수 있다.

### 가설 → 최소 개입 → 실험

**가설:** corruption의 양보다 실제 inference IDSW의 거리·IoU 분포를 맞추는 것이 중요하며, 동시 exit/entry에는 short-term confirmation만으로 충분하지 않다.

**최소 개입:** 기존 학습 pipeline에서 corruption sampler만 uniform / GIoU / empirical-IDSW-matched로 바꾸고, inference에서 `N_init=1,2,3`을 sweep한다.

**검증 실험:**

1. 실제 baseline IDSW의 pixel distance, GIoU, occlusion duration을 먼저 계측한다.
2. 세 sampler의 분포 divergence와 HOTA·AssA·IDSW를 같은 seed에서 paired 비교한다.
3. 같은 위치 exit/entry synthetic clips를 만들고 appearance similarity를 단계적으로 높인다.
4. proximity-only, appearance gate, re-entry cooldown을 분리 ablation한다.

**GO:** empirical-matched sampler가 두 데이터셋에서 uniform보다 HOTA·AssA를 높이고, appearance gate가 same-location swap을 줄이면서 정상 continuation의 IDSW를 늘리지 않는다.  
**KILL/수정:** sampler 분포를 맞춰도 개선이 사라지거나 detector false positive가 IDSW 대부분을 설명하면 association loss가 아니라 detection calibration 문제로 전환한다.

**점수:** 심각도 4/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 5/5

## 3. One-Shot Adaptive Segmentation — 특정 artifact에는 강하지만 chest X-ray에서는 SAM2와 동률

**자료:** [One-Shot Adaptive Segmentation 공식 원문](https://arxiv.org/html/2610.10306v1)  
**모델·데이터·구성:** frozen DINOv3 feature, background-adaptive orthogonalization, cosine localization, SAM segmentation; 20개 pool-boiling frame, Montgomery chest X-ray 138장, RBC microscopy  
**공식 인정:** 저자들은 chest radiograph 성능을 “comparable”로 표현하고 pool-boiling 표본 수와 전체 수치를 공개했다. 독립 reproduction과 공식 code release는 확인하지 못했다.

### 실패 조건과 재현 증거

`확인된 사실` pool-boiling에서 제안법 mIoU는 0.7579로 INSID3 0.4243, GF-SAM 0.1646, SAM2 0.0600보다 높았다. 논문은 이를 strongest baseline 대비 33.36 percentage points, 또는 78.62% relative improvement로 표현한다.

`확인된 사실` Montgomery chest X-ray에서는 제안법 mIoU 0.3960, Dice 0.5610이고 SAM2는 0.3962, 0.5608이었다. mIoU는 0.0002 낮고 Dice는 0.0002 높아 사실상 동률이다. 같은 one-shot framework의 이득이 imaging domain 전반에 균일하게 이어지지 않았다.

`확인된 사실` pool-boiling 평가는 20 frames, chest X-ray는 138 images다. 논문 표에는 reference image 선택을 바꾼 분산이나 여러 seed/reference의 신뢰구간이 없다.

### 진단과 의심 메커니즘

`저자 주장` background direction을 annotated reference에서 추정해 DINOv3의 artifact response를 제거하면 structured illumination residual이 강한 pool-boiling에서 target contrast가 살아난다.

`추론` 이 기법은 general one-shot adaptation이라기보다 **dominant background artifact가 저차원·일관적일 때 강한 specialist correction**일 수 있다. X-ray에서는 anatomy overlap과 low-contrast boundary가 단일 background direction으로 분리되지 않아 SAM2 대비 이득이 사라졌을 가능성이 있다.

### 기존 주장과 충돌

“한 장의 annotated reference로 다양한 scientific imaging domain에 적응한다”는 넓은 설명은 pool-boiling과 RBC에는 지지되지만 chest X-ray에서는 우위를 보이지 못한다. 또한 78.62% relative와 33.36%p absolute는 둘 다 계산상 가능한 표현이나, 작은 20-frame 실험에서 relative 수치만 읽으면 일반화 규모를 과대평가할 수 있다.

### 가설 → 최소 개입 → 실험

**가설:** 성능은 reference choice와 background feature rank에 민감하며, artifact가 단일 방향으로 설명되는 domain에서만 큰 이득이 난다.

**최소 개입:** 모델을 재학습하지 않고 reference image를 10개 바꿔 각 target에 대한 mIoU 분포를 구한다.

**검증 실험:**

1. reference당 foreground 크기·background covariance spectrum·target-reference similarity를 기록한다.
2. zero/one/three background directions 제거를 비교한다.
3. pool-boiling은 leave-one-sequence-out, X-ray는 환자 단위 split을 유지한다.
4. SAM2와 제안법의 per-image paired IoU 및 bootstrap 95% CI를 계산한다.

**GO:** pool-boiling 이득이 여러 reference에서 유지되고 background spectral concentration과 개선량이 연동되며, X-ray의 무이득도 사전 예측된다.  
**KILL/수정:** reference 하나를 바꾸면 순위가 뒤집히거나 20-frame 외부 sequence에서 이득이 사라지면 background adaptation을 일반법이 아니라 reference-sensitive heuristic으로 재정의한다.

**점수:** 심각도 3/5 · 재현 신뢰도 2/5 · 연구 아이디어 가치 4/5

## 4. TouchScale — 데이터 5배 확대의 tactile proxy 이득은 작고 downstream 연계는 약함

**자료:** [TouchScale 공식 원문](https://arxiv.org/html/2610.10288v1)  
**모델·데이터·구성:** 500시간 human vision-touch mid-training, robot post-training; future-tactile Top-10/MRR/NCE와 네 개 contact-rich manipulation task  
**공식 인정:** 저자들은 20%→100% scaling gain을 “modest”라고 명시하고, tactile error와 action error의 weak correlation을 보고했다. 독립 community reproduction은 확인하지 못했고 데이터·코드 공개는 논문 시점에 향후 공개로 기술됐다.

### 실패 조건과 재현 증거

`확인된 사실` future-tactile train Top-10은 mid-training 없음 0.18%에서 20% 데이터 2.87%로 올랐지만, 100% 데이터에서는 3.31%였다. 데이터 양을 5배 늘린 구간의 절대 이득은 0.44%p였다.

`확인된 사실` validation Top-10은 20%에서 2.93%, 40%에서 2.80%, 60%와 80%에서 3.13%, 100%에서 4.17%로 단조 증가하지 않았다. pooled Top-10은 20% 2.34%, 100% 2.49%였다.

`확인된 사실` held-out robot data에서 future-tactile prediction error와 action prediction error의 Pearson 상관은 mid-training model에서 `r=0.119, p=0.020`이었다. 통계적으로 검출됐지만 설명력은 작다.

`확인된 사실` 실제 로봇 네 task의 평균 성공률은 mid-training 없이 22.5%, 적용 후 57.5%로 올랐다. 각 task는 같은 50 demonstrations로 post-train하고 20 trials로 평가했다. 따라서 tactile proxy의 작은 scaling과 robot success의 큰 gain은 동시에 존재한다.

### 진단과 의심 메커니즘

`저자 주장` human visual-tactile mid-training이 future touch representation과 contact-rich control을 개선하지만, 20% 이후 tactile prediction scaling은 완만하다.

`추론` 큰 downstream gain이 future-tactile 예측 정확도 하나에서 왔다고 보기 어렵다. representation regularization, visual diversity, action prior, optimization warm-start가 함께 작동했을 수 있다. 20 trials/task에서는 success rate의 불확실성도 작지 않다.

### 기존 주장과 충돌

“더 많은 human touch data가 tactile world prediction을 통해 robot control을 계속 개선한다”는 단순 scaling 서사와 충돌한다. 20% 이후 proxy metric은 포화에 가깝고 action error와의 상관도 약하다. 다만 no-mid-training 대 yes-mid-training의 robot 결과는 분명한 개선을 보이므로, 이 부정 결과는 **TouchScale 전체 효과가 없다는 뜻이 아니라 메커니즘과 scaling attribution이 미확정**이라는 뜻이다.

### 가설 → 최소 개입 → 실험

**가설:** downstream improvement의 대부분은 초기 20% 데이터에서 얻는 broad contact representation이고, 이후 데이터는 tactile retrieval보다 rare contact coverage에 기여한다.

**최소 개입:** 0/20/100% checkpoint를 같은 robot post-training seed와 demonstration subset에 고정해 비교한다.

**검증 실험:**

1. task별 100 trials 이상 또는 sequential confidence interval로 성공률을 추정한다.
2. future-tactile accuracy, tactile embedding linear probe, action error, task success를 같은 checkpoint에서 연결한다.
3. 데이터 시간을 고정하고 contact type diversity만 바꾸는 stratified subset을 만든다.
4. mediation 분석은 탐색적으로만 사용하고, 20%→100%의 paired downstream 차이를 1차 endpoint로 둔다.

**GO:** 100%가 20%보다 rare-contact task에서 반복적으로 높고, 이 차이가 contact diversity와 연결된다.  
**KILL/수정:** 20%와 100%의 robot success 신뢰구간이 겹치고 proxy 개선도 downstream을 예측하지 못하면 규모 확대보다 data curation과 objective 교체를 우선한다.

**점수:** 심각도 3/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 4/5

## 오늘의 실패 패턴 3개

1. **인터페이스 한 줄이 알고리즘 이득을 지울 수 있다.** CoBEVFlow의 hard mask는 flow보다 먼저 context를 파괴했다.
2. **학습용 오류 분포가 실제 오류 분포와 다르면 augmentation이 독이 된다.** uniform ID swap은 현실의 근접 confusion을 반영하지 못했다.
3. **큰 headline gain은 domain·reference·proxy에 국한될 수 있다.** pool-boiling 개선은 X-ray로 이어지지 않았고, tactile proxy scaling은 robot gain의 메커니즘을 설명하지 못했다.

## 논문 아이디어로 연결 가능한 빈틈

가장 가치 있는 빈틈은 **failure-distribution-matched augmentation과 context-preserving correction을 함께 검증하는 tracking protocol**이다.

MOTIP2는 실제 IDSW의 공간 분포와 학습 corruption을 맞추는 중요성을 보였고, CoBEVFlow diagnostic은 correction을 적용할 때 원 context를 보존해야 함을 보였다. 둘을 연결하면 다음 질문이 된다.

> 해양·저조도 multi-object tracking에서 실제 association failure의 거리·가림·교체 분포를 학습 corruption에 반영하고, correction 밖의 feature context를 보존하면 ID switch를 줄이면서 detector 성능을 유지할 수 있는가?

신규성은 새 loss 이름보다 **실제 failure distribution 측정 → matched corruption → context-preserving intervention → same-location exit/entry stress test**를 하나의 검증 protocol로 묶는 데 있다.

## 직접 재현해볼 최소 실험

**1순위, 학습 없는 audit:**

1. 기존 tracker prediction에서 IDSW 직전 두 frame의 bbox distance, GIoU, occlusion gap, entry/exit flag를 수집한다.
2. uniform corruption sampler의 동일 통계를 계산해 실제 failure와 Jensen–Shannon divergence를 비교한다.
3. 기존 BEV/feature correction code가 ROI 밖 값을 0으로 만드는지 unit test한다.
4. segmentation one-shot pipeline은 reference 10개만 바꿔 per-image IoU 분산을 기록한다.

**2순위, 작은 개입 실험:**

- tracking은 한 checkpoint에서 `N_init=1,2,3`과 appearance gate만 inference sweep한다.
- collaborative perception은 같은 checkpoint의 hard mask / background-preserving blend / identity warp만 비교한다.
- tactile pipeline은 20%와 100% checkpoint에 같은 robot demonstration subset을 사용한다.

**GO:** matched corruption과 context-preserving blend가 서로 다른 두 split에서 같은 방향의 개선을 보이고, same-location 교체·moving-object subset에서도 실패율이 감소한다.  
**KILL/수정:** 개선이 evaluator revision이나 특정 reference/seed에만 남으면 모델 논문보다 evaluation artifact 보고로 범위를 줄인다.
