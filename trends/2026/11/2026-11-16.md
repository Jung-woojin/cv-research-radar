# 격주 CV·딥러닝 트렌드 맵 — 2026년 11월 16일

분석 기간: 2026년 11월 2~16일 오전(KST) · 비교 기간: 10월 19일~11월 2일 · 근거: arXiv 원문, NeurIPS 2026 채택 논문, 공식 챌린지 보고서 및 공개 코드.

## 1. 이번 2주를 한 문장으로 요약

**Computer Vision은 더 큰 foundation model에 모든 문제를 맡기는 방향보다, 시각적 증거의 위치·품질·정보 손실을 진단하고, foundation model의 지식을 작은 전문 모델·검증 가능한 중간 표현·효율적인 추론 시스템으로 전달하는 방향으로 구체화되고 있다.**

지난 격주 보고서가 객체 정체성, 장기 기억, 동적 계산 예산을 강조했다면, 이번에는 모델이 무엇을 실제로 보았는지, 정답이 영상 증거에 의존하는지, 미지 클래스 정보가 어디서 사라지는지, 작은 모델이 얼마나 다양한 작업을 처리할 수 있는지가 부상했다. 2주치 논문 기반의 정성적 해석이며 확정된 전체 분야 전환은 아니다.

## 2–3. 핵심 트렌드 8개와 대표 근거

### T1. Visual evidence 중심의 VLM 평가 — 강한 상승

**[사실]** [Where and Why is Grounded Reasoning Useful?](https://arxiv.org/abs/2611.08485)(11/5)는 좌표 출력 기반 grounding이 counting에 도움이 되지만 다수 공간추론·지각 벤치마크에서 비grounded baseline보다 유의미하게 낫지 않다고 보고한다. 언어로 고유하게 지칭하기 어려운 시각 대상에 특히 효과가 크며 BrickVision을 제안했다.

[ZoomGain: Mining Global-to-Zoom Perception Gaps for Fine-Grained Visual Supervision](https://arxiv.org/abs/2611.14076)(11/10)는 전체 이미지에서는 어렵지만 확대된 영역에서 인식 가능한 증거를 이용해 데이터셋을 구성했다. 1,000문항 ZoomGainBench에서 28개 VLM 중 최고 61.08점, 약 9천 개 학습 샘플로 4B/9B 모델의 세밀한 지각 개선을 저자 보고했다.

[Visual Cipher Bench: Benchmarking LLM Agents on Long-Horizon Visual Reasoning](https://arxiv.org/abs/2611.16861)(11/12)는 40개 시각 퍼즐에서 최고 구성이 26.7% 정확도였고, 일부 문제의 비정답형 규칙 힌트가 큰 도움이 됐다고 보고했다.

**[해석]** Grounded CoT를 길게 출력하는 것보다 실제 시각 증거를 찾고 다시 접근하고 규칙을 발견했는지를 별도로 평가하는 것이 중요해진다.

### T2. OVD의 novel-class 표현 보존과 자동 라벨링 — 상승

**[사실]** [Partition, Refine, and Detect: Preserving Novel Category Capacity in Open-Vocabulary Object Detection](https://arxiv.org/abs/2611.12976)(11/8, PR-OVD)는 CLIP 기반 표현의 base-class 편향과 novel semantic collapse를 다룬다. Base/novel/background partition과 refinement로 두 OVD 벤치마크에서 novel category 평균 상대 개선 6.5%를 보고했다.

[Annotator-Free Object Detection via Foundation Model Collaboration](https://arxiv.org/abs/2611.06195)(11/4)는 segmentation FM과 VLM을 통해 타깃 데이터의 사람 주석 없이 pseudo-label을 만들고 lightweight detector를 반복 학습한다. 저자 보고 COCO 60.8 AP, LVIS 47.4 AP이지만 대형 teacher의 선행학습·API 비용·오류 증폭 가능성을 감안해야 한다.

**[해석]** 지난 보고서의 FocusOVD가 작은 RoI의 시각 표현을 다뤘다면 이번 PR-OVD는 base와 novel의 구분 용량을 직접 다룬다. OVD negative transfer의 서로 다른 병목이다.

### T3. Vision encoder 내부 표현을 직접 해부 — 상승

**[사실]** [Shape-based Figure-Ground Organization in Vision Transformers](https://arxiv.org/abs/2607.08932)(11/9 v2, NeurIPS 2026)는 25개 ViT를 비교했다. 중간 레이어의 figure-ground 정보와 texture replacement에 대한 일부 shape cue robustness를 보였다.

[Training Vision Transformers to Focus: Emergence of Spatial Attention Head Specialization](https://arxiv.org/abs/2611.11890)(11/9)는 focusing loss로 head별 공간적 선택성을 강화하고 zero-shot segmentation의 개선을 보고했다.

**[해석]** Image-level accuracy보다 어느 레이어·헤드에 어떤 정보가 존재하고 최종 readout이 무엇을 사용하는지 진단하는 연구가 중요하다. Probe와 attention은 인과적 사용의 충분한 증거가 아니므로 intervention이 필요하다.

### T4. Small model의 다중 CV 작업 통합 — 강한 상승

**[사실]** [Report of the 8th LSVOS Challenge: Mobile Unified Multimodal Understanding](https://arxiv.org/abs/2611.16925)(11/12)는 ECCV 2026 연계 MUMU 챌린지를 정리한다. Image tagging, OVD, image captioning을 한 모델로 수행하면서 **0.5B parameters / 8GB peak memory** 예산을 요구한다. 상위 3팀은 모두 Florence-2-base에서 lightweight head, LoRA, task decoding, training-free 변형을 사용했다. 저자들은 novel OVD가 주요 병목이라고 평가했다.

**[해석]** 더 큰 VLM만 추구하지 않고 작은 shared backbone + 특화 readout + 비용 제한을 공식 benchmark 목표로 삼은 점이 중요하다. 8GB 제한이 특정 Jetson에서 실시간 동작을 보증하지는 않는다.

### T5. CNN·ViT·SSM 경쟁에서 역할별 설계 — 유지·정교화

**[사실]** [LiSA: Linear Stochastic Attention for Long-Range Visual Modeling](https://arxiv.org/abs/2611.04216)(11/3, v2 11/4)은 선형 attention에 확률적 diffusion 방식의 고차 token interaction을 결합해 classification/detection/segmentation 결과 개선을 보고한다.

IEEE Signal Processing Letters의 11월 논문 [Enhancing Real-Time Semantic Segmentation With Routing Attention and Boundary-Guided Fusion](https://signalprocessingsociety.org/publications-resources/ieee-signal-processing-letters/2026/11/enhancing-real-time-semantic-segmentation-routing-attention-and-boundary-guided-fusion)(RBNet)은 CNN의 고해상도 공간 정보와 Transformer의 문맥 정보를 boundary alignment로 연결한다. 기간 직전 10/30 공개된 [PAM-Mamba](https://arxiv.org/abs/2611.00423)는 temporal action detection의 Mamba 기반 선형시간 처리와 비교 모델 대비 61~63% 낮은 파라미터 수를 보고했다.

**[해석]** CNN의 지역 구조, ViT의 global interaction, SSM의 장기 순서 정보 중 무엇이 필요한가가 중요하며 특정 계열의 전면적 승리는 입증되지 않았다.

### T6. Video understanding: 객체 의미·identity·구조적 상태 — 상승

**[사실]** [Exploiting Textual Semantics for Robust Cross-View Object Correspondence](https://arxiv.org/abs/2611.02356)(11/2, NeurIPS 2026)는 시점 변경 환경에서 객체의 텍스트 속성으로 visual feature를 보강하고 search-view에 맞게 반복 보정한다. Ego-Exo4D, HANDAL-X를 평가했다.

[SpaceMCP: Vision Language Model Spatial Reasoning via Model Context Protocol](https://arxiv.org/abs/2611.15680)(11/11)는 외부 3D 복원과 scene graph를 구성하고 VLM이 위치·거리 등을 질의한다. VSI-Bench 등의 저자 보고 base 대비 15~22점 향상은 외부 구조화 도구를 포함한 시스템 성능이지 VLM 단독 능력은 아니다.

**[해석]** 지난 기간의 temporal identity/memory 연구가 cross-view appearance와 질의 가능한 scene state로 확장됐다.

### T7. Maritime·remote sensing: domain-shift 진단과 semantic preservation — 상승 신호

**[사실]** [Video Object Segmentation under Aquatic Domain Shift: A Diagnostic Benchmark and Restoration Adapter](https://arxiv.org/abs/2603.24006)(11/7 v2)는 UW-VOS(1,431 video, 307,267 mask, 411 classes, 16 attributes)를 구축하고 기존 VOS의 평균 J&F 13점 하락을 보고했다. Aquatic Restoration Adapter로 효율적인 feature restoration을 비교한다.

[Bridging Low-Level Image Fusion and High-Level Semantic Understanding](https://arxiv.org/abs/2611.02896)(11/2, LANCE)는 remote-sensing 이미지 융합의 reconstruction fidelity와 downstream semantic utility가 다를 수 있다고 분석한다. 별도 aerial detector 평가에서 +6.4 mAP라는 저자 보고 결과가 있다.

**[해석]** 복원된 영상이 더 보기 좋아도 task-relevant information은 손상될 수 있다. 수중 optical degradation과 해무 대기영상은 동일한 domain이 아니므로 직접 일반화하지 않는다.

### T8. Efficiency: 파라미터 외 adaptation·frame selection·system cost — 상승

**[사실]** [On the Few-Shot Adaptation of Vision-Language Models: A Few Gradient Signs Are All You Need](https://arxiv.org/abs/2611.08800)(11/5)는 noisy few-shot gradient의 일부 방향 정보만 활용하는 SignSparseSGD를 제안한다. 11 datasets, 3 CLIP backbones, 5 shot levels에서 기존 baseline과 경쟁력 있는 성능을 보고했으며 코드는 부록에 포함됐지만 저장소 공개는 출판 후를 예고했다.

[Budget-aware Correspondence-driven View Selection for Real-time 3D Perception of Mobile Robots](https://arxiv.org/abs/2611.11809)(11/9)는 CPU에서 22+ FPS를 보고하는 view filtering으로, aerial/marine robotics field trial에서 최대 16% redundancy 감소를 보였다.

**[해석]** Update할 gradient, 관찰할 frame, 처리할 token 및 여러 task를 공유하는 비용을 포함해 효율을 정의하는 방향이 강화된다. FLOPs만으로 latency·energy를 평가하면 안 된다.

## 6. Architecture·학습·추론

**Architecture:** shared visual encoder → task-specific spatial refinement / semantic partition → selective readout → optional tracker or scene graph. Dense prediction은 경계와 고해상도, OVD는 novel 표현 용량, Video VLM은 identity/state 유지가 중요하다.

**Training:** full FT에 대한 대안으로 sparse gradient update, partition/refinement, teacher-based pseudo-label을 실험한다. 사전학습 표현의 파괴/보존과 classifier readout 문제를 별도 확인해야 한다.

**Inference:** full-resolution/full-frame에서 selective zoom, budgeted sampling, structured visual evidence recheck로 관심이 이동한다. End-to-end latency, memory, energy, selection overhead와 FN 비용을 함께 측정해야 한다.

## 7. 반복되는 미해결 문제

1. 올바른 VLM 답변이 실제 시각 증거에 의존했는지 불분명하다.
2. OVD novel AP 하락이 feature forgetting, 작은 RoI의 정보 부족, head calibration 중 어디서 발생하는지 분리되지 않는다.
3. Tiny object는 encoder에 증거 자체가 들어오지 않을 수 있다.
4. Linear probe나 attention map은 모델이 그 정보를 의사결정에 인과적으로 사용했다는 증명이 아니다.
5. 장기 영상에서는 occlusion, viewpoint shift, re-entry에서 identity가 변질된다.
6. 자동 pseudo-label의 오류가 반복 학습으로 고착될 수 있다.
7. Domain adaptation의 성능 개선과 source retention은 상충할 수 있다.
8. FLOPs/parameter 감소는 Jetson 등의 실제 지연·에너지 개선과 다르다.

## 8. 앞으로 1~3개월의 전망 [추론]

- Evidence-aware supervision과 grounding utility를 구분하는 평가 증가.
- Novel class capacity를 보존하는 OVD adaptation/calibration.
- Shared compact multimodal specialists 및 다중 작업 평가.
- Feature-level domain adaptation과 semantic preservation.
- Tiny-object recall을 보존하는 zoom/query/frame budgeting.
- Representation과 head의 information-use diagnosis.

이것들은 채택과 성공이 확정된 사실이 아니라 이번 관찰을 바탕으로 한 연구적 전망이다.

## 9. Hype 검증 포인트

- 좌표 grounded CoT를 넣으면 항상 좋아진다 → 과제별로 효과가 다르며 BrickVision은 필요한 조건을 좁힌다.
- 더 큰 VLM이 tiny object도 추론만으로 해결한다 → ZoomGain은 evidence access bottleneck을 보여준다.
- 자동 annotation은 supervision이 필요 없다는 뜻이다 → 사람 타깃 주석을 생략할 뿐 강한 pretrained teachers와 pseudo-label에 의존한다.
- CNN/SSM hybrid라 실시간이다 → hardware 실제 latency를 보고해야 한다.
- 0.5B로 다중 CV 작업을 해결했다 → MUMU에서 novel OVD는 지속적인 병목이다.

## 10. 사용자 연구와 연결되는 연구 기회 다섯 개

**A. OVD negative transfer: representation vs readout diagnosis** (4–6주 MVP)
- 문제: novel AP 하락이 encoder 정보 소실인지, region aggregation/head suppression인지 불분명.
- 가설: oracle crop + frozen probe/prototype를 통해 일부 novel 성능을 회복할 수 있다.
- 비교: pre/post adaptation feature, oracle crop, linear probe, prototype, original head.
- 지표: base/novel/small novel AP, CKA, prototype margin, calibration. 실패해도 손실 단계 식별이 기여.

**B. 해무 3-class Global-to-Zoom Perception Gap** (2–4주 MVP)
- normal / lowvis / seafog 분류에서 전체 CCTV와 수평선·해면·원거리 물체 crop의 entropy/macro F1을 비교.
- 가설: 전역 장면의 무관한 정보가 시정 증거를 희석할 수 있다.
- 비교: global-only, crop-only, multi-crop, selective zoom, CNN vs ViT.
- 항만×월별 split 동일 고정. Test label 정보로 crop을 선정하지 않는다.

**C. Maritime Semantic-Preserving Adaptation** (4–8주 MVP)
- 해무/저시정 복원 후 PSNR/SSIM 상승이 detector/classifier 성능 상승을 보장하는지 검사.
- 비교: no restoration, classical enhancement, learned restoration, feature adapter.
- 지표: macro F1, worst-port/month F1, source retention, CKA, confidence calibration.
- 수중 UW-VOS는 문제 정의 참고이지 직접 동일 데이터라고 취급하지 않는다.

**D. Tiny UAV Detection의 Evidence-Aware Zoom Policy** (4–6주 MVP)
- fixed tiling vs confidence crop vs scale-aware crop vs oracle zoom.
- 가설: uncertainty-only selection이 낮은 confidence의 진짜 tiny object를 건너뛸 수 있다.
- 지표: AP_tiny, recall_tiny, high-risk FN, latency, peak VRAM. Crop selection 실패 분석 자체를 contribution으로 구성한다.

**E. 0.5B급 Unified Maritime Vision Specialist** (6–8주 pilot)
- Florence-2-base 계열 backbone 위에 tagging/detection/captioning을 통합한다.
- 지표: per-task quality, novel-object recall, peak memory, task latency, edge latency.
- 0.5B/8GB 제약은 실시간 Jetson 추론의 검증을 대신하지 않는다.

**실행 우선순위:** A(OVD representation/readout diagnosis), B(해무 zoom gap). 기존 모델 및 split을 재사용해 구조 설계보다 먼저 핵심 가설을 확인할 수 있다.

## 12. 텍스트 기반 트렌드 맵

**축 A — Closed-set → Evidence-grounded VLM**

    Closed-set detection
      → Open-vocabulary detection (PR-OVD)
        → Grounding / visual reasoning
          → Evidence verification (BrickVision / ZoomGain)

**축 B — Large FM → Efficient / Specialized**

    Large pretrained encoder
      → Frozen/Selective adaptation
        → Shared compact backbone (MUMU)
          → Task-specific readout
            → Real edge cost

**축 C — ViT 중심 → 역할별 CNN/SSM/hybrid 재평가**

    CNN local geometry
      + ViT semantic/global interaction
      + SSM temporal efficiency
      → Selective hybrid design (LiSA / RBNet / PAM-Mamba)

**축 D — Accuracy → Diagnosis**

    Final accuracy
      → Evidence access
        → Representation quality
          → Readout / calibration
            → Domain robustness
              → Deployment efficiency

## 결론 및 근거 판정
