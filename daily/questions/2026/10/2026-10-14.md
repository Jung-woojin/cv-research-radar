## Q1. “Shortcut budget”이 미지 재난 성능 하락을 사전에 예측할 수 있는가?

**직접 근거:** [GFM Shortcut Learning](https://arxiv.org/abs/2610.13766) · [공식 코드](https://github.com/alishibli97/gfm-shortcut-learning) · [Building Damage Assessment 재정의](https://arxiv.org/abs/2610.13857)

### 1. 문제 정의

재난 피해 분류기의 전체 입력 성능에서 `pre-only`, `building-count-only`, `shuffled-pair`, `event-prior-only` 성능을 뺀 차이를 shortcut budget으로 정의하고, 이 값이 leave-one-event-out(LOEO) 하락을 예측하는지 검증한다.

### 2. 왜 지금 가치가 있는가

xView2 balanced accuracy는 random split `0.807`에서 LOEO `0.638`, BRIGHT는 `0.818→0.568`로 하락했다. 새 BDA review도 단일 aggregate score의 취약성과 unseen event/region 일반화를 핵심 미해결 문제로 지목한다. 모델을 모두 재학습하기 전에 위험한 benchmark 설정을 선별할 저비용 지표가 필요하다.

### 3. Observation과 Gap

- **확인된 사실:** 건물 수만으로 xView2 `0.629`, BRIGHT `0.653` balanced accuracy를 얻었다.
- **확인된 사실:** BRIGHT pre-only `0.571`이 full pair `0.568`보다 높았다.
- **저자 주장:** 사건·취득 문맥과 건물 밀도가 피해 신호보다 쉬운 shortcut이다.
- **Gap:** 여러 event와 backbone에 걸쳐 대조군 성능이 실제 LOEO 하락량을 예측하는지는 미확인이다.

### 4. 핵심 가설

대조군 중 최댓값이 full-input 점수에 가까울수록 LOEO 하락이 크다. 특히 `full − max(shortcut controls)`가 작은 모델은 표현 변환을 적용해도 미지 사건 일반화가 제한된다.

### 5. 최소 실험(MVP)

공식 코드의 xView2·BRIGHT 매니페스트에서 두 GFM만 선택하고, 사건별 random/LOEO 및 네 shortcut control을 동일 선형 분류기로 평가한다. event 단위 30개 안팎의 관측점에서 shortcut budget과 LOEO drop의 Spearman 상관을 계산한다.

- **GO:** bootstrap 95% CI 하한이 `ρ>0.3`이고 두 dataset에서 방향이 일치.
- **KILL:** 상관 부호가 dataset별로 바뀌거나 event class imbalance 통제 후 `|ρ|<0.2`.

### 6. baseline과 dataset

xView2, BRIGHT, raw embedding, PCA, SupCon. random split accuracy만 쓰는 기존 선택 기준과 event-prior/building-count 대조군을 포함한 선택 기준을 비교한다.

### 7. 성공·실패 판정 metric

Balanced accuracy, AUC, per-event LOEO drop, shortcut budget, bootstrap CI, Spearman ρ, calibration error, worst-event accuracy.

### 8. compute 난이도

**2.5/5.** 공개 임베딩을 재사용하면 선형 모델 중심이다. 임베딩을 직접 추출할 경우 DINOv3·GFM checkpoint별 VRAM은 별도 확인한다.

### 9. novelty 위험요인

Shortcut control 자체는 알려진 감사 기법이다. novelty는 여러 대조군을 **사전 위험 예측량**으로 묶고, BDA challenge 모델 선택과 연결하는 데 있다.

### 10. 4~8주 논문화 가능성

2주 내 두 dataset audit, 4주 내 event-level predictor와 confidence interval, 6~8주 내 다른 지역·센서 또는 해상 재난 영상으로 외부 검증이 가능하다.

### 11. negative result의 가치

상관이 없다면 shortcut 대조군은 설명 도구일 뿐 성능 예측 도구가 아니라는 경계를 제시한다. 이 경우 split 설계와 private event test가 유일하게 신뢰할 수 있는 검증이라는 결론이 남는다.

**평가:** Novelty 4.5/5 · Feasibility 4.5/5 · Compute efficiency 4.5/5 · Publication potential 5/5

## Q2. 중간 표현의 motion 정보를 작은 readout만으로 언어 출력에 안정적으로 결속할 수 있는가?

**직접 근거:** [Mind the Temporal Gap](https://arxiv.org/abs/2610.12575)

### 1. 문제 정의

비디오 VLM의 vision encoder·projector 표현에 motion direction이 존재하지만 최종 답변은 한 방향으로 붕괴할 때, 전체 LoRA 대신 direction-consistency readout 또는 작은 projector adapter만으로 출력 결속을 복원할 수 있는지 묻는다.

### 2. 왜 지금 가치가 있는가

여섯 모델이 표준 prompting에서 모두 `forward 100% / backward 0%`를 보였다. 논문은 간단한 probe와 LoRA가 강한 motion-discriminative 성능을 회복한다고 보고해, perception 부재보다 readout 실패라는 더 좁은 진단을 가능하게 한다.

### 3. Observation과 Gap

- **확인된 사실:** Qwen2-VL과 Qwen2.5-VL도 `left 100% / right 0%`로 붕괴했다.
- **확인된 사실:** LoRA는 400개 action-pair 비디오의 80/20 분할, rank 16, 3 epoch에서 매우 높은 source-task 성능을 보였다.
- **저자 주장:** motion cue는 중간 표현에 있으나 최종 video-to-language 경로가 안정적으로 사용하지 못한다.
- **Gap:** 작은 adapter의 개선이 역재생·frame shuffle·실영상에서 실제 시간 단서 사용으로 이어지는지는 미확인이다.

### 4. 핵심 가설

인접 프레임 feature difference에 부호화된 2D direction vector를 보조 목표로 학습하면, 언어 prior를 덜 건드리면서 class recall 균형과 역재생 일관성을 회복한다.

### 5. 최소 실험(MVP)

한 개 open video VLM을 고정하고 `linear probe`, `answer-head adapter`, `feature-difference adapter`, `LoRA`를 비교한다. 학습 320개, 검증·테스트 80개 수준으로 시작하고 정방향·역재생·셔플 입력을 함께 평가한다.

- **GO:** 최소 class recall `≥70%`, 역재생 답 반전율 `≥80%`, 일반 VideoQA 하락 `≤1%p`.
- **KILL:** source accuracy만 오르고 역재생 반전율이 `≤55%`이거나 셔플 영상에서도 정답률이 유지.

### 6. baseline과 dataset

논문의 CARLA 6-class protocol, 60개 실영상, zero/few-shot, linear probe, rank-16 LoRA. 가능하면 synthetic-to-real holdout을 고정한다.

### 7. 성공·실패 판정 metric

Class별 recall, macro accuracy, minimum recall, reversal consistency, shuffle sensitivity, ECE, VideoQA retention, trainable parameter 수.

### 8. compute 난이도

**3/5.** frozen feature와 작은 adapter는 8GB에서 가능할 수 있으나, 선택 VLM의 프레임 수·양자화 조건을 먼저 측정해야 한다.

### 9. novelty 위험요인

방향 보조 loss 자체는 단순할 수 있다. novelty는 **표현 존재–언어 사용 간 결속 실패**를 counterfactual consistency로 직접 검증하는 데 있다.

### 10. 4~8주 논문화 가능성

2주에 class collapse 재현, 4주에 adapter 비교, 6주에 synthetic-to-real과 역재생 평가, 8주에 다른 motion primitive로 확장 가능하다.

### 11. negative result의 가치

작은 readout이 실패하면 cue가 선형적으로 존재한다는 사실만으로 생성 경로에서 사용 가능하다고 볼 수 없다는 증거가 된다. 이때 temporal tokenization이나 projector 구조가 우선 연구 대상이다.

**평가:** Novelty 4.5/5 · Feasibility 4/5 · Compute efficiency 4/5 · Publication potential 4.5/5

## Q3. 입력별 scale/frequency router가 Squint Text를 읽으면서 일반 OCR 퇴화를 막을 수 있는가?

**직접 근거:** [SquintBench](https://arxiv.org/abs/2610.13465)

### 1. 문제 정의

모든 이미지에 고정 축소나 저역통과를 적용하지 않고, 원본·축소·low-pass view 중 필요한 경로만 선택하는 router가 숨은 텍스트 인식과 일반 OCR을 동시에 보존하는지 검증한다.

### 2. 왜 지금 가치가 있는가

Qwen3.5-9B base는 원본에서 ANLS `26.50`, `1/8` 추가 view에서 `58.96`, OPSD에서 `88.61`을 기록했다. 반면 특화 후 AI2D, DocVQA, OCRBench가 하락해 성능 회복과 범용성 사이의 trade-off가 남는다.

### 3. Observation과 Gap

- **확인된 사실:** 저역통과는 같은 token budget에서도 성능을 높였다.
- **확인된 사실:** 올바른 spatial region을 제공하면 glyph identity 접근성이 증가했다.
- **확인된 사실:** OPSD 후 DocVQA `95.93→92.98`, OCRBench `879→833`.
- **Gap:** 별도 fine-tuning 없이 어떤 입력에 어떤 view를 쓸지 결정하는 저비용 기준이 없다.

### 4. 핵심 가설

고주파 에너지 비율, OCR confidence, multi-scale prediction disagreement 세 신호만으로도 특화 모델 없이 어려운 입력을 선별할 수 있다. 선택된 사례에만 축소 view를 추가하면 일반 OCR 손실과 token 비용을 억제한다.

### 5. 최소 실험(MVP)

SquintCtrl 200개와 일반 OCR 200개에서 `always-original`, `always-downscale`, `two-view`, `handcrafted router`, `small learned router`를 비교한다.

- **GO:** Squint ANLS가 original 대비 `≥15`점 상승하고 일반 OCR 하락 `≤2`점, 평균 visual token 증가 `≤40%`.
- **KILL:** router AUC `<0.7`이거나 항상 two-view 대비 비용 절감이 `10%` 미만.

### 6. baseline과 dataset

SquintCtrl 공개 가능 부분, TextVQA/DocVQA 또는 OCRBench subset, 동일 frozen MLLM. 입력 변환 외 prompt와 decoding을 고정한다.

### 7. 성공·실패 판정 metric

ANLS, exact match, no-text false negative, router AUROC, 일반 OCR delta, token 수, latency, calibration.

### 8. compute 난이도

**2/5.** frozen inference와 작은 router가 중심이다. 7B~9B 모델 양자화 실행 가능성은 로컬에서 먼저 확인한다.

### 9. novelty 위험요인

단순 image preprocessing selector로 보일 수 있다. 주파수·공간 readout 진단과 token-budget 최적화를 함께 정식화해야 기여가 선명해진다.

### 10. 4~8주 논문화 가능성

2주에 feature audit, 4주에 router, 6주에 일반 OCR guardrail, 8주에 해양 표지·계기판의 cross-domain 검증이 가능하다.

### 11. negative result의 가치

간단한 router가 실패하면 Squint Text는 입력 통계만으로 사전 식별하기 어렵고, encoder 내부 spatial selection을 직접 학습해야 한다는 결론이 남는다.

**평가:** Novelty 4/5 · Feasibility 4.5/5 · Compute efficiency 4.5/5 · Publication potential 4.5/5

## Q4. specimen·촬영 세션·배경을 순차 분리하면 “객체 자체”의 일반화 성능을 얼마나 남길 수 있는가?

**직접 근거:** [WoodBR-Cross](https://arxiv.org/abs/2610.12676)

### 1. 문제 정의

이미지 random split, specimen-disjoint, acquisition-session-disjoint를 계층적으로 적용하고 center/border/background-only 입력을 결합해 모델이 객체 고유 신호와 촬영 문맥 중 무엇을 쓰는지 정량화한다.

### 2. 왜 지금 가치가 있는가

ConvNeXt-Tiny macro-F1은 B1 image split `0.9736`에서 B2 tree-disjoint `0.7979`로 낮아졌다. border-only도 tree-level `0.8428`을 기록해 객체가 아닌 주변 신호가 높은 성능을 만들 가능성이 있다.

### 3. Observation과 Gap

- **확인된 사실:** WoodBR-Cross는 4,875장·303개 나무와 명시적 tree ID를 제공한다.
- **확인된 사실:** frozen DINOv2의 B2 tree-level macro-F1은 `0.9000±0.0722`.
- **주의:** B1과 B2는 구성이 완전히 같지 않아 격차를 순수 누수 효과로 해석할 수 없다.
- **Gap:** tree ID를 넘어 촬영일·장비·배경까지 분리했을 때 남는 성능과 원인별 error budget이 없다.

### 4. 핵심 가설

specimen split이 가장 큰 하락을 만들고, border/background 대조군 점수는 acquisition-session split에서 급락한다. center-only 성능은 더 낮지만 외부 수집에 더 안정적일 것이다.

### 5. 최소 실험(MVP)

20종 subset에서 기존 tree ID를 사용하고, EXIF 또는 파일 계보로 session proxy를 만든다. 동일 frozen DINOv2 + linear classifier에 세 split과 네 입력 마스크를 적용한다.

- **GO:** session-disjoint에서 center-only가 border-only보다 macro-F1 `≥0.10` 우세하고 외부 fold의 variance도 작음.
- **KILL:** center/border 차이가 CI 내에 있거나 session proxy가 label과 완전히 결합되어 분리 불가능.

### 6. baseline과 dataset

WoodBR-Cross B1/B2, ResNet-50 또는 ConvNeXt-Tiny 1개, frozen DINOv2, random-label control. 해상 확장 시 선박 ID·카메라 ID·항만 ID를 그룹으로 사용한다.

### 7. 성공·실패 판정 metric

Image/tree macro-F1, worst-group F1, fold variance, center-border gap, session leakage classifier accuracy, external split calibration.

### 8. compute 난이도

**1.5/5.** frozen features와 split 재구성이 중심이다.

### 9. novelty 위험요인

Group split과 background-only control은 알려진 방법이다. novelty는 **계층적 그룹 분리 × 입력 영역 대조군**으로 shortcut 손실을 단계별 분해하는 데 있다.

### 10. 4~8주 논문화 가능성

2주에 split과 metadata 감사, 4주에 frozen-feature 결과, 6~8주에 해상 또는 다른 fine-grained dataset 전이가 가능하다.

### 11. negative result의 가치

session split이 추가 하락을 만들지 않으면 tree-disjoint만으로도 현 수집 문맥을 충분히 차단한다는 실용적 결론을 준다.

**평가:** Novelty 4/5 · Feasibility 5/5 · Compute efficiency 5/5 · Publication potential 4/5

## Q5. segmentation 누락을 포함한 positive-unlabeled cascade가 극희소 객체의 end-to-end recall을 높이는가?

**직접 근거:** [Rare Dead-Cell Detection](https://arxiv.org/abs/2610.13780) · [SADL](https://arxiv.org/abs/2610.13422)

### 1. 문제 정의

segmentation mask와 연결되지 않은 양성, 미주석 객체를 모두 정상으로 간주하는 문제, 고정 threshold의 small-object 누락을 하나의 cascade에서 다룬다. 분류기 F1이 아니라 원본 이미지의 실제 양성부터 최종 알림까지 end-to-end recall을 측정한다.

### 2. 왜 지금 가치가 있는가

사멸 세포 330개 라벨 중 87개가 Cellpose mask와 연결되지 않았고, 매핑된 양성은 65,527개 세포 중 243개뿐이다. 최선 ResNet-18도 F1 `0.617`이었다. SADL은 small-lesion에서 고정 threshold가 버린 사례를 size-aware threshold와 never-empty rescue로 회복했다.

### 3. Observation과 Gap

- **확인된 사실:** Deep SVDD는 여러 설정에서 F1 `0` 또는 근사 `0`이었다.
- **확인된 사실:** rare dead-cell 연구의 테스트 양성은 53개다.
- **확인된 사실:** SADL은 site-disjoint holdout에서 Dice `0.7322`, lesion-F1 `0.7461`, PR-AUC `0.8430`을 보고했다.
- **Gap:** upstream missing instance와 uncertain negative를 포함한 end-to-end 평가·학습은 두 연구 모두 완전하게 다루지 않는다.

### 4. 핵심 가설

`high-recall proposal → positive-unlabeled classifier → size/confidence-adaptive decision → expert review` cascade는 고정 segmentation+binary classifier보다 전체 recall을 높이면서 검토량을 제한한다.

### 5. 최소 실험(MVP)

테스트 양성을 `matched / merged / missing mask`로 감사하고, Cellpose threshold 2개와 permissive proposal을 만든다. reliable positive와 unlabeled를 사용한 PU baseline, 표준 classifier, size-adaptive threshold를 비교한다.

- **GO:** end-to-end recall `≥0.70`, expert review 대상 `≤5%`, 양성 precision `≥0.90`.
- **KILL:** permissive proposal이 missing positive의 절반도 회복하지 못하거나 검토량이 `>15%`.

### 6. baseline과 dataset

공식 dead-cell 데이터·코드가 실제 접근 가능한 범위, Cellpose, ResNet-18, XGBoost, nnPU 또는 non-negative PU, fixed/adaptive threshold. 코드 저장소 실행 가능 상태는 아직 검증되지 않았다.

### 7. 성공·실패 판정 metric

Proposal recall, end-to-end recall/precision/F1, PR-AUC, review burden, false alarms per image, size bucket recall, annotation disagreement.

### 8. compute 난이도

**2/5.** 작은 crop classifier와 threshold audit 중심이며 대형 모델이 필요 없다.

### 9. novelty 위험요인

PU learning과 cascade는 성숙한 기술이다. novelty는 segmentation-label 연결 실패를 평가 분모에 포함하고 human-in-the-loop 비용까지 함께 최적화하는 데 있다.

### 10. 4~8주 논문화 가능성

2주에 label lineage audit, 4주에 proposal/PU baseline, 6주에 adaptive decision, 8주에 희귀 해양 결함 또는 plankton dataset으로 전이 가능하다.

### 11. negative result의 가치

PU 학습이 개선하지 못하면 병목은 label noise가 아니라 optical ambiguity·segmentation 자체라는 근거가 되고, 추가 annotation보다 imaging protocol 개선을 우선할 수 있다.

**평가:** Novelty 4.5/5 · Feasibility 4/5 · Compute efficiency 4.5/5 · Publication potential 4.5/5

## Q6. 전역 OOD 점수보다 “가장 닮은 known class 주변의 국소 unknown 경계”가 해상 open-world 인식에 유리한가?

**직접 근거:** [CUBE](https://arxiv.org/abs/2610.13610)

### 1. 문제 정의

미등록 선박·부표·해양 생물을 하나의 전역 unknown 분포로 보지 않고, 가장 가까운 known class마다 별도 rejection boundary를 학습한다. 위치·항로 metadata를 추가했을 때 실제 시각 증거를 강화하는지, metadata shortcut을 만드는지도 함께 평가한다.

### 2. 왜 지금 가치가 있는가

CUBE는 시각적으로 가까운 unknown insect가 전역 이상치가 아니라 특정 known class 경계에 놓인다고 보고했다. Open-Insect C-America에서 local unknown AUROC `95.8%`, closed-set accuracy `94.9%`를 보고했고 ecological metadata를 추가한 CUBE-E는 local unknown AUROC `96.0%`였다.

### 3. Observation과 Gap

- **확인된 사실:** non-local/non-moth unknown AUROC는 local unknown보다 훨씬 높아, 시각적으로 가까운 unknown이 더 어려운 조건이다.
- **저자 주장:** class-conditioned boundary와 taxonomic candidate calibration이 global rejection보다 적합하다.
- **확인된 사실:** location consistency는 backbone을 바꾸지 않는 경량 항으로 추가됐다.
- **Gap:** 항만·카메라·계절이 바뀌는 환경에서 metadata가 도움이 되는지, known-class prior shortcut이 되는지는 미확인이다.

### 4. 핵심 가설

fine-grained 해상 객체에서도 class-local boundary가 global energy/Mahalanobis보다 near-unknown 검출을 개선한다. 그러나 위치 metadata의 이득은 geography-disjoint split에서 줄거나 역전될 수 있다.

### 5. 최소 실험(MVP)

공개 선박 또는 해양 생물 dataset에서 known 10종, visually close unknown 5종, far unknown 5종을 구성한다. frozen encoder에 global OOD, nearest-class Mahalanobis, class-conditioned evidence를 비교하고 카메라·지역 metadata를 on/off한다.

- **GO:** near-unknown AUROC `+5%p` 이상, closed-set accuracy 하락 `≤2%p`, geography-disjoint에서도 개선 방향 유지.
- **KILL:** 이득이 far unknown에만 나타나거나 metadata 제거 시 전부 사라짐.

### 6. baseline과 dataset

Open-Insect protocol 재현 가능 범위, ShipRSImageNet/FGSC-23 또는 공개 해양 생물 분류 자료, MSP, energy score, Mahalanobis, OpenMax, CUBE-style local boundary.

### 7. 성공·실패 판정 metric

Near/far unknown AUROC, AUPR, FPR95, OSCR, closed-set accuracy, geography worst-group, metadata swap sensitivity.

### 8. compute 난이도

**3/5.** frozen encoder 실험은 가볍지만 auxiliary unknown과 해상 fine-grained split 설계가 주요 비용이다.

### 9. novelty 위험요인

CUBE의 단순 domain transfer로 보일 수 있다. metadata counterfactual swap과 geography-disjoint 평가를 핵심 기여로 만들어야 한다.

### 10. 4~8주 논문화 가능성

2주에 split 설계, 4주에 global/local baseline, 6주에 metadata swap, 8주에 다른 항만·생물 분류 외부 검증이 가능하다.

### 11. negative result의 가치

class-local 경계가 이기지 못하면 해상 unknown은 known class 주변의 미세 외형 차이보다 센서·거리·해상도 shift가 더 큰 병목이라는 결론을 준다.

**평가:** Novelty 4/5 · Feasibility 3.5/5 · Compute efficiency 4/5 · Publication potential 4.5/5

## 2. 오늘의 선택

### 가장 먼저 테스트할 질문: Q1

- 공식 코드가 대조군과 LOEO 절차를 제공해 evaluator 구축 비용이 낮다.
- 재학습 전에 선형 probe와 통계 분석으로 핵심 가설을 반증할 수 있다.
- **첫날 작업:** xView2 한 모델에서 random/LOEO/pre-only/building-count-only 결과 파일을 재생성하고 event별 표본 수를 감사한다.
- **하루 종료 판정:** 논문 수치와 split이 일치하지 않으면 predictor 분석 전에 매니페스트·version 문제부터 해결한다.

### RTX 5060 Ti 8GB에서 가능한 질문: Q4, Q5, Q1

- Q4는 frozen DINOv2 feature와 split 재구성이 중심이다.
- Q5는 작은 crop classifier, PU baseline, threshold audit가 중심이다.
- Q1은 공개·사전 추출 embedding을 사용할 수 있으면 선형 모델만으로 시작할 수 있다.

### 장기 박사 주제로 키울 질문: Q1

- 사건·지역·센서 shortcut을 진단하고 실제 미지 재난 성능을 예측하는 문제는 remote sensing generalization의 중심 과제다.
- 데이터 분할, 표현 분석, causal intervention, private-event challenge를 단계적으로 확장할 수 있다.
- 해무·홍수·산불·건물 피해처럼 사용자의 해양·재난 CV 관심사를 하나의 연구 축으로 묶을 수 있다.

## 4. 증거와 제한

- 논문 수치와 공식 코드 설명은 확인된 사실로, 원인 설명은 저자 주장으로 구분했다.
- 질문의 threshold, GO/KILL 기준, 해양 domain 전이는 오늘 제안한 실험 가설이다.
- GFM 논문은 공식 코드를 확인했지만 독립 제3자 재현은 확인하지 못했다.
- temporal VLM, SquintBench, WoodBR-Cross, CUBE는 arXiv 원문에서 공식 code link를 확인하지 못해 재현 범위를 낮게 잡았다.
