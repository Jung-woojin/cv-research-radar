### 2.1 SuperNav: An Agentic Navigation System for Any Task in Any Scene

- **버전/날짜:** arXiv:2610.12126 v1, 2026-10-08.
- **문제·새로움:** 미세조정된 내비게이션 MLLM의 학습 분포 의존성을 줄이기 위해, 범용 MLLM은 요청 해석·장면 이해·의사결정에 집중하고 이동은 도구로 위임한다.
- **방법:** Navigation Skills, 물리 상호작용 도구, 진행상태·문맥 관리, 이미지 좌표를 목적지로 지정하는 visual-point 인터페이스.
- **저자 주장:** 네 종류의 비교 기준보다 instance-level·multi-object·demand-driven task에서 우수하고 HM3D 및 실제 사족보행 로봇에서 적용 가능성을 보였다.
- **데이터/재현성:** [공식 저장소](https://github.com/zju3dv/SuperNav)에 런타임·도구·평가 코드와 learned executor weight가 있다. 논문 task list와 정답은 공개 범위에서 제외됐다고 README가 밝힌다.
- **미확인:** 정확한 학습 계산량·반복 시드·전체 task split. geometry executor는 oracle depth/NavMesh를 사용하므로 방법 간 비교 때 정보 우위를 통제해야 한다.
- **진단→가설→최소 실험:** 새로운 요청에서 실패한다 → 계획보다 도구 실행/상태 관리가 병목일 수 있다 → AI2-THOR 20개 task에서 동일 MLLM의 primitive-action 대 tool harness를 고정 시드 3회 비교한다.
- **Woojin 연관성:** 에이전트형 CV 시스템에서 foundation model과 실행기를 분리하는 좋은 기준선이다. [원문](https://arxiv.org/abs/2610.12126)

### 2.2 Multi-Agent Egocentric World Model with Fine-Grained Embodied Interaction

- **버전/날짜:** arXiv:2610.12299 v1, 2026-10-08.
- **문제·새로움:** 다중 에이전트가 공유 세계에서 세밀하게 상호작용할 때 각 1인칭 영상이 같은 상태 변화를 반영해야 한다.
- **방법:** 여러 ego stream을 하나의 token sequence에서 공동 denoising하고, 모든 agent의 target-view pose와 shared environment memory로 조건화한다.
- **저자 주장:** 환경·업데이트·정체성 일관성, action control, 영상 품질이 비교 방법보다 향상됐다.
- **데이터/재현성:** 실세계와 합성 multi-agent data를 사용하며 [공식 저장소](https://github.com/cvlab-kaist/ME-World)가 공개됐다.
- **미확인:** 초록 기준 절대 점수, 계산량, 시드, cross-domain split. 새 consistency metric이 인간 평가와 얼마나 정렬되는지도 추가 확인이 필요하다.
- **진단→가설→최소 실험:** 한 agent의 조작이 다른 view에 늦게 반영된다 → shared memory update가 병목이다 → 동일 scene에서 agent 수 1/2/3으로 늘리며 state-update consistency 곡선을 측정한다.
- **Woojin 연관성:** 해무·해양 다중 카메라처럼 관측점이 다른 영상의 상태 일관성 평가에 아이디어를 옮길 수 있다. [원문](https://arxiv.org/abs/2610.12299)

### 2.3 OuroWorld: Bringing Any 3D World Alive as Diverse, Endlessly Looping 3D Cinemagraphs

- **버전/날짜:** arXiv:2610.12461 v1, 2026-10-08.
- **문제·새로움:** 정적인 3D Gaussian Splatting 장면을 마스크 없이 다양한 시점에서 반복 가능한 동적 장면으로 바꾼다.
- **방법:** VLM이 동역학을 제안하고 video model이 reference video를 생성한 뒤, Fourier-series deformation과 Grounded Drift Field를 쓰는 periodic 4DGS로 다중 시점에 확장한다.
- **저자 주장:** 39개 장면에서 모든 비교 기준을 앞섰고 사용자 비교에서 70.8%–99.0% 선호를 얻었다.
- **데이터/재현성:** [코드](https://github.com/youzhe0305/OuroWorld)와 Hugging Face dataset이 공개됐다.
- **미확인:** user-study 표본 구성·시드·학습 GPU 시간. ground-truth-free metric은 동일 생성 prior에 유리할 가능성을 점검해야 한다.
- **진단→가설→최소 실험:** loop seam은 낮지만 물체 정체성이 흔들린다 → drift field가 motion과 identity error를 함께 흡수한다 → deformation amplitude를 3단계로 고정하고 DINO identity·loop seam을 함께 측정한다.
- **Woojin 연관성:** 시계열 해무 장면의 주기성/조명 변화 시뮬레이션과 4D scene consistency 연구에 연결된다. [원문](https://arxiv.org/abs/2610.12461)

### 2.4 Beyond Spatio-Temporal Priors: A Generalizable Approach for Dense Correspondence Matching

- **버전/날짜:** arXiv:2610.12421 v1, 2026-10-08.
- **문제·새로움:** 편집·참조 생성은 외형 정체성을 유지하면서 물리적 연속성을 깨므로 smooth motion·rigid geometry 가정이 맞지 않는다.
- **방법:** 생성·semantic foundation representation, 고전 dataset·tracked video·synthetic scene의 이질적 supervision, teacher-guided iterative refinement를 결합한 FreeMatching.
- **저자 주장:** 하나의 모델로 IEG correspondence를 크게 개선하면서 고전 benchmark 경쟁력을 유지하고, identity-preservation metric이 인간 판단과 상관된다고 보고했다.
- **데이터/재현성:** [공식 코드](https://github.com/luping-liu/FreeMatching)가 공개됐다.
- **미확인:** 초록 기준 절대 점수·시드·학습 비용·합성 데이터 비중. teacher 편향이 metric에 전이되는지 확인이 필요하다.
- **진단→가설→최소 실험:** 해무 전후 영상에서 optical flow가 붕괴한다 → 물리 motion보다 semantic identity가 안정적이다 → 동일 쌍에 RAFT와 FreeMatching을 적용하고 수작업 keypoint 100개 EPE를 비교한다.
- **Woojin 연관성:** 저가시성·도메인 변화에서 correspondence를 진단하는 직접 후보이다. [원문](https://arxiv.org/abs/2610.12421)

### 2.5 MC-Sparse: Deconstructing and Closing the Dense-Sparse Attention Gap in Diffusion Transformers

- **버전/날짜:** arXiv:2610.06801 v1, 2026-10-05; 2026-10-09 Daily Papers 재노출.
- **문제·새로움:** 고희소 attention의 품질 저하를 token grouping 제약, interaction 선택 오류, 버려진 attention contribution으로 분해한다.
- **방법:** query를 tile-aligned group으로 묶되 KV는 개별 선택하고, 정확 attention probability·KV index·dense-sparse residual 메타데이터를 이후 denoising step에 재사용한다.
- **저자 주장:** dense 대비 Minimax-H3-Base 1.80×, 3D asset generation 2.32× denoising speedup과 무시 가능한 품질 손실을 보고했다.
- **데이터/재현성:** 초록과 확인한 paper page에서 공식 코드·checkpoint는 확인하지 못했다. training-free라는 주장도 실제 kernel·hardware 의존성을 검증해야 한다.
- **미확인:** GPU 종류, batch/sequence length, wall-clock 전체 pipeline 속도, 시드.
- **진단→가설→최소 실험:** 동일 sparsity에서도 특정 frame에서 artifact가 집중된다 → cached residual이 scene transition에서 낡는다 → shot boundary 전후 residual refresh 주기 1/2/4/8을 비교한다.
- **Woojin 연관성:** video diffusion 실험의 메모리·지연 최적화와 실패 원인 분해 방식이 유용하다. [원문](https://arxiv.org/abs/2610.06801)

### 2.6 DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training

- **버전/날짜:** arXiv:2610.12468 v1, 2026-10-08.
- **문제·새로움:** 카메라 보정 오차는 action conditioning을 틀어지게 하고, 성공 시연 위주의 데이터는 실패 상호작용을 과소표현한다.
- **방법:** action trajectory의 image-space rendering과 offline calibration, counterfactual trajectory/video 생성, 사람이 라벨링한 interaction-defect reward model로 RL post-training.
- **저자 주장:** AgiBot에서 action following SOTA, 인간 평가 interaction defect 48.12%→6.25%, AgiBot World Challenge 2026 world-model track 1위를 보고했다.
- **데이터/재현성:** 논문은 AgiBot 등 다중 embodiment를 사용한다. 프로젝트·코드 신호는 있으나, 데이터 라이선스와 전체 checkpoint 공개 범위는 실행 전 별도 확인이 필요하다.
- **미확인:** reward-labeler 합의도, 독립 seed 분산, 전체 학습 계산량. reward model이 선호하는 영상과 실제 물리가 일치하는지는 별도 검증 대상이다.
- **진단→가설→최소 실험:** 성공처럼 보이지만 contact가 어긋난다 → image-space calibration residual이 원인이다 → calibration on/off에서 end-effector pixel error와 defect rate를 함께 측정한다.
- **Woojin 연관성:** negative/failure data를 world model에 넣는 구체적 설계로서 실패 레이더와 직접 맞닿는다. [원문](https://arxiv.org/abs/2610.12468)

### 2.7 LEGO: A Lifting-Free Approach for Exocentric-to-Egocentric Video Generation

- **버전/날짜:** arXiv:2610.12442 v1, 2026-10-08.
- **문제·새로움:** 단일 exocentric video에서 egocentric view를 만들 때 depth→point cloud→reprojection 오차가 잘못된 위치로 그대로 전달된다.
- **방법:** depth lifting 없이 LVSM-style transformer가 target view를 직접 생성하고, 확률적 correspondence로 구조를 우선 보존한 뒤 diffusion이 세부 질감을 복원한다.
- **저자 주장:** 구조 정렬을 선명도보다 우선하는 조건이 diffusion generator에 더 적합하다고 보고한다.
- **데이터/재현성:** 초록에서 코드·checkpoint 공개를 확인하지 못했다.
- **미확인:** 절대 benchmark 수치, camera split, 계산량, 시드, unseen scene 일반화.
- **진단→가설→최소 실험:** 날카로운 reprojection이 오히려 최종 frame을 망친다 → condition의 구조 오차가 texture blur보다 치명적이다 → 같은 입력에 sharp-warp와 learned-soft condition을 넣어 LPIPS·pose error를 분리 측정한다.
- **Woojin 연관성:** 다중 카메라 해양 영상의 view transfer에서 기하 사전과 생성 prior의 역할을 비교할 수 있다. [원문](https://arxiv.org/abs/2610.12442)

### 2.8 Pumpire: Unified Benchmark for Metric Distance Estimation

- **버전/날짜:** arXiv:2610.12423 v1, 2026-10-08.
- **문제·새로움:** depth·intrinsic을 따로 평가하는 대신 복원된 3D에서 두 점 사이의 실제 거리 오차를 직접 평가한다.
- **방법/데이터:** 100개 실세계 scene × 64 frame, 총 6,400 frame에 물리적으로 측정한 point-pair distance를 붙인 pumpire-6k와 image/video 공통 protocol.
- **저자 주장:** 대표 3D foundation model 29개 설정을 비교해 physical scale estimation의 빈틈을 드러냈다.
- **재현성:** project page는 공개됐으나 확인한 초록에서 dataset license·download와 evaluation code 상태는 확정하지 못했다.
- **미확인:** 측정 오차·장면 분할·센서 구성·반복 시드. 한 scene의 64 frame이 train/test에 섞이면 누수가 생길 수 있다.
- **진단→가설→최소 실험:** 상대 depth는 맞는데 미터 단위가 흔들린다 → camera prior 부재가 scale ambiguity를 만든다 → depth prior on/off와 single/video 입력을 2×2로 비교해 absolute distance error를 측정한다.
- **Woojin 연관성:** 해양 관측에서 실제 거리·가시거리 평가를 모델 출력과 연결하는 benchmark 설계 참고점이다. [원문](https://arxiv.org/abs/2610.12423)

### 3.1 OneSearch-VL: Unified Multimodal Deep Research Agent for Image and Video

- **버전/날짜:** arXiv:2610.12419 v1, 2026-10-08.
- **문제·새로움:** single-image·multi-image·video research가 서로 다른 도구를 쓰더라도 시각 앵커, entity relation, 외부 근거, 답 생성 연산의 의존성을 보존해야 한다.
- **방법:** Visually Grounded Evidence Graph(VGEG)를 데이터 생성·process supervision·operation evaluation의 공통 표현으로 사용한다.
- **데이터/재현성:** 저자는 SFT 110K와 RL 10K를 구성했다. [공식 저장소](https://github.com/appletea233/OneSearch-VL)에 학습·추론·평가 코드, 모델과 dataset 링크가 공개됐다.
- **저자 주장:** 여러 시각 입력 형식을 하나의 research policy로 처리하고 evidence traceability와 grounding을 함께 개선한다.
- **미확인:** web corpus 시점·검색 backend 의존성·seed·총 계산량. 외부 웹 변경으로 재현 점수가 흔들릴 수 있다.
- **진단→가설→최소 실험:** 정답은 맞지만 근거 frame이 틀린다 → answer reward가 evidence path를 압도한다 → EVGR on/off로 answer accuracy와 evidence recall을 동시에 비교한다.
- **Woojin 연관성:** 자동 연구 레이더가 논문·그림·코드 근거를 연결하는 내부 provenance graph로 바로 응용 가능하다. [원문](https://arxiv.org/abs/2610.12419)

### 3.2 Reasoning-Informed Visual Editing

- **버전/날짜:** arXiv:2610.12343 v1, 2026-10-08.
- **문제·새로움:** 복잡한 편집 지시가 시간·인과·공간·논리·반사실·혼합 추론을 요구하는데 기존 평가는 이를 충분히 분해하지 못한다.
- **방법/데이터:** RISEBench++는 6개 reasoning dimension, 12개 subcategory, 65개 task type, 영·중 1,000개 human-annotated case와 multi-image conditioning을 포함한다.
- **재현성:** 기존 RISEBench [코드·데이터](https://github.com/PhoenixZ810/RISEBench)는 공개됐지만 ++ 확장분의 완전한 릴리스 상태는 별도 확인이 필요하다.
- **저자 주장:** 현재 editing model의 instruction reasoning, appearance consistency, plausibility 사이 격차를 세분화한다.
- **미확인:** judge model calibration, human inter-rater agreement, 새 1,000건의 중복·누수 점검.
- **진단→가설→최소 실험:** counterfactual edit는 보기 좋지만 조건을 위반한다 → generative prior가 논리 제약보다 강하다 → 30개 case에 rule-based condition checker를 추가해 LMM judge와 불일치를 분석한다.
- **Woojin 연관성:** 생성 모델 평가를 단일 미학 점수에서 진단 가능한 reasoning taxonomy로 확장한다. [원문](https://arxiv.org/abs/2610.12343)

### 3.3 SpaceCast-Bench: Evaluating Predictive Spatial Reasoning in Vision-Language Models

- **버전/날짜:** arXiv:2610.12402 v1, 2026-10-08.
- **문제·새로움:** 입력에 이미 보이는 관계를 읽는 대신, 관측에서 scene을 만들고 개입 뒤 보이지 않는 결과를 예측하는 능력을 평가한다.
- **방법/데이터:** observe-transform-infer 구조, 182개 실세계 scene, 3,862문항, 16 task type, static/local/global prediction 3단계.
- **저자 주장:** 21개 모델 중 최고 58.0%, 인간 87.2%; Qwen3-VL-4B를 생성 데이터로 학습하면 34.0%→65.7%이며 6개 OOD benchmark 평균도 상승했다.
- **재현성:** 초록에서 code/data release 상태와 license를 확인하지 못했다.
- **미확인:** human protocol, programmatic data의 template leakage, seed·계산량. OOD benchmark 선택 편향도 확인해야 한다.
- **진단→가설→최소 실험:** bridge view 제거 시 global prediction이 급락한다 → 분산 관측을 연결하는 공통 좌표계가 병목이다 → view 수 1/2/3과 explicit depth on/off를 교차 실험한다.
- **Woojin 연관성:** CV 연구 질문을 perception에서 intervention-aware prediction으로 끌어올리는 가장 강한 오늘의 seed다. [원문](https://arxiv.org/abs/2610.12402)

### 3.4 Distilling Routed 3D Privilege for Spatial Reasoning in Vision-Language Models

- **버전/날짜:** arXiv:2610.12355 v1, 2026-10-08.
- **문제·새로움:** inference 때 3D module을 붙이지 않고, 학습 때만 true geometry를 teacher privilege로 사용한다.
- **방법:** depth·semantic·BEV cue를 compact text로 렌더링해 teacher에 route하고, 오답 trajectory에만 privileged KL을 적용해 GRPO를 보강한다. 배포 모델은 RGB-only다.
- **저자 주장:** 4B backbone에서 VSI-Bench 57.1, MindCube·SPARBench·MMSI-Bench·ViewSpatial 평균 37.6으로 GRPO와 answer-privileged OPSD를 앞섰다.
- **재현성:** 확인한 초록에서 공식 code/checkpoint 공개는 확인하지 못했다.
- **미확인:** geometry renderer 오류 민감도, seed, training compute, teacher cue의 dataset-specific shortcut.
- **진단→가설→최소 실험:** RGB-only 학생이 방향은 맞지만 depth를 틀린다 → 모든 오답에 같은 3D cue를 주는 대신 error type routing이 필요하다 → depth/direction/occlusion 오답을 나눠 cue ablation을 수행한다.
- **Woojin 연관성:** 학습 시 privileged sensor를 쓰고 배포는 RGB만 쓰는 해양 CV 설계에 직접 적용 가능하다. [원문](https://arxiv.org/abs/2610.12355)

## 4. LLM / Agent / Reasoning / Training / System 1건

### 4.1 REMORY: Learning Residual Memory for Context Compaction

- **버전/날짜:** arXiv:2610.11287 v1, 2026-10-08.
- **문제·새로움:** 긴 agent history를 텍스트 요약만으로 줄이면 이후 결정을 위한 세부 신호가 사라진다.
- **방법:** history와 summary에서 bounded soft memory token을 생성해 요약 뒤에 붙이고, frozen LLM이 full-history continuation을 근사하도록 학습한다.
- **저자 주장:** SummHay에서 input position 5.2%만 사용해 full-context joint score에 접근했고, Qwen3.8-27B·GLM-5.3-Flash에서 장기 agent benchmark가 개선됐으며 BrowseComp·Terminal-Bench 2.1 tool 반복/오류가 감소했다.
- **재현성:** [공식 저장소](https://github.com/1ring2rta/Remory)가 공개됐다.
- **미확인:** memory network 학습비용, seed, context-length별 분산, 다른 backbone 전이. soft token은 사람이 감사하기 어렵다.
- **진단→가설→최소 실험:** 레이더 agent가 같은 검색을 반복한다 → textual summary가 과거 tool outcome을 잃는다 → 최근 20회 ledger로 summary-only 대 summary+memory의 중복 query율·task success를 비교한다.
- **Woojin 연관성:** 장기 자동화 ledger를 모델 입력으로 압축할 때의 직접 후보이지만 감사 가능성을 위해 구조화 로그를 병행해야 한다. [원문](https://arxiv.org/abs/2610.11287)

## 6. 오늘의 중요한 발견 3가지

1. **공간 지능의 평가 단위가 관계에서 상태 전이로 바뀐다.** SpaceCast-Bench와 DreamTrue는 둘 다 개입 이후의 미관측 결과를 핵심으로 둔다.
2. **실패 데이터가 world model의 필수 재료가 된다.** 성공 궤적만 학습하면 물리적으로 불가능한 성공을 생성할 수 있으며, DreamTrue는 counterfactual failure와 reward model로 이를 직접 겨냥한다.
3. **범용 모델과 실행 계층의 분리가 강해진다.** SuperNav는 MLLM 재학습 없이 harness를 붙이고, GPD는 3D privilege를 학습에만 사용해 배포 모델을 RGB-only로 유지한다.

## 7. 과대평가 가능성 / 주의 2가지

1. **생성 품질 개선을 물리 이해로 읽으면 안 된다.** DreamTrue·ME-World·OuroWorld의 저자 수치는 강하지만, reward model·사용자 평가·새 metric이 실제 dynamics와 일치하는지는 별도 검증이 필요하다.
2. **새 benchmark의 큰 격차는 dataset 설계의 힘일 수 있다.** SpaceCast·RISEBench++·Pumpire는 중요한 문제를 정의하지만 template, scene split, judge calibration이 공개되기 전 leaderboard 숫자만으로 일반화를 단정하면 안 된다.

## 8. 오늘 읽을 Top 3

1. **SpaceCast-Bench** — perception과 prediction의 차이를 가장 명확히 수치화한다.
2. **DreamTrue** — calibration→counterfactual failure→reward post-training으로 진단과 개입이 연결된다.
3. **SuperNav** — 코드가 열려 있고 범용 VLM+도구 분리를 최소 실험으로 검증하기 쉽다.

## 9. Top 1 미니 리뷰 — SpaceCast-Bench

**핵심 진단.** 기존 spatial benchmark는 화면에 보이는 관계를 읽는 능력과, 장면을 구성한 뒤 개입 후 상태를 갱신하는 능력을 섞는다. SpaceCast-Bench는 observe-transform-infer로 이를 분리한다.

**왜 중요한가.** 저자 보고에서 최상위 모델 58.0%와 인간 87.2%의 차이는 단순 객체 인식 개선만으로 채우기 어려운 병목을 시사한다. bridge view와 explicit 3D evidence가 중요하다는 분석은 실패가 언어 reasoning보다 관측 통합에서 시작할 수 있음을 보여준다.

**가장 의심할 지점.** programmatic training data로 Qwen3-VL-4B가 34.0%에서 65.7%로 오른 결과는 크다. 이 상승이 추론 규칙 학습인지 template 적합인지 판단하려면 unseen transform family와 scene-level split 결과가 필요하다.

**최소 재현 실험.** 30개 scene을 골라 bridge view 유/무 × explicit depth 유/무의 2×2 실험을 한다. exact answer 외에 scene graph state-update accuracy를 기록한다. 세 번의 고정 seed에서 global prediction만 선택적으로 오르면 “3D evidence가 perception error를 줄인다”는 가설을 지지한다.

## 10. 후속 연구 질문 seed

1. 해무처럼 관측 신뢰도가 시간에 따라 변할 때, predictive spatial reasoning model은 uncertainty를 scene state에 어떻게 전파해야 하는가?
2. 성공 궤적에 counterfactual failure를 합성할 때 reward hacking 없이 물리 위반 다양성을 늘리는 최소 supervision은 무엇인가?
3. privileged depth/BEV teacher가 RGB-only 학생에게 주는 이득은 실제 geometry 학습인가, dataset-specific text cue 암기인가?
4. dense correspondence metric을 해무 전후 영상에 적용하면 optical-flow failure와 semantic identity preservation을 분리할 수 있는가?
5. multimodal research agent의 evidence graph를 장기 memory token과 결합할 때 정확도와 감사 가능성 사이 최적점은 어디인가?

## 11. 오늘의 최소 실행 계획

1. **SuperNav dry-run:** 공개 demo/config를 설치하지 않고 먼저 README·task schema만 검사해 외부 asset 요구량과 평가 가능 범위를 표로 만든다.
2. **SpaceCast proxy:** 기존 RGB-D 장면 30개로 observe-transform-infer 소형 split을 만들고 RGB-only 대 RGB+depth의 state-update accuracy를 측정한다.
3. **FreeMatching fog test:** 맑음/해무 대응쌍 20개, 수작업 keypoint 100개로 RAFT 대비 endpoint error와 identity score를 비교한다.
4. **성공 기준:** 재현 가능한 script, 고정 split, seed 3개, 실패 사례 10개를 남기고 평균 점수보다 failure taxonomy를 먼저 기록한다.

## 12. 오늘은 건너뛴 항목

- **V-CoLA:** vision token compression은 관련성이 높지만 오늘 원문·코드 교차검증 시간이 부족해 보류했다.
- **SPW-Nav:** navigation 주제는 중복되며 SuperNav보다 공개 재현 범위를 확인하지 못했다.
- **SatNav:** 장거리 UAV VLN은 흥미롭지만 dataset license와 실제 geographic split을 확인하기 전까지 선정하지 않았다.
