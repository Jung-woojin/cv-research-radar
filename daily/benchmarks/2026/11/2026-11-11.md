## 핵심 요약

1. 최근 24~72시간에 공식 leaderboard의 새 SOTA 수치·split 변경·metric 교체는 확인하지 못했다.
2. 대신 Supervision `0.31.6`은 Grounding DINO/RF-DETR result loading, OWLv2 class naming, empty-frame keypoint와 `DetectionsSmoother` 동작을 바꿨다. 결과 후처리·tracking benchmark의 비교 contract에 영향을 줄 수 있는 새 신호다.
3. Ultralytics `v8.4.208`의 NMS default 분리와 V-Thinker 데이터 schema는 전일 보고서와 동일하여 새 revision 없이 반복 채택하지 않았다.
4. Supervision release가 새로운 detector benchmark score나 model gain을 주장한 것은 아니다.
5. 위험은 stored prediction을 같은 detector 결과로 간주하면서 annotation/tracker adapter version이 바뀌는 것이다.
6. 최소 실험은 fixed 10-frame fixture에서 old/new adapter의 detection tensor, class label, track ID, rendered image, exception을 분리 비교하는 것이다.
7. backbone, checkpoint, pretraining, resolution, confidence/NMS, tracker parameters, evaluator version이 고정되지 않으면 결과는 not strictly apples-to-apples다.

## 핵심 사례 — adapter/tracker revision이 benchmark 결과를 바꿀 수 있는 경우

- **사실:** Supervision `0.31.6` release는 empty video frame에서의 `KeyPoints` filter crash, Grounding DINO와 RF-DETR segmentation result loading, OWLv2 class-name 처리, grayscale/BGRA/palette annotation, integer box/mask-shift를 수정했다고 명시한다.
- **사실:** 같은 release는 `DetectionsSmoother`가 unconfirmed track를 하나의 평균 box로 합치지 않고 separate box로 유지하도록 바뀐다고 설명한다.
- **저자 주장:** release는 drop-in upgrade라고 표현하지만, stored output을 비교하는 경우 migration guide 확인을 권한다.
- **진단:** 같은 detector/checkpoint 출력이라도 adapter가 class name·box dtype·mask rendering·unconfirmed-track aggregation을 바꾸면 per-class score, count error, tracking ID 분석, 정성 시각화가 달라질 수 있다.
- **가설:** empty-frame와 tentative track를 포함한 evaluation set에서 global mAP 변화 없이 tracking/count/error slice가 바뀔 수 있다.
- **최소 실험:** 같은 raw model outputs를 `0.31.5`와 `0.31.6`에 각각 넣고 class-id/name, float/int box, empty frame exception, unconfirmed-track count, confirmed-track ID, rendered overlay hash를 비교한다. detector inference는 실행하지 않는다.
- **GO/KILL:** confirmed-track 및 raw tensor contract가 유지되고 변경이 release note와 일치하면 GO다. class mapping·track aggregation이 저장 결과와 다르면 historical benchmark table과 new result를 합산하는 것은 KILL이다.
- **한계:** maintainer release note는 adapter patch의 설명이며, 특정 dataset에서의 mAP/IDF1/HOTA 변화나 model accuracy gain을 제공하지 않는다.

## 오늘의 benchmark signal 3개

1. **Evaluator adapter version:** raw prediction과 result parser/annotation library 버전을 함께 저장해야 한다.
2. **Tracking state:** tentative/unconfirmed track 처리 여부는 count·ID metrics의 전제 조건이다.
3. **Visual regression:** grayscale/BGRA/palette rendering fix는 model score가 아니라 qualitative audit artifact를 바꿀 수 있다.

## 내 연구에 바로 연결되는 포인트

- small-object/crowded tracking에서는 detector score와 post-processor/tracker state를 분리한다.
- grounding/segmentation adapter는 class-name·mask loading regression fixture를 version pin과 함께 둔다.
- 새 패키지의 “drop-in” 표기를 accuracy parity의 근거로 쓰지 않는다.
