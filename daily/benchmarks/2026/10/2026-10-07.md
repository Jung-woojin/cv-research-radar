## 1. SpatialChain — 답 정확도와 근거 충실도의 분리

**확인된 변화:** v1 제출은 10월 5일 23:29:54 KST다. GQA 기반 학습 28,350개·테스트 899개에 공간 추론 체인을 결합하고, answer accuracy와 faithfulness/completeness를 함께 평가한다. 테스트는 복잡한 관계 질문을 선별한 구성이므로 일반 GQA와 점수를 직접 비교하면 안 된다. **저자 보고:** Qwen3-VL-8B FT는 정확도 85.03%, 정답 중 shortcut 비율 22.2%다. 두 수치는 분모가 다르다. [논문 및 제출 이력](https://arxiv.org/abs/2610.06413), [평가 정의와 결과](https://arxiv.org/html/2610.06413v1)

**비교 조건:** backbone·pretraining이 다른 모델 간 순위와, 추가 SpatialChain 데이터로 SFT한 모델 대 base 비교는 **not strictly apples-to-apples**다. 입력 해상도·TTA·외부 데이터·서비스 모델의 추론 예산까지 동일하게 통제됐다고 확인하지 못했다.

**공식 구현 교차검증:** 논문은 shortcut을 `RF <= 0.5`로 정의하지만 README는 `RF < 0.5`로 설명한다. 읽은 `metrics.py`는 평균 충실도와 pass rate를 계산하며 shortcut 경계 자체를 확정하지 못한다. 따라서 **문서 불일치는 확인됐지만 실행 코드의 버그는 미확인**이다. evaluator commit을 고정하고 shortcut 집계 경로를 추가 점검해야 한다. [공식 저장소](https://github.com/spatialchain/SpatialChainBenchmark), [metrics.py](https://raw.githubusercontent.com/spatialchain/SpatialChainBenchmark/main/judge/src/spatial_eval/metrics.py)

**연구 해석·최소 실험:** Answer–Region Gap 연구에 우선 연결할 가치가 있다. 기존 예측·judge 결과를 재사용해 `<`와 `<=`의 집계를 비교하고, 경계 사례를 사람이 검사한다. 모델을 다시 학습하기 전에 평가 정의만으로 순위가 변하는지 진단한다.

## 2. Readout Blindness / ADR — 이미지가 실제로 기여한 정도 측정

**확인된 변화:** v1 제출은 10월 5일 22:36:45 KST다. 동일 항목의 이미지가 다른 원본 이미지로 교체된 null 대조군을 만들고, `grounded gain = 원본 정확도 − null 정확도`를 평가한다. **저자 보고:** Qwen3.6 likelihood의 VALSE actant-swap 정확도는 93.99%지만 null에서도 88.41%로, 차이는 약 5.6%p다. 높은 정확도만으로 시각 근거 활용을 단정할 수 없다는 사례다. ADR은 frozen feature의 객체 중심 간 방향을 읽는 학습 없는 방법이다. [논문](https://arxiv.org/abs/2610.06324), [평가 결과 원문](https://arxiv.org/html/2610.06324v1)

**비교 조건:** 동일 encoder의 deployed score 대 ADR 비교가 핵심이다. 서로 다른 모델·pretraining, chat 대 likelihood 결과는 **not strictly apples-to-apples**다. null 차이는 이 대조군 대비 이미지 기여이며 시각 추론의 완전한 인과적 측정값은 아니다.

**공식 구현 교차검증:** 저장소에서 CLIP ViT-B/16 설정, real/null 실행 방법, 샘플 목록 및 평가 규칙을 확인했다. 이미지는 재배포하지 않는다. `--limit`은 null 이미지 풀도 바꾸므로 짧은 smoke test 결과를 본문 수치의 재현으로 보고하면 안 된다. VSR의 일부 점수는 real/null 각각 oracle threshold를 사용하므로 별도로 표시해야 한다. [공식 코드와 실행 안내](https://github.com/GarryLarry010131/ADR)

**연구 해석·최소 실험:** 8GB 환경의 첫 후보는 대형 chat VLM보다 frozen CLIP 비교다. 같은 이미지 전처리·caption·샘플 순서에서 deployed score와 ADR을 비교하고, real/null 정확도 및 paired bootstrap 신뢰구간을 기록한다. 해상도·TTA·모델 revision·evaluator commit을 실행 전에 고정한다. 실제 VRAM과 실행 시간은 아직 측정하지 않았다.

## 3. BabelFake — 언어·오디오 조건별 DeepFake 평가

**확인된 변화:** v1 제출은 10월 5일 22:42:34 KST다. 약 399k 영상, 5개 언어의 시청각 DeepFake 벤치마크이며 identity-disjoint train/val/test를 70/10/20으로 구성한다. **저자 보고:** 탐지 성능은 영상과 오디오 생성 조합에 따라 달라지고, 원래 오디오를 유지하는 조건에서 성능 저하가 나타난다. 이 결과의 metric은 AUC이며 accuracy나 detection AP로 바꾸어 해석하지 않는다. [논문과 제출 이력](https://arxiv.org/abs/2610.06339), [데이터 분할 및 평가 원문](https://arxiv.org/html/2610.06339v1)

**비교 조건:** 서로 다른 학습 데이터·backbone·입력 modality의 detector 비교, cross-dataset 결과 대 이 데이터로 학습한 결과는 **not strictly apples-to-apples**다. 입력 해상도·frame budget·TTA·compute까지 통제한 공통 순위로 확인하지 못했다.

**공식 구현 교차검증:** 이번 조사에서 벤치마크 자체의 다운로드 가능한 공식 데이터와 고정 evaluator 버전은 확인하지 못했다. 논문의 생성 도구 링크를 벤치마크 전체 공개로 간주하지 않는다.

**연구 해석·최소 실험:** 현재는 실행 우선순위가 낮다. 공개와 이용 조건을 확인한 뒤 동일 detector에서 언어 × real/fake audio별 AUC와 신뢰구간을 비교한다. 통합 점수의 변화가 시각 탐지 개선인지 오디오 shortcut인지 분리하는 진단에 가치가 있다.

## 내 연구에 바로 연결되는 포인트

먼저 frozen CLIP 기반 real/null 진단을 수행한다. 가설은 “공간 방향 실패의 일부가 encoder의 정보 부재보다 readout에 있다”이다. 최소 개입은 학습 없이 readout만 변경하는 것이고, baseline은 동일 encoder의 기존 점수다.

**GO:** direction-balanced subset에서 ADR의 grounded gain 개선이 양수이고 paired bootstrap 95% 신뢰구간이 0을 넘으며, 두 subset에서 방향이 일치한다. **KILL/수정:** 개선이 null·threshold 선택에만 의존하거나 한 subset에서만 나타난다. 이는 제안한 판정 기준이며 실험 결과가 아니다.

small-object·해양·안개 영상으로의 확장은 후속 가설이다. 오늘의 근거만으로 해당 도메인에서도 개선된다고 주장하지 않는다.
