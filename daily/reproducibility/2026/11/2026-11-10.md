## 핵심 사례 — Grounding DINO v5 phrase-delimiter position ids

- **사실:** 공식 Transformers issue #50465는 v5.0부터 vectorized generate_masks_with_special_tokens_and_transfer_map에서 closing delimiter가 이전 special token을 포함해 계산되어 position id -1 후 0으로 clamp된다고 보고한다. 작성자가 제시한 a cat. 예에서 v5 position ids는 [0,0,1,0,0], v4/original convention은 [0,0,1,2,0]이다.
- **커뮤니티 재현 조건:** Transformers 5.18.0, torch 2.14.1, Python 3.12.13, macOS 27.2 arm64 CPU; IDEA-Research/grounding-dino-tiny과 repository integration fixture가 사용됐다.
- **작성자 주장:** v5.18 condition의 logits maximum absolute difference가 0.3004이고, dtype와 delimiter fix를 모두 적용하면 0.0126, PIL image processor까지 맞추면 0.0010이라고 제시한다. 2,000 random special-token batch 중 installed function의 position-id가 1,834개에서 v4 loop와 달랐다고도 보고한다.
- **관찰된 gap:** original Grounding DINO/mmdetection과의 output parity가 text position embedding 및 image-resize path에 의해 깨질 수 있다는 주장이다.
- **가능 mechanism:** delimiter token의 position index가 BERT position embedding과 text sine embedding에 전달되어 phrase-conditioned text feature를 바꾼다.
- **한계:** issue는 open 상태이며 maintainer-accepted fix나 versioned release가 확인되지 않았다. random-batch count와 numerical differences는 작성자의 환경/patch 결과이므로 독립 실험 사실이 아니다.
- **반증 가능한 최소 실험:** 동일 model revision·image·prompt에 대해 v4/v5 processor로 input ids/position ids를 저장하고 default/PIL image processor를 분리한 2×2 matrix에서 fixed logits, boxes, score, phrase recall을 비교한다.
- **GO/KILL:** position ids와 expected fixture tolerance가 맞으면 해당 setup을 GO한다. mismatch가 재현되면 v5 result를 v4/original baseline과 직접 비교하지 않고 processor/version pin과 regression test를 먼저 적용한다(KILL: benchmark claim 중단).

## 진단 → 가설 → 최소 실험

- **관찰:** 같은 weights라도 tokenizer-position mapping과 resize processor가 다르면 output parity가 달라질 수 있다.
- **가설:** phrase delimiter가 많은 open-vocabulary prompts에서 v5 preprocessor mismatch가 phrase-level score ranking drift를 키운다.
- **최소 실험:** one phrase, five phrases, adjacent delimiter, paraphrase 네 prompt family에 대해 v4/v5 × default/PIL processor를 실행하고 logits max-diff, box IoU, phrase recall, score ranking correlation을 기록한다.
- **성공:** expected fixture와 original implementation tolerance를 통과하고 prompt family별 ranking이 유지된다.
- **실패:** processor/version별 ordering reversal 또는 tolerance failure가 생기면 score 결과를 configuration-specific으로 격리한다.

## 오늘의 GO / KILL

- **GO:** Grounding DINO 실험 manifest에 Transformers version, processor class, image resize path, token/position-id artifact를 넣는다.
- **GO:** release upgrade 전 고정 image/prompt fixture의 logits/boxes checksum test를 CI 또는 notebook preflight에 둔다.
- **KILL:** open issue의 patch 성능을 official fix나 모든 Grounding DINO/VLM 모델의 재현 실패로 일반화하지 않는다.
- **KILL:** hardware·processor·precision이 다른 결과를 same model이라는 이유만으로 직접 비교하지 않는다.
