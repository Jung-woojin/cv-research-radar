# CV Paper Idea Radar — 2026-10-09

- 조사 범위는 **2026-10-02~2026-10-08 KST**이며, 최신 후보 11편을 검토해 후속 연구 질문이 선명한 7편을 남겼다.
- 이번 주 가장 강한 공통 신호는 모델이 이미 계산한 evidence를 더 쌓는 것보다 **언제 기록하고, 언제 수정하며, 언제 믿지 않을지**를 명시하는 방향이다.
- MOTIP2는 end-to-end tracker의 identity decoder가 공간 정보를 버려 생기는 비현실적 ID jump를 보여주고, Ledger는 장기 기억의 construction·retrieval 오류를 분리한다.
- HeiCo-FOCUS는 수 시간 video에서 persistent identity와 누적 상태가 아직 풀리지 않았으며, temporal grounding 평균 정확도가 저자 실험에서 19.7%임을 보였다.
- One-Shot Adaptive Segmentation은 한 장의 reference background 방향을 제거해 큰 개선을 보고했지만, **어떤 reference가 도움이 되거나 해로운지**는 평가하지 않는다.
- Temporal Residual Bottleneck은 stale feature를 직접 덮어쓰기보다 보수적으로 residual correction하는 편이 severe delay에 강할 수 있음을 보였지만, gate는 안전 보장이 아니다.
- 이번 제안은 **① ConfusionScope Tracking, ② ReferenceGuard Segmentation, ③ ResidualTrust Fusion** 세 가지다.
- 1순위는 **ConfusionScope Tracking**이다. 기존 tracking validation clip에 합성 exit/re-entry stress를 추가하면 1~2주 안에 핵심 가설을 싸게 죽일 수 있다.

## 조사 기준

- **확인된 사실:** 논문 원문에 명시된 공개일, protocol, dataset, metric, 공개 상태.
- **저자 주장:** 저자가 보고한 실험 결과이며 독립 재현 결과가 아니다.
- **해석/제안:** 아래 proposal에서 확장한 연구 가설이다.
- 서로 다른 backbone·split·input·reader·hardware의 수치는 `not strictly apples-to-apples`로 취급했다.
- 2026-10-02 보고서의 EvidenceBudget, Disagree-to-Adapt, EvidenceCredit-VQA를 반복하지 않았다. 오늘 proposal은 identity update, one-shot reference risk, asynchronous residual trust라는 새 빈틈에서 출발한다.
- 11개 후보 중 FigCodeBench, BagDINO, GRACE, MORCA는 흥미롭지만 이번 회차의 4~8주 진단형 proposal과 직접 연결되는 반증 실험이 상대적으로 약해 우선순위에서 제외했다.

## 연결 가치가 높은 최신 논문 7편

### 1. MOTIP2: Spatial Priors for End-to-End Multi-Object Tracking

- **공개:** arXiv v1, 2026-10-07. BMVC 2026 accepted 표기.
- **문제:** end-to-end association이 공간적으로 불가능한 ID jump까지 만들 수 있다.
- **방법:** training data의 spatial ID switch, 거리 가중 ID loss, positional anchor를 data/loss/representation 세 단계에 넣는다.
- **저자 결과:** DanceTrack 73.4 HOTA, SportsMOT 76.0 HOTA, PersonPath22 71.1 IDF1을 보고한다. 동일 backbone에서 spatial prior가 DanceTrack test의 HOTA +2.1, AssA +3.5를 더했다고 분석한다. MOTIP2-S는 T4 TensorRT FP16에서 10.1 ms를 보고한다.
- **중요 limitation:** proximity prior가 강할수록 **같은 위치에서 한 물체가 나가고 다른 물체가 들어오는 경우**를 혼동할 가능성이 논문에 명시돼 있다. 일부 model은 DanceTrack train+val을 사용하므로 표의 모든 행이 동일 data 조건은 아니다.
- **공개 상태:** [공식 논문](https://arxiv.org/html/2610.10391v1)에서 별도 코드 저장소는 확인하지 못했다.
- **연결 이유:** 단순 architecture gain보다 “어떤 training corruption이 실제 inference confusion과 일치하는가”를 묻는 좋은 진단형 연구다.

### 2. Never Look Back: Understanding Persistence in 3D Object Memory from Egocentric Videos

- **공개:** arXiv v1, 2026-10-07.
- **문제:** 질문을 미리 알 수 없는 장시간 egocentric video에서 물체 위치·이동·문맥을 어떻게 지속 기억할 것인가.
- **방법:** Ledger가 3D 위치, resting segment, contextual description을 저장하고 질문 시 원본 frame을 다시 읽지 않는다.
- **저자 결과:** HD-EPIC prototype-averaged accuracy 29.7%→42.6%, UCS-Bench에서 DirectMe graph 42.9% 대비 Ledger 46.3%, VQ3D returned prediction median error 0.99 m를 보고한다.
- **중요 limitation:** offline construction이며, VQ3D 오차는 반환한 prediction의 coverage와 함께 봐야 한다. 100개 stitched stream에서 scene change가 construction과 retrieval을 모두 악화시켰다.
- **공개 상태:** [공식 논문](https://arxiv.org/html/2610.10538v1); 독립 실행 가능한 공식 Ledger repo는 원문에서 확인하지 못했다.
- **연결 이유:** tracking의 ID switch를 단기 association 오류에서 장기 memory write/update 오류로 확장할 수 있다.

### 3. HeiCo-FOCUS: A Clinically Grounded Dataset for Long-Context Video Understanding

- **공개:** arXiv v1, 2026-10-07.
- **문제:** 수십 분~수 시간 video에서 여러 foreign object의 삽입·가림·제거와 누적 상태를 일관되게 추론하는가.
- **방법:** 96시간 수술 영상, 30,000 VQA pair, frame→segment→procedure track, 다섯 capability로 구성한다.
- **저자 결과:** 10개 frontier VLM 중 약 절반만 text-only baseline을 명확히 넘었고, 모델 평균 temporal grounding accuracy는 19.7%, event/procedural understanding은 56.5%였다.
- **중요 limitation:** human reference도 event aggregation 35%, duration estimation 40%였지만 각각 20문항이라 상한 추정이 불안정하다. 작은 staple은 instance annotation 자체가 어렵고, data는 원문 시점에 공개 예정이었다.
- **공개 상태:** [공식 논문](https://arxiv.org/html/2610.10156v1), [공식 코드](https://github.com/IMSY-DKFZ/orena-focus).
- **연결 이유:** “긴 context를 넣었는가”가 아니라 persistent identity와 state aggregation을 직접 평가한다.

### 4. One-Shot Adaptive Segmentation for Scientific Images

- **공개:** arXiv v1, 2026-10-07.
- **문제:** 과학 영상마다 많은 annotation과 task-specific training이 필요한 문제.
- **방법:** 한 장의 annotated reference에서 foreground prototype과 background direction을 얻고, DINOv3 feature에서 background 방향을 직교 제거한 뒤 SAM2 prompt를 만든다.
- **저자 결과:** red-blood-cell microscopy와 pool-boiling에서 strongest baseline 대비 개선을 보고하고, pool-boiling 20 frame에서는 mIoU 0.4243→0.7579를 제시한다. chest radiograph는 0.3960으로 SAM2 0.3962와 사실상 비슷하다.
- **중요 limitation:** abstract의 “78.62% 개선”과 본문의 “33.36 percentage points”는 상대 개선과 절대 개선의 표현 차이로 읽어야 한다. reference 선택 민감도, 여러 seed/reference, cross-site robustness가 보고되지 않았고 공식 코드도 확인되지 않았다.
- **공개 상태:** [공식 논문](https://arxiv.org/html/2610.10306v1).
- **연결 이유:** feature에 target evidence가 남아 있지만 background direction 때문에 readout이 실패한다는 representation-vs-readout 진단을 만들 수 있다.

### 5. Temporal Residual Bottleneck for Robust Asynchronous Collaborative Perception

- **공개:** arXiv v1, 2026-10-07.
- **문제:** collaborator feature가 늦거나 일부 유실됐을 때 direct transport가 reliable anchor를 덮어쓰는 문제.
- **방법:** pose-warped feature를 anchor로 유지하고, Δt-conditioned xLSTM이 history에서 residual만 예측하며 gated correction을 적용한다.
- **저자 결과:** DAIR-V2X AP@0.7에서 synchronized 조건은 LRCP 0.669 대비 0.664로 낮지만 irregular 500 ms에서는 0.611 대비 0.635였다. sync→irregular 500 ms drop이 0.058 대 0.029로 절반이었다.
- **중요 limitation:** packet drop은 실제 wireless channel을 모사한 것이 아니라 severe stress test이며 gate는 formal safety guarantee가 아니다. synchronized 성능 손실은 추가 fine-tuning으로 줄어 training distribution trade-off임을 appendix가 보여준다.
- **공개 상태:** [공식 논문](https://arxiv.org/html/2610.10090v1); 논문은 코드 공개 예정 링크를 제공한다.
- **연결 이유:** feature update를 항상 적용하지 않고 “보수적 anchor + 신뢰 가능한 residual”로 제한하는 구조가 fog·maritime·multi-sensor fusion에 직접 연결된다.

### 6. Performance at What Cost? A Sustainability-Aware Performance Index for Cell and Nucleus Instance Segmentation

- **공개:** arXiv v1, 2026-10-07.
- **문제:** segmentation accuracy gain이 energy와 model size 증가를 정당화하는가.
- **방법:** performance·energy·parameter count를 결합한 SAPI로 19개 zero-shot model과 16개 few-shot model을 CellBinDB 6개 modality에서 비교한다.
- **저자 결과:** PathoSAM ViT-B는 performance 0.675, 164.15 J/image, 104.8M parameter이고 ViT-H는 0.680, 342.71 J/image, 652.1M이다. SAPI 순위가 accuracy-only 순위와 달라졌다.
- **중요 limitation:** Tesla V100 한 구성의 hardware-domain 측정이며 wall-socket·cooling·pretraining energy는 제외한다. SAPI weight가 달라지면 순위도 변한다.
- **공개 상태:** [공식 논문](https://arxiv.org/html/2610.10324v1), [코드](https://github.com/eiram-mahera/sapi), [데이터](https://doi.org/10.5281/zenodo.15370205).
- **연결 이유:** proposal의 성공 기준에 accuracy뿐 아니라 latency·energy·VRAM Pareto를 넣게 한다.

### 7. TouchScale: 500 Hours of Human Vision and Touch for Visual-Tactile Learning

- **공개:** arXiv v1, 2026-10-07.
- **문제:** video만으로는 contact와 pressure가 보이지 않고, 기존 tactile dataset은 작거나 sensor가 섞여 scale effect를 분리하기 어렵다.
- **방법:** 한 wearable pipeline으로 500시간, 약 87,000 episode, 약 2,000 task description, 1,500개 이상 object를 수집하고 RGB-D·wrist RGB·bimanual tactile을 동기화한다.
- **저자 결과:** unseen tactile sensor의 zero-shot contact IoU 개선을 보고하며, 통제된 표에서는 EgoTouch 학습 0.134 대비 TouchScale 학습 0.181 cIoU를 제시한다.
- **중요 limitation:** robot 검증은 한 platform·네 task이고 action label이 없다. 20%→100% data 확대의 future-tactile prediction은 2.87%→3.31%로 증가폭이 작다.
- **공개 상태:** [공식 논문](https://arxiv.org/html/2610.10288v1); 전체 recording 공개를 예고했지만 원문에서 즉시 사용할 공식 repo는 확인하지 못했다.
- **연결 이유:** modality가 다르면 동일 공간의 evidence라도 신뢰도와 해상도가 달라지며, fusion update의 utility를 직접 측정해야 한다.

# Proposal 1 — ConfusionScope Tracking

## Local Spatial Priors Are Not Persistent Identity: Stress-Testing and Repairing Same-Location Re-entry

1. **문제 정의와 가치**  
   MOTIP2는 비현실적 장거리 ID jump를 줄이지만 proximity prior가 가장 약해지는 조건은 같은 위치의 exit/re-entry다. Ledger와 HeiCo-FOCUS도 장기 identity/state update가 병목임을 보여준다. 핵심 질문은 **“근처에 있다는 이유로 기존 identity를 이어야 하는가, 아니면 새 identity로 기록해야 하는가?”**다.

2. **기존 연구의 빈틈**  
   HOTA/IDF1은 전체 평균에서 same-location replacement, long occlusion, scene cut 오류를 분리하지 않는다. MOTIP2는 local geometry를 강화하지만 persistent memory의 write/overwrite 결정을 명시적으로 평가하지 않는다. Ledger는 persistent record를 갖지만 end-to-end MOT association을 학습하지 않는다.

3. **핵심 가설**  
   local proximity와 appearance confidence만으로는 same-location re-entry를 구분할 수 없다. **track survival uncertainty + absence duration + trajectory termination evidence + memory consistency**를 함께 쓰면 기존 identity 재사용과 newborn 결정을 더 잘 분리할 수 있다.

4. **방법 구조 / 모듈**  
   Detector/DETR → spatially grounded ID decoder → Track Survival Head → Persistent Identity Ledger → Re-entry Gate.  
   Gate 입력은 마지막 위치·속도·absence duration·appearance drift·scene boundary·recent occlusion evidence다. Gate는 `continue / dormant / terminate / newborn`을 출력하며 confidence가 낮으면 identity 결정을 지연한다.

5. **Baseline과 비교군**  
   MOTIP/MOTIP2, ByteTrack/BoT-SORT, spatial anchor만 사용한 variant, history length만 늘린 variant, fixed max-age, appearance-only re-ID, oracle termination, oracle scene boundary.

6. **Dataset / metric**  
   DanceTrack, PersonPath22, MOT17 validation. 기존 clip에 controlled exit/re-entry와 scene-cut stress set을 추가한다. HOTA, AssA, IDF1, IDSW, long-range IDSW, same-location replacement error, re-entry identity accuracy, coverage, latency를 보고한다.

7. **필수 ablation**  
   survival head 유무, absence duration 유무, appearance drift 유무, scene boundary 유무, delayed commitment 길이 0/1/2/4, ledger capacity, spatial prior 강도, synthetic stress 없이 학습한 경우.

8. **예상 실패 / negative result**  
   detector miss가 identity decision보다 큰 병목이면 ledger가 효과가 없다. appearance가 거의 같은 대상에서는 newborn 판단이 불안정할 수 있다. negative result라도 “장기 identity 오류는 association보다 detection recall이 지배한다”는 진단이 남는다.

9. **Novelty risk와 방어**  
   단순 track lifecycle head로 보일 위험이 있다. 방어 포인트는 새 module보다 **same-location re-entry stress protocol과 error taxonomy**, 그리고 local spatial prior가 persistent identity를 보장하지 않는다는 causal ablation이다.

10. **4~8주 MVP**  
    - Week 1: DanceTrack/PersonPath22에서 IDSW를 거리·absence·exit/re-entry 유형으로 재분류.
    - Week 2: synthetic same-location replacement generator와 oracle termination gap 측정.
    - Week 3: survival/newborn probe.
    - Week 4: delayed-commit gate.
    - Week 5~6: full ledger, cross-dataset.
    - Week 7~8: latency·failure analysis·paper figures.

11. **성공 contribution 3개**  
    1. Local association과 persistent identity를 분리하는 stress benchmark.  
    2. survival uncertainty 기반 identity write/update mechanism.  
    3. IDSW를 distance·absence·replacement 원인으로 분해한 진단.

12. **제목 후보**  
    - *ConfusionScope: When Spatial Priors Fail Persistent Multi-Object Tracking*  
    - *Same Place, Different Object: Diagnosing Re-entry Errors in End-to-End Tracking*  
    - *From Local Association to Persistent Identity Memory*

13. **Abstract 개요**  
    Spatial prior는 장거리 jump를 줄이지만 same-location replacement를 악화시킬 수 있음 → 기존 평균 metric이 이를 숨김 → stress protocol과 survival-aware ledger 제안 → 여러 tracker에서 원인 분해와 최소 intervention 검증.

14. **Introduction 흐름**  
    E2E MOT 발전 → spatial grounding 회복 → proximity의 한계 → persistent identity의 write/terminate 문제 → benchmark gap → survival-aware minimal repair.

15. **Related Work 구조**  
    End-to-End MOT / Tracking-by-Detection Priors / Re-identification and Track Lifecycle / Egocentric Object Memory / Long-Term Tracking Evaluation.

16. **Method 구조**  
    3.1 Error taxonomy, 3.2 Re-entry stress construction, 3.3 Track survival estimation, 3.4 Persistent ledger, 3.5 delayed identity commitment, 3.6 training losses.

17. **표·그림 계획**

# Proposal 2 — ReferenceGuard Segmentation

## Predicting When One-Shot Feature Orthogonalization Helps or Destroys Target Evidence

1. **문제 정의와 가치**  
   한 장의 annotated reference로 background direction을 제거하면 큰 개선이 가능하지만, reference가 atypical하거나 target과 background feature가 겹치면 유효한 target evidence도 제거할 수 있다. 질문은 **“적용 전에 이 reference가 실제로 도움 될지 예측할 수 있는가?”**다.

2. **기존 연구의 빈틈**  
   One-Shot Adaptive Segmentation은 chosen reference의 평균 성능을 보고하지만 reference-to-reference variance, harmful projection rate, site/scanner shift를 측정하지 않는다. SAPI는 비용을 포함하지만 reference quality에 따른 failure는 다루지 않는다.

3. **핵심 가설**  
   foreground/background subspace angle, target prototype compactness, perturbation stability, pre/post-projection similarity margin이 **realized mIoU gain과 negative transfer**를 예측한다.

4. **방법 구조 / 모듈**  
   Frozen DINOv3 → reference foreground/background subspace estimator → Reference Risk Probe → `project / soften / abstain` controller → SAM2 prompt generation. Soft projection은 predicted risk에 따라 제거 강도를 조절한다.

5. **Baseline과 비교군**  
   SAM2, GF-SAM, INSID3, fixed background orthogonalization, multiple-reference averaging, random reference, confidence threshold, oracle best reference, oracle projection strength.

6. **Dataset / metric**  
   100k-RBC-PathOlOgics, Montgomery Chest X-ray, 공개 가능한 microscopy/remote-sensing segmentation dataset 1개. mIoU/Dice, worst-reference mIoU, harmful-reference rate, gain-prediction AUROC/Spearman, calibration error, J/image, p95 latency.

7. **필수 ablation**  
   subspace angle만, margin만, perturbation stability만, 결합 predictor, hard vs soft projection, reference 1/2/4장, class별·site별 split, DINO layer, SAM/SAM2, target size bin.

8. **예상 실패 / negative result**  
   one-shot gain이 reference 통계보다 target-image artifact에 좌우될 수 있다. predictor가 domain마다 재학습을 요구하면 training-free 장점이 사라진다. negative result라도 one-shot segmentation의 reference variance benchmark가 남는다.

9. **Novelty risk와 방어**  
   confidence gating처럼 보일 수 있다. 방어는 uncertainty 일반론이 아니라 **feature subspace intervention의 counterfactual gain**을 label로 삼고, target evidence removal을 직접 측정하는 데 있다.

10. **4~8주 MVP**  
    - Week 1: dataset별 20~50개 reference를 바꿔 full reference-gain matrix 생성.
    - Week 2: subspace angle/margin과 realized ΔmIoU correlation.
    - Week 3: logistic/MLP risk probe.
    - Week 4: soft projection.
    - Week 5~6: cross-domain·small-target test.
    - Week 7: SAPI식 energy/latency Pareto.
    - Week 8: failure audit.

11. **성공 contribution 3개**  
    1. One-shot segmentation의 reference-risk evaluation protocol.  
    2. Projection benefit를 사전 예측하는 training-light controller.  
    3. 정확도·reference robustness·energy를 함께 보는 Pareto 평가.

12. **제목 후보**  
    - *ReferenceGuard: Predicting Harmful One-Shot Adaptation in Scientific Segmentation*  
    - *One Example Can Hurt: Reference Risk in Training-Free Segmentation*  
    - *Before Orthogonalizing: Forecasting Feature-Projection Utility*

13. **Abstract 개요**  
    one-shot reference가 foundation feature를 specialization하지만 reference 선택은 불안정 → counterfactual reference sweep으로 harmful projection 정의 → subspace geometry 기반 risk predictor → selective/soft intervention으로 worst-case 개선.

14. **Introduction 흐름**  
    annotation scarcity → one-shot foundation adaptation → impressive average gain → single-reference brittleness → intervention utility 예측 → 안전한 specialization.

# Proposal 3 — ResidualTrust Fusion

## Calibrated Abstention for Asynchronous Multi-Sensor and Collaborative Perception

1. **문제 정의와 가치**  
   stale collaborator feature나 비동기 sensor evidence를 잘못 보정하면 reliable anchor보다 나빠질 수 있다. residual correction은 보수적이지만 현재 gate가 **이번 residual이 실제 detection을 개선할지** 보장하지 않는다.

2. **기존 연구의 빈틈**  
   Temporal Residual Bottleneck은 severe delay robustness를 보여주지만 packet loss가 현실 channel model이 아니고, residual norm·uncertainty와 realized detection gain의 관계를 평가하지 않는다. TouchScale도 modality scale을 보여주지만 sensor별 evidence reliability를 action-level fusion decision으로 연결하지 않는다.

3. **핵심 가설**  
   residual magnitude, history disagreement, Δt, pose uncertainty, anchor-residual gradient conflict를 결합하면 correction의 realized utility를 예측할 수 있고, harmful correction을 abstain하면 worst-case AP drop을 줄일 수 있다.

4. **방법 구조 / 모듈**  
   Pose-warped conservative anchor → temporal residual candidates → Trust Feature Extractor → calibrated utility head → cell/object-level `apply / attenuate / abstain` → detector fusion. Utility head는 synthetic corruption이 아니라 held-out counterfactual `with residual vs without residual` gain으로 supervision한다.

5. **Baseline과 비교군**  
   no collaboration, synchronized fusion, LRCP, CoDynTrust, Temporal Residual Bottleneck, norm threshold, entropy threshold, global gate, oracle cell/object residual selection.

6. **Dataset / metric**  
   DAIR-V2X, OPV2V Culver City. 후속 외부 검증으로 maritime camera-radar가 확보되면 확장한다. AP@0.5/0.7, delay-conditioned AP, worst-case AP drop, harmful-correction rate, utility AUROC, calibration error, bandwidth, latency, energy를 기록한다.

7. **필수 ablation**  
   Δt, pose uncertainty, residual norm, history disagreement, gradient conflict 각각과 결합; global/object/cell gate; fixed·irregular·Markov burst loss; 100/300/500 ms; synchronized mixture 비율; xLSTM history 1/2/4/8.

8. **예상 실패 / negative result**  
   counterfactual utility label이 detector noise 때문에 불안정할 수 있다. cell-level gate가 지나치게 fine-grained해 calibration이 무너질 수 있다. negative result라도 residual norm이 신뢰도 proxy가 아니라는 결과와 realistic packet process에서의 robustness gap이 남는다.

9. **Novelty risk와 방어**  
   기존 dynamic trust와 유사해질 수 있다. 방어는 domain-shift score가 아니라 **residual intervention의 realized counterfactual gain**을 예측하고 abstention calibration을 평가하는 데 있다.

10. **4~8주 MVP**  
    - Week 1: 공식 temporal baseline 재현 또는 공개 전이면 자체 cached-history baseline 구성.
    - Week 2: residual on/off로 object별 realized gain label 수집.
    - Week 3: cheap utility probe와 calibration.
    - Week 4: apply/abstain gate.
    - Week 5: Markov burst loss + pose jitter.
    - Week 6: cross-dataset.
    - Week 7~8: bandwidth·latency·failure analysis.

11. **성공 contribution 3개**  
    1. Residual correction utility를 counterfactual하게 정의.  
    2. calibrated abstention으로 asynchronous fusion의 harmful update 감소.  
    3. delay·packet·pose corruption을 분리한 robustness protocol.

12. **제목 후보**  
    - *ResidualTrust: Calibrated Abstention for Asynchronous Collaborative Perception*  
    - *Do Not Correct What You Cannot Trust*  
    - *Counterfactual Utility Gating for Stale Multi-Sensor Features*

13. **Abstract 개요**  
    delayed evidence compensation이 anchor를 손상시킬 수 있음 → residual correction도 항상 유익하지 않음 → on/off counterfactual gain으로 trust 학습 → harmful update abstention → severe delay와 realistic burst에서 worst-case robustness 개선.

# 이번 주 1순위 — ConfusionScope Tracking

선정 이유는 세 가지다.

1. MOTIP2가 스스로 명시한 hardest case와 Ledger/HeiCo의 persistent identity gap이 정확히 맞물린다.
2. 새 대형 backbone 없이 validation clip과 작은 probe만으로 핵심 가설을 검증할 수 있다.
3. 실패해도 “spatial prior 이후 남는 ID 오류는 무엇인가”라는 error taxonomy와 stress benchmark가 논문 자산으로 남는다.

## 첫 실험

- **모델:** 공개 가능한 MOTIP 또는 유사 query-based tracker 1개와 ByteTrack 계열 1개.
- **Dataset:** DanceTrack validation 10개 sequence에서 원래 clip과 합성 stress clip을 구성.
- **Subset:** 정상 구간 200개, long occlusion 100개, same-location exit/re-entry 100개 event를 목표로 하되 실제 추출 가능한 verified event만 사용.
- **변경 변수:** association 구조는 고정하고 `max-age / delayed commitment / survival probe`만 변경.
- **측정:** HOTA, IDF1, IDSW, same-location replacement error, re-entry identity accuracy, long-range IDSW, latency.
- **진단 곡선:** absence duration×spatial distance별 ID reuse probability와 error heatmap.
- **GO 기준:** survival probe 또는 delayed commitment가 same-location replacement IDSW를 **20% 이상 줄이고**, 전체 HOTA 손실이 0.5 point 이하이며, 단순 max-age tuning보다 낫다.
- **KILL 기준:** oracle termination조차 의미 있는 gap을 만들지 못하거나, 개선이 history length/max-age tuning만으로 동일하게 재현된다.
- **다음 단계:** GO면 persistent ledger를 추가하고 PersonPath22로 transfer한다. KILL이면 identity memory보다 detector miss/duplicate suppression을 주원인으로 재정의한다.

## 실행 우선순위

1. **오늘:** 기존 tracker output에서 IDSW를 거리·absence·occlusion 유형으로 재분류하는 분석 script 작성.
2. **이번 주:** synthetic same-location replacement stress set과 oracle termination gap 측정.
3. **다음 주:** survival probe 및 delayed commitment 비교.
4. **보조 저비용 트랙:** ReferenceGuard의 reference sweep은 GPU 여유가 적을 때 병렬로 시작할 수 있다.

## 근거 상태

- 수치와 제한은 arXiv 원문 및 연결된 공식 코드·데이터 페이지에서 확인했다.
- MOTIP2, One-Shot Adaptive Segmentation, Ledger, TouchScale은 원문에서 즉시 실행 가능한 공식 code artifact를 확인하지 못했으므로 재현 완료로 표현하지 않았다.
- HeiCo-FOCUS와 TouchScale은 공개 예고 상태가 포함되어 있어 실제 download·license 확인 전 완전 재현 가능으로 분류하지 않았다.
- proposal 점수는 실측치가 아니라 실행 우선순위를 위한 판단이다.
