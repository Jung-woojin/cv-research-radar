## 1. NVIDIA PAI-AV — public-board 종료와 final ranking을 혼동하지 않기

**[확인된 사실]** 공식 challenge 페이지는 2026-10-31을 submission deadline 및 public leaderboard close로, 2026-11-15를 final results release 예정일로 구분한다. 날짜는 tentative라고도 명시한다. 따라서 11월 5일에는 새 final ranking을 주장할 근거가 없다.  
출처: https://huggingface.co/spaces/nvidia/PhysicalAI-AV-OOD-Reasoning-Challenge-2026/blob/main/index.html

**[해석]** 제출 마감 뒤의 public snapshot은 final evaluation, 검증, award decision과 같은 이벤트가 아니다. 모델 간 현재 순위를 논문 표의 확정 성능으로 옮기는 것은 **not strictly apples-to-apples**다.

**진단 → 가설 → 최소 실험**
- 진단: reasoning track의 multi-rollout top-1은 평균적인 policy quality보다 best-of-N 탐색을 크게 반영할 수 있다.
- 가설: top-1, top-k, rollout mean, 비용/clip을 함께 보고하면 탐색 이득과 일관성을 분리할 수 있다.
- 최소 실험: 공개 validation 형식에서 같은 모델·동일 총 token budget으로 1/3/6 rollout을 실행하고 top-1, mean, variance, latency/clip을 기록한다. 실제 challenge score를 재현했다고 주장하지 않는다.

## 2. PAI-AV reasoning labels — validation과 held-out test를 분리하는 것이 오늘의 비교 조건

**[확인된 사실]** NVIDIA의 dataset card는 OOD driving reasoning labels를 train 1,450 clips·1,728 labels, val 290 clips·349 labels로 제공하며, test는 held out 및 OOD Benchmark Challenge용으로 예약했다고 명시한다. labels는 human-in-the-loop quality-control로 OOD validity와 temporal alignment를 검증했다고 설명한다.  
출처: https://huggingface.co/datasets/nvidia/PhysicalAI-Autonomous-Vehicles/blob/main/README.md

**[저자/운영자 설명]** card의 human-verified·temporal alignment 설명은 dataset 제작자의 설명이며, 특정 model의 generalization 보장은 아니다.

**비교 조건**: 공개 val에서의 reasoning score와 held-out test/final challenge rank는 같은 수치가 아니다. rollout 수, judge version, output schema, clip preprocessing이 다르면 **not strictly apples-to-apples**다.

**진단 → 가설 → 최소 실험**
- 진단: action-grounded chain-of-causation에서 텍스트 정답만 맞아도 시간적으로 잘못된 frame을 근거로 삼을 수 있다.
- 가설: answer score와 keyframe/evidence alignment를 분리하면 language-only shortcut과 visual-temporal reasoning을 구분할 수 있다.
- 최소 실험: val 50 clips에서 answer-only prompt와 keyframe citation prompt를 비교해 정답·cited-frame overlap·abstention·latency를 함께 측정한다.

## 3. Fixed-resolution VLM runtime support — 호환성 변경은 성능 표가 아니다

**[확인된 사실]** ONNX Runtime GenAI 공식 PR 목록에는 11월 2일 “fixed-resolution vision-language models를 위한 llava model type 추가” PR이 열려 있다. 목록은 score, input preprocessing parity, evaluator revision, 동일 task 조건의 전후 결과를 제공하지 않는다.  
출처: https://github.com/microsoft/onnxruntime-genai/pulls

**해석**: 이 변화는 deployment path가 새 모델 형식을 처리할 수 있게 되는 compatibility signal이다. 정확도 또는 throughput improvement로 기록할 수 없으며, 다른 VLM benchmark 표와 **not strictly apples-to-apples**다.

**진단 → 가설 → 최소 실험**
- 진단: fixed input resolution의 letterbox/crop 정책은 특히 작은 text·표 cell·tiny object에서 evaluation result를 바꿀 수 있다.
- 가설: resolution 자체보다 aspect-ratio policy와 evidence region 보존 여부가 answer variance를 설명할 수 있다.
- 최소 실험: 문서·small-object 질문 각 100개에서 native resize, letterbox, center crop을 같은 model/runtime·same decoding으로 비교한다. exact accuracy, evidence-cell/box hit, latency, peak memory를 분리한다.

## 4. System One Bench — 새 점수 없이 유지되는 protocol boundary

**[확인된 사실]** 전일 다시 확인한 공식 저장소는 Vision Track의 frozen data, data_lock.py hash, EXIF 회전 후 resize envelope, 동일 request shape 조건을 설명한다. 이번 창에는 이 조건을 바꾸는 새 revision 또는 같은 조건의 새 board score를 확인하지 못했다.  
출처: https://github.com/alilibx/system-one-bench

**해석**: 업데이트가 없다는 것은 모델 성능이 정체됐다는 뜻이 아니라, 오늘 보고할 검증 가능한 protocol-consistent movement가 없다는 뜻이다.

## 오늘의 benchmark signal 3개

1. **마감/leaderboard close/final result release는 서로 다른 benchmark 이벤트다.**
2. **공개 validation과 held-out test는 label 수가 비슷해 보여도 합산하거나 대체할 수 없다.**
3. **VLM runtime compatibility PR은 performance claim이 아니라 input-policy를 재검증해야 하는 신호다.**

## 내 연구에 바로 연결되는 포인트

VLM·maritime·UAV·small-object 실험 manifest에 split, evaluator/judge revision, rollout aggregation, input resolution + aspect-ratio policy, evidence-frame/region rule, runtime version을 함께 남긴다. 우선 공개 PAI-AV validation 50 clips 또는 자체 문서 200개에서 answer 정확도와 evidence alignment를 분리해, 점수가 올랐지만 실제 근거가 보존됐는가를 먼저 확인한다.
