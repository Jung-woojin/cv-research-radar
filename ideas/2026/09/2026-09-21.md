# 후보 1. Temporal Evidence Accumulation for RGB Tiny-Object Detection

## 1) 문제 정의
Tiny-object detection은 대부분 single-frame spatial problem으로 다뤄진다.

하지만 멀리 있는 UAV/선박은 한 frame에서는 threshold 아래의 약한 response만 남더라도 여러 frame에서 일관된 evidence가 반복될 수 있다.

PointEvent가 event domain에서 보여준 질문을 RGB video로 옮기면:

> **tiny object가 없는 것이 아니라 시간에 걸쳐 약하게 흩어져 있는 것은 아닌가?**

## 2) 기존 연구의 빈틈
기존 video detection은 보통:
- dense feature aggregation
- detect first → track later

형태다.

문제는 tiny object가 detection threshold를 넘기기 전에 버려진다는 것.

## 3) 핵심 가설
```
single-frame score < threshold
but
temporally persistent weak evidence
→ recoverable detection
```

## 4) 제안 구조
가칭 **TEA — Temporal Evidence Accumulator**

```
Frame t
  ↓
Backbone + FPN
  ↓
P2/P3 low-threshold candidate sampler
  ↓
candidate token
[x,y,w,h,score,ROI feature,motion]
  ↓
Temporal Order + Spatial-Motion Order
  ↓
SSM / GRU
  ↓
Evidence Gate
  ↓
score / box residual refinement
  ↓
NMS
```

핵심은 **NMS 이전의 low-confidence evidence**를 살리는 것.

## 5) Baseline
- YOLO / D-FINE frame-only
- P2 detector
- EMA
- ROI average
- ConvLSTM
- TSM
- Proposal Transformer
- single-order SSM
- dual-order
- detect→ByteTrack

특히 EMA baseline이 중요.

## 6) Dataset / Metric
- UAVDT
- VisDrone video/MOT
- HARD
- maritime CCTV external validation

Metric:
- AP50-95
- APsmall
- Recallsmall
- Low-confidence Recovery Rate
- false alarms/min
- temporal continuity
- latency / memory / FLOPs

## 7) 필수 ablation
- P2 vs P3
- pre-NMS vs post-NMS
- candidate threshold
- top-K
- 2/4/8/16 frames
- timestamp order
- spatial-motion order
- dual order
- SSM vs GRU vs Transformer vs EMA
- camera motion compensation
- score-only vs score+box

## 8) 실패 모드
- camera motion이 false evidence를 누적
- static tiny object에는 motion cue가 약함
- EMA가 SSM과 비슷하게 잘 될 가능성

EMA가 비슷하게 좋다면:
> sophisticated temporal model보다 **weak-candidate survival 자체**가 핵심이었다

는 negative finding으로 전환 가능.

## 9) Novelty 방어
단순 “PointEvent를 RGB로 옮기고 Mamba 붙임”이면 약하다.

논문의 중심은:
> **Detect-then-track → Evidence-before-detection**

으로 바뀌어야 한다.

## 10) MVP
- Week 1: pre-NMS candidate hook
- Week 2: candidate association + EMA
- Week 3: oracle temporal pooling
- Week 4: GRU/SSM
- Week 5: dual-order
- Week 6: cross-dataset
- Week 7: camera-motion / latency
- Week 8: ablation / paper

GO/KILL:
oracle temporal pooling이 recall을 충분히 못 올리면 접는다.

## 11) Contribution
1. RGB tiny-object detection을 weak temporal evidence accumulation 문제로 정식화
2. sparse pre-NMS temporal evidence module
3. spatial high-resolution vs temporal evidence trade-off 분석

## 12) 제목
- **Weak in One Frame, Strong Across Time: Temporal Evidence Accumulation for Tiny Object Detection**
- **Before Detection: Recovering Tiny Objects by Sparse Temporal Evidence Propagation**
- **Temporal Evidence Is a Feature**

## 평가
- Novelty: 4.6/5
- Feasibility: 4.8/5

# 후보 2. Frequency-Aware Prompt Calibration for Robust VLM under Fog

## 1) 문제 정의
최근 연구는 prompt wording이 language reasoning만 바꾸는 것이 아니라 **cross-modal visual attention의 spatial-frequency support** 자체를 바꿀 수 있음을 보여준다.

새 질문:
> 실제 fog/haze/low-light에서 degradation spectrum을 보고 prompt/readout을 조절하면 robustness가 올라가는가?

## 2) 기존 연구의 빈틈
기존은:
- image robustness
- prompt engineering

을 분리해서 본다.

하지만 실제 VLM은:
```
(image, question) → answer
```
이고 question이 visual readout을 바꿀 수 있다.

## 3) 핵심 가설
```
risk ∝ overlap(
  prompt-conditioned attention spectrum,
  corruption spectrum
)
```

## 4) 구조
가칭 **SpecPrompt**

```
Image
 └─ Degradation Spectrum Estimator
Question
 └─ Prompt Bank
      ↓
Spectral Compatibility
      ↓
Prompt Selector
      ↓
Frozen VLM
      ↓
Answer + Grounding
```

처음엔 training-free selector로 시작.

## 5) Baseline
- original prompt
- verbose prompt
- random paraphrase
- prompt ensemble
- CoT
- dehazing + prompt
- denoise preprocessing
- soft prompt
- proposed spectral selector

## 6) Dataset
- GQA / CLEVR mechanism replication
- RefCOCO / RefCOCOg + corruption
- adverse-weather imagery
- maritime VQA / CCTV

Metric:
- answer accuracy
- grounding IoU
- ECE
- paraphrase variance
- answer drift
- spectral overlap correlation

## 7) Ablation
- prompt length
- semantics fixed / wording varied
- filler tokens
- low/high-frequency corruption
- fog severity
- question granularity
- model family
- answer-only vs grounding

## 8) 실패 모드
Real fog는 단순 frequency degradation이 아니므로 synthetic에서는 correlation이 나오지만 real fog에서는 깨질 수 있음.

그 경우에도:
> synthetic corruption robustness와 atmospheric degradation은 mechanism이 다르다

는 좋은 negative finding.

## 9) Novelty 방어
“긴 prompt가 좋다”는 paper로 보이면 약함.

필수:
- frequency causal intervention
- semantics-matched control
- real weather
- grounding
- cross-model

## 10) MVP
1. 기존 frequency finding replication
2. fog/blur/contrast별 overlap
3. prompt bank
4. simple selector
5. grounding
6. real fog
7. cross-model
8. causal intervention

## Contribution
1. Real degradation에서 prompt-conditioned visual frequency selection 검증
2. training-free spectral prompt calibration
3. answer + grounding robustness를 frequency mechanism과 연결

## 제목
- **When Words Change What Vision Sees: Spectral Prompt Calibration for Robust VLMs**
- **Prompting the Right Frequencies**
- **SpecPrompt**

## 평가
- Novelty: 4.8/5
- Feasibility: 4.2/5
- Compute cost: 2.8/5

# 후보 3. Harm-Aware Selective Test-Time Adaptation for Streaming Detection

## 1) 문제 정의
평균적으로 좋아지는 TTA라도 frame 단위로는 상당한 harm가 생길 수 있다.

Detection에서는 adaptation 전후 output이 unordered box set이라 segmentation보다 harm 진단이 어렵다.

## 2) 핵심 가설
Source boxes와 tentative-adapted boxes 사이 **box-set fragmentation**이 실제 performance degradation을 예측할 수 있다.

## 3) 구조
가칭 **SafeTTA-Det**

```
Frame
 ↓
Source Detector → B0
 ↓
Tentative 1-step adaptation → B1
 ↓
Box Fragmentation Analyzer
 ├ birth/death
 ├ IoU displacement
 ├ class flip
 ├ confidence mass shift
 ├ split/merge
 └ track break
 ↓
Harm Router
 ├ ACCEPT → commit
 └ REJECT → rollback
```

## 4) Baseline
- source only
- BN adaptation
- TENT
- fixed adaptation step
- confidence gating
- entropy gating
- gradient norm
- temporal consistency
- proposed fragmentation
- GT oracle router

## 5) Dataset
- BDD100K weather/time
- SHIFT
- synthetic fog/rain
- maritime clear↔fog

## 6) Metric
- mAP
- APsmall
- ECE
- adaptation latency
- acceptance rate
- Harmed Frame Rate

## 7) Ablation
- fragmentation components
- 1 vs 3 steps
- frame vs clip
- temporal track feature
- calibration size
- cross-domain threshold transfer
- YOLO vs DETR
- reset vs continual
- rollback

## 8) 실패 모드
Detection frame-level mAP noise가 큼.
Confidence calibration이 geometry보다 더 좋은 harm predictor일 수 있음.

그 경우:
> detector TTA harm는 geometry보다 confidence routing에 의해 지배된다

는 finding으로 전환.

## 9) Novelty 방어
단순 segmentation TTA port가 아니라:
- set-valued output geometry
- box fragmentation
- commit/rollback
- temporal track fragmentation
- small-object harm analysis

필수.

## 10) MVP
- Week 1 source/corruption baseline
- Week 2 one-step TTA
- Week 3 frame-wise harm labels
- Week 4 fragmentation correlation
- 이후 router / cross-domain / cross-detector

## 제목
- **Adapt or Abstain: Harm-Aware Test-Time Adaptation for Streaming Object Detection**
- **When Not to Adapt**
- **SafeTTA-Det**

## 평가
- Novelty: 4.4/5
- Feasibility: 4.9/5
- Compute cost: 2.0/5
- Publication potential: 4.5/5

# 이번 주 최우선 추천

## Temporal Evidence Accumulation for RGB Tiny-Object Detection

이유는 4주 안에 매우 명확한 viability test가 가능하기 때문이다.

가장 먼저 할 실험:
> GT trajectory 주변 pre-NMS low-confidence candidate를 oracle로 시간축 aggregate했을 때 APsmall / recall이 얼마나 회복되는가?

회복 폭이 크면 연구 bottleneck이 실재한다.
작으면 fancy temporal architecture를 만들기 전에 바로 접을 수 있다.

이번 주 핵심 질문은:
> **What if the evidence is not missing, but fragmented across time?**
