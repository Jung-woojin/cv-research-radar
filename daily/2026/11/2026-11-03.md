## 2) CV / DL-CV 핵심

### ReuScope: Auditing Data Reuse and Evaluation Sensitivity in Capsule Vision 2024
- **상태/출처:** 2026-10-30 v1, [arXiv](https://arxiv.org/abs/2610.41835), 코드·데이터 링크가 있다.
- **사실:** Capsule Vision 2024 public training–validation 경계에서 byte-identical file과 Kvasir-Capsule recording의 cross-split overlap을 관측했다고 보고한다.
- **저자 주장:** training row/near-match 5개 제거 후 public-validation balanced accuracy가 82.5%→61.2%였으나 다른 source validation에서는 제거가 1.38 point 개선이었다.
- **진단:** data reuse 관측과 leakage-induced inflation 추정은 다르다. 저자도 전자를 후자의 양으로 해석하지 않는다.
- **최소 실험:** exact hash, embedding near-match, source/video/patient group overlap 표를 만들고 random/source-held-out split을 5 seed로 비교한다.

### NVIDIA ModelOpt 0.48.0 — BEVFormer ONNX PTQ
- **출처:** 2026-11-02 [official release](https://github.com/NVIDIA/Model-Optimizer/releases/tag/0.48.0).
- **사실:** temporal calibration data generation, INT8/FP8 quantization, TensorRT engine build, nuScenes accuracy evaluation을 포함하는 BEVFormer ONNX PTQ 예제를 추가했다.
- **주의:** 일부 vLLM mode/CUDA graph 조합은 지원하지 않는다. 엔진·드라이버·전처리 조건 없이 지표를 비교할 수 없다.
- **최소 실험:** 같은 ONNX input/subset에서 FP16·INT8·FP8을 30회 warm-up+100회 반복해 p50/p95, peak VRAM, accuracy를 한 표로 기록한다.

### OpenCV 5.x와 System One Bench
- **출처:** [OpenCV 5.x commit](https://github.com/opencv/opencv/commit/739c1e60fdbedfe84b3236e63322d9d6437a1a1b), [System One Bench](https://github.com/alilibx/system-one-bench).
- **사실:** OpenCV 5.x는 CV_Bool의 bitwise_not 의미를 logical NOT로 고치는 PR을 병합했다. System One Bench는 frozen data/identical request에서 accuracy, calibration, latency, cost를 비교한다고 설명한다.
- **최소 실험:** bool/uint8 mask와 threshold dtype regression test를 고정하고, image case 20개를 같은 요청으로 두 번 실행해 accuracy·latency·cost 변동을 함께 기록한다.

## 3) VLM / Multimodal / Video 핵심

### Open-Weight MLLMs Cannot Compare What They Cannot Name
- **출처:** 2026-10-30 v1, [arXiv](https://arxiv.org/abs/2610.41841), [official code](https://github.com/kreshuklab/Open-Weight-MLLMs-Cannot-Compare-What-They-Cannot-Name).
- **사실:** synthetic ant images에서 open-weight MLLM이 단순 신체 부위 크기 비교를 부위별로 다르게 실패한다고 보고한다.
- **저자 주장:** 인식하지 못하는 구조가 recognizable concept와 연관되어 grounding·comparison이 함께 손상된다.
- **최소 실험:** 정확한 이름/가명/무의미 토큰 prompt에서 recognition과 relative-size accuracy의 조건부 상관을 crop/whole image로 나눠 측정한다.

### Think in 360°: Benchmarking and Bootstrapping Panoramic Video Reasoning
- **출처:** 2026-10-30 v1, [arXiv](https://arxiv.org/abs/2610.42082).
- **사실:** PanoVideoBench는 5개 범주·15 question type의 수동 annotation 1,000문항을 제안하며, 11개 모델의 cross-view tracking/sphere-time integration을 약점으로 보고한다.
- **저자 주장:** PanoVideoCoT 13,465 QA-CoT pair 학습 모델이 55.7%, backbone 대비 +12.5 point, 이전 SOTA 대비 +2.6 point를 기록했다.
- **주의/실험:** backbone·data·view sampling이 다르면 strict apples-to-apples가 아니다. 반대 view/다른 시점 evidence 50개에서 view order·frame density를 바꿔 answer/evidence localization을 함께 채점한다.

### 늦게 발견한 비교 맥락
- [AdaGround](https://arxiv.org/abs/2610.36874): target-size adaptive zoom과 verifier로 Qwen3-VL에서 +7.4~20.6 point를 보고한다. fixed/adaptive/verifier의 accuracy·token·abstention precision을 함께 측정할 만하다.
- [Video RLVR shortcut amplification](https://arxiv.org/abs/2610.37211): RLVR이 visual evidence보다 text-prior compression을 강화할 수 있다고 주장한다. relevant/irrelevant frame deletion 전후 entropy가 최소 검증이다.
- [Discrete visual tokens](https://arxiv.org/abs/2610.37662): effective bit budget이 중요하다고 주장한다. bit budget만 바꾼 OCR·fine-grained recognition·captioning 분리가 필요하다.

## 5) 중요한 Finding 3개
1. **평가 shift는 단일 숫자가 아니다.** source removal과 evaluation population replacement를 분리해야 한다.
2. **VLM visual reasoning은 grounding에 조건부다.** naming confidence와 comparison을 분해해야 한다.
3. **동적 비전 추론은 evidence path가 핵심이다.** answer-only 평가는 sphere-time/faithfulness failure를 놓친다.

## 8) Top 1 미니 리뷰 — ReuScope
가치는 누수 발견보다 발견 뒤 주장 가능한 범위를 정한 데 있다. shared recording은 관측 사실이지만 source 제거 뒤 score 하락은 data dependency 또는 distribution sensitivity일 수 있다. 다른 source validation에서 방향이 바뀐 결과는 overlap만으로 inflation 크기를 말할 수 없음을 보인다. hash exact match → embedding near-match → source/video/patient group split 순서의 provenance 감사가 필요하다.

## 9) 후속 연구 씨앗
### A. Source-aware overlap stress test
- **가설:** random split 이득은 source-held-out에서 축소되고 축소량은 near-duplicate density와 관계가 있다.
- **MVP/판정:** random/source-held-out/near-duplicate-removed split을 5 seed 비교한다. source-held-out에서만 붕괴하면 provenance/coverage 병목이라는 negative result도 유의미하다.

### B. Name-ablation visual comparison
- **가설:** object label을 가명으로 바꾸면 comparison accuracy가 recognition confidence와 함께 하락한다.
- **MVP/판정:** natural/pseudo/no-name과 crop/whole image를 교차한다. label effect가 재현되면 grounding bottleneck이다.

### C. Evidence-path reward for video RLVR
- **가설:** answer reward에 evidence localization consistency를 더하면 text-prior shortcut이 줄어든다.
- **MVP/판정:** original/relevant-frame-deleted/irrelevant-frame-deleted 조건을 비교한다. relevant deletion에서만 confidence가 줄면 GO, 모든 deletion에 같은 반응이면 KILL한다.
