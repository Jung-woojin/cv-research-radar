## 1. GenOlympiad — frontier image model 평가를 고난도 prompt와 evidence-grounded grading으로 이동

### 무엇이 실제로 바뀌었나

GenOlympiad는 일반적인 미학 선호나 쉬운 prompt 평균 대신, 현재 frontier text-to-image 모델이 실패하도록 설계한 801개 prompt를 9개 capability axis로 분리한다. 각 task는 easy question을 먼저 통과해야 hard question을 채점하며, counting·geometry 같은 항목은 judge VLM이 선·box를 그린 뒤 deterministic program이 답을 계산한다.

### 확인된 사실

공식 저장소는 text fidelity 83개, counterfactual instruction 95개, symbolic systems 83개, world knowledge 82개, physical consistency 92개, quantitative precision 87개, spatial/3D reasoning 83개, latent computation 109개, long-range consistency 87개로 구성됐다고 명시한다. strict score는 모든 hard question을 통과한 task 비율이고, relaxed score는 hard question 가중치 합의 평균이다.

공식 leaderboard에서 closed-source T2I 중 Nano Banana Pro의 strict overall은 23.9, GPT-Image-2.5는 14.9, Seedream 5.0 Pro는 15.1이다. HTML을 그리는 coding model은 GPT-6 Astra 40.5, GPT-5.6 Sol 37.5로 더 높다. 이는 image generator와 HTML renderer의 생성 공간·tooling이 달라 직접적인 모델 우열로 읽을 수 없다.

공식 코드와 801개 task가 공개돼 있지만 Gemini 2.5 Flash judge API가 필수다. judge가 evidence를 grounding하지 못하면 task는 0점이 아니라 **withheld**되어 axis와 overall 계산에서 제외된다. 긴 prompt가 context limit을 넘는 일부 open-weight model은 약 20개 task가 생성·채점되지 않았다고 논문이 밝힌다.

### 저자 주장

저자들은 strict task success가 frontier 모델 사이의 capability boundary를 더 잘 분리하고, grounding helper가 단순 VLM judge보다 counting·spatial grading을 안정화한다고 주장한다.

### 같은 조건 비교인가

같은 task·원본 prompt·image size·judge version·withheld rule을 사용한 T2I 행끼리는 비교 가능하다. coding model, prompt rewriting 후 GPT-Image-2.5, native T2I는 generation interface가 달라 `not strictly apples-to-apples`다. 모델별 denominator가 withheld와 not-generated task 때문에 달라질 수 있으므로 overall score만 보고 순위를 고정하면 안 된다.

### 진단 → 가설 → 최소 실험

- **진단:** 어려운 small-object counting이나 spatial relation에서 judge가 근거를 찾지 못한 sample을 제외하면, 실제로 더 모호한 출력을 만드는 모델이 불리하거나 유리해질 수 있다.
- **가설:** withheld를 실패로 보는 lower bound와 제외하는 conditional score를 함께 보고하면 모델 순위의 안정성을 더 정확히 판단할 수 있다.
- **최소 실험:** 100개 task에 대해 strict/relaxed score, withheld rate, not-generated rate를 함께 계산하고, withheld=0점과 withheld=제외 두 순위를 비교한다.
- **GO/KILL:** pairwise ordering의 10% 이상이 denominator 처리에 따라 바뀌면 dual score를 정식 protocol로 유지한다.

### 판정

평가를 주관적 Elo에서 시각적으로 검증 가능한 capability stress test로 옮긴 점은 강한 변화다. 다만 현재 leaderboard는 **모델이 생성한 것**뿐 아니라 **judge가 채점할 수 있었던 것**에도 조건부이므로 coverage-adjusted score가 필요하다.

- 공식 프로젝트: https://genolympiad.github.io/
- 공식 코드·leaderboard: https://github.com/GenOlympiad/GenOlympiad

## 2. PVBench — video 물리성을 semantic judge에서 object-state 측정으로 이동

### 무엇이 실제로 바뀌었나

PVBench는 “영상이 물리적으로 그럴듯해 보이는가”를 VLM이 총평하는 대신, 600개 prompt를 46개 dimension과 7개 domain으로 나눈다. 25개 physical dimension은 6D pose, metric scale, surface normal, trajectory, kinematics, conservation-law residual처럼 계산 가능한 object-level quantity로 평가한다. T2V와 I2V를 모두 지원하며 prompt의 30%는 robot arm·humanoid·quadruped·multi-agent 같은 embodied agent를 포함한다.

### 확인된 사실

수치 quantity는 합리적 범위를 기준으로 수동 설정한 threshold를 통해 1~5점으로 변환한 뒤 percentile scale로 mapping한다. dimension별 평균을 먼저 계산하고 domain·overall은 dimension을 동일 가중 평균해 sample 수가 많은 dimension이 총점을 지배하지 않도록 한다.

저자들은 6개 모델의 T2V·I2V 설정을 평가했다. 예를 들어 T2V에서 Seedance 2.5는 semantic layer의 CSF 92.2, BC 83.3이지만 physical layer의 mechanical consistency는 30.0이다. 이 수치는 서로 다른 dimension의 percentile이므로 하나의 절대 물리 정확도로 해석하면 안 된다.

human alignment 검증은 dimension별 5개 prompt, 3개 T2V model, sample당 10명 평가를 사용한다. 저자 보고에서 numerical physical score는 global entropy 2.25, dimension variance 1.05, human score와 Spearman 0.84였고 MLLM score는 각각 1.12, 0.14, 0.14였다. MLLM score의 73.7%가 maximum에 포화됐다. appendix의 25개 physical dimension 전체 집계는 Spearman 0.772, Kendall 0.643이며 detection·tracking·long-term consistency가 필요한 dimension은 낮은 상관을 보였다.

### 저자 주장

저자들은 물리성 평가의 단위를 holistic semantic judgment에서 observable state와 law residual로 바꾸면 model 간 차이와 실패 원인을 더 잘 분리할 수 있다고 주장한다.

### 같은 조건 비교인가

동일 prompt·generation mode·evaluator threshold 안의 모델 비교는 가능하다. T2V와 I2V, semantic layer와 physical layer, 서로 다른 percentile dimension을 단순 평균해 “물리적으로 더 좋다”고 결론내리면 안 된다. object detector나 tracker가 실패해 sample이 skip되면 generator failure와 evaluator coverage가 섞이므로 coverage도 함께 봐야 한다.

arXiv abstract는 benchmark·prompt·calibration protocol 공개를 약속하지만, 확인 시 arXiv landing page에는 별도 공식 code/data URL이 연결되지 않았다. 따라서 이번 보고서는 공개 paper의 protocol을 확인했으나 runnable release를 확인하지 못했다.

### 진단 → 가설 → 최소 실험

- **진단:** 해양 video generation에서 파도·선박의 움직임을 VLM 총평만으로 채점하면 appearance quality가 kinematic failure를 가린다.
- **가설:** 선박 중심·heading·속도와 horizon 안정성을 수치화하면 semantic score가 높은데 물리적으로 실패한 영상을 분리할 수 있다.
- **최소 실험:** 50개 생성 영상에 detector/tracker 기반 heading change, acceleration jerk, waterline drift를 계산하고, 5인 human ranking과 상관 및 evaluator coverage를 보고한다.
- **GO/KILL:** 수치 metric의 human Spearman이 0.6 이상이고 evaluable coverage가 80% 이상이면 확대한다. coverage가 낮으면 generator 비교 전에 detector failure를 개선한다.

### 판정

VLM judge saturation을 실제 수치로 보여준 강한 metric 변화다. 핵심은 overall score 상승보다 **물리 상태 측정과 evaluator coverage를 동시에 공개하는 것**이다.

- 공식 원문: https://arxiv.org/abs/2610.26711
- 공식 HTML 원문: https://arxiv.org/html/2610.26711v1

## 3. One Fact, Many Places — single-gold retrieval·citation 평가가 정답 근거를 오답으로 처리

### 무엇이 실제로 바뀌었나

long visual document benchmark는 보통 질문마다 하나의 gold page·region만 둔다. 이 연구는 같은 fact가 chart, 본문, summary에 반복되는 경우를 모두 annotation하고, retrieval recall·citation attribution·masking 평가를 set-valued evidence 기준으로 다시 계산했다.

### 확인된 사실

저자들은 MMLongBench-Doc와 MMDocRAG에서 420개 질문을 두 명의 독립 reviewer로 검토했다. MMLongBench-Doc test의 19.5%에는 gold 밖 strict copy가 있었고, MMDocRAG 질문의 28%에서는 non-gold candidate 하나만으로 필요한 fact를 뒷받침할 수 있었다.

copy가 있는 질문에서 text·visual retriever의 page recall@1은 single-gold 채점 때문에 13~24 points 낮게 측정됐다. equivalent evidence를 credit하면 MMDocRAG 65개 경쟁 시스템 pairwise ordering의 11%가 뒤집혔다. gold region만 mask했을 때 네 모델의 correct answer 41~56%가 살아남았지만, annotation된 모든 instance를 mask하면 사라졌다. 자동 copy set masking은 같은 granularity에서 완전 annotation masking과의 gap 78%를 닫았다.

논문은 code·data를 GitHub 링크 대신 arXiv ancillary `code-and-data.7z`로 공개했다. 이는 공개 artifact가 존재함을 확인한 것이며, 이번 실행에서 archive를 내려받아 evaluator를 실행하지는 않았다.

### 저자 주장

저자들은 single-gold scoring이 올바른 alternative evidence를 retrieval miss와 wrong citation으로 만들고, gold-only masking이 모델의 shortcut 사용을 과소평가한다고 주장한다.

### 같은 조건 비교인가

single-gold recall과 redundancy-aware recall은 정답 집합 자체가 다르므로 수치 차이를 retriever 개선으로 해석하면 안 된다. ranking reversal은 동일 65개 시스템의 scorer를 바꾼 결과다. 자동 key-string mask는 완전 annotation보다 3배 넓은 면적을 가려 answer drop을 과장할 수 있으므로 동일 masking area에서 비교해야 한다.

### 진단 → 가설 → 최소 실험

- **진단:** 연구 보고서·해양 관측 문서의 같은 수치가 table, chart, caption에 반복되면 현재 citation metric이 올바른 근거를 틀렸다고 판정할 수 있다.
- **가설:** page 하나가 아니라 evidence equivalence class를 gold로 두면 retrieval과 answer correctness의 상관이 높아지고 false-negative citation이 줄어든다.
- **최소 실험:** 100개 문서 QA에서 질문당 모든 독립 evidence location을 이중 annotation하고 single-gold recall@k, set recall@k, citation precision, all-copy masking survival을 함께 계산한다.
- **GO/KILL:** 시스템 ordering의 5% 이상이 뒤집히거나 citation false negative가 10% 이상이면 set-valued gold를 유지한다.

### 판정

새 모델 SOTA가 아니라 **gold annotation ontology가 leaderboard를 바꾸는 변화**다. document VQA와 video QA 모두 반복 근거가 흔하므로 바로 적용할 가치가 높다.

- 공식 원문: https://arxiv.org/abs/2610.26401
- 공식 ancillary README: https://arxiv.org/src/2610.26401/anc/README.txt
- 공식 code/data archive: https://arxiv.org/src/2610.26401/anc/code-and-data.7z

## 4. StreamRPS — streaming radar panoptic 평가에서 sector partition이 PQ를 부풀리는 artifact 확인

### 무엇이 실제로 바뀌었나

StreamRPS는 spinning FMCW radar를 full scan뿐 아니라 4·8·16·32 sector streaming 조건으로 나눠 semantic mIoU와 panoptic PQ/SQ/RQ를 평가한다. LiDAR scene completion으로 dense auto-label을 만들고, SAX의 radar scan 100개에는 manual annotation을 추가했다.

### 확인된 사실

SAX는 20,875 radar scan, Boreas subset은 16,450 scan이며 chronological·geographical region을 분리한 70/15/15 split을 사용한다. FPS는 RTX 2080 Ti에서 측정한다. 저자 보고에서 StreamRPS는 4-sector 조건에서 400 FPS 이상으로 sector를 처리하고, 4 Hz sensor에 대해 최대 128 Hz prediction rate를 낸다.

semantic segmentation은 sector가 작아질수록 전반적으로 하락했다. SAX와 Boreas 모두 small/thin object인 two-wheeled vehicle, person, pole은 10 mIoU 미만이었고, class reweighting만으로 해결되지 않았다. 반면 panoptic PQ는 여러 method에서 full scan보다 4-sector가 더 높아졌다. 저자들은 동일 stuff region이 sector 경계로 작은 instance처럼 나뉘어 correct match가 쉬워지는 **metric artifact**라고 설명한다.

StreamRPS는 Boreas 4-sector에서 PQ 23.31로 Mask2Former 21.53보다 높고, SAX 4-sector에서 15.43으로 Mask2Former 14.40보다 높다. 그러나 SAX full scan에서는 StreamRPS PQ 13.37이 Mask2Former 15.45보다 낮다. 또한 full-scan semantic ablation에서 temporal frame을 단순 stack한 값은 30.84로 single frame 30.88보다 개선되지 않았고, radar stem·azimuth roll·rectangular patch·axial attention을 더해 34.35가 됐다.

### 저자 주장

저자들은 radar-specific polar inductive bias와 streaming sector 처리로 실시간성과 정확도를 함께 얻고, manual SAX label로 auto-label pipeline을 독립 평가할 수 있다고 주장한다.

### 같은 조건 비교인가

같은 dataset·sector·split·hardware 안의 method 비교는 가능하다. full scan과 4-sector PQ는 instance partition이 달라 직접적인 품질 향상 비교가 아니다. 400+ sector FPS와 128 Hz full prediction rate도 단위가 다르다. Mask2Former·SegFormer는 implementation의 최소 spatial dimension 때문에 16/32 sector에서 제외돼 모든 sector의 완전한 leaderboard가 아니다.

### 진단 → 가설 → 최소 실험

- **진단:** 항만 panorama를 tile로 나눠 segmentation하면 stuff region의 matching 단위가 작아져 PQ가 실제 경계 품질보다 좋아질 수 있다.
- **가설:** global instance/stuff ID로 tile을 다시 stitch한 뒤 PQ를 계산하면 sector 증가에 따른 가짜 개선이 사라진다.
- **최소 실험:** 같은 100개 panorama를 1·4·8 tile로 inference하고 local PQ와 stitched-global PQ, seam IoU, small-object recall을 함께 측정한다.
- **GO/KILL:** local PQ는 오르지만 global PQ나 seam IoU가 떨어지면 local PQ를 주 metric에서 제외한다.

### 판정

adverse-weather radar와 해양 panorama 모두에 직접 연결되는 평가 변화다. 속도보다 중요한 신호는 **partition이 metric의 matching problem 자체를 바꾼다**는 점이다.

- 공식 원문: https://arxiv.org/abs/2610.26816
- 공식 HTML 원문: https://arxiv.org/html/2610.26816v1

## 5. Pathology VLM controlled probes — 높은 VQA accuracy와 visual grounding 분리

### 무엇이 실제로 바뀌었나

이 연구는 pathology VLM을 개발자별 test set의 self-reported score로 비교하는 대신, 공개 checkpoint와 public data에서 입력 하나만 바꾸는 네 controlled probe를 사용한다. 특히 slide 제공, slide 제거, mismatched slide, option 위치 변경을 분리해 visual evidence 의존성을 측정한다.

### 확인된 사실

SlideBench-VQA(TCGA)에서 SlideChat은 slide가 있을 때 74.82%, 없을 때 74.41%였다. SlideChat의 language backbone인 Qwen2.5-7B는 slide 없이 43.52%였고, letter-position baseline은 40.7%였다. 저자 해석으로 약 31 points는 slide evidence가 아니라 instruction-tuning data의 regularity에서 왔다. paraphrase는 aggregate accuracy를 거의 바꾸지 않지만 individual answer의 8~23%를 뒤집었다.

report text의 frozen embedding을 slide embedding에 추가하면 1,633명 TCGA patient에서 progression-free interval pooled C-index가 0.019, overall survival은 0.016 올랐고, stage statement를 다시 넣어도 추가 이득은 없었다. 반대로 feature와 pooling을 고정한 lung·renal subtype classification에서는 zero-shot prompt와 supervised linear probe가 통계적으로 구분되지 않았다.

### 저자 주장

저자들은 language가 일부 prognosis에는 좁지만 실제 신호를 더하지만, slide-level QA와 prompt-based classification의 많은 headline score는 visual grounding이나 language reasoning의 기여로 귀속할 수 없다고 주장한다.

### 같은 조건 비교인가

같은 checkpoint에서 slide 유무만 바꾼 ablation은 직접 비교 가능하다. SlideChat, WSI-LLaVA, language backbone 간 절대 accuracy는 training data·architecture가 달라 순위로 해석하면 안 된다. self-reported agentic navigation gain은 동일 protocol로 재평가하지 않았으므로 controlled result와 합칠 수 없다.

### 진단 → 가설 → 최소 실험

- **진단:** 해양 VQA도 answer-option regularity와 domain prior로 높은 정확도를 내면서 영상·region을 보지 않을 수 있다.
- **가설:** image-ablated와 mismatched-image baseline을 추가하면 실제 visual grounding gain이 headline accuracy보다 훨씬 작게 나타난다.
- **최소 실험:** 300개 항만 VQA 문항에 correct image, blank image, shuffled image, evidence crop 네 조건과 option permutation을 적용한다. accuracy, answer flip, grounding overlap을 분리한다.
- **GO/KILL:** correct-image와 blank-image gap이 3%p 미만이거나 option permutation flip이 10%를 넘으면 dataset을 재설계한다.

### 판정

VQA benchmark가 반드시 가져야 할 negative control을 정량화했다. 앞으로 “정답률”은 image-ablated gap, mismatch gap, option-position robustness 없이는 grounding 성능으로 해석하지 않는다.

## Apples-to-apples 체크표

| 항목 | 직접 비교 가능한 범위 | 직접 비교하면 안 되는 범위 | 현재 artifact 상태 |
|---|---|---|---|
| GenOlympiad | 동일 prompt·judge·withheld rule의 T2I 모델 | coding HTML과 native T2I, denominator가 다른 overall | 801 tasks·evaluator·leaderboard 공개; 외부 judge API 필요 |
| PVBench | 동일 mode·prompt·dimension·threshold의 generator | T2V와 I2V, semantic/physical percentile 단순 합산 | paper protocol 확인; 별도 runnable release URL 미확인 |
| One Fact, Many Places | 같은 시스템의 single-gold vs evidence-set scorer | scorer 변경을 retriever 성능 향상으로 해석 | annotation·code/data arXiv ancillary 공개 |
| StreamRPS | 같은 dataset·sector·split·hardware의 method | full scan과 sector PQ, sector FPS와 full prediction rate | paper·manual-label protocol 확인; 별도 code URL 미확인 |
| Pathology VLM probes | 같은 checkpoint의 image ablation·mismatch | 서로 다른 model/training data의 절대 accuracy | 공개 checkpoint/data 기반 분석; paper의 controlled results 확인 |

## 오늘의 benchmark signal 3개

1. **coverage와 denominator를 점수 옆에 둔다.** GenOlympiad의 withheld task와 PVBench의 unevaluable object는 제외 방식에 따라 순위를 바꿀 수 있다.
2. **gold는 하나의 위치가 아니라 evidence set일 수 있다.** 반복 근거를 인정하지 않으면 올바른 retrieval과 citation을 오답으로 만든다.
3. **negative control과 partition audit을 기본으로 둔다.** image 없이도 맞히는 VQA와 tile을 쪼갤수록 오르는 PQ는 모델 개선이 아니라 평가 artifact다.

## 내 연구에 바로 연결되는 포인트

- 해무·항만 VQA에 correct/blank/shuffled/crop 4조건을 추가하고 answer accuracy와 region grounding을 분리한다.
- long report와 영상 QA는 page/frame 하나 대신 같은 fact를 독립적으로 지지하는 evidence equivalence class를 annotation한다.
- panorama·streaming segmentation은 local tile PQ와 stitched-global PQ를 동시에 기록하고 seam artifact를 별도 측정한다.
- 생성 영상 평가는 VLM 총점과 함께 선박 trajectory, heading, waterline drift 같은 object-level physical quantity를 계산한다.
- leaderboard에는 score, evaluable coverage, withheld/not-generated count, scorer version을 함께 저장한다.
