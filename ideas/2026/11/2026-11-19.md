## 2. 선별 논문 6편

### P1. TIVS: Mapping the Sensitivity Landscape of Visual Token Transformations in MLLMs

- **공개 이력:** v1 2026-11-15 03:13:43 UTC; v2 11-17 03:16:41 UTC. v2 본문을 확인했다.
- **문제·방법:** frozen MLLM에서 permutation, retention, quantization, 통계적 token replacement를 분리해 검사한다.
- **저자 결과:** POPE 192문항에서 permutation의 평균 정확도 변화는 작지만 개별 예측은 바뀐다. 평균 유지가 문항별 불변성을 뜻하지 않는다.
- **한계:** 소규모 이미지·과제 조건이며 image-cluster CI는 탐색적이고 다중비교 보정이 없다. 공간적 증거 보존과 실제 답변 의존성은 별도 질문이다.
- **공개:** 전용 코드·checkpoint·실험 manifest 배포는 이번 확인에서 확정하지 못했다.
- **연결:** 평균 정확도 대신 correct→wrong과 wrong→correct를 분리하고, 보존된 객체 token만으로 충분한지 진단한다.

출처: [공식 공개 이력](https://arxiv.org/abs/2611.19745), [v2 방법·평가](https://arxiv.org/html/2611.19745v2).

### P2. Event-based object detection under adverse lighting and motion: lessons for construction sites

- **v1:** 2026-11-15 03:17:10 UTC. 확인한 history에는 v1만 있다.
- **문제·방법:** PEOD의 RGB/event detector를 조명·움직임별로 비교하고 pruning·activation patching을 수행한다.
- **저자 결과:** 입력 tile 60% 보존 시 전체 AP는 비교적 유지되지만 작은 객체 recall은 크게 감소한다. §3.5는 작은 box 영역 대부분이 남아도 오류가 발생한다고 보고한다.
- **한계:** 영역의 잔존은 유효 feature의 잔존과 다르다. 입력 마스킹 결과를 실제 sparse-kernel 속도 개선으로 해석할 수 없다.
- **공개:** PEOD 사용은 확인했으나 이 연구의 전용 코드·weight 배포는 확정하지 못했다.
- **연결:** 객체 내부, 국소 문맥, 먼 배경의 기여를 같은 보존 예산에서 분리할 근거다.

출처: [공식 이력](https://arxiv.org/abs/2611.19746), [v1 §3.5–3.6](https://arxiv.org/html/2611.19746v1).

### P3. Oriented Semi-DETR for Semi-Supervised Aerial Object Detection

- **v1:** 2026-11-16 15:09:55 UTC. ICASSP 2027 제출 표기는 채택을 뜻하지 않는다.
- **문제·방법:** 같은 회전 상자의 두 parameter encoding이 loss·matching·GMM filtering을 바꾸는 문제를 swap-aware 규칙으로 교정한다.
- **저자 결과:** DOTA-v2.0 개선과 초기 학습에서 더 큰 matching/filter 변화가 보고된다.

## 3. Proposal A — Evidence Survival Audit

1. **문제·가치:** 압축 후 평균 점수 유지가 시각적 증거 보존을 보장하는가? P1의 예측 이동과 P2의 작은 객체 손실이 출발점이다.
2. **Gap:** token/box가 남는다는 측정과 답변에 필요한 증거가 남는다는 측정을 연결하지 못한다.
3. **가설:** 객체 내부 token 보존율보다 주변 문맥을 포함한 보존 패턴이 harmful flip을 더 잘 설명하는 질문군이 있다.
4. **구조:** frozen vision encoder/projector/decoder → 동일 token 수의 선택 mask → 객체/인접 ring/먼 배경의 factorial intervention → 원본 대비 paired answer audit. 첫 개입은 새 module 없이 selection rule만 변경한다.
5. **Baseline:** full tokens, uniform/random retention, feature-norm top-k, object-only, object+ring, 동일 수의 먼 배경 token 교환. GT box는 진단용 oracle이며 배포 방법으로 주장하지 않는다.
6. **데이터·지표:** COCO 기반 POPE에서 원본 이미지별 분리. accuracy, correct→wrong, wrong→correct, yes bias, 객체 크기별 harmful flip, logit margin, 실제 latency·peak VRAM을 보고한다.
7. **Ablation:** retention budget, ring 폭, projector 전/후, token 제거 대 zero masking, 질문의 존재/관계 유형, object token 수를 고정한 주변 token 교환.
8. **실패 모드:** contextual token에 다른 객체가 들어갈 수 있다. 겹친 객체를 별도 층으로 보고한다. hook·position indexing 오류와 길이 변경 자체의 효과를 통제한다.
9. **Negative result:** random과 ring이 동등하면 문맥 보존 규칙을 폐기한다. 그래도 평균 점수 뒤의 오류 상쇄와 모델별 불변 범위는 남는다.
10. **Novelty 위험·방어:** TIVS·context ablation·token pruning과 중복이 크다. paired flip 자체를 새 기여로 내세우지 않는다. 객체 token 고정하의 문맥 교환과 독립 backbone 전이를 핵심으로 제한한다.
11. **4~8주 MVP:** 1주 hook·정답 검수, 2주 GO/KILL, 3~4주 size/question별 taxonomy, 5~6주 두 번째 모델, 7~8주 event 실험 가능성 검토 및 논문화.
12. **기여 3개:** 객체/문맥 증거의 통제 protocol; 평균 유지와 subgroup 손실의 분해; 최소 selection rule의 유효·실패 조건.
13. **제목 2개:** *When Kept Objects Still Disappear*; *Evidence Survival under Visual Token Compression*.
14. **Abstract 개요:** 평균 효율 지표의 맹점 → 동수 token 교환 → paired/subgroup 진단 → 최소 교정과 일반화 한계.
15. **Introduction:** 압축의 가치 → 보존율의 불충분성 → P1/P2의 다른 관찰 → 원인 분리와 제한된 주장.
16. **Related Work:** visual token pruning; contextual recognition; paired evaluation; event sparsification.
17. **Method:** semantic region mapping → matched retention → error transition matrix → cross-model verification.
18. **표·그림:** budget×size harmful-flip heatmap, correct/wrong 이동표, 객체 고정 ring 교환 곡선, token 위치와 답변의 사례도.

**첫 실험:** frozen SmolVLM-256M-Instruct를 사용해 COCO annotation과 연결 가능한 최대 100개 이미지·이미지당 최대 6개 POPE 문항을 pilot으로 선정한다. 실제 매칭 수·제외 사유를 기록한다. 이미지 50/50으로 dev/test 분리하고 50% retention에서 객체 token 수를 고정한 채 ring과 먼 배경 token만 교환한다. clean arm이 GT 답변을 맞힌 문항의 harmful flip과 전체 accuracy를 함께 본다. mask 설계에 test 정답을 사용하지 않는다.

**1~2주 GO/KILL:** image-cluster paired 95% CI에서 ring 보존이 budget-matched random보다 harmful flip을 줄이고, 다른 질문군의 손실이 이를 상쇄하지 않으면 두 번째 모델로 GO. 효과가 동등하거나 위치/hook 수정 후 사라지면 KILL. CI가 넓으면 미결이다. 이 기준은 사전 계획이며 실측 결과가 아니다. token mask 실험만으로 실제 가속을 주장하지 않는다.

## 4. Proposal B — Stage Boundary of Geometric Ambiguity

1. **문제·가치:** 회전 상자 encoding 교정의 효과는 one-to-many 학습에 국한되는가? P3의 명시적 미검증 구간을 다룬다.
2. **Gap:** 같은 상자 표현의 교정 자체는 선행 기여다. one-to-one 전환이 assignment·filtering·recall에 미치는 상호작용은 남아 있다.
3. **가설:** 단계 전환은 encoding ambiguity의 빈도뿐 아니라 잘못 버려지는 pseudo box의 구성을 바꾸며, 최종 checkpoint 진단은 초기 손실을 과소평가한다.
4. **구조:** 고정 teacher/student → encoding swap → assignment 재계산 → GMM keep/drop → 단계별 기록. 최소 개입은 cost 교정 on/off이며 DN schedule은 고정한다.
5. **Baseline:** fixed encoding, canonicalization, P3 swap-invariant cost; one-to-many 유지와 정상 one-to-one 전환의 2×2 비교.
6. **데이터·지표:** DOTA-v2.0 공식 train 내부 pilot과 별도 val. source image 단위 분리. assignment/filter flip, retained pseudo-label precision/recall, aspect ratio별 AP50/AP75, 실제 training time.
7. **Ablation:** 동일 frozen teacher의 재매칭과 joint training 분리; 전환 시점; near-square strata; cost만 교정; DN schedule; 3개 독립 seed.
8. **실패 모드:** teacher 변화와 단계 변화의 혼동, tile의 원본 이미지 중복, angle normalization 오류를 검사한다.
9. **Negative result:** 전환 후 차이가 없으면 적용 범위를 one-to-many로 제한한다. flip만 있고 GT precision 차이가 없으면 품질 개선 주장을 기각한다.
10. **Novelty·방어:** 선행 Appendix H와 매우 가깝다. 단순 재측정은 약하다. 단계×교정의 상호작용과 품질 label을 확보하지 못하면 별도 논문화하지 않는다.
11. **4~8주 MVP:** 1주 geometry·출력 확보, 2주 frozen rematching, 3~4주 짧은 단계 전환 실험, 5~6주 multi-seed, 7~8주 검수.
12. **기여 3개:** 단계별 적용 경계; selection flip과 실제 품질의 연결; 교정 활성 구간을 정할 근거.
13. **제목 2개:** *When Does Geometric Ambiguity Matter?*; *Stage-Dependent Pseudo-Label Selection in Oriented Detection*.
14. **Abstract:** parameter ambiguity → 미검증 학습 단계 → factorial 실험 → 필요/불필요 조건.
15. **Introduction:** 형상과 encoding 차이 → 기존 교정의 성과 → stage 한계 → 범위 검증.
16. **Related Work:** oriented representations; teacher–student detection; DETR assignment; stage-wise training.
17. **Method:** equivalence 검사 → 재매칭 → stage factorial → 품질/성능 분리.
18. **표·그림:** stage×cost 표, checkpoint별 filter/precision 곡선, aspect-ratio 분포, seed별 효과도.

**첫 실험·GO/KILL:** 접근 가능한 oriented teacher/student 출력으로 128개 unlabeled image의 frozen rematching을 먼저 수행한다. 출력·checkpoint 확보가 안 되면 P3 재현이라고 부르지 않고 이용 가능한 rotated detector로 geometry 검사만 한다. one-to-one 전환 전후 teacher를 확보한 뒤 독립 val GT에 대해 교정 효과의 상호작용이 확인되면 GO. 단순 flip만 재현되거나 P3의 기존 분석 이상을 얻지 못하면 KILL. 전체 180k schedule을 첫 주에 재학습하지 않는다.

## 5. Proposal C — Same Pixels, Different Water

1. **문제·가치:** 축소 물체와 실물의 apparent size가 같으면 detector 난도도 같은가? P4의 실제 고고도 전이 미검증이 직접 출발점이다.
2. **Gap:** pixel footprint 일치는 배경 파장·광학 blur·표적 질감·가시성의 일치를 보장하지 않는다. P5의 문맥 보존을 통제 실험에 활용한다.
3. **가설:** 같은 객체 픽셀에서 주변 물결의 상대 스케일 변화가 tiny-object 신뢰도·recall을 바꾸며, 내부 해상도 변화와 독립적인 손실이 있다.
4. **구조:** 원본 객체 내부 고정 → 주변 annulus의 스케일만 변경 → 동일 경계 합성 → 고정 detector 평가. 최소 개입은 context-scale augmentation 하나다.
5. **Baseline:** 원본, global resize, sham compositing, 동일 경계의 색 변화, context-scale 변경; 후속 학습에서는 동일 annotation/pixel/update 예산을 맞춘다.
6. **데이터·지표:** TinyWOD official split을 유지하고 별도 source-video holdout 감도 분석. APtiny 정의를 evaluator에서 먼저 확인하고 AP50/AP75, recall@고정 FP/image, calibration을 측정한다.
7. **Ablation:** 객체 ESL, ring 폭, 배경 scale, interpolation, 경계 feather, 낮/밤·지역, 객체 내부 변형 유무.
8. **실패 모드:** 합성 seam이 난도를 만들 수 있다. 독립 검수와 sham control을 두고 invalid composite를 제외한다. 실제 고고도 샘플 없이는 물리적 전이 결론을 내리지 않는다.
9. **Negative result:** context-scale 효과가 sham과 같으면 가설 기각. 내부 blur만 지배하면 문맥 개입을 중단하고 optical degradation 진단으로 범위를 줄인다.
10. **Novelty·방어:** copy-paste·domain randomization과 경쟁한다. 새로운 augmentation을 주장하기보다 고정 표적 픽셀 아래의 배경 상대 스케일 반례를 검증한다.
11. **4~8주 MVP:** 1주 다운로드·split 검사, 2주 합성 validity·GO/KILL, 3~4주 두 detector, 5~6주 최소 augmentation, 7~8주 허가된 실물 영상 검증 또는 한계 명시.
12. **기여 3개:** apparent-size equivalence의 검증 protocol; 문맥/광학 confound 분해; 제한된 최소 교정과 전이 경계.
13. **제목 2개:** *Same Pixels, Different Water*; *Does Apparent Size Preserve Tiny-Object Detection Difficulty?*
14. **Abstract:** 대체 촬영의 전제 → 표적 고정 context intervention → 조건별 손실 → 실제 전이 미확인 범위.
15. **Introduction:** 고고도 데이터 수집 비용 → apparent-size 대체 → 배경 상대 스케일 질문 → 검증 가능한 주장.
16. **Related Work:** maritime tiny detection; scaled-target acquisition; context augmentation; dataset distillation의 geometry 보존.
17. **Method:** split audit → paired context renderer → validity control → minimal augmentation.
18. **표·그림:** ESL×context-scale heatmap, sham 대비 paired recall, FP/image–recall 곡선, 합성 유효/실패 사례.

**첫 실험·GO/KILL:** TinyWOD 접근과 evaluator를 확인한 뒤 최대 200개 held-out 이미지에서 lifebuoy 내부를 고정하고 배경 scale만 0.5/1/2로 바꾼다. 이 배수는 실험 계획값이다. TinyWOD train으로 학습한 고정 Faster R-CNN-R50 한 모델로 시작한다. 공개 weight가 없으면 학습 비용을 먼저 계측한다. video-cluster CI에서 context 효과가 sham보다 크고 유효 합성 조건에서 재현되면 GO. seam에만 반응하거나 source-video를 바꾸면 효과가 사라지면 KILL. 실제 고고도 transfer 개선은 별도 데이터 없이는 주장하지 않는다.

## 6. 우선순위와 이번 주 행동

점수는 평가자의 판단이며 실측치가 아니다. Compute cost는 1이 가볍고 5가 무겁다.

| 후보 | Novelty /5 | Feasibility /5 | Compute cost /5 | Publication potential /5 |
|---|---:|---:|---:|---:|
| A — Evidence Survival Audit | 3 | 4 | 1 | 3 |
| B — Stage Boundary | 3 | 2 | 4 | 3 |
| C — Same Pixels, Different Water | 4 | 3 | 2 | 3 |

**1순위는 A다.** 작은 frozen 모델로 1~2주 안에 핵심 가설을 반증할 수 있고, 학습 없이 object/context의 원인을 분리할 수 있다. 단, TIVS와의 중복 위험을 넘어서는 spatial intervention·전이가 없으면 논문으로 확대하지 않는다. 작은 GPU 후보도 A이며, 실제 peak VRAM과 처리시간 확인을 먼저 한다. B는 단계별 checkpoint 확보가 선행 조건이고, C는 데이터 접근과 합성 유효성 검사가 선행 조건이다.

장기 주제로는 C의 “같은 픽셀 크기지만 다른 촬영 물리”를 실제 고고도·해상 환경으로 확장할 수 있다. 현재 근거는 그 전이를 입증하지 않는다. 이번 주에는 A의 hook 검증 → dev에서 mask 규칙 고정 → held-out paired audit → GO/KILL 결정 순서로 진행하는 것이 적절하다.
