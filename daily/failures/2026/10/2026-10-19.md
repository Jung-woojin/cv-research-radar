## 1. ACEdit — 누적 drift는 줄었지만 이전 편집 상태의 선택적 소실은 남음

**실패 조건.** 편집 결과를 다음 입력으로 되먹이는 multi-turn 이미지 편집에서 작은 분포 이동이 누적된다. 색이 변하고 미세 질감이 사라지며, no-op인 “keep the image as is”조차 손상을 축적한다. 제안 모델에서도 9단계 편집의 마지막 “Make the hiker smile”이 이전 단계에서 추가한 선글라스를 제거했다.

## 2. DINO-FIL — 더 많은 encoder fine-tuning이 외부 위조 데이터에서 역효과

**실패 조건.** B-Free로 학습한 inpainting forgery localizer에서 DINOv3 encoder의 마지막 layer를 더 많이 미세조정하면 in-domain 성능은 올라가지만 cross-dataset 성능은 비단조적으로 변한다. 입력 해상도를 512에서 1024로 올려도 원본 정보가 없는 고정 저해상도 데이터에서는 이득이 없거나 약간 낮아진다.

**모델·데이터·설정.** DINOv3 ViT-H+/16의 여러 층 특징을 fusion decoder가 합친다. B-Free 206,065장으로 2 epoch 학습하고 Beyond the Brush, CocoGlide, TGIF, SAGI-D, B-Free를 512 또는 1024로 평가했다. encoder unfreeze 수는 0/6/12/16/24/32다.

**확인된 사실.** 512px에서 16-layer unfreeze는 평균 IoU/F1 0.61/0.67이었다. 24-layer는 0.60/0.65, 32-layer는 0.61/0.66으로 F1이 낮아졌다. 동시에 B-Free IoU는 0.90에서 0.91로 올랐지만 Beyond the Brush는 0.36에서 0.32/0.33, TGIF는 0.38에서 0.33/0.36으로 내려갔다. frozen encoder에서 test resolution을 512→1024로 높이면 외부 데이터 평균은 좋아졌지만 B-Free IoU/F1은 0.82/0.89에서 0.80/0.88로 낮아졌다. 저자는 B-Free·CocoGlide처럼 고정 저해상도인 데이터는 upsampling으로 새 정보가 생기지 않는다고 구분했다. [공식 논문 및 ablation](https://arxiv.org/html/2610.21780v1#S5.SS1)

**저자·maintainer 인정 여부.** 저자가 encoder unfreeze 수와 해상도별 ablation을 표로 공개했다. 다만 이를 일반적인 “overfitting failure”로 직접 명명하지는 않았다. 역효과라는 판정은 표의 cross-dataset 변화에 대한 본 보고서의 해석이다.

**community reproduction 여부와 재현 근거.** 독립 재현과 공식 코드 링크는 확인하지 못했다. 결과는 저자 표에 한정되며, baseline인 DinoLizer·TruFor 수치는 다른 논문에서 가져온 보고값이라 모든 학습 조건의 완전한 통제 비교는 아니다.

**진단 → 의심 메커니즘 → 가설.** 관찰은 더 깊은 적응이 training generator의 artifact에는 맞지만 외부 generator의 trace에는 약해진다는 것이다. 의심 메커니즘은 DINO의 범용 texture·semantic representation이 B-Free perturbation과 mask 통계에 맞춰 덮이는 것이다. **가설:** layer별 gradient alignment를 감시하고 외부 style perturbation에 민감한 layer를 동결하면 in-domain gain을 유지하면서 외부 F1 하락을 막을 수 있다.

**기존 주장과 충돌 여부.** DINO-FIL이 평균적으로 강한 cross-dataset 성능을 보인다는 주장과 직접 충돌하지 않는다. 그러나 “더 많은 backbone adaptation이 더 낫다”는 일반화는 성립하지 않으며, 512와 1024 결과도 native resolution이 달라 **not strictly apples-to-apples**다.

**후속 최소 실험.** B-Free의 10% subset으로 0/8/16/24/32 layer unfreeze를 3 seed 반복하고, hold-out generator와 JPEG/blur 강도별 F1을 기록한다. CKA drift와 layer gradient norm도 측정한다. **GO:** selective freeze가 16-layer 기준 B-Free F1 손실 0.01 이내에서 외부 4개 데이터 평균 F1을 0.02 이상 높인다. **KILL:** seed 표준편차가 설정 간 차이보다 크거나 외부 gain이 threshold 0.5 재조정만으로 사라진다.

**평가:** 심각도 **4/5** · 재현 신뢰도 **4/5** · 연구 아이디어 가치 **5/5**

## 3. P³-WAM — video planning 우위가 closed-loop 로봇 성공을 보장하지 않음

**실패 조건.** 단안 egocentric video에서 global 3D hand 위치가 본질적으로 모호하고, 생성된 hand trajectory를 실제 dexterous robot에 open-loop로 재타기팅하면 접촉·위치 오차를 온라인으로 교정할 경로가 없다. 장기 조작일수록 작은 오차가 누적될 가능성이 크다.

**모델·데이터·설정.** P³-WAM은 하나의 video diffusion transformer에서 Perceive, Predict, Plan을 통합한다. EgoDex, ARCTIC, HOT3D, EgoLive에서 hand reconstruction과 action-conditioned video prediction을 평가하고, Plan 영상은 Qwen3.8-Max judge가 1–5점으로 평가한다. 실제 로봇 데모는 생성된 human-hand motion을 retarget해 실행한다.

**확인된 사실.** 저자는 global 3D hand position의 monocular ambiguity와 현재 robot experiment의 open-loop 실행을 limitation으로 명시했다. Plan은 action process·instruction·physical interaction·goal transition에서 보고된 baseline보다 높았지만, temporal/identity consistency는 4.651로 표의 최고 baseline 4.684보다 0.033 낮았다. 이 최고 baseline은 goal image가 없는 Cosmos 설정이어서 조건이 같지 않아 **not strictly apples-to-apples**다. 논문은 robot execution 예시를 제시하지만 closed-loop success rate나 disturbance recovery rate를 보고하지 않았다. [공식 논문](https://arxiv.org/html/2610.22363v1#S5) · [공식 프로젝트](https://p3-wam.pages.dev/)

**저자·maintainer 인정 여부.** 인정했다. 깊이·촉각이 더 강한 기하 제약을 줄 수 있고 closed-loop feedback이 장기 robustness를 높일 수 있다고 저자가 직접 썼다. 프로젝트 페이지의 code는 forthcoming이다.

**community reproduction 여부와 재현 근거.** 독립 재현은 확인하지 못했다. 공식 supplementary video와 논문 protocol은 있으나 코드와 로봇 execution log가 아직 공개되지 않아 물리 재현 신뢰도는 낮다.

**진단 → 의심 메커니즘 → 가설.** 관찰은 영상상 그럴듯한 trajectory와 실제 접촉 성공 사이에 검증되지 않은 간극이 있다는 것이다. 메커니즘은 moncular depth ambiguity, human-to-robot kinematic retarget error, object slippage가 누적돼도 plan을 재계산하지 않는 것이다. **가설:** wrist camera의 optical flow와 fingertip contact confidence만 사용하는 저비용 residual controller도 open-loop 대비 장기 성공률을 유의하게 높일 수 있다.

**기존 주장과 충돌 여부.** Perceive/Predict/Plan 통합 학습이 offline metric을 높였다는 주장과 충돌하지 않는다. 다만 VLM judge의 planning score를 physical task success로 대신할 수 없고, 공개 근거는 robustness claim까지 지지하지 않는다.

**후속 최소 실험.** 동일한 20개 pick-place trajectory에 ±5mm object shift와 5° camera perturbation을 주고 open-loop, visual residual, visual+contact residual을 비교한다. success, first-contact error, replan count, completion time을 기록한다. **GO:** visual residual이 open-loop 대비 성공률을 15점 이상 높이고 latency 증가는 20% 이하다. **KILL:** 개선이 초기 calibration을 다시 맞춘 결과이거나 perturbation 없는 조건에서 성공률이 5점 이상 떨어진다.

**평가:** 심각도 **5/5** · 재현 신뢰도 **3/5** · 연구 아이디어 가치 **5/5**

## 4. EOS-Story — attention-derived mask와 SDXL backbone 실패가 장면 적응을 깨뜨림

**실패 조건.** cross-attention map이 subject가 아닌 영역을 잡으면 identity feature가 잘못 주입되어 객체가 어긋나거나 부분적으로 잘못 배치된다. SDXL이 “faun” 같은 개념 자체를 정확히 생성하지 못하는 경우 EOS-Story도 복구하지 못한다. 또한 CLIP EOS token의 contextual summarization을 쓰기 때문에 T5·LLM text encoder로 직접 옮길 수 없다.

**모델·데이터·설정.** training-free SDXL pipeline에 Cross-Contextual Bridging, Identity Anchoring, Identity-Aware Self-Attention을 적용한다. 공식 구현 기본값은 1024×1024, 50 denoising step, CFG 7.0, λ=0.55다. 5개 story 생성 측정에서 EOS-Story는 47,777MB GPU memory와 118.570초를 사용했다.

**확인된 사실.** 논문 failure figure는 cross-attention mask가 관련 없는 영역을 포착하고, SDXL이 특정 concept를 생성하지 못하는 사례를 제시한다. 저자는 explicit subject mask를 추가 조건으로 쓰는 해결책을 제안했다. FLUX 실험에서도 FLUX-Kontext는 identity metric이 강하지만 reference에 고정돼 copy-and-paste 형태와 rigid pose를 만들고, CLIP-T 0.8544로 EOS-Story 0.8722보다 낮았다. [공식 논문](https://arxiv.org/html/2610.22320v1#A0.SS4) · [공식 구현](https://github.com/SeungJuCha/EOS-Story)

**저자·maintainer 인정 여부.** 인정했다. 잘못된 attention region, 기반 SDXL concept failure, text encoder 구조 의존성을 limitation으로 명시했다.

**community reproduction 여부와 재현 근거.** 공식 코드는 공개됐지만 독립 재현은 확인하지 못했다. README는 single/multi-subject와 pose-control 실행법, default seed와 설정을 제공하므로 제한적 재현은 가능하다. 47GB대 메모리 측정은 서로 다른 baseline resolution·batch 방식이 섞여 있어 직접 효율 비교에는 주의가 필요하다.

**진단 → 의심 메커니즘 → 가설.** 관찰은 mask 오류가 identity 보존 모듈 전체로 전파된다는 것이다. 메커니즘은 cross-attention이 causal localization이 아니라 text-image affinity proxy인데 이를 hard spatial carrier처럼 사용하기 때문이다. **가설:** attention entropy와 multi-layer agreement로 mask confidence를 계산해 낮은 경우 explicit segmentation 또는 injection abstention으로 전환하면 misplacement가 줄어든다.

**기존 주장과 충돌 여부.** 평균적인 identity–scene 균형 우위와 충돌하지 않는다. 다만 “training-free”는 failure-free 또는 architecture-agnostic을 의미하지 않고, 공식 구현도 SDXL 경로에 묶여 있다.

**후속 최소 실험.** Consistory+에서 40 prompt를 골라 automatic mask, explicit mask, confidence-gated hybrid를 3 seed로 생성한다. mask IoU, subject misplacement, CLIP-I, CLIP-T, human preference, peak VRAM을 측정한다. **GO:** hybrid가 automatic 대비 misplacement를 30% 이상 줄이며 CLIP-I 손실 0.01 이하, 추가 VRAM 10% 이하다. **KILL:** confidence AUROC가 mask failure 예측에서 0.65 미만이거나 explicit mask 품질에 결과가 과도하게 종속된다.

**평가:** 심각도 **4/5** · 재현 신뢰도 **4/5** · 연구 아이디어 가치 **5/5**

## 5. TRACE 비교 — topology objective는 OOM과 metric trade-off를 동시에 드러냄

**실패 조건.** 3D vessel·centerline segmentation에서 topology-aware loss가 메모리를 초과하거나, pixel Dice를 높이면서 실제 connectivity metric인 clDice를 낮춘다. thin structure는 몇 픽셀 단절만으로 path가 깨지므로 평균 overlap만으로는 실패를 가릴 수 있다.

**모델·데이터·설정.** nnU-Net 기반으로 Dice+CE, clDice, Topo-clDice, clCE, cbDice, SkelRecall, Betti Matching, TRACE를 2D·3D 데이터에서 통제 비교한다. TopCoW와 MSD hepatic vessel은 3D benchmark다.

**확인된 사실.** TopCoW에서 Topo-clDice는 OOM으로 결과를 내지 못했다. 같은 데이터에서 기본 Dice+CE는 clDice 86.32, Dice 80.57이었고 clDice loss 추가는 Dice 81.20으로 올랐지만 clDice는 85.49로 낮아졌다. SkelRecall도 clDice 85.70으로 기본보다 낮았다. 반면 TRACE는 clDice 87.35, topology violation β 0.26, Dice 82.42였다. 코드 공개는 acceptance 이후로 예고되어 현재 실행 가능한 공식 구현은 없다. [공식 논문 및 3D 비교](https://arxiv.org/html/2610.22210v1#S4.SS1)

**저자·maintainer 인정 여부.** 저자는 OOM을 공식 표에 기록하고, 기존 fixed-skeleton objective가 현재 prediction이 선택할 수 있는 대체 연결 경로를 고려하지 못한다고 문제를 정의했다. 기존 방법의 metric 역전은 저자 표의 사실이며 원인 해석은 본 보고서의 추론이다.

**community reproduction 여부와 재현 근거.** 독립 재현은 확인하지 못했다. 코드가 아직 공개되지 않아 TRACE 자체는 재현할 수 없고, 비교 결과는 논문 protocol과 표에 의존한다.

**진단 → 의심 메커니즘 → 가설.** 관찰은 topology supervision을 추가하는 행위 자체가 connectivity 향상을 보장하지 않는다는 것이다. 메커니즘은 fixed skeleton이 prediction의 plausible local route와 어긋나 불필요한 gradient를 만들고, 3D global topology 연산은 volume 크기에 따라 memory가 급증하는 것이다. **가설:** local bottleneck만 선택적으로 계산하고 active connection 수를 제한하면 global loss보다 적은 memory로 clDice를 안정적으로 개선할 수 있다.

**기존 주장과 충돌 여부.** TRACE의 핵심 주장과는 충돌하지 않고 오히려 문제 설정을 지지한다. 다만 code unavailable 상태라 저자 방법의 low-overhead 주장을 독립 확인하지 못했다.

**후속 최소 실험.** 공개 가능한 DRIVE 2D와 소형 3D vessel subset에서 Dice+CE, clDice, patchwise Betti, local bottleneck loss를 같은 batch와 patch size로 비교한다. clDice, β, Dice, peak VRAM, step time을 3 seed로 기록한다. **GO:** local loss가 기본 대비 clDice 1점 이상 개선하고 peak VRAM 증가는 15% 이하이며 Dice 손실이 0.3점 이하다. **KILL:** 개선이 threshold tuning으로 사라지거나 3D patch 경계에서 false connection이 증가한다.

**평가:** 심각도 **4/5** · 재현 신뢰도 **3/5** · 연구 아이디어 가치 **5/5**

## 오늘의 실패 패턴 3개

1. **평균 향상 뒤에 state-specific failure가 남는다.** ACEdit은 전체 consistency를 높였지만 이전 편집 하나를 잃었고, P³-WAM은 offline video score와 실제 closed-loop recovery 사이에 간극이 있다.
2. **적응 강도를 높일수록 일반화가 좋아진다는 보장은 없다.** DINO-FIL의 deep unfreeze는 training domain을 개선하면서 일부 외부 generator를 악화시켰고, EOS-Story의 강한 identity injection은 mask 오류까지 강화할 수 있다.
3. **보조 목표와 proxy가 실제 목표를 대신하지 못한다.** topology loss가 clDice를 낮추거나 OOM을 내고, VLM judge·attention map·pixel overlap은 각각 physical success·causal region·connectivity를 완전히 측정하지 못한다.

## 논문 아이디어로 연결 가능한 빈틈

- **Persistent Edit State Evaluation:** multi-turn image editing을 화질·현재 instruction·과거 edit retention의 세 축으로 분해하고 객체별 state deletion을 검출한다.
- **Layer-Selective Forensic Adaptation:** generator별 feature drift와 gradient conflict를 이용해 DINO encoder의 fine-tuning layer를 자동 선택한다.
- **Recoverable World-Action Models:** 계획 영상 생성과 접촉 기반 online residual correction을 결합하고, disturbance recovery를 별도 benchmark로 만든다.
- **Confidence-Gated Identity Injection:** cross-attention mask uncertainty가 높을 때 segmentation·abstention으로 전환해 identity module의 오류 증폭을 막는다.
- **Topology Gain per GiB:** clDice 개선량을 peak VRAM·step time과 함께 보고해 3D topology loss의 실용성을 비교한다.
