## Q1. Long-tail compound를 보호하는 label-shift-aware TTA가 overall 중심 TTA보다 실제 domain generalization을 개선하는가?

### 1. 문제 정의

unseen source에 적응할 때 plate-level normalization은 abundant control class의 성능을 크게 높이지만 희소 class를 거의 개선하지 못할 수 있다. test label 비율을 직접 알 수 없는 조건에서 uncertainty와 class-frequency proxy를 이용해 long tail을 보호하는 TTA가 가능한가?

### 2. 왜 지금 가치가 있는가

domain adaptation의 평균 정확도 향상이 rare class 배포 성능을 보장하지 않는다는 직접 근거가 나왔다. 이 문제는 biomedical image뿐 아니라 희귀 선박·소형 부표·이상 상황이 적은 해양 CCTV에도 그대로 연결된다.

### 3. 직접 근거

- **사실:** BatchBench는 JUMP-CP-2k의 공개 source 8개를 학습하고 source 4·6·9·13을 private test로 사용한다.
- **사실:** 공개→test label 비율은 POSCON 51%→36%, TARGET 25%→55%, REST 24%→9%로 변한다.
- **사실:** ResNet18 overall은 0.175, ARM-BN은 0.260이었지만 REST는 각각 0.002와 0.004였다. 최고 REST도 deepCORAL의 0.007이었다.
- **사실:** 공식 baseline 저장소는 학습 코드, checkpoint, Docker submission, adapt()/predict() 인터페이스를 공개한다.
- **저자 주장:** weak phenotype과 few-image compound의 unseen-source 식별이 핵심 미해결 문제다.
- 논문: https://arxiv.org/abs/2610.30104
- 공식 코드: https://github.com/ml-jku/batchbench-baselines

### 4. 핵심 가설

entropy minimization과 BatchNorm update가 test의 다수·강한 phenotype에 끌린다. prediction stability와 prototype uncertainty를 사용해 고신뢰 class만 적응하고, rare candidate에는 source prototype을 보존하면 REST와 macro accuracy가 함께 오른다.

### 5. 최소 실험(MVP)

공개 200×200 development set에서 ResNet18 checkpoint를 고정하고 다음 네 조건을 세 seed로 비교한다.

1. no adaptation
2. AdaBN
3. TENT
4. uncertainty-gated AdaBN/TENT

gate는 augmentation 간 prediction agreement와 prototype distance만 사용한다. 학습 가능한 추가 파라미터 없이 시작한다.

### 6. Baseline과 dataset

- Baseline: ResNet18, AdaBN, TENT, deepCORAL
- Dataset: JUMP-CP-2k-200 공개 development split
- 추가 일반화: class imbalance를 인위적으로 바꾼 source-held-out validation
- 조건 주의: private leaderboard 결과와 development 결과는 `not strictly apples-to-apples`다.

### 7. 성공·실패 판정 metric

- 성공: REST 또는 rare-bin accuracy가 AdaBN 대비 2배 이상이고 TARGET이 하락하지 않으며 세 seed 방향이 일치
- 실패: overall만 상승하거나 rare-bin 성능이 0.01 미만에 머묾
- 보조: macro accuracy, worst-class recall, calibration error, adaptation drift

### 8. Compute 난이도

**3/5.** 5-channel 200×200 입력과 ResNet18이므로 단일 GPU로 가능하지만 다중 seed가 필요하다.

### 9. Novelty 위험요인

label-shift-aware TTA는 기존 분야다. 차별성은 **rare-class 보호 기준을 unlabeled morphology uncertainty로 구성하고 long-tail failure를 주요 endpoint로 삼는 것**에 있다.

### 10. 4~8주 내 논문화 가능성

**4/5.** 1~2주에 development 결과, 3~4주에 다른 medical/remote-sensing source shift로 확장 가능하다.

### 11. Negative result의 가치

gate가 효과가 없으면 문제의 병목이 test-time normalization이 아니라 학습 단계의 phenotype representation 또는 extreme sample scarcity임을 좁힐 수 있다.

**평가:** 새로움 4/5 · 실행 가능성 4/5 · 계산 효율 3/5 · 논문화 가능성 4/5

## Q2. False-alert 예산을 직접 제약한 proactive vision agent가 recall 중심 agent보다 안전한가?

### 1. 문제 정의

proactive agent는 사건을 놓치지 않으려다 과도한 알림을 만들고, precision을 높이려다 silence로 붕괴할 수 있다. alerts/hour와 false-alert cost를 명시한 constrained policy가 notification F1, intervention overlap, memory-backed QA를 함께 높이는가?

### 2. 왜 지금 가치가 있는가

항만 안전 agent는 false alarm이 누적되면 운영자가 경보를 무시하게 된다. 단순 recall 최대화는 배포 목적과 맞지 않는다. 공개 streaming protocol과 scorer가 생겨 작은 비용 제약 실험을 즉시 설계할 수 있다.

### 3. 직접 근거

- **사실:** ProactEgoMem의 Daily→Science paired 비교에서 notification recall은 28.5%→15.5%, F1은 5.9%→3.9%로 하락했다.
- **사실:** Science의 30개 model–task cell 중 29개에서 precision이 9.8% 이하였다.
- **사실:** proactive memory는 uniform no-memory baseline보다 36개 QA cell 중 22개에서 낮았다.
- **사실:** 공식 저장소는 trace generation, notification/intervention scorer, QA evaluator와 threshold config를 공개한다.
- **저자 주장:** laboratory domain의 주 병목은 정답 생성보다 evidence acquisition이다.
- 논문: https://arxiv.org/abs/2610.30089
- 공식 코드: https://github.com/mayhugotong/ProactEgoMem

### 4. 핵심 가설

event probability만 thresholding하면 domain shift에서 trigger rate가 불안정하다. conformal calibration 또는 dual-variable 방식으로 alerts/hour 제약을 맞추면 같은 recall에서 precision과 downstream QA가 높아진다.

### 5. 최소 실험(MVP)

공개 trace 또는 한 개 접근 가능한 VLM의 50개 clip 결과에서 세 정책을 비교한다.

1. 고정 threshold
2. validation F1 최적 threshold
3. alerts/hour≤B를 만족하는 calibrated threshold

B는 0.5, 1, 2 alerts/min의 세 수준으로 둔다. 모델 재학습 없이 trace score calibration부터 시작한다.

### 6. Baseline과 dataset

- Baseline: fixed threshold, F1-tuned threshold, silence, always-trigger
- Dataset: ProactEgoMem-Daily validation과 Science subset
- 해양 이전: 짧은 항만 CCTV event 30개
- 동일 semantic judge cache와 scorer version을 고정한다.

### 7. 성공·실패 판정 metric

- 성공: 사전 alert budget을 지키며 fixed threshold보다 F1과 memory-backed QA가 모두 개선
- 실패: precision 향상이 recall 붕괴로만 발생하거나 QA가 uniform sampling보다 낮음
- 보조: alerts/hour, intervention mIoU, expected calibration error, domain별 constraint violation

### 8. Compute 난이도

**2/5.** 저장 trace로 시작하면 CPU 중심이며, 새 inference는 소규모다.

### 9. Novelty 위험요인

cost-sensitive detection은 성숙한 분야다. novelty는 **streaming multimodal agent의 lifecycle와 memory usefulness까지 같은 제약 아래 평가하는 것**에 달려 있다.

### 10. 4~8주 내 논문화 가능성

**4/5.** calibration 결과는 빠르게 나오며, 작은 policy head와 해양 domain을 추가하면 시스템 논문으로 확장할 수 있다.

### 11. Negative result의 가치

비용 제약만으로 QA가 좋아지지 않으면 trigger calibration보다 event representation과 memory selection이 병목이라는 근거가 된다.

**평가:** 새로움 4/5 · 실행 가능성 5/5 · 계산 효율 5/5 · 논문화 가능성 4/5

## Q3. 생성형 3D 모델에 “물리 acceptance contract”를 붙이면 외형 점수와 실제 사용 가능성을 분리할 수 있는가?

### 1. 문제 정의

3D 생성·완성 모델은 Chamfer distance나 coverage가 좋아도 collision, thickness, watertightness를 만족하지 않을 수 있다. task-independent foundation model 출력 뒤에 물리 제약을 검사·수리하는 acceptance layer를 두면 실제 사용 가능성을 높일 수 있는가?

### 2. 왜 지금 가치가 있는가

최근 감사에서 세 pretrained model의 implantable output이 0건이었다. 이는 모델 규모보다 평가 계약과 표현 형식이 문제일 수 있음을 보여준다. 같은 원리는 선박 부품, 해양 구조물 결손, 로봇 grasp geometry에도 적용된다.

### 3. 직접 근거

- **사실:** MSN-FM, AdaPoinTr, MGPC를 239개 cranial defect에 zero-shot 적용했을 때 implantable 결과는 모두 0/239였다.
- **사실:** median advantage over no-op은 각각 -0.156, -0.036, -0.130이었다.
- **사실:** real case 29개에서 MGPC는 24개가 no-op보다 나았지만 collision-free 조건까지 통과한 출력은 없었다.
- **사실:** point-cloud 표현에서는 implant thickness를 직접 읽을 수 없었다.
- **저자 주장:** 외형 coverage는 실제 장착 가능성을 측정하지 못한다.
- 논문: https://arxiv.org/abs/2610.30035
- 공식 HTML: https://arxiv.org/html/2610.30035v1

### 4. 핵심 가설

모델을 처음부터 재학습하지 않아도 signed-distance collision removal, minimum thickness, watertight mesh projection을 순차 적용하면 외형 이득을 유지하면서 acceptance rate를 크게 높일 수 있다.

### 5. 최소 실험(MVP)

공개 case 30개와 한 개 checkpoint에서 세 조건을 비교한다.

1. 원 출력
2. collision-only repair
3. collision + thickness + watertight repair

각 repair 단계의 geometry 변화와 실패 원인을 기록한다.

### 6. Baseline과 dataset

- Baseline: no-op, raw model, Laplacian smoothing, constrained optimization
- Dataset: 논문이 공개한 cranial audit subset 또는 사용 가능한 AutoImplant subset
- Metric: advantage@2mm, penetration depth, collision-free@1mm, watertightness, surface regularity

### 7. 성공·실패 판정 metric

- 성공: 30개 중 24개 이상이 물리 조건을 통과하고 median advantage가 양수
- 실패: collision 제거 뒤 missing-region recall이 no-op 이하이거나 mesh conversion이 불안정
- 추가: repair time, geometry distortion, human CAD correction distance

### 8. Compute 난이도

**3/5.** 학습보다 geometry optimization이 중심이지만 3D preprocessing이 필요하다.

### 9. Novelty 위험요인

후처리 기반 collision repair는 알려져 있다. 논문성은 **foundation-model output을 통과/거부/수리로 분류하는 표준 acceptance contract**와 task transfer 검증에 있다.

### 10. 4~8주 내 논문화 가능성

**4/5.** 의료 한 domain의 소형 audit는 가능하며, 다른 3D completion task까지 확장하면 기여가 강해진다.

### 11. Negative result의 가치

post-hoc repair가 실패하면 출력 representation 자체가 물리 설계에 부적합하다는 결론을 얻는다. 이는 point cloud 대신 implicit surface나 volumetric decoder가 필요하다는 근거다.

**평가:** 새로움 4/5 · 실행 가능성 4/5 · 계산 효율 4/5 · 논문화 가능성 4/5

## Q4. 해무·소형 객체 benchmark의 난이도 공백이 모델 개선을 숨기거나 과장하는가?

### 1. 문제 정의

해양 CV benchmark의 평균 mAP는 맑음·중간 크기 객체가 많은 구간에 지배될 수 있다. visibility, object size, range, occlusion을 난이도 축으로 만들고 coverage gap을 측정하면 기존 score에서 보이지 않던 개선과 실패를 찾을 수 있는가?

### 2. 왜 지금 가치가 있는가

P2, 고해상도 입력, dehazing, domain adaptation의 효과는 특정 조건에 국한될 수 있다. 평균 mAP만으로는 어려운 해무·tiny-object 구간이 실제로 좋아졌는지 판단하기 어렵다. 학습 없이 기존 prediction만으로 먼저 진단할 수 있다.

### 3. 직접 근거

- **사실:** *Your Benchmark Is an Empirical Measure Over Difficulty*는 7개 domain의 25개 benchmark를 분석했다.
- **사실:** 10/25가 DDM≥0.10, 8/25가 Max Gap≥0.10, 9/25가 Top-5 Gap Sum≥0.30이었다.
- **사실:** benchmark당 세 item을 추가한 BenchFill은 Top-3 Gap Sum을 평균 32.67% 줄였고 budget-matched baseline은 17.52%였다.
- **저자 주장:** 난이도 공백은 해당 구간의 실제 학습 개선을 aggregate score가 감지하지 못하게 한다.
- 논문: https://arxiv.org/abs/2610.29927
- 공식 코드: https://github.com/ASTRAL-Group/benchmark-difficulty-measure
- 공식 데이터: https://huggingface.co/datasets/Yifan99/BenchFill

### 4. 핵심 가설

해양 benchmark는 맑음·큰 객체에 과밀하고 짙은 해무·tiny-object·강한 occlusion 구간에 공백이 있다. difficulty-uniform macro score와 worst-bin score는 기존 mAP보다 P2 또는 dehazing의 실제 이득을 더 안정적으로 구분한다.

### 5. 최소 실험(MVP)

기존 검증 세트와 두 detector checkpoint의 prediction을 사용해 다음을 수행한다.

1. object area, visibility proxy, occlusion, range를 binning
2. bin별 AP/recall 계산
3. empirical difficulty distribution, Max Gap, uniform-bin macro 계산
4. bootstrap으로 checkpoint 순위 안정성 비교

새 학습은 하지 않는다.

### 6. Baseline과 dataset

- Baseline: 기존 mAP, AP-small, fog severity별 AP
- Dataset: SeaShips, Singapore Maritime Dataset 또는 보유 해무 CCTV validation
- Model: 기본 FPN과 P2/high-resolution variant
- visibility label이 없으면 contrast·transmission proxy를 쓰되 proxy 한계를 명시한다.

### 7. 성공·실패 판정 metric

- 성공: 기존 mAP에서 보이지 않던 특정 난이도 구간의 일관된 개선을 세 bootstrap split에서 검출
- 실패: difficulty 순서가 model pool·proxy 선택에 따라 뒤집힘
- 보조: DDM, Max Gap, worst-bin recall, rank correlation, confidence interval

### 8. Compute 난이도

**1/5.** 저장 prediction이 있으면 CPU 분석만으로 시작할 수 있다.

### 9. Novelty 위험요인

difficulty-aware evaluation은 새 개념이 아니다. 차별성은 해무 visibility와 tiny-object scale을 결합하고 **architecture 이득의 위치를 진단하는 것**에 있다.

### 10. 4~8주 내 논문화 가능성

**5/5.** 1주 내 audit 결과, 2~4주 내 gap-filling sample 수집과 외부 dataset 검증이 가능하다.

### 11. Negative result의 가치

rank가 변하지 않으면 현재 benchmark가 생각보다 균형 잡혔다는 근거가 된다. 반대로 proxy가 불안정하면 해양 난이도 annotation protocol 자체가 새 기여가 된다.

**평가:** 새로움 4/5 · 실행 가능성 5/5 · 계산 효율 5/5 · 논문화 가능성 5/5

## Q5. 합성 구름에서 얻은 RGB–SAR open-vocabulary 이득이 실제 해무·구름에서도 유지되는가?

### 1. 문제 정의

remote-sensing OVS에서 합성 cloudy condition은 통제된 robustness 평가를 제공하지만 실제 구름·해무의 산란, sensor artifact, registration error를 충분히 반영하지 못할 수 있다. synthetic→real weather gap을 별도 측정하면 RGB–SAR fusion의 실제 이득을 판별할 수 있는가?

### 2. 왜 지금 가치가 있는가

OpenEarth-OVS44는 fine-grained 44-class taxonomy와 RGB–SAR pair, cross-region split을 제시했다. 그러나 dataset·code는 원문 시점에 “will be released” 상태이며, cloudy track은 synthetic condition이다. 실제 해무와 sensor misregistration을 포함한 검증이 비어 있다.

### 3. 직접 근거

- **사실:** OpenEarth-OVS44는 2,832 RGB image, 1,341 registered RGB–SAR pair, 290,587 expert segment, 40개 도시, 44개 class를 포함한다.
- **사실:** RGB-only, synthetic cloudy multimodal, held-out cross-region의 세 track을 제시한다.
- **사실:** 저자들은 training-free baseline 대비 unseen class 최대 +7.1 mIoU, seen class 최대 +27.6 mIoU를 보고했다.
- **사실:** arXiv abstract는 dataset과 code가 향후 공개될 것이라고 적는다. 오늘 시점에서 artifact 기반 독립 재현은 확인하지 못했다.
- **레이더 추론:** “최대” 이득은 하나의 공통 설정 평균이 아니므로 설정별 표가 없으면 직접 일반화하기 어렵다.
- 논문: https://arxiv.org/abs/2610.29642

### 4. 핵심 가설

synthetic cloud에서 학습된 fusion gate는 RGB 품질 저하에는 대응하지만 실제 SAR speckle, 비정합, 해무 산란이 결합되면 오히려 negative transfer를 만든다. uncertainty-aware modality gating이 고정 fusion보다 안전하다.

### 5. 최소 실험(MVP)

dataset 공개 후 RGB–SAR pair subset에서 네 조건을 만든다.

1. clear RGB
2. synthetic cloud
3. 실제 cloud/fog가 있는 공개 Sentinel-1/2 pair
4. 1–5 pixel registration perturbation

RGB-only, early fusion, late fusion, uncertainty gate를 비교한다.

### 6. Baseline과 dataset

- Baseline: training-free OVS, RGB-only, fixed RGB–SAR fusion
- Dataset: OpenEarth-OVS44 공개본, SEN12MS-CR 또는 실제 cloudy Sentinel pair
- Metric: seen/unseen mIoU, boundary IoU, class-wise calibration, weather degradation slope
- sensor·resolution 차이는 `not strictly apples-to-apples`이므로 동일 spatial support로 재표본화한다.

### 7. 성공·실패 판정 metric

- 성공: real-weather와 misregistration 조건에서 gate가 fixed fusion보다 unseen mIoU를 3점 이상 높이고 clear 성능 하락이 1점 이내
- 실패: synthetic cloud에서만 이득이 있거나 SAR 추가가 small structure boundary를 악화
- 보조: modality weight entropy, registration sensitivity, rare-class IoU

### 8. Compute 난이도

**4/5.** segmentation inference와 multimodal preprocessing이 필요하나 frozen encoder 기반 MVP로 줄일 수 있다.

### 9. Novelty 위험요인

weather robustness와 SAR fusion은 활발한 분야다. novelty는 **open-vocabulary unseen class, synthetic-real gap, misregistration을 같은 평가 계약으로 묶는 것**에 있다.

### 10. 4~8주 내 논문화 가능성

**3/5.** 공개 artifact 시점과 실제 cloudy pair 정리에 의존한다. 데이터가 확보되면 workshop 규모 결과는 가능하다.

### 11. Negative result의 가치

RGB–SAR가 실제 weather에서 이득을 주지 않으면 합성 cloud benchmark가 fusion robustness를 과대평가한다는 중요한 평가 결과가 된다.

**평가:** 새로움 5/5 · 실행 가능성 3/5 · 계산 효율 2/5 · 논문화 가능성 4/5

## Q6. Unified visual encoder의 policy 이득은 visual token 때문인가, native text tower와 auxiliary objective 조합 때문인가?

### 1. 문제 정의

state·language·pixel capability를 하나의 encoder에 통합한 모델은 downstream policy에서 높은 성능을 보이지만, visual token 개선과 instruction text encoder 교체 효과가 섞일 수 있다. visual encoder, text tower, objective 조합을 완전 교차하면 실제 이득의 원인을 분리할 수 있는가?

### 2. 왜 지금 가치가 있는가

foundation encoder 비교에서 backbone만 바뀐 것처럼 보여도 text interface, pretraining objective, parameter count가 함께 바뀌면 결론이 불명확하다. 작은 probe와 frozen policy 실험으로 architecture invention 전에 무엇이 필요한지 진단할 수 있다.

### 3. 직접 근거

- **사실:** ALPS는 ViT-B/16을 language, reconstruction, dense correspondence로 사전학습한 뒤 cross-view self-distillation을 적용한다.
- **사실:** Stage 2는 state-probe error를 17% 줄이고 LIBERO-Spatial success를 76.8%→86.5%로 높였다.
- **사실:** BERT instruction에서는 ALPS mean success가 83.4%, native text tower에서는 85.5%였다.
- **사실:** reconstruction 또는 captioning objective를 제거하면 state-probe error가 각각 8.5%, 4.3% 낮아져 auxiliary-task capacity trade-off가 나타났다.
- **사실:** 저자들은 pixel decoding을 유지하기 위해 일부 state-probe accuracy를 교환한다고 명시했다.
- 공식 HTML: https://arxiv.org/html/2610.30120v1
- 공식 코드: https://github.com/UCSC-VLAA/ALPS

### 4. 핵심 가설

policy 이득의 일부는 visual token보다 native text tower의 instruction alignment에서 온다. 반면 spatial task 이득은 Stage 2의 cross-view geometry에 주로 의존한다. 두 효과는 task family별로 분리될 것이다.

### 5. 최소 실험(MVP)

frozen visual token과 frozen text embedding을 2×2로 교차한다.

1. Stage 1 visual + BERT
2. Stage 1 visual + native text
3. Stage 2 visual + BERT
4. Stage 2 visual + native text

LIBERO 전체 대신 Spatial·Object 각 3 task, 세 seed로 축소한다.

### 6. Baseline과 dataset

- Baseline: CLIP/SigLIP visual + BERT/native text, ALPS Stage 1/2
- Dataset: LIBERO-Spatial, LIBERO-Object의 소형 subset
- Metric: policy success, state-probe error, language retrieval, seed variance
- V-JEPA2-L과 ViT-B 비교는 크기·video pretraining이 달라 `not strictly apples-to-apples`다.

### 7. 성공·실패 판정 metric

- 성공: visual refinement와 text tower의 주효과·상호작용이 세 seed에서 안정적으로 분리
- 실패: confidence interval이 겹치고 task별 방향이 일관되지 않음
- 보조: ANOVA effect size, worst-task success, state-language Pareto frontier

### 8. Compute 난이도

**4/5.** frozen encoder라도 policy training과 rollout이 필요하다. task 수를 줄여야 한다.

### 9. Novelty 위험요인

factorial ablation 자체는 단순하다. 그러나 unified encoder 주장에 대한 **interface-confound audit**로 제시하고 여러 encoder에 반복하면 연구성이 생긴다.

### 10. 4~8주 내 논문화 가능성

**3/5.** 환경 구축이 가장 큰 위험이다. 공식 checkpoint와 training recipe가 안정적으로 동작하면 진단 논문으로 가능하다.

### 11. Negative result의 가치

visual/text 효과를 분리하지 못하면 현재 benchmark variance가 주장 크기보다 크다는 결론을 얻는다. 이는 더 많은 rollout과 standardized instruction interface 필요성을 뒷받침한다.

**평가:** 새로움 4/5 · 실행 가능성 3/5 · 계산 효율 2/5 · 논문화 가능성 3/5
