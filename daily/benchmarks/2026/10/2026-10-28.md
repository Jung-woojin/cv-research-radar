## 1. Aerial-R1 / VSAI-Ref — 항공 segmentation benchmark에 “없는 객체를 거부하는 능력” 추가

**확인된 사실.** VSAI-Ref는 기존 VSAI 항공 영상을 바탕으로 5,372개 referring segmentation sample을 구성한다. split은 train 3,003, validation 886, test 1,483이며, test에는 VQA 842쌍과 scene description 214개가 추가된다. 별도로 차량이 전혀 없는 배경 영상에서 832개 hard negative를 만들고, 존재하지 않는 차량 표현에 empty mask로 응답하는지를 평가한다. hard negative의 언어 표현은 13개 error-prone vehicle description pool과 Qwen-VL-Max를 이용해 장면에 그럴듯하지만 부재한 대상을 선택하는 방식이다. [논문](https://arxiv.org/abs/2610.33056) · [HTML 원문](https://arxiv.org/html/2610.33056) · [공식 코드](https://github.com/phy709/Aerial-R1)

**저자 주장과 수치.** 같은 Sa2VA 계열에서 표준 SFT는 hard negative 832개 중 323개를 거부해 38.82% pass rate를 기록했다. low-resolution augmentation은 52.64%, Aerial-R1은 61.18%다. Specific Vehicle Segmentation에서 SFT의 mIoU/F1은 42.96/49.66, Aerial-R1 Blur는 46.06/52.76이다. General Vehicle Segmentation은 54.93/67.62에서 57.53/69.93으로 올랐다.

**동조건 판정.** SFT, low-res augmentation, Aerial-R1은 같은 Sa2VA 기반·VSAI-Ref·1024 입력에서 비교되므로 논문 내부 비교는 대체로 apples-to-apples다. 다만 H-GAWR는 group size 8의 다중 forward와 4×H100, DeepSpeed를 사용하고, SFT dataset repetition은 10배지만 H-GAWR는 1 epoch다. 최종 inference는 저자 설명상 base SFT와 같은 single pass이나 학습 compute는 같지 않다.

**진단.** 기존 aerial referring segmentation은 query의 대상이 이미지에 존재한다는 폐쇄세계 가정 때문에, 미세 객체를 못 보는 실패와 존재하지 않는 객체를 언어 prior로 그려내는 hallucination을 분리하지 못했다.

**가설.** 저해상도 view에서 무조건 mask를 맞히게 하는 대신 “증거가 부족하면 empty mask”를 보상하면 positive mIoU를 크게 희생하지 않고 false positive를 줄일 수 있다. 단, 13개 prompt pool이 실제 사용자 언어를 충분히 대표하는지는 미확인이다.

**최소 실험.** 자체 UAV/항만 이미지 100장에 positive query 50개와 absent-target query 50개를 만든다. 기존 모델과 empty-mask calibration을 비교해 positive mIoU, absent refusal rate, false-mask area, target area <1% 구간 recall을 기록한다. 텍스트 표현은 색·종류·공간관계별로 최소 5개 template을 분리한다.

**판정.** **의미 있는 benchmark 이동**이다. 항공 MLLM의 정확도와 안전 경계를 한 데이터셋에서 함께 보지만, hard-negative 언어 생성 편향과 독립 인간 검수 규모를 추가 확인해야 한다.

## 2. DRA-SAM — 작은 UAV referent를 위해 “어디를 한 번 더 볼지”를 평가 budget에 포함

**확인된 사실.** DRA-SAM은 RIS-LAD와 UAVid-RIS에서 benchmark별로 적응한 SAM3-I를 사용한다. 382,920-parameter EvidenceScorer가 기존 mask 후보와 unresolved state의 belief를 만들고, parameter-free LOOK policy가 2,304개 crop action 중 하나를 선택한다. 선택한 crop만 같은 SAM3-I에 한 번 더 통과시켜 후보를 갱신한다. [논문](https://arxiv.org/abs/2610.33057) · [HTML 원문](https://arxiv.org/html/2610.33057) · [공식 코드](https://github.com/phy709/DRA-SAM)

**저자 주장과 수치.** RIS-LAD matched backbone에서 global SAM3-I는 mIoU/oIoU/P@0.5가 49.55/49.08/46.80이다. EvidenceScorer만 쓰면 51.06/51.65/55.56, 지역 추론을 포함한 DRA-SAM은 52.34/53.45/58.05다. test set 2,763개 중 2,287개(82.8%)가 영상 면적의 1% 미만이며, 이 작은 세 구간에서 P@0.5 증가가 11.70~15.70점이라고 보고한다. UAVid-RIS에서는 73.26 mIoU와 86.86 P@0.5를 보고하지만 oIoU 79.71은 AeroReformer의 81.53보다 낮다.

**동조건 판정.** matched global SAM3-I → EvidenceScorer → DRA-SAM 단계는 같은 checkpoint와 split을 쓰므로 추가 scorer와 local pass의 효과를 비교할 수 있다. 반면 기존 공개 방법과의 전체 표는 각 논문의 evaluation protocol과 independently adapted backbone을 섞으므로 not strictly apples-to-apples다. DRA-SAM은 global baseline보다 backbone pass가 하나 더 있어 latency와 energy budget도 다르다.

**진단.** UAV 영상의 global resize는 작은 대상의 식별 단서를 지운다. 전체 영상을 무조건 두 번 보는 것은 비싸고, top-belief crop은 첫 번째 오판을 확대할 수 있다.

**가설.** 후보 간 disagreement와 unresolved mass를 동시에 쓰면 단순 uncertainty나 random crop보다 한 번의 추가 pass를 더 효율적으로 배치할 수 있다. 다만 향상 중 상당 부분은 crop policy보다 “두 번째 고해상도 관찰 자체”에서 올 수 있다.

**최소 실험.** 같은 100개 aerial RIS sample에서 global-only, random crop, top-belief crop, disagreement crop을 고정된 한 번의 local pass로 비교한다. mIoU/P@0.5와 함께 평균 crop 면적, 추가 latency, peak VRAM, target area bin별 gain을 기록한다. local pass를 쓰지 않은 sample을 허용하는 adaptive gate도 별도 실험한다.

**판정.** **small-object benchmark에 inference allocation을 포함한 이동**이다. 최고 mIoU만 보면 계산 예산 차이를 숨길 수 있으므로 성능-지연 Pareto가 필수다.

## 3. CANARY — failure prediction이 평균 점수에서 “shift cell별 비열화”로 이동

**확인된 사실.** CANARY는 ImageNet-1k validation 50k를 clean reference로 쓰고 ImageNet-C 15 corruption×5 severity, ImageNet-A, ImageNet-R을 평가한다. ObjectNet은 별도 일반화 시험이며 CIFAR-100/CIFAR-100-C도 label-space transfer로 쓴다. 주요 backbone은 ViT-B/16, ResNet-50, Swin-B, ConvNeXt-B, EfficientNet-B4이고 DINOv2와 다른 ViT scale도 추가한다. metric은 base accuracy 차이를 보정하는 e-AURC가 주 지표이고 AUGRC와 AUROC를 보조로 쓴다. [논문](https://arxiv.org/abs/2610.33063) · [HTML 원문](https://arxiv.org/html/2610.33063)

**저자 주장과 수치.** CANARY는 clean validation만으로 PCA residual의 class-conditional kNN distance와 MSP를 calibration한다. 5개 주요 backbone×77 shift cell=385개 비교에서 e-AURC 기준 382개, AUROC 기준 379개 cell에서 MSP와 같거나 낫다고 보고한다. e-AURC에서는 308개 cell에서 20개 detector 중 단독 1위이며, AUROC 최악 회귀는 -0.0002로 seed noise 범위라고 주장한다.

**동조건 판정.** 각 backbone의 같은 prediction·shift cell에서 MSP와 CANARY를 비교하므로 내부 비교는 apples-to-apples다. 그러나 backbone마다 clean validation에서 fusion weight를 별도 cross-fit하고 class별 reference residual을 저장한다. “training-free”는 network weight를 추가 학습하지 않는다는 뜻이지 calibration data·memory·kNN 비용이 없다는 뜻은 아니다.

**진단.** 평균 AUROC 하나는 특정 corruption이나 자연 shift에서 confidence detector가 악화되는 배치 위험을 숨긴다. 또한 raw accuracy가 다른 backbone의 selective risk를 단순 AURC로 비교하면 정확도 차이가 섞인다.

**가설.** 실제 배포에서는 평균 최고점보다 “기존 MSP 대비 악화되는 shift cell 수”와 risk-coverage curve의 안정성이 더 중요한 선택 기준이다. off-manifold residual은 synthetic corruption보다 natural shift에서 더 보완적일 가능성이 높다.

**최소 실험.** 현재 classifier 하나에 MSP와 class-conditional residual kNN을 붙여 clean validation에서만 weight를 정한다. fog, blur, night, different-camera 네 shift×3 severity를 만들고 e-AURC/AUROC뿐 아니라 MSP 대비 악화 cell 수, 90% coverage risk, reference memory, query latency를 기록한다.

**판정.** **leaderboard 목표가 평균 1위에서 안전한 fallback으로 이동한 신호**다. 코드를 독립 확인하지 못했으므로 수치 재현성은 논문 명세에 의존한다.

## 4. OvisOCR3 — benchmark 범위 확장과 동시에 “최고” 서술의 내부 불일치 노출

**확인된 사실.** OvisOCR3는 0.8B 모델 하나로 document parsing, general OCR, KIE, figure captioning, cross-page table reconstruction을 처리한다. 공식 Hugging Face 모델 카드에는 Apache-2.0, Transformers·vLLM·SGLang 사용법과 가중치가 공개돼 있다. 평가에는 OmniDocBench v1.6, PureDocBench, Real5-OmniDocBench, MDPBench, OCRBench/v2, 네 KIE benchmark, DocFigCapBench, CrossTabBench, MPDocBench-Parse가 포함된다. [논문](https://arxiv.org/abs/2610.33066) · [HTML 원문](https://arxiv.org/html/2610.33066) · [공식 모델 카드](https://huggingface.co/ATH-MaaS/OvisOCR3)

**저자 주장과 수치.** 논문 초록은 OmniDocBench v1.6에서 overall 96.74를 달성하고 다른 benchmark에서도 최고라고 기술한다. OCRBench v2 English/Chinese는 65.9/61.3, MDPBench 88.80, PureDocBench 82.31, Real5-OmniDocBench 93.63을 보고한다. cross-page table은 relation F1과 truncated-table TEDS를 분리한다.

**원문 내부 충돌.** 논문 Table 3에서 OvisOCR3 overall은 96.74지만 Xiaomi-OCR-0은 96.83으로 더 높다. OvisOCR3는 Table TEDS 95.16, TEDS-S 97.46으로 표 구조 지표를 앞서지만 overall 단독 1위는 아니다. 따라서 초록의 “OmniDocBench v1.6 최고” 또는 이를 요약한 2차 자료는 본문 표와 일치하지 않는다.

**동조건 판정.** 논문은 일부 baseline을 저자가 로컬 평가하고 dagger로 표시하지만, 나머지는 공식 leaderboard와 각 model report에서 가져왔다. prompt, decoder, evaluator commit, image preprocessing이 완전히 통일됐다고 확인할 수 없어 전체 순위는 not strictly apples-to-apples다. 같은 OvisOCR2↔OvisOCR3의 공개 표도 training data와 multi-task objective가 달라 architecture-only 비교가 아니다.

**진단.** unified OCR은 metric이 많은 만큼 “어느 task에서 무엇이 좋아졌는가”가 overall 한 숫자에 가려진다. 초록의 최고 표현이 표의 개별 metric 또는 다른 benchmark의 최고와 섞일 위험이 있다.

**가설.** OvisOCR3의 실제 강점은 OmniDoc overall 1위가 아니라, 0.8B 한 checkpoint가 MDP/PureDoc/Real5와 cross-page relation을 동시에 처리하는 Pareto 범위에 있다. 평가에서는 overall보다 task별 score와 latency·VRAM을 함께 봐야 한다.

**최소 실험.** OvisOCR2와 OvisOCR3를 동일 Transformers commit, 동일 prompt, 동일 50문서 subset에서 실행한다. text edit, formula CDM, table TEDS/TEDS-S, reading-order edit, cross-page relation F1, tokens/s, peak VRAM을 기록한다. 1페이지와 cross-page 문서를 분리해 통합성의 실제 이득을 확인한다.

**판정.** **평가 범위 확장은 의미 있지만 SOTA 문구는 정정해서 읽어야 한다.** 오늘 네 신호 중 가장 분명한 “저자 서술과 공식 원문 표의 불일치” 사례다.

## 공통 해석

### 무엇이 실제로 바뀌었나

1. 항공 dense grounding에 absent-target refusal과 hard negative가 들어왔다.
2. small-object 성능이 backbone 교체뿐 아니라 추가 관찰을 어디에 배치하는지의 문제로 분리됐다.
3. failure prediction에서 평균 성능 외에 baseline 대비 비열화 cell 수가 중요해졌다.
4. OCR benchmark는 단일 페이지 인식에서 cross-page relation과 reconstruction으로 범위가 넓어졌고, metric별 최고와 overall 최고의 구분이 더 중요해졌다.

### 의미 있는 변화와 leaderboard noise

- **의미 있음:** 같은 backbone·split에서 refusal, local pass, calibration 같은 한 요소만 바꾼 matched control.
- **보류:** independently adapted backbone을 섞은 전체 순위, 외부 보고값을 합친 OCR 표, 생성형 hard-negative prompt의 실제 사용자 대표성.
- **노이즈 가능성:** 추가 inference pass를 숨긴 SOTA, metric 하나의 최고를 overall 최고로 서술하는 요약, 평균 점수만 보고 shift cell 악화를 무시하는 비교.

### 재현 시 반드시 고정할 변수

- Aerial-R1: positive/negative 비율, prompt template, empty-mask threshold, input 1024, base Sa2VA checkpoint.
- DRA-SAM: local pass 수, crop grid·scale, adapted SAM3-I checkpoint, target-area bin, latency.
- CANARY: clean reference split, PCA rank, kNN k, fusion weight cross-fit, class reference memory.
- OvisOCR3: evaluator version/commit, prompt, rendering DPI, max tokens, cross-page pairing, baseline 실행 출처.

## 오늘의 benchmark signal 3개

1. **거부 능력은 정확도와 별도 지표여야 한다.** target이 항상 존재하는 benchmark는 grounding hallucination을 평가하지 못한다.
2. **추가 계산은 성능표에 노출해야 한다.** 한 번의 local pass도 small-object 성능을 크게 바꿀 수 있으므로 pass 수·latency·VRAM을 함께 기록해야 한다.
3. **SOTA 문구보다 표의 comparator를 먼저 본다.** OvisOCR3처럼 초록과 자체 표가 충돌하면 metric별 실제 순위를 기준으로 해석한다.

## 내 연구에 바로 연결되는 포인트

- 해양 안전 VQA와 grounding에서는 “선박이 없음/식별 불가” query를 별도 hard-negative split으로 만들고 refusal rate와 false-region area를 측정한다.
- 안개·야간 CCTV에서는 full-frame 재추론보다 uncertainty/disagreement 기반 crop 1회를 허용하고 target-size bin별 gain과 latency를 비교한다.
- classifier 또는 detector confidence 평가는 평균 AUROC만 쓰지 말고 날씨×강도 cell마다 기존 confidence보다 악화되는 경우의 수를 기록한다.
- 문서·표 OCR을 VQA evidence pipeline에 넣을 때는 single-page OCR 점수와 cross-page relation F1을 분리한다.
- 오늘의 첫 실험은 기존 aerial/maritime grounding 결과 30개에 absent-target query 15개를 추가해 positive IoU와 refusal rate를 동시에 계산하는 것이다. 학습 없이 하루 안에 benchmark 결론이 바뀌는지 확인할 수 있다.
