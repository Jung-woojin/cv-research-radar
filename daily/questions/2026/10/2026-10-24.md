## Q1. 근거 연결형 해무·해양 VLM은 긴 설명의 grounding failure와 후반부 hallucination을 동시에 줄일 수 있는가?

### Research Question / 문제 정의

해무 CCTV나 선박 영상에 대해 VLM이 긴 상황 설명을 만들 때, 각 명사·위험 판단·행동 권고를 `box 또는 mask + track ID + 시간 구간`에 연결하고 근거가 약하면 생성을 멈추게 하면 일반적인 자유 생성보다 근거 있는 정보량을 늘리면서 hallucination을 줄일 수 있는가?

### Observation / 왜 지금 가치가 있는가

- **확인된 사실:** AgentVQA는 5개 agent domain의 1,000문항을 평가했고 최고 모델도 58.5%였다. 저자들의 오류 분석에서는 grounding, 시각 오해, 공간 혼동, viewpoint gap이 주요 실패로 나타났다.
- **확인된 사실:** RetinaGroundBench의 최고 범용 grounding 결과는 F1 23.7%, precision 47.9%, recall 16.5%였다. biomarker 존재를 묻는 VQA 성능과 실제 위치를 찾는 능력 사이에 큰 간극이 있었다.
- **확인된 사실:** 긴 caption 연구는 6개 captioner 평균에서 supported detail이 Q1 0.527에서 Q4 0.333으로 감소하고 generic detail은 0.103에서 0.281로 증가했다고 보고했다.
- **저자 주장:** 세 연구는 각각 agentic visual understanding, 임상 grounding, long-form caption의 위치별 실패가 단일 전체 점수로 가려진다고 본다.
- **레이더 해석:** 해양 안전 문장은 “무엇이 보이는가”와 “어디·언제 관측됐는가”가 분리되면 신뢰하기 어렵다. grounding과 장문 생성의 실패를 한 계약으로 묶는 것이 지금 가장 직접적인 연구 공백이다.

직접 근거:

- AgentVQA: https://arxiv.org/abs/2610.31494
- AgentVQA 공식 코드: https://github.com/zlab-princeton/AgentVQA
- RetinaGroundBench: https://arxiv.org/abs/2610.31205
- Long Caption Position Failure: https://arxiv.org/abs/2610.31111

### Gap

기존 grounded captioning은 주로 object phrase와 image region의 연결을 평가하고, 장문 생성 연구는 문장 위치별 hallucination을 본다. 해무·해양 영상에서 track과 temporal interval까지 포함한 claim-level evidence contract, 그리고 근거가 소진됐을 때 멈추는 정책은 충분히 검증되지 않았다.

### Hypothesis / 핵심 가설

`claim → region/track/time` 연결을 강제하고 grounding confidence가 임계값 아래로 내려가면 생성을 종료하는 방식은 자유 생성보다 supported-claim precision과 temporal grounding을 높이고, 특히 설명 후반부의 generic/hallucinated claim 비율을 낮춘다.

### Experimental Design / 최소 실험(MVP)

1. 보유 해무·항만 영상 또는 Singapore Maritime Dataset에서 120개 clip을 선정한다.
2. 선박·부표·해무 영역과 위험 event에 box/mask, track, 시간 구간을 붙인다.
3. 같은 VLM·같은 decoding budget에서 세 조건을 비교한다: 자유 생성, 문장별 box 근거, claim별 box+track+time 근거와 adaptive stop.
4. claim을 atomic unit으로 분해해 사람이 support/contradiction/unsupported를 blind 평가한다.
5. 초기에 학습 없이 prompting과 constrained output schema만 사용하고, 필요할 때 작은 verifier만 추가한다.

### Baseline과 dataset

- Baseline: free-form caption, region-prompted caption, fixed-length grounded caption.
- Dataset: Singapore Maritime Dataset, SeaShips, 보유 해무 CCTV 중 annotation 가능한 subset.
- 비교 모델: 동일 VLM 한 개로 먼저 고정하고, 결과가 있으면 open-weight VLM 한 개를 추가한다.
- Ablation: box only, box+track, box+track+time, adaptive stop on/off.

### 성공·실패 판정 metric

- 핵심 metric: supported-claim precision/recall, grounding IoU, temporal IoU, track consistency, hallucinated claims per 100 words, late-quartile generic rate.
- **제안 GO 기준:** 자유 생성 대비 supported-claim precision이 10%p 이상 높고 late-quartile hallucinated claim rate가 20% 이상 상대 감소하며, critical hazard recall 하락이 3%p 이내.
- **제안 KILL 기준:** 문장이 짧아져 hallucination은 줄지만 critical hazard recall이 5%p 이상 떨어지거나, annotation agreement가 Cohen’s κ 0.6 미만.

### Compute 난이도

**2/5.** prompt/schema 실험과 저장된 video inference로 시작할 수 있다. verifier fine-tuning을 추가해도 8GB GPU에서 소형 모델 또는 embedding 기반 분류기로 축소 가능하다.

### Novelty 위험요인

grounded captioning과 abstention은 이미 연구됐다. 차별성은 해양 영상에서 **장문 위치별 실패, object track, temporal interval, 안전 판단**을 하나의 evidence contract로 평가하는 데 있다.

### 4~8주 내 논문화 가능성

**5/5.** 1주 내 prompt-only pilot, 2~3주 내 annotation과 metric, 4~6주 내 verifier/ablation이 가능하다. 작은 diagnostic benchmark로도 workshop 제출 가치가 있다.

### Negative result의 가치

근거 연결이 hallucination을 줄이지 못하면 실패 원인이 grounding 형식보다 language prior 또는 unsafe inference에 있다는 증거가 된다. adaptive stop이 recall을 크게 해치면 해양 경보에서는 abstention보다 retrieval·sensor fusion이 필요하다는 결론을 얻는다.

**평가:** 새로움 5/5 · 실행 가능성 5/5 · 계산 효율 5/5 · 논문화 가능성 5/5

## Q2. 해양 tiny-object tracking을 link·repair·inspect로 분해하면 최종 tracking score가 숨기던 개선 가능성을 찾을 수 있는가?

### Research Question / 문제 정의

선박·부표·표류물의 tracking을 최종 MOTA/HOTA만으로 비교하지 않고 `link decision`, `graph repair`, `failure inspection utility`로 분해하면, P2/high-resolution feature나 VLM 보조 판단이 실제로 어떤 오류를 고치는지 식별할 수 있는가?

### Observation / 왜 지금 가치가 있는가

- **확인된 사실:** CellTrack-Bench는 15개 데이터셋, 4개 modality, 1,537개 문제, 9,041개 cell-linking decision을 사용한다.
- **확인된 사실:** 고정 c1 harness에서 GPT-5.6(sol)은 Link F1 0.811, Repair F1 0.815, Inspect F1 0.631을 기록했다. nearest-centroid graph의 `LNK_sub` 0.493과 비교해 해당 모델은 0.767이었다.
- **저자 주장:** 전문 tracker가 함께 실패한 hard cases를 원자적 연결 문제로 바꾸면 VLM이 단순 근접성 shortcut을 넘어 repair와 inspection에 기여하는지 구분할 수 있다.
- **레이더 해석:** 해양 tiny object도 낮은 해상도, 안개, crossing, entry/exit 때문에 전체 track 결과보다 연결 결정의 실패 원인을 먼저 알아야 한다.

직접 근거:

- CellTrack-Bench: https://arxiv.org/abs/2610.31566
- 공식 코드·저장 출력: https://github.com/royerlab/celltrack-bench

### Gap

해양 tracking benchmark는 객체 크기와 가시성 stratification은 일부 제공하지만, 같은 frame pair에서 어떤 연결을 틀렸고 사람이 보거나 VLM이 고칠 수 있는지를 표준화하지 않는다. detector 개선과 association 개선이 한 점수에 섞인다.

### Hypothesis / 핵심 가설

저가시성·tiny-object 구간에서 P2는 detection recall을 높이지만 ID switch 일부만 줄이고, VLM 보조는 crossing/occlusion의 repair에는 도움이 되지만 단순 link에서는 비용 대비 이득이 작다. link/repair/inspect 분해가 이 상호보완성을 드러낼 것이다.

### Experimental Design / 최소 실험(MVP)

1. 20개 해양 clip에서 baseline tracker 세 개가 공통으로 실패한 frame pair를 수집한다.
2. source object 3~5개와 candidate target을 동일 crop/layout으로 렌더링한다.
3. nearest-neighbor, Kalman+appearance, P2 detector tracker, VLM-assisted repair를 동일 후보 집합에서 비교한다.
4. prompt, crop, resize, token budget, parser를 사전에 고정한다.
5. repair가 전체 HOTA/IDF1에 미치는 실제 downstream gain도 다시 연결해 측정한다.

### Baseline과 dataset

- Baseline: nearest centroid, ByteTrack/BoT-SORT류 association, 기본 FPN, P2/high-resolution variant.
- Dataset: Singapore Maritime Dataset 또는 보유 항만 CCTV; 필요하면 SeaDronesSee의 small-object subset.
- Metric: Link F1, division 대신 entry/exit correctness, repair success, inspection precision, ID switches, track fragmentation, HOTA/IDF1.

### 성공·실패 판정 metric

- **제안 GO 기준:** VLM repair가 baseline tracker의 공통 실패 subset에서 Link F1을 8%p 이상 높이고 전체 ID switch를 10% 이상 줄이며, 한 decision의 median latency가 2초 이하.
- **제안 KILL 기준:** link-level 개선이 전체 IDF1/HOTA로 전파되지 않거나, 단순 spatial baseline 대비 이득이 visibility·object-size split에서 일관되지 않음.
- bootstrap confidence interval과 condition별 worst-bin 결과를 함께 보고한다.

### Compute 난이도

**2/5.** 저장 detection과 짧은 frame pair로 대부분 실행할 수 있다. VLM은 소형 subset에서 API 또는 8GB용 quantized model로 평가 가능하다.

### Novelty 위험요인

tracking error taxonomy와 graph repair는 기존 분야다. novelty는 CellTrack식 frozen harness를 **해양 tiny-object의 P2·VLM repair 효용 분석**에 이식하고 최종 tracking metric으로 재연결하는 데 있다.

### 4~8주 내 논문화 가능성

**4/5.** 데이터 annotation 부담이 있지만 100~200개 hard case로 diagnostic paper를 만들 수 있다. 외부 dataset 하나를 더하면 일반화 주장이 강해진다.

### Negative result의 가치

VLM이 spatial baseline을 넘지 못하면 해양 association 병목은 semantic reasoning이 아니라 해상도·motion estimation이라는 결론을 얻는다. link 개선이 최종 점수에 반영되지 않으면 현재 tracking metric 또는 오류 전파 구조를 다시 봐야 한다.

**평가:** 새로움 4/5 · 실행 가능성 4/5 · 계산 효율 4/5 · 논문화 가능성 4/5

## Q3. 압축률을 고정한 gigapixel 표현에서 PSNR보다 tiny-object·해무 하류 성능이 다른 모델 선택을 만드는가?

### Research Question / 문제 정의

gigapixel 해양·위성 영상을 learnable representation으로 압축할 때, 동일 compression ratio에서 PSNR이 높은 표현과 tiny-object detection 또는 fog segmentation을 가장 잘 보존하는 표현이 같은가?

### Observation / 왜 지금 가치가 있는가

- **확인된 사실:** GigaBench는 PSNR뿐 아니라 compression ratio(CR), compression time(CT), full-image inference time(IT)을 함께 보고한다.
- **확인된 사실:** I-NGP(T=24)는 평균 PSNR 33.19 dB와 평균 2분 미만의 fitting을 보고했다. SmartSplat은 CR=15에서 30.40 dB, CT 98.48분, IT 3.36초였다.
- **확인된 사실:** 큰 implicit configuration은 압축에 최대 206분, 전체 gigapixel 복원에 약 7~11분이 걸릴 수 있다.
- **저자 주장:** moderate compression에서는 hybrid, extreme compression이나 빠른 decode가 필요한 조건에서는 다른 표현이 더 유리할 수 있다.
- **레이더 해석:** 해무 boundary와 tiny vessel은 평균 pixel quality가 놓치기 쉬운 구조다. 표현 선택을 reconstruction score만으로 하면 하류 작업에 불리할 수 있다.

직접 근거:

- GigaBench: https://arxiv.org/abs/2610.31644
- 공식 프로젝트: https://matteofusconi.github.io/GigaBench/

### Gap

gigapixel representation benchmark의 quality–size–time 평가는 발전했지만, 해양 remote sensing에서 object AP·boundary IoU·false alarm과 같은 하류 metric까지 같은 CR에서 연결한 비교는 부족하다.

### Hypothesis / 핵심 가설

같은 CR에서 PSNR 상위 표현이 반드시 tiny-object AP나 fog boundary IoU 상위가 아니다. 특히 smoothing 성향이 강한 표현은 PSNR을 유지하면서 작은 선박과 얇은 안개 경계를 지울 수 있다.

### Experimental Design / 최소 실험(MVP)

1. 0.25~1 gigapixel 해양 mosaic 3장을 고른다.
2. I-NGP, SmartSplat, JPEG2000/WebP 계열 baseline을 CR 15와 100에 맞춘다.
3. full decode와 tile-on-demand 두 경로로 frozen detector/segmenter를 실행한다.
4. 원본 대비 metric 변화와 전체 pipeline latency, peak VRAM을 기록한다.
5. PSNR 순위와 downstream 순위의 Kendall tau를 bootstrap한다.

### Baseline과 dataset

- Baseline: uncompressed original, lossless tile, JPEG2000 또는 WebP, I-NGP, SmartSplat.
- Dataset: xView/DIOR의 maritime class가 포함된 대형 scene, Sentinel-2 coastal mosaic, 보유 항만·해무 mosaic.
- Metric: PSNR/SSIM, CR, CT, IT, peak VRAM, AP-small, recall@fixed-FP, fog IoU/boundary F1.

### 성공·실패 판정 metric

- **제안 GO 기준:** 동일 CR에서 reconstruction rank와 downstream rank의 Kendall tau가 0.5 미만이고, 한 표현이 PSNR 1 dB 이내 손실로 AP-small 또는 boundary F1을 3%p 이상 더 보존.
- **제안 KILL 기준:** 모든 표현의 downstream 순위가 PSNR과 안정적으로 일치하거나, CT/IT가 실제 inference budget을 초과해 비교 자체가 비현실적.

### Compute 난이도

**4/5.** representation fitting과 gigapixel I/O가 무겁다. MVP는 crop mosaic, CR 두 점, frozen downstream model로 줄이고 8GB GPU에서는 tile 단위로 실행한다.

### Novelty 위험요인

task-aware compression은 이미 큰 분야다. 차별성은 learnable gigapixel representation의 다축 benchmark에 **maritime tiny-object와 fog boundary 보존**을 연결하는 것이다.

### 4~8주 내 논문화 가능성

**3/5.** 시스템 구축이 병목이지만, 두 representation·두 CR·두 downstream task만으로도 강한 negative-result paper 또는 benchmark note가 가능하다.

### Negative result의 가치

PSNR 순위와 downstream 순위가 같으면 비싼 task-aware 평가 없이 reconstruction metric으로 초기 선별할 수 있다는 실용적 결론을 얻는다. 표현 fitting cost가 너무 크면 learnable compression의 운영 한계를 정량화할 수 있다.

**평가:** 새로움 4/5 · 실행 가능성 3/5 · 계산 효율 2/5 · 논문화 가능성 4/5

## Q4. 해무 예측의 첫 물리 위반 시점을 찾으면 frame-level 오차보다 실패 원인을 더 잘 분리할 수 있는가?

### Research Question / 문제 정의

video fog nowcasting 또는 생성형 해무 augmentation에서 prediction과 observation의 시간별 alignment를 추적해 `첫 물리적 위반 구간`을 찾으면, 전체 SSIM/LPIPS나 frame accuracy가 구분하지 못하는 continuity·persistence·boundary motion 실패를 진단할 수 있는가?

### Observation / 왜 지금 가치가 있는가

- **확인된 사실:** PhysTrace는 물리 타당성의 이진 판정 대신 violation interval localization을 평가한다.
- **확인된 사실:** IntPhys2-Timing에서 전체 Hit Rate는 Continuity 63.2%, Immutability 70.7%, Permanence 56.6%, Solidity 69.6%였다.
- **확인된 사실:** 공개 방식은 과거 관측으로 다음 상태를 서술한 뒤 실제 video window와의 alignment 변화를 추적한다.
- **저자 주장:** 물리적으로 이상한지뿐 아니라 언제 어떤 속성이 깨지는지를 찾을 수 있다.
- **레이더 해석:** 해무는 물체처럼 고정된 solidity를 갖지 않지만, 발생·이동·소멸의 continuity와 persistence는 time-localized diagnosis가 가능하다.

직접 근거:

- PhysTrace: https://arxiv.org/abs/2610.31429
- 공식 코드: https://github.com/PhysTrace/PhysTrace

### Gap

해무 예측 평가는 보통 frame 평균 error나 event detection을 사용한다. forecast가 언제부터 관측과 물리적으로 불일치했고, 그 불일치가 advection·growth·dissipation 중 무엇인지 구간 annotation과 함께 평가하는 표준은 부족하다.

### Hypothesis / 핵심 가설

optical-flow/meteorological prior로 만든 간단한 expected-state representation과 multi-frame alignment를 결합하면 frame anomaly score보다 첫 위반 시점을 정확히 찾고, 오류 유형별 개선 방향을 제시할 수 있다.

### Experimental Design / 최소 실험(MVP)

1. 60개 해무 sequence에서 onset, growth, drift, dissipation event를 annotation한다.
2. persistence baseline, optical-flow warp, 기존 nowcasting model의 예측을 비교한다.
3. pixel error, feature alignment, expected-state text+vision alignment 세 detector를 적용한다.
4. window와 stride, threshold를 사전에 고정하고 ±20% sensitivity를 측정한다.
5. first-violation time과 사람이 붙인 failure interval을 비교한다.

### Baseline과 dataset

- Baseline: per-frame SSIM/LPIPS threshold, optical-flow residual, ConvLSTM 또는 보유 nowcasting baseline.
- Dataset: 보유 해무 CCTV sequence, 공개 coastal CCTV 또는 time-lapse fog subset.
- Metric: interval Hit Rate, temporal IoU, onset lead/lag, failure-type macro F1, false alarm per hour.

### 성공·실패 판정 metric

- **제안 GO 기준:** frame residual baseline 대비 temporal IoU가 0.10 이상 높고 first-violation median absolute error가 20% 이상 감소하며 threshold 변화에서도 순위가 유지.
- **제안 KILL 기준:** 사람 간 interval agreement가 낮거나, feature/text alignment가 단순 optical-flow residual을 넘지 못함.

### Compute 난이도

**3/5.** 기존 prediction이 있으면 inference 중심이다. 8GB GPU에서도 짧은 window와 frozen encoder로 가능하다.

### Novelty 위험요인

video anomaly localization과 forecast error attribution은 알려져 있다. novelty는 해무 dynamics의 event taxonomy와 PhysTrace식 **first-violation localization**을 결합하는 데 있다.

### 4~8주 내 논문화 가능성

**4/5.** 소형 annotated dataset과 baseline 세 개로 시작할 수 있다. 물리 변수나 기상 센서가 추가되면 기여가 강해진다.

### Negative result의 가치

복잡한 alignment가 residual baseline을 넘지 못하면 해무에서는 language-based physical prior보다 optical flow와 관측 센서가 중요하다는 결론을 얻는다. annotation agreement가 낮으면 “물리 위반” 정의 자체의 불확실성을 보고할 수 있다.

**평가:** 새로움 5/5 · 실행 가능성 4/5 · 계산 효율 4/5 · 논문화 가능성 4/5

## Q5. 웹에서 얻은 변환 조합에 강한 합성 해양 이미지 detector는 artifact fingerprint보다 semantic/provenance 신호를 더 사용해야 하는가?

### Research Question / 문제 정의

합성 해양·선박 이미지 detector가 resize, sharpening, denoise, color transform, recompression 같은 CPU 후처리 조합에서 무너질 때, artifact feature 대신 scene semantics와 provenance-consistency feature를 추가하면 worst-transform robustness를 높일 수 있는가?

### Observation / 왜 지금 가치가 있는가

- **확인된 사실:** WildFakeToolBench는 220개 공개 출처, 142개 domain에서 얻은 156개 executable CPU tool을 수집했다.
- **확인된 사실:** 5개 generator의 105개 이미지와 6개 detector에서 강한 단일 tool의 attack success rate는 detector에 따라 25.25~100%였다.
- **확인된 사실:** 8-tool pool의 subset 평가에서 모든 detector에 대해 worst-case coverage가 80%를 넘었다.
- **확인된 사실:** SSIM 0.75 이상 조건만으로 자연스러움과 semantic preservation을 보장하지 못했다.
- **저자 주장:** 공개 웹 정보와 CPU 도구만으로도 detector-specific sparse weakness를 찾을 수 있다.
- **레이더 해석:** 해양 이미지는 압축·dehazing·색 보정이 흔해 artifact detector의 domain shift가 더 클 수 있다.

직접 근거:

- WildFakeToolBench: https://arxiv.org/abs/2610.31152
- 논문 연결 저장소: https://github.com/TrustAIRLab/WildFakeToolBench

### Gap

AI-image detection은 평균 augmentation robustness를 자주 보고하지만, 실제 웹 변환 조합의 worst case, semantic preservation, 해양 domain shift를 한 평가에 묶지 않는다. 논문 연결 저장소는 점검 시점에 공개 API에서 404여서 정확한 도구 재현성에도 공백이 있다.

### Hypothesis / 핵심 가설

frequency/artifact 중심 detector는 특정 transform에 높은 취약성을 보이고, content-independent provenance feature 또는 cross-view consistency를 결합한 detector는 clean accuracy를 크게 해치지 않으면서 worst-transform TPR을 개선한다.

### Experimental Design / 최소 실험(MVP)

1. 실제·합성 해양 이미지 각 150장을 모은다.
2. resize/recompression, denoise/sharpen, color/tone, 복합 pipeline 네 family를 CPU로 적용한다.
3. artifact detector, vision-language semantic detector, 두 score의 calibrated ensemble을 비교한다.
4. SSIM과 함께 객체/scene label 보존을 사람이 표본 검증한다.
5. 평균 성능보다 family별 worst group과 unseen composition을 우선 보고한다.

### Baseline과 dataset

- Baseline: 공개 synthetic-image detector 2개, CLIP/VLM embedding classifier, calibrated ensemble.
- Dataset: 공개 AI-generated image benchmark의 maritime subset + 실제 SeaShips/항만 이미지 + 같은 prompt의 생성 이미지.
- Metric: AUROC, TPR@1%FPR, worst-group TPR, calibration error, clean false-positive rate, semantic-preservation pass rate.

### 성공·실패 판정 metric

- **제안 GO 기준:** ensemble이 artifact baseline 대비 worst-group TPR@1%FPR을 10%p 이상 높이고 clean false-positive rate 증가가 0.5%p 이하.
- **제안 KILL 기준:** semantic/provenance feature가 generator identity만 학습하거나 unseen transform에서 개선이 사라짐.

### Compute 난이도

**2/5.** 변환은 CPU이고 frozen embedding으로 시작할 수 있다. 8GB GPU에서 batch를 줄이면 충분하다.

### Novelty 위험요인

robust synthetic-image detection은 경쟁이 치열하다. 차별성은 **웹 변환의 worst case, semantic preservation, maritime domain**을 같이 평가하는 소형 but auditable benchmark에 있다.

### 4~8주 내 논문화 가능성

**4/5.** 도구 manifest와 평가 protocol을 명확히 공개하면 workshop/benchmark paper 가능성이 있다. 공식 저장소가 현재 접근되지 않는 점 때문에 독립 재구성이 필요하다.

### Negative result의 가치

semantic feature도 무너지면 현재 detector가 generator·content shortcut에 의존한다는 근거가 된다. ensemble이 clean FP를 높이면 provenance metadata나 watermark처럼 image-only detector 밖의 신호가 필요하다는 결론을 얻는다.

**평가:** 새로움 4/5 · 실행 가능성 5/5 · 계산 효율 5/5 · 논문화 가능성 4/5

## Q6. Embodiment-matched offline proxy는 해양 로봇 정책 선별 비용을 줄이면서 실제 rollout 순위를 보존할 수 있는가?

### Research Question / 문제 정의

해양·수상 로봇 VLA의 시각 표현과 motion trajectory geometry를 정렬하는 offline score를 만들 때, 같은 플랫폼의 reference trajectory를 쓰면 적은 실제 rollout으로 정책 순위를 안전하게 선별할 수 있는가?

### Observation / 왜 지금 가치가 있는가

- **확인된 사실:** Sensorimotor Alignment(S²)는 12개 fine-tuned VLA에서 SimplerEnv-WidowX 성공률과 Pearson `r=0.717`, model-bootstrap 95% CI `[0.436, 0.912]`을 보고했다.
- **확인된 사실:** matched bimanual ALOHA reference로 3개 WAM을 비교했을 때 `r=0.999`였지만 mismatched single-arm DROID reference에서는 `r=0.246`, `p=0.421`이었다.
- **확인된 사실:** text-only feature는 유의한 양의 상관을 보이지 않았다.
- **저자 주장:** 감각 표현이 행동의 물리 구조를 반영하는 정도가 policy success의 training-free proxy가 될 수 있다.
- **레이더 해석:** reference embodiment가 proxy의 일부이므로, 이를 고정하지 않은 leaderboard는 모델이 아니라 reference 선택을 평가할 수 있다.

직접 근거:

- S²: https://arxiv.org/abs/2610.31670
- 공식 코드: https://github.com/yunfeixie233/sensorimotor-alignment
- 공식 프로젝트: https://yunfeixie233.github.io/s2/

### Gap

해양 로봇에서는 실제 rollout이 비싸고 위험하지만, land-manipulation reference를 그대로 사용하면 hull dynamics, camera pose, action space가 맞지 않는다. matched와 mismatched reference 민감도를 함께 보고하는 선별 protocol이 부족하다.

### Hypothesis / 핵심 가설

동일 camera/action space의 짧은 reference trajectory로 계산한 alignment score는 정책 checkpoint의 rollout 순위를 보존하지만, platform 또는 viewpoint가 바뀌면 상관이 급격히 낮아진다. proxy는 최종 평가가 아니라 screening gate로만 유효하다.

### Experimental Design / 최소 실험(MVP)

1. simulator 또는 기록된 항해 데이터에서 같은 task의 정책 checkpoint 4개를 준비한다.
2. matched reference, viewpoint-mismatched reference, platform-mismatched reference를 만든다.
3. proxy 계산 후 각 checkpoint를 simulator 20회 또는 실제/반실물 10회 rollout한다.
4. reference당 Spearman/Kendall rank와 success·collision·intervention을 비교한다.
5. proxy 상위 정책만 rollout하는 정책이 전체 rollout 대비 얼마나 비용을 줄이는지 계산한다.

### Baseline과 dataset

- Baseline: visual embedding similarity, action-distribution divergence, random/reference-free ranking, S²식 alignment.
- Dataset: VRX/MarineGym류 simulator 또는 보유 USV trajectory; same-view와 shifted-view를 분리한다.
- Metric: Spearman/Kendall rank, top-1 selection regret, success, collision/intervention, rollout saved, proxy compute time.

### 성공·실패 판정 metric

- **제안 GO 기준:** matched reference에서 Kendall tau 0.6 이상, top-1 selection regret 5%p 이하, 실제 rollout 수 40% 이상 절감.
- **제안 KILL 기준:** reference subset 변화로 순위가 자주 뒤집히거나 proxy 개선이 rollout success 개선과 연결되지 않음.
- mismatched 조건의 하락 자체도 필수 결과로 보고한다.

### Compute 난이도

**3/5.** proxy 자체는 가볍지만 simulator/robot rollout이 필요하다. MVP는 기록 trajectory와 simulator로 제한한다.

### Novelty 위험요인

offline policy evaluation은 오래된 분야다. novelty는 **embodiment mismatch sensitivity와 screening regret**를 해양 로봇 조건에서 명시적으로 측정하는 데 있다.

### 4~8주 내 논문화 가능성

**3/5.** simulator만으로는 workshop 수준이며 실제 USV trace가 있으면 강해진다. 플랫폼 준비 시간이 가장 큰 위험이다.

### Negative result의 가치

matched reference에서도 rank가 보존되지 않으면 표현 정렬만으로 dynamics와 closed-loop recovery를 설명할 수 없다는 근거가 된다. 이는 proxy를 안전 gate로 쓰지 말아야 한다는 중요한 운영 결론이다.

**평가:** 새로움 4/5 · 실행 가능성 3/5 · 계산 효율 3/5 · 논문화 가능성 4/5
