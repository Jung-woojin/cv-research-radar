## 1) 오늘의 전체 DL 트렌드 5줄

1. VLM의 입력 변환은 method 바깥이 아니라 method의 일부다.
2. frame sampling·camera view·execution provider가 바뀌면 비교 대상 자체가 달라질 수 있다.
3. batch size·parser·cache key는 평가 score의 숨은 confounder다.
4. edge VLM의 INT4/ONNX packaging은 유망하지만 열린 PR을 production feature로 읽으면 안 된다.
5. 오늘의 우선순위는 새 fine-tuning보다 입력-출력-설정 regression artifact를 만드는 것이다.

## 2) CV / DL-CV 핵심

### Lie Routing Vision Language Models for View-Robust 3D Understanding
- **상태:** 2026-11-01 arXiv v1. https://arxiv.org/abs/2611.02306
- **사실/저자 주장:** viewpoint-induced semantic drift를 정의하고 geometry token routing·feature correction으로 3D captioning, grounding, detection, spatial reasoning 개선을 주장한다.
- **진단:** held-out camera trajectory 없이 view invariance와 train-view fitting을 분리하기 어렵다.
- **최소 실험:** 동일 scene/query의 azimuth/elevation 100쌍에서 answer consistency, grounding IoU, calibration을 기록한다.

### Seeing Through the Illusion: Test-Time Scaling for World Action Models
- **상태:** 2026-11-02 arXiv v1. https://arxiv.org/abs/2611.03585
- **저자 주장:** frozen WAM의 validity·temporal/inverse-dynamics consistency·task progress selector가 RoboLab Cosmos 3 Edge 4-candidate success를 6.0%→24.0%, LIBERO DreamZero mean을 75.1%→78.3%로 높인다.
- **주의:** selection quality와 candidate compute가 함께 변한다.
- **최소 실험:** random/validity/progress/full selector를 candidate 1/2/4/8에서 success, wall-clock, rejection rate로 비교한다.

### Zero-shot evaluation of open vision-language models as System 1 decision models on radiology tasks
- **상태:** 2026-11-01 arXiv v1. https://arxiv.org/abs/2611.01631
- **저자 주장:** 7 task에서 report-text retrieval AUROC가 모두 0.95 초과, motion-artifact severity에는 어떤 model도 잘 작동하지 않았다.
- **주의/실험:** multi-question 호출 패턴이 cost 결론을 바꾼다. modality별 50 사례에서 fixed-token과 multi-question 조건의 AUROC·latency·cost를 비교한다.

### vLLM — video VLM timestamp와 graph path
- **상태:** 2026-11-03~04 open issue.
- **사실:** #65523은 32-frame sampling의 source-time mismatch, #65531은 precomputed multimodal embedding+CUDA graph engine failure, #65513은 attention routing TTFT 병목을 보고한다. H100 수치는 작성자 prototype 결과다.
- **최소 실험:** 30초/150초 synthetic video에서 selected frame, prompt timestamp, FPS, TTFT를 저장하고 timestamp error가 1 frame을 넘으면 path를 보류한다.

## 6) 중요한 Finding 3개

1. input metadata preservation이 VLM temporal reasoning의 전제다.
2. evaluation configuration은 score의 metadata가 아니라 causal variable이다.
3. quantization/provider 선택은 efficiency뿐 아니라 output fidelity와 failure pattern을 바꾼다.

## 9) Top 1 미니 리뷰 — vLLM video timestamp

고정 frame 수는 compute를 맞추지만 source-time semantics를 보장하지 않는다. 30초와 150초 clip의 같은 event를 비교해 source frame, sampled index, prompt timestamp, response를 연결하면 semantic reasoning failure와 preprocessing contract failure를 분리할 수 있다. 이슈 하나가 모든 model path를 일반화하지는 않으며, 그러므로 model별 regression artifact가 필요하다.
