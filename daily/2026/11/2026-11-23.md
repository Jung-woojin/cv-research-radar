## 2) CV / DL-CV 핵심 6편

### C1. Depth Pro 2: Sharp and Temporally Consistent Metric Monocular Depth

**최근 연구, v1 UTC 11/19.** image와 video를 함께 처리하는 multi-view transformer와 DPT decoder로 native-resolution metric depth를 예측한다. **저자 보고:** 경계 선명도와 시간 일관성의 trade-off를 개선하며 Sintel·Spring의 Boundary F1·Jitter를 제시한다. 이번에는 개별 표 수치를 확정하지 않았다. **진단·제안:** temporal smoothing이 thin structure를 지우는지 객체 경계·가림 구간별로 본다. 공식 데모는 각 baseline의 기본 해상도와 H+의 native resolution을 쓰므로 시각 비교는 **not strictly apples-to-apples**다. 같은 입력 해상도·frame 수·실측 latency에서 정확도–jitter–boundary 곡선을 다시 비교할 가치가 있다. UAV의 전선·작은 표적 depth 안정성과 연결되지만 해당 domain 전이를 검증한 것은 아니다. code·HF 모델 안내를 확인했으며 실제 weight 다운로드·실행은 하지 않았다.

### C2. Tracking Objects Through Assembly and Decomposition

**최근 연구, v1 UTC 11/19.** Atlas는 initial prompt 없이 전체 object track과 assembly/decomposition을 복원한다. forward·reverse spatiotemporal partition을 함께 추론하며 OmniST에 두 종류의 event를 주석화한다. **저자 보고:** 기존 방법보다 두 배 이상 많은 state change를 복원한다. [논문](https://arxiv.org/abs/2611.26269), [본문](https://arxiv.org/html/2611.26269v1)

**진단·제안:** event recall 증가가 segmentation 후보 증가에서 오는지, 양방향 event reasoning에서 오는지 나눈다. 전체 clip의 역방향 처리는 미래 frame을 사용하는 offline 조건이다. causal tracker와 동일한 latency·관측 범위로 비교하기 전 실시간 우월성을 말할 수 없다. assembly·decomposition·단순 가림을 따로 평가하고 event precision과 오검출도 측정해야 한다. maritime의 합쳐 보이는 선박과 실제 물체 결합은 다른 현상이므로 직접 전이를 가정하지 않는다. [공식 프로젝트](https://atlas-track-objects.github.io/)에 code/data 안내가 있으나 다운로드·주석 검수는 수행하지 않았다.

### C3. RL Post-Training in Diffusion Transformers Is Activation Steering

**최근 연구, v1 UTC 11/19.** frozen diffusion model의 block output에 prompt·token·sampling seed와 무관한 vector를 더하고 RL-tuned teacher의 velocity를 맞춘다. **저자 보고:** SD3.5-M에서 0.29M parameter로 18.8M LoRA보다 작으며, 여섯 image 모델의 reward gain 90.0~96.3%를 회수한다. [논문](https://arxiv.org/abs/2611.26627)

**진단·제안:** 표현의 새로운 계산과 기존 계산의 선택을 분리하는 단순 intervention이라는 점이 핵심이다. reward 회수 비율은 절대 task accuracy가 아니다. teacher supervision도 사용하므로 “추가 학습 없이 RL을 대체했다”고 읽으면 안 된다. held-out 조합·희귀 속성·reward 밖 metric에서 base/teacher/vector를 같은 noise로 비교한다. parameter 절감과 end-to-end 학습비용 절감은 별도로 측정한다. [본문](https://arxiv.org/html/2611.26627v1)에 same-size LoRA·seed·색상·다양성·한계 분석 항목이 있으나 모든 표를 감사하지는 않았다.

### C4. One Prior, Two Dynamics: Repurposing Video Diffusion Transformers for Self-Supervised Latent Action Learning

**최근 연구, v1 UTC 11/19.** O²LaF는 동일 pretrained video prior로 inverse transition encoder와 causal forward generator를 초기화하고 compact action bottleneck으로 공동 학습한다. navigation·robot manipulation에서 few-shot probing과 zero-shot transfer 개선은 **저자 주장**이며 이번 조사에서는 수치를 확정하지 않았다. [논문](https://arxiv.org/abs/2611.26617)

**진단·제안:** latent가 action을 표현하는지 appearance·camera motion을 부호화하는지 배경 교환과 embodiment 교차 probe로 구분한다. 동일 prior·bottleneck 크기의 baseline이 필요하다. pretrained generator와 V-JEPA2 비교는 전체 학습·데이터 조건을 맞추기 전 **not strictly apples-to-apples**다. [공식 repo](https://github.com/showlab/O2LaF)는 현재 README·license·그림 중심이며 code/weights는 “coming in the next few days”로 안내한다. 현재 실행 가능한 공개 구현으로 분류하지 않았다.

### C5. Training Vision Models for LLM-Driven Weight-Space Programming

**최근 연구, v1 UTC 11/19.** 다섯 LLM이 CNN·ViT를 직접 편집하는 2,600개 이상의 process를 Waterbirds·CIFAR-100·PACS·Entity-30에서 평가한다. Edit-Ready Training은 closed-form weight edit를 훈련 중 연습하며 held-out 성공·부작용·accuracy loss를 측정한다. **저자 보고:** 편집 준비 훈련이 표준 모델의 어려운 편집을 개선한다. [논문](https://arxiv.org/abs/2611.26408)

**진단·제안:** “편집할 수 있는 표현”과 “강한 LLM 편집자”의 효과를 나눠야 한다. 같은 edit 예산에서 heuristic closed-form edit·gradient edit·LLM edit를 비교하고 untouched class와 OOD 손상을 확인한다. Waterbirds의 spurious feature 제거에도 쓸 질문이지만 결과를 이미 입증했다고 쓰지 않는다. framework·trajectory·score는 공개 예정 문구이며 실제 배포를 확인하지 못했다. 정확한 gain·GPU 비용·seed variance는 미확인이다.

### C6. BADAS-3.0: Real-Time Driving Perception and Planning from One Camera

**최근 연구, v1 UTC 11/19.** 1B video encoder와 네 head로 speed·ego-pose·risk·여섯 future trajectory를 출력한다. **저자 보고:** 현재 speed를 제공한 조건에서 다섯 trajectory benchmark의 minADE₆가 34B Alpamayo 2 Super보다 44% 낮다. 공통 camera rig에서는 동등하며 이득은 두 모델 모두 훈련하지 않은 rig에서 나온다고 명시한다. [논문](https://arxiv.org/abs/2611.26294)

**진단·제안:** headline을 일반적인 planning 우월성으로 확대하지 않는다. camera 수·입력·학습 데이터가 달라 **not strictly apples-to-apples**다. 본문 runtime은 compiled A100·batch one에서 43ms·1.9GiB라고 보고한다. open-loop collision/NCAP pass rate도 closed-loop 안전 보장이 아니다. camera calibration·speed conditioning을 고정해 rig별 오차를 먼저 분해하는 편이 유용하다. [실험·한계](https://arxiv.org/html/2611.26294v1). weights·데이터 전체의 실제 배포는 이번 조사에서 확정하지 않았다.

## 3) VLM / Multimodal / Video 핵심 3편

### V1. Interpreting DeepStack-Style Vision-Language Models: Do Input or Deeper-Layer Visual Tokens Drive Answers?

**최근 연구, v1 UTC 11/19.** main·later visual entry에 색이 다른 동일 장면의 feature를 각각 넣어 어느 근거를 따르는지 비교한다. **저자 보고:** 사진에서 DeepStack은 later, Qwen3-VL은 main 쪽 답을 따른다. 양쪽을 같은 blur로 손상한 stripe task에서 Qwen 8B·32B는 모두 50 percentage points 손실을 보이지만 later만 복원하면 각각 약 8·48 points를 회복한다. [논문](https://arxiv.org/abs/2611.25713)

**진단:** influence·recovery·removal을 구분한 설계가 중요하다. 구조 이름으로 feature의 쓰임을 예측할 수 없다. 작은 객체의 정보가 later에 있어도 readout이 활용하지 못할 가능성을 검사하는 출발점이다. 모델 크기 차이를 decoder의 원인으로 확정할 수는 없다. mini-review에 개입과 한계를 정리했다. [공식 code/data repo](https://github.com/yucheng-du/interpreting-deepstack-style-vlms)에 접근했지만 실행 재현은 하지 않았다.

### V2. Recurrent Vision Language Models Solve the Shell Game

**범위 확장, v1 UTC 11/18.** pretrained VLM의 attention layer가 완료된 frame group의 출력에서 KV를 계산해 시간 방향으로 recur하도록 한다. **저자 보고:** VET-Bench 100%, MET-Bench 99.6%, 최대 30-swap 학습 후 50-swap에서 99%다. [논문](https://arxiv.org/abs/2611.25210)

**진단·제안:** “장기 memory가 늘었다”보다 serial state transition 능력이 개선됐다는 가설을 검증한다. 현재 상태 유지와 과거 상세 회상의 trade-off도 보고한다. 같은 frame·연산 예산에서 명시적 state tracker 및 비재귀 모델과 비교하고 중간 시점 질의·역순 질의·누락 frame을 교차한다. shell-game 성공을 일반 영상 이해로 확대하지 않는다. code는 공개 예정으로 명시돼 있다. 전체 학습비용·실제 checkpoint 배포는 미확인이다.

### V3. TacInno: Teaching Vision-Language-Action Models the Contact Dynamics Beyond Vision and Action

**최근 연구, v1 UTC 11/19.** 시각·실행 action으로 예측 가능한 tactile 변화를 제외한 innovation을 discrete code로 압축해 training target으로 사용한다. 배포 때 code용 추가 module이 없다는 설명이다. **저자 보고:** 여섯 simulation task 평균 87.5%, 네 real task 70.5%이며 강한 visuo-tactile baseline 대비 각각 +10.7·+9.0 percentage points다. [논문](https://arxiv.org/abs/2611.26405)

**진단·제안:** 유용한 접촉 정보와 gripper 움직임의 재기술을 분리한다. action-conditioned target·unconditioned target·shuffled target을 같은 학습량으로 비교하고 미관측 object/material에서 성능을 확인한다. “추가 module 없음”은 전체 배포 sensing·encoder 비용이 0이라는 뜻이 아니다. tactile runtime 입력의 세부 구성, seed variance·code/weights 배포는 미확인이다.

## 4) LLM / Agent / Training / System 변화 3편

### L1. SKILL.PNG: Learning Agent Skills in Pixel Space

**최근 연구, v1 UTC 11/19.** frozen VLM vision encoder를 통해 image pixel을 최적화해 skill input으로 사용한다. **저자 보고:** 4 VLM×4 benchmark 중 9/16에서 textual skill보다 높고 inference image token은 64~256개다. [논문](https://arxiv.org/abs/2611.26296)

**확인 사실:** [공식 README](https://github.com/omseeth/skill.png)는 jointly optimized ensemble 안 전이는 가능하지만 ensemble 밖 모델로는 전이하지 못했다고 적는다. 전처리 해상도와 fused Mamba kernel의 중요성도 명시한다. **제안:** 같은 모델의 resize/JPEG·processor 변경과 미관측 task를 평가해 semantic instruction인지 model-specific optimization인지 나눈다. token 수 감소만으로 학습·vision encoding을 포함한 비용 우월성을 확정하지 않는다.

### L2. Learning to Defer under Expert Drift

**최근 연구, v1 UTC 11/19.** 최근 expert outcome의 sequence로 deferral head를 조건화한다. image classification·medical diagnosis·hate speech에서 시간 변화에 적응하는 성능은 **저자 보고**이며 수치는 이번에 확정하지 않았다. [논문](https://arxiv.org/abs/2611.26440)

**진단·제안:** expert 정답 여부가 즉시 관측되는 설정과 실제 지연 feedback 설정을 나눈다. confidence calibration·coverage·지연 길이별 regret를 봐야 한다. [공식 repo](https://github.com/ZiyaoMou/L2D-Expert-Drift)는 training code를 제공하지만 plotting/evaluation utility는 포함하지 않는다고 명시한다. CheXpert expert curve의 재구성·rescaling도 안내하므로 자연 상태의 온라인 전문가 실험과 구분한다. annotation routing에 연결할 수 있지만 실제 임상 효과를 주장하는 근거로 삼지 않는다.

### L3. TideCache: Efficient Hybrid LLM Serving with Transparent Cache Management and Layer-Wise Streaming

**최근 연구, v1 UTC 11/19.** hybrid model의 heterogeneous cache 사이 physical page를 재분배하고 과거 global-attention prefix를 layer별 stream한다. generated KV는 resident로 남긴다. **저자 보고:** GB300·GH200의 일곱 구성에서 SGLang+HiCache 대비 agent turn 최대 2.04배, overall P50 per-token latency 20~59% 감소다. [논문](https://arxiv.org/abs/2611.26619)

**진단·제안:** host–device bandwidth와 bounded-state layer의 compute가 transfer를 숨기는 조건을 검사해야 한다. 일반 PCIe GPU나 모든 VLM serving으로 수치를 옮기지 않는다. queue·context·concurrency별 tail latency와 실제 메모리 사용을 같은 workload로 측정한다. 이번 조사에서 실행 가능한 공식 code release·재현 recipe·전력 비용은 확정하지 못했다.

## 6) 연구적으로 중요한 Finding 3개

1. **영향력과 유효 정보 활용은 다른 측정이다.** DeepStack의 conflict 개입과 clean/degraded 복원은 각각 답의 의존성과 오류 회복을 본다. **추론:** feature 중요도 heatmap만으로 bottleneck을 판정하면 confidence 변화와 실제 task recovery를 혼동할 수 있다. [근거](https://arxiv.org/html/2611.25713v1)
2. **작은 개입의 성능 회수가 새 능력의 부재를 곧바로 증명하지 않는다.** steering은 고정 vector의 충분성을 특정 reward에서 보인다. **추론:** reward 밖 조합·다양성·실패 slice에 teacher 고유 이득이 남는지가 다음 질문이다. [근거](https://arxiv.org/abs/2611.26627)
3. **추가 modality보다 조건부 잔차가 더 좋은 supervision일 수 있다.** TacInno는 이미 설명 가능한 tactile 변화를 구분한다. **추론:** 다른 센서에서도 이 원리가 성립하는지는 독립 문제이며 visual/action predictor가 놓친 잡음까지 target으로 남길 위험을 검사해야 한다. [근거](https://arxiv.org/abs/2611.26405)

## 9) Top 1 미니 리뷰 — DeepStack visual entry 진단

**왜 중요한가:** representation이 존재하는지와 decoder가 실제 쓰는지를 분리할 수 있다. main/later 각각에 상충하는 object feature를 넣는 influence 검사와 동일 장면을 복원하는 recovery 검사가 핵심이다.

**실험 논리:** main/later에 clean(C)·degraded(D)를 교차한다. `A_DC − A_DD`는 손상된 main 아래 later 복원의 이득이다. 여기에 `A_CC − A_CD`를 빼면 main 품질에 따른 복원 이득 차이를 본다. conflict에서는 target·control 객체 반응을 함께 읽는다. 답 생성과 candidate log-probability도 분리한다. [설계](https://arxiv.org/html/2611.25713v1)

**실제 기여:** 같은 DeepStack 계열도 entry의 역할이 달라 checkpoint·task별 진단이 필요하다는 관찰이다. **한계:** feature 구성·projector·해상도·학습이 함께 달라 구조적 원인을 특정하지 못한다. bounding-box token도 contextualized되어 영역 밖 정보를 포함한다. 사진 panel은 64장이고 benchmark는 선택 validation subset이다. 일부 분석은 exploratory·unadjusted interval이다. 저자도 main이 손상되었음을 모델이 감지했다고 해석하지 않는다.

**가져올 것:** 작은 객체에서 main/later를 바로 pruning하지 말고, 크기와 손상 위치에 따른 recovery map부터 만든다. 오늘 MVP는 한 checkpoint·직접 답변·동일 processor로 시작한다. 실제 최소 VRAM은 weight precision·해상도·offload에 따라 달라 이번 조사에서 확정하지 않았다.

## 10) 후속 연구 씨앗 3개

아래는 제안이며 실험 결과가 아니다. GO/KILL은 사전에 고정할 판단 규칙이다.

### S1. 작은 객체의 later feature는 정보가 부족한가, 읽히지 않는가?

- **관찰→진단:** V1에서 checkpoint마다 recovery가 다르다. 객체 크기에 따른 차이는 아직 이 조사로 설명되지 않았다.
- **가설:** tiny-object failure 중 일부는 later feature 부재보다 decoder 활용 실패다.
- **최소 개입·실험:** GQA attribute 이미지에서 객체 크기·region-local blur·전체 blur를 교차한다. 같은 checkpoint의 C/C·C/D·D/C·D/D와 self-patch·무관 객체 patch를 비교한다. feature probe는 별도 학습·test 이미지로 나누고 balanced accuracy를 본다.
- **판정:** probe 정보가 유지되지만 recovery가 낮고 무관 객체 대조로 설명되지 않으면 readout 가설을 추적한다. probe와 recovery가 함께 붕괴하면 정보 손실 쪽으로 전환한다. 둘이 모두 정상이라면 tiny-object bottleneck 가설을 KILL한다.
- **비용·신규성:** frozen inference와 작은 probe부터 시작한다. 정확한 GPU 비용은 미측정. 원 논문이 이미 recovery·task 차이를 다루므로 **크기별 probe–recovery 불일치**가 없으면 독립 기여가 약하다. 4~8주에는 한 계열과 두 visual task로 제한한다.

### S2. 고정 steering의 reward 회수는 드문 조합에도 유지되는가?

- **관찰→기전:** C3의 vector는 입력에 무관하지만 학습된 generator와 결합해 동작한다.
- **가설:** 흔한 prompt의 reward gain을 회수해도 희귀 object–attribute binding에서는 teacher 고유 이득이 남는다.
- **최소 실험:** 공개 checkpoint 확보 후 base·RL teacher·vector·동일 parameter LoRA를 같은 noise·prompt·sampling budget에서 비교한다. 저자 평가 외에 독립 생성한 held-out 조합과 간단한 수작업 검증 subset을 둔다.
- **판정:** reward 밖 paired gap이 특정 조합에서 반복되면 GO. teacher와 vector가 모든 검증 slice에서 동등하면 “새 능력 차이” 가설은 KILL하고 단순 대체 가능성의 범위를 기록한다.
- **비용·신규성:** 우선 소규모 inference로 제한하고 vector 재학습은 후순위다. 원 논문에 reward 밖·다양성 분석이 있어 단순 metric 추가는 신규성이 약하다. 조합별 counterexample과 동등한 평가 예산이 필요하다.

### S3. 조립 event의 이득은 역방향 추론인가, 미래 관측량인가?

- **관찰→진단:** C2는 forward/reverse partition을 함께 사용한다.
- **가설:** event 이득 일부는 reverse 방향 자체보다 event 이후 frame의 관측에서 온다.
- **최소 실험:** OmniST 확보 후 forward-only·동일 미래 window를 쓰는 forward·bidirectional을 같은 segmentation 후보와 관측량으로 비교한다. assembly/decomposition/가림별 event precision·recall·탐지 지연을 측정한다.
- **판정:** 미래량을 맞춰도 bidirectional 이득이 남으면 방향성 추론 GO. 이득이 사라지면 latency–accuracy trade-off를 결과로 남긴다. 원 annotation·split 검증이 안 되면 학습 실험부터 시작하지 않는다.
- **비용·신규성:** 기존 partition 출력 확보가 첫 단계이며 full video pipeline은 무겁다. 원 논문 ablation과 중복 여부를 먼저 확인한다. offline/causal 차이만 재확인하면 신규성은 낮다.

**첫 테스트:** S1의 self-patch와 clean/degraded 네 조건.  
**작은 GPU 우선:** S1의 작은 checkpoint·낮은 해상도 smoke test 후 probe. 작은 모델에서도 원 논문과 같은 현상이 난다고 가정하지 않는다.  
**장기 주제:** checkpoint·해상도·압축·시간축을 아우르는 정보 보존과 readout recovery의 불일치 지도.

## 11) 오늘 안 읽어도 되는 것·후보 제외 기록

15개 공식 초록 중 위 12편을 선정하고 다음 3편은 낮은 즉시 활용도로 제외했다.

- [Posterior Matching Distillation](https://arxiv.org/abs/2611.26629), v1 UTC 11/19: posterior mean constraint와 mode coverage는 중요하지만 오늘의 perception 진단 우선순위보다 낮다. zero population loss의 이론 결과를 finite-budget 성능 보장으로 읽지 않는다.
- [ScaleWorld: High-Resolution World Generation through Shared Prediction and Refinement](https://arxiv.org/abs/2611.26615), v1 UTC 11/19: shared prediction/refinement·task-asymmetric distillation이 중심이다. 오늘은 상세 compute·artifact를 확인하지 못해 추가 생성 연구로 깊게 포함하지 않았다.
- [Active Feature Acquisition by Distilling an Oracle Teacher](https://arxiv.org/abs/2611.26598), v1 UTC 11/19: train-time label·unobserved feature로 만든 oracle ranking과 deploy-time recoverability의 구분은 유용하다. acquisition 연구를 시작할 때 읽되 현재 CV entry 진단보다 후순위다.

이번 실행은 문헌·공개 상태 검토다. 새 성능값·독립 재현·설치 성공을 주장하지 않는다.
