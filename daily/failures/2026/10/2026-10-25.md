## 1. Ask About the Right Moment — 영상 VLM은 객체를 보지만 끝까지 같은 객체로 묶지 못한다

**실패 조건.** 동일하거나 매우 비슷한 컵·카드가 교차하고 가려지는 셸 게임에서, 최종 위치를 묻는 순간까지 목표 객체의 정체성을 유지해야 할 때 실패한다.

**모델·데이터·설정.** Qwen3-VL 8B·32B·235B의 직접 응답과 thinking, 도구 사용 에이전트, 다수결을 VET-Bench, TOC-Bench, Perception Test의 실제 셸 게임에서 비교했다. 실제 컵 하위집합은 65개 영상이며 3지선다 우연 수준은 33.3%다.

**확인된 사실.** 실제 65개 컵 영상에서 Qwen3-VL 계열은 27.7~33.8%, RL 기반 도구 에이전트는 33.8%였다. Qwen3-VL-32B 기반 세 종류의 training-free 도구 에이전트도 30.8~38.5%에 머물렀다. TOC-Bench에서는 32B thinking 36.9%, 직접 응답 37.1%로 추론 모드의 이점이 없었다. 16회 샘플 다수결도 VET-Bench에서 28~32%였다. 반면 `Track, Then Bind`는 추적 결과를 구조화된 상태로 읽게 해 VET-Bench 컵·카드에서 100%/100%, 실제 PT-65에서 55.4%, TOC-Bench에서 48.6%를 기록했다.

**저자 인정과 재현 상태.** 저자는 외부 추적기가 동일한 컵의 교차·들림에서 ID를 바꾸고, 매우 작거나 완전히 가려진 물체를 놓칠 수 있다고 명시한다. 질문당 약 11회의 VLM 호출도 비용 한계다. 공개된 에이전트 코드를 평가하고 예측 결과를 제공했지만, 현재 독립 커뮤니티 재현 보고는 확인하지 못했다. 올바른 추적 사실을 영상과 함께 보여줘도 모델이 영상을 다시 해석해 합성 컵 정확도가 8B 38%, 32B 76%로 떨어진 결과는 모델 내부 결속 실패를 뒷받침한다.

**기존 주장과의 충돌.** 모델 크기, 더 긴 추론, 도구 호출, 자기 일관성 다수결이 영상 추론을 안정화한다는 일반적 기대와 충돌한다. 여기서는 프레임별 인식보다 객체 ID를 시간축에 보존하는 상태 표현이 더 중요했다.

**진단 → 가설 → 최소 실험.** 진단은 “추적 결과를 보아도 영상의 인상으로 되돌아간다”이다. 가설은 좌표·ID·가림 상태를 자연어가 아닌 강제 스키마로 읽게 하면 규모보다 결속 오류가 크게 줄어든다는 것이다. 50개 셸 영상에서 직접 응답, thinking, 추적 오버레이, 구조화 상태 읽기를 비교한다. 정확도, ID switch, 호출 수, 지연을 측정한다. 구조화 상태가 직접 응답 대비 15%p 이상 개선되고 ID switch가 감소하면 진행하고, 성능 저하의 대부분이 추적기 교환 오류에서 발생하면 중단한다.

## 2. BrickWright — 그럴듯한 3D 생성물은 실제로 조립되지 않는다

**실패 조건.** 실재 부품 라이브러리로 LEGO형 모델을 생성할 때 충돌, 부유 부품, 연결 단절, 잘못된 스터드 결합을 피하면서 프롬프트 의미도 유지해야 하는 조건이다.

**모델·데이터·설정.** GPT-6 Luna·Sol·Astra 계열 코딩 에이전트를 BrickNet-512의 512개 프롬프트에 적용하고, 원시 LDraw 생성, 조립 API, 물리 검증기, 둘의 결합을 비교했다.

**확인된 사실.** 기본 코딩 에이전트의 물리 유효성은 모델별 9~69%였다. 조립 API와 검증기를 함께 쓰면 모든 백엔드에서 512개 표본의 검증기 기준 유효성이 100%였다. 검증기를 제거하면 모든 모델이 79% 미만이었고, Luna는 52.9%, Sol은 77.9%였다. 조립 API 없이 생성하면 토큰 비용이 약 2배, 검증 호출이 약 3배가 됐으며 Luna의 평균 부품 수는 27.4개에서 7.2개로 줄어 문제를 단순화하는 양상이 나타났다.

**저자 인정과 재현 상태.** 논문의 물리 유효성은 유효한 조립 순서와 완성물의 안정성까지 보장하지 않는다. 에이전트 방식은 더 느리고 비용도 높다. 프로젝트와 구현은 공개됐지만, 독립 커뮤니티가 실제 부품 또는 별도 시뮬레이터로 재현한 결과는 확인하지 못했다. 따라서 100%는 해당 검증기 정의 안의 결과다.

**기존 주장과의 충돌.** 강한 생성·코딩 모델이 기하 오류를 스스로 감지할 것이라는 기대와 충돌한다. Astra가 생성기와 검증기를 높은 비율로 작성해도 범용 자기 검증만으로는 충분하지 않았고, 도메인 제약과 실행 가능한 피드백이 성능을 지배했다.

**진단 → 가설 → 최소 실험.** 진단은 원시 좌표 생성이 연결 규칙을 암묵적 언어 지식에 맡긴다는 것이다. 가설은 스냅·커넥터 제약과 실행 가능한 검증 루프가 모델 확대보다 효과적이라는 것이다. 100개 프롬프트에서 원시 LDraw, API만, 검증기만, 계획-실행-검증 전체 구성을 비교한다. 충돌·연결 유효성, 부품 수, 프롬프트 유사도, 토큰, 지연, 안정성 시뮬레이션을 측정한다. 전체 구성이 95% 이상 유효성을 보이고 의미 점수 하락 없이 토큰 1.5배 이내면 진행하며, 검증기 점수만 통과하고 안정성에서 무너지면 중단한다.

**평가.** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5.

## 3. Lightweight Frame Compensation — 정적 분할 점수가 높아도 프레임 스킵에서 무너진다

**실패 조건.** 내시경 비디오를 실시간 처리하려고 3프레임당 1회만 추론할 때, 작은 용종·빠른 카메라 움직임·기구 가림·형태 변화가 있는 구간이다.

**모델·데이터·설정.** TransUNet, Polyp-PVT, ResNet-UNet을 VIM-Polyp, HyperKvasir 및 추가 용종 영상 데이터에 적용했다. 입력은 352×352, 고정 K=3 프레임 스킵, ImageNet 사전학습 인코더, 고정 시드 3회, NVIDIA RTX 5090 한 대 조건이다.

**확인된 사실.** Polyp-PVT의 프레임별 Dice는 0.7994/0.7671/0.7616이었지만 단순 스킵은 0.7296/0.6834/0.6965로 각각 6.98/8.37/6.51%p 하락했다. ResNet-UNet은 데이터셋별 4.20~11.84%p, TransUNet은 VIM-Polyp 6.27%p와 HyperKvasir 9.00%p 손실을 보였다. 저자가 제안한 경량 보상은 TransUNet을 0.7265와 0.7063으로 올려 두 데이터셋의 프레임별 0.6923과 0.6971을 웃돌았다. 속도는 TransUNet 기준 프레임별 114.9 FPS, 단순 스킵 344.4 FPS, 보상 292.8 FPS였다.

**저자 인정과 재현 상태.** 저자는 전역 attention이 어긋난 패치를 전파할 수 있고, ResNet의 상대적 안정성이 낮은 정적 정확도에 가려진 결과일 수 있다고 해석한다. 실험은 K=3에 한정됐고, 보상 학습의 pseudo-label은 다른 시드 모델이 생성했으며 전문가 추가 라벨이 아니다. 공식 코드와 독립 재현은 확인하지 못했다.

**기존 주장과의 충돌.** 높은 정적 Dice와 높은 단일 프레임 FPS를 가진 모델이 스트리밍 배치에서도 우월하다는 가정과 충돌한다. 시간축 샘플링은 단순한 배포 최적화가 아니라 별도 강건성 축이다.

**진단 → 가설 → 최소 실험.** 진단은 프레임 스킵이 경계 위치와 객체 출현 시점을 지연시키며, 전역 attention이 오차를 넓힌다는 것이다. 가설은 움직임 크기에 따라 보상 강도를 조절하면 고정 K 보상보다 안정적이라는 것이다. 동일 비디오에서 프레임별, 단순 스킵, optical-flow warp, 경량 보상을 K=2/3/4와 움직임 구간별로 비교한다. Dice/IoU, temporal jitter, 누락 지속시간, FPS를 측정한다. 원 손실의 70% 이상을 회복하면서 2배 이상 속도와 고난도 구간 -3%p 이내를 만족하면 진행하고, K=3 또는 pseudo-label 데이터에서만 이득이면 중단한다.

**평가.** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 4/5.

## 4. LACToS — 산업용 이상 탐지의 단일 정상성 가정이 다봉 분포에서 실패한다

**실패 조건.** 의료 CT, 얼굴, 수하물 X-ray처럼 정상 데이터 자체가 위치·해부·개인별로 여러 모드를 갖고, 이상 여부가 주변 문맥에 의존하는 경우다.

**모델·데이터·설정.** PatchCore, SimpleNet, SuperSimpleNet, EfficientAD, GLASS, DDAD와 LACToS를 CHAOS CT, FFHQ 얼굴 이상, DVXray 국소 이상에서 비교했다. AUROC, AP, AUPRO를 함께 평가했다.

**확인된 사실.** CHAOS에서 PatchCore는 AUROC 0.9297이지만 AP 0.0590, AUPRO 0.6811이었고, EfficientAD는 0.6664/0.0105/0.2513, SuperSimpleNet은 0.3786/0.0051/0.0332였다. FFHQ에서 PatchCore는 0.8491/0.0798/0.4094, LACToS는 0.8515/0.1177/0.5320이었다. DVXray에서는 PatchCore가 AUROC 0.9640으로 LACToS 0.9607보다 높았지만, LACToS는 AP 0.0568과 AUPRO 0.8179로 각각 PatchCore 0.0545와 0.8141을 소폭 웃돌았다. 즉 단일 지표 우승보다 데이터와 지표 사이의 변동성이 핵심 실패 신호다.

**저자 인정과 재현 상태.** 저자는 저주파 이상이 희귀 정상 특징과 비슷하면 false negative가 될 수 있고, 정상 학습 세트에 목표 이상이 섞이지 않아야 한다고 명시한다. 확산 posterior sampling 때문에 PatchCore보다 비용이 높고, 큰 superpixel이나 이질적 이상에서는 가정이 깨질 수 있다. 공개 저장소는 코드, 정확한 환경, 7.5GB 자산 번들, 기준 score map, Table 1 재생성 스크립트를 제공하며 다른 장비 검증도 기록한다. 저장소 자료는 강한 재현 자산이지만 독립 커뮤니티 논문 재현은 아직 확인하지 못했다.

**기존 주장과의 충돌.** 산업 데이터에서 강한 최근 이상 탐지기가 도메인 이동만으로 의료·얼굴·X-ray에 일반화할 것이라는 기대와 충돌한다. 희귀 정상 모드를 점 이상치처럼 다루면 정상 다양성이 곧 오탐 원인이 된다.

**진단 → 가설 → 최소 실험.** 진단은 전역 또는 1차 점 추정이 위치와 문맥에 따른 정상 모드를 합쳐 버린다는 것이다. 가설은 국소 조건부 정상성 모델이 해무·주야·항적처럼 다봉 정상 배경의 오탐을 줄인다는 것이다. 정상 500장으로 PatchCore, DDAD, LACToS를 학습하고 희귀 정상 하위집단과 실제 이상을 분리 평가한다. AUPRO, AP, 희귀 정상 하위집단 FPR, 지연을 측정한다. 희귀 정상 FPR이 30% 이상 감소하고 이상 AP 하락이 2%p 이내면 진행하며, 정상 학습에 유사 이상이 조금만 섞여 false negative가 급증하면 중단한다.

**평가.** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5.

## 오늘의 실패 패턴 3개

1. **관측과 상태는 다르다.** 영상 VLM은 각 프레임의 물체를 인식해도 동일 객체라는 상태를 시간축에 유지하지 못한다. 프레임 스킵도 관측 사이의 상태 변화를 잃는다.
2. **출력 점수와 실행 가능성은 다르다.** 시각적 품질, 정적 Dice, AUROC가 높아도 물리 제약, 시간적 안정성, 희귀 정상 오탐 같은 배포 실패를 설명하지 못한다.
3. **범용 자기 검증보다 도메인 구조가 강하다.** 구조화된 ID, 스냅 규칙, 움직임 보상, 조건부 정상 분포처럼 실패를 직접 표현하는 중간 상태가 모델 규모보다 일관된 개선을 만들었다.

## 논문 아이디어로 연결 가능한 빈틈

1. **추적 상태 충실도 평가:** 최종 정답만 보지 않고, VLM이 각 시점의 객체 ID·가림·교차를 얼마나 일관되게 읽는지 측정하는 benchmark와 calibration loss.
2. **검증기 편향에 강한 물리 생성:** 하나의 규칙 검증기를 통과하도록 최적화하는 대신, 조립 순서·정적 안정성·충돌을 서로 다른 시뮬레이터로 교차 검증하는 생성 루프.
3. **움직임 적응형 추론 예산:** 고정 K 프레임 스킵 대신 optical flow, 불확실성, 객체 출현을 이용해 추론 시점을 선택하고 누락 지속시간을 직접 최소화하는 정책.
4. **희귀 정상 모드 보존형 이상 탐지:** 정상 클러스터의 크기와 무관하게 하위집단별 FPR을 제한하고, 위치·문맥 조건부 typicality를 학습하는 공정성형 이상 탐지 목적함수.

## 해석 한계

- 오늘은 논문과 저자 제공 코드·자산을 교차 확인했으며 직접 모델 실행은 하지 않았다.
- 독립 커뮤니티 재현이 확인된 사례는 없었다. LACToS의 다른 장비 검증은 저자 저장소가 제공한 기록이다.
- 모든 수치는 각 논문의 데이터·검증기·하드웨어 정의에 종속된다. 특히 BrickWright의 100%는 안정성과 조립 순서를 포함하지 않는다.
- 평가 점수는 레이더의 연구 우선순위 판단이며 실험 측정값이 아니다.
