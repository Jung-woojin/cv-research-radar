## 2. CV 핵심 — 6편

### 2.1 Less Context, Better Geometry: Masked Geometric Encoder for Robust 3D Foundation Models

**문제·방법:** 가림과 외형이 비슷하지만 다른 장소의 시점이 전역 attention을 통해 오류를 전파할 수 있다. MGE는 학습 중 프레임 토큰의 전역 문맥을 줄이고 full-context teacher의 기하·특징을 증류한다. 추론에는 Anchor-Guided Adaptive token merging을 사용한다.

**저자 결과:** Doppelganger 평가의 all-pair AUC@30은 MGE 58.68, VGGT 55.56, π3 51.23이다. 다만 LoFTR는 59.60으로 더 높다. “모든 방법에서 최고”라는 결론은 성립하지 않는다. 학습은 13개 데이터셋 혼합과 사전학습 교사에 의존하며, 4 H200에서 6일이 보고된다. 가림·시점 혼동 및 ablation은 있으나 전체 재학습은 가벼운 실험이 아니다. [원문](https://arxiv.org/html/2610.06813v1)

**해석·후속:** 더 많은 문맥이 항상 낫지 않다는 통제 실험에 가치가 있다. 우리 첫 단계는 공개 3D 모델에 잘못된 시점을 단계적으로 추가해 reference-only와 cross-pair 오차를 분리하는 것이다. 공식 실행 코드·가중치는 이번 조사에서 확인하지 못했고, seed 분산과 모든 train/test 중복 여부도 검증하지 못했다.

### 2.2 GS-Pool: Object-Level Change Detection in 3D Gaussian Splatting

**문제·방법:** 같은 장면을 따로 재구성해도 stochastic training 때문에 Gaussian field가 달라진다. 이 차이를 실제 객체 변화로 오인할 수 있다. SAM2 마스크로 객체 pool을 만들고, 다른 방문의 사진에 대한 재구성 loss gradient인 photographic carrier를 geometry·color·DINOv3 증거와 결합한다. 공통 객체의 증거를 scene별 empirical null로 사용한다.

**저자 결과:** PASLCD mIoU/F1은 0.751/0.846, GS-Diff는 0.644/0.758이다. 저자의 17%/12%는 상대 개선이며 percentage point가 아니다. 세 재구성 seed를 평가했고, 재구성·segmentation 입력이 준비된 뒤의 탐지 단계 median은 RTX4090에서 FastPGSR 기반 2.1분이다. 재구성 전체 시간이 아니다. [논문](https://arxiv.org/html/2610.06688v1)

**공개 상태·후속:** 공식 repo에 실행 코드가 아직 없으며 README는 coming soon이다. HF에는 재구성·evidence·결과와 변화 annotation 파일이 있다. 즉 데이터 다운로드와 end-to-end 코드 재현은 다르다. null에 변화 객체가 섞이면 임계값이 흔들리는지 먼저 조사할 가치가 있다. [공식 저장소](https://github.com/BoazKG93/gs-pool), [PASLCD 산출물](https://huggingface.co/datasets/boazkg/gs-pool-paslcd)

### 2.3 MaRO-GS: Mask-Robust Object-Centric Gaussian Splatting from Inconsistent Multi-view Masks

**문제·방법:** 시점마다 마스크가 다르면 객체 Gaussian에 배경이 섞이거나 일부가 소실된다. 신뢰도에 따른 view filtering, 객체 중심 density control, silhouette 정렬 loss를 결합한다.

**저자 결과:** LERF-Mask PSNR은 42.89 대 FDS-GS 40.84다. 비교는 같은 controlled masked-input protocol이며 공식 평가 스크립트 설명은 object-mask 영역 측정을 명시한다. 작은 객체의 full-frame PSNR만으로 얻은 개선이라고 단정하면 잘못이다. LERF-Mask·Mip-NeRF360·Tanks and Temples, DTU mask-error 평가가 있고, 핵심 표 1·3의 세 seed 통계가 supplementary에 제공된다고 명시한다. 본문 주 실험 A6000, ablation RTX4070Ti Super다. [원문](https://arxiv.org/html/2610.06472v1)

**해석·재현:** train.py와 객체 평가 구현을 확인했다. 그러나 배포용 LERF-Mask annotation은 README에서 Coming Soon이고 Gaussian-Splatting 계열 별도 라이선스다. 기존 mask-error ablation을 반복하는 수준을 넘어, 어려운 view를 버려 점수가 높아지는지와 새로운 시점의 coverage를 함께 측정해야 한다. [코드·재현 안내](https://github.com/kgh1234/MaRO-GS)

### 2.4 Video Encoders Built on Image Representations

**문제·방법:** 영상에서 표현 생성, 토큰 예산 배분, 시간 통합을 한 과정으로 묶으면 손실 원인을 구분하기 어렵다. frozen image encoder의 프레임별 후보를 question-aware relevance·diversity·correspondence로 선택하고, retained anchor에만 시간 refiner의 residual을 쓴다.

**저자 결과:** Qwen3-VL-8B의 13개 benchmark 평균은 1,535 visual tokens에서 62.75, Full Image는 4,424 tokens에서 62.58이다. Full Image와 native Conv3D는 full-input reference로, 압축 방법의 동일 예산 비교와 별개다. appendix에는 학습 없는 selection-only 비교가 있어 refiner 학습 이득을 분리한다. [abstract](https://arxiv.org/abs/2610.06616)

**해석·한계:** encoder 출력과 LLM 입력을 구분해 효율을 설명한다는 점이 중요하다. token 감소율을 같은 비율의 VRAM·FLOPs 감소로 해석하지 않는다. 상세 검증과 최소 실험은 9·10절에 있다. 코드·학습 가중치의 실제 공개는 확인하지 못했다.

### 2.5 AstraSR: Real-World Thermal Super-Resolution with GPT-6 Astra

**문제·방법:** 열화상 LR에 대응하는 실제 HR를 확보하기 어렵다는 문제를, 생성 교사가 만든 HR reference로 감독해 해결하려 한다. captured LR를 입력으로 유지하고 pixel·gradient·perceptual loss로 학습한다.

**저자 결과:** UAV-TSR에서 800 training pairs, 300 test LR를 사용한다. 모델은 20.47M params, 764.57G FLOPs로 보고되며 7개 방법과의 비교는 주로 시각적 결과다. Real-ESRGAN의 16.70M/587.43G보다 무거워 “가장 가벼운 모델”도 아니다. [본문](https://arxiv.org/html/2610.05910v1)

**해석·한계:** 생성 HR는 센서로 측정한 정답이 아니다. 더 선명한 경계가 실제 열 분포나 작은 대상의 보존을 입증하지 않는다. teacher 생성의 정확한 모델 snapshot·프롬프트 안정성, 전체 ablation·seed·실측 latency, 공개 code/weights/data는 이번 조사에서 검증하지 못했다. 열화상/UAV 관심과 연결할 첫 실험은 생성 reference 대비 점수보다 실제 관측의 경계·대상 보존 검증이다.

### 2.6 Toward Reliable Infant Pose Estimation: A Training-Dynamics Approach to Noisy Annotation Detection

**문제·방법:** regression loss가 큰 keypoint에는 오표기와 어려운 정상 표본이 섞인다. 좌표·지역 특징으로 anatomical class를 예측하고 CE 학습 dynamics를 clustering하여 noise를 탐지한다.

**저자 결과:** NeoPose는 65명 영상에서 7,563개 RGB frames를 추출한 데이터다. 위치 교란·좌우 교환의 injected noise 조건에서 F1 최대 91.9%, COCO의 중간~높은 noise 조건에서 filtering 후 HRNet 성능 최대 +7.4 AP points를 보고한다. EfficientNet-B3의 ImageNet 초기화를 사용하고 feature-subset·CE/MSE 비교가 있다. [원문](https://arxiv.org/html/2610.06423v1)

**해석·한계:** 실제 자연 발생 오표기 전체에 같은 효과가 있다는 증거는 아니다. 환자 단위 generalization split, seed 분산, 공개 NeoPose 접근 및 실행 코드는 확인하지 못했다. 논문이 적은 A100 64GB 사양은 그대로 실험 예산에 사용하지 않고 별도 확인이 필요하다. CV 관점의 후속 질문은 clean-but-hard keypoint를 제거해 생기는 장기적인 편향이다. 임상 효과를 결론내리지 않는다.

## 3. VLM/Video 핵심 — 3편

### 3.1 Lens3D: Target-Conditioned Visual Foveation for Fine-Grained 3D Understanding

**문제·방법:** 3D 객체의 작은 속성은 전체 장면 표현에서 잘 읽히지 않을 수 있다. LensUnd는 3D 대상 위치에 맞춰 2D VLM이 볼 view를 선택하고, LensDistill은 상세 caption을 native 3D LLM에 증류한다.

**저자 결과:** LensBench는 held-out 객체 2,068개, 객체당 silver-standard reference 3개다. Video-3D LLM에 Lens3D를 적용한 Summary F1은 0.228→0.483이다. human rating 및 기존 grounding/scene QA 유지 평가도 있다. [본문](https://arxiv.org/html/2610.06611v1)

**해석·검증:** 부분 관측을 확대하는 전략과 교사 지식 주입을 분리해야 한다. silver reference를 사용하므로 teacher 스타일에 가까운 답이 유리해질 가능성을 human 평가만으로 완전히 배제할 수 없다. ScanNet 기반 객체 split 외 domain, pretraining 오염·seed·전체 비용과 공개 코드/가중치는 검증하지 못했다. 첫 진단은 같은 객체의 view 수·해상도를 맞춘 random view와 target-conditioned view 비교다.

### 3.2 VideoTapestry: Query-Adaptive Memory Refinement for Multi-Agent Long-Video Understanding

**문제·방법:** 긴 영상을 한 번 요약하면 질문에 필요한 순간이 빠질 수 있다. global/event/fine relational memory와 세 scale의 agent가 질문에 맞춰 재관측하고 선택된 memory node를 갱신한다. 방식은 training-free다.

**저자 결과:** GPT-5.5 direct prompting 대비 LVBench, LongVideoBench-Long, VideoMME-Long, EgoSchema 정확도 이득은 각각 +17.2, +14.9, +9.8, +7.0 points다. 같은 model/tool-call budget의 single-agent ablation이 있으며 agent 분해 제거 시 4.5 points 낮아진다. [원문](https://arxiv.org/html/2610.06672v1)

**해석·한계:** “agent를 늘렸으니 더 많은 호출을 쓴 결과뿐”이라는 비판은 해당 통제를 무시한다. 다만 전체 pixel/token 양, offline memory 생성 비용의 상각, API 변동과 seed 분산을 함께 확인해야 한다. 공식 실행 코드·snapshot은 확인하지 못했다. 오늘 질문 보고서의 예산·memory 통제 분석을 유지하고 비슷한 아이디어를 새 연구로 포장하지 않는다.

### 3.3 Readout Blindness: VLM Scores Miss the Spatial Direction Their Frozen Encoders Retain

**문제·방법:** 낮은 공간 관계 점수가 encoder에 방향 정보가 없다는 뜻인지 묻는다. ADR은 frozen patch와 단어의 정렬로 객체 centroid와 signed displacement를 읽으며 별도 learned parameters 없이 real/null 비교를 한다.

**저자 결과:** VALSE actant-swap의 Qwen3.6 likelihood 사례에서 real 93.99, null 88.41이다. 이 차이는 5.58 points지만 모든 공간 추론과 calibration으로 일반화할 수 없다. [원문](https://arxiv.org/html/2610.06324v1)

**확인·후속:** 공식 code와 sample 목록은 있으며 원 이미지 재배포와는 다르다. subset/limit로 null pool이 달라질 수 있고 일부 VSR 설정의 threshold를 다른 split에 그대로 적용할 근거를 분리해야 한다. 오늘 benchmark/failure 보고서와 중복되므로 여기서는 “encoder 정보 존재”와 “생성 head 사용 능력”의 차이만 강조한다. [코드](https://github.com/GarryLarry010131/ADR)

## 4. LLM/Agent/System 변화 — 3편

### 4.1 Can Agent Harnesses and Inference Engines Hear Each Other? The HEAR Protocol for Agentic LLM Serving

**문제·방법:** harness는 다음 작업을 알고 engine은 queue/KV cache를 안다. 이 정보를 양방향 전달하되 intent와 control, acceptance와 completion을 구분하는 protocol을 제시한다.

**저자 결과:** Qwen3-8B·한 H100·96GiB L2 cache의 SCBench에서 Guard-40 설정은 FCFS 대비 batch completion 1.61배, median TTFT 2.23배 개선이다. cache-aware만 쓰면 median은 더 좋아져도 max 대기가 악화되는 trade-off가 있다. 모델·입력·workflow/tool budget·hardware를 맞추고 실패·재시도를 포함한다고 명시한다. [원문](https://arxiv.org/html/2610.06597v1)

**해석·후속:** 처리량만 개선하면 일부 요청은 더 오래 기다릴 수 있다. CV batch inference도 평균 처리량과 tail latency·실패를 함께 로그해야 한다. 다른 모델/큐 부하의 일반화, 실행 구현 공개·seed 분산은 확인하지 못했다.

### 4.2 DGA-Muon: Decoupled Geometry-Aligned Adaptive Scaling for Muon

**문제·방법:** orthogonalized update에서 adaptive 신호를 뽑으면 square/wide matrix의 row 차이가 사라질 수 있다. raw gradient에서 scaling 신호를 추출하고 matrix shape에 맞춰 적용해 방향 변환과 적응을 분리한다.

**저자 결과:** NanoChat 1.38B·24-layer, 8 A100 80GB 실험의 validation BPB는 0.6910 대 NorMuon 0.6924, DCLM CORE는 0.3089 대 0.2942다. validation 차이는 0.0014이므로 seed 분산 없이 확실한 개선이라고 확대하지 않는다. [논문](https://arxiv.org/html/2610.06578v1)

**해석·한계:** 수학적 병목 진단은 흥미롭지만 현재 evidence는 LLM pretraining이며 ViT/CNN 개선을 보여주지 않는다. NanoChat·Muon 참조 링크는 저자 DGA 구현 공개와 다르다. CV 적용은 작은 모델에서 raw-gradient scaling만 바꾼 matched-seed 실험부터이며 지금 대규모 재학습을 우선할 이유는 적다.

### 4.3 MC-Sparse: Deconstructing and Closing the Dense–Sparse Attention Gap in Diffusion Transformers

**문제·방법:** sparse attention의 차이를 grouping 제약, KV 선택 오류, 잔여 output 손실로 분해한다. anchor step에서 individual KV를 선택하고 grouping/selection metadata와 dense–sparse residual을 재사용하되 Q/K/V는 갱신한다.

**저자 결과:** Minimax-H3-Base의 MC-Sparse-Flash는 15% density에서 27.30dB의 dense-output 대비 PSNR과 denoising 1.80배 speedup을 보고한다. 이는 관측 정답 대비 화질이나 text/VAE를 포함한 전체 pipeline 배속이 아니다. Penguin/VBench 입력과 dense-output fidelity, 단계별 ablation을 사용한다. [원문](https://arxiv.org/html/2610.06801v1)

**확인·한계:** 공식 kernel·MiniMax-H3 integration과 테스트 파일이 있으며 현재 지원은 NVIDIA Hopper다. residual cache로 VRAM/CPU 전송 비용이 생길 수 있고 geometry의 HY3D-Internal 평가와 공개 H3 구현은 재현 범위가 다르다. seed·품질 평가의 coverage도 독립 확인이 필요하다. [공식 코드](https://github.com/dodododddo/mcsparse)

위 항목은 선정 논문을 연결한 해석이며 서로 동일한 실험에서 입증된 사실은 아니다.

## 9. Top 1 mini-review — Video Encoders, 5~10분 읽기

**읽을 순서:** introduction의 짧은 사건 예시 → 표현/예산 분해 → 주요 비교 → appendix C.1/C.2/C.4 → training details다. [본문과 appendix](https://arxiv.org/html/2610.06616v1)

**실제 contribution:** independent frame candidate를 만든 뒤 질문에 맞게 예산을 배분하고, 추가 출력 토큰 없이 selected anchor를 시간 문맥으로 보정한다. 단순히 “압축 모듈 하나 추가”보다 어떤 증거가 선택 과정에서 사라지는지를 논의한다.

**실험에서 인정할 부분:** 13개 benchmark와 세 VLM backbone을 다루고 selection-only training-free 비교·component/system ablation을 제공한다. refiner는 약 18M trainable parameters이며 65K Video-ChatGPT training data에서 2 epochs, 8 A100에서 약 12시간 학습을 보고한다. benchmark prompt/metadata에 대한 exact n-gram 및 semantic 중복 검사도 있다.

**아직 구분할 부분:** 이 검사는 base VLM pretraining 전체의 contamination 부재를 증명하지 않는다. 전체 입력 reference와 budget-matched compression은 별개이고, 큰 후보 pool을 계산·보관한 뒤 줄인 출력 토큰 수만으로 메모리 절감을 확정할 수 없다. 모든 backbone·질문 유형에서 얻는 이득도 macro average만으로 판단하지 않는다.

**우리에게 유용한 blind spot:** selection에서 빠진 결정적 순간을 refiner가 unselected context로 보충하는지, 아니면 관련 없는 문맥으로 평균 점수만 올리는지다. 논문이 이미 correspondence·coverage ablation을 다뤘으므로 그것을 신규 아이디어라고 내세우지 않는다. 먼저 사건 길이·가림·반복 배경 별 실패를 수집하고 기존 ablation 범위를 확인한다.

**첫 조치:** 공개 코드가 확인될 때까지 full refiner 재학습을 시작하지 않는다. 기존 VLM의 같은 frame pool에서 uniform과 question-aware selection을 비교하고, 그 결과를 바탕으로 작은 시간 문맥 개입의 필요성을 판단한다.

## 10. 후속 연구 씨앗 — 3개

아래 GO/KILL은 실험 전에 정할 제안 기준이다. 예상 성능이나 이미 얻은 결과가 아니다. 비용 /5는 1이 가볍고 5가 무겁다.

### A. 같은 영상 증거에서 “올바른 시간 문맥”의 가치만 측정하기

- **Observation → diagnosis:** 압축 후 평균 점수는 유지되지만 짧은 transition의 증거가 실제로 보존됐는지 불명확하다.
- **가설:** static 질문보다 temporal 질문에서 정확한 이웃 frame context가 refiner의 이득을 설명한다.
- **MVP·baseline:** 같은 selected anchor·source position·출력 budget을 고정하고 no-context / 올바른 neighbor / 같은 영상의 시간상 먼 context / context 순서 교란을 비교한다. encoder와 candidate frame pool도 고정한다. retraining 전에 selection-only uniform 및 question-aware baseline을 기록한다.
- **Dataset·측정:** TempCompass/MVBench의 이용 가능한 temporal/static subset. paired answer accuracy, decisive-event coverage, peak VRAM, wall-clock을 측정한다. 실제 frame decode부터 시간을 잰다.
- **GO:** temporal subset에서 올바른 context의 이득이 paired bootstrap 95% CI로 0보다 크고 static subset 악화가 없는 경우. **KILL:** 먼 context에도 같은 개선이 나면 시간 추론 설명을 중단하고 generic feature smoothing 또는 질문 shortcut을 조사한다.
- **비용·위험:** 소규모 inference 진단 2/5, 논문 refiner 재학습은 4/5. 기존 C.4 correspondence ablation과 겹칠 위험이 높아 짧은 사건/가림 층별 실패와 독립적인 교란이 차별점인지 먼저 확인한다. negative result도 temporal gain의 설명을 제한한다.

### B. GS-Pool의 empirical null은 변화가 많은 장면에서도 정상 기준인가?

- **Observation → diagnosis:** 공통 객체를 null 기준으로 쓸 때 matching 오류와 실제 변화가 calibration에 들어갈 수 있다.
- **가설:** 공통 pool의 contamination 비율이 커지면 변화 누락 또는 정상 객체 false alarm이 증가한다.
- **MVP·baseline:** 공개 evidence에서 calibration pool만 교란한다. 원본 null / 검증된 unchanged calibration / contamination 단계별 null을 비교한다. geometry와 feature는 고정하고 threshold를 test 정답에 맞추지 않는다.
- **Dataset·측정:** PASLCD scene 단위 held-out calibration, 가능하면 CL-Splats transfer. object false-positive/false-negative, threshold 변화, lighting 및 reconstruction seed 별 민감도를 기록한다.
- **GO:** scene held-out에서 특정 contamination 수준 이후 오류가 일관되게 증가하고 작은 robust calibration으로 개선되는 경우. **KILL:** matching·lighting 조건을 고정하자 효과가 사라지면 null보다 upstream 원인이 핵심이다.
- **비용·위험:** evidence-only 분석 1/5, field 재구성 4/5. 실행 코드가 없어 동일 score recomputation은 지금 불가할 수 있다. 저장된 evidence로 가능한 분석과 저자 코드가 필요한 분석을 구분한다. 4~8주 주제는 calibration failure taxonomy부터 시작한다.

### C. MaRO-GS의 view filtering은 어려운 객체 부분을 제외해 성공하는가?

- **Observation → diagnosis:** 오류 마스크를 배제하는 것은 유용하지만 가려진 작은 대상의 유일한 view도 제거할 수 있다.
- **가설:** object-mask 품질과 새로운 surface coverage가 충돌하는 경우 filtering이 평균 render quality를 올리면서 드문 view의 완성도를 떨어뜨린다.
- **MVP·baseline:** 원래 filtering / 같은 view 수의 random removal / coverage-preserving removal을 비교한다. object size·occlusion·mask corruption을 층화하고 총 view 수·training iterations를 맞춘다.
- **Dataset·측정:** 이용 가능한 LERF-Mask 또는 DTU object masks. object-region PSNR, mIoU/bIoU, held-out hard-view 성능과 peak VRAM을 함께 기록한다. 배포 예정 annotation을 확보한 것으로 가정하지 않는다.
- **GO:** matched-count baseline보다 hard-view 오류가 늘고 coverage 보존만으로 개선되며 easy-view 성능은 유지되는 경우. **KILL:** 원문 mask-error/threshold ablation으로 이미 설명되거나 차이가 seed CI 이내면 새 방법 개발을 중단한다.
- **비용·위험:** 제한된 객체·3 seeds 3/5. mask robustness 자체는 이미 논문 기여라 novelty 위험이 높다. “어려운 부분을 보존하는 관측 선택”이라는 독립 원인이 보여야 4~8주 연구로 확장한다.

**오늘 가장 먼저:** A의 selection-only 고정 예산 진단을 준비한다. **작은 GPU에서도 가능한 것:** B의 공개 evidence 통계 분석. **장기 주제:** 관측의 coverage, 신뢰도, readout 사용을 함께 감사하는 video/3D evidence framework. 이는 방향 제안이며 장기 성과 전망을 사실로 표현하지 않는다.

## 11. 오늘 안 읽어도 되는 것

- ChronoWorld 상세 architecture는 오늘 Top 3를 읽고 직접 world generation 문제를 잡을 때로 미룬다.
- RealtimeWAM은 실제 checkpoint가 있으나 robotics deployment가 당장 목표가 아니라면 설치를 미룬다.
- DGA-Muon의 전체 증명은 optimizer 연구를 시작할 때 읽는다. 작은 BPB 차이를 근거로 CV 학습 stack을 교체하지 않는다.
- EO 연구와 ADR의 상세 비교는 오늘 별도 질문·benchmark·failure 보고서에 있으므로 중복 정독을 줄인다.
- 코드가 공개 예정인 GS-Pool을 바로 clone하면 end-to-end 재현할 수 있다는 기대는 보류한다. 오늘은 공개 evidence와 null 설계부터 읽는다.

보고서의 수치·조건은 공식 원문에 대한 확인이며 독립 재현 결과가 아니다. 공개 파일 목록과 release 시각의 조사 snapshot은 로컬에 보존했다.
