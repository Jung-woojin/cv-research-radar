# Biweekly CV Trend Map — 2026-11-03

## 요약

- 최근 2주의 핵심은 “더 잘 맞히는가”에서 “무엇을 근거로, 어떤 조건에서 맞혔는가”로 평가축이 이동하는 것입니다.
- AdaGround와 PROVE는 관측 근거·불확실성·보류를 명시적으로 다루며, 단일 답 정확도만으로는 부족하다는 신호를 보입니다.
- Video RLVR은 outcome reward가 언어 사전지식에 치우친 답을 강화할 수 있음을 지적해, 시각적 정답성과 언어적 정답성을 분리해야 함을 보여줍니다.
- Reversion Retention은 CLIP 계열 delta update의 개선이 실제로 필요한 방향인지 반전 실험으로 점검하는 개입적 평가를 제안합니다.
- FVQ는 재구성 오차가 시각 언어 모델에 필요한 의미 보존을 대변하지 못할 수 있음을 보여, 토큰 압축을 task-conditioned하게 평가해야 한다는 근거를 제공합니다.
- PanoGraphGS와 spherical PSGG는 3D·파노라마에서 기하 구조를 표현에 내장하는 방향을 강화합니다.
- 항공·수중 등 세밀한 관측 환경에서는 고해상도 관측과 기하 제약을 분리해 검증하는 일이 여전히 병목입니다.
- 다음 2주의 실험 우선순위는 evidence/abstention, intervention, token fidelity를 하나의 OVD/VLM 진단 프로토콜로 연결하는 것입니다.

## 1. 2주 한 문장 결론

최근 2주 CV/VLM 연구 신호는 **정답률 중심 최적화에서 벗어나, 관측 근거·개입 안정성·의미 보존을 함께 측정하는 검증 가능한 시각 추론**으로 이동하고 있다.

## 2. 핵심 추세 6개

1. **개입적 표현 검증** — Reversion Retention은 CLIP 파라미터 delta의 일부를 되돌리거나 유지해 개선에 실제로 기여하는 방향을 분리한다.
2. **근거 기반 grounding과 보류** — AdaGround는 목표 크기에 맞는 관측, verifier, 재-grounding 및 abstention을 한 루프로 다룬다.
3. **결과 정답과 시각적 충실성의 분리** — Video RLVR은 outcome reward만으로는 언어 prior 기반의 정답이 강화될 수 있다고 분석한다.
4. **압축 품질의 의미 단위 재정의** — FVQ는 reconstruction/quantization error가 시각적 의미 충실도를 충분히 대변하지 못한다고 주장한다.
5. **기하·계층을 표현 안으로 흡수** — PanoGraphGS와 spherical PSGG는 3D 공유 geometry, 구면 왜곡/경계, 계층 관계를 구조적으로 모델링한다.
6. **세밀한 환경에서 관측 자체가 병목** — OBB-PBD·GeoPrompt 계열 신호는 작은 물체, 방향, 수중 환경처럼 관측 해상도와 geometry가 성능 상한을 좌우하는 문제를 부각한다.

## 3. 대표 근거와 구분

| 신호 | 확인된 사실 | 저자 주장 | 해석 |
|---|---|---|---|
| Reversion Retention | CLIP delta의 revert/retain 실험을 제안한 2026-10-25 공개 원고 | 실험 설정에서 visual-only update가 개선분의 43–87%를 회복 | 파라미터 효율 기법은 평균 성능 외에 “어떤 update가 필요한가”를 점검해야 한다 |
| AdaGround | adaptive zoom, verifier, re-grounding, abstention을 포함한 방법과 코드를 공개 | OSWorld-G·ScreenSpot-Pro에서 기반 모델 대비 7.4–20.6점 향상 | grounding은 단발 crop 문제가 아니라 관측-검증-재관측 제어 문제다 |
| Video RLVR | 결과 보상 기반 video RL의 시각 근거 부족을 분석 | 제안 BSPO가 텍스트 prior를 줄이고 시각 귀속 불확실성을 낮춤 | VLM reward 설계에는 answer와 evidence를 분리한 평가가 필요하다 |
| FVQ | visual-token quantization 평가와 코드를 공개 | 재구성/양자화 오차만으로 semantic fidelity를 보장할 수 없음 | compression benchmark는 downstream visual evidence를 포함해야 한다 |
| PanoGraphGS | 공유 Gaussian geometry 기반 panoptic scene graph 표현을 제안 | Replica/NaviGS의 object-node accuracy에서 강한 비교 기준 대비 50점 이상 이득 보고 | 3D scene graph는 RGB feature 결합보다 shared geometry·hierarchy의 이득을 분리 측정해야 한다 |
| Spherical PSGG | ERP 왜곡·seam 문제와 340개 파노라마, 10,571 nodes, 6,632 relations를 명시 | projection-aware 설계의 PQ·mR 개선 보고 | 파노라마에서는 평면 이미지 모델의 개선이 실제 구면 관계 이해로 이어지는지 별도 검증해야 한다 |

## 4. 상승·유지·하락 판단

| 상태 | 추세 | 근거와 판단 |
|---|---|---|
| 상승 | evidence-aware grounding | AdaGround, PROVE의 patch/evidence 계열 신호가 관측·검증·보류를 모두 요구한다 |
| 상승 | causal/intervention evaluation | Reversion Retention이 update 효과를 반전 실험으로 해석한다 |
| 상승 | semantic-fidelity-aware token design | FVQ가 compression loss와 task 의미의 불일치를 직접 문제화한다 |
| 상승 | geometry-aware scene understanding | PanoGraphGS·spherical PSGG가 구조적 기하 제약을 사용한다 |
| 유지 | small-object/high-resolution observation | 항공·수중·멀티뷰 환경에서 세밀한 관측 필요성이 계속된다 |
| 하락 위험 | answer-only leaderboard 해석 | Video RLVR·PROVE 신호 때문에 정답률 단독 비교의 설명력이 약해진다 |

판정은 공개 원고 묶음에서의 **추론**이며, 분야 전체의 정량 점유율 변화는 아니다. 이전 biweekly 원격 보고서를 찾을 수 없어 상태 판정은 동일 주제의 최근 공개 근거 대비 질적 판단으로 제한한다.

## 5. 데이터·벤치마크 변화

- Spherical PSGG는 파노라마 scene graph에서 구면 투영과 seam을 명시해야 한다는 데이터 구조 문제를 드러낸다.
- AdaGround의 OSWorld-G·ScreenSpot-Pro 평가는 작은 GUI target에서 정답뿐 아니라 관측 제어가 평가 변수가 됨을 시사한다.
- PanoGraphGS의 Replica/NaviGS 결과는 2D panoptic label, depth, mesh, 3D hierarchy가 함께 맞물린 평가가 필요함을 보인다.
- **진단:** 현 benchmark 다수는 final answer/IoU에 집중한다.
  **가설:** evidence coverage, abstention calibration, counterfactual stability를 추가하면 language-prior shortcut이 드러난다.
  **최소 실험:** 기존 OVD 200개 샘플에 evidence box/mask·답변 confidence·counterfactual crop을 붙여 세 지표의 순위 상관을 측정한다.

## 6. 아키텍처·학습·추론 변화

- 아키텍처: shared 3D geometry와 spherical projection-aware relation modeling이 늘고 있다.
- 학습: answer reward와 visual evidence reward를 분리하려는 요구가 강해진다.
- 추론: adaptive observation → verify → re-ground/revise → abstain의 폐루프가 부상한다.
- 압축: VQ의 codebook/bit budget을 복원 품질이 아니라 downstream visual attribution으로 판단해야 한다.
- 개입: delta update는 추가 모듈 성능이 아니라 revert/retain sensitivity로 진단할 수 있다.

## 7. 반복되는 미해결 문제

**문제:** 모델이 맞는 답을 낼 때 그것이 실제 시각 증거·기하 구조·필요한 update에 의해 나왔는지, 언어 prior·재구성 손실·우연한 shortcut에 의한 것인지 분리하기 어렵다.

**진단:** answer-only metric은 증거 부족과 shortcut을 숨긴다.
**가설:** 동일 답을 유지한 counterfactual observation과 targeted parameter reversion을 함께 적용하면 shortcut 비율을 관측할 수 있다.
**최소 실험:** OVD/VLM validation set에서 (a) 원본, (b) evidence crop 제거, (c) distractor crop 교체, (d) visual delta reversion 네 조건의 정답·근거·confidence 변화를 기록한다.

## 8. 향후 1–3개월 전망

- **높음:** GUI·robotics·small-object grounding에서 active observation과 abstention이 일반 평가 요소로 확장될 가능성.
- **중간:** visual-token compression에서 reconstruction metric 대신 task-conditioned semantic fidelity benchmark가 늘어날 가능성.
- **중간:** 3D/panorama에서 projection/geometry-aware relation learning이 scene graph 쪽으로 확장될 가능성.
- 이 전망은 위 원고들의 방법적 방향에서 도출한 **추론**이며, 제품 출시나 벤치마크 채택을 확인한 사실이 아니다.

## 9. 과열 또는 약한 기여 경계

- 단일 공개 benchmark의 평균 점수만으로 grounding quality를 일반화하지 않는다. AdaGround의 수치는 저자 보고이며 대상 benchmark와 baseline 조건을 함께 재현해야 한다.
- visual-token의 PSNR/quantization error만 낮추고 evidence-grounded task를 측정하지 않으면 FVQ가 지적한 semantic loss를 놓칠 수 있다.
- geometry-aware module이 성능을 냈더라도 projection, data split, resolution, depth/mesh 접근성의 영향을 제거하지 않으면 구조 효과로 단정할 수 없다.
- RLVR의 answer 개선을 visual faithfulness 개선으로 해석하지 않는다. answer/evidence disagreement 표가 먼저 필요하다.

## 10. 사용자 연구 기회 4개

1. **Counterfactual Evidence OVD**
   - 질문: 작은 물체 OVD의 향상이 물체 증거에 의한 것인가?
   - 가설: distractor 교체·evidence 제거에서 confidence와 answer가 함께 안정적인 모델이 실제 grounding도 높다.
   - 최소 실험: 3개 OVD 모델 × 200 이미지 × 3 counterfactual을 평가.

2. **Answer–Evidence Dual Reward for VLM**
   - 질문: outcome reward와 evidence reward를 분리하면 hallucination을 줄일 수 있는가?
   - 가설: answer reward 단독보다 evidence mask reward를 추가한 정책이 evidence-drop 조건에서 덜 붕괴한다.
   - 최소 실험: 1개 QA task에서 두 reward 설정을 동일 seed 3개로 비교.

3. **Task-conditioned Visual Token Fidelity**
   - 질문: reconstruction loss가 아닌 region/relationship 보존으로 VQ bit budget을 정하면 효율이 좋아지는가?
   - 가설: 작은 target과 relation query에서 semantic-loss-guided codebook이 동일 bit budget의 reconstruction-guided VQ보다 낫다.
   - 최소 실험: 2개 bit budget, 2개 tokenization 방식, grounding/evidence F1 비교.

4. **Geometry–Evidence Coupling in Panorama/3D**
   - 질문: shared geometry가 관계 예측의 시각 근거를 강화하는가?
   - 가설: depth/mesh 교란 시 hierarchy-consistent 모델의 evidence degradation이 더 설명 가능하다.
   - 최소 실험: panorama 또는 3D scene graph 100개에서 depth noise·seam shift ablation.
