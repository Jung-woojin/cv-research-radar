## Q1. recurrent ViT의 expert 수는 모델 width에 따라 달라져야 하는가?

**직접 근거:** [One Block, Multiple Depths: Recurrent Vision Transformers with Depth-Programmed Experts](https://arxiv.org/html/2610.12448), arXiv v1, 2026-10-08

### 1. 문제 정의

하나의 Transformer block을 반복 사용하면 파라미터를 크게 줄일 수 있지만, 작은 ViT에서는 depth-specific function을 표현할 expert capacity가 부족할 수 있다. 고정 expert 수를 모든 width에 적용하는 설계가 실제 병목인지 검증한다.

### 2. 왜 지금 가치가 있는가

edge·on-device vision에서는 checkpoint 크기와 memory bandwidth가 중요하다. reViT는 저장 파라미터를 줄이면서 GFLOPs를 유지하는 새 축을 보여줬지만, S/B/L에서 expert 증가의 효과가 크게 다르다. 이를 width-aware capacity rule로 정리하면 단순 압축을 넘어 재사용 가능한 설계 원리를 만들 수 있다.

### 3. Observation과 최신 근거

- **확인된 사실:** 동일 supervised recipe에서 DeiT III-S/16은 79.9%, reViT-S/16 E=4는 78.2%다. B/16은 82.8% 대 83.0%, L/16은 84.1% 대 83.8%다.
- **확인된 사실:** E=1→8에서 top-1 향상은 S/16 +9.6%p, B/16 +6.8%p, L/16 +5.7%p다.
- **확인된 사실:** E=4→8 추가 이득은 S/16 +2.0%p, L/16 +0.2%p다.
- **저자 주장:** 큰 backbone은 더 적은 effective direction을 사용하고 추가 expert의 이득도 작다.
- **추론:** 필요한 expert 수는 깊이보다 hidden width와 depth-phase separability에 더 강하게 좌우될 수 있다.

### 4. 핵심 가설

동일 recurrent depth에서 적정 expert 수는 width와 반비례한다. 작은 width는 step별 표현을 activation에 암묵적으로 담기 어려워 더 많은 explicit expert direction이 필요하다. gate effective rank가 accuracy recovery를 예측할 것이다.

### 5. 최소 실험(MVP)

- 모델: 축소형 reViT-T/S 두 width, recurrent depth 12
- 조건: E={1,2,4,8}, 3 seeds, 같은 augmentation·epoch·GFLOPs
- 데이터: ImageNet-100 또는 ImageNet-1k 10% train subset으로 1차 반증
- 분석: top-1, calibration, gate entropy, merged-weight effective rank, depth별 CKA
- **GO:** 작은 width에서 E 증가의 기울기가 큰 width보다 일관되게 크고, effective rank가 accuracy와 seed 전반에서 상관
- **KILL:** width×E interaction이 seed variance보다 작거나, parameter-matched untied adapter가 동일 이득을 냄

### 6. baseline과 dataset

Tied ViT E=1, reViT E=2/4/8, layer-wise LoRA, four-block Raptor-style recurrence. ImageNet-100으로 빠르게 반증한 뒤 ImageNet-1k로 확인한다.

### 7. 성공·실패 판정 metric

top-1 평균·표준편차, parameter count, GFLOPs, checkpoint MB, gate effective rank, p95 latency. 핵심 통계는 width×E interaction effect다.

### 8. compute 난이도

3/5. 전체 ImageNet 재현은 무겁지만 작은 width와 subset으로 핵심 interaction을 먼저 볼 수 있다.

### 9. novelty 위험요인

기존 width scaling·MoE capacity 연구와 겹칠 수 있다. 방어점은 token routing이 아니라 **depth-programmed recurrence에서 width와 expert rank의 상호작용**을 직접 측정하는 것이다.

### 10. 4–8주 논문화 가능성

4주 안에 subset factorial 실험과 representation 분석이 가능하다. ImageNet-1k full run은 외부 compute가 필요하지만, 진단 결과와 compact scaling law만으로 workshop급 논문 가능성이 있다.

### 11. negative result의 가치

interaction이 없으면 reViT의 S-scale 손실은 expert 부족보다 optimization 또는 shared-attention bottleneck에서 온다는 경계조건을 얻는다.

**평가:** Novelty 4.5/5 · Feasibility 3.5/5 · Compute efficiency 3/5 · Publication potential 4.5/5

## Q2. unified 2D·3D decoder의 scaling regression은 backbone이 아니라 codebook 병목인가?

**직접 근거:** [DVD: Dynamic Vector Decoding for Efficient MLLM-based Perception](https://arxiv.org/html/2610.12266), arXiv v1, 2026-10-08

### 1. 문제 정의

DVD-8B는 2B보다 3D AP와 mask cIoU가 높지만, 일부 2D grounding Precision과 3D dataset에서는 낮다. unified codebook이 task별 정보를 경쟁시키는지, backbone 확대가 decoder 병목에 막히는지 분리한다.

### 2. 왜 지금 가치가 있는가

MLLM의 structured output을 compact vector token으로 바꾸는 흐름이 빨라지고 있다. backbone 규모만 키우는 관행이 box·mask·3D box를 모두 개선하지 않는다면, 저비용 2B 모델에서도 decoder·sampling을 고치는 편이 더 효과적이다.

### 3. Observation과 최신 근거

- **확인된 사실:** DVD-2B→8B에서 SUN-RGBD 40.0→40.3, Hypersim 15.7→18.4, nuScenes 19.8→24.4 AP3D@15다.
- **확인된 사실:** ARKitScenes는 62.4→62.1, KITTI는 31.4→28.7로 8B가 낮다.
- **확인된 사실:** RefCOCOg val Precision은 89.9→88.7, cIoU는 70.4→73.4다.
- **확인된 사실:** unified vector autoencoder는 codebook 4096, latent channel 16을 사용한다.
- **저자 주장:** compact vector representation이 text-coordinate의 길이와 fixed quantization 한계를 줄인다.
- **추론:** 8B의 추가 표현력이 고정 codebook에서 충돌하거나, RES/3D gradient가 box Precision을 희생할 수 있다.

### 4. 핵심 가설

8B regression의 주원인은 backbone scale이 아니라 codebook collision과 mixed-task gradient conflict다. codebook을 task-shared core와 task-specific residual로 분리하거나 sampling conflict를 완화하면 8B의 2D Precision 하락이 회복된다.

### 5. 최소 실험(MVP)

- backbone은 2B로 고정하고 decoder만 비교: shared codebook, doubled codebook, shared+task residual
- 2D box·mask의 공개 subset으로 시작하고 3D는 synthetic vector reconstruction으로 대체
- 각 task batch의 gradient cosine, code usage entropy, collision rate 측정
- **GO:** task-residual 또는 conflict-aware sampling이 2D Precision을 1%p 이상 높이면서 mask cIoU 손실 0.5%p 이하
- **KILL:** codebook 변경이 reconstruction error만 줄이고 downstream task metric은 바꾸지 않음

### 6. baseline과 dataset

DVD-style shared autoencoder proxy, independent task codebooks, larger shared codebook, text-coordinate baseline. RefCOCO/+/g와 COCO mask, 3D는 SUN-RGBD annotation의 vector-only subset.

### 7. 성공·실패 판정 metric

Precision@0.5, cIoU, AP3D@15 또는 vector IoU surrogate, code perplexity, collision rate, gradient cosine, output tokens, latency.

### 8. compute 난이도

3/5. 8B full fine-tuning은 제외하고 frozen 2B backbone·decoder-only 학습으로 축소한다.

### 9. novelty 위험요인

multi-task codebook과 gradient surgery는 알려진 주제다. novelty는 2D box·mask·3D box를 같은 discrete geometry space에 넣었을 때 발생하는 **representation collision과 scaling regression의 연결**에 둔다.

### 10. 4–8주 논문화 가능성

4주 안에 vector autoencoder audit와 2D downstream 실험이 가능하다. 3D까지 완전 재현하면 8주 이상 걸릴 수 있으므로 첫 논문은 diagnostic note가 현실적이다.

### 11. negative result의 가치

codebook이 병목이 아니면 8B regression이 data mixture·optimization·metric variance에서 온다는 근거가 되며, 더 큰 decoder 설계를 중단할 수 있다.

**평가:** Novelty 4/5 · Feasibility 3.5/5 · Compute efficiency 3/5 · Publication potential 4/5

## Q3. camera geometry와 appearance robustness를 분리 학습하면 VLA의 worst-group success가 개선되는가?

**직접 근거:** [VersaCamVLA: Camera-Configurable VLA Policies for Robotic Manipulation](https://arxiv.org/html/2610.12451), arXiv v1, 2026-10-08

### 1. 문제 정의

한 VLA가 unseen camera pose에는 강하지만 texture·lighting·scene appearance 변화에는 크게 무너진다. 동일한 scene token에 geometry와 appearance를 함께 담는 것이 robustness 축 간 간섭을 만드는지 검증한다.

### 2. 왜 지금 가치가 있는가

로봇 배치는 카메라 이동, 조명, 배경, 물체 외형 변화가 동시에 발생한다. “camera-configurable” 성능만으로 실제 domain robustness를 보장할 수 없으므로, factorized evaluation과 representation이 필요하다.

### 3. Observation과 최신 근거

- **확인된 사실:** RoboTwin camera pose에서 VersaCamVLA는 seen 53.44%, unseen 52.63%다.
- **확인된 사실:** camera extrinsic noise 50mm/5°에서도 52.56→50.38%로 완만히 하락한다.
- **확인된 사실:** 공식 Clean→DR 평균은 52.56→23.00%다. DR은 appearance·scene variation이다.
- **확인된 사실:** RGB-only DR 20.94%, edge+semantic supervision을 합치면 29.50%다.
- **확인된 사실:** scene token 수 48/192/432의 평균은 50.06/55.63/47.50%로 더 많은 token이 항상 좋지 않다.
- **추론:** geometry alignment와 semantic invariance가 하나의 token bottleneck에서 경쟁하며, token 수 증가가 nuisance appearance까지 정책에 전달할 수 있다.

### 4. 핵심 가설

posed multi-view geometry token과 appearance-invariant semantic token을 분리하고, policy에는 task-dependent gate로 주입하면 pose와 appearance의 joint shift에서 worst-group success가 개선된다.

### 5. 최소 실험(MVP)

- full robot 학습 대신 RoboTwin 4개 task와 frozen encoder 사용
- representation: shared token, geometry-only, semantic-only, factorized dual stream
- 평가: pose {seen, unseen} × appearance {clean, DR} 2×2
- token 수를 총량 고정해 capacity confound 제거
- **GO:** factorized model이 clean 평균 손실 2%p 이하에서 4개 group 최저 success를 5%p 이상 개선
- **KILL:** semantic supervision만으로 동일 개선이 나와 factorization이 불필요

### 6. baseline과 dataset

VersaCamVLA-style shared scene tokens, direct multi-view concatenation, RGB-only, RGB+edge+semantic, factorized token proxy. RoboTwin 2.0의 4개 난도 다른 task.

### 7. 성공·실패 판정 metric

group별 task success, worst-group success, pose/appearance sensitivity slope, feature-domain distance, token mutual information, p95 latency.

### 8. compute 난이도

4/5. 원 논문 규모는 8×H100이므로 full 재현은 어렵다. frozen encoder와 4-task policy adapter로 줄여야 한다.

### 9. novelty 위험요인

disentangled representation·domain generalization과 겹칠 수 있다. novelty는 카메라 pose라는 명시적 geometry nuisance와 appearance DR을 **교차 factorial로 평가하고 policy token interface에서 분리**하는 데 있다.

### 10. 4–8주 논문화 가능성

시뮬레이터와 checkpoint가 확보되면 6–8주 pilot이 가능하다. 공개 코드가 늦으면 scene-token proxy로 representation audit부터 시작한다.

### 11. negative result의 가치

factorization이 실패하면 bottleneck이 representation이 아니라 demonstration diversity 또는 action decoder에 있음을 보여준다.

**평가:** Novelty 4.5/5 · Feasibility 2.5/5 · Compute efficiency 2/5 · Publication potential 5/5

## Q4. omnimodal collaboration을 inference-time sparse routing으로 접어도 품질을 유지할 수 있는가?

**직접 근거:** [Syn-Omni: Structured Specialization and Progressive Collaboration for Omnimodal Embeddings](https://arxiv.org/html/2610.12256), arXiv v1, 2026-10-08

### 1. 문제 정의

Syn-Omni는 modality expert를 함께 활성화해 embedding 품질을 높이지만, expert path와 router가 inference graph에 남아 latency가 약 18% 증가한다. train-time soft collaboration을 더 싼 inference graph로 변환할 수 있는지 묻는다.

### 2. 왜 지금 가치가 있는가

retrieval 시스템은 batch throughput과 p95 latency가 중요하다. 평균 Hit@1 +0.9~1.7%p가 18% latency를 정당화하지 못하는 환경이 많으므로, quality–latency Pareto를 직접 최적화해야 한다.

### 3. Observation과 최신 근거

- **확인된 사실:** 3B Uni-Omni→Syn-Omni 전체 Hit@1은 47.7→49.4, 7B는 50.7→51.6이다.
- **확인된 사실:** RTX A6000 batch 1에서 3B latency는 300.3±25→354.6±20ms, 7B는 377.1±26→443.5±30ms다.
- **확인된 사실:** peak memory 증가는 작지만 expert path와 router는 dynamic routing 때문에 남는다.
- **저자 주장:** absent-modality expert의 의미 있는 activation이 cross-modal synergy를 만든다.
- **추론:** hard top-1 routing은 synergy를 잃을 수 있으나, teacher의 soft mixture를 folded low-rank adapter에 증류하면 대부분 보존될 수 있다.

### 4. 핵심 가설

입력별 soft expert mixture를 작은 gating code로 근사하거나 modality-combination별 folded adapter로 증류하면 Hit@1 손실 0.5%p 이하에서 latency 증가를 5% 이내로 줄일 수 있다.

### 5. 최소 실험(MVP)

- 3B model 또는 작은 Qwen/CLIP proxy
- 조건: full soft routing, top-1, top-2, static modality fold, distillation fold
- image/audio/audiovisual subset에서 quality와 runtime 동시 측정
- **GO:** full 대비 Hit@1 -0.5%p 이내, Uni-Omni 대비 p95 latency +5% 이하
- **KILL:** absent-modality activation을 제거하면 audiovisual Hit@1이 2%p 이상 하락하고 folded adapter가 회복하지 못함

### 6. baseline과 dataset

Uni-Omni shared LoRA, Syn-Omni soft routing, top-k routing, weighted adapter merge, student distillation. VALOR-32k subset과 image/audio retrieval subset.

### 7. 성공·실패 판정 metric

modality별 Hit@1, 전체 macro average, p50/p95 latency, QPS, peak VRAM, 활성 expert 수, energy/query.

### 8. compute 난이도

3/5. full 3B 학습보다 공개 checkpoint 후 inference-time folding·소규모 distillation을 우선한다.

### 9. novelty 위험요인

MoE pruning·adapter merging과 겹친다. 차별점은 absent-modality expert가 기여하는 omnimodal synergy를 유지하는 **modality-combination conditional folding**이다.

### 10. 4–8주 논문화 가능성

checkpoint 접근 시 4주 내 latency audit와 top-k baseline, 6–8주에 distillation까지 가능하다.

### 11. negative result의 가치

folding이 실패하면 soft cross-modal activation이 단순 overhead가 아니라 실제 representation mechanism이라는 강한 증거가 된다.

**평가:** Novelty 4/5 · Feasibility 4/5 · Compute efficiency 3.5/5 · Publication potential 4/5

## Q5. benchmark 답으로 팀을 고른 anomaly ensemble의 이득은 held-out·sequential protocol에서도 남는가?

**직접 근거:** [Is In-Domain Training Enough for Fine-Grained Industrial Anomaly Understanding?](https://arxiv.org/html/2610.12310), arXiv v1, 2026-10-08

### 1. 문제 정의

SiGMA는 MMAD 평균 85.2%를 보고하지만, agent team과 hyperparameter를 MMAD evaluation answers로 선택하고 controller를 evaluation batch의 unlabeled predictions에 transductive fit한다. 이 성능이 unseen category와 sequential query에서도 유지되는지 검증한다.

### 2. 왜 지금 가치가 있는가

VLM ensemble·agent system은 모델 수보다 selection·calibration protocol에서 큰 이득을 얻을 수 있다. benchmark-level tuning을 일반화 성능으로 오해하면 연구 결론과 deployment 기대가 모두 왜곡된다.

### 3. Observation과 최신 근거

- **확인된 사실:** MMAD 39,670 questions에서 SiGMA 평균 85.2%, JUDO 81.2%다.
- **확인된 사실:** anomaly detection/localization은 82.6/79.6으로 강하지만 defect description/analysis는 best trained보다 1.4/3.0%p 낮다.
- **확인된 사실:** team과 hyperparameter는 MMAD answers로 선택됐다.
- **확인된 사실:** controller는 별도 calibration split 없이 evaluation predictions의 unlabeled batch 통계를 사용한다.
- **확인된 사실:** 저자들은 frozen-statistics sequential protocol을 평가하지 않았다고 명시한다.
- **추론:** headline gain의 일부는 team selection과 batch composition에 의존할 수 있다.

### 4. 핵심 가설

category-held-out nested validation과 frozen sequential statistics를 적용하면 평균 이득은 줄지만, reference-based defect expert의 detection/localization 기여는 남는다. 줄어드는 폭이 protocol dependence를 정량화한다.

### 5. 최소 실험(MVP)

- MMAD의 공개 prediction 또는 재현 가능한 500–1,000 question subset
- outer split: product/category held-out
- inner split: team·hyperparameter 선택
- 비교: oracle benchmark selection, nested selection, transductive batch, frozen historical batch, per-query no-fit
- **GO:** defect expert 이득이 held-out detection/localization에서 각각 5%p 이상 유지
- **KILL:** nested/frozen protocol에서 전체 이득이 1%p 미만이거나 category 순서에 따라 부호가 바뀜

### 6. baseline과 dataset

단일 Qwen 계열, fixed eight-agent team, full ten-agent pool, agent-only, +defect expert, reliability controller. MMAD를 category-level outer fold로 재분할한다.

### 7. 성공·실패 판정 metric

task별 accuracy, macro average, category bootstrap CI, calibration ECE, batch-order sensitivity, latency·비용, agent count.

### 8. compute 난이도

2/5. 공개 prediction이 있으면 재학습 없이 protocol audit가 가능하다. 모든 MLLM을 다시 실행하면 비용이 커진다.

### 9. novelty 위험요인

“평가 leakage audit”로만 보일 수 있다. 방어점은 transductive ensemble의 batch dependence와 benchmark-level model selection을 하나의 재현 protocol로 정식화하고, anomaly VLM의 reference expert 효과를 분리하는 것이다.

### 10. 4–8주 논문화 가능성

prediction 접근 시 2–4주에 완료 가능하다. 가장 빠른 diagnostic benchmark note 후보다.

### 11. negative result의 가치

성능이 그대로 유지되면 SiGMA의 이득이 selection artifact가 아니라 robust expert composition에서 온다는 강한 독립 검증이 된다.

**평가:** Novelty 3.5/5 · Feasibility 4.5/5 · Compute efficiency 5/5 · Publication potential 4/5

## Q6. token budget은 실제 wall-clock과 tiny-object 보존을 예측하는 충분한 지표인가?

**직접 근거:** [BudgetPix: Compute-Adaptive Tokenization for Pixel-Space Image Diffusion](https://arxiv.org/html/2610.12307), arXiv v1, 2026-10-08 · [공식 프로젝트](https://karaozgur.com/BudgetPix/)

### 1. 문제 정의

같은 25% token budget이라도 parent architecture에 따라 wall-clock speed-up이 1.36×에서 3.59×까지 다르다. 평균 생성 품질이 유지돼도 tiny object와 구조적 경계가 보존되는지는 별도 문제다.

### 2. 왜 지금 가치가 있는가

생성형 augmentation을 해상·UAV 탐지에 쓰려면 “토큰을 줄였다”보다 실제 시간·에너지와 작은 객체 보존을 알아야 한다. budget ratio를 효율 지표로 직접 쓰는 관행을 검증할 필요가 있다.

### 3. Observation과 최신 근거

- **확인된 사실:** 25% budget에서 BudgetPix wall-clock speed-up은 MiniT2I-L/16 3.59×, MiniT2I-B/16 3.34×, PixelDiT-T2I 1.95×, JiT-B/32 1.36×다.
- **확인된 사실:** PixelDiT 1024² 25% budget은 GenEval 0.725, DPG 83.7이고 full-budget base는 0.721/84.8이다.
- **확인된 사실:** BudgetPix는 별도 fine-tuning과 encoder/decoder를 필요로 한다.
- **저자 주장:** content-adaptive tokenization이 넓은 budget 범위에서 품질–비용 trade-off를 개선한다.
- **추론:** token ratio는 kernel occupancy·fixed overhead를 반영하지 않으며, global quality metric은 작은 선박·부표 손실을 숨길 수 있다.

### 4. 핵심 가설

실제 speed-up은 token ratio보다 `attention fraction + fixed encoder/decoder overhead + hardware occupancy` 모델로 더 잘 예측된다. entropy routing은 낮은 면적의 작은 객체를 과소할당할 수 있어 object-aware floor가 필요하다.

### 5. 최소 실험(MVP)

- 공개 코드 전에는 dense pixel DiT 또는 token-merging proxy 사용
- maritime/UAV prompt 50개, 고정 seed 5개
- budget={100,50,25%}, object-aware minimum-token floor 유무
- GPU profiler로 encoder/decoder/denoiser 시간을 분리
- **GO:** runtime model의 speed-up 예측 오차 10% 이하, object-aware floor가 25% budget의 small-object recall을 5%p 이상 개선하며 latency 증가 10% 이하
- **KILL:** object loss가 entropy allocation과 무관하거나 frozen detector artifact로 설명됨

### 6. baseline과 dataset

uniform downsampling, ToMe/FeatSim proxy, entropy quadtree, object-aware quadtree. maritime prompt set, VisDrone/SeaShips object compositing prompt, 일반 GenEval control.

### 7. 성공·실패 판정 metric

wall-clock, kernel time, peak VRAM, energy/image, GenEval/DPG, detector APs·recall, object count correctness, boundary LPIPS.

### 8. compute 난이도

3/5. 대규모 학습 없이 inference audit가 가능하지만, 공식 checkpoint·code 공개에 의존한다.

### 9. novelty 위험요인

효율 profiling과 task-aware routing 연구와 겹친다. 차별점은 생성형 token budget benchmark에서 **실측 cost model과 tiny-object preservation을 공동 평가**하는 것이다.

### 10. 4–8주 논문화 가능성

코드가 공개되면 4주 내 audit, 6주 내 object-aware floor까지 가능하다. 미공개 상태가 길어지면 proxy 연구로 가치가 낮아진다.

### 11. negative result의 가치

token ratio가 실제 시간을 잘 예측하고 small-object 손실도 없다면, 복잡한 cost model과 object floor가 불필요하다는 실용적 결론을 얻는다.

**평가:** Novelty 4/5 · Feasibility 3.5/5 · Compute efficiency 3.5/5 · Publication potential 4/5

## 오늘의 선택

### 가장 먼저 테스트할 질문: Q1

- **진단:** recurrent sharing의 손실이 작은 width에서 집중된다.
- **가설:** width가 작을수록 더 많은 depth-specific expert direction이 필요하다.
- **첫 실험:** ImageNet-100에서 width 2수준 × E={1,4,8}, 3 seeds.
- **하루 종료 판정:** E 증가의 이득이 작은 width에서 더 크지 않으면 full ImageNet 확장을 중단한다.

### RTX 5060 Ti 8GB에서 가능한 질문: Q5

- 공개 prediction이나 소규모 subset만 있으면 모델 재학습이 필요 없다.
- 핵심은 category-held-out split과 transductive/frozen protocol 비교다.
- GPU보다 데이터 분할·bootstrap·calibration 분석이 중심이다.

### 장기 박사 주제로 키울 질문: Q3

- representation factorization, domain generalization, embodied policy, worst-group robustness를 연결한다.
- camera geometry와 appearance라는 해석 가능한 두 nuisance axis를 갖는다.
- 장기적으로 조명·occlusion·sensor failure·camera count까지 확장할 수 있다.
