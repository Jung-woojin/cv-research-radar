# CV 논문 아이디어 레이더 — 2026년 10월 30일

**조사 범위:** 2026년 10월 23~29일. arXiv 원문·공식 코드 공개를 중심으로 확인했으며, 10월 30일 오전 기준으로 최신 공개분을 반영했다. 아래의 논문 성능은 별도 표기가 없는 한 **저자 보고 결과**이고, 후속 연구의 예상 효과와 점수는 **검증 전 연구 가설**이다.

## 핵심 요약

1. 이번 주에는 **OVD 성능 저하의 원인을 실제 fine-tuning weight 변화에서 찾는 방법**이 등장했다. CLIP 업데이트를 되돌리거나 일부만 유지하는 개입이 핵심이다.
2. Aerial grounding에서는 oriented box를 학습했을 때의 이득을 단순 decoder 확장 효과와 분리한 실험이 주목할 만하다.
3. **PROVE**는 대상이 존재하지 않는 경우를 명시적으로 다루고, **AdaGround**는 확대 관측 후의 결과를 무조건 수용하지 않고 검증한다.
4. **GeoPrompt**는 악화된 해양 환경에서 RGB appearance만이 아니라 구조적 단서를 사용해 open-vocabulary alignment를 보완한다.
5. **PerceptRL**은 정답 보상에 가려진 spatial-tool 오류를 별도로 감독하고, video RLVR 연구는 오히려 정답 보상이 visual shortcut을 강화할 수 있음을 지적한다.
6. **FVQ**는 visual token의 reconstruction error가 semantic fidelity와 일치하지 않는다는 반례를 제시했다. 전체 VLM 정확도가 높아도 tiny evidence가 보존되는지는 별개 문제다.
7. 이번 회차의 연구 후보는 **DeltaCausal-OVD**, **AbsentOrUnseen**, **TinyBitAudit** 세 가지다.
8. 최우선 추천은 **DeltaCausal-OVD**다. 새로운 OVD 구조를 만들기 전에 *어떤 weight update가 novel-class 성능을 해치는지* 직접 개입으로 검증할 수 있다.

### 주목할 근거와 한계

**① CLIP fine-tuning delta의 기능적 기여.** 저자들은 ViT-L/14 등으로 분류 실험을 수행하고, attention의 value-output(VO) 업데이트만 유지해도 fine-tuning 정확도 향상분의 **43~87%**가 회복된다고 보고했다. 그러나 해당 업데이트를 되돌렸을 때의 영향과 *그 업데이트만 남겼을 때의 영향*은 동일하지 않았다. VO와 MLP 업데이트 사이에서도 기능적 중복이 관찰됐다. 중요한 점은 **어떤 파라미터가 변했는지**와 **그 변화가 어떤 예측에 실제로 필요한지**가 다르다는 것이다. 다만 논문의 주 실험은 분류이며, OVD novel-class AP에 대한 결론을 직접 제공하지 않는다. [원문](https://arxiv.org/abs/2610.34144)

**② OBB-PBD의 geometry-specific 효과.** Aerial Visual Grounding에서 rotated IoU가 zero-shot baseline 0.1253에서 **0.303±0.012**로 개선됐고, oriented box를 직접 학습한 효과는 axis-aligned control 대비 **+0.055±0.008 rotIoU**였다. 단순 decoder block 확대만으로는 통계적으로 분리 가능한 이득이 없었다. Image/prompt shuffle과 leakage probe까지 수행했다는 점이 특히 좋다. 단, 6,139개 test record가 120개 이미지에 분포하므로 이미지 단위 의존성을 고려한 평가도 중요하다. 공식 코드·checkpoint가 공개됐다. [원문](https://arxiv.org/abs/2610.35450)

**③ GeoPrompt의 구조적 정보 활용.** 수중 환경의 산란·색 감쇠·탁도 때문에 region feature와 text embedding의 정렬이 불안정해진다는 문제에서 출발한다. Depth-derived structural prior를 multi-scale visual feature에 주입하고 geometry-conditioned text classifier를 생성한다. 여기서 **구조 정보가 appearance보다 안정적일 수 있다**는 해석은 유용하지만, 모든 해무·안개·저조도 환경에서 동일하게 성립한다고 일반화할 수는 없다. [원문](https://arxiv.org/abs/2610.34190)

**④ PROVE의 부재 판단.** Frozen CLIP의 patch feature에서 Beta 분포를 학습해 positive/negative evidence를 표현하고, posterior mean과 vacuity, 이미지 수준 absence score를 산출한다. 기존의 단일 relevance map과 달리 **대상이 없는 질문에 억지 위치를 반환하지 않을 수 있다**는 점이 중요하다. 다만 vacuity가 높다는 사실만으로 *대상이 실제로 없는지, 너무 작아서 보이지 않는지*를 구별한다고 볼 수는 없다. [원문](https://arxiv.org/abs/2610.32440)

**⑤ AdaGround의 검증 후 확대.** GUI grounding에서 target size에 따라 zoom 깊이와 범위를 조절하고, 확대 후 결과를 Yes/No verifier로 검증한다. 필요하면 다시 탐색하거나 abstain한다. 저자들은 OSWorld-G와 ScreenSpot-Pro에서 backbone 대비 **+7.4~20.6%p** 개선을 보고했다. 실제 aerial scene으로의 이전은 별도 검증이 필요하지만, *추가 관측 결과를 무조건 수용하지 않는다*는 설계 원칙이 유용하다. 공식 코드가 공개됐다. [원문](https://arxiv.org/abs/2610.36874)

**⑥ PerceptRL의 중간 과정 감독.** Dense caption에서 확인된 지각 오류를 정답이 고정된 QA 문제로 변환해 RL에 사용한다. 또한 crop 좌표가 잘못되어 이후 추론에 오류가 전파되는 **coordinate drift**를 발견하고, Coordinate Injection과 grounding-aware process reward를 제안했다. 7개 benchmark에서 평균 **71.6%**, 동일 도구를 사용하는 기본 모델보다 **+15.7%p**를 보고한다. [원문](https://arxiv.org/abs/2610.37471)

**⑦ Video RLVR의 반례.** 결과 보상만 최적화하면 모델의 답변 confidence는 높아지지만 visual evidence가 기여하는 uncertainty reduction은 감소할 수 있다. 저자들은 이를 **perceptual uncertainty collapse**로 분석하고, 시각적 교란과 self-distillation을 결합한 BSPO를 제안했다. 즉 정확도가 올라갔다고 해서 모델이 영상을 더 잘 본 것은 아닐 수 있다. [원문](https://arxiv.org/abs/2610.37211)

**⑧ FVQ의 semantic-fidelity 반례.** 저자들은 reconstruction MSE가 **9.1배 높아도** understanding score는 **9.5점 높은** 이산 표현 사례를 제시한다. 또한 FVQ를 통해 여러 codebook의 정보 포화를 줄여 연속 visual representation에 가까운 이해 성능을 보고했다. 코드와 tokenizer·VLM weights가 공개되어 있으며, 전체 industrial-scale training을 재현하려면 상당한 자원이 필요하다. [원문](https://arxiv.org/abs/2610.37662)

공식 구현 중 바로 확인할 수 있는 것은 [FVQ](https://github.com/hustvl/FVQ), [AdaGround](https://github.com/bcwang-sjtu/AdaGround), [OBB-PBD](https://github.com/ce-dric/OBB-PBD)다. 다른 논문의 공식 코드·checkpoint는 이번 조사에서 공개 여부를 충분히 검증하지 못했으므로, 재현 가능하다고 전제하지 않는다.

# 2. 연구 후보 A — DeltaCausal-OVD

## Functional Reversion of Fine-Tuning Updates for Open-Vocabulary Detection

**1) 문제 정의와 연구 가치.** OVD fine-tuning 후 base-class 성능이 개선되고 novel-class AP가 떨어졌을 때, 현재는 이를 representation forgetting, text-image alignment 붕괴, negative transfer 등으로 설명할 수 있다. 하지만 **어떤 weight update를 되돌리면 어떤 클래스의 성능이 실제로 회복되는가**는 별도의 질문이다. 이번 주 CLIP delta 연구를 OVD의 region-level·class-level 동작으로 확장한다.

**2) 기존 연구의 빈틈.** Reversion/retention 연구는 CLIP 분류에서 기능적 업데이트를 측정했지만 detection의 box proposal, region feature, novel text classifier를 분리하지 않았다. 또한 OVD에서 파라미터 변화의 크기나 feature similarity가 곧 novel-class 손실의 원인이라고 단정하기 어렵다.

**3) 핵심 가설.** 일부 VO/MLP fine-tuning delta는 base-class 개선에 기여하지만 novel-class alignment를 해칠 수 있다. 다만 그 영향은 업데이트 크기와 반드시 비례하지 않으며, **class·object scale·region context에 따라 달라질 것**이다. 기여가 중복되는 업데이트를 선택적으로 되돌리면 base 성능을 크게 희생하지 않고 novel AP를 회복할 가능성이 있다.

**4) 제안 구조.** Pretrained CLIP과 fine-tuned CLIP의 가중치 차이 ΔW를 구한다. Block/attention VO/MLP별로 (a) revert, (b) retain only, (c) partial interpolation을 수행한다. 같은 region proposal을 고정한 상태에서 class score·region embedding·localization quality 변화를 측정하고, 별도의 full-detector 실험에서 최종 AP를 평가한다. 초기에 새로운 학습 모듈은 만들지 않는다.

**5) Baseline과 비교군.** Frozen pretrained model, full fine-tuned model, WiSE-FT 계열 weight interpolation, random matched-size delta removal, magnitude-based delta removal, VO-only/MLP-only reversion, LoRA/adapter baseline, oracle layer-selection upper bound를 비교한다.

**6) 데이터셋·지표.** LVIS base/novel split을 중심으로 하고, novel category 구성이 다른 외부 데이터로 ODinW subset을 고려한다. APbase, APnovel, APrare, APsmall, region classification margin, forgetting ratio, localization error, calibration을 측정한다. **AP는 데이터셋 수준 지표**이므로 sample별 update utility를 AP로 직접 정의하지 않고 개별 region loss/margin을 사용한다.

**7) 필수 ablation.** Revert vs retain, VO vs MLP, layer depth, random/magnitude-matched mask, box proposal 고정 여부, 3 seeds, class frequency, visual similarity, object size, prompt template 변화, update interpolation coefficient.

**8) 실패 모드와 negative result.** 유해 업데이트가 일부 블록에 국한되지 않고 광범위하게 분포할 수 있다. 한 블록의 효과를 되돌렸을 때 다른 블록이 대체하는 기능적 중복도 예상된다. Novel AP가 회복되어도 base AP가 비슷한 폭으로 하락할 수 있다. 이 경우에도 **negative transfer를 일으키는 weight delta가 특정 semantic direction으로 단순히 국소화되지 않는다**는 결과가 가능하다.

**9) Novelty 위험과 방어 논리.** 단순 weight interpolation이나 기존 논문의 OVD 적용으로 끝나면 약하다. 논문 중심을 **detection-specific causal intervention protocol**과 *class/scale-conditioned functional redundancy*에 둬야 한다. Reversion·retention은 완전한 인과 증명이 아니라 **통제된 모델 개입의 증거**로 표현한다.

**10) 4~8주 MVP.** 1주차: 동일 CLIP backbone을 쓰는 OVD baseline과 pretrained/fine-tuned checkpoint 확보, proposal 고정 평가. 2주차: 마지막 4~6개 visual block의 VO/MLP reversion matrix 생성. 3주차: class/scale별 loss·AP 변화 분석. 4주차: base-retention constraint를 포함한 delta selection. 5~6주차: 외부 데이터·다중 seed. 7~8주차: mechanistic figure와 negative controls.

**11) 성공할 경우 contribution 3개.** (i) OVD 업데이트의 class-conditioned functional necessity/sufficiency 측정, (ii) scale별 harmful/beneficial delta와 중복성 분석, (iii) base–novel trade-off를 완화하는 저비용 selective reversion.

**12) 제목 후보.** *DeltaCausal-OVD: Which Fine-Tuning Updates Actually Hurt Novel Objects?* / *Revert, Retain, or Reuse: Functional Attribution of Open-Vocabulary Detector Updates* / *Where Does Negative Transfer Live?*

**13) Abstract 개요.** OVD fine-tuning의 이득과 novel-class 손실 제시 → weight-space attribution의 상관관계 한계 → reversion/retention intervention 도입 → region/class/scale별 기여 분석 → trade-off 및 일반화 실험.

**14) Introduction 논리.** OVD 성능 개선과 negative transfer 공존 → representation forgetting 설명의 불충분성 → fine-tuning delta의 기능적 중복에 대한 최근 증거 → detection에서 아직 검증되지 않은 class-dependent 영향 → 개입 중심 분석.

**15) Related Work 구성.** Open-Vocabulary Detection / Fine-Tuning and Negative Transfer / Weight-Space Model Editing and Interpolation / Mechanistic Attribution / Scale-Conditioned Detection.

**16) Method 구성.** 3.1 Controlled OVD Setup → 3.2 Functional Delta Decomposition → 3.3 Reversion–Retention Intervention → 3.4 Region/Class Attribution → 3.5 Base-Constrained Delta Selection.

**17) Experiment 표·그림.** Table 1 base/novel AP, Table 2 intervention별 효과, Table 3 scale-conditioned AP, Table 4 외부 검증. Figure 1 method, Figure 2 layer×class effect heatmap, Figure 3 revert/retain asymmetry, Figure 4 base–novel Pareto, Figure 5 실제 novel recovery 사례.

# 3. 연구 후보 B — AbsentOrUnseen

## Distinguishing Target Absence from Insufficient Visual Evidence

**1) 문제 정의와 연구 가치.** Aerial·maritime grounding에서 모델이 목표를 찾지 못했을 때 실제로는 서로 다른 세 상황이 존재한다. **대상이 없음(Absent)**, **대상은 있지만 현재 해상도에서 보이지 않음(Unresolved)**, **대상이 보이지만 후보가 모호함(Ambiguous)**이다. 이를 단일 confidence나 unknown label로 처리하면 불필요한 확대·오탐·거부가 발생한다.

**2) 기존 연구의 빈틈.** PROVE는 absence uncertainty를, AdaGround는 zoom·검증·abstention을, OBB-PBD는 aerial geometry와 leakage control을 다룬다. 그러나 **현재 시야에 정보가 없어서 판단할 수 없는 상태와 실제 대상 부재를 분리한 의사결정 protocol**은 이 세 연구만으로 해결되지 않는다.

**3) 핵심 가설.** Evidence vacuity, candidate disagreement, image scale, crop 후 score 변화 가능성을 결합하면 absent/unresolved/ambiguous를 단일 confidence보다 잘 구분할 수 있다. 이 상태를 식별하면 모든 실패 사례에 확대를 적용하는 대신 **답변·추가 관측·거부**를 선택할 수 있다.

**4) 제안 구조.** Frozen grounder → Patch Evidence Estimator → Candidate Competition / Vacuity → Three-State Risk Predictor → accept / reobserve / abstain policy → local re-grounding 및 검증. 최종 예측에는 rotated box 또는 mask를 사용할 수 있지만, 핵심 novelty는 새로운 decoder가 아니라 **증거 부족의 유형 식별**이다.

**5) Baseline.** CLIP grounding, PROVE-style vacuity, confidence threshold, size-based zoom, AdaGround-style verifier, random fixed-budget zoom, always-zoom, always-abstain-risk matching, oracle state policy.

# 4. 연구 후보 C — TinyBitAudit

## Scale-Conditioned Semantic Fidelity of Discrete Visual Tokens

**1) 문제 정의와 연구 가치.** FVQ 결과는 재구성 MSE가 semantic understanding의 좋은 대리 지표가 아닐 수 있음을 보여준다. 그러나 전체 benchmark에서 continuous representation과 비슷하더라도, 이미지의 **1% 미만 영역을 차지하는 작은 객체의 존재·위치·종류**가 같은 정도로 보존되는지는 별개다.

**2) 기존 연구의 빈틈.** Visual tokenizer 평가는 전역 이미지 이해나 OCR 등에서 강하지만 object scale과 spatial localization에 따라 *의미 정보가 실제로 몇 bit에서 사라지는가*를 체계적으로 분리하지 않는다. Tiny-object detector의 P2 활용도 discrete token bit budget과 직접 연결해 설명된 바가 부족하다.

**3) 핵심 가설.** 동일한 평균 VLM understanding score에서도 객체 크기가 작을수록 token quantization으로 인한 **semantic decision flip**이 증가할 수 있다. MSE보다 GT-object 주변의 region-feature margin, codebook 정보량, object-token overlap이 tiny failure를 더 잘 예측할 가능성이 있다.

**4) 제안 구조.** Frozen vision encoder → continuous feature reference → VQ/RVQ/PQ/FVQ tokenizer → per-codebook truncation/masking → frozen probe/grounder → scale-conditioned distortion audit. 효과가 확인되면 **object-critical region에 code budget을 추가 배분하는 lightweight budget allocator**를 별도 제안한다. 처음부터 대형 VLM을 재학습하지 않는다.

**5) Baseline.** Continuous features, uniform bit budget, VQ/RVQ/PQ/FVQ, MSE-optimal allocation, entropy allocation, random region allocation, objectness-guided allocation, oracle object-mask allocation.

**6) 데이터셋·지표.** VisDrone, AI-TOD 또는 TinyPerson의 공개 split, COCO small-object bin, 선택적으로 remote-sensing grounding subset을 사용한다. Main metric은 APsmall/Recalltiny와 **semantic flip rate**, per-object bit budget, region cosine/margin retention, localization drift, bit–accuracy Pareto다. VLM understanding과 detector probe 결과는 별도 표로 분리한다.

**7) Ablation.** Codebook 수, object pixel size, patch overlap, background complexity, compression ratio, continuous vs discrete, MSE vs task-based allocation, P2 vs P3 source feature, multiple seeds, tokenizer freezing 여부.

**8) 실패 모드와 negative result.** Frozen VLM이 특정 discrete code 조합에만 학습돼 있으면 임의 codebook masking이 distribution shift를 만든다. 따라서 masking 결과를 순수 정보 손실이라고 단정하지 않고, **토큰별 probe 및 재학습한 얕은 decoder**로 교차 확인해야 한다. Tiny-object 손실이 특별히 크지 않으면 오히려 discrete representation의 강건성을 뒷받침하는 결과가 된다.

**9) Novelty 위험과 방어.** 단순 FVQ 재현이나 compression experiment로 보이지 않아야 한다. 논문의 질문은 **“global semantic fidelity가 scale-conditional evidence preservation을 보장하는가?”**이다. 최소한 object-location-conditioned diagnostic과 동일 bit budget 비교가 있어야 한다.

**10) 4~8주 MVP.** 1주차 FVQ tokenizer 설치·continuous/discrete feature 추출. 2주차 object-size bin별 semantic flip/probe. 3주차 VQ/RVQ 비교. 4주차 fixed budget allocation. 5~6주차 P2/P3 interaction. 7~8주차 외부 dataset, 8B VLM에서 일부 검증. 공개 tokenizer inference부터 시작하고 대규모 재학습은 제외한다.

**11) Contribution 3개.** (i) Scale-conditioned semantic fidelity protocol, (ii) token bit allocation과 tiny-object evidence retention의 관계 분석, (iii) 유효할 경우 scale-aware budget allocation.

**12) 제목 후보.** *TinyBitAudit: Are Discrete Visual Tokens Semantically Lossless for Tiny Objects?* / *Beyond Reconstruction Error: Measuring Object-Scale Information Loss in Visual Quantization* / *Where Do the Bits Go? Scale-Conditioned Evidence Preservation in Visual Tokenizers.*

**13) Abstract 개요.** Discrete token의 전역 성능 개선 → tiny object evidence 보존 문제 → continuous/discrete matched representation 비교 → semantic flip와 지역 정보량 측정 → uniform/task-aware bit budget 실험.

**14) Introduction 논리.** Native multimodal tokenization 확대 → reconstruction error와 이해 정확도의 괴리 → 작은 객체의 정보 희소성 → 기존 전역 benchmark의 사각지대 → object-scale semantic fidelity 측정.

**15) Related Work.** Visual Tokenization / Vector Quantization / Small Object Representation / High-Resolution Feature Pyramids / Semantic Rate–Distortion / Efficient Multimodal Models.

**16) Method.** 3.1 Scale-Conditioned Fidelity Definition → 3.2 Discrete/Continuous Matched Probe → 3.3 Token-Budget Intervention → 3.4 Semantic Flip Analysis → 3.5 Optional Budget Allocator.

**17) Experiment 표·그림.** Table 1 tokenizer별 scale 성능, Table 2 동일 bit budget, Table 3 P2/P3 비교, Table 4 external transfer. Figure 1 visual tokenization, Figure 2 object size–flip curve, Figure 3 MSE–semantic loss 상관관계, Figure 4 bit allocation map, Figure 5 tiny-object 실패 사례.

**첫 2주 GO/KILL:** Continuous–discrete 성능 차이가 tiny-object bin에서 일관되게 확대되고, MSE보다 object-conditioned metric이 이를 잘 설명한다면 GO. 차이가 주로 frozen probe나 masking artifact에서만 발생한다면 representation-level 결론은 보류하고 controlled tokenizer comparison으로 전환한다.

### 이번 주 1순위 — DeltaCausal-OVD

**선택 이유는 원인 분석 실험을 가장 먼저 수행할 수 있기 때문**이다. 지난 보고서의 PromptEscape-LT는 *추론 prompt를 바꾸면 성능이 복구되는가*를 물었다. 이번 DeltaCausal-OVD는 질문이 다르다. **실제 fine-tuning으로 변한 weight 중 어느 부분이 novel-class 손실의 필요조건 또는 충분조건에 가까운가**를 개입으로 검증한다.

첫 실험은 동일 detector architecture에서 pretrained/fine-tuned CLIP의 마지막 4~6개 visual block을 대상으로 한다. Proposal과 detection head를 고정한 비교를 먼저 수행하고, 각 block의 VO/MLP delta를 개별 revert/retain한 뒤 LVIS base/novel region score와 최종 AP의 변화를 분리해 측정한다. Random·magnitude-matched intervention을 반드시 포함한다.

**GO 기준:** 여러 seed 또는 독립 class split에서 특정 업데이트의 되돌리기가 random-matched보다 일관되게 novel 성능을 회복시키며, base 손실을 제한할 수 있는 경우. **KILL/PIVOT 기준:** 업데이트의 기능적 효과가 넓게 분산되거나 상호 보상되어 selective reversion이 안정적으로 작동하지 않는 경우.

이 판단은 **첫 2주 내 진단 가능**하며, 실패해도 OVD negative transfer의 분산적 특성·functional redundancy를 설명하는 diagnostic research로 발전시킬 수 있다. 단, 첫 실험에서 상관관계만 얻었다고 곧바로 SCI급 novelty가 확보되는 것은 아니다. 최소한 다중 backbone 또는 독립 dataset, 통제된 weight intervention, base–novel trade-off, seed variation을 갖춰야 논문 기여가 설득력을 얻는다.

**이번 회차의 핵심 연구 질문:** *Fine-tuning은 open-vocabulary 지식을 어디에서 훼손하며, 그 훼손은 기능적으로 되돌릴 수 있는가?*
