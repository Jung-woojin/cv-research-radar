## 1. BatchBench — test-time adaptation의 전체 향상이 희소 화합물 실패를 가린다

**대상:** *BatchBench: Benchmarking AI Robustness to Batch Effects and Domain Shift in Biomedical Images*  
**실패 조건:** 학습에 없던 source·batch·plate의 5-channel Cell Painting image에서 2,000개 compound를 분류할 때  
**모델·데이터·설정:** JUMP-CP-2k, 공개 source 8개 학습·source 2 검증, source 4·6·9·13 private test, ResNet18 기반 no-adaptation·DANN·deepCORAL·AdaBN·TENT·CS-ARM-BN·ARM-BN, 세 seed

### 확인된 사실

- 공개 split과 private test 사이에는 covariate shift와 label shift가 동시에 존재한다. POSCON 비중은 51%→36%, TARGET은 25%→55%, REST는 24%→9%로 변한다.
- REST는 공개 split에서 compound당 평균 약 12개 image, private test에서는 2.20개 image만 가진 long tail이다.
- no-adaptation ResNet18의 overall accuracy는 0.175±0.015였다. ARM-BN은 0.260±0.002로 가장 높았다.
- 그러나 POSCON/TARGET/REST는 ResNet18에서 0.465/0.012/0.002, ARM-BN에서 0.665/0.035/0.004였다.
- 가장 높은 REST 결과도 deepCORAL의 0.007±0.002였으며 chance level 0.0005에 가깝다.
- AdaBN과 TENT는 overall을 0.244와 0.249로 높였지만, 저자들은 이득 대부분이 POSCON에서 왔고 TENT가 TARGET과 REST를 개선하지 못했다고 명시했다.
- DANN은 overall 0.170으로 no-adaptation보다 낮았다.

### 저자 인정·공동체 재현 상태

- **저자 인정:** 현재 방법은 weak phenotype과 few-shot compound를 unseen source에서 식별하는 문제를 해결하지 못했다.
- **공개 재현 범위:** 공개 baseline repository와 containerized `adapt()/predict()` 규약이 제공된다. private test label은 leaderboard가 보유하므로 로컬에서 동일 test score를 독립 계산할 수는 없다.
- **공동체 재현:** 공개 직후라 독립 팀의 재현 보고는 확인되지 않았다.

### 기존 주장과 충돌하는 지점

TTA가 domain gap을 줄인다는 aggregate 주장은 overall과 POSCON에는 맞는다. 그러나 long-tail compound의 실제 개선으로 일반화하면 틀린다. 전체 test의 90% 이상을 POSCON과 TARGET이 차지하므로 overall ranking은 REST 실패에 둔감하다.

### 진단 → 가설 → 최소 실험

- **진단:** plate별 BatchNorm adaptation은 풍부하고 강한 phenotype의 통계에는 맞지만, 희소 class의 구분 경계를 복구하지 못한다.
- **가설:** label-frequency-aware prototype calibration과 source-invariant feature learning을 함께 써야 REST를 개선할 수 있다.
- **최소 실험:** 동일 ResNet18에서 (a) AdaBN, (b) class-balanced prototype calibration, (c) 두 방법 결합을 세 seed로 비교한다. overall, POSCON, TARGET, REST와 macro accuracy를 모두 기록한다.
- **GO:** REST가 0.015 이상이고 TARGET이 기준 대비 하락하지 않으며 세 seed 모두 같은 방향이다.
- **KILL:** overall만 상승하고 REST가 0.01 미만이거나 rare-class calibration이 POSCON/TARGET을 크게 훼손한다.

**평가:** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 2. ProactEgoMem — 실험실 domain에서 놓치고, 잡음을 알림으로 바꾼다

**대상:** *ProactEgoMem: Benchmarking Proactive Memory in Streaming Egocentric Video*  
**실패 조건:** 매초 streaming frame을 보며 사용자의 요청 전에 notification 또는 memory-tool lifecycle을 결정하고, Daily에서 Science domain으로 이동할 때  
**모델·데이터·설정:** Daily 300 clips·QA 1,000개, Science 100 clips·QA 500개, Information Capture·State Tracking·Location Tracking, proprietary·open·video-language·streaming baseline

### 확인된 사실

- 같은 30개 model–task cell의 paired 비교에서 평균 notification recall은 Daily 28.5%에서 Science 15.5%로 하락했다.
- 30개 cell 중 28개에서 recall이 낮아졌고, 높아진 cell은 없었다. notification F1도 5.9%에서 3.9%로 내려갔다.
- best single value도 notification F1 19.0%→10.8%, intervention mIoU 17.2%→10.2%, memory-backed QA 66.5%→57.2%로 하락했다.
- Science에서 intervention output을 전혀 내지 않은 cell이 전체 grid의 3분의 1이었다.
- 반대 극단에서는 30개 cell 중 29개가 notification precision 9.8% 이하였고, 유일한 25.9% precision cell의 recall은 6.1%였다.
- proactive memory는 uniform-sampling no-memory baseline보다 36개 QA cell 중 22개에서 낮았고, State Tracking에서는 12개 중 11개 모델이 하락했다.
- oracle memory는 proactive memory보다 36개 cell 모두에서 높았다. 저자들은 Science의 주 병목을 답변 능력보다 evidence acquisition으로 해석했다.

### 저자 인정·공동체 재현 상태

- **저자 인정:** 현재 모델은 laboratory evidence를 적시에 획득하지 못하며, 겉보기 recall은 over-triggering으로 얻어진다.
- **공개 재현 범위:** project page, code, dataset, leaderboard가 연결돼 있고 공통 1 fps streaming protocol과 JSON tool-call 규약이 공개됐다.
- **공동체 재현:** 독립 재현은 확인되지 않았다. proprietary endpoint와 serving version은 장기적으로 달라질 수 있다.

### 기존 주장과 충돌하는 지점

streaming 또는 proactive용으로 설계된 모델이 실제로 더 안정적인 것은 아니었다. 높은 recall을 유용한 proactivity로 해석하는 관행도 precision과 lifecycle overlap을 함께 보면 성립하지 않는다.

### 진단 → 가설 → 최소 실험

- **진단:** event relevance와 action timing이 분리되지 않아 모델이 silence와 무차별 trigger 사이를 오간다.
- **가설:** false-positive cost를 포함한 calibrated hazard model과 explicit abstention이 notification F1과 intervention overlap을 함께 높인다.
- **최소 실험:** 100개 streaming clip에서 동일 backbone에 (a) threshold trigger, (b) precision-constrained calibration, (c) abstention head를 비교한다. event recall, precision, F1, intervention mIoU, alerts/hour를 기록한다.
- **GO:** precision 30% 이상, recall 25% 이상을 동시에 달성하고 alerts/hour가 사전 설정 예산 이하다.
- **KILL:** recall 향상이 false positive 증가로만 발생하거나 memory-backed QA가 uniform sampling보다 낮다.

**평가:** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 3. Plausible but Unimplantable — 형상 유사도가 물리적 장착 가능성을 보장하지 않는다

**대상:** *Plausible but Unimplantable: A Trustworthiness Audit of Shape Completion Foundation Models for Cranial Defect Reconstruction*  
**실패 조건:** 공개 pretrained shape-completion checkpoint를 cranial defect에 zero-shot 적용하고, no-op 이득과 retained bone 충돌 여부를 함께 검사할 때  
**모델·데이터·설정:** MSN-FM 297M, AdaPoinTr 32M, MGPC 559M; 239 defects(210 synthetic carved, 29 real post-craniectomy); 공통 6,144-point budget; advantage@2mm와 collision-free@1mm

### 확인된 사실

- 239개 전체에서 MSN-FM, AdaPoinTr, MGPC의 median advantage over no-op은 각각 -0.156, -0.036, -0.130이었다.
- 세 모델 모두 implantable count가 0/239였다.
- 210개 synthetic defect에서 no-op보다 나은 사례는 MSN-FM 0, AdaPoinTr 29, MGPC 4였다.
- 29개 real case에서는 MGPC가 median +0.118이고 24/29에서 no-op보다 나았지만, collision-free 조건까지 만족한 implantable output은 여전히 0이었다.
- task-specific volumetric reference는 238/239에서 implantable했지만, 같은 210 synthetic case에서 138개 protocol arm 중 최선을 고른 test-selected upper reference다.
- 총 2,868 model–arm–skull 조합에서도 collision-free output이 없었다.
- 일반적인 coverage만 보면 모델이 완전히 망가진 것처럼 보이지 않았지만, 저자들은 coverage가 새 material을 추가했는지 또는 실제 장착 가능한지 말해주지 못한다고 지적했다.

### 저자 인정·공동체 재현 상태

- **저자 인정:** 공개 checkpoint를 그대로 사용한 세 모델은 임상 사용에 적합하지 않으며, point-cloud output은 implant thickness조차 표현하지 못한다.
- **공개 재현 범위:** source code가 공개돼 있고 protocol dimension sweep과 positive control이 포함됐다. MSN-FM과 MGPC checkpoint는 upstream behavior를 재현했지만 AdaPoinTr는 공개 test split 부재로 weight loading보다 강한 upstream 검증을 하지 못했다.
- **공동체 재현:** 독립 연구팀의 재현은 확인되지 않았다.

### 기존 주장과 충돌하는 지점

foundation-scale 또는 medical pretraining이 task transfer를 보장한다는 기대와 충돌한다. 시각적 완성도와 평균 coverage는 임상 acceptance criterion을 대체하지 못한다. 단, task-specific reference는 test-selected이므로 foundation model과의 수치를 일반적 SOTA 비교로 해석하면 안 된다.

### 진단 → 가설 → 최소 실험

- **진단:** 학습 objective와 representation에 defect boundary, collision, thickness, manufacturability 제약이 없다.
- **가설:** retained-bone signed-distance field와 minimum-thickness constraint를 decoder 또는 post-optimization에 넣어야 implantability가 생긴다.
- **최소 실험:** 공개 30개 case에서 원 checkpoint, collision penalty fine-tuning, constrained post-optimization을 비교한다. advantage@2mm, collision depth, implantable count, surface smoothness를 기록한다.
- **GO:** 30개 중 24개 이상이 collision-free@1mm이면서 median advantage가 양수다.
- **KILL:** collision만 줄고 결손 영역 material recall이 no-op 이하이거나 결과가 watertight implant로 변환되지 않는다.

**평가:** 심각도 5/5 · 재현 신뢰도 5/5 · 연구 아이디어 가치 5/5

## 4. Benchmark Difficulty Measure — 평균 점수가 난이도 공백과 지역적 개선을 놓친다

**대상:** *Your Benchmark Is an Empirical Measure Over Difficulty*  
**실패 조건:** benchmark item의 난이도 분포를 명시하지 않고 aggregate score로 모델 순위와 training progress를 판단할 때  
**모델·데이터·설정:** 7개 domain의 25개 benchmark, item-response theory 기반 difficulty 추정, difficulty-distribution mismatch(DDM), Max Gap, Top-5 Gap Sum

### 확인된 사실

- 25개 benchmark 중 10개가 DDM≥0.10이었다. 이는 empirical difficulty distribution을 동일 크기 uniform reference에 맞추려면 전체 난이도 범위의 평균 10% 이상 이동해야 한다는 뜻이다.
- 25개 중 8개는 Max Gap≥0.10, 9개는 Top-5 Gap Sum≥0.30이었다.
- MATH-500 DDM은 0.164였다. AMC23은 Max Gap 0.217, Top-5 Gap Sum 0.539였다.
- HumanEval처럼 수백 문항이 있는 benchmark도 substantial gap을 보여, coverage gap이 작은 benchmark에만 생기는 문제가 아니었다.
- 저자들의 BenchFill은 benchmark당 세 item만 추가해 Top-3 Gap Sum을 21.09–38.88% 줄였다. 평균 감소는 32.67%로 budget-matched baseline 17.52%보다 컸다.
- 이 결과는 benchmark score가 난이도 중립적 측정값이 아니라 현재 item 분포에 대한 가중 평균이라는 점을 보여준다.

### 저자 인정·공동체 재현 상태

- **저자 주장:** measure mismatch는 leaderboard 결론을 특정 난이도 구간에 편향시키고, coverage gap은 그 구간에서 발생한 실제 training improvement를 감지하지 못하게 한다.
- **저자 인정:** non-uniformity 자체가 잘못은 아니며 target use-case의 난이도 분포와 일치하면 유효하다. uniform reference는 별도 prior가 없을 때의 중립 기준이다.
- **공개 재현 범위:** 공식 code와 BenchFill dataset이 공개됐다. 난이도 추정은 사용 가능한 model response matrix와 IRT 가정에 의존한다.
- **공동체 재현:** 독립 재현은 확인되지 않았다.

### 기존 주장과 충돌하는 지점

한 개 aggregate score가 모델 능력 또는 학습 진전을 안정적으로 대표한다는 가정과 충돌한다. 같은 모델도 target difficulty distribution이 바뀌면 상대 우위가 달라질 수 있다. 이 연구의 25개 benchmark 전체가 CV는 아니므로 수치를 CV benchmark 전체에 직접 일반화할 수는 없다.

### 진단 → 가설 → 최소 실험

- **진단:** 평균 정확도는 item density가 높은 난이도 구간에 과도한 가중치를 주고, 비어 있는 구간의 개선에는 반응하지 않는다.
- **가설:** CV benchmark에서도 fog severity, object scale, occlusion, illumination으로 만든 difficulty axis에 유사한 공백이 존재한다.
- **최소 실험:** 해무 분류·검출 benchmark의 item을 visibility와 target size로 층화하고, 기존 score와 uniform-bin macro score, worst-bin score를 비교한다. 두 checkpoint의 순위가 metric에 따라 바뀌는지 확인한다.
- **GO:** gap 진단이 기존 aggregate에서 보이지 않던 특정 severity 개선을 재현 가능하게 검출한다.
- **KILL:** difficulty estimate가 seed·모델 pool에 따라 크게 흔들리거나 gap-filled item이 원 task semantics를 보존하지 못한다.

**평가:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 오늘의 실패 패턴 3개

1. **평균 향상은 long tail을 숨긴다.** BatchBench의 overall gain은 REST collapse를 복구하지 못했고, benchmark 난이도 분포는 item이 몰린 구간을 과대표현한다.
2. **행동을 많이 하는 것은 더 나은 agent가 아니다.** ProactEgoMem의 높은 recall은 낮은 precision과 과잉 trigger를 동반했다.
3. **표면적 유사도는 사용 가능성이 아니다.** cranial completion의 coverage는 collision-free implantability와 분리됐다.

## 논문 아이디어로 연결 가능한 빈틈

### A. Long-Tail-Aware Test-Time Adaptation for Biomedical Imaging

- source·plate statistics와 class prototype uncertainty를 분리해 adaptation한다.
- overall 외에 TARGET/REST macro objective를 직접 최적화한다.
- **핵심 기여 후보:** label shift 아래에서 abundant control에 끌리지 않는 uncertainty-gated TTA.

### B. Cost-Calibrated Proactive Vision Agent

- trigger를 binary classification이 아니라 false-alert budget이 있는 survival/hazard process로 모델링한다.
- abstention과 lifecycle overlap을 공동 최적화한다.
- **핵심 기여 후보:** alerts/hour 제약을 만족하면서 memory-backed QA를 최대화하는 deployable policy.

### C. Physical Acceptance Layer for 3D Foundation Models

- visual similarity scorer 뒤에 signed-distance collision, minimum thickness, watertightness 검사를 붙인다.
- model output을 통과/거부/repair로 나누는 acceptance contract를 만든다.
- **핵심 기여 후보:** 생성 품질과 실제 제조 가능성을 분리 평가하는 의료 3D benchmark.

### D. Difficulty-Coverage Audit for Maritime CV

- visibility, object size, range, occlusion, camera motion을 난이도 축으로 추정한다.
- aggregate mAP와 difficulty-uniform mAP, worst-bin mAP를 함께 보고한다.
- **핵심 기여 후보:** 새 모델의 향상이 쉬운 맑은 날 표본 증가인지, 어려운 해무 구간의 실제 개선인지 구분하는 평가 규약.

## 출처와 해석 한계

- 네 논문 모두 최근 공개본이므로 장기적인 peer review와 독립 공동체 재현은 아직 없다.
- 수치는 공식 arXiv HTML과 연결된 공식 artifact에서 확인한 저자 보고값이며, 이번 실행에서 모델 학습·추론을 새로 수행하지 않았다.
- BatchBench의 private test는 leaderboard가 보유해 완전한 독립 점수 계산에 제한이 있다.
- ProactEgoMem의 proprietary model endpoint는 향후 version 변화로 정확한 재현이 어려울 수 있다.
- cranial audit의 task-specific reference는 test-selected upper reference이므로 foundation model과의 일반적 우열로 해석하지 않았다.
- benchmark difficulty 결과는 여러 domain을 포함하며, CV·해양 domain으로의 확장은 별도 검증이 필요하다.
