## Q1. VLM 벤치마크의 label-token 계약을 자동 검사하면 보고된 방법 이득의 신뢰구간이 달라지는가?

### 1. Research Question / 문제 정의

VLM의 yes/no, A/B, entailment label을 평가하는 코드가 실제 tokenizer surface form과 일치하는지 자동 검사하고, readout 선택에 따른 점수 범위를 `evaluation sensitivity interval`로 보고할 수 있는가?

### 2. Observation — 왜 지금 가치가 있는가

POPE 재현 연구에서 LLaVA-1.5-7B가 9,000번의 greedy decode 동안 ID 3582(`yes`)와 1217(`no`)를 한 번도 생성하지 않았고, 실제 출력은 공백이 붙은 token이었다. 두-token readout과 여덟-token readout의 adversarial F1 차이는 6.13점이었다. 저자들은 이 차이가 조사한 여섯 방법 중 다섯 방법의 보고 이득보다 크다고 밝혔다.

### 3. Gap과 직접 근거

- **확인된 사실:** 여덟-token readout의 LLaVA-1.5-7B F1은 adversarial 0.8221, popular 0.8498, random 0.8713이었다.
- **확인된 사실:** 다른 tokenizer family의 두 disjoint-vocabulary 모델에 LLaVA token ID를 그대로 쓰면 F1 0.00이 됐고, tokenizer-derived readout은 0.80–0.92였다.
- **저자 인정:** 원 참조는 4-bit NF4였으므로 readout과 precision을 모두 맞추기 전에는 기존 방법 이득을 정확히 재귀속할 수 없다.
- **Gap:** benchmark가 label string, prompt suffix, tokenizer revision, allowed token set을 하나의 versioned contract로 공개하지 않는다.
- 출처: [POPE audit 원문](https://arxiv.org/abs/2610.25964), [공식 코드·prediction record](https://github.com/Kesav2k04/ugaa-research)

### 4. Hypothesis / 핵심 가설

tokenizer-derived label enumeration과 generated-string parsing을 함께 사용하면 copied-ID failure를 제거하고, 작은 decoding-method 이득 중 일부는 통계 불확실성이 아니라 평가 계약 민감도로 재분류된다.

### 5. Experimental Design / 최소 실험

공개 POPE 9,000 prediction record와 logits를 사용해 (a) 고정 2-token, (b) 표면형 8-token, (c) tokenizer 자동 열거, (d) 생성 문자열 normalization 네 readout을 비교한다. NF4와 BF16 결과가 있으면 2×4 교차표로 분리한다.

### 6. Dataset·baseline·ablation

- Dataset: POPE adversarial/popular/random
- Baseline: 저자 2-token·8-token evaluator
- Ablation: prompt suffix, leading space, uppercase/lowercase, tokenizer revision, quantization
- 추가 검증: tokenizer family가 다른 공개 VLM 2개

### 7. Metric과 GO/KILL

F1 범위, prediction disagreement, 방법 순위 Kendall τ, invalid-token coverage를 쓴다. **GO:** 하나 이상의 모델에서 readout만으로 F1이 2점 이상 또는 pairwise 순위가 변하고, 자동 계약 검사가 이를 사전에 탐지한다. **KILL:** 모든 정상 evaluator가 ±0.5점 안에서 일치하고 순위가 유지된다.

### 8. Compute 난이도

**1/5.** 공개 prediction 재채점은 GPU가 필요 없다. 추가 logits 생성도 단일 모델 소규모 subset으로 제한할 수 있다.

### 9. Risk / novelty 위험

단순 bug report로 보일 수 있다. 여러 tokenizer family, multiple-choice label, constrained decoding까지 일반화하고 contract schema를 공개해야 연구 기여가 된다.

### 10. Expected Contribution / 4~8주 가능성

**높음.** evaluator lint 도구, benchmark contract 명세, sensitivity interval을 함께 내면 재현성 short paper 또는 evaluation workshop에 적합하다.

### 11. Negative result의 가치

정상 구현 사이 점수가 안정적이면 POPE 사례가 특정 prompt/tokenizer interaction에 국한됨을 보여주고 자동 감사의 적용 경계를 정할 수 있다.

- **평가:** novelty **4/5** · feasibility **5/5** · compute efficiency **5/5** · publication potential **4/5**

## Q2. Judge가 채점하지 못한 sample을 포함한 coverage-adjusted score는 생성 모델 순위를 바꾸는가?

### 1. Research Question / 문제 정의

evidence-grounded judge가 evidence를 찾지 못해 withheld한 sample과 model이 생성하지 못한 sample을 분모에서 제외하지 않고, coverage와 conditional quality를 함께 추정하면 T2I 모델 순위가 얼마나 바뀌는가?

### 2. Observation — 왜 지금 가치가 있는가

GenOlympiad는 801개 어려운 prompt와 9개 capability axis를 공개했다. judge가 작은 객체나 글자를 grounding하지 못한 task는 0점이 아니라 withheld되어 overall 계산에서 빠진다. context limit으로 생성되지 않은 task도 별도 집계된다.

### 3. Gap과 직접 근거

- **확인된 사실:** official leaderboard의 overall은 scored task의 평균이며 withheld task는 axis와 overall 분모에 포함되지 않는다.
- **확인된 사실:** strict score는 모든 hard question을 통과해야 task 100점을 주며, evidence grounding에는 Gemini 2.5 Flash judge가 항상 필요하다.
- **저자 주장:** grounding helper가 counting·spatial grading을 단순 VLM judge보다 안정화한다.
- **Gap:** conditional score가 높은 이유가 image quality인지, judge가 어려운 output을 더 자주 보류했기 때문인지 분리되지 않는다.
- 출처: [GenOlympiad 원문](https://arxiv.org/abs/2610.26850), [공식 코드·leaderboard](https://github.com/GenOlympiad/GenOlympiad)

### 4. Hypothesis / 핵심 가설

`conditional strict score`, `withheld/not-generated coverage`, `withheld=fail lower bound`를 함께 보고하면 일부 pairwise ordering이 바뀌고, judgeability 자체가 독립적인 모델 특성으로 드러난다.

### 5. Experimental Design / 최소 실험

공개 결과가 있는 모델 중 5개와 capability axis별 100개 task를 사용한다. 기존 점수, withheld=0, inverse-propensity weighting, human-adjudicated subset 네 평가를 비교한다. judge version을 고정하고 withheld 이유를 small object/text/occlusion/invalid output으로 분류한다.

### 6. Dataset·baseline·ablation

- Dataset: GenOlympiad 100-task stratified subset
- Baseline: official conditional strict/relaxed score
- Ablation: denominator rule, judge seed, judge model version, human tie-break
- 비교 제한: coding model과 native T2I는 생성 interface가 달라 `not strictly apples-to-apples`로 별도 표기

### 7. Metric과 GO/KILL

Coverage, lower/upper bound, pairwise rank flip, judge-human agreement, capability별 withheld odds를 본다. **GO:** denominator rule로 pairwise ordering 10% 이상이 바뀌거나 withheld odds가 모델·axis와 유의하게 연결된다. **KILL:** 모든 ordering이 안정적이고 coverage 차이가 2%p 미만이다.

### 8. Compute 난이도

**2/5.** 공개 output 재채점과 100개 human audit가 중심이다. API judge 비용은 있지만 새 모델 학습은 없다.

### 9. Risk / novelty 위험

missing-data 통계의 단순 적용으로 보일 수 있다. withheld mechanism을 시각 속성과 연결하고 재현 가능한 dual-score protocol로 만들어야 한다.

### 10. Expected Contribution / 4~8주 가능성

**높음.** 생성 모델 benchmark의 selective evaluation bias를 직접 다루는 protocol paper로 발전 가능하다.

### 11. Negative result의 가치

순위가 안정적이면 GenOlympiad의 conditional scoring이 실용적으로 견고하다는 근거가 되고, withheld rate는 보조 진단으로만 남길 수 있다.

- **평가:** novelty **4/5** · feasibility **5/5** · compute efficiency **4/5** · publication potential **4/5**

## Q3. 해양 AV-VLM의 실패는 시각 증거 부재인가, 발화 시점과의 조합 실패인가?

### 1. Research Question / 문제 정의

항만·선박 영상에서 VLM이 전체 영상 질문에 틀렸을 때, 관련 객체·행동을 국소 window에서는 인식하지만 VHF/음성 발화 시점과 연결하지 못한 것인지 분리할 수 있는가?

### 2. Observation — 왜 지금 가치가 있는가

SVHalluc에서 네 AV-LLM의 full-video Temporal Forecasting은 29.3–33.7%였지만, 동일 frozen backbone의 audio-free local window evidence를 ASR interval에 맞춰 조합한 TED는 79.3–82.2%였다. 이는 perception이 완전히 사라진 것보다 temporal composition 실패가 큰 경우를 시사한다.

### 3. Gap과 직접 근거

- **확인된 사실:** SVHalluc는 TA 368, TF 276, CMTB 339개이고, TED는 5개 uniform window와 ASR utterance interval을 사용한다.
- **확인된 사실:** TED는 TA/TF 항목당 ASR 외 10번의 local call을 사용하므로 direct와 `not strictly apples-to-apples`다.
- **저자 주장:** locally recoverable evidence와 successful full-video decision은 다르다.
- **Gap:** 해양 safety QA는 영상, radar/AIS, 음성 보고의 시차가 크지만 retrieval과 composition을 분리한 protocol이 없다.
- 출처: [TED 원문](https://arxiv.org/abs/2610.25352), [공식 HTML 실험 설정](https://arxiv.org/html/2610.25352v1)

### 4. Hypothesis / 핵심 가설

항만 위험 이벤트의 오답 중 상당수는 local object/action score가 맞지만 발화 anchor 전후 evidence aggregation이 틀린 `evidence-available/decision-failed` 유형이며, 이 비율은 fog와 long context에서 증가한다.

### 5. Experimental Design / 최소 실험

공개 해양·항만 clip 60개에 synthetic 또는 실제 음성 보고를 붙이고 before/during/after 질문을 만든다. direct full-video, 5-window local verifier, matched-call full-video interval prompt를 비교한다.

### 6. Dataset·baseline·ablation

- Dataset: 해양 clip 60개, clear/fog와 small/large target 균형
- Baseline: uniform frame full-video VLM, ASR-text-only classifier
- Ablation: true/shuffled utterance anchor, target/donor transcript, 5/10 windows, audio on/off

### 7. Metric과 GO/KILL

Direct accuracy, local evidence recall, local-correct/direct-wrong rate, anchor sensitivity, call-normalized accuracy를 사용한다. **GO:** 두 backbone에서 local-correct/direct-wrong이 20% 이상이고 true anchor가 shuffled보다 10%p 이상 높다. **KILL:** matched-call 통제 후 차이가 5%p 미만이거나 text-only가 같은 성능을 낸다.

### 8. Compute 난이도

**3/5.** multi-call AV inference가 필요하지만 60개 clip과 frozen model로 제한한다.

### 9. Risk / novelty 위험

TED의 도메인 적용으로 보일 수 있다. 안개, tiny maritime target, multi-sensor/voice delay가 어떤 failure stage를 바꾸는지 보여야 한다.

### 10. Expected Contribution / 4~8주 가능성

**중상.** 작은 diagnostic benchmark와 stage-wise error taxonomy가 있으면 maritime VLM workshop 논문으로 가능하다.

### 11. Negative result의 가치

local evidence도 회복되지 않으면 병목이 temporal composition이 아니라 해무·작은 객체 perception임을 명확히 하고 연구 자원을 detector/encoder 쪽으로 돌릴 수 있다.

- **평가:** novelty **4/5** · feasibility **4/5** · compute efficiency **3/5** · publication potential **4/5**

## Q4. 파일 중복이 없는 remote-sensing split에도 construction-lineage leakage가 남아 있는가?

### 1. Research Question / 문제 정의

동일 원영상·tile·mask·합성 배경·augmentation seed에서 파생된 표본이 train/test에 나뉘어 들어가는지를 계보 graph로 감사하면 aerial small-object 성능과 방법 순위가 얼마나 달라지는가?

### 2. Observation — 왜 지금 가치가 있는가

image harmonization benchmark는 파일명이 다르고 byte duplicate가 없어도 train과 test가 같은 원본 사진에서 파생된 composite 1,399개를 포함했다. 이는 test의 25%였고 세 방법의 오차는 공유 구간에서 나머지보다 2–5배 낮았다.

### 3. Gap과 직접 근거

- **확인된 사실:** 저자들은 construction identity가 train에 없는 5,581개 composite clean list를 공개했다.
- **저자 인정:** 공유 자체의 인과 효과는 확정되지 않았고 source collection이 강한 교란이다. 같은 collection 내 격차는 약 1.5배였다.
- **Gap:** aerial/remote-sensing dataset은 큰 orthomosaic를 tile로 자르거나 같은 scene에 여러 합성을 적용하므로 file-level disjoint만으로 독립성을 보장하기 어렵다.
- 출처: [Only Means Only 원문](https://arxiv.org/abs/2610.25387), [공식 부속 감사 자료](https://doi.org/10.5281/zenodo.23404530)

### 4. Hypothesis / 핵심 가설

orthomosaic/source-scene 단위 connected component split은 random tile split보다 mAP를 낮추고, 특히 tiny-object recall과 background-heavy method의 순위를 더 크게 바꾼다.

### 5. Experimental Design / 최소 실험

공개 aerial dataset 하나에서 image hash, GPS/scene ID, tile coordinate, augmentation metadata를 graph edge로 묶는다. 동일 checkpoint를 random-file, spatial-disjoint, lineage-disjoint test에 재채점하고 필요하면 소형 detector 두 개만 재학습한다.

### 6. Dataset·baseline·ablation

- Dataset: scene provenance가 있는 UAV/remote-sensing detection dataset 1개
- Baseline: official split과 exact duplicate removal
- Ablation: near-duplicate만 제거, spatial buffer, source-scene component, collection-stratified bootstrap

### 7. Metric과 GO/KILL

mAP50-95, AP_small, scene-level bootstrap CI, rank correlation, leakage edge count를 사용한다. **GO:** lineage-disjoint에서 AP_small이 5%p 이상 감소하거나 detector ordering이 바뀐다. **KILL:** spatial/file/lineage split의 차이가 CI 안에 있고 provenance edge가 거의 없다.

### 8. Compute 난이도

**2/5.** 1차는 기존 checkpoint 재채점이다. 순위 변화가 보일 때만 두 모델을 재학습한다.

### 9. Risk / novelty 위험

data leakage audit가 이미 많은 remote-sensing 연구에 존재한다. construction graph와 synthetic derivative까지 포함하고, collection confound와 sharing effect를 분리해야 한다.

### 10. Expected Contribution / 4~8주 가능성

**높음.** reproducible split generator와 clean manifest를 공개하면 benchmark note로 가치가 크다.

### 11. Negative result의 가치

차이가 없으면 해당 dataset의 split이 construction-level로도 견고하다는 긍정적 증거와 일반 감사 도구를 남긴다.

- **평가:** novelty **3/5** · feasibility **5/5** · compute efficiency **5/5** · publication potential **4/5**

## Q5. Open-vocabulary evaluator가 paraphrase를 살리면서 predicate와 role을 보존할 수 있는가?

### 1. Research Question / 문제 정의

free-text interaction·relation prediction에서 lexical mismatch를 완화하되 잘못된 동작과 subject/object 역할 반전을 보상하지 않는 relation-preserving semantic credit를 설계할 수 있는가?

### 2. Observation — 왜 지금 가치가 있는가

HICO-DET 여섯 시스템을 같은 prediction으로 다섯 scoring view에서 평가했을 때 선두가 바뀌었다. semantic gain은 1.6–20.3 mAP였고, AgentHOI는 strict propositional equivalence를 강제하면 gain의 절반 미만만 유지했다.

### 3. Gap과 직접 근거

- **확인된 사실:** category score는 valid paraphrase를 거절할 수 있고 semantic similarity는 wrong action·reversed role을 받아들일 수 있다.
- **저자 주장:** semantic credit는 relational validity와 paired uncertainty와 함께 보고해야 한다.
- **Gap:** OVD/grounding benchmark도 synonym credit를 주지만 relation과 attribute composition의 truth condition을 별도 보존하지 않는 경우가 많다.
- 출처: [OV-HOI evaluation audit](https://arxiv.org/abs/2610.25849)

### 4. Hypothesis / 핵심 가설

문장을 agent–predicate–patient graph로 파싱한 뒤 node synonym과 edge direction을 분리 채점하면 paraphrase recall은 유지하면서 role/predicate swap false accept를 절반 이하로 줄일 수 있다.

### 5. Experimental Design / 최소 실험

HICO-DET 또는 관계 grounding prediction 300개에 human paraphrase, predicate swap, role swap, attribute swap 변환을 만든다. embedding similarity, LLM judge, graph-constrained judge를 동일 prediction에 적용한다.

### 6. Dataset·baseline·ablation

- Dataset: natural prediction 300개 + controlled transform 1,200개
- Baseline: exact/category match, sentence embedding, generic LLM judge
- Ablation: node synonym only, edge direction only, visual box role evidence, calibrated abstention

### 7. Metric과 GO/KILL

Paraphrase recall, invalid accept rate, macro-F1, model rank stability, paired bootstrap CI를 쓴다. **GO:** paraphrase recall 하락 ≤3%p에서 role/predicate false accept를 50% 이상 줄인다. **KILL:** strictness 증가가 valid paraphrase를 같은 비율로 제거한다.

### 8. Compute 난이도

**1/5.** prediction 재채점과 소규모 human audit가 중심이다.

### 9. Risk / novelty 위험

semantic parsing 기반 metric의 재발견일 수 있다. visual grounding box와 relation role을 함께 써서 CV 특유의 오류를 보여야 한다.

### 10. Expected Contribution / 4~8주 가능성

**높음.** evaluator와 controlled transformation set을 공개하면 OVD/HOI/scene graph 공통 진단 도구가 된다.

### 11. Negative result의 가치

graph constraint가 자연 prediction에서 불안정하면 현재 parser가 open-vocabulary relation을 충분히 구조화하지 못한다는 한계를 정량화한다.

- **평가:** novelty **4/5** · feasibility **5/5** · compute efficiency **5/5** · publication potential **4/5**

## Q6. Aerial small-object detector의 병목은 proposal retrieval인가, fine classification·localization인가?

### 1. Research Question / 문제 정의

작은 항공 객체 검출을 candidate retrieval과 fine discrimination으로 분해했을 때, P2/high-resolution feature의 이득이 candidate recall 증가인지 후보 간 구별 향상인지 규명할 수 있는가?

### 2. Observation — 왜 지금 가치가 있는가

산림 LiDAR place recognition에서 TNVD support key는 valid location을 Top-25에 Venman 98.89%, Karawatha 98.76% 포함했지만 conventional SC matcher의 R@1은 57.20%, 66.47%였다. K=250까지 늘려도 final R@1이 약 40–50%에 머물러 retrieval과 fine matching이 별도 병목임을 보였다.

### 3. Gap과 직접 근거

- **확인된 사실:** 동일 raw-SC candidate에서 terrain normalization은 max-height cell에 +1.21점, vertical distribution에 +19.72점이었다.
- **저자 주장:** candidate recovery와 fine discrimination은 대체할 수 없는 병목이며 representation이 terrain normalization의 효과를 결정한다.
- **Gap:** small-object detection 연구는 AP_small 향상을 P2/high resolution에 귀속하지만, proposal recall과 class confusion/localization quality를 고정 후보에서 분리하는 경우가 드물다.
- 출처: [TNVD-SC 원문](https://arxiv.org/abs/2610.25637), [공식 stage-wise 분석](https://arxiv.org/html/2610.25637v1)

### 4. Hypothesis / 핵심 가설

P2/high-resolution feature의 주된 이득은 작은 객체 proposal recall이 아니라 visually similar background·class 사이의 fine discrimination이며, oracle candidate를 고정하면 classification head·representation 차이가 남는다.

### 5. Experimental Design / 최소 실험

한 aerial dataset에서 baseline FPN과 P2 모델의 proposal을 교차한다. `baseline proposal + P2 ROI/head`, `P2 proposal + baseline ROI/head`, 공통 oracle proposal 세 조건으로 분해한다.

### 6. Dataset·baseline·ablation

- Dataset: VisDrone 또는 DOTA small-object subset
- Baseline: 동일 backbone의 FPN/P2 detector
- Ablation: proposal source, ROI resolution, receptive field, class-agnostic box regression, oracle proposal
- 통제: 같은 input resolution·pretraining·TTA·training schedule

### 7. Metric과 GO/KILL

AR_small@K, AP_small, fixed-candidate classification accuracy, localization IoU, confusion matrix, latency를 사용한다. **GO:** proposal recall을 맞춘 뒤에도 P2 head가 AP_small 또는 classification accuracy를 3%p 이상 높인다. **KILL:** 모든 이득이 AR_small 차이로 설명되거나 input-resolution 통제 후 사라진다.

### 8. Compute 난이도

**3/5.** 두 detector 학습과 proposal/head 교차 inference가 필요하지만 단일 dataset으로 제한 가능하다.

### 9. Risk / novelty 위험

detector component ablation으로 보일 수 있다. effective receptive field와 visually similar class confusion을 연결하고 oracle ceiling을 제시해야 한다.

### 10. Expected Contribution / 4~8주 가능성

**중상.** P2가 언제 필요한지를 병목별로 설명하면 architecture paper보다 작은 진단 논문으로 설득력이 있다.

### 11. Negative result의 가치

이득이 전부 proposal recall이면 복잡한 fine matcher보다 candidate generation과 resolution policy에 집중해야 한다는 명확한 설계 결론을 얻는다.

- **평가:** novelty **4/5** · feasibility **4/5** · compute efficiency **3/5** · publication potential **4/5**
