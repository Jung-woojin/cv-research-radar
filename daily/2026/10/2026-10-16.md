# CV / DL Research Briefing — 2026-10-16

- 오늘은 **agent가 더 많이 보는 능력**보다, 본 근거를 올바른 객체·사건·상태에 결합하는 능력이 핵심으로 떠올랐다.
- Open-o3-Video-v2는 active evidence acquisition을 도입했지만 오류의 대부분은 여전히 근거 선택과 미세 지각에 남는다.
- Urbex는 원거리 landmark와 같은 클래스 밀집 구간에서 city-scale grounding이 단계적으로 무너짐을 보였다.
- FramePack-U는 constant memory를 달성해도 작은 VLM에서 추가 frame이 distraction이 될 수 있음을 인정한다.
- AReA는 CLIP·Aesthetic가 전역 layout 붕괴를 놓칠 수 있다는 평가기 문제를 드러낸다.
- X-Ragent와 EventLens는 routing·temporal supervision의 평균 이득보다 applicability와 반복 사건의 경계조건이 중요함을 보여 준다.
- 수치는 공식 저자 보고이며 이번 backfill이 독립 재현한 결과가 아니다.

## 조사 범위

- **기준:** 2026-10-16 KST. 2026-10-13까지 제출된 신규 원문과 그날까지 공개된 프로젝트·코드를 사용했다.
- **후보/선정:** 15건을 검토해 12건을 선정했다. 신규 7건과 이전 72시간의 비교 기준선 5건을 함께 봤다.
- **증거 규칙:** 같은 backbone·frame/tool budget·split·evaluator가 아니면 직접 우열을 주장하지 않았다.

## 1) 오늘의 전체 DL 트렌드 5줄

1. agentic perception은 retrieval→association→state update로 분해해야 한다.
2. 더 많은 frame·view·tool은 base model의 통합 능력을 넘으면 잡음이 된다.
3. 전역 구조 붕괴는 CLIP·Aesthetic 같은 평균 perceptual metric에 숨을 수 있다.
4. tool applicability와 utility를 하나의 policy score로 합치면 누락과 과호출이 동시에 생긴다.
5. efficiency는 student stage나 peak memory만이 아니라 teacher·decode·tool 비용을 모두 포함해야 한다.

## 2) CV / DL-CV 핵심 논문 6개

### 2.1 AReA: Adaptive Receptive-Field Attention for Efficient High-Resolution Diffusion Transformers

- **상태:** 2026-10-13 v1, 오늘 신규. global-to-local receptive-field schedule로 4K diffusion의 효율과 구조를 조절한다.
- **저자 인정:** fixed window 64는 영역 간 불일치로 unusable한 결과를 만들었지만 Aesthetic·CLIP 점수는 높을 수 있었다. fixed pooling factor는 subject fusion 또는 duplication을 만들었다.
- **해석:** method gain뿐 아니라 metric blind spot이 contribution이다. object count와 relation graph 오류를 human usable label과 비교해야 한다.
- **실험 연결:** 30 prompt×4 schedule에서 기존 metric과 count/relation audit의 AUROC를 비교한다.
- [논문](https://arxiv.org/abs/2610.17227) · [코드](https://github.com/KooroshRH/AReA)

### 2.2 Urbex: Agentic Spatial Grounding for City-Scale 3D Scenes

- **상태:** 2026-10-13 v1, 오늘 신규. landmark query, zoom, oblique view를 사용해 도시 규모 3D grounding을 수행한다.
- **저자 결과:** 200m 이상 landmark에서 regional success가 10.0~22.5%로 낮아지고, 같은 클래스 distractor 10개 이상에서 local success가 0.0~25.1%까지 하락했다.
- **주의:** bin 간 query composition이 다르다. distance-aware crop과 distractor-aware extra-view gate를 각각 검증해야 한다.
- **실험 연결:** 거리×distractor bin별 30 query에서 regional/local success, IoU, tool call을 기록한다.
- [논문](https://arxiv.org/abs/2610.18356) · [코드](https://github.com/AMAP-ML/Urbex)

### 2.3 X-Ragent

- **상태:** 2026-10-13 v1, 의료 VLM tool routing 연구.
- **저자 결과:** ChestAgentBench에서 learned routing 71.7, all-tool 71.0. independent validity gate는 ChestAgent/CheXbench 71.7/77.3으로 policy+gate 71.0/76.1보다 높았다.
- **주의:** 코드·checkpoint와 seed variance를 확인하지 못했다. 작은 차이를 일반적 우월성으로 확대하지 않는다.
- **실험 연결:** deterministic applicability와 learned value-of-information을 분리한 two-gate routing을 100문항에서 시험한다.
- [논문](https://arxiv.org/abs/2610.16811)

### 2.4 VEDJE: Video-Efficient Discriminative Joint Encoder

- **상태:** 최근 공개, 공식 저장소 확인. scalable video-text retrieval을 목표로 한다.
- **기여:** 영상·텍스트의 discriminative joint encoding으로 retrieval throughput과 accuracy의 균형을 다룬다.
- **주의:** clip 수, video duration, negative pool, backbone이 다른 결과는 직접 비교할 수 없다. end-to-end decode 포함 latency가 필요하다.
- **실험 연결:** 같은 후보 video pool에서 8/16/32 frame과 hard-negative 수를 고정해 Recall@K, latency, VRAM을 측정한다.
- [논문](https://arxiv.org/abs/2610.11850) · [코드](https://github.com/GabrieleSerussi/vedje)

### 2.5 RoboFake — 전날 신호의 안전성 기준선

- physical robot을 거의 모두 fake로 보는 detector와 7% 미만만 flag하는 detector가 동시에 존재한다. codec에 따라 score ordering도 흔들린다.
- 오늘 신규 모델과 비교할 때 binary accuracy보다 material/type factorization과 codec worst-group이 더 적합한 기준선이다.
- [논문](https://arxiv.org/abs/2610.14269)

### 2.6 GeoFix — reward metric 기준선

- FOV overlap이 cross-view depth agreement를 높여 작은 camera motion을 잘못 보상할 수 있음을 보정한다.
- AReA의 perceptual metric blind spot과 함께 보면, 생성 모델 평가는 counterfactual input perturbation을 기본 절차로 삼아야 한다.
- [논문](https://arxiv.org/abs/2610.14293)

## 3) VLM / Multimodal / Video 핵심 논문 4개

### 3.1 Open-o3-Video-v2

- **상태:** 2026-10-13 v1, code/model 공개. agent가 필요한 frame·crop을 추가 요청하고 timestamp·box를 reasoning trace에 쓴다.
- **저자 결과:** 4B 모델은 V-STaR mAM 40.4%, mLGM 56.3%로 Qwen3-VL-4B 대비 +8.5/+12.6점이다.
- **저자 failure analysis:** 시간 근거 회수·사건 선택 약 43%, object grounding·미세 지각 27%, 지식 약 6%가 오답 원인이다.
- **주의:** 더 많은 관찰과 RL data가 함께 바뀌므로 순수 tool effect가 아니다. cited evidence necessity를 지우는 counterfactual가 필요하다.
- [논문](https://arxiv.org/abs/2610.17656) · [코드](https://github.com/Multimedia-Semantic-Analytics-Lab/Open-o3-Video-v2)

### 3.2 FramePack-U

- **상태:** 2026-10-12 v1. relevance·diversity 기반 frame packing과 해상도 배분으로 constant memory를 목표로 한다.
- **저자 인정:** 작은 Qwen 모델에서 frame 수를 늘리면 LongVideoBench가 좋아져도 MLVU/Video-MME는 하락할 수 있다.
- **주의:** 3,600초 후보 decode와 224-frame vanilla는 wall-clock 비교가 공정하지 않다.
- **실험 연결:** model size별 32/64/128/256 frame saturation curve와 attention entropy를 측정한다.
- [논문](https://arxiv.org/abs/2610.16118) · [코드](https://github.com/ZelD0n/framepack-U)

### 3.3 EventLens

- **상태:** 2026-10-12 v1. event structure RL과 teacher/student post-training으로 temporal understanding을 강화한다.
- **저자 인정:** 점진적 경계, 반복 행동, long-range narrative는 남은 실패다. broad Video QA 변화는 작고 비단조적이다.
- **주의:** `1/3 training time`은 student stage만 측정한다. teacher 학습·query 비용을 포함해야 한다.
- **실험 연결:** 반복 행동 50개와 control 50개에서 event ID와 entity-state ledger를 비교한다.
- [논문](https://arxiv.org/abs/2610.16172) · [프로젝트](https://lostgreen.github.io/EventLens/)

### 3.4 Video-Arena — 상태 추적 기준선

- native와 tool-assisted protocol을 나누고 event perception, update interpretation, resulting-state tracking을 측정한다.
- Open-o3-Video-v2의 active retrieval 이득을 해석할 때, retrieval이 좋아져도 state tracking이 남는다는 기준선으로 유용하다.
- [논문](https://arxiv.org/abs/2610.14158)

## 4) Training / Inference / System 변화 2개

### 4.1 Applicability–utility 분리 routing

- X-Ragent ablation은 cheap·valid measurement를 policy 선택에 맡기기보다 독립 validity gate로 공급하는 편이 나을 수 있음을 보여 준다.
- 시스템 관점의 KPI는 accuracy뿐 아니라 missing-valid rate, irrelevant-call rate, calls/question, latency다.

### 4.2 End-to-end video compute accounting

- FramePack-U의 decode 비용과 EventLens의 teacher 비용은 headline 효율 수치 밖에 남는다.
- 공정한 비교는 data preparation, teacher generation, decode, inference, tool call을 합친 capability-gain-per-GPU-hour로 해야 한다.

## 6) 오늘의 연구적으로 중요한 Finding 3개

1. **근거를 찾는 것과 근거를 쓰는 것은 다르다.** Open-o3와 Urbex 모두 retrieval 이후 association·commit 단계에서 큰 오류가 남는다.
2. **모델 용량이 input budget의 상한을 정한다.** frame/view/tool을 늘리는 정책은 capacity-aware gate가 필요하다.
3. **평가기와 비용 경계가 결론을 바꾼다.** layout-blind metric과 decode/teacher-excluded efficiency는 방법 순위를 뒤집을 수 있다.

## 7) 과대평가 가능성 / 주의해서 볼 논문

- **FramePack-U:** constant memory를 end-to-end speedup으로 읽지 않는다. 후보 decode 수가 다르다.
- **EventLens:** student-stage 1/3 training time을 전체 post-training 비용으로 읽지 않는다.

## 8) 오늘 바로 읽을 논문 Top 3

1. **Open-o3-Video-v2** — evidence acquisition과 grounded trace를 함께 공개한다.
2. **Urbex** — active 3D grounding의 실패를 거리와 distractor density로 분해한다.
3. **AReA** — receptive-field schedule과 metric blind spot을 한 실험에서 보여 준다.

## 9) Top 1 미니 리뷰 — Open-o3-Video-v2

이 논문의 실제 contribution은 video agent에게 crop tool을 붙인 사실보다, 도구 호출 전후의 accumulated evidence를 RL reward에 넣은 데 있다. 단순히 더 많은 frame을 보는 정책은 반복 retrieval을 만들 수 있는데, CS-GRPO는 clue coverage와 step-wise gain을 보상하고 불필요한 호출을 벌점화한다. 4B 모델의 V-STaR mAM/mLGM 개선은 answer와 localization이 함께 움직일 수 있음을 보여 준다.

그러나 verifiable trace가 causal evidence라는 뜻은 아니다. 모델이 이미 답을 정한 뒤 그럴듯한 timestamp와 box를 붙일 수 있다. 저자 failure analysis에서도 약 70%가 근거 선택과 미세 지각에 남는다. 따라서 같은 정답을 유지하면서 cited crop만 지우거나 다른 crop으로 교체하는 necessity test가 필요하다.

해양 안전 VQA에는 적은 비용으로 옮길 수 있다. 30개 질의에 대해 전체 영상, cited evidence only, cited evidence removed 세 조건을 만들고 answer accuracy, grounding IoU, necessity gap, tool calls를 기록한다. cited evidence를 지워도 정답이 유지되면 그 trace는 설명 가능성보다 사후 합리화에 가깝다.

## 10) 후속 연구 씨앗

1. **Proof-of-Vision:** cited evidence 제거·교체로 answer necessity를 평가한다. 최소 30문항, answer delta와 grounding IoU를 본다.
2. **Belief-calibrated active grounding:** same-class density와 posterior entropy가 높을 때만 추가 view를 요청한다. Hit@1, abstention, tool calls로 평가한다.
3. **PhaseERF for tiny objects:** global→local receptive-field schedule을 detection neck에 이식하고 APs, boundary error, latency를 비교한다.
4. **Capacity-aware frame router:** attention entropy와 answer margin으로 다음 frame 추가 여부를 결정한다. accuracy 손실 1점 이내, latency 20% 절감을 GO 기준으로 둔다.

## 11) 오늘 안 읽어도 되는 것

- artifact가 없고 headline metric만 제공하는 video agent 논문은 보류했다.
- 더 큰 backbone·더 많은 frame·더 많은 tool을 동시에 바꾼 평균점수 비교는 오늘의 핵심 읽기에서 제외했다.
- VEDJE는 실용적이지만 오늘의 evidence/state 진단보다 우선순위가 낮아 quick scan 대상으로 두었다.

## 오늘의 실행 제안

- **30분:** 해양 VQA 30개에서 cited evidence timestamp·box를 수동 표기한다.
- **2시간:** full / evidence-only / evidence-removed 세 inference condition을 만든다.
- **반나절:** answer necessity gap, IoU, tool call, latency를 측정한다.
- **중단 기준:** evidence 제거가 정답률을 3점 미만만 낮추면 agent trace를 신뢰하지 않고 evidence objective를 재설계한다.
