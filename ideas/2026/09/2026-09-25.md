# 후보 1. Query-Conditioned Spatial Resolution Routing for Oriented Open-Vocabulary Aerial Grounding

## 문제 정의
Remote-sensing grounding은 object가 작고 회전돼 있으며, 한 이미지 안에 크기 분포가 매우 넓다. 동시에 Pro-Bench는 같은 target을 가리키는 prompt라도 wording에 따라 target recovery가 크게 흔들릴 수 있음을 보였다. 현재 대부분의 방법은 언어가 무엇을 요구하든 동일한 FPN level/해상도/token budget을 사용한다.

핵심 질문: **질의가 요구하는 object scale·geometry·relation에 따라 high-resolution spatial capacity를 조건부로 쓰면, fixed P2/고해상도보다 같은 계산량에서 더 robust한 grounding이 가능한가?**

## 기존 연구의 빈틈
- O²-VG는 oriented grounding을 정식화하지만 spatial compute를 query에 따라 동적으로 배분하는 것이 중심은 아니다.
- Pro-Bench는 prompt robustness 문제를 보여주지만 architecture-level remedy를 제시하지 않는다.
- SatOV는 spatial prior restoration의 중요성을 보여주지만 language query가 필요한 spatial scale을 선택하도록 만들지는 않는다.
- HDMamba-YOLO는 local/global 역할 분업을 보여주지만 closed-set detector이고 query-conditioned routing이 아니다.

## 핵심 가설
- H1: 질의 embedding에는 target의 예상 scale, relation complexity, orientation sensitivity와 연관된 정보가 있다.
- H2: fixed P2 또는 full-resolution 처리보다 query-conditioned routing이 같은 FLOPs에서 small-object oriented grounding recall을 높인다.
- H3: 동일 referent paraphrase 간 consistency를 걸면 prompt-induced target flip을 줄일 수 있다.

## 제안 방법
가칭 **ScaleGround**.
- Global Semantic Encoder: CLIP/DINO 계열 또는 기존 OVG image encoder.
- Query Encoder.
- Scale-Geometry Router: query + global image context를 받아 P2/P3/P4 또는 high-resolution tile별 budget score 출력.
- Local Spatial Restorer: 선택된 level/region에만 lightweight CNN/local operator 적용.
- Oriented Proposal Bank: OBB proposal을 text-independent하게 생성하고 embedding을 cache.
- Query-Proposal Matcher.
- Prompt Consistency Regularizer: 동일 referent paraphrase 간 proposal ranking과 routing distribution을 정렬.

핵심은 semantic backbone을 더 크게 만드는 것이 아니라 **어떤 공간 정보에 계산을 쓸지 언어가 결정**하게 만드는 것이다.

## Baseline
- O²-VG-Trans / O²-VG-Uni / O²-VG-VLM
- Grounding DINO류 + rotated proposal head
- fixed P3
- fixed P2+P3
- always-high-resolution
- SAHI/fixed tiling
- image-only adaptive routing
- query-only routing
- query+image routing
- GT area 기반 oracle scale routing

## 데이터셋 / 지표
Primary: DIOR-R-RSVG.  
Secondary: Pro-Bench(prompt robustness), DOTA/VisDrone(auxiliary detector ablation).

Metrics:
- oriented IoU / Precision@0.5
- Recall@IoU thresholds
- small/tiny target recall
- Prompt Target Recovery Consistency
- paraphrase-induced target flip rate
- routed pixel/token ratio
- FLOPs / latency / memory
- accuracy-vs-compute Pareto

## 필수 ablation
P2/P3/P4 routing, query-only/image-only/query+image, hard top-k/soft routing, local restorer 종류, consistency loss, oriented proposal cache, paraphrase 수, object-size/query-type별 효과, fixed compute 비교, oracle routing gap.

## 실패 모드 / negative result
Query가 scale을 못 예측하고 category prior만 학습할 수 있다. Image-only router가 동일하게 잘할 수 있다. Always-P2가 compute-matched setting에서도 더 강할 수 있다. OBB proposal recall이 bottleneck일 수 있다. 이 경우 “prompt robustness의 주 bottleneck은 spatial resolution이 아니라 proposal semantics”라는 진단 결과가 남는다.

## Novelty 방어
“OVG + P2 + router”가 아니라:
1. language query가 spatial budget requirement를 예측하는가?
2. fixed compute에서 conditional resolution이 prompt robustness를 높이는가?
3. paraphrase-invariant routing이 target consistency를 개선하는가?
를 논문의 중심 질문으로 둔다.

## 4~8주 MVP
Week 1 DIOR-R-RSVG baseline 및 rotated proposal pipeline.  
Week 2 paraphrase set 구축 + fixed P3/P2/high-res sensitivity.  
Week 3 GT area oracle router.  
Week 4 query-only scale gate.  
Week 5 query+image router + local restorer.  
Week 6 consistency regularization.  
Week 7 Pro-Bench + efficiency.  
Week 8 ablation/paper.

가장 빠른 GO/KILL은 oracle scale routing. 동일 compute budget에서 fixed high-resolution보다 Pareto gain이 없으면 learned router 개발 전에 중단.

## 예상 contribution
1. Oriented OVG를 query-conditioned spatial compute allocation으로 재정식화.
2. Prompt semantics로 multi-scale/high-resolution budget을 라우팅하는 Scale-Geometry Router.
3. Accuracy + prompt consistency + compute를 함께 평가하는 protocol.

## 예상 제목

# 후보 2. Actionable Confusion Provenance for Open-Vocabulary Fine-Grained Aerial Detection

## 문제 정의
Fine-grained aircraft/ship OVD에서 같은 off-diagonal confusion이라도 원인은 다를 수 있다: visual affinity, semantic affinity, prompt instability, epistemic boundary uncertainty, within-class heterogeneity. 최근 A²E²가 closed-set fine-grained aircraft detection에서 source-aware diagnosis의 필요성을 보였으므로, 다음 단계는 visual-language provenance를 분해하고 **진단이 실제 remedy 선택을 예측하는지** 검증하는 것이다.

## 기존 빈틈
A²E²는 closed-set 중심, OVD negative transfer는 대개 aggregate base/novel gap을 보고, prompt robustness는 wording sensitivity만 본다. 이들을 pair-level treatment specificity로 연결하는 연구가 비어 있다.

## 핵심 가설
각 confusion pair는 visual/semantic/prompt/epistemic source의 서로 다른 mixture를 가지며, matched intervention이 generic intervention보다 효율적이다.

## 방법
가칭 **Confounder-OVD**. Class pair별 provenance vector:
- Visual Affinity: OBB geometry + high-res visual embedding overlap
- Semantic Affinity: text embedding + ontology distance
- Prompt Instability: paraphrase/template prediction variance
- Epistemic Boundary: ensemble/Laplace/MC-dropout disagreement
- Data Collapse: exposure + within-class spread

Intervention:
- prompt canonicalization / description disambiguation
- targeted hard-negative or boundary data
- class-balanced data
- high-res crop/routing
- abstention for irreducible affinity

## Baseline
Closed-set Oriented R-CNN, YOLO-World/Grounding-DINO 계열, prompt ensemble, class-balanced sampling, hard-negative mining, generic P2/high-res, visual-only diagnosis, oracle intervention.

## Dataset / metric
Gaofen fine-grained aircraft 또는 접근 가능한 동급 dataset, FAIR1M/MAR20 aircraft subset, DIOR 계열, LVIS/ODinW similar-class subset.

Metrics: pair AP/F1, confusion error, base/novel gap, prompt variance, ECE/NLL, matched-treatment gain, gain/sample 또는 gain/FLOP.

## Ablation
visual-only/text-only/full, prompt set size, text encoder, geometry, ensemble size, OBB/HBB, closed/open-vocab, matched/mismatched treatment, source thresholds.

## 실패 모드
Visual/semantic affinity가 분리되지 않을 수 있고 prompt instability가 실제 error를 예측하지 못할 수 있다. Last-layer uncertainty가 충분하지 않을 수 있다. 이 경우 source entanglement 자체가 결과다.

## Novelty 방어
A²E² port가 아니라 visual+language+prompt provenance를 동시에 분해하고 **진단-specific treatment를 causal intervention으로 검증**해야 한다.

## 4~8주 MVP
Week1 OVD aerial baseline/confusion pairs; Week2 visual/semantic/prompt score; Week3 epistemic score; Week4 three interventions; Week5 matched-vs-mismatched matrix; Week6 second model/dataset; Week7-8 calibration/paper.

## Contribution
1. Multimodal confusion provenance decomposition.
2. Diagnosis-conditioned treatment-specific evaluation.
3. Reducible/irreducible OVD negative transfer 분석.

## 제목
- Diagnose Before You Adapt: Actionable Confusion Provenance for Open-Vocabulary Aerial Detection
- Why Did the Detector Confuse Them?
- From Confusion to Treatment: Multimodal Error Provenance in Aerial OVD

## Abstract 개요
OVD fine-grained confusion을 visual ambiguity, semantic aliasing, prompt instability, epistemic boundary uncertainty의 provenance로 분해하고, source-aware targeted intervention의 효율성을 검증한다.

## Introduction
OVD vocabulary 확장 → fine-grained confusion 지속 → confusion matrix는 원인을 설명하지 못함 → uncertainty diagnosis와 prompt robustness 연구가 일부 원인을 따로 다룸 → provenance와 treatment를 연결.

## Related Work

## Method
Pair-level confusion graph; visual affinity; semantic/prompt affinity; epistemic uncertainty; provenance vector; diagnosis-conditioned interventions; intervention validation.

## Experiment

# 후보 3. Grounding-Calibrated Mixed Precision for Vision-Language Models

## 문제 정의
GHOST-Q는 quantization 후 aggregate score가 유지돼도 grounding/hallucination behavior가 바뀔 수 있음을 보였고, Alignment Illusion은 일반 alignment metric이 actual content usage를 제대로 반영하지 못할 수 있음을 보였다. 따라서 precision allocation을 weight magnitude가 아니라 실제 grounding sensitivity에 연결한다.

## 기존 빈틈
Uniform INT8/NF4는 module importance를 무시하고, AWQ/GPTQ류는 주로 language/perplexity 또는 activation statistics를 최적화한다. Same-score grounding drift를 bit allocation 자체에 연결하는 연구 공간이 있다.

## 핵심 가설
Controlled visual perturbation 및 module-wise quantization에 의해 grounding output이 크게 흔들리는 module은 high precision을 유지해야 하며, 이 sensitivity로 bit를 배분하면 같은 memory budget에서 grounding stability가 개선된다.

## 방법
가칭 **GCMP**.
1. Grounding calibration set.
2. Vision encoder/projector/LM block 단위 temporary quantization.
3. Grounding Sensitivity Score: IoU drop + target flip + PA-gap change.
4. Memory/latency budget 하 FP16/INT8/INT4 allocation.
5. 선택적으로 sensitive block에만 tiny calibration.

## Baseline
FP16/BF16, uniform INT8/NF4, bitsandbytes, AWQ/GPTQ, activation-outlier mixed precision, Hessian/sensitivity allocation, random matched budget, PA-gap-only, grounding-only.

## Dataset / metric
RefCOCO/+/g, DIOR-R-RSVG, MMStar, AMBER, Pro-Bench.

Metrics: accuracy, grounding IoU/P@0.5, Grounding Flip Rate, prompt consistency, hallucination score, VRAM, model size, latency, throughput, PA-gap correlation.

## Ablation
PA-gap vs CKA/SVCCA/MIR, vision/projector/LM block, calibration size, precision choices, layer/block granularity, utility vs grounding objective, cross-dataset/model transfer.

## 실패 모드
PA-gap이 quantization error를 못 예측할 수 있다. Model별 sensitive layer가 다를 수 있다. VRAM은 줄어도 latency가 안 줄 수 있다. Calibration overfit 가능.

## Novelty 방어
“또 하나의 quantization”이 아니라 same-score grounding drift + mechanistic sensitivity + grounding-aware bit allocation + real deployment Pareto를 중심에 둔다.

## MVP
Week1 FP16/INT8/NF4 audit; Week2 paired grounding; Week3 block-wise sweep; Week4 sensitivity + greedy allocation; Week5 second model; Week6 aerial transfer; Week7 profiling; Week8 ablation/paper.

## Contribution
1. Quantized VLM same-score grounding drift의 module-level diagnosis.
2. Grounding-sensitive mixed precision.
3. Accuracy-grounding-memory-latency joint evaluation.

## 제목
- Same Score, Different Grounding: Grounding-Calibrated Mixed Precision for VLMs
- Quantize What Vision Can Afford to Lose
- GCMP: Grounding-Aware Precision Allocation for Efficient Vision-Language Models

## Abstract / Introduction / Related Work / Method / Experiment
Abstract는 quantization utility preservation과 grounding preservation의 불일치를 문제로 제시하고 GCMP를 해결책으로 둔다. Introduction은 edge deployment → same-score drift → alignment metric 한계 → behavior-grounded bit allocation 순서. Related Work는 VLM quantization, mixed precision, grounding/hallucination, multimodal alignment diagnostics, edge VLM. Method는 drift definition, controlled precision perturbation, sensitivity score, PA-gap diagnostic, budgeted allocation. Experiment는 precision baseline, cross-model transfer, latency/VRAM, diagnostic correlation, grounding-memory Pareto를 표/그림으로 구성.

# 이번 주 최우선 추천

**Query-Conditioned Spatial Resolution Routing for Oriented Open-Vocabulary Aerial Grounding**

이유:
- O²-VG가 oriented grounding problem/dataset을 만들었다.
- Pro-Bench가 prompt wording에 따른 target recovery 불안정을 보여줬다.
- SatOV는 spatial prior/detail 손실을 병목으로 제시한다.
- HDMamba-YOLO는 local detail과 global context의 역할 분업을 뒷받침한다.

따라서 자연스러운 다음 질문은 **“질의가 요구하는 공간 해상도를 질의 자체가 선택하게 할 수 있는가?”**다.

가장 큰 장점은 1~3주 안에 죽일 수 있다는 점이다. Learned router보다 먼저 GT object size 기반 oracle routing을 돌려 fixed P2/high-resolution baseline 대비 accuracy-compute Pareto와 paraphrase consistency가 실제로 개선되는지 본다. Gap이 없으면 접고, gap이 크면 learned query router를 만들 명확한 이유와 upper bound가 생긴다.

권장 첫 실험:
1. DIOR-R-RSVG baseline.
2. 각 expression에 의미 보존 paraphrase 2~3개.
3. P3-only / always-P2 / fixed tiling / GT-area oracle routing.
4. oriented IoU, small-target recall, prompt target-recovery consistency, FLOPs.
5. Oracle routing이 Pareto frontier를 움직일 때만 learned router 진행.

**이번 주 핵심 질문: Can language decide how much spatial resolution vision should spend?**
