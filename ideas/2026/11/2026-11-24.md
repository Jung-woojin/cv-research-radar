## 1. 조사 범위와 근거의 수준

기준일은 Asia/Seoul 2026-11-24, 조사 창은 11/17~11/24 실행 시점이다. arXiv submission history의 날짜는 UTC로 표기한다. 검색엔진의 수집일을 발표일로 사용하지 않았다. 검색으로 후보를 찾은 뒤 arXiv 공식 abstract·version별 HTML과 저자 GitHub·Hugging Face를 대조했다.

후보 9편을 1차 검토하고 아래 5편을 선택했다. 이전 회차의 TinyWOD·SemGeo는 반복을 피했다. ABSClaw와 정보작전 탐지 연구는 이번 CV 진단 질문과 거리가 있어 제외했다. 제외 후보는 정밀 검토를 완료한 핵심 논문 수에 포함하지 않는다. 11/20 이후 신규 CV 논문을 찾는 검색도 수행했으나 이번 선택은 원문 검증과 구체적인 후속 실험 설계가 가능한 자료에 한정했다.

최근 원격 11/17·11/19 보고서의 전체 본문을 읽었다. Acquire-or-Read, Transition-Lag, Independent-Witness, Evidence Survival, Geometric Stage Boundary, Same Pixels Different Water를 그대로 재제안하지 않는다. 이번 A는 측정 지표의 타당성, B는 선택 교정의 조건별 전이 경계, C는 반사실적 참조의 오염을 연구 대상으로 삼는다.

**확인 사실**은 공개 이력·본문·배포 페이지에 실제로 있는 내용이다. **저자 주장**은 그 자료의 성능·메커니즘 해석으로 독립 검증되지 않았다. **제안·추론**은 아래 레이더의 가설과 실험 계획이다. 인과적 설명은 통제 개입과 대조 실험을 통과하기 전까지 확정하지 않는다.

논문 간 점수는 backbone, pretraining, 데이터, 입력 해상도, split, 예산이 달라 **not strictly apples-to-apples**다. SOTA 순위를 합성하지 않는다. 아래 실험에서는 동일 checkpoint·입력·평가 코드와 source 단위 분할을 고정한다.

- **공개 이력:** v1 2026-11-17. 이번 확인에서 후속 revision은 보이지 않았다.
- **문제·방법:** 인간의 시선 전체를 복제하는 대신 공간 탐색을 위한 유연한 prior로 사용해 grounded reasoning을 학습한다.
- **저자 결과:** chart 이해·탐색·counting에서 전체 시선 sequence 감독보다 prior 방식이 유리하며, gaze alignment와 grounding을 개선한다고 보고한다.

- **연결:** A에서 동일 계열 모델의 정렬 점수와 개입 반응을 분리한다.

## 3. Proposal A — Evidence Metric Validity

1. **문제·가치:** 답을 맞히고 올바른 위치도 가리켰는데, 그 위치의 정보가 답변에 필요하지 않을 수 있다. P1의 정렬과 P2의 hit 지표를 동일한 개입 타당성 관점에서 검증한다.
2. **Gap:** P2가 hit의 불충분함을 이미 인정한다. 새 기여는 그 지적이 아니라, 공간 정렬 점수로 개입 민감도를 예측할 수 있는 조건과 실패 유형의 계량화다.
3. **가설:** 같은 정답률·질문 유형에서 정렬 점수가 높은 표본도 evidence masking과 비증거 masking의 반응 차이가 작을 수 있다. 반대로 낮은 정렬이 반드시 증거 미사용을 뜻하지 않을 수 있다.
4. **구조:** 고정 모델 → 원본 답·point trace → 독립 검수한 증거 영역 → 면적·위치 대조 개입 → 답 변화와 정렬 지표의 대응 분석. 초기에는 새 학습 모듈을 추가하지 않는다.
5. **Baseline:** GGR-SFT와 No-Gaze-SFT, 가능하면 RL pair; random/중앙/면적 일치 mask; 정렬 점수만 사용하는 예측과 질문 유형을 통제한 예측.
6. **데이터·지표:** GGR held-out 중 chart·counting·search. image hash와 원출처로 분리한다. 정답률, evidence 대 control의 정확도 감소 차이, 정답 문자열 변화, gaze log-likelihood, point support, metric–intervention 상관과 calibration을 보고한다.
7. **Ablation:** blur·인접 배경 채움, mask 면적, 증거 영역 밖 가림, trace 비제공 재답변, SFT/RL, 정답/오답 층별 분석. 출력 token 상한과 해상도를 고정한다.
8. **실패 모드:** 증거가 중복되거나 mask가 문자·물체를 함께 파괴할 수 있다. 인간 검수로 증거 충분성과 개입 후 answerability를 각각 기록한다.
9. **Negative result:** 정렬이 개입 반응을 잘 예측하면 “정렬은 무의미”라는 가설을 기각한다. 차이가 mask artifact로 설명되면 causal faithfulness 주장을 폐기한다.
10. **Novelty·방어:** saliency faithfulness·deletion/insertion과 중복 위험이 높다. novelty는 explicit point reasoning과 human alignment에서 지표가 타당한 조건을 밝히는 데 한정한다. 같은 실험이 선행 연구에 있으면 축소하거나 KILL한다.
11. **4~8주 MVP:** 1주 schema·증거 검수, 2주 paired inference와 GO/KILL, 3~4주 대조·통계, 5~6주 다른 모델·task, 7~8주 temporal 확장과 정리. NexSight 배포 미확인 때문에 temporal 확장은 필수 성공 조건으로 삼지 않는다.
12. **기여 3개:** evidence metric 검증 protocol; 정렬–의존성 불일치 taxonomy; 지표의 유효 범위와 반례를 담은 감사 subset.
13. **제목 2개:** *Looking Right, Reasoning Right? Auditing Grounded Evidence Metrics*; *When Gaze Alignment Predicts Evidence Dependence*.
14. **Abstract 개요:** 정렬 평가의 불명확성 → paired 개입 → 유효/실패 조건 → 제한된 적용 지침.
15. **Introduction:** 정답률의 한계 → 위치 정렬 도입 → 위치와 필요성의 간극 → 통제 검증 질문.
16. **Related Work:** gaze supervision; grounded reasoning; explanation faithfulness; evidence sufficiency와 counterfactual evaluation.
17. **Method:** source 분리 → 증거 annotation → 개입 대조 → 조건부 타당성 분석.
18. **표·그림:** 모델별 정답률/정렬/민감도 표, 정렬 분위수별 개입 곡선, 네 가지 일치·불일치 사례, mask 방식 민감도 그림.

**첫 실험:** 공개 Qwen3-VL-8B-GGR-SFT와 No-Gaze-SFT, held-out에서 서로 다른 source image 최대 200개를 계획한다. 가용 수가 적으면 실제 수와 이유를 기록한다. 정답과 gaze를 모델 입력에 노출하지 않는다. 같은 질문의 원본·evidence mask·면적 일치 control mask를 paired 평가한다. 원본에서 지정한 증거 영역을 두 모델에 공통 적용한다. point는 평가 출력이며 가리는 영역의 유일한 정답으로 사용하지 않는다.

**GO/KILL:** 첫 1~2주에 image 단위 bootstrap 95% CI로 evidence–control 차이를 확인하고, 최소 두 개입 방식에서 방향이 일치하며 metric의 예측 실패가 질문 유형·면적 통제 뒤에도 남으면 GO. control masking에도 같은 변화가 생기거나 annotation 불확실성이 주효과를 설명하면 KILL. CI가 넓으면 미결이다. 첫 단계는 학습 없이 한 checkpoint씩 순차 추론하고 실제 VRAM·GPU 시간을 측정한다. 특정 GPU에서의 로딩 가능성을 보장하지 않는다.

## 4. Proposal B — Selection Repair Boundary

1. **문제·가치:** 좋은 box가 후보에 있어도 선택이 실패한다는 P3의 관찰 이후, 어떤 shift에서 선택 교정이 여전히 유효한지 알아야 한다.
2. **Gap:** P3의 oracle·mask 보조학습을 반복하지 않는다. unseen intersection·거리·pose noise에 따라 “선택만 고쳐 회복 가능한 오류 비중”이 바뀌는지 진단한다.
3. **가설:** localization-aware 점수는 source 환경의 ranking gap을 줄여도 shift 뒤에는 candidate coverage 감소 때문에 효과가 제한된다.
4. **구조:** 고정 detector의 pre-NMS box·score·anchor ID를 저장 → candidate availability와 ranking 실패 분해 → source에서 학습한 작은 quality calibration → 고정 NMS. GT oracle은 분석 상한에만 사용한다.
5. **Baseline:** native NMS, Soft-NMS, source-calibrated quality score, P3의 legal-lineage oracle. GeoScaffold checkpoint가 확보되면 별도 2×2 비교하되 없으면 재현을 주장하지 않는다.
6. **데이터·지표:** UrbanIng-V2X crossing1/2 내부 source split과 crossing3 held-out, 후속 V2V4Real. BEV AP@0.5/0.7, candidate recall, selection loss, false-positive 변화, latency.
7. **Ablation:** box 고정/score만 변경, threshold sweep, 거리·가림·class 층화, pose noise, 동일 후보 수, calibration feature 제거. 교차로 간 frame 누출을 차단한다.
8. **실패 모드:** calibration이 class·거리 빈도를 암기하거나 높은 IoU 후보가 낮은 IoU 객체를 희생할 수 있다. recall과 class별 손해를 병기한다.
9. **Negative result:** shift에서 후보 자체가 사라지면 selection 연구의 한계를 보고한다. 그 결과는 더 큰 fusion 모델이 필요하다는 증거와도 구분한다.
10. **Novelty·방어:** quality-aware NMS는 기존 분야다. 단순 재점수화 성능 논문으로는 약하다. 독립 shift에서 oracle headroom과 실제 교정의 괴리가 어떻게 변하는지가 핵심이며, 안정된 새 현상이 없으면 중단한다.
11. **4~8주 MVP:** 1주 데이터·checkpoint 허가와 실행, 2주 후보 dump·경계 진단, 3~4주 calibration, 5~6주 shift 전이, 7~8주 통계·분석.
12. **기여 3개:** 후보 부족/선택 실패의 shift별 분해; 교정 전이 한계; 개선과 부작용을 함께 드러내는 평가 protocol.
13. **제목 2개:** *When Better Ranking Cannot Repair Collaborative Detection*; *The Shift Boundary of Selection Repair*.
14. **Abstract 개요:** 선택 손실의 존재 → 환경 변화에 따른 회복 가능성 → 고정 후보 평가 → 교정의 조건부 효용.
15. **Introduction:** 협력 관측의 이득 → 최종 선택 손실 → 기존 진단의 다음 질문 → 전이 경계.
16. **Related Work:** collaborative perception; localization-aware scoring; NMS; calibration under shift.
17. **Method:** lineage 기록 → 오류 분해 → source-only calibration → held-out shift 평가.
18. **표·그림:** 환경별 coverage/selection 표, 거리별 oracle–실제 회복 곡선, 2×2 교정·학습 비교, 개선·악화 사례.

**첫 실험·GO/KILL:** OpenCOOD의 이용 가능한 V2X-ViT checkpoint를 먼저 검증하고 crossing1/2와 crossing3에서 각각 최대 500 frame을 장면·시간 간격으로 추출할 계획이다. 후보와 좌표를 고정하고 score만 바꾼다. checkpoint가 없으면 2주 MVP에 대규모 재학습을 억지로 넣지 않고 feasibility 실패로 기록한다. held-out shift에서 candidate recall과 ranking loss가 서로 다르게 움직이고 scene 단위 CI로 구분되면 진단 GO. source에서만 차이가 있거나 통상적인 IoU-aware scoring으로 전부 설명되면 새 방법 주장은 KILL한다.

## 5. Proposal C — Counterfactual Reference Audit

1. **문제·가치:** P4의 annular feature reference에 target 정보가 섞이면 낮은 residual을 “증거 부족”으로 읽을 위험이 있다.
2. **Gap:** 이 가능성은 저자가 이미 인정했다. 후속 gap은 참조 오염이 target 크기·clutter·receptive field에 따라 얼마나 바뀌며 false alarm 교정에 어떤 영향을 주는지다.
3. **가설:** target 주변 참조 반경을 바꿀 때 true target과 structured clutter의 evidence ordering이 뒤집히는 구간이 있으며, 이는 단순 response magnitude로 설명되지 않는다.
4. **구조:** 고정 U-Net계 infrared detector → frozen decoder feature → P4 식의 annular residual audit → 반경별 score 안정성 측정. 첫 단계에는 새 enhancement network를 만들지 않는다.
5. **Baseline:** raw response, local contrast, 고정 annulus, 면적 일치 random reference, 여러 반경의 robust aggregation. P4 구현 미확보 시 “CBE 유사 진단”으로 명명하고 VBE-UNet 재현으로 쓰지 않는다.
6. **데이터·지표:** IRSTD-1K 원래 split에서 시작하고 NUAA-SIRST로 전이. Pd–Fa curve, mIoU/nIoU, target/clutter ranking, 반경별 순위 역전, target 크기·배경 복잡도별 결과.
7. **Ablation:** inner/outer radius, input 대 feature space, 채널별 정규화, feature level, 표적 제외 참조와 일반 참조. GT로 표적을 제외하는 조건은 oracle 진단이며 배포 성능과 분리한다.
8. **실패 모드:** 참조 반경 변화가 target leakage보다 배경 비정상성을 바꿀 수 있다. 표적이 없는 matched patch와 동일 면적 대조가 필요하다.
9. **Negative result:** 순위가 안정적이면 leakage 지배 가설을 기각한다. synthetic target에서만 효과가 있으면 실제 적외선 일반화 주장을 철회한다.
10. **Novelty·방어:** local contrast·counterfactual saliency와 중복된다. 참조 오염의 operational 정의와 실제 데이터에서의 안정성 경계가 남아야 한다. 단순 multi-radius 모듈은 기여로 보지 않는다.
11. **4~8주 MVP:** 1주 모델·split 확인, 2주 반경 sweep, 3~4주 대조와 실제 target 분석, 5~6주 최소 안정화 규칙, 7~8주 cross-dataset.
12. **기여 3개:** 참조 오염 감사법; true target/clutter의 민감도 지도; 오염이 심할 때 enhancement를 보류하는 최소 규칙.
13. **제목 2개:** *Is the Background Really Target-Free?*; *Reference Contamination in Infrared Evidence Verification*.
14. **Abstract 개요:** counterfactual proxy 한계 → 참조 반경 개입 → 순위 안정성 → 교정이 통하는 조건과 실패 조건.
15. **Introduction:** 강한 response의 모호함 → evidence verification → 배경 참조 가정 → 오염을 측정할 필요.
16. **Related Work:** infrared detection; local background modeling; perturbation attribution; receptive-field leakage.
17. **Method:** 참조 정의 → matched control → 안정성 측정 → 선택적 보류 규칙.
18. **표·그림:** 반경×feature level heatmap, Pd–Fa 곡선, 크기·clutter 층별 순위 역전, 참조 오염 시각화.

**첫 실험·GO/KILL:** 공개 구현·checkpoint를 확보할 수 있는 DNANet을 우선 검토하고, IRSTD-1K test에서 최대 100개 target-bearing image와 해당 이미지의 matched background patch를 사용한다. 모델·학습은 고정하고 annulus 반경만 3조건으로 바꾼다. GT는 진단용 영역 정의에만 쓴다. 실제 표적에서도 조건별 ordering 변화가 bootstrap으로 확인되고 matched background·정규화 대조로 설명되지 않으면 GO. 변화가 배경 비정상성 또는 feature padding만으로 설명되면 leakage 설명은 KILL한다. checkpoint 미확보 시 구현 가능성부터 보고하고 결과를 만들지 않는다.

**이번 주 1순위는 A다.** GGR·No-Gaze의 코드·모델·데이터 페이지가 확인되어 의존성이 가장 명확하다. 새로운 학습 이전에 1~2주 내 핵심 가설을 반증할 수 있고, 부정 결과도 grounded metric의 적용 범위를 설명한다. 다만 explanation faithfulness 선행 연구와의 중복 검토를 첫 주에 병행해야 한다.

작은 GPU를 우선한다면 C의 frozen-feature 감사가 후보이나 checkpoint와 입력 크기를 먼저 확인해야 한다. 장기 확장은 A의 공간·시간 evidence metric을 하나의 평가 체계로 연결하는 방향이며, 아직 통합 방법의 효과를 주장하지 않는다.
