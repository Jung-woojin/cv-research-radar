## 1. Stable Scores, Unstable Answers — 점수는 비슷해도 답은 흔들린다

**자료:** [arXiv abstract](https://arxiv.org/abs/2610.08649) · [공식 HTML 원문](https://arxiv.org/html/2610.08649v1)  
**발표 시점:** 2026-10-07 01:36 KST에 v1 제출  
**평가 대상:** EgoSchema, MVBench, Video-MME의 video multiple-choice QA  
**감사 규모:** Qwen2.5-VL-7B, Qwen3-VL-8B, InternVL2.5-8B; 9개 model×benchmark cell, cell당 500문항×10개 option ordering. 별도 phase sweep을 포함해 총 289,000회 inference를 수행했다.

### 확인된 사실과 저자 주장

- 균일 프레임 샘플링에는 **rate뿐 아니라 phase**, 즉 같은 간격에서 어느 지점부터 프레임을 뽑는지가 있다. 기존 보고는 대개 프레임 수나 rate만 적고 phase는 생략한다.
- 저자 실험에서 동일한 8-frame grid의 위상을 반 step 이동했을 때 consensus answer disagreement는 Qwen3-VL 18.7%, Qwen2.5-VL 20.1%, InternVL2.5 두 설정에서 15.6%와 15.2%였다. phase별 accuracy 차이는 2%p 미만이었다.
- 즉 평균 accuracy가 거의 같아도 **문항 단위 예측은 약 5개 중 1개꼴로 바뀔 수 있다**. 논문 초록의 대표 배치에서는 두 sampler가 23.6% 문항에서 불일치하면서 점수 차이는 1%p 이내였다.
- Option ordering을 바꾼 실험에서는 pooled answer flip이 54.0%였고, 같은 reorderings가 점수를 최대 5.8%p 움직였다. 한 model–benchmark pair에서는 열 번 중 한 번 ranking reversal도 관측됐다.
- 저자는 8프레임 위상 세 개의 option posterior를 평균하는 **PhaseFusion**을 제안했다. Qwen3-VL paired subset에서 60.4%(3×8-frame) 대 60.0%(single 32-frame), visual-prefix attention은 192 대 1,024로 보고했다. 반 step origin shift 시 answer change는 single 8-frame 18.2%, dense 24-frame 13.3%, PhaseFusion 10.1%였다.
- 직렬 latency 중앙값은 PhaseFusion 3.18초, single 32-frame 3.92초, single 8-frame 0.99초였다. 따라서 PhaseFusion은 attention budget에는 유리하지만 한 번의 8-frame 실행보다 지연이 크다.

### 비교 가능성과 재현성

- 같은 모델 안의 phase 비교는 frame count·prompt·option order를 고정해 비교 가능성이 높다. 반면 서로 다른 모델 family의 불일치율과 정확도는 **not strictly apples-to-apples**다.
- PhaseFusion과 single pass 비교도 총 forward-pass 수와 직렬 지연이 다르므로, accuracy만으로 효율 우위를 선언하면 안 된다.
- 논문은 corpus와 code를 출판 시 공개하겠다고 적었다. 현재 공식 공개 저장소를 확인하지 못했으므로 오늘 독립 실행은 불가능하다.

### 해석과 최소 실험

**해석:** 현재 video VLM benchmark에서 “32프레임을 사용했다”는 정보만으로는 재현 조건이 충분하지 않다. sampling phase, option order, decoding 설정과 per-item disagreement를 함께 기록해야 한다.

**최소 실험:**

1. 내부 video VLM 평가셋에서 모델·prompt·8-frame budget·option order를 고정한다.
2. normalized timestamp 기준 phase 0과 0.5-step 두 조건을 실행한다.
3. accuracy 차이와 함께 문항별 disagreement, confidence 이동, 짧은 사건이 위치한 구간을 기록한다.
4. disagreement가 동일 조건 반복 추론의 noise floor보다 클 때만 3-phase posterior fusion을 시험한다.

**GO:** phase fusion이 single-phase 대비 disagreement를 절반 가까이 낮추면서 accuracy 손실을 2.5%p 이내로 유지한다.  
**KILL/재진단:** phase 차이가 동일 조건 재실행 변동과 구분되지 않거나, 변화 대부분이 option-order 효과로 설명된다.

## 2. Data Leakage in Patch-Based HSI Classification — spatial split이 모델 순위를 재작성한다

**자료:** [arXiv abstract](https://arxiv.org/abs/2610.08770) · [공식 HTML 원문](https://arxiv.org/html/2610.08770v1) · [저자 GitHub 저장소](https://github.com/mqalkhatib/Data_Leakage_in_HSI_Classification)  
**발표 시점:** 2026-10-07 02:55 KST에 v1 제출, 공식 저장소 최신 확인 commit `30d0812a82d4894e43d1599c3aaf9d13754bba44`  
**평가 대상:** Pavia University hyperspectral image, random spatial sampling과 non-random connected-region sampling 비교  
**모델:** SVM, MLP, 2D-CNN, 3D-CNN, ViT, MorpMamba

### 확인된 사실과 저자 주장

저자가 보고한 overall accuracy는 다음과 같다.

| 모델 | Random split | Non-random split | 하락 |
|---|---:|---:|---:|
| SVM | 62.15% | 51.25% | -10.90%p |
| MLP | 69.50% | 50.15% | -19.35%p |
| 2D-CNN | 86.97% | 48.16% | -38.81%p |
| 3D-CNN | 96.17% | 55.20% | -40.97%p |
| ViT | 91.78% | 51.07% | -40.71%p |
| MorpMamba | 81.07% | 48.45% | -32.62%p |

- patch size를 5에서 19로 키울 때 random split의 overlap percentage는 23.28%에서 77.02%로 증가했다. non-random split에서는 0.83%에서 4.66%였다.
- random split의 average overlap ratio도 47.29%에서 79.91%로 증가한 반면, non-random 조건은 약 45.26%에서 39.42% 범위였다.
- 논문의 핵심 주장은 patch classifier가 test pixel 주변의 train context를 사실상 다시 보게 되면, 특히 spatial model의 accuracy가 과대평가된다는 것이다.

### 코드 교차검증과 비교 가능성

- 공식 저장소의 `Leakage_with_Overlap.py`는 Pavia dataset, class별 최소 개수 기반 train/validation 수, 10개 seed, random split을 사용한다.
- `Leakage_No_Overlap.py`는 class별 connected region을 train/validation으로 구성한다.
- 다만 확인한 기본 script에서 overlap 조건은 `patch_size=5`, no-overlap 조건은 `patch_size=19`였다. README는 제목 한 줄뿐이고 설치·데이터 배치·실행 명령·license가 없다.
- 따라서 현재 공개 코드만 단순 실행해 두 script의 결과를 비교하면 split 이외에 patch size까지 달라질 수 있다. 논문 표를 재현하려면 patch size·모델·학습 설정·class별 표본 수를 명시적으로 맞춰야 한다.
- random split과 connected-region split은 배포 공간분포 자체도 달라질 수 있어 **not strictly apples-to-apples**다. 이는 generalization stress test로는 유효하지만, 하락 전체를 오직 pixel overlap 탓으로 돌리려면 buffer distance와 지역별 distribution shift를 분리해야 한다.

### 해석과 최소 실험

**해석:** 해양 안개·위성 segmentation에서도 동일 항공/위성 tile의 인접 patch가 train과 test에 섞이면 높은 IoU가 공간 기억의 결과일 수 있다. 특히 큰 receptive field나 contextual model일수록 위험하다.

**최소 실험:**

1. Sentinel-2 또는 해양 관측 tile 하나를 기준으로 기존 random patch split을 보존한다.
2. 같은 train sample 수·patch size·augmentation을 유지한 geographic block/group split을 추가한다.
3. train–test pixel overlap, 최소 buffer 거리, class별 IoU와 calibration error를 함께 측정한다.
4. 최소 두 개 지역 또는 촬영 시점에서 block split을 반복해 overlap과 regional shift를 분리한다.

**GO:** split 변경이 모델 순위나 class별 IoU를 실질적으로 바꾸고, 하락 크기가 overlap/buffer 지표와 일관되게 연결된다.  
**KILL/재명명:** overlap을 0으로 만든 뒤에도 지역만 바꾸면 같은 하락이 유지된다. 이 경우 결과를 “leakage” 하나로 설명하지 말고 spatial domain shift 평가로 재정의한다.

## 3. RenderBench — real/proxy 쌍으로 render-to-real 실패를 구조적으로 측정한다

**자료:** [arXiv abstract](https://arxiv.org/abs/2610.08684) · [공식 HTML 원문](https://arxiv.org/html/2610.08684v1)  
**발표 시점:** 2026-10-07 02:03 KST에 v1 제출  
**평가 단위:** appearance reference, held-out real target, editable digital twin, matched proxy render, renderer-native annotation의 묶음  
**현재 공개 규모:** 등록 14개 scene 중 검증을 통과한 12개 scene, paired real–proxy 1,496 frames, 30 fps

### 확인된 사실과 저자 주장

- RenderBench는 생성 결과를 reference-free 미학 점수 하나로 평가하지 않고, 같은 장면의 real target과 proxy render를 짝지어 구조 보존을 측정한다.
- PAI-Bench-C와 호환되는 structural projection을 사용하며 edge F1, depth scale-invariant RMSE, instance mIoU와 paired-reference metric을 함께 보고한다.
- 데이터 무결성 검사에서 real/proxy frame-count 일치는 12/12, SHA-256 검사는 48/48, edit-isolation에서 foreground·camera·animation hash 불변은 12/12로 보고됐다.
- proxy diagnostic baseline은 depth si-RMSE 0.2170, 95% bootstrap interval [0.1774, 0.2633], instance mIoU 0.3673 [0.2751, 0.4504]였다.
- 이 값은 생성 모델 leaderboard의 우승 점수가 아니라 **proxy 품질과 평가 난도를 진단하는 기준값**이다.
- 저자는 fluids, deformable objects, outdoor crowds, severe occlusion, fast motion을 현재 digital-twin 구성과 annotation의 어려운 범위로 든다.
- 모델별 conditioning interface가 다르므로 pooled ranking은 모델 능력과 입력 정보량을 함께 반영한다. 논문도 track별 보고와 matched information budget을 권장한다.

### 비교 가능성과 재현성

- scene·camera·time alignment와 renderer-native annotation을 고정한 점은 강하다.
- 그러나 closed video APIs와 서로 다른 conditioning channel을 한 표에서 비교하면 **not strictly apples-to-apples**다. image/video reference 수, mask·depth 제공 여부, 해상도, 프레임 길이, retry budget을 같은 열에 기록해야 한다.
- 논문은 benchmark release를 기술하지만, 확인 시점에 arXiv 원문에서 공식 download·code repository 링크를 찾지 못했다. 따라서 12-scene artifact와 evaluator version을 실제 내려받아 검증하지 못했다.

### 해석과 최소 실험

**해석:** 사용자의 해양 비전 과제에서도 하나의 aggregate quality score보다 real/proxy 혹은 clear/degraded pair를 만들고, 객체 경계·깊이 대용치·visibility strata로 나누는 편이 실패 원인을 더 잘 드러낸다.

**최소 실험:**

1. 같은 항만 장면에서 clear frame을 기준으로 controlled fog degradation 세 단계를 만든다.
2. detector/segmenter 입력 정보와 해상도를 고정한다.
3. 전체 mAP/mIoU와 함께 small-object recall, boundary F1, 거리 또는 contrast bin별 recall을 기록한다.
4. real fog 소규모 holdout에서 degradation 단계별 순서가 유지되는지 확인한다.

**GO:** controlled degradation의 strata별 순위가 real-fog holdout에서도 유지되고, aggregate score가 숨긴 실패 구간을 식별한다.  
**KILL:** synthetic degradation에서만 순위가 바뀌고 real fog에서는 상관이 사라진다. 이 경우 twin/degradation fidelity부터 수정한다.

## 4. World Models’ Last Exam in Physics — VLM 심판에서 측정 가능한 물리 기준으로

**자료:** [arXiv abstract](https://arxiv.org/abs/2610.08791) · [공식 HTML 원문](https://arxiv.org/html/2610.08791v1)  
**발표 시점:** 2026-10-07 02:59 KST에 v1 제출  
**평가 대상:** initial image와 prompt로부터 생성한 video의 물리적 타당성  
**구성:** mechanics, optics, fluids, thermal/phase, electromagnetism, surface tension 등을 포함한 9개 범주, 40개 통제 과제

### 확인된 사실과 저자 주장

- benchmark는 reference video 없이 관측 가능한 물리 criterion을 과제별로 정의한다.
- evaluator는 먼저 현상이 충분히 보이는지와 영상이 일관적인지를 gate로 검사한 뒤, trajectory·형상·광학·유체 등 과제별 측정을 적용한다.
- 8개 video generation model에서 총 1,280개 영상을 평가했고, 저자 보고 최고 overall score는 57.76/100이었다.
- evaluator 자체의 sanity check로 40개 과제별 12개, 총 480개 synthetic reference video를 평가했다. consistency gate를 우회한 평균 physical score는 Easy 97.93, Medium 96.64, Hard 98.25, 전체 97.53이었다.
- human study는 40개 과제의 320개 영상을 10명이 평가했다. 논문은 measurement-based evaluator가 direct VLM judge보다 사람 판단과 더 잘 맞는다고 주장한다.
- direct VLM baseline은 Qwen3.6-27B, 24 sampled frames, 최대 변 640, temperature 0 조건이었다.
- 첫 프레임은 GPT-Image-2.5로 생성한 뒤 사람이 검사·수정했다. 따라서 initial-condition 품질과 사람 선별이 benchmark 난도에 영향을 줄 수 있다.

### 비교 가능성과 재현성

- observability gate는 “현상이 보이지 않아 측정 불가능한 영상”과 “보이지만 틀린 물리”를 구분하는 데 유용하다.
- 반대로 측정식은 검출·tracking·segmentation이 안정적으로 가능한 현상에 편향된다. 저자도 visibility와 reliable extraction을 한계로 둔다.
- 서로 다른 closed model/API의 해상도·길이·sampling·서비스 설정은 완전히 같지 않으므로 모델 간 점수는 **not strictly apples-to-apples**다.
- 확인 시점에 공식 evaluator·dataset 저장소 링크를 찾지 못해 57.76점이나 human-alignment 결과를 독립 검증하지 못했다.

### 해석과 최소 실험

**해석:** 핵심 이동은 “큰 VLM에게 자연어로 좋아 보이는지 묻기”에서 “먼저 관측 가능성을 확인하고, 실패 가설마다 계산 가능한 증거를 수집하기”로의 전환이다. 이 구조는 생성 영상뿐 아니라 해무 속 객체 인식 진단에도 적용할 수 있다.

**최소 실험:**

1. 해무 영상에서 관측 가능성 gate를 object contrast·가시 픽셀 수·frame persistence로 정의한다.
2. gate 통과 표본에는 trajectory smoothness, mask area continuity, class confidence drift를 계산한다.
3. 동일 표본을 범용 VLM judge와 사람이 평가하게 하고, 세 방식의 오류 유형 일치도를 비교한다.

**GO:** 측정 기반 scorecard가 사람의 실패 분류와 더 일치하고, 재실행에도 안정적이다.  
**KILL:** measurement extractor 오류가 실제 모델 오류보다 많다. 이 경우 evaluator를 leaderboard에 쓰지 말고 진단 보조로 제한한다.

## 교차 신호: 오늘 바뀐 것은 점수가 아니라 신뢰 조건이다

| 이동 | 기존 관행 | 오늘 확인된 위험 | 보고서에 추가할 필드 |
|---|---|---|---|
| Video MCQ sampling | frame count/rate만 표기 | phase만으로 문항별 답이 크게 변함 | phase/origin, item disagreement, option order |
| Spatial imagery split | random patch split | 인접 context 재사용으로 성능 과대평가 | tile/group ID, overlap, buffer distance |
| Video generation | 단일 VLM·미학 점수 | 구조 실패와 입력 정보량이 섞임 | track, conditioning budget, edge/depth/instance 지표 |
| Physical plausibility | direct VLM judge | 관측 불가능과 물리 오류가 혼동됨 | observability gate, task-specific measurement, extractor failure |

네 연구를 서로 직접 순위 비교할 수는 없다. 데이터·모델·과제가 모두 다르다. 공통점은 **작은 protocol perturbation 또는 명시적 measurement가 aggregate score의 취약성을 드러냈다**는 데 있다.

## 오늘의 benchmark signal 3개

1. **평균 score와 prediction stability를 분리하라.** Accuracy가 1%p 이내로 같아도 video MCQ 답의 약 15–20%가 바뀔 수 있다. 앞으로는 seed·order·phase perturbation에 대한 disagreement를 기본 지표로 둔다.
2. **공간 데이터는 sample 수보다 경계를 먼저 감사하라.** patch 크기, tile ID, buffer, train–test overlap을 기록하지 않은 remote-sensing 점수는 배포 성능의 증거로 약하다.
3. **evaluator도 측정 대상이다.** 공개 코드, artifact version, conditioning budget, observability, extractor failure를 확인하지 못하면 leaderboard 숫자를 확정 사실이 아니라 저자 주장으로 유지한다.

## 내 연구에 바로 연결되는 포인트

- **최우선:** 해무·연안 Sentinel-2/영상 데이터의 현재 split을 tile/group 기준으로 다시 그려 train–test overlap과 최소 거리를 계산한다. 모델을 새로 만들기 전에 기존 점수의 누수를 먼저 측정한다.
- **두 번째:** video VLM 또는 temporal classifier에 8-frame phase 0/0.5 audit을 추가하고, accuracy와 per-sample disagreement를 함께 저장한다.
- **세 번째:** detector/segmenter 결과를 전체 mAP/mIoU 하나로 끝내지 말고 visibility·object size·boundary quality·temporal persistence별 scorecard로 분해한다.
- **보류:** Stable Scores, RenderBench, World Models’ Last Exam의 공식 실행 artifact가 공개되기 전에는 숫자 재현을 주장하지 않는다. artifact가 확인되면 commit/version을 고정해 1회 smoke test 후 채택 여부를 결정한다.
- **오늘의 90분 실행안:** 30분은 split/overlap audit script, 30분은 frame-phase paired evaluation, 30분은 strata별 metric schema 작성에 배정한다. 새 모델 학습 없이도 현재 benchmark 신뢰도를 먼저 높일 수 있다.
