## 1. UAV 안정화 — 내부 일관성에서 배경 정렬 평가로

**변화·저자 주장.** 새 benchmark는 정적·동적 protocol로 안정화 pipeline을 평가한다. 같은 방향으로 움직이는 차량이 robust estimator를 포획하는 consensus capture를 다룬다. 논문은 실시간 조건의 unmasked ORB에서 304개 동적 pair 중 28개 포획을 보고하며, 해당 추정의 corner error 중앙값은 18.8px인데도 inlier 통계는 정상적이라고 설명한다. 독립 재현 수치가 아니다. [논문 초록·제출 기록](https://arxiv.org/abs/2611.17190)

**공식 구현 교차확인 — 사실.** 저장소는 site-disjoint tuning, 해상도·feature budget 통제, 실패 포함 집계를 명시한다. inlier 수는 진단용이며 순위 metric으로 쓰지 않는다. sample 실행은 smoke test로 제한하며 전체 순위의 근거로 사용하지 말라고 밝힌다. 논문 설명과 README는 정합적이지만 코드 실행·결과 파일의 수치 일치는 검증하지 않았다. [공식 저장소](https://github.com/rfonod/stabilo-benchmark), [논문 방법론](https://arxiv.org/html/2611.17190v1)

**진단 → 기전 — 추론.** 대응점끼리 잘 맞는다는 사실은 대응점이 정지 배경이라는 보장이 아니다. 차량 흐름이 지배하면 작은 내부 오차와 큰 지상 위치오차가 공존할 수 있다.

**가설 → 최소 개입.** 동일 ORB 설정에서 움직이는 물체를 feature 추출 전에 제외하면, inlier 통계보다 고정 지상점 오차가 더 일관되게 개선될 수 있다.

**최소 실험 제안.** 보유 UAV hover 한 구간에서 정지 지상점을 수동 지정하고 none/HBB/OBB masking을 paired 비교한다. 입력 해상도·feature 수·estimator seed·reference frame을 고정한다. 지상점 오차, object-center error, capture fraction, 실패율, 처리시간을 기록한다. 작은 구간은 기전 확인에만 쓰며 일반 순위를 만들지 않는다.

**GO/KILL.** 배경 오차가 줄고 정지 control에서 손실이 작으면 다음 장소로 확장한다. 개선이 masking 면적·feature budget 변화로 설명되면 consensus capture 억제 가설은 보류한다.

**비교 판정.** 정적 synthetic homography와 동적 pseudo-GT, offline과 real-time은 **not strictly apples-to-apples**다. 이 결과는 항공 detection AP 향상을 직접 입증하지 않는다.

## 2. MUMU — 효율 가중 종합점수와 OVD의 간극

**변화·사실.** 11월 12일 공개 보고서는 0.5B parameter·PC 측 peak inference memory 8GB 이하의 단일 모델로 tagging·OVD·captioning을 평가한다. 기존 대회의 결과 보고서 공개이며 대회가 그날 열렸다는 뜻은 아니다. 상위 세 팀은 Florence-2-base를 사용한다. [보고서 초록](https://arxiv.org/abs/2611.16925)

**결과·저자 주장.** 논문 Table 2에서 SSUfficient의 detection은 8.22, baseline은 4.77이다. tagging 선두는 다른 팀이다. 종합점수는 과제 가중합에 효율 계수를 곱하므로 전체 순위를 OVD 순위로 대체할 수 없다. [논문 평가·결과](https://arxiv.org/html/2611.16925v1)

**원문 충돌 — 확인 사실.** 공식 웹페이지는 private final test를 30,000장으로 기술하지만 논문은 최종 순위를 1,038장 held-out test에서 계산했다고 쓴다. 변경 원인·동일 subset 여부는 미확인이다. 웹페이지의 8GB 제한은 PC 측 inference 기준이다. RTX 5060 Ti 8GB의 실제 여유나 학습 가능성을 보장하지 않는다. [공식 규칙·split](https://lsvos.github.io/mumu)

**진단 → 기전 — 추론.** 같은 backbone이어도 학습 데이터 구성, caption 경로 고정 여부, cross-task refinement, TTA가 다르면 성능 차이를 새 architecture 효과로 귀속할 수 없다. test manifest 불일치는 재현 점수 비교의 선행 장애다.

**가설 → 최소 개입.** shared adaptation으로 tagging이 좋아질 때 caption 품질이나 novel detection이 저하되는 과제 간 간섭이 발생할 수 있다.

**최소 실험 제안.** 접근 가능한 자체 검증셋에서 동일 Florence-2 checkpoint·학습 split·해상도·decode budget을 고정하고 baseline, tagging head만 학습, shared adapter를 비교한다. macro-F1·novel AP·caption 점수를 각각 보고하고 peak memory·지연도 함께 기록한다. TTA와 cross-task refinement는 별도 ablation으로 둔다.

**GO/KILL.** 개별 과제 손실이 반복 seed에서 재현되면 gradient·decode 경로 진단으로 진행한다. training coverage가 달라 원인이 구분되지 않으면 negative transfer 주장은 보류한다. 공식 test 규모가 해소되기 전 challenge 점수 재현 성공을 선언하지 않는다.

**비교 판정.** 동일 backbone만으로 동일 조건은 아니다. 팀 간 결과는 **not strictly apples-to-apples**다. 제출 artifact의 organizer 재현 규정은 확인했지만 상위 팀 코드·가중치를 직접 확보해 실행하지 않았다.

## 3. DashBench — 위험 존재와 근거 있는 설명을 분리

**변화·저자 주장.** 새 DashBench는 1,709개 driving video로 25개 Video LLM을 평가한다. 저자는 위험 누락과 존재하지 않는 행위자·행동의 환각을 보고한다. 이는 특정 benchmark의 저자 결과이며 전체 실제 도로 성능이나 정량적 안전 인증으로 일반화하지 않는다. [논문 초록·이력](https://arxiv.org/abs/2611.16767)

**평가 조건 — 사실.** 본문은 16-frame uniform sampling으로 사건을 식별 가능한 clip을 선별하고, binary event detection과 원인·행위자·시점이 맞는 설명을 따로 평가한다. 설명 평가는 DeepSeekV3 judge를 사용한다. 따라서 높은 binary 점수는 grounded explanation의 성공이 아니다. 연결 프로젝트는 이번 열람에서 404였으며 코드·데이터 공개 상태를 확인하지 못했다. [논문 protocol](https://arxiv.org/html/2611.16767v1), [접근 실패한 프로젝트](https://cornercase-dashbench.github.io/)

**진단 → 기전 — 추론.** 사건이 포함된 clip의 존재 판정은 정상 clip의 오경보율을 대체하지 못한다. cue가 강한 prompt에서 답변이 좋아져도 영상 증거 활용과 언어적 위험 prior를 분리해야 한다.

**가설 → 최소 개입.** 위험을 암시하는 prompt가 사건 설명을 늘리면서 정상 장면의 환각도 늘릴 수 있다.

**최소 실험 제안.** 사용 권한이 있는 CCTV·driving 영상에서 사건/정상 control을 준비한다. 동일 모델·16 frames·해상도·decode 설정으로 중립 설명과 위험 cue prompt를 paired 비교한다. 사람이 blind 검토해 event recall, 정상 control 오경보, 행위자·시점 일치율, JSON 실패를 별도 집계한다. GT event window를 주는 조건은 oracle ablation으로 분리한다.

**GO/KILL.** recall 증가와 함께 오경보가 증가하면 cue 의존성을 후속 연구한다. prompt 이득이 human ground-truth grounding에서도 유지되면 단순 언어 prior 가설을 축소한다. 데이터 접근 전에는 원 논문의 재현이라고 부르지 않는다.

**비교 판정.** 모델별 pretraining·외부 데이터·reasoning budget은 통제되지 않았고, full clip과 GT window는 이용 가능한 정보가 달라 **not strictly apples-to-apples**다. 공개 초록과 본문은 정합적이나 evaluator commit·artifact 수준 일치는 미확인이다.
