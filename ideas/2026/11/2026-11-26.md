## 2. 핵심 논문 5편

### P1. When Does Looking Closer Pay Off? Simple Foveated ViTs for Fine-Grained Recognition

- **공개:** v1 2026-11-20 16:20:23 UTC. 확인한 이력은 v1이다.
- **문제·방법:** 저해상도 glance의 attention으로 셀을 선택하고 고해상도 패치로 교체해 같은 backbone으로 분류하는 FoVT다.
- **저자 결과:** 다섯 fine-grained benchmark에서 attention 선택의 이점을 보고한다. 다만 FGVC-Aircraft는 학습 시 셀 예산에서 정확도가 정점을 보이고 추론 시 예산 확대가 오히려 불리할 수 있다.
- **중요 한계:** §V-E가 예산 전이 문제를 이미 명시한다. FLOPs 감소를 실제 latency 감소와 동일시하지 않는다.
- **공개 상태:** 이번 확인에서 저자 구현·checkpoint 배포를 확정하지 못했다. 기존 데이터셋 사용과 데이터 자체 재배포는 별개다.
- **후속 연결:** A는 비단조성의 발견이 아니라, 어떤 표본이 개선·악화되는지와 최소 교정의 전이 가능성을 연구한다.

출처: [공식 제출 이력](https://arxiv.org/abs/2611.27788), [v1 §V-D~V-I](https://arxiv.org/html/2611.27788v1).

### P2. GeLiFiSH: Recursive LiDAR Keypoint Estimation with Ground and Moving Object Segmentation

- **공개:** v1 2026-11-23 10:03:59 UTC.
- **문제·방법:** rolling map의 keypoint를 학습 없이 추적하며 sequential test로 지속성을 판단한다. 최신 scan이 실제로 재관측한 경우에 hit를, 통과 관측이 있는 경우에 miss를 갱신한다.
- **저자 결과:** SemanticKITTI·HeLiMOS·HeLiPR에서 repeatability와 registration 성능을 보고한다.
- **중요 한계:** 최신 관측을 골라 누적한다는 설계가 실제 통계적 독립성을 증명하는 것은 아니라는 점이 이번 해석이다. 논문을 “중복 관측을 그대로 세는 방법”으로 오독하면 안 된다.
- **공개 상태:** 본문은 acceptance 이후 코드 공개 예정이라고 적는다. 배포 완료·checkpoint 공개로 표시하지 않는다. 학습 없는 방법이므로 weight 유무보다 코드·설정이 중요하다.
- **후속 연결:** B는 novelty gate를 통과한 관측 사이에도 남는 상관과 confidence 오차를 진단한다.

출처: [공식 이력](https://arxiv.org/abs/2611.30402), [v1 §III-C 및 코드 공개 안내](https://arxiv.org/html/2611.30402v1).

### P3. AdvMTO: Multimodal and Temporal Adversarial Object Attacks via 2D Gaussian Splatting for BEV-Based 3D Object Detection

- **공개:** v1 2026-11-23 08:40:14 UTC.
- **문제·방법:** 동일 object state에서 camera·LiDAR와 detector-native history를 구성해 BEV detector를 평가한다.
- **저자 결과:** nuScenes의 traffic cone과 세 detector에서 검출 억제를 보고한다.
- **중요 한계:** Appendix D에서 native history 대 current-only의 일부 최종 점수 차이 구간은 0을 포함한다. history를 바꾸면 clean 기준도 달라지므로 감소율만으로 우열을 단정할 수 없다.
- **공개 상태:** 이번 원문 확인에서 공식 코드·학습된 object asset·checkpoint 배포를 확정하지 못했다.
- **후속 연결:** B의 보조 근거다. 시간 누적 비교에서는 관측 구성과 clean baseline을 함께 고정·기록해야 한다. 공격 최적화 자체는 이번 MVP에 넣지 않는다.

출처: [공식 이력](https://arxiv.org/abs/2611.30283), [v1 §4.3·Appendix C~D](https://arxiv.org/html/2611.30283v1).

## 3. Proposal A — Budget Change Error Asymmetry

1. **문제·지금의 가치:** 고해상도 토큰을 늘리는 배포 정책이 평균 예산을 바꾸면서 새로운 오류를 만들 수 있다. P1의 비단조적 예산 전이를 표본 수준에서 설명해야 한다.
2. **기존 gap:** P1이 보고한 데이터셋별 예산 전이와 confidence gate를 반복하지 않는다. 같은 checkpoint에서 예산 변경으로 생기는 correct→wrong과 wrong→correct가 클래스·객체 크기·토큰 구성에 따라 어떻게 달라지는지가 질문이다.
3. **가설:** 일부 예산에서 정확도가 내려가는 이유는 정보량 부족보다 학습 시 토큰 구성에 대한 readout 적합성일 수 있다. 작은 출력 교정으로 회복되면 이 설명을 지지하지만, 그것만으로 내부 인과기전을 확정하지 않는다.
4. **구조:** frozen backbone → 예산별 paired logits·선택 셀 저장 → 오류 전이 분해 → calibration split에서 작은 affine readout 교정. 첫 단계에는 selector나 backbone을 바꾸지 않는다.
5. **Baseline:** 학습 예산의 원래 모델, 다른 예산의 동일 모델, temperature scaling, 작은 affine logit 교정, attention/random 선택. CF-ViT 비교는 같은 학습·비용 조건을 확보한 뒤 추가한다.
6. **데이터·지표:** FGVC-Aircraft를 주 대상으로 하고 CUB를 대조 대상으로 계획한다. 정확도, correct→wrong·wrong→correct 비율, NLL·ECE, class별 손해, transformer MACs와 실제 latency를 별도로 보고한다.
7. **필수 ablation:** 셀 예산만 변경, 선택 규칙 고정/변경, class-balanced 교정, 같은 예산에서의 교정 대조, held-out class 전이, 가능하면 두 학습 seed. scalar temperature는 argmax를 바꾸지 않으므로 정확도 회복 baseline으로 해석하지 않는다.
8. **실패 모드:** 다른 예산이 다른 위치의 토큰을 노출하므로 정보와 readout을 완전히 분리하기 어렵다. 좌표·토큰 수를 기록하고 selector 고정 실험과 함께 해석한다.
9. **Negative result:** affine 교정이 효과 없으면 readout으로 충분하다는 가설을 기각한다. 효과가 calibration class에만 남으면 예산 전이 방법으로의 일반화를 주장하지 않는다.
10. **Novelty 위험·방어:** resolution mismatch·FlexiViT·dynamic inference와 중복 위험이 크다. 새 gate 자체는 기여가 아니다. 기존 연구에 동일한 오류 전이·교정 결과가 있으면 KILL하고, 없을 때만 재현 가능한 실패 경계에 집중한다.
11. **4~8주 MVP:** 1주 구현·배포 가능성 확인, 2주 paired sweep와 GO/KILL, 3~4주 calibration 대조, 5~6주 두 번째 데이터셋·seed, 7~8주 통계와 정리. 공식 checkpoint 미확보 시 자체 재구현임을 명시하고 학습비를 먼저 측정한다.
12. **기여 3개:** 예산 변경 오류 전이 taxonomy; readout 교정의 회복 가능 범위; 평균 정확도·최악 class 손해·실제 비용을 함께 보는 평가 protocol.
13. **제목 2개:** *More Tokens, New Mistakes: Auditing Budget Transfer in Foveated Vision*; *When Inference Budgets Outgrow the Readout*.
14. **Abstract 개요:** 예산 유연성의 실용성 → 비대칭 오류 진단 → 최소 교정 대조 → 회복·실패 경계.
15. **Introduction 흐름:** adaptive vision의 필요 → 예산 전이의 암묵적 가정 → 이미 알려진 비단조성 → 표본별 설명과 교정 가능성이라는 후속 질문.
16. **Related Work:** foveated vision; resolution/budget transfer; dynamic inference; calibration와 readout adaptation.
17. **Method:** 예산별 출력 정렬 → paired 오류 분해 → source calibration → held-out 전이 평가.
18. **표·그림 계획:** 예산×정확도 표, correct/wrong 전이 Sankey 또는 행렬, class별 이득·손해 plot, 교정 전후 곡선, MACs·latency 별도 표.

**첫 실험:** 동일 FoVT 설정의 한 checkpoint로 FGVC-Aircraft held-out에서 최대 500개 이미지를 class 균형 추출할 계획이다. calibration 데이터는 별도 분리한다. P1의 K=64 학습 설정을 기준으로 K=32/64/128만 바꾸고 paired logits를 저장한다. 공식 weight를 확보하지 못하면 첫 1~2주는 가설 검증이 아니라 구현 feasibility 단계로 보고하며 결과를 만들지 않는다.

**GO/KILL:** 두 seed 또는 독립 재실행에서 오류 전이 패턴이 유지되고, held-out에서 affine 교정의 회복이 동일 예산 대조보다 크며 class 손해로만 설명되지 않으면 GO. 학습 noise·selector 변경·한 class의 표본 편향으로 설명되거나 기존 연구와 동일하면 KILL. image 단위 bootstrap 95% CI와 class 단위 민감도 분석을 함께 보고한다. CI가 넓으면 미결이다.

## 4. Proposal B — Evidence Clock Audit

1. **문제·가치:** temporal perception의 confidence가 반복 횟수와 함께 높아져도 새 증거가 늘어난 것은 아닐 수 있다.
2. **Gap:** P2는 이미 novelty-gated evidence를 도입한다. 추가 질문은 gate를 통과한 인접 관측의 상관이 confidence와 유령 keypoint의 수명에 얼마나 남는지다. P3는 history 구성과 clean 기준의 중요성을 보조한다.
3. **가설:** resampling 비율이 같아도 시점 변화가 작은 scan들은 잔여 상관을 가지며, 독립성에 기대는 sequential confidence를 과도하게 높일 수 있다.
4. **구조:** 고정 keypoint detector → scan/voxel lineage → hit·miss·no-evidence 기록 → scan 간 상관 감사 → 필요할 때만 시간 블록당 evidence update를 제한하는 최소 규칙.
5. **Baseline:** 모든 scan 누적, novelty gate, 일정 간격 subsampling, 제안 block update. detector·association·threshold는 고정하고 변화가 필요하면 별도 ablation으로 분리한다.
6. **데이터·지표:** SemanticKITTI의 sequence 단위 분리로 시작한다. keypoint repeatability, 수용까지 걸린 시간, departed object 이후 track 수명, confidence calibration, false persistent keypoint 비율, scan latency를 평가한다.
7. **Ablation:** 정확한 scan 복제, 실제 인접 scan, 시간 간격 확대, pose 고정/변경, GT pose와 추정 pose, novelty 기준 고정, 지상·동적 제거 모듈 고정. 복제는 unit sanity check이며 핵심 실험은 실제 재관측이다.
8. **실패 모드:** pose 오차와 association 실패가 관측 상관처럼 보일 수 있다. GT pose 대조와 track lineage 검수가 필요하다.
9. **Negative result:** 원래 gate가 calibration까지 안정화하면 상관 문제 가설을 기각한다. 추가 gate가 recall이나 수용 지연만 악화하면 개입은 폐기한다.
10. **Novelty·방어:** SLAM·occupancy filtering의 correlated evidence 연구와 강하게 겹친다. 반복을 세지 말자는 주장만으로 논문이 되지 않는다. novelty gate 이후에도 남는 특정 실패 조건과 실제 trade-off가 있어야 한다.
11. **4~8주 MVP:** 1주 데이터·구현 확보, 2주 실제 재관측 audit, 3~4주 pose·association 대조, 5~6주 최소 개입과 다른 sequence, 7~8주 센서 전이 검토. GeLiFiSH 코드가 없으면 명시적인 최소 재구현으로 진행한다.
12. **기여 3개:** lineage 기반 evidence clock; 잔여 상관과 confidence 오차의 조건별 지도; false persistence와 지연 사이의 교정 경계.
13. **제목 2개:** *Counting Scans or Counting Evidence?*; *Residual Dependence after Novelty Gating in LiDAR Perception*.
14. **Abstract 개요:** 관측 누적의 독립성 가정 → gate 이후 상관 분석 → 최소 갱신 규칙 → 안정성과 지연의 경계.
15. **Introduction:** temporal fusion의 이득 → 중복 억제의 발전 → 재관측과 독립성의 차이 → 검증 가능한 감사.
16. **Related Work:** recursive keypoints; sequential tests; occupancy evidence; correlated sensor fusion; moving-object segmentation.
17. **Method:** scan lineage → novelty와 visibility 기록 → 조건부 calibration → block update.
18. **표·그림:** 관측 간격별 calibration 표, false track 수명 곡선, pose 오차 대조, 수용 지연–repeatability frontier, 동일 장소 재관측 시각화.

**첫 실험·GO/KILL:** SemanticKITTI에서 최소 재구현이 처리 가능한 두 개의 분리된 짧은 연속 구간을 사용하고 각 구간 최대 300 scan을 계획한다. 한 구간으로 규칙을 정하고 다른 구간에서 검증한다. 300 scan을 독립 표본 300개로 세지 않는다. 실제 인접 scan에서 novelty 조건을 통제해도 confidence 과대추정이 남고, block update가 동일 keypoint 수 또는 동일 수용 지연에서 이를 줄이면 GO. 복제 scan에서만 문제가 보이거나 pose·association으로 전부 설명되면 KILL. 두 구간만으로 센서 일반화를 주장하지 않는다.

## 5. Proposal C — Chart Evidence Interface Audit

1. **문제·가치:** 해도 VLM에 증거를 추가해 좋아진 결과가 해도 정보를 이해한 것인지, 읽기 쉬운 형식으로 답 단서를 전달받은 것인지 구분해야 한다.
2. **Gap:** P4의 evidence intervention을 반복하지 않는다. 같은 사실을 원래 기호·중립 overlay·구조화 텍스트로 전달할 때 downstream 판단이 달라지는지를 본다. P5는 표현 인터페이스의 중요성을 시사하지만 이 가설의 직접 증거는 아니다.
3. **가설:** 정답 사실 집합을 고정해도 표현 형식이 판단을 크게 바꿀 수 있으며, 일부 이득은 새로운 reasoning보다 symbol-to-language interface의 부담 감소로 설명될 수 있다.
4. **구조:** chart feature ID·속성·관계의 검수된 record → 세 가지 렌더러 → frozen VLM → 중간 사실 응답과 최종 관계 응답의 일관성 검사. 새 생성 모델은 학습하지 않는다.
5. **Baseline:** 원본 crop, 원본+중립 overlay, 원본+동일 사실 텍스트, 길이 일치 무관 텍스트, text-only, 정답을 포함하지 않는 질문. oracle 사실은 진단 상한이며 deployable 입력과 분리한다.
6. **데이터·지표:** ENC-QA 공개 시 해당 protocol을 사용한다. 미공개 상태의 MVP는 합법적으로 확보한 NOAA ENC에서 별도 pilot을 만들며 ENC-QA 재현이라 부르지 않는다. symbol·direction·topology 정답률, 중간–최종 일관성, 형식별 paired 정확도 차이, token·latency를 평가한다.
7. **Ablation:** 사실 개수·좌표 정밀도·답변 길이 고정, entity ID 익명화, rendering scale, overlay 색상, 질문 paraphrase, text-only 대조. 서로 다른 chart cell·지역을 calibration/test로 나눈다.
8. **실패 모드:** 텍스트가 관계 정답을 직접 말하거나 overlay가 답을 암시할 수 있다. 완성된 관계나 최종 중요도 label을 주지 않고 primitive 사실만 제공하며 독립 검수한다.
9. **Negative result:** 표현 차이가 작으면 interface bottleneck 가설을 기각한다. 차이가 text-only shortcut으로만 설명되면 multimodal reasoning 개선 주장을 철회한다.
10. **Novelty·방어:** modality substitution·visual prompting·OCR assistance와 중복 위험이 높다. prior gaze 정렬 audit와 달리 위치 정렬의 타당성을 평가하지 않는다. 동일 의미·동일 정보량이라는 통제가 성립해야 하며 선행 연구와 겹치면 중단한다.
11. **4~8주 MVP:** 1주 자료 권한·렌더링 확인, 2주 검수 pilot와 GO/KILL, 3~4주 지역 분리·대조, 5~6주 두 번째 VLM, 7~8주 공개 protocol과 사례 정리. 자료 구성이 안 되면 실행 가능성 실패로 기록한다.
12. **기여 3개:** 의미를 고정한 표현 형식 감사; perception–interface–decision 오류 분해; shortcut과 실질 회복을 구분하는 chart pilot.
13. **제목 2개:** *Same Facts, Different Charts: Auditing VLM Evidence Interfaces*; *Does Chart Reasoning Improve, or Does the Interface Get Easier?*
14. **Abstract 개요:** 증거 제공 이득의 모호성 → 동일 사실 형식 대조 → interface 영향·shortcut 진단 → 적용 범위.
15. **Introduction:** 해도 이해의 복합성 → 단계별 평가 → 증거 형식이라는 혼재 변수 → 통제 실험.
16. **Related Work:** chart/geospatial VQA; visual prompting; structured evidence; modality shortcuts; multimodal representations.
17. **Method:** fact record → 의미 보존 검수 → 렌더링 개입 → 지역 분리 평가 → 오류 분해.
18. **표·그림:** 형식×task 표, 중간 사실/최종 판단 2×2 표, 지역별 전이, text-only 대조, 동일 record의 세 가지 표현 그림.

**첫 실험·GO/KILL:** Qwen3-VL-8B 계열의 가용 공개 checkpoint 하나를 검증한 뒤, 최대 100개 서로 다른 chart crop의 pilot을 계획한다. 정답은 전문가 중요도 판단이 필요한 항해 안전 조언 대신 기호·방향·topology처럼 record로 검증 가능한 항목으로 제한한다. 같은 crop에서 사실 record를 고정하고 세 표현만 바꾼다. 형식 효과가 별도 지역에서 재현되고 무관 텍스트·답 누설 대조로 설명되지 않으면 GO. 의미 동등성을 검수할 수 없거나 text-only shortcut만 남으면 KILL. crop이 겹치는 질문들은 chart cell 단위로 묶어 bootstrap하며 해상도·token 상한을 고정한다.

## 6. 평가와 이번 주 우선순위

다음 점수는 평가자의 판단이며 실측치나 게재 확률이 아니다. **Compute cost는 1이 가볍고 5가 무겁다.**

| 후보 | Novelty /5 | Feasibility /5 | Compute cost /5 | Publication potential /5 |
|---|---:|---:|---:|---:|
| A — Budget Change Error Asymmetry | 3 | 3 | 3 | 3 |
| B — Evidence Clock Audit | 3 | 3 | 2 | 3 |
| C — Chart Evidence Interface Audit | 3 | 2 | 2 | 3 |

**이번 주 1순위는 A다.** P1에 명시된 재현 가능한 관찰에서 출발하며, budget만 바꾸는 paired 설계가 명확하고 기존 분류 연구 경험을 활용할 수 있다. 다만 공식 checkpoint 미확인이 핵심 실행 위험이다. 첫 3일에 checkpoint·구현·데이터 조건과 선행 연구 중복을 먼저 확인한다. 사용할 구현이 없고 2주 내 준비가 어렵다면 새 학습을 무리하게 시작하지 않고 A의 feasibility를 보류한다.

A는 이전 video 탐색의 Acquire-or-Read와 문제 공간이 다르다. 새 controller 개발보다 동일 모델의 토큰 예산 변경이 만드는 오류와 readout 회복 한계를 먼저 측정한다. 둘 사이의 개념적 연관은 인정하되 새로움으로 과장하지 않는다.

작은 GPU 의존성을 줄일 후보는 B의 학습 없는 짧은 sequence 감사다. C는 inference compute보다 자료 확보와 의미 동등성 검수 비용이 병목이다. 장기 연구는 B를 여러 temporal perception 시스템의 evidence accounting으로 확장할 수 있지만, LiDAR pilot만으로 VLM까지 일반화됐다고 주장하지 않는다.

어느 후보든 1~2주 판단은 GO·KILL·미결 중 하나로 기록한다. 구현 미확보와 데이터 부족은 과학적 가설의 반증과 구분한다. 실제 GPU 시간·VRAM·latency는 실행 후 계측한다.
