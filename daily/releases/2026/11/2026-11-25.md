## 1. Supervision 0.32.1 — evaluator와 split 변경을 model gain과 분리

**정확한 artifact.** [공식 tag](https://github.com/roboflow/supervision/releases/tag/0.32.1)는 commit `16f61cb90fd543401bfaa556b9ec24a951467c4d`를 가리킨다. 발행 시각은 11월 24일 19:31:30 KST다. 19일 보고의 0.32.0과 다른 실제 배포다. [고정 pyproject](https://github.com/roboflow/supervision/blob/16f61cb90fd543401bfaa556b9ec24a951467c4d/pyproject.toml)상 MIT·Python ≥3.10이다. 새 model weight나 학습 data를 배포한 사건은 아니다.

**사실 — 평가 계약.** [고정 detection.py](https://github.com/roboflow/supervision/blob/16f61cb90fd543401bfaa556b9ec24a951467c4d/src/supervision/metrics/detection.py)의 `ConfusionMatrix.plot(normalize=True)`는 열 합 대신 행 합으로 나눈다. ground-truth class 행의 대각값은 recall 해석을 갖고, unmatched prediction 행은 별도로 읽어야 한다. 양수인 작은 share는 heatmap에 남기고 숫자 표기 cutoff와 구분한다. raw matching count 전체가 개선됐다는 뜻은 아니다.

[고정 mAR 구현](https://github.com/roboflow/supervision/blob/16f61cb90fd543401bfaa556b9ec24a951467c4d/src/supervision/metrics/mean_average_recall.py)은 target이 없는 전체 평가·크기 bucket의 undefined recall을 `0` 대신 `-1`로 표시한다. 이를 실제 실패 점수나 일반 음수 성능으로 평균내면 안 된다. 반대로 target은 있지만 맞힌 prediction이 없는 실제 0 recall은 유지되어야 한다.

**사실 — 분할 계약.** [고정 split helper](https://github.com/roboflow/supervision/blob/16f61cb90fd543401bfaa556b9ec24a951467c4d/src/supervision/dataset/utils.py)의 `_train_split_index`는 decimal 문자열의 정확한 곱과 기존 floating-point 곱의 floor 중 큰 값을 사용한다. 단순히 모든 비율을 반올림하는 변경이 아니다. NumPy scalar의 decimal 처리도 추가됐다. release가 제시하는 90개·0.7 예시는 62/28에서 63/27로 바뀐다. 이는 공식 예시이며 이번 실행의 실측이 아니다. 같은 seed라도 version이 다르면 split identity가 달라질 수 있다.

**저자 주장·활동의 한계.** [PR #3058](https://github.com/roboflow/supervision/pull/3058)은 11월 24일 10:01:06 UTC merge됐고, BGRA·small-share plot·NumPy ratio 등 후속 경계를 수정했다. 저자는 regression test와 suite 통과를 보고하지만, 해당 검증 환경에는 OpenCV가 없어 관련 경로는 NumPy fallback에서 검사했다고 명시한다. Windows/OpenCV 검증 완료로 확대하지 않는다. release의 호환성 설명과 실제 반환값·split 변화는 별도로 평가해야 한다.

**설치·자원·무결성.** pin 후보는 `supervision==0.32.1`이다. NumPy ≥1.21.2·SciPy ≥1.10·Matplotlib ≥3.6 등의 범위 의존성이 있어 package pin은 전체 환경 lock이 아니다. evaluator·manifest fixture에는 GPU/VRAM이 필요 없다. BGRA 검사는 OpenCV 유무와 backend도 기록해야 한다. [공식 PyPI metadata](https://pypi.org/pypi/supervision/0.32.1/json)의 wheel SHA256은 `03a2910420aeb93fa06858c122adde030d60db25732914cdae9433bcc6987094`다. 업로드는 11월 24일 10:32:14 UTC이며 다운로드 검산은 미실행이다.

**추론 — 진단 → 가설 → 최소 실험, 10~30분 계획.**

1. 고정 prediction과 GT로 0.32.0/0.32.1의 raw confusion count를 먼저 비교한다. 비대칭 클래스 혼동·빈 행·FP/FN을 포함하고, 정규화 행 합과 plotted diagonal을 따로 확인한다.
2. target 없음, target 있음·prediction 없음, 빈 size bucket을 분리한다. undefined sentinel과 실제 0을 구분하고, 사용자 집계 코드의 분모·제외 규칙을 기록한다.
3. 같은 정렬 입력·seed·ratio로 split ID 목록을 비교한다. 90×0.7, 계산된 1/3, NumPy float16 비율을 포함한다. 모델을 다시 학습하기 전에 manifest를 고정한다.

**GO:** CPU 평가·manifest audit부터 진행한다. **KILL:** plot 값이나 undefined bucket 처리로 생긴 차이를 representation 향상으로 해석하지 않는다. 재분할 전후 수치를 같은 benchmark 비교로 쓰면 **not strictly apples-to-apples**다.

## 2. Transformers v5.24.1 — forward 복구와 image feature 계약은 별개

**정확한 artifact.** [공식 release](https://github.com/huggingface/transformers/releases/tag/v5.24.1)는 11월 25일 01:13:08 KST 발행됐다. annotated tag object `4f1aa904d924ba2deb090185ba5a6c0cf550e56e`는 commit `e68083bdf4035ba6d75976a3b7ce15c98a61f278`로 해석된다. tag API의 signature verification은 false다. 이를 악성·손상 증거로 해석하지 않는다. 23일 보고의 v5.24.0과 구분한다.

**사실 — Llama4 출력 연결.** [tag 간 코드 차이](https://github.com/huggingface/transformers/compare/v5.24.0...v5.24.1)에서 Llama4 wrapper가 text-model 출력의 `outputs.image_outputs`를 읽던 부분을 `mm_encoder_outputs.get("image")`로 바꾼다. deprecated `image_hidden_states` property에는 `image_outputs is None` guard가 추가된다. 새 encoder나 checkpoint가 아니라, 이미 계산된 vision output을 반환 객체에 연결하는 수정이다.

**저자 주장·남은 간극.** [PR #51144](https://github.com/huggingface/transformers/pull/51144)는 11월 24일 13:24:31 UTC merge됐다. release branch에는 13:56:58 UTC의 별도 commit으로 포함됐다. 저자는 이전 wrapper가 text-only와 multimodal forward에서 누락 attribute로 실패한다고 설명한다. 동시에 vision tower가 `pooler_output`을 채우지 않아 deprecated image feature property가 이미지 입력에서도 `None`을 반환할 수 있다는 잔여 문제를 명시한다. 고정 코드도 그 property가 `pooler_output`을 읽는 구조다. **forward가 성공하는 것과 과거 feature extraction API가 같은 tensor를 반환하는 것은 다른 검증 항목**이다.

**사실 — cache 호환성.** 같은 patch는 legacy cache 필드를 직접 선언한 remote-code output dataclass의 생성·조회 계약을 보존한다. 일부 decoder에는 deprecated `past_key_values`를 introspection signature에 노출한다. 호출자가 signature로 kwargs를 거르면 decorator가 옛 이름을 수용하는 것만으로는 충분하지 않기 때문이다. deprecated `modeling_attn_mask_utils`도 복원한다. 이를 모든 remote-code model에 대한 호환성 보장으로 확대하지 않는다.

Dory에는 read-only cache 경로와 static/dynamic parity test가 포함된다. 공식 test는 작은 config와 chunked input으로 두 cache mode를 비교한다. 이러한 fixture의 존재는 공개 checkpoint의 장문 품질·속도 향상을 독립 검증했다는 뜻이 아니다.

**설치·자원·무결성·활동.** code license는 Apache 2.0이다. [고정 setup.py](https://github.com/huggingface/transformers/blob/e68083bdf4035ba6d75976a3b7ce15c98a61f278/setup.py)는 torch ≥2.6, tokenizers ≥0.23.1,<0.24.0, huggingface-hub ≥1.31.0,<3.0 범위를 안내한다. pin 후보는 `transformers==5.24.1`이며 image processor·torchvision 등 실제 사용 경로의 의존성을 별도로 고정해야 한다. 새 model weights/data는 이 package release의 검증 대상에 포함되지 않으며, 사용하는 checkpoint의 license·접근 조건은 별도다.

작은 random-config 출력·cache fixture는 CPU를 우선할 수 있어 GPU VRAM은 필요하지 않다. full Llama4 checkpoint의 최소 VRAM은 확인하지 않았다. [PyPI metadata](https://pypi.org/pypi/transformers/5.24.1/json)의 wheel SHA256은 `505b39d3e45a3715f3acb81b858eb245ce1a462373b7f99e26f0dcd41ed4cd0f`다. wheel 업로드는 11월 24일 16:11:43 UTC로 GitHub release 발행보다 앞선다. 두 시각을 동일시하지 않는다. PR merge·release 반영은 확인했지만 사용자 환경에서 모든 residual이 해결됐다고 주장하지 않는다.

**추론 — 진단 → 가설 → 최소 실험, 10~30분 계획.**

1. 같은 seed·작은 random Llama4 config·CPU FP32·batch 1로 text-only와 image forward를 나눈다. crash 여부, 새 `image_outputs`의 존재·내용, deprecated property 값을 각각 검사한다.
2. encoder 출력은 있지만 old property가 비어 있다면 representation 손실 대신 반환 경로 문제라는 가설을 우선한다. full checkpoint 다운로드보다 tensor shape·field routing fixture부터 검증한다.
3. legacy field를 가진 작은 output dataclass와 signature로 kwargs를 거르는 caller를 만들어 cache 전달이 보존되는지 확인한다. 이어 Dory의 같은 weight·token·loop 수에서 static/dynamic logits와 cache length를 비교한다.

**GO:** 반환 계약과 cache 전달 fixture부터 진행한다. **KILL:** forward 성공만으로 image feature 호환성·시각 능력·논문 점수 재현을 선언하지 않는다. checkpoint·precision·backend·cache 정책이 다른 품질·속도 비교는 **not strictly apples-to-apples**다.
