## Roboflow Supervision

- **사실:** 공식 PR 목록에 YOLO segmentation compact-mask loading, bit-packed dense-mask overlap counting, DetectionDataset empty/add 변경 PR이 11/05에 열렸다.
- **진단:** compact decode가 thin/small/overlap-heavy sample의 area·IoU 경계 조건을 바꿀 수 있다.
- **최소 audit:** 원본 polygon/RLE와 decode의 image별 instance count, empty-image count, mask area, pairwise overlap, class count, split ID hash 비교.
- **GO/KILL:** instance count 일치와 사전 정의 area/IoU tolerance 통과 시 GO; class missing/overlap drift 시 KILL.
- https://github.com/roboflow/supervision/pulls

## HumanSignal Label Studio / SDK

- **사실:** Label Studio와 SDK가 11/05에 update됐고 standardized output format annotation tool로 설명된다.
- **확인되지 않음:** project taxonomy, guideline, export schema, correction diff.
- **최소 audit:** tool/SDK version, export JSON schema hash, task/annotation/label count, annotator metadata presence manifest.
- **GO/KILL:** raw export+설명 가능한 diff면 GO; schema revision 없이 label count가 변하면 KILL.
- https://github.com/humansignal
- https://github.com/HumanSignal/label-studio

## Hugging Face dataset-viewer

- **사실:** official organization은 dataset-viewer를 dataset page의 public API backend로 설명하고 11/05 update를 표시한다.
- **확인되지 않음:** 특정 CV dataset revision, split, license, row 변경.
- **최소 audit:** revision/config/split/row count/features schema/license/sampled-row hash manifest.
- **GO/KILL:** immutable revision pin 시 GO; main만 기록하거나 license/revision이 비면 KILL.
- https://github.com/orgs/huggingface/repositories?type=all
- https://github.com/huggingface/dataset-viewer
