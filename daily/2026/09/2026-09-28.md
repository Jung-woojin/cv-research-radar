## 전체 트렌드
- Encoder-free MLLM이 가능성 논의에서 compute-optimal scaling 분석으로 이동.
- Synthetic object-centric data가 detection/segmentation/grounding supervision을 통합.
- UAV vision의 ground-view pretrained depth domain gap이 독립 benchmark가 됨.
- Panoramic/4D perception은 더 넓은 시야보다 supervision/action design이 중요.
- VLA는 unseen-task failure detection을 별도 문제로 분리.

## 핵심 연구
### How Far Are We from Removing the Visual Encoder? Scaling Laws for Encoder-Free Multimodal Pretraining
Raw pixel에서 직접 multimodal representation을 학습하는 encoder-free MLLM의 scaling law를 비교한다. Visual encoder 제거 시 multimodal objective의 compute-optimal allocation이 더 큰 model 쪽으로 이동한다는 결과가 핵심이다.
Source: https://huggingface.co/papers/2609.35457

### SOS: Synthetic Object Segments Improve Detection, Segmentation, and Grounding
Object-centric composition, structured layout prior, generative relighting으로 mask/box/referring expression을 함께 합성한다. 100K synthetic images로 LVIS detection +10.9 AP, gRefCOCO grounding +8.4 N_Acc를 보고. Generator fingerprint와 cross-domain 통제가 중요하다.
Source: https://huggingface.co/papers?q=LVIS+detection

### AerialMetric: Benchmarking and Adapting UAV Monocular Metric Depth Estimation in the Real World
52K real + 16K synthetic image-depth pairs로 UAV viewpoint의 metric-depth domain gap을 평가한다. Photogrammetry, controlled acquisition, synthetic, in-the-wild를 함께 포함.
Source: https://huggingface.co/papers?q=aerial+benchmark

### PanoVLN: Towards Effective Panoramic Vision-and-Language Navigation
Panorama 입력만으로는 gain이 제한적이라는 진단 후 longer-horizon action prediction, branching-route supervision, semantic+geometric representation을 결합. 4B RGB-only에서 R2R-CE/RxR-CE Val-Unseen SR 개선을 보고.
Source: https://huggingface.co/papers/2609.34759

### SAFE: Multitask Failure Detection for Vision-Language-Action Models
Generalist VLA의 unseen task/environment failure를 조기에 감지하는 multitask failure detection을 정의한다.
Source: https://huggingface.co/papers?q=failure+detector

### Describe Anything Anywhere At Any Moment
Localized captioning을 이용한 large-scale real-time 4D semantic memory로 geometry와 open-vocabulary description을 함께 유지.
Source: https://huggingface.co/papers?q=OC-NaVQA+benchmark

### InstaGeo: Compute-Efficient Geospatial Machine Learning from Data to Deployment
Raw satellite imagery curation → task distillation → web-map deployment까지 연결하는 geospatial ML framework.
Source: https://huggingface.co/papers?q=crop+segmentation

3. Aerial/robotics에서 viewpoint·action·failure가 독립 benchmark 축으로 분화.
