## 1. 30,000시간 world-model scaling — agent는 배우지만 물체 상호작용은 낮은 ceiling에서 포화

**공식 원문:** [What 30,000 Hours of Ego-centric Video Does Not Teach](https://arxiv.org/abs/2610.12464)  
**모델·데이터·구성:** Cosmos 3 계열 Edge·Nano·Super, 300/1k/3k/10k/30k 시간의 nested egocentric corpus, 150개 OOD 평가 clip, agent/object SCS와 LPIPS  
**공식 인정:** 저자들이 제목·본문·ablation에서 직접 negative scaling result를 보고했다. 코드·checkpoint·평가 benchmark는 공개 예정으로 기술됐으며 이번 실행 시 독립 재현은 확인하지 못했다.

### 실패 조건과 재현 근거

**확인된 사실:** Skeleton conditioning을 사용해 agent fidelity를 조기에 포화시킨 조건에서 object SCS는 300→3k 시간에 0.056, 3k→30k 시간에 0.035만 증가했다. 저자들의 saturation fit은 object asymptote를 0.565로 추정했고, 30k 시간 모델이 이미 그 93%에 도달했다고 보고했다. metric이 측정할 수 있는 범위로 정규화하면 agent는 86%, object는 63% 수준에 수렴했다.

**확인된 사실:** 모델 크기를 4배 늘렸을 때 object ceiling은 0.034 SCS 상승했다. 저자 계산대로 남은 agent-object gap 0.205를 같은 증가율로 메우려면 약 6회의 추가 4배 확장, 즉 대략 네 자릿수 배의 parameter 증가가 필요하다. 이 계산은 증가율이 감소하지 않는다는 낙관적 가정을 둔다.

**확인된 사실:** 기존 interaction-focused PhysisForcing 재구현은 10k 시간 조건에서 skeleton baseline object SCS `0.513±0.004`에 대해 `0.515±0.005`로 사실상 겹쳤다. 저자들의 dynamic-noise 방식은 `0.526±0.004`였고, 30k 시간에는 baseline 0.527 대비 0.546으로 올랐지만 agent 수준과의 큰 차이는 남았다.

### 의심 메커니즘

**저자 주장:** pixel prediction loss는 면적이 크고 예측하기 쉬운 배경과 agent appearance에 학습 용량을 우선 배분한다. 접촉 순간 작고 가려지는 물체는 causal importance에 비해 loss 비중이 낮다.

**추론:** 데이터 부족보다 objective allocation의 문제다. 해양 world model에서도 화면 대부분을 차지하는 물·하늘·카메라 운동을 잘 재현하면서 작은 선박의 충돌·가림·상태 변화는 틀릴 수 있다.

### 기존 주장과 충돌

“더 많은 egocentric video와 더 큰 모델이면 물리적 상호작용도 계속 좋아진다”는 단순 scaling 기대와 충돌한다. 다만 Edge와 Nano는 architecture뿐 아니라 사전학습도 달라 capacity 효과로만 해석하면 **not strictly apples-to-apples**다. Super 학습 비용 때문에 모든 conditioning 조합이 평가되지 않은 점도 남는다.

### 가설 → 최소 개입 → 실험

**가설:** 전체-frame reconstruction loss보다 small dynamic object와 contact region을 별도 가중한 loss가 데이터 10배 확대보다 object fidelity에 효율적이다.

**최소 개입:** 기존 checkpoint와 동일 데이터에서 손·도구·조작 물체 mask 주변 latent loss만 2배 가중한다. 새 architecture는 추가하지 않는다.

**검증 실험:**

1. agent SCS, object SCS, LPIPS를 따로 기록한다.
2. small/large object와 occluded/unoccluded contact subset을 분리한다.
3. uniform loss, ROI reweighting, dynamic-noise를 동일 training step·seed로 비교한다.
4. object SCS 상승이 agent SCS·LPIPS 손실과 맞바뀌는지 Pareto curve를 그린다.

**GO:** 세 seed에서 object SCS가 동일 compute의 uniform baseline보다 높고, agent SCS 하락이 0.01 이내다.  
**KILL/수정:** oracle object mask를 써도 개선이 없으면 loss allocation보다 latent representation과 temporal correspondence를 먼저 바꾼다.

**점수:** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 2. 산업 이상 이해 — in-domain 학습과 multi-agent 투표가 공유된 미세 지각 오류를 못 고침

**공식 원문:** [Is In-Domain Training Enough for Fine-Grained Industrial Anomaly Understanding?](https://arxiv.org/abs/2610.12310)  
**모델·데이터·구성:** MMAD, 10개 compact MLLM, OmniAD·JUDO 등 학습형 specialist, Qwen 계열·Gemini 계열, SiGMA multi-agent + defect expert  
**공식 인정:** 저자들이 in-domain 학습의 역효과, 모델 간 공유 localization failure, raw anomaly overlay의 false-positive 증가를 직접 보고했다. 독립 community reproduction과 공식 code release는 확인하지 못했다.

### 실패 조건과 재현 근거

**확인된 사실:** 학습형 모델의 최고 defect localization은 75.5%였고 human expert는 92.3%였다. OmniAD와 JUDO의 anomaly detection은 각각 68.8%, 65.0%로, 두 모델의 frozen base인 Qwen2.5-VL-7B 70.5%보다 낮았다.

**확인된 사실:** 10개 compact MLLM의 defect localization 평균은 55.94%였다. Qwen3-VL 계열에서는 8B가 60.8%로 4B의 63.6%보다 낮았고, Gemini-2.5-Pro도 67.2%에 그쳤다. 크기와 범용 reasoning 능력이 미세 결함 위치 추정으로 곧바로 이어지지 않았다.

**확인된 사실:** best single MLLM에 retrieval을 붙이면 anomaly detection/localization은 74.1/63.6에서 74.3/64.8로 변했다. heterogeneous majority vote까지 추가해도 74.7/65.4였다. 반면 독립 defect expert를 넣으면 80.5/73.6, reliability controller까지 넣으면 82.6/79.6이 됐다. 여러 MLLM이 같은 지각 오류를 공유하면 투표만으로 복구하기 어렵다는 결과다.

**확인된 사실:** raw anomaly map을 입력에 overlay하면 localization은 65.8→75.0으로 올랐지만 anomaly detection은 75.1→69.8로 떨어지고 normal image false-positive rate는 17.8→30.6으로 증가했다. 공간 단서가 강해도 정상 변이를 defect처럼 보이게 만들 수 있다.

### 의심 메커니즘

**저자 주장:** in-domain 학습은 domain 표현과 reasoning을 개선하지만, fine-grained perception의 공통 약점은 남는다. 독립적인 reference-based defect expert와 calibration이 필요하다.

**추론:** “전문 지식을 더 학습”하는 것과 “작은 결함을 더 잘 본다”는 서로 다른 문제다. 해무·선박 imagery에서도 language-tuned VLM ensemble은 같은 작은 객체를 모두 놓칠 수 있고, uncalibrated heatmap은 파도·반사·센서 노이즈를 결함으로 확대할 수 있다.

### 기존 주장과 충돌

“in-domain SFT/RL이면 범용 MLLM의 산업 지각도 함께 좋아진다”, “여러 agent를 합치면 약점이 평균화된다”는 기대와 충돌한다. 단, SiGMA는 최대 8개 base agent와 3개 reader, 256장 normal bank를 사용하며 peak memory 105 GiB를 4×L20에서 보고했다. single 7B 15.2 GiB와 실행 조건이 달라 정확도·비용 비교는 **not strictly apples-to-apples**다. controller 통계도 전체 unlabeled evaluation batch에서 추정하는 transductive 설정이다.

### 가설 → 최소 개입 → 실험

**가설:** 여러 VLM의 수를 늘리는 것보다 독립 low-level anomaly detector 하나와 정상 변이 calibration을 추가하는 편이 small-defect recall과 FPR을 더 잘 개선한다.

**최소 개입:** 기존 VLM 한 개를 고정하고 `VLM only`, `raw anomaly overlay`, `normal-bank calibrated score`만 비교한다.

**검증 실험:**

1. anomaly detection, pixel/region localization, normal FPR을 동시에 기록한다.
2. normal bank를 1/16/64장으로 바꾸되 calibration 방법을 고정한다.
3. 파도·반사·안개·압축 artifact를 정상 hard negative로 분리한다.
4. 동일 evaluation query를 하나씩 처리해 transductive batch 통계 없이도 성능을 확인한다.

**GO:** calibrated score가 raw overlay보다 localization을 유지하면서 normal FPR을 절반 가까이 줄이고, scene-level OOD에서도 같은 방향을 보인다.  
**KILL/수정:** normal bank 크기나 촬영 조건 변화에 따라 FPR이 크게 흔들리면 VLM 결합 전에 anomaly representation 자체를 재설계한다.

**점수:** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 3. Modifier grounding — attention은 “어느 객체인가”를 안정적으로 설명하지 못하고 정보도 token 하나에 있지 않음

**공식 원문:** [From What to Which: Decoding Modifier Grounding in Frozen MLLMs](https://arxiv.org/abs/2610.12305)  
**모델·데이터·구성:** frozen Qwen2.5-VL, RefCOCO 기반 2,500장 probe 학습, RefCOCO-MOD, COCO Caption·OpenPSG·RefCOCOg transfer, token-level noun/attribute/spatial/relation grounding  
**공식 인정:** 저자들이 attention baseline의 약점, noun/modifier 정보 분산, sparse relation sample, OT ablation의 구조적 confound를 직접 적었다. 독립 재현과 공식 code release는 확인하지 못했다.

### 실패 조건과 재현 근거

**확인된 사실:** deletion AUC에서 spatial token의 attention baseline은 0.147로 random 0.151보다 낮았다. modifier 전체도 attention 0.202로 random 0.182에 조금 앞섰을 뿐이며, semantic 0.320과 OTTER 0.322보다 낮았다. attention weight를 곧바로 faithful grounding으로 읽기 어렵다.

**확인된 사실:** 같은 이미지에서 referent를 바꾼 2,971개 pair에서 modifier target preference는 0.776, contextualized noun은 0.779였다. 엄격한 217개 left/right pair에서는 modifier 0.772, noun 0.795였다. “which” 정보가 modifier에만 있고 noun은 “what”만 담는다는 깔끔한 분리는 관찰되지 않았다.

**확인된 사실:** token-type 분해에서 spatial pair는 2,578개, attribute는 173개였지만 relation/action은 3개뿐이었다. relation/action grounding에 대한 수치는 안정적인 결론을 내릴 근거가 부족하다.

**확인된 사실:** learned OTTER projection의 calibrated mIoU는 0.458이었고 raw cosine 0.130, shuffled projection 0.135였다. frozen representation에 정보가 있다는 것과 그 정보가 native attention이나 cosine으로 바로 읽힌다는 것은 다르다.

### 의심 메커니즘

**저자 주장:** autoregressive contextualization 때문에 instance identity가 noun과 modifier를 포함한 여러 token state에 분산된다. OT의 global assignment와 abstention dustbin이 독립 softmax보다 compact map을 만든다.

**추론:** VLM 설명에서 “왼쪽의 작은 빨간 선박”을 생성했다고 해서 `왼쪽`, `작은`, `빨간` attention을 각각 독립적인 시각 근거로 사용할 수 없다. grounding audit은 phrase 전체와 counterfactual referent switch를 포함해야 한다.

### 기존 주장과 충돌

“modifier token attention이 해당 속성·위치를 직접 가리킨다”는 해석과 충돌한다. 또한 OT가 softmax보다 Soft-IoU를 spatial +0.021, attribute +0.018 높였지만, OT head만 learned dustbin abstention을 갖는다. 따라서 transport operator 단독 효과와 abstention 효과가 묶여 있어 완전히 분리된 비교는 아니다.

### 가설 → 최소 개입 → 실험

**가설:** 작은 선박·부표 grounding에서는 noun-only attention보다 전체 referring phrase의 counterfactual consistency가 hallucination을 더 잘 예측한다.

**최소 개입:** 모델을 학습하지 않고 동일 이미지의 표현에서 `왼쪽↔오른쪽`, `큰↔작은`, 색상 modifier를 바꿔 heatmap이 target instance를 따라 바뀌는지 측정한다.

**검증 실험:**

1. noun, modifier, phrase map의 target preference와 distractor gap을 비교한다.
2. attention, raw cosine, learned lightweight probe를 같은 layer·threshold로 평가한다.
3. modifier를 삭제·교체한 뒤 answer와 grounding이 함께 변하는지 본다.
4. relation/action은 표본이 충분해질 때까지 별도 결론을 보류한다.

**GO:** counterfactual phrase map이 두 scene split에서 noun-only보다 높은 referent-switch consistency를 보이고, 잘못된 answer에서 일관되게 낮아진다.  
**KILL/수정:** map이 바뀌어도 answer가 유지되거나 answer가 바뀌어도 map이 고정되면 explanation이 아니라 diagnostic proxy로만 사용한다.

**점수:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 4. 고정-camera VLA — seen-task 성공률이 큰 viewpoint shift에서 유지되지 않음

**공식 원문:** [VersaCamVLA](https://arxiv.org/abs/2610.12451)  
**모델·데이터·구성:** pretrained `π0.5` VLA와 VersaCamVLA, RoboTwin 2.0·LIBERO·real robot, 4-view matched input, camera azimuth·거리·pitch perturbation  
**공식 인정:** 저자들이 baseline의 viewpoint degradation과 제안법의 calibration-noise 민감도를 공식 ablation으로 보고했다. 독립 community reproduction과 공식 code release는 확인하지 못했다.

### 실패 조건과 재현 근거

**확인된 사실:** RoboTwin 2.0에서 `π0.5`의 평균 success rate는 seen pose 48.88%였다. absolute azimuth offset 0–30°에서는 43.38%, 30–60°에서는 34.13%, 60–90°에서는 30.06%로 떨어졌다. 가장 큰 shift에서 seen pose 대비 18.82%p 하락이다.

**확인된 사실:** 동일 camera configuration을 공유한 matched comparison에서 VersaCamVLA는 seen 53.44%, 세 shift 구간에서 53.25%, 52.13%, 53.38%였다. 이는 고정 2D token interface의 실패가 task 자체보다 camera geometry 미표현과 연결될 가능성을 지지한다.

**확인된 사실:** 제안법도 정확한 intrinsics/extrinsics를 요구한다. extrinsic noise가 clean 0mm/0°에서 52.56%, 20mm/2°에서 52.13%, 50mm/5°에서 50.38%로 감소했다. 평가 범위에서는 완만하지만 calibration-free는 아니다.

**확인된 사실:** LIBERO 평균에서는 `π0.5` 95.8, VersaCamVLA 95.9로 seen configuration의 총점 차이는 0.1%p에 불과했다. camera robustness를 따로 평가하지 않으면 핵심 이득을 일반 task score에서 거의 볼 수 없다.

### 의심 메커니즘

**저자 주장:** standard VLA의 camera token tuple은 학습 때의 view 수와 pose에 결합돼 있다. posed RGB set을 고정 길이 scene token으로 변환하면 action policy의 입력 형식을 안정화할 수 있다.

**추론:** 해양·UAV detector도 camera heading, zoom, mount height가 달라질 때 image appearance shift를 새로운 객체 분포로 오인할 수 있다. augmentation만으로 해결하기보다 camera metadata를 표현에 넣을 필요가 있다.

### 기존 주장과 충돌

“동일 task와 object를 학습했으면 camera를 조금 옮겨도 policy가 유지된다”는 기대와 충돌한다. 그러나 VersaCamVLA는 추가 Stage I scene encoder, camera calibration, posed multi-view 입력을 사용하고 Stage II를 8×H100에서 30,000 step 학습했다. 기본 VLA와 비용·입력이 달라 **not strictly apples-to-apples**이며, mobile·uncalibrated camera는 아직 검증되지 않았다.

### 가설 → 최소 개입 → 실험

**가설:** camera shift 실패의 상당 부분은 appearance augmentation 부족보다 pose-unaware representation에서 발생한다.

**최소 개입:** 기존 모델을 고정하고 camera azimuth·height·zoom metadata를 작은 MLP embedding으로 feature에 더하는 adapter만 학습한다.

**검증 실험:**

1. seen pose와 0–30°/30–60°/60–90°를 분리한다.
2. image-only augmentation, pose metadata adapter, explicit homography normalization을 비교한다.
3. extrinsic noise 0/2/5°와 translation noise 0/20/50mm를 교차한다.
4. 전체 success뿐 아니라 small-object miss, wrong-target action, grasp/place error를 분리한다.

**GO:** pose adapter가 큰 camera shift에서 image-only보다 5%p 이상 높고, 2° calibration noise에서도 이득의 절반 이상을 유지한다.  
**KILL/수정:** pose를 넣어도 개선이 없고 target visibility가 성능을 대부분 설명하면 representation보다 active viewpoint selection 문제로 전환한다.

**점수:** 심각도 4/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 4/5

## 오늘의 실패 패턴 3개

1. **Scale은 objective가 무시하는 영역을 자동으로 구하지 못한다.** 30,000시간과 큰 모델도 작은 조작 물체의 dynamics gap을 남겼다.
2. **공유된 지각 오류는 학습·투표·attention 시각화로 감춰질 수 있다.** MLLM ensemble은 localization을 거의 못 올렸고 raw attention은 spatial grounding에서 random 이하가 됐다.
3. **평균 task score는 deployment shift를 숨긴다.** LIBERO seen score는 비슷했지만 고정-camera VLA는 큰 viewpoint 변화에서 18.82%p 하락했다.

## 논문 아이디어로 연결 가능한 빈틈

가장 직접적인 빈틈은 **pose-aware, failure-calibrated small-object perception protocol**이다.

현재 결과들은 각각 다른 영역을 보지만 같은 구조를 가진다.

- world model은 small dynamic region을 전체 pixel loss가 희석한다.
- industrial VLM은 shared perceptual failure를 여러 agent가 반복한다.
- grounding attention은 어느 instance인지 충실하게 설명하지 못한다.
- fixed-camera model은 camera geometry shift를 견디지 못한다.

이를 해양 영상으로 묶으면 다음 질문이 된다.

> camera pose·zoom·visibility가 바뀌는 해양 영상에서 작은 선박의 detection·grounding·future-state prediction 오류를 하나의 평균 score로 합치지 않고, pose-aware representation과 정상 변이 calibration으로 동시에 줄일 수 있는가?

신규성은 새 backbone 이름보다 **scene-level OOD split → camera shift stress test → phrase-level counterfactual grounding → calibrated small-object expert → interaction fidelity**를 하나의 진단 protocol로 연결하는 데 있다.

## 직접 재현해볼 최소 실험

### 1순위: 학습 없는 audit

1. 해양 데이터 100 scene을 원본 scene 단위로 고정한다.
2. 각 scene에 azimuth/zoom/crop 변화 세 단계를 만들고 detector·VLM의 성능 곡선을 기록한다.
3. 작은 선박 질문의 noun/modifier/phrase grounding map을 저장하고 `왼쪽↔오른쪽`, `큰↔작은` counterfactual consistency를 측정한다.
4. raw anomaly/attention overlay가 정상 파도·반사 이미지의 FPR을 올리는지 확인한다.
5. 전체 AP 외에 small-object recall, localization IoU, normal FPR, object-state consistency를 별도 보고한다.

### 2순위: 작은 개입

- detector/VLM은 frozen 상태로 두고 camera pose embedding adapter만 학습한다.
- normal bank 16장으로 anomaly map을 calibration한다.
- small dynamic region loss는 1×/2×만 비교한다.
- 여러 agent 투표는 추가하지 않고 low-level expert 한 개의 순효과부터 측정한다.

**GO:** pose adapter와 calibration이 서로 다른 두 scene split에서 small-object recall·grounding consistency를 높이고 normal FPR을 낮춘다.  
**KILL/수정:** 성능 변화가 특정 crop이나 reference 선택에만 남으면 방법 논문보다 evaluation artifact·dataset protocol 논문으로 범위를 줄인다.
