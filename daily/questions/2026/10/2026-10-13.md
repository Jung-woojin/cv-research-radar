## Q1. answer–evidence consistency를 학습 목표에 넣으면 unsupported-correct를 줄일 수 있는가?

**직접 근거:** [G-RSVQA/AESP 논문](https://arxiv.org/abs/2610.13636) · [공식 evaluator](https://github.com/pingggg516/AESP-Evaluation)

### 1. 문제 정의

grounded remote-sensing VQA에서 답은 맞지만 모델이 낸 box가 그 답을 지지하지 않는 현상을 평가 후 진단에 그치지 않고 학습 objective로 줄일 수 있는지 묻는다.

### 2. 왜 지금 가치가 있는가

G-RSVQA의 7개 모델에서 올바른 답 중 최대 50.82%가 grounding evidence로 지지되지 않았다. small-object counting과 comparison에서는 box 하나의 누락이 답의 의미를 바꾸므로 안전·원격탐사 적용에서 핵심 신뢰성 문제다.

### 3. Observation과 Gap

- **확인된 사실:** 15,027 samples, 163,399 related-object annotations를 공개한다.
- **확인된 사실:** 기존 Answer Accuracy와 Loc-F1은 answer–box consistency를 직접 측정하지 않는다.
- **확인된 사실:** 공식 evaluator는 ES-overall, ES-correct, Joint Success를 별도로 계산한다.
- **Gap:** AESP는 평가 protocol이며, consistency를 직접 최적화하는 경량 학습 objective의 효과는 미확인이다.

### 4. 핵심 가설

answer loss와 box loss에 task-specific evidence coverage penalty를 추가하면 AA 손실을 작게 유지하면서 ES-correct와 JS를 높일 수 있다. counting은 predicted answer와 box count, comparison은 두 class의 상대 box 수를 맞추는 제약이 효과적일 것이다.

### 5. 최소 실험(MVP)

- 공개 G-RSVQA의 existence/counting/comparison 각 300개로 시작
- frozen VLM에서 answer head·grounding adapter만 학습
- baseline: answer+box loss; intervention: +evidence penalty
- **GO:** AA 하락 1%p 이하에서 JS +5%p 이상, 세 question type 중 둘 이상에서 개선
- **KILL:** extractor를 바꾸면 개선이 사라지거나 Loc-F1만 오르고 ES-correct는 변화 없음

### 6. baseline과 dataset

G-RSVQA official split, 공개 grounded VLM 한 개, answer-only, answer+box, answer+box+evidence penalty. 가능하면 DIOR/NWPU/SODA-A source별로 분리 보고한다.

### 7. 성공·실패 판정 metric

AA, Loc-P/R/F1, ES-overall, ES-correct, JS, invalid parse rate, source-dataset worst-group JS.

### 8. compute 난이도

2/5. evaluator-only audit는 8GB GPU에서도 가능하고, 학습은 LoRA 또는 작은 grounding adapter로 제한한다.

### 9. novelty 위험요인

consistency regularization 자체는 알려져 있다. novelty는 existence/counting/comparison별 논리 조건과 remote-sensing tiny-object grounding을 하나의 differentiable risk로 연결하는 데 있다.

### 10. 4~8주 논문화 가능성

공식 evaluator가 있어 1~2주에 baseline audit, 3~5주에 adapter 실험, 6~8주에 source-wise generalization과 error taxonomy가 가능하다.

### 11. negative result의 가치

penalty가 실패하면 답과 box가 공유 표현을 쓰지 않거나 extractor가 병목이라는 증거가 된다. 이 경우 joint generation architecture보다 evaluator reliability 연구로 전환할 수 있다.

**평가:** Novelty 4.5/5 · Feasibility 4.5/5 · Compute efficiency 4.5/5 · Publication potential 5/5

## Q2. visual hypothesis를 먼저 만들고 물리 단서와 대조하면 해상 VLM의 direct-cue gap이 줄어드는가?

**직접 근거:** [OccludeBench 논문](https://arxiv.org/abs/2610.13790) · [공식 데이터](https://huggingface.co/datasets/afs07fda89sdfas90/data)

### 1. 문제 정의

해무·야간·부분 가림 장면에서 선박 본체가 보이지 않아도 wake·반사·그림자가 남는다. 일반 VLM이 이러한 direct cue보다 장면 문맥에 의존하는지, hypothesis-confront 절차가 이를 줄이는지 검증한다.

### 2. 왜 지금 가치가 있는가

OccludeBench의 5개 VLM 평균은 direct 42.7%, inferential 62.7%로 20.0%p 차이다. 인간은 63.4/68.5%로 유의한 격차가 없었다. 해상 안전에서는 직접 단서 사용 여부가 hallucination과 false alarm을 가르는 핵심이다.

### 3. Observation과 Gap

- **확인된 사실:** 실패/성공 예의 full-image highlighted recovery는 50/91%로 크게 갈린다.
- **확인된 사실:** extended reasoning·tool use·few-shot은 gap을 안정적으로 없애지 못했다.
- **확인된 사실:** inpaint-then-confront는 생성 가능한 두 모델에서 gap을 통계적으로 유의하지 않은 수준까지 줄였다.
- **Gap:** 자연 해상 영상의 물리 단서와 생성 불가능한 open VLM에서도 같은 메커니즘이 성립하는지 미확인이다.

### 4. 핵심 가설

실제 inpainting이 없어도 후보 객체를 텍스트 또는 retrieval image로 외부화한 뒤 cue와 모순 검사를 하면 direct-cue 정확도와 grounding이 함께 개선된다.

### 5. 최소 실험(MVP)

- direct-cue 50장, context-inference 50장 수동 구축
- base, crop-only, text-hypothesis confront, retrieval-image confront 비교
- 세 open VLM, 동일 prompt, 세 seed
- **GO:** direct accuracy +10%p 이상, gap 30% 이상 감소, cue grounding도 동반 개선
- **KILL:** 답만 개선되고 cue grounding은 그대로거나 context subset의 prior가 성능을 설명

### 6. baseline과 dataset

OccludeBench transfer baseline, SeaShips 또는 공개 해상 CCTV에서 수동 가림 subset, base prompting, steering, crop, hypothesis-confront.

### 7. 성공·실패 판정 metric

direct/inferential accuracy, gap, cue-region IoU/pointing accuracy, hypothesis rejection rate, calibration, human agreement.

### 8. compute 난이도

2.5/5. 데이터 annotation이 중심이며 open 7B/8B VLM은 8GB에서 quantized inference가 가능할 수 있으나 모델별 실제 VRAM은 사전 확인한다.

### 9. novelty 위험요인

OccludeBench의 단순 domain transfer로 보일 수 있다. wake·해무 산란·수면 반사라는 해상 고유 물리 단서와 safety-oriented grounding metric이 필요하다.

### 10. 4~8주 논문화 가능성

2주에 100-image diagnostic set, 4주에 intervention 비교, 6~8주에 human baseline과 cross-model 결과가 가능하다.

### 11. negative result의 가치

hypothesis externalization이 효과 없으면 해상 단서가 OccludeBench의 그림자·반사보다 저해상도·ambiguous하며, 문제의 병목이 evidence selection보다 perception resolution임을 보여준다.

**평가:** Novelty 4.5/5 · Feasibility 4/5 · Compute efficiency 4/5 · Publication potential 4.5/5

## Q3. multi-view 해상 추론의 실제 병목은 node perception인가, cross-view edge alignment인가?

**직접 근거:** [MVGraph 논문](https://arxiv.org/abs/2610.12961) · [공식 저장소](https://github.com/AAAndy-Zhu/MVGraph)

### 1. 문제 정의

RGB·thermal·AIS에서 같은 선박을 맞추고 관계·시간 변화를 합성하는 과정의 오류를 perception, alignment, composition, reasoning으로 분해한다.

### 2. 왜 지금 가치가 있는가

MVGraph는 72,000 instances와 golden intermediate로 cross-view edge alignment와 relation-level composition을 병목으로 지목했다. 해상 감시에서도 최종 VQA 정확도만으로는 association failure와 reasoning failure를 분리할 수 없다.

### 3. Observation과 Gap

- **확인된 사실:** thinking에서도 multi-view graph exact match가 모든 모델에서 47% 이하이다.
- **확인된 사실:** Node F1이 Edge F1보다 높고 view-specific edge가 특히 약하다.
- **확인된 사실:** Qwen3.8-Flash는 non-thinking 2.6%에서 thinking 50.4%로 오르지만 최고 평균도 52.4%다.
- **Gap:** 합성 graph의 stage bottleneck이 자연 영상 sensor fusion에서도 유지되는지는 미확인이다.

### 4. 핵심 가설

해상 multi-view에서는 node detection보다 identity/relation edge alignment가 최종 temporal query의 주된 손실원이다. oracle edge를 주면 oracle node보다 더 큰 정확도 회복이 나타날 것이다.

### 5. 최소 실험(MVP)

- 30개 장면, RGB/thermal/AIS 세 view
- gold node, identity edge, spatial/temporal relation edge annotation
- raw, oracle node, oracle edge, oracle composed graph 네 조건
- **GO:** oracle edge가 oracle node보다 최종 정확도를 10%p 이상 더 회복
- **KILL:** oracle edge 효과가 작고 최종 reasoning oracle에서만 큰 회복

### 6. baseline과 dataset

공개 RGB-thermal 또는 maritime multi-sensor subset과 synthetic AIS table, independent-view VLM, concatenated-view VLM, explicit graph pipeline.

### 7. 성공·실패 판정 metric

node F1, edge F1, identity accuracy, temporal relation accuracy, final query exact match, oracle recovery curve, token/latency.

### 8. compute 난이도

3/5. 학습보다 annotation과 staged inference가 중심이다. 작은 VLM과 symbolic graph solver로 분리하면 비용을 낮출 수 있다.

### 9. novelty 위험요인

multi-sensor fusion과 graph reasoning은 기존 분야다. novelty는 golden intermediate intervention으로 error budget을 정량화하고 VLM과 symbolic solver를 같은 stage에서 비교하는 데 있다.

### 10. 4~8주 논문화 가능성

4주에 30-scene pilot과 oracle 분석, 8주에 장면 수·sensor 조합을 늘린 diagnostic benchmark note가 가능하다.

### 11. negative result의 가치

edge가 병목이 아니면 해상 센서 fusion의 실패가 low-resolution perception 또는 temporal solver에 있다는 명확한 설계 우선순위를 준다.

**평가:** Novelty 4/5 · Feasibility 3.5/5 · Compute efficiency 4/5 · Publication potential 4.5/5

## Q4. image-free benchmark audit는 model pool과 null correction을 바꿔도 안정적인가?

**직접 근거:** [Auditing VLM Benchmarks 논문](https://arxiv.org/abs/2610.13548) · [공식 audit layer](https://github.com/avos-rnd/vlm-bench)

### 1. 문제 정의

이미지 유무에 따른 gain이 0인 문항을 shortcut으로 표시할 때, 모델 pool·parser·answer format·permutation null에 따라 결과가 얼마나 달라지는지 측정한다.

### 2. 왜 지금 가치가 있는가

MMStar에서 raw zero-gain은 20.2%지만 null 17.0%를 제외한 excess는 +3.2%p다. audit detector 자체를 절대 판정기로 쓰면 benchmark leakage를 다시 과장할 수 있다.

### 3. Observation과 Gap

- **확인된 사실:** +3.2%p excess는 p=0.001이며 mathematics·science에 집중된다.
- **확인된 사실:** 공통 non-gold consensus 후보 134개는 perception category에 집중된다.
- **확인된 사실:** binary yes/no benchmark에서는 detector calibration이 저하된다.
- **Gap:** small/open VLM과 domain VQA에서 model-pool sensitivity의 실용 범위가 정리되지 않았다.

### 4. 핵심 가설

raw zero-gain 비율은 pool에 민감하지만 null-corrected excess와 category ranking은 모델 규모·계열을 섞은 pool에서 더 안정적이다.

### 5. 최소 실험(MVP)

- MMStar 공개 artifacts 또는 자체 VQA 500개
- pool: 1개, 동일 계열 3개, 이질 계열 3개, 5개
- full, blind, shuffled-image와 parser 두 종류
- **GO:** corrected excess의 category top-2가 pool 변경의 75% 이상에서 유지
- **KILL:** pool/parser에 따라 excess 부호가 바뀌거나 CI가 0을 넓게 포함

### 6. baseline과 dataset

vlm-bench official detectors, MMStar artifacts, 자체 maritime VQA control. Raw zero-gain, permutation excess, consensus-wrong detector를 비교한다.

### 7. 성공·실패 판정 metric

raw proportion, null-corrected excess, bootstrap CI, category-rank Kendall tau, pool sensitivity, parser disagreement, review precision.

### 8. compute 난이도

1.5/5. 저장된 prediction이 있으면 대부분 후처리이며, blind run만 추가 inference가 필요하다.

### 9. novelty 위험요인

단순 robustness audit로 보일 수 있다. model-pool selection을 sampling problem으로 정식화하고 최소 안정 pool을 제안해야 기여가 선명하다.

### 10. 4~8주 논문화 가능성

공개 artifacts로 2주 내 실험 가능하고, 4주 내 domain VQA 검증과 human review를 붙일 수 있다.

### 11. negative result의 가치

corrected excess도 불안정하면 현 benchmark audit 수치의 일반화 한계를 보여주며, item-level review가 aggregate detector보다 우선이라는 결론을 준다.

**평가:** Novelty 4/5 · Feasibility 5/5 · Compute efficiency 5/5 · Publication potential 4/5

## Q5. adverse-weather AP를 object difficulty와 matching하면 모델 순위가 바뀌는가?

**직접 근거:** [Beyond the Snowflakes 논문](https://arxiv.org/abs/2610.13891) · [WADS-3D](https://digitalcommons.mtu.edu/wads-3d/)

### 1. 문제 정의

weather severity bin의 object point count·size·range·contrast 분포가 달라질 때 raw AP가 robustness를 과장하는지, matching 후 모델 순위까지 바뀌는지 검증한다.

### 2. 왜 지금 가치가 있는가

눈이 강할수록 AP가 오르는 역설이 WADS-3D와 CADC에서 관찰됐다. WADS snow intensity와 object point count의 상관은 r=0.820이었고, weather-only 평가로 deployment robustness를 판단하면 잘못된 모델을 선택할 수 있다.

### 3. Observation과 Gap

- **확인된 사실:** WADS snow filtering은 평균 AP를 6.72% 높였지만 severity 상승 trend는 남았다.
- **확인된 사실:** CADC point count r=0.733, intensity r=0.694로 snow bin과 함께 증가한다.
- **저자 주장:** point count가 counter-intuitive performance의 주된 통계 원인이다.
- **Gap:** 해무 RGB detection에서 pixel area·contrast·range를 통제한 순위 안정성은 미확인이다.

### 4. 핵심 가설

fog severity와 object difficulty를 matching하면 raw AP의 severe-bin 역설이 줄고, high-resolution/P2 모델과 global-context 모델의 상대 순위가 달라진다.

### 5. 최소 실험(MVP)

- 해무 dataset 또는 synthetic fog가 있는 detector validation set
- severity × area × contrast × range propensity matching
- detector 3종: P2/high-resolution, standard FPN, global-context
- **GO:** matched AP에서 모델 순위가 두 단계 이상 변하거나 raw severity effect의 절반 이상 감소
- **KILL:** matching 후에도 effect와 순위가 bootstrap CI 안에서 동일

### 6. baseline과 dataset

WADS/CADC protocol을 참고하되 RGB maritime/fog dataset에 맞춘다. YOLO/FPN baseline, P2 variant, transformer/global-context detector를 동일 input과 training data로 비교한다.

### 7. 성공·실패 판정 metric

raw/matched AP50·APs, recall, rank stability, effective sample size, balance diagnostics, severity coefficient와 CI.

### 8. compute 난이도

2.5/5. 기존 checkpoint의 inference와 통계 matching이 중심이며 full retraining은 선택 사항이다.

### 9. novelty 위험요인

confound control은 통계적으로 익숙하다. novelty는 detector robustness leaderboard에 object-difficulty matching과 rank stability를 표준 protocol로 넣는 데 있다.

### 10. 4~8주 논문화 가능성

2주에 metadata 추출, 4주에 matched evaluation, 6~8주에 다른 weather/domain으로 확장 가능하다.

### 11. negative result의 가치

순위가 유지되면 현재 weather benchmark의 상대 모델 비교는 생각보다 강건하다는 근거가 되며, matching을 진단용 보조 지표로 제한할 수 있다.

**평가:** Novelty 4/5 · Feasibility 4.5/5 · Compute efficiency 4.5/5 · Publication potential 4.5/5

## Q6. Answer–Evidence Gap은 객체가 작아질수록 더 커지는가?

**직접 근거:** [G-RSVQA/AESP](https://arxiv.org/abs/2610.13636) · [Beyond the Snowflakes](https://arxiv.org/abs/2610.13891)

### 1. 문제 정의

grounded VQA의 unsupported-correct 현상이 object area·point count·range 같은 관측 난이도와 어떻게 상호작용하는지 묻는다. 답은 language prior로 유지되지만 box evidence만 small-object 구간에서 붕괴할 수 있다.

### 2. 왜 지금 가치가 있는가

AESP는 answer와 evidence의 분리를 보였고 Snowflakes는 object meta-factor가 robustness 결론을 바꿀 수 있음을 보였다. 두 흐름을 합치면 tiny-object VQA의 신뢰성 문제를 직접 진단할 수 있다.

### 3. Observation과 Gap

- **확인된 사실:** G-RSVQA는 163,399 object annotation을 포함해 object-level stratification이 가능하다.
- **확인된 사실:** 올바른 답 중 최대 50.82%가 evidence로 지지되지 않는다.
- **확인된 사실:** LiDAR에서는 object point count가 weather-bin 성능의 핵심 confound였다.
- **Gap:** unsupported-correct risk를 object scale·density·range별로 분해한 결과는 공식 요약에서 제공되지 않는다.

### 4. 핵심 가설

object가 작거나 밀집될수록 AA보다 JS가 더 빠르게 감소한다. 특히 counting에서 AA–JS gap의 scale slope가 existence보다 클 것이다.

### 5. 최소 실험(MVP)

- G-RSVQA를 object area 또는 box pixel size의 quartile로 분할
- question type과 source dataset을 고정한 stratified regression
- high-resolution crop 또는 P2 feature를 intervention으로 적용
- **GO:** smallest quartile의 AA–JS gap이 largest보다 10%p 이상 크고 crop/P2가 JS를 5%p 이상 회복
- **KILL:** source dataset·question type 통제 후 scale interaction이 사라짐

### 6. baseline과 dataset

G-RSVQA official annotations, base grounded VLM, crop-upsample, tiled inference, P2/high-resolution grounding head. 별도 학습 없이 평가부터 시작한다.

### 7. 성공·실패 판정 metric

scale별 AA, Loc-F1, ES-correct, JS, AA–JS gap, interaction coefficient, bootstrap CI, compute/latency.

### 8. compute 난이도

2/5. annotation 기반 audit는 저비용이며 tiled/crop inference만 추가한다.

### 9. novelty 위험요인

small-object degradation 자체는 새롭지 않다. novelty는 answer가 유지되는 동안 evidence만 무너지는 비대칭과 이를 joint metric으로 측정하는 데 있다.

### 10. 4~8주 논문화 가능성

2주에 stratified audit, 4주에 crop/tile intervention, 6주에 maritime dataset transfer가 가능하다.

### 11. negative result의 가치

scale interaction이 없으면 unsupported-correct가 perception 해상도보다 language/grounding decoupling에서 비롯된다는 증거가 된다.

**평가:** Novelty 4.5/5 · Feasibility 5/5 · Compute efficiency 5/5 · Publication potential 4.5/5

## 3. 오늘의 선택

### 가장 먼저 테스트할 질문: Q1

- 공식 evaluator가 있어 데이터·metric 설계 비용이 낮다.
- 평가 audit부터 시작해 학습 intervention으로 자연스럽게 확장된다.
- **첫날 작업:** 공개 sample 300개에서 AA, Loc-F1, ES-correct, JS를 재계산하고 extractor invalid rate를 확인한다.
- **하루 종료 판정:** 공식 결과와 metric이 일치하지 않으면 학습 전에 evaluator/version 문제부터 해결한다.

### RTX 5060 Ti 8GB에서 가능한 질문: Q4와 Q6

- Q4는 저장된 prediction의 후처리와 text-only inference가 중심이다.
- Q6는 annotation stratification과 crop/tiled inference부터 시작할 수 있다.
- 대형 VLM fine-tuning 없이도 핵심 가설을 먼저 반증할 수 있다.

### 장기 박사 주제로 키울 질문: Q2

- 해상 안전 VLM, 물리 단서 추론, grounding, hypothesis testing을 하나의 축으로 묶는다.
- wake·반사·그림자에서 시작해 해무 산란·열화상·레이더 단서까지 확장할 수 있다.
- benchmark, 진단, intervention, domain adaptation을 단계적으로 쌓을 수 있다.

## 4. 4~8주 실행 순서

1. **1주차:** Q1/Q6 evaluator 재현, object-scale metadata와 invalid parse 감사
2. **2주차:** Q4 full/blind/shuffled audit와 model-pool sensitivity
3. **3주차:** Q2 해상 direct-cue/context 100개 annotation pilot
4. **4주차:** Q5 weather×difficulty matching 및 rank stability 분석
5. **5~6주차:** Q1 evidence penalty adapter와 Q2 hypothesis-confront 비교
6. **7~8주차:** Q3 30-scene multi-view oracle study, 가장 강한 질문의 외부 dataset 검증

## 5. 증거와 제한

- 질문은 확인된 수치를 출발점으로 삼았지만 제안된 threshold와 GO/KILL 기준은 실험 설계 선택이다.
- 폐쇄형 모델·API thinking의 compute와 revision이 달라 모델 간 결과는 strictly apples-to-apples가 아니다.
- 합성 visual graph와 자동차 LiDAR 결과를 해상 영상 성능으로 직접 일반화하지 않고 진단 protocol만 이전한다.
- 오늘 다룬 공식 결과의 독립 커뮤니티 재현은 아직 확인되지 않았다.
