1. **CV benchmark 자체가 새로운 병목**으로 올라왔다. 재주석 결과 COCO/VOC/Cityscapes/KITTI에서 small/occluded/dense object 누락이 상당히 확인됐다.

# CV / DL-CV 핵심

## 1. Object Detection Benchmarks are Incomplete: The Role of Label Errors and Annotation Uncertainty
**v1: 2026-09-18**

COCO, Pascal VOC, Cityscapes, KITTI를 다시 annotation해 benchmark completeness를 점검.

재주석 후 annotated objects가:
- COCO 약 +40%
- KITTI 약 +60%

늘어난 setting이 확인됨.

누락은 특히:
- small
- occluded
- densely packed objects

에 집중.

중요한 결과:
- 절대 AP는 annotation quality에 민감
- model ranking은 비교적 안정

메시지:
> 기존 detection literature가 무효라는 게 아니라, +0.5~1 AP 같은 작은 gain을 architecture superiority로 해석할 때 annotation uncertainty를 더 조심해야 한다.

Small-object 연구에서 특히 중요.

## 2. PointLAM: Local Attentive Mamba for Efficient Point-based 3D Object Detection
**v1: 2026-09-18 · ECCV 2026**

세 역할로 분해:
- **Laplacian Point Sampler**: high-frequency local geometry 보존
- **Local Hadamard Aggregator**: bounded local topology
- **Bi-Directional Mamba**: global dependency

즉:
```
local high-frequency structure → local operator
global dependency → Mamba
```

공식 결과:
- nuScenes test: 73.0 NDS / 68.8 mAP
- Waymo: 79.8 L1 / 74.4 L2 mAPH
- 8.6M params
- 90.7 GFLOPs
- 약 93.1 ms on A800

중요한 설계 메시지:
> Global context를 위해 local geometry까지 global operator에 맡길 필요는 없다.

2D aerial tiny-object에도:
- downsampling 전 high-frequency preservation
- global context
를 독립 설계축으로 볼 수 있다.

## 3. Info3R: Information-Adaptive Test-Time Training for 3D Reconstruction
**v1: 2026-09-18**

Online 3D reconstruction에서 recurrent state가 오래될수록 saturated되고 early-frame bias가 쌓이는 문제.

두 진단:
1. 새 frame이 기존 state보다 얼마나 informative한가
2. 현재 state가 얼마나 saturated됐는가

이를 이용해 update strength를 조절하고 필요하면 **dynamic reset**.

핵심:
> memory size보다 state plasticity와 reset policy가 중요할 수 있다.

---

## 4. VideoReloc: Long-Term Indoor Video Relocalization against a Kilobyte-Scale Semantic Scene Graph
**v1: 2026-09-18**

기존 appearance-heavy map 대신:
```
class-labelled 3D boxes
```
중심의 매우 작은 semantic map을 유지.

부족한 정보는 persistent map에 다 저장하지 않고 **query video의 temporal evidence**에서 수집.

핵심 inversion:
```
Rich Map + Short Query
→ Tiny Semantic Map + Longer Temporal Query
```

Persistent map은 약 100kB 수준.

---

## 5. Balanced Prompt Adaptation against Entropy-Induced Collapse for Test-Time Binary Segmentation
**v1: 2026-09-18**

Binary segmentation TTA에서 foreground가 작을 때 entropy minimization이 background collapse를 일으키는 문제를 분석.

해결:
- Class-Balanced Anchors
- Dynamic Prompt Adaptation
- vision encoder frozen
- text-side prompt residual만 update

핵심 가치는 최고 성능보다 **entropy minimization failure mode를 설명했다는 점**.

---

## 6. A Scene Language Model for Open-Vocabulary Scene Mapping
**v1: 2026-09-18**

기존 scene map이 visual feature bank를 persistent memory로 유지한다면 SceneLM은 memory를 **structured text state**로 만든다.

개념적으로:
```
chair_3: near table_1
table_1: center=(...), size=(...)
door_2: open
```

새 observation마다:
- ADD
- EDIT
- REMOVE

를 수행.

Persistent representation을 약 6–12× compact하게 유지하면서 open-vocabulary retrieval/localization을 수행.

중요한 질문:
> Persistent world state에 정말 raw visual embedding이 필요한가?

주의:
논문은 code available이라고 했지만 당시 공개 URL은 실제로 404여서 full artifact 공개 완료로 보기는 어려웠다.

## 7. ZYT-World: A Real-Time Controllable World Model for Closed-Loop Autonomous-Driving Simulation
**v1: 2026-09-18**

Production-like mixed camera rig:
- 4 fisheye
- 3 pinhole
- 총 7-view

를 native projection/resolution 그대로 생성.

Long rollout:

# VLM / Multimodal / Video

## 1. DRT: Dense Reasoning Trace for Efficient and Grounded Multimodal Reasoning
**v1: 2026-09-18**

일반 verbose CoT 대신:
```
<visual> concise evidence </visual>
<think> relational deduction </think>
<answer> result </answer>
```

처럼 visual observation과 logical deduction을 구조적으로 분리.

학습:
- Dense Trace Initialization
- Trace-Grounded GRPO

보고 결과:
- Qwen3-VL-8B-Instruct 대비 평균 accuracy +1.3pt
- reasoning token efficiency 약 5.5× 개선

공식 repo:
- DRT-SFT-8B
- DRT-RL-8B
- 약 194k SFT samples
- 약 14.7k RL samples
- evaluation / VLMEvalKit integration

artifact completeness가 좋은 편.

핵심:
> reasoning을 길게 늘리는 것보다 visual evidence와 deduction을 잘 분리하는 것이 더 중요할 수 있다.

## 2. VidOmni-Bench: A Benchmark for Fine-Grained Video Understanding via Spatio-Temporal Event Verification across Complexity and Duration
**v1: 2026-09-18**

500 videos, 4초~90분.

Model-generated dense caption의 각 event sentence가 실제 video에 존재하는지 human-verified hard negatives로 평가.

핵심 finding:
- Video-LLM은 plausible but false event를 생성
- verifier 역할에서도 그 false claim을 잘 잡지 못함
- model scale이 커져도 temporal error가 static-frame error만큼 쉽게 줄지 않음
- frame 수를 많이 넣는다고 항상 좋아지지 않음

즉:
```
Answer Accuracy
→ Event Claim ↔ Video Evidence
```
로 benchmark가 이동.

## 3. PRIME: Perception Feedback with Situational Memory Embeddings in VLA Models
**v1: 2026-09-18**

기존:
```
Perception → Reasoning → Planning
```

제안:
과거 perception/reasoning/goal/action latent를 Situational Memory로 만들고 **다시 perception query에 feedback**.

즉:
```
Goal/Reasoning_(t-1)
→ Perception_t
```

7.3B base에 약 29.7M params, 0.41%만 추가.

Bench2Drive에서:
- Driving Score 82.47
- Success Rate 60.00%

핵심:
> downstream intent가 perception 자체를 다시 조건화할 수 있다.

Flow-matching generator RL에서 denoising step별 importance-ratio instability를 **path variance λ**로 정식화.

각 denoising step에 gradient budget을 다르게 배분.

메시지:
> training compute도 모든 step에 동일하게 쓰지 말고 adaptive allocation해야 한다.

## 2. Abstention and Noise Filtering: Two Missing Primitives of Softmax Attention

Softmax attention은:
```
sum attention = 1
```
이라 읽을 게 없어도 어디엔가는 attention을 줘야 한다.

제안:
- Abstention: 아무것도 읽지 않기
- Noise filtering: irrelevant value suppression

현재 vision 실험이 아니라 LM 중심이라 CV 적용은 후속 가설 수준.

# 오늘의 중요한 Finding 3개

## Finding 1. Benchmark uncertainty가 architecture gain과 같은 크기일 수 있다
특히 tiny/small object에서 missing GT가 false positive 평가에 직접 영향을 준다.

향후 좋은 small-object paper는:
```
AP gain
vs
annotation sensitivity
```
를 같이 볼 가치가 있다.

## Finding 2. Persistent vision의 다음 단계는 feature memory보다 structured state
Info3R, VideoReloc, SceneLM, PRIME 모두:
- 무엇을 저장?
- 언제 update?
- 언제 reset/delete?
를 핵심 문제로 다룬다.

## Finding 3. 효율화는 model pruning보다 information routing
- PointLAM: local/global role split
- DRT: evidence/reasoning split
- Qwen-Image-2.1: immutable prefix caching
- λ-GRPO: optimization budget allocation

공통:
```
Different information
→ different pathway / budget
```

# 1위 미니 리뷰 요약

Detection evaluation은 GT를 절대 기준으로 본다.

하지만 tiny/small object에서 GT가 누락되면:
```
true object prediction
→ false positive
```
로 평가될 수 있다.

따라서 detector A가 더 aggressive하게 tiny object를 찾는 경우 기존 GT에서는 precision이 나빠 보이다가 reannotation 후 일부 FP가 TP로 바뀔 수 있다.

새 연구 질문:
> **Is my tiny-object AP gain real?**

VisDrone/AI-TOD subset을 multi-annotator로 재검수해:
- missing GT rate vs size
- density
- occlusion
- FP→TP conversion
- detector별 sensitivity
를 측정하면 architecture gain의 reliability 자체를 연구할 수 있다.
