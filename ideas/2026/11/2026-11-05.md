# CV Paper Idea Radar — 2026-11-05

## 요약

- 최근 공식 원문은 문서·웹·PDF를 한 VLM이 처리하는 흐름과 고정 해상도 VLM 런타임 지원을 동시에 보여 준다.
- 따라서 점수 상승보다 resize/crop 뒤에도 근거 위치가 보존되는지를 측정하는 논문이 가장 즉시 검증 가능하다.
- vLLM의 11월 2일 hybrid GDN 재현성 보고는 동일 생성도 batch 조건에 따라 갈릴 수 있음을 문서화했다.
- 이를 VLM의 객체·표·OCR 근거 답변으로 옮겨 동시성 변화를 견디는지를 별도 축으로 측정할 수 있다.
- Nemotron의 공개 recipe는 VLM post-training의 SFT/RL 데이터가 아직 공개되지 않았다고 밝힌다.
- 그래서 더 큰 모델이 아니라 공개 데이터로 만든 근거 우선 post-training이 숨김/환각에 미치는 영향을 분리할 여지가 있다.
- 우선순위는 LayoutShield-VL → BatchPerturb-VL → Provenance-First SFT 순서다.
- 오늘의 최소 실험은 모델 하나·문서 200개·세 resize 조건·두 batch 조건으로 시작한다.

## Proposal A — LayoutShield-VL: 입력 변환 뒤에도 남는 문서 근거를 측정하고 보존하는 VLM

1. **문제**: 문서·웹페이지·표를 읽는 VLM은 resize, crop, padding 후에도 답을 내지만, 답에 필요한 증거 토큰/셀 자체가 보존되었는지는 별개다.
2. **관측된 gap (사실)**: NVIDIA는 문서 OCR·표·차트를 핵심 사용처로 제시하고, ORT GenAI는 fixed-resolution VLM 지원을 추가 중이다. 두 원문은 입력 변환별 근거 보존 측정을 주장하지 않는다.
3. **가설**: 변환 전후의 정답 일치보다 근거 영역 보존률과 근거-답 정합성을 함께 최적화하면, 작은 글자·표 셀·범례에서의 무근거 정답을 줄일 수 있다.
4. **방법/모듈**: (i) 같은 문서를 native/letterbox/short-side resize/tile 입력으로 생성, (ii) 질문별 gold evidence box 또는 cell을 둔 Evidence Retention Score, (iii) visual token 중 해당 영역의 coverage가 낮으면 판독 불가를 허용하는 abstention head, (iv) 고해상도 재질의는 coverage가 낮은 영역에만 수행한다.
5. **비교 대상**: 기본 VLM 단일 resize, 전역 고해상도, OCR-first pipeline, 단순 self-consistency.
6. **데이터·지표**: 공개 문서 VQA/표 VQA 중 evidence annotation을 확보할 수 있는 subset과 직접 만든 200-document pilot; answer EM/F1, evidence IoU 또는 cell hit, calibration/ECE, abstention precision, latency/VRAM을 함께 보고한다.
7. **핵심 ablation**: coverage estimator 제거, selective rerun 제거, gold box 대신 model box, resize policy별, 글자 크기·표 밀도별.
8. **실패/negative result 기준**: answer EM만 오르고 evidence hit가 오르지 않으면 근거 보존 주장을 철회한다. 고해상도 전체 재실행이 같은 예산에서 더 낫다면 selective module은 제거한다.
9. **novelty risk**: 기존 document VQA의 grounding/region routing과 겹칠 수 있다. 차별점은 단일 입력의 attention 시각화가 아니라 배포 변환 간 동일 증거의 보존/붕괴를 측정 단위로 삼는 데 있다.
10. **4–8주 MVP**: 1주 데이터·transform harness, 2주 evidence score, 3주 baselines, 4주 error taxonomy; 여유가 있으면 두 번째 VLM으로 재현한다.
11. **예상 기여 3개**: 변환-조건부 evidence benchmark, 선택적 재질의 policy, 정확도/근거/비용의 Pareto 분석.
12. **제목 후보**: *LayoutShield-VL: Measuring Evidence Retention under Document Input Transformations*.
13. **초록 뼈대**: 문서 VLM은 입력 transform 뒤에도 답하지만 증거가 남았는지는 측정하지 않는다; 우리는 retention metric과 selective re-query를 제안하고 정확도뿐 아니라 evidence·calibration·비용을 평가한다.
14. **서론/관련연구**: document VQA·OCR·visual grounding·adaptive computation을 다루되, NVIDIA의 문서 사용처 주장은 동기이지 성능 근거로 쓰지 않는다.
15. **방법 그림**: document → four transforms → evidence coverage → answer / abstain / local re-query; 표 1은 transform별 answer/evidence/cost.
16. **실험 표·그림**: (a) document density × font size heatmap, (b) retention-vs-EM scatter, (c) failure gallery: 잘못 읽은 셀·차트 범례·crop 누락.
17. **최소 실험**: 모델 1개, 문서 200개, transform 4개, 질문당 exact answer와 evidence location을 사람이 이중 검수한다.

## Proposal B — BatchPerturb-VL: VLM 시각 근거 답변의 동시성-조건부 재현성

1. **문제**: production VLM은 단일 요청 평가와 달리 여러 이미지·문서 요청을 batch로 처리한다. 같은 visual query가 batch size, request order, co-tenant에 따라 다른 객체/셀을 지목하면 audit가 어렵다.
2. **관측된 gap (사실)**: vLLM 이슈 #65112는 hybrid GDN에서 batched greedy output이 batch-dependent floating-point reduction 때문에 run-to-run 재현 불가할 수 있다고 보고한다. 그 사례는 시각 과제가 아니며, VLM grounding에 일반화된다는 증거는 없다.
3. **가설**: token-exact 일치만 요구하지 않고 answer agreement, evidence-region agreement, tool action agreement을 분리하면 시각 에이전트의 위험한 불안정과 무해한 문장 변형을 구분할 수 있다.
4. **방법/모듈**: batch perturbation generator(1/2/4/8, order permutation, distractor insertion), output canonicalizer, region/action agreement scorer, 위험한 disagreement만 request-wise replay하는 scheduler.
5. **비교 대상**: 고정 batch, temperature 0, seed 고정, 전체 request-wise serving, 단순 majority vote.
6. **데이터·지표**: 객체 위치 질문, 문서 cell retrieval, GUI screenshot action subset; answer agreement, box/cell IoU agreement, action disagreement, replay latency, worst-cell rate.
7. **핵심 ablation**: perturbation 종류별, visual token 수별, model family별, canonicalization 전후, replay threshold별.
8. **실패/negative result 기준**: 두 VLM 모두에서 action/evidence disagreement가 충분히 낮으면, 일반적 VLM 문제가 아니라 특정 hybrid/runtime 문제로 결과를 축소한다.
9. **novelty risk**: LLM nondeterminism benchmark와 겹친다. 차별점은 시각 근거 영역과 후속 tool action을 함께 판정하고 deployment batch를 독립변수로 둔다는 점이다.
10. **4–8주 MVP**: 1주 replay harness, 2주 3개 visual task, 3주 agreement metric, 4주 runtime/model matrix.
11. **예상 기여 3개**: visual batch perturbation protocol, evidence/action stability metric, 위험 조건에서만 비용을 쓰는 scheduler.
12. **제목 후보**: *BatchPerturb-VL: Auditing Concurrency-Induced Instability in Vision-Language Agents*.
13. **초록 뼈대**: 동일 VLM request의 batch-조건부 변화를 재현성 결함이 아닌 시각 근거·행동 안정성으로 측정하고 selective replay의 비용-안정성 trade-off를 제시한다.
14. **서론/관련연구**: decoding determinism·serving systems·visual grounding·agent reliability. vLLM 이슈는 동기 사례로만 쓰며 논문 결과는 독립 재현 실험으로만 주장한다.
15. **방법 그림**: same image-query × batch perturbations → answer/evidence/action agreement → risk gate → replay.
16. **실험 표·그림**: batch size별 worst-cell 표, answer/evidence/action disagreement의 Venn diagram, throughput 대비 stability curve.
17. **최소 실험**: 동일 visual query 100개를 1/2/4/8 batch와 10개 순열에서 실행하고 decoding 설정·runtime·GPU를 완전 기록한다.

## Proposal C — Provenance-First SFT: 미공개 post-training 데이터 아래의 근거 우선 VLM 미세조정

1. **문제**: 공개 weight가 있어도 post-training 데이터/teacher blend가 공개되지 않으면 재현자는 같은 task score가 아닌, 자신이 구성한 데이터의 품질과 거절 정책을 검증해야 한다.
2. **관측된 gap (사실)**: Nemotron recipe는 SFT/RL data가 아직 공개되지 않았고 own data 실행 결과는 report benchmark와 달라진다고 명시한다. 이는 데이터가 나쁘다는 주장도, 해당 모델이 환각한다는 증거도 아니다.
3. **가설**: visual answer에 source region, readability, unsupported label을 함께 학습하면, 일반 preference SFT보다 근거가 없는 단정 답변을 줄이면서 읽을 수 있는 사례의 정확도를 유지할 수 있다.
4. **방법/모듈**: 공개 문서·차트·스크린샷을 evidence-labelled triples (question, answer, evidence/unsupported)로 curate; evidence token loss, unsupported contrastive loss, answer loss를 분리하고 inference에서 evidence가 부족하면 abstain한다.
5. **비교 대상**: answer-only SFT, generic instruction SFT, RAG/OCR-first, post-hoc confidence threshold.
6. **데이터·지표**: 라이선스가 명확한 공개 문서와 screenshot; answer accuracy, evidence hit, false-supported rate, selective risk, data construction time을 보고한다.
7. **핵심 ablation**: unsupported label 제거, noisy box 비율, OCR noise, source type별(표/차트/일반 문서), in-domain/out-of-domain.
8. **실패/negative result 기준**: abstention 증가만으로 false-supported rate가 감소하고 coverage가 크게 하락하면 성공으로 보지 않는다; risk-coverage curve를 필수 보고한다.
9. **novelty risk**: grounded VLM SFT와 중복 가능성이 높다. 공개 post-training recipe의 own data 조건에서 data card·lineage·실패 annotation을 완전 공개하는 재현 프로토콜이 차별의 핵심이다.
10. **4–8주 MVP**: 1주 라이선스/lineage 카드, 2주 5k triple, 3주 LoRA, 4주 in/out-domain 및 human audit.
11. **예상 기여 3개**: provenance-rich SFT set, false-supported 측정, 공개 recipe에서의 reproducible data-card protocol.
12. **제목 후보**: *Provenance-First SFT for Vision-Language Models with Explicit Unsupported Claims*.
13. **초록 뼈대**: 미공개 post-training corpus를 복제하려 하지 않고 공개·추적 가능한 근거 라벨을 통해 답변·증거·거절을 함께 학습하며 risk–coverage를 평가한다.
14. **서론/관련연구**: instruction tuning, VLM hallucination, data documentation, abstention/calibration. 모델 공개성과 training-data 공개성을 동일시하지 않는다.
15. **방법 그림**: licensed source → evidence/unsupported annotation → three-loss SFT → answer with evidence or abstain.
16. **실험 표·그림**: label budget curve, risk–coverage curve, source type별 false-supported 표, provenance audit example.
17. **최소 실험**: 모델 1개·5k triple·LoRA 1회·독립 문서 300개 human audit로 시작한다.
