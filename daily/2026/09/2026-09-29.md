## 전체 트렌드
- Grounding이 주어진 phrase localization에서 text span 자체를 발견하는 양방향 correspondence로 확장.
- Visual-token efficiency는 pruning뿐 아니라 representation evolution을 싸게 근사하는 방향으로 확장.
- Document AI에서 rendered visual representation을 retrieval용 압축 표현으로 사용.

## 핵심 연구
### Vision-Language Grounding as Bidirectional Concept Correspondence
Prespecified phrase 없이 image-text pair에서 visually referential text span과 instance segment의 모든 correspondence를 복원하도록 grounding을 재정의한다.
Source: https://huggingface.co/papers?q=Vision-language+grounding

### Just MLPs: Efficient Visual State Reconstruction for Multimodal Language Models
Visual token을 영구 삭제하는 pruning 대신 evidence를 보존하면서 Transformer layer의 visual-state evolution 비용을 줄이는 방향. Low-rank intervention으로 visual-to-text information flow를 분석한다.
Source: https://huggingface.co/papers/2609.34972

### RenderRank: Learning to Rerank Text with Compressed Visual Tokens
문서를 image로 render해 compressed visual representation으로 reranking. BEIR 11 datasets에서 16.5–35.5% fewer input tokens, 평균 NDCG@10 55.96; long-document 4 datasets에서 평균 88.27과 높은 throughput을 보고.
Source: https://huggingface.co/papers/2609.35069

### ColNanoVDR: Document-Free Query Distillation for Multi-Vector Visual Document Retrieval via Optimal Transport
Teacher의 모든 page token을 cache하지 않고 query representation 중심으로 student를 distill하는 document-free multi-vector VDR.
Source: https://huggingface.co/papers/2609.34899

### A Benchmark & Dataset for Detecting AI-Manipulated Visual Evidence in the Court System
Surveillance/dashcam/phone photo의 localized prompt-based manipulation을 법정 증거 threat model로 benchmark화.
Source: https://arxiv.org/abs/2609.37783
