## 3. WoodBR-Cross — image-disjoint 점수가 개체 일반화를 과대평가할 수 있다

**공식 원문:** [arXiv](https://arxiv.org/abs/2610.12676), [HTML tables](https://arxiv.org/html/2610.12676)

### 확인된 사실

- 데이터는 38개 operational taxonomic classes의 4,875장, 303개 개별 나무로 구성된다. species subset은 20 classes, 3,406장, 214개 나무다.
- A/B1은 duplicate group을 보존하면서 이미지를 분할한다. B2는 catalogue witness code, 즉 개별 나무 ID를 기준으로 train/validation/test를 완전히 분리한다.
- 세 outer folds와 다섯 training seeds를 사용한다. 저자가 표시한 표준편차는 세 개의 seed-averaged fold mean에 대한 기술통계이며 confidence interval이 아니다.
- ConvNeXt-Tiny의 image-level macro-F1은 B1에서 `0.9736±0.0226`, B2에서 `0.7979±0.0260`이다. 약 0.176 차이지만 test composition과 task별 선택 config가 달라 split 효과의 인과 추정치는 아니다.
- B2의 주 평가 단위는 이미지가 아니라 나무다. validation-selected ConvNeXt-Tiny의 tree-level macro-F1은 `0.8621±0.0317`이다.
- frozen DINOv2는 B2 tree-level macro-F1 `0.9000±0.0722`를 얻었다. 저자는 paired inferential comparison이 없으므로 fine-tuned model보다 우월하다고 결론 내리지 않는다.
- ResNet-50, ConvNeXt-Tiny, ViT-B/16이 서로 다른 ImageNet pretraining checkpoint를 사용하므로 architecture-only 비교가 아니다.
- border-only control도 B2 tree-level macro-F1 `0.8428±0.0798`을 유지했다. 주변부 목재 구조와 촬영 맥락을 분리하지 않아 실제 shortcut 원인은 미확인이다.

### 저자 주장

동일 개체에서 찍은 여러 이미지가 train과 test에 나뉘면 unseen specimen 일반화가 과대평가될 수 있으며, 실제 현장 배치를 반영하려면 specimen-disjoint split과 specimen-level aggregation이 필요하다는 주장이다.

### 비교 가능성 감사

B1→B2의 하락은 중요한 경고지만 완전히 동일한 학습 configuration과 동일 test composition을 유지한 실험은 아니다. 따라서 “개체 누수 때문에 정확히 17.6pp 과대평가됐다”고 단정하면 안 된다. 가장 강한 결론은 **split unit을 image에서 specimen으로 바꾸면 순위와 절대 점수가 크게 달라진다**는 것이다.

### 진단 → 가설 → 최소 실험

- **진단:** 선박·CCTV·UAV 영상은 같은 장소, 같은 선박, 같은 비행 경로의 인접 frame이 무작위 image split을 통해 train/test에 동시에 들어가기 쉽다.
- **가설:** vessel-ID, camera-ID, flight-ID 중 하나라도 group-disjoint로 바꾸면 기존 detector/VLM 성능이 크게 낮아지고 모델 순위도 바뀐다.
- **최소 실험:** 현재 데이터에서 random-image split과 vessel-or-sequence-disjoint split을 같은 seed·backbone·augmentation으로 비교한다. object-size bin별 AP와 group-level bootstrap CI를 함께 계산한다. AP가 5pp 이상 떨어지거나 모델 순위가 바뀌면 random split 결과를 배포 기준에서 제외한다.

## 4. Mind the Temporal Gap — 평균 50%가 “무작위”가 아니라 클래스 붕괴일 수 있다

**공식 원문:** [arXiv](https://arxiv.org/abs/2610.12575), [HTML results](https://arxiv.org/html/2610.12575)

### 확인된 사실

- 1,200개 CARLA 영상은 forward/backward, left/right, accelerate/decelerate 각 class 200개로 구성된다. 별도 real-world set은 class당 10개, 총 60개다.
- VideoLLaMA2, Qwen2-VL, Qwen2.5-VL, Qwen3-VL, InternVL 3.5, MiniCPM-V 4.5를 평가했다.
- 모든 모델이 standard prompting에서 forward 100%, backward 0%를 기록했다. 평균 50%는 균형 잡힌 불확실성이 아니라 forward-only 예측이다.
- Qwen2-VL과 Qwen2.5-VL은 left 100%, right 0%로 붕괴했다. InternVL 3.5는 left/right 평균 67%지만 class별로는 39%/95%다.
- real-world set과 CARLA의 class-level 결과 상관은 `r=0.957`이다. 저자도 forward/backward 공통 붕괴와 작은 real set 때문에 독립적인 sim-to-real 일반화 증거로 해석하지 않는다.
- prompt 조건은 모델별 frame budget이 다르다. 일부는 10초 clip에서 8 frames, Qwen 계열은 약 20 frames를 사용하므로 모델 간 절대 점수는 동일 compute 비교가 아니다.
- LoRA는 action pair당 400개를 80/20으로 분할하고 rank 16, 3 epochs로 학습했다. 대부분의 task에서 거의 완벽한 분류를 회복했다.
- 논문은 single-frame 및 frame-shuffling control을 수행하지 않았다. 따라서 LoRA/probe가 진짜 시간 정보를 사용했는지, CARLA의 frame-level appearance shortcut을 썼는지는 미확인이다.

### 저자 주장

motion cue가 vision hierarchy 내부에는 존재하지만, prompted video-to-language pathway가 이를 안정적으로 사용하지 못한다는 주장이다. CoT와 visual prompt는 이 문제를 일관되게 해결하지 못했다.

### 비교 가능성 감사

같은 모델에서 prompt 전략을 비교하는 것은 유효하지만 frame sampling과 context 형식이 모델별로 다르다. 특히 LoRA 100%에 가까운 결과는 frame-order control이 없으므로 temporal reasoning 성취로 해석할 수 없다.

### 진단 → 가설 → 최소 실험

- **진단:** 해상 CCTV에서 접근/이탈, 좌/우 이동, 가속/감속을 묻는 VLM이 전체 accuracy 50%를 내더라도 한 class만 고를 수 있다.
- **가설:** class-balanced accuracy와 confusion matrix를 보면 평균 정확도보다 훨씬 심한 방향 편향이 드러난다.
- **최소 실험:** 선박 motion pair별 100 clips를 구성해 원본, frame-reversed, frame-shuffled, single-middle-frame 네 조건을 같은 frame budget으로 평가한다. class별 recall, macro-F1, prediction entropy를 기록한다. 원본과 shuffled 차이가 5pp 미만이면 temporal reasoning 성공으로 인정하지 않는다.

## 5. TerraAgent — RS-VQA에 visual dependency를 추가

**공식 원문:** [arXiv](https://arxiv.org/abs/2610.12517), [HTML results](https://arxiv.org/html/2610.12517)

### 확인된 사실

- TerraAgent는 frozen remote-sensing MLLM 위에 GSD-aware retrieval, evidence ledger, counterfactual evidence audit를 붙인 training-free pipeline이다.
- 논문은 RSVQA-LR/HR에서 93.40/94.10, VRSBench overall 80.2, LHRS-Bench average 46.30을 보고한다.
- VRSBench에서 저자 표의 strongest same-setting baseline인 Mini-Gemini 77.8보다 2.4 points 높다.
- 논문이 보고한 visual-dependency score는 0.28→0.49, prior-only answer rate는 46.2%→21.7%, judged hallucination rate는 17.1%→9.8%다.
- inference cost는 single backbone forward의 2.6배로 보고된다.
- ablation에서 GDR는 VRSBench 76.0→78.1, MACE는 LHRS-Bench 39.38→43.10, 전체 조합은 각각 80.2와 46.30을 기록했다.
- LHRS-Bench의 resolution, distance, quantity에서는 closed model이 더 강한 항목이 남았다. 저자는 perception grounding 개선과 world knowledge 개선을 구분한다.
- 이번 점검에서는 공식 공개 코드/weights 저장소를 확인하지 못했다. 따라서 수치와 evaluator 구현을 독립적으로 대조하지 못했다.

### 저자 주장

정답 accuracy만으로는 이미지 없이 맞힌 prior-only answer를 발견할 수 없으며, cited evidence의 ablation/swap에 대한 답변 민감도를 별도 metric으로 보고해야 한다는 주장이다.

### 비교 가능성 감사

RSVQA, VRSBench, LHRS-Bench는 질문 형식과 evaluator가 다르므로 세 benchmark의 절대 accuracy를 한 순위로 묶으면 안 된다. VDS 역시 저자 구현의 evidence citation과 perturbation 품질에 의존한다. 공개 artifact 전에는 “0.49”를 표준화된 외부 metric으로 보지 않는다.

### 진단 → 가설 → 최소 실험

- **진단:** 해상 안전 VQA는 이미지가 없어도 “선박이 있다”, “안개가 짙다” 같은 데이터 prior로 정답을 맞힐 수 있다.
- **가설:** answer accuracy가 높은 모델도 근거 box를 제거하거나 다른 장면의 box로 바꾸면 답이 유지되는 prior-only 비율이 높다.
- **최소 실험:** 현재 VQA validation 200개에 대해 original, cited-region blur, same-class region swap, full-image removal 네 조건을 실행한다. accuracy, answer-change rate, VDS-like sensitivity, abstention calibration을 계산한다. image removal 후 정답 유지가 20%를 넘으면 accuracy-only 리더보드를 중단한다.

## 6. Thermal-UAV-Paired — 새 dataset보다 먼저 공간 중복과 검색 난이도를 본다

**공식 원문:** [arXiv](https://arxiv.org/abs/2610.12835), [HTML experiments](https://arxiv.org/html/2610.12835), [official repository](https://github.com/YuxinWang879/SAMF)

### 확인된 사실

- 공식 저장소는 Python 3.10.19, PyTorch 2.9.1+cu128, CUDA 12.8 환경과 Swin-T/256×256/NetVLAD-64 설정을 명시한다.
- Thermal-UAV-Paired는 원본 thermal UAV image에 center coordinate로 satellite patch를 대응시킨다. split은 train 7,886, validation 1,407, test 2,350 pairs다.
- 정답 판정은 top-K satellite candidate가 query 위치 50m 안에 있으면 성공이다. `R512@K`와 512m search radius 안의 L2 위치 오차도 보고한다.
- 저자 표에서 SAMF는 test R@1 97.0%, R@5 99.4%, R512@1 98.1%, R512@5 99.8%, L2 4.8m다.
- 같은 표의 DINOv3-ViT-S는 R@1 94.6%, L2 6.3m다. SAMF의 R@1 차이는 2.4pp다.
- Boson-nighttime에서는 SAMF R@1 93.6%, 기존 SGM 92.1%, Swin-T 84.1%다.
- 공개 README는 dataset download와 loader 형식을 제공하지만, 지리적으로 인접한 patch가 split 사이에 얼마나 떨어져 있는지와 장소 단위 disjoint 보장은 명시하지 않는다.

### 저자 주장

열화상과 위성 RGB 사이에서 색·밝기보다 방향성 경계와 저주파 구조가 안정적이며, 이를 강화한 SAMF가 cross-modal retrieval을 개선한다는 주장이다.

### 비교 가능성 감사

동일 표의 baseline은 같은 retrieval framework를 사용해 비교 가능성이 높다. 다만 Thermal-UAV-Paired에서 강한 backbone이 이미 94%대 R@1을 얻으므로 benchmark가 포화에 가까울 수 있다. center crop으로 만든 인접 satellite patch가 train/test에 공간적으로 근접한다면 location-specific texture 누수가 생길 수 있다. 공개 split의 geographic distance matrix를 먼저 계산해야 한다.

### 진단 → 가설 → 최소 실험

- **진단:** UAV geo-localization benchmark의 높은 recall이 cross-modal 일반화가 아니라 인접 지역 기억일 수 있다.
- **가설:** flight-area 또는 geographic block-disjoint split으로 바꾸면 R@1이 크게 낮아지고 구조 기반 모듈의 상대 이점은 더 명확해진다.
- **최소 실험:** 공개 pairs.json의 좌표로 train-test 최근접 거리를 계산하고 500m/1km spatial block split을 새로 만든다. Swin-T, DINOv3-ViT-S, SAMF를 같은 input과 checkpoint 정책으로 비교한다. 기존 split 대비 R@1이 5pp 이상 낮아지면 원래 점수를 cross-location 일반화로 해석하지 않는다.

## 7. SquintBench — OCR benchmark는 해상도보다 frequency pathway를 감사해야 한다

**공식 원문:** [arXiv](https://arxiv.org/abs/2610.13465), [HTML experiments](https://arxiv.org/html/2610.13465)

### 확인된 사실

- SquintBench는 production moderation pipeline에서 수집한 1,076개 이미지다. production-derived 부분은 승인 요청형 접근이라 모든 독립 연구자가 즉시 받을 수 있는 공개 benchmark가 아니다.
- controlled set은 hidden-text presence 500 pairs, Chinese/Latin glyph 각 500장, strength sweep 200 scenes, open-vocabulary readout 200장으로 구성된다.
- 저자가 평가한 off-the-shelf MLLM의 original-image SquintBench ANLS는 8.33~24.44다.
- Qwen3.5-9B base는 26.50, 저자의 OPSD 학습 모델은 88.61 ANLS를 보고한다.
- 단순히 1/8 view를 추가한 base는 58.96이므로, 같은 backbone에서 학습된 readout이 inference-only resize보다 29.65 points 높다.
- 저주파 filter는 원본 token budget에서 ANLS 26.4→39.3, 64-token matched setting에서 29.2→67.0을 만들었다고 보고된다.
- glyph token replacement는 OPSD accuracy를 90.5→71.5로 낮췄지만 같은 수의 random background token replacement는 90.5→91.0이었다.
- specialization trade-off도 있다. OPSD는 base 대비 AI2D 86.66→85.33, DocVQA 95.93→92.98, OCRBench 879→833으로 낮아졌다.

### 저자 주장

hidden text는 encoder에 어느 정도 표현되지만 high-frequency interference와 spatial selection/readout 실패 때문에 최종 답변에 나타나지 않으며, privileged low-resolution view로 학습하면 original-only inference에서도 복구할 수 있다는 주장이다.

### 비교 가능성 감사

같은 Qwen3.5-9B 기반 비교는 유효하지만 폐쇄형 모델 이름·preprocessor·API revision은 조건이 다르다. `not strictly apples-to-apples`다. production benchmark가 gated이고 평가 모델 일부가 가변 API이므로 raw predictions와 exact model revision 없이는 표 전체를 재현하기 어렵다.

### 진단 → 가설 → 최소 실험

- **진단:** 해상 표지판, 선박명, CCTV distant text는 원본 고해상도 입력에서도 배경 texture에 묻힐 수 있다.
- **가설:** 원본 단일 view보다 원본+low-pass/downscale dual-view가 distant maritime OCR을 안정화한다.
- **최소 실험:** 선박명·항로표지 100개 crop에 original, downscale, Gaussian low-pass, dual-view 조건을 적용한다. ANLS와 exact-match, small-text height bin별 성능을 비교한다. dual-view가 원본보다 10 points 이상 높고 일반 OCR 하락이 2 points 이내면 inference pipeline에 추가한다.

## 8. 교차 신호

1. **split unit이 metric만큼 중요하다.** WoodBR의 tree ID와 Thermal-UAV의 geographic block은 random image split보다 배포 조건에 가깝다.
2. **aggregate accuracy는 class collapse를 숨긴다.** temporal driving 결과는 macro-F1, per-class recall, confusion matrix가 필수임을 보여준다.
3. **정답과 visual dependency를 분리해야 한다.** TerraAgent의 evidence ablation과 SquintBench의 glyph-token intervention은 모델이 실제 visual cue를 썼는지 직접 건드린다.
4. **높은 SOTA 차이보다 baseline 포화도를 본다.** Thermal-UAV-Paired의 97.0%는 94.6% strong baseline과 함께 읽어야 한다.
5. **intervention 없는 해석은 약하다.** group split, frame shuffle, evidence swap, frequency filtering처럼 mechanism을 바꾸는 최소 실험이 leaderboard 숫자보다 정보량이 높다.

## 9. 오늘의 benchmark signal 3

1. **Group-disjoint evaluation:** 같은 종·장면이라도 specimen, vessel, camera, flight, geographic block 단위 분리가 없으면 실제 일반화가 과대평가될 수 있다.
2. **Class-wise temporal audit:** 평균 정확도 50%가 무작위 수준이 아니라 100/0 class collapse일 수 있으므로 class별 결과와 frame-order control이 필수다.
3. **Evidence sensitivity:** correct answer가 image ablation에도 유지되면 grounded success가 아니다. accuracy와 visual-dependency/evidence-support를 함께 보고해야 한다.

## 10. Woojin 연구에 바로 연결할 포인트

- 해무·선박 detection split을 `image random`과 `vessel/camera/day disjoint` 두 버전으로 고정해 성능 격차를 기록한다.
- maritime video VQA에 frame-reverse, frame-shuffle, single-frame 세 control을 추가해 실제 temporal cue 사용 여부를 판별한다.
- answer accuracy 옆에 evidence-ablation sensitivity와 answer–box joint success를 고정 열로 둔다.
- UAV/remote-sensing retrieval은 좌표 기반 train-test 최근접 거리 histogram을 필수 artifact로 보존한다.
- 작은 문자와 작은 객체 모두 original/high-resolution만 고집하지 말고 low-pass/downscale 보조 view를 동일 token budget에서 비교한다.
- 모든 실행에 dataset revision, group split key, model revision, frame budget, input resolution, evaluator commit, raw prediction을 함께 보존한다.
