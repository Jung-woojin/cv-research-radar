### C1. Training Lightweight Gaze Models without Target Gaze Annotation: What Makes a Good Teacher?

**날짜:** v1 2026-11-24 UTC, 최근 공개분.

**문제·방법·저자 보고:** gaze-point label 출처만 바꾸고 student·학습 절차·361k sample을 고정한다. 세 video dataset, 두 student 크기, 세 seed와 11개 supervision 조건을 비교한다. Gaze-LLE label로 학습한 ViT-Small의 평균 거리 오류는 0.187, annotation 학습은 0.196이다. ViT-Tiny는 laptop CPU에서 teacher 대비 32배 빠르다고 보고한다. 특정 실행 조건의 비율이지 모든 장치의 가속률은 아니다.

다른 사람의 face center를 prompt에 주면 InternVL3·Qwen3-VL이 이를 반환하는 비율이 93.4%·81.1%이며, 좌표 복사 baseline이 InternVL3 label과 student를 설명한다. **좋은 답처럼 보이는 label과 유용한 시각 감독을 구분하는 대조군**이 기여다. [공식 초록](https://arxiv.org/abs/2611.33014)

**진단·한계:** student 평가는 human annotation으로 해야 한다. target gaze annotation을 쓰지 않았다는 사실이 foundation backbone의 전체 pretraining overlap 부재를 뜻하지 않는다. VAT·ChildPlay·VACATION을 사용하며 MTGS는 앞의 두 dataset 학습 노출이 있어 VACATION held-out 확인이 중요하다. code·weights bundle은 이번 조사에서 확인하지 못했다. 사용자 연구에는 평균 teacher 점수보다 위치·오류 유형별 pseudo-label 효용을 감사하는 방식이 유용하다. [실험 설계·본문](https://arxiv.org/html/2611.33014v1)

### C2. PointX: Multi-View Consistent Intrinsics by Querying Surface Points

**날짜:** v1 2026-11-24 UTC, 최근 공개분.

**방법·저자 보고:** image별 intrinsic을 독립 예측하지 않고, 같은 표면점에 대응하는 여러 view token을 모아 albedo·roughness·metallicity·normal·irradiance를 한 번 decode한다. 동일 점의 예측은 구성상 같지만 per-view map의 일치는 추정 geometry·correspondence 정밀도에 제한된다. [공식 원문](https://arxiv.org/abs/2611.33157)

**사실·진단:** 프로젝트는 visibility confidence로 가중 pooling하며, view 증가에 따른 정확도 이득의 상당 부분이 pooling 없이도 multi-view transformer에서 나온다고 설명한다. Hypersim test scene으로 학습한 비교법도 표시한다. view 수·학습 데이터가 다른 headline 비교는 `not strictly apples-to-apples`다. **후속:** 정확한 track와 교란 track에서 “점별 일관성”과 GT intrinsic error를 따로 측정하자. 잘못 연결된 점도 일관되게 틀릴 수 있다. 코드·weights 실행 가능성은 미확인이다. [저자 프로젝트](https://pointx-paper.github.io/)

### C3. Linear Probes Can Guide: Training-Free Control of Representation Generators

**날짜:** v1 2026-11-24 UTC, 최근 공개분.

**방법·저자 주장:** LiSM은 representation generator의 linear probe로 class·attribute·foreground·keypoint 제어를 통합한다. 이상적인 denoiser의 clean prediction에 선형 probe를 적용하면 probe score의 posterior mean을 얻는다는 논리에서 출발한다. 이 성질은 임의 nonlinear semantic의 완전한 제어 보장이 아니다. [공식 초록](https://arxiv.org/abs/2611.33037)

**진단·후속:** Fit-Path는 제약 만족과 보존의 균형을 개선하며 internal probe와 external evaluator 간 차이도 평가한다. “training-free”는 generator·foundation encoder·probe 학습 자체가 없다는 뜻이 아니다. 내부 점수 상승이 외부 인식·사람 판단에서도 유지되는지, 희귀 속성 조합에서 검사할 가치가 있다. 정확한 최저 VRAM·전체 비용과 다운로드 가능한 실행 bundle은 미확인이다. [본문](https://arxiv.org/html/2611.33037v1) · [프로젝트](https://penway.cn/lism/)

### C5. RePix-VFI: Re-rendering Observed Pixels for Video Frame Interpolation with Generative Priors from One-Step Diffusion

**날짜:** v1 2026-11-24 UTC, 최근 공개분.

**방법·저자 보고:** flow draft를 one-step video diffusion으로 보정하고, 생성 결과와 양쪽 keyframe 사이 correspondence를 구해 원본 RGB를 VAE 밖에서 다시 렌더링한다. appearance fusion head가 생성 appearance와 결합한다. SNU-FILM ×8·×16에서 비교한 diffusion baseline보다 PSNR +1.71·+1.48dB, 기존 multi-frame diffusion 대비 32~42배 가속을 보고한다. [공식 원문](https://arxiv.org/abs/2611.33016)

[프로젝트](https://kaist-viclab.github.io/RePix-VFI_site/) · [repo](https://github.com/KAIST-VICLab/RePix-VFI)

### S1. RecordRoute: Auditing Agent Failures with Localization-Guided Diagnosis

**날짜:** v1 2026-11-24 UTC, 최근 공개분.

**방법·저자 보고:** trajectory 내 record를 word·character feature로 비교해 최초 결정적 오류를 고른 뒤, 선택 record와 metadata로 error mode를 진단한다. Who&When Pro의 controlled injection에서 actor·step 예측을 고정하면 local diagnosis의 pooled joint accuracy는 77.47%, full trace는 69.28%다. [공식 원문](https://arxiv.org/abs/2611.33022)

**진단·후속:** injected text의 흔적을 읽은 것인지 자연 실패 원인을 찾은 것인지 별도 검증이 필요하다. 선택 record만 보는 이득과 긴 문맥 truncation 손해를 같은 token budget에서 분리하자. causal repair로 실패가 회복되는지 확인하기 전에는 “원인 발견”보다 “오류 귀속 정확도”로 표현하는 편이 정확하다. code·weights와 자연 실패 전이는 미확인이다.

### S2. Delegent: A Multi-Agent Harness That Reduces Cost without Sacrificing Performance

**날짜:** v1 2026-11-24 UTC, 최근 공개분.

**방법·저자 보고:** frontier 모델이 주도하며 검색·코드 조사 등 제한된 일을 local SLM에 맡긴다. 27B FP8 SLM에서 frontier 비용을 long-horizon coding 67%, agentic search 59% 줄였고, 2B SLM에서도 coding 66% 절감을 보고한다. router 학습은 하지 않는다. [공식 원문](https://arxiv.org/abs/2611.33098)

**사실·주의:** repo에는 구현·test·재현 문서가 있다. headline은 frontier 비용이며 local GPU 시간·전력·wall-clock·검증 부담까지 포함한 총비용 절감과 다르다. “성능 손실 없음”도 평가 task의 결과이지 모든 위임의 무손실 보장이 아니다. **후속:** 같은 답변 정확도에서 evidence 누락·검증 호출·총 latency를 함께 기록하자. 설치·실행하지 않았다. [공식 repo](https://github.com/castorini/delegent)

### S3. LoomKV: Lossless KV Cache Compression from GPU Memory to SSD for LLM Serving

**날짜:** v1 2026-11-24 UTC, 최근 공개분.

**방법·저자 보고:** BF16 high-byte 분포를 이용해 KV를 lossless 압축하고 external tier와 GPU pool에 각각 적용한다. 아홉 모델에서 BF16 저장 크기는 raw의 0.71이다. LRU capacity cliff 근처의 tier-mode goodput 2.7~3.6배와 달리, 실제 AI IDE trace의 tier/pool 결과는 1.24·1.59배다. [공식 원문](https://arxiv.org/abs/2611.32954)

**진단·후속:** 압축률·capacity 효과·kernel 효과를 구분해야 한다. tier는 bit-exact를 보고하지만 pool-mode attention의 numerical equivalence를 임의 bitwise 동일성으로 확대하지 않는다. capacity가 충분하면 최대 2.2% throughput 비용도 보고한다. working-set 크기를 capacity 경계 양쪽으로 sweep해 비용·이득을 같이 측정하자. 코드·지원 GPU·최저 VRAM은 미확인이다.

## 6) 중요한 Finding 3개

1. **감독의 정확도와 효용은 다르다.** Gaze 연구의 좌표 복사 대조군은 그럴듯한 teacher 답이 시각 추론을 반영하지 않을 수 있음을 보여준다. BioLoom의 related positive 역시 관계의 참·거짓과 학습 효용을 별도 검증해야 한다. 전자는 저자 실험, 두 연구를 연결한 해석은 추론이다.
2. **일관성은 정확성의 충분조건이 아니다.** PointX는 동일 점에 하나의 값을 주지만 대응점이 틀리면 잘못된 일관성이 생길 수 있다. E-MAPS의 memory도 관측이 희소할 때 잘못된 상태를 유지할 가능성이 있다. 후자는 제안된 실패 가설이며 확인된 failure 수치가 아니다.
3. **좋은 평균은 병목을 가릴 수 있다.** GRAPE의 난이도·환경별 순위, LoomKV의 capacity cliff, Delegent의 frontier 비용은 각각 조건부 결과다. 합계 수치보다 실패 subset과 실제 자원 경계를 먼저 확인하자.

## 7) 과대평가 가능성 / 주의할 연구

- **EventDiffusion:** “2배 정확도”를 실제 event 재현·downstream 인식·모든 camera의 두 배 성능으로 확장하지 않는다. 조건부 생성의 다양성과 GT event 충실도는 다른 목적이다.
- **Delegent / LoomKV:** frontier 청구 비용 절감과 cache capacity 경계의 최대 가속을 총 작업시간 절감으로 읽지 않는다. local 자원·작업 분포·용량 여유를 맞추기 전 비교는 `not strictly apples-to-apples`다.
- **공통:** source split·external data·resolution·prompt/frame budget·checkpoint·dtype·hardware·evaluator를 고정한다. 미확인 조건을 같다고 가정하지 않는다.

## 9) 1위 논문 5~10분 mini-review

**왜 중요한가:** teacher 출력의 그럴듯함을 student 학습 효용과 동일시하는 blind spot을 직접 검사한다. 같은 student와 sample을 유지한 실험이 핵심이며 새로운 block의 효과를 주장하는 연구가 아니다.

**읽기 순서:** label-source 통제 → target dataset 학습 노출 → copy-coordinate baseline → human annotation 평가 → confidence replacement·prediction spread를 확인한다.

**핵심 contribution:** target gaze annotation 없이도 specialist label이 유용할 수 있고, 좌표를 제공한 VLM은 이를 복사하는 shortcut으로 좋아 보일 수 있다. 또한 teacher label을 기준으로 student를 평가하면 실패를 숨길 수 있다. specialist label의 fit 용이성이 효용을 설명할 가능성은 지지되지만 단일 인과기전으로 확정된 것은 아니다.

**놓치면 안 될 negative result:** confidence-guided replacement는 같은 수 random replacement보다 일관되게 좋지 않았다. 거리 오류만 보면 중앙 쏠림을 놓칠 수 있어 PCK와 예측 분산을 함께 봐야 한다. 이 결과를 모든 detector confidence의 무용성으로 일반화하지 않는다.

**사용자 연구에 가져올 것:** pseudo-label 기반 작은 모델에서 teacher AP만으로 선정하지 말고, 크기·위치·희귀 상태별 오류와 student 예측 분산을 함께 기록한다. gaze에서 작은 객체 탐지로의 전이는 아직 연구 가설이다. [본문·대조 실험](https://arxiv.org/html/2611.33014v1)

## 10) 후속 연구 씨앗 3개

아래는 미실행 계획이다. 점수·비용은 조사자의 판단이며 실측치나 출판 보장이 아니다. Compute cost /5는 낮을수록 가볍다.

### A. 같은 평균 오류의 teacher도 희귀 상태를 다르게 가르치는가?

- **Observation → Diagnosis:** C1에서 teacher 모방과 실제 gaze 성능이 분리된다. 평균 label error만으로 student의 tail failure를 설명할 수 있는가?
- **Hypothesis → 최소 개입:** 평균 오류를 맞춰도 주변부·social gaze 오류의 집중도가 student tail error를 바꿀 수 있다. label source를 추가하기보다 오류 위치 분포만 바꾼다.
- **첫 실험:** VAT·ChildPlay·VACATION의 허용된 고정 subset에서 teacher label과 human label을 감사한다. 중심/주변부·social/object를 층화하고 동일 수·동일 평균 거리 오류의 controlled label corruption을 만든다. student 학습 전 label 분포·유효 sample 수를 검사한다.
- **Baseline·metric:** annotation, specialist label, 동일 오류의 무작위 교란. ADE·PCK·prediction spread·tail error를 clip 단위로 비교한다.
- **GO/KILL:** 다른 seed와 held-out clip에서도 오류 구조에 따른 tail 차이가 유지되면 GO. 평균 오류·sample 수를 맞추면 사라지면 가설 KILL이며, 평균 proxy가 충분한 적용 범위를 얻는다.
- **기여·novelty risk:** teacher 효용의 오류 구조 진단. 원논문에 teacher selection·fit 분석이 이미 있어 단순 재현은 신규성이 낮다. 첫 1~2주 감사, 이후 4~8주 통제·domain 확장을 검토한다. 감사 cost 1/5, student 학습 3/5이며 8GB 적합성은 미측정이다.

### B. 정확히 일관된 표현은 잘못된 대응점을 얼마나 숨기는가?

- **Observation → Diagnosis:** C2는 동일 표면점의 출력 일치를 구성상 보장한다. 대응점 오류가 있을 때 일관성 metric이 오류를 과소평가할 수 있다.
- **Hypothesis → 최소 개입:** GT track와 교란 track를 바꾸면 consistency가 유지돼도 intrinsic error·relighting error는 증가한다.
- **첫 실험:** 공개 합성 scene의 GT geometry에서 occlusion·깊이·track perturbation을 개별 주입한다. 실행 artifact가 확보되기 전에는 GT correspondence 감사까지만 진행한다.
- **Baseline·metric:** per-view 독립 예측, naive fusion, point query의 동일 view budget. GT intrinsic error·cross-view error·visibility·relighting residual을 따로 측정한다.
- **GO/KILL:** 실제 reconstruction noise에서도 consistency와 정확도 괴리가 반복되면 GO. 임의의 비현실적 교란에서만 나타나면 실용 가설 KILL이다.
- **기여·novelty risk:** 일관성 지표의 적용 경계. geometry 의존성은 원문도 인정하므로 “대응점이 틀리면 성능 저하”만으로는 부족하다. 4~8주에는 error predictor의 held-out 검증까지 필요하다. cost 2~3/5, artifact·GPU 비용 미확인.

### C. 합성 손상으로 고른 개입이 실제 손상에서도 같은 실패를 고치는가?

- **Observation → Diagnosis:** V1의 synthetic/real 순위 역전은 합성 robustness 점수만의 모델 선택이 위험할 수 있음을 보여준다.
- **Hypothesis → 최소 개입:** 평균 synthetic 점수보다 corruption별·난이도별 failure profile이 실제 환경 전이를 더 잘 예측할 수 있다.
- **첫 실험:** GRAPE의 기존 clip·질문을 고정하고 severity를 여러 수준으로 바꾼다. 동영상 source 단위 split과 near-duplicate를 먼저 감사한다. 새 module 없이 selection rule만 바꾼다.
- **Baseline·metric:** 전체 synthetic 평균 기반 선택, corruption 균등 평균, 난이도별 worst-group 선택. 실제 조건별 정확도·기본 질문의 손상률·선택 regret·동일 frame budget의 latency를 비교한다.
- **GO/KILL:** held-out 실제 condition에서 selection regret가 일관되게 줄면 GO. 같은 real set으로 선택·평가하거나 severity 튜닝이 그 set에 의존하면 주장 KILL이다.
- **기여·novelty risk:** 평균 robustness보다 전이 가능한 진단 profile을 찾는 연구. synthetic-to-real 분석은 원논문에 이미 있으므로 severity 일반화·분리된 모델 선택 검증이 필요하다. 1~2주 데이터 감사, 3~4주 작은 paired 평가, 5~8주 복수 모델 검증. 감사 cost 1/5·추론 3/5, full 9B 실행의 8GB 적합성은 미확인이다.

**오늘 첫 행동:** A의 label 감사부터 시작한다. 작은 GPU에서도 모델 학습 전 CPU로 분포·split·clip 중복을 확인할 수 있다. 장기적으로는 B의 관측 정합성과 C의 환경 전이를 연결해 “일관된 내부 상태가 실제 세계에서 정확한가”를 추적할 수 있으나, 현재는 제안이다.
