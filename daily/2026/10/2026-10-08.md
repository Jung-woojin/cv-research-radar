## 2. CV / DL-CV 핵심 — 6편

### 2.1 Data Leakage in Patch-Based Hyperspectral Image Classification: Quantifying the Impact of Spatial Overlap

**문제·방법:** HSI 분류에서 인접 pixel patch가 train/test에 함께 들어가면 중심 pixel은 달라도 주변 내용이 겹친다. 논문은 random pixel split과 spatially disjoint split을 비교하고 patch 크기에 따른 overlap을 직접 계산한다.

**저자 결과:** Pavia University의 3D-CNN overall accuracy는 random split 96.17%, spatial split 55.20%다. patch 크기가 5에서 19로 커질 때 overlap은 23.28%에서 77.02%로 증가한다. 이 차이는 architecture 개선이 아니라 평가 protocol 차이에서 생긴다. [원문](https://arxiv.org/html/2610.08770v1)

**재현 감사:** 공식 저장소의 기본 설정은 random split patch size 5, spatial split patch size 19로 서로 다르다. 따라서 저장소 기본값을 그대로 비교하면 split 효과와 receptive field 효과가 섞인다. [공식 코드](https://github.com/mqalkhatib/Data_Leakage_in_HSI_Classification)

**해석·최소 실험:** 같은 patch size·seed·class sample 수를 고정한 뒤 random/spatial split만 바꾼다. 그 다음 patch size를 바꾸며 train/test footprint intersection과 정확도를 함께 그린다. **가설:** 정확도 하락의 상당 부분은 scene generalization 실패이며, 더 큰 patch의 이점은 leakage가 제거되면 줄어든다.

### 2.2 Post-Training Semantic Lifting for 3D Gaussian Splatting

**문제·방법:** 2D detector 결과를 이미 학습된 3D Gaussian scene으로 올릴 때 오류가 detector, multi-view lifting, 3D representation 중 어디서 생기는지 분리한다. 장면을 다시 학습하지 않는 post-training 방식이다.

**저자 결과:** ScanNet++에서 annotation mask를 입력으로 쓴 lifting mIoU는 0.80, YOLO mask는 0.54로 보고돼 detector로 인한 격차가 0.26이다. 39개 class-scene pair 중 27개에서 3D IoU가 2D pixel IoU보다 높아 multi-view aggregation이 일부 오류를 상쇄한다. 한 번도 검출되지 않은 class는 복구할 수 없다. [원문](https://arxiv.org/html/2610.08756v1)

**공개 상태:** 공식 저장소에는 semantic lifting 구현이 있다. 저장소 파일 존재와 논문 재현 성공은 다르다. [공식 코드](https://github.com/ivanver02/semantic-lifting-3dgs)

**해석·최소 실험:** annotation mask / 실제 detector / controlled false-negative mask를 같은 3D scene에 넣고 detector recall과 최종 3D IoU 관계를 측정한다. **가설:** lifting 개선보다 detector의 view coverage를 보장하는 것이 먼저다.

### 2.3 Knowing When to Trust a Prior: Reliability-Gated Cue Fusion for Video Gaze Prediction

**문제·방법:** defocus 같은 prior는 일부 scene에서 도움이 되지만 sports나 web 영상에서는 해로울 수 있다. FocusGate는 prior의 신뢰도를 추정해 cue를 조건부로 결합한다.

**저자 결과:** 저자 표의 16개 비교 cell에서 방향성 개선이 16개, 그중 15개가 유의하다고 보고한다. 추가 지연은 약 1%다. 무조건적 defocus fusion은 일부 domain에서 성능을 악화한다. [원문](https://arxiv.org/html/2610.08663v1)

**해석·한계:** gate가 진짜 prior reliability를 학습하는지, dataset/domain identity를 shortcut으로 쓰는지 분리해야 한다. domain holdout과 blur/defocus 품질 교란이 필요하다.

**최소 실험:** backbone과 cue를 고정하고 unconditional fusion / learned gate / oracle reliability / shuffled reliability를 비교한다. **KILL:** shuffled gate도 같은 이득이면 신뢰도 추정이라는 설명을 중단한다.

### 2.4 Catastrophic Forgetting in Sequential Thermal Anti-UAV Detection

**문제·방법:** 열화상 UAV 탐지를 scale 순서대로 학습할 때 표적 크기별 gradient imbalance가 이전 지식을 어떻게 지우는지 분석한다.

**저자 결과:** continuous scale training 자료에서 tiny 87.9%, small 11.9%, large 0%의 비중이 제시된다. Stage 3 첫 epoch에 이전 large-target mAP가 0.000으로 떨어지는 사례가 보고된다. 다만 Stage 3은 single seed이고 일부 단계에서 optimizer·batch·protection 조건이 달라 전체 결과를 순서 효과만으로 돌릴 수 없다. [원문](https://arxiv.org/html/2610.08315v1)

**해석·최소 실험:** 같은 optimizer·batch·augmentation·seed에서 scale curriculum 순서만 바꾸고, scale별 gradient norm과 old-scale mAP를 매 epoch 기록한다. **가설:** tiny가 많은 stage의 gradient가 shared representation을 지배해 large-scale 결정 경계를 빠르게 이동시킨다.

### 2.5 Test-Time Adaptation of Quantized ViTs via Single-Pass Quantizer-Aligned Recalibration

**문제·방법:** quantized ViT는 distribution shift에서 activation이 고정 quantizer range를 다르게 사용한다. QuAR는 frozen quantizer 직전 activation의 running per-channel statistics를 source calibration 쪽으로 맞춘다. backprop, parameter update, 과거 sample 저장 없이 한 번의 forward 안에서 동작한다.

**저자 결과:** ImageNet-C ViT-B에서 strongest backprop-free baseline 대비 W8A8 +2.28 points, W3A3 +4.00 points를 보고한다. TITAN RTX의 PyTorch quantize/dequantize harness에서 No Adapt 6.0ms/image이고 QuAR는 약 1.10배 latency, 메모리 증가는 0.17MB다. Jetson Orin Nano에서는 No Adapt latency의 1.071배라고 보고한다. 절대 시간은 integer-only deployment 수치가 아니다. [원문](https://arxiv.org/html/2610.08358v1)

**공개 상태·최소 실험:** 모든 표·그림 재현용 코드가 공개됐다고 논문이 명시한다. [QuAR 코드](https://github.com/chahh9808/QuAR) 먼저 W6A6 ViT-B에서 corruption 순서를 고정/교란하고 continual state carry가 drift를 만드는지 3 seeds로 본다. 실제 TensorRT/INT kernel에서는 상대 overhead를 다시 측정해야 한다.

### 2.6 Backend-Agnostic Sparse Attention for Fast High-Resolution Visual Generation

**문제·방법:** sliding-window sparse attention은 품질이 좋지만 irregular kernel이 이론적 sparsity를 실제 속도로 바꾸지 못할 수 있다. BASA는 block 사이에서 window를 shift해 cross-window interaction을 만들고 표준 backend를 사용한다.

**저자 결과:** FLUX 1024→2048 실험에서 BASA w=32,p=4는 dense output 대비 PSNR 24.09, FID 20.97이며 weighted attention latency는 dense SDPA 21.666ms에서 8.871ms로 2.443배 빨라진다. 이론 배속의 90.1%다. Wan에서는 attention 구간 최대 4.52배를 보고한다. 모든 실험은 single A100이다. [원문](https://arxiv.org/html/2610.08772v1)

**주의:** 이는 attention layer 또는 weighted MSA 배속이며 전체 생성 pipeline 배속이 아니다. FLUX 비교는 동일 dense teacher로 sparse variant를 distill하지만, 해상도·window·backend가 다른 표는 not strictly apples-to-apples다.

**최소 실험:** 같은 SDPA backend와 window density에서 BASA/Swin을 비교하고 attention latency, 전체 denoising latency, peak VRAM, boundary artifact를 따로 기록한다.

## 3. VLM / Multimodal / Video 핵심 — 3편

### 3.1 Stable Scores, Unstable Answers: Frame Phase and Option Order in Video Multiple-Choice Evaluation

**문제·방법:** 같은 영상에서 같은 개수의 frame을 뽑아도 sampling 시작 위상과 선택지 순서가 답을 바꿀 수 있다. 논문은 aggregate accuracy와 per-item answer stability를 분리한다.

**저자 결과:** 8-frame sampling rate를 유지하고 half-step phase만 바꿨을 때 답의 23.6%가 달라지지만 정확도 차이는 0.7 percentage point에 불과한 조건이 보고된다. 평균 점수가 안정적이어도 개별 예측은 불안정할 수 있다. [원문](https://arxiv.org/html/2610.08649v1)

**최소 실험:** 기존 video MCQ 평가에 phase 4개×option permutation 4개를 추가하고, 평균 정확도뿐 아니라 answer flip rate, entropy, correctness transition matrix를 저장한다. **가설:** 짧은 결정적 사건이 frame 경계에 걸릴수록 phase 민감도가 커진다.

### 3.2 Have I Seen Enough? Frozen Video-Language Models Encode Evidence Readiness

**문제·방법:** 영상이 도착하는 중 언제 답할 증거가 충분해졌는지를 frozen VideoLLM activation에서 읽을 수 있는지 분석한다.

**저자 결과:** evidence readiness probe의 AUROC는 조건별 0.733–0.905로 보고된다. 오답 sample만 본 조건에서도 AUROC 0.722가 보고돼 correctness와 완전히 같은 신호는 아니라는 저자 주장이다. [원문](https://arxiv.org/html/2610.08560v1)

**해석·한계:** probe가 내용의 충분함보다 frame index나 video length prior를 읽을 수 있다. 같은 prefix 내용에 time index를 교란하고, short/long video 간 calibration을 분리해야 한다.

**최소 실험:** frozen activation probe / frame-count-only baseline / shuffled-content baseline을 비교하고, early-stop 시 정확도·평균 frames·P95 latency를 함께 측정한다.

### 3.3 SpaTime: Streaming Vision-Language Models for Spatio-temporal Reasoning

**문제·방법:** offline spatial VLM은 전체 영상을 기다린다. SpaTime은 frozen causal geometry encoder의 token을 매 frame 언어모델에 넣고, ground-truth response frame과의 거리를 줄이는 differentiable response-time loss를 사용한다.

**저자 결과:** StreamVSTI-Bench에서 overall accuracy 49.2%, mean response-time error 0.12초다. 표의 strongest streaming accuracy baseline VideoLLM-online은 48.40%, strongest timing baseline Streamo는 0.35초이므로 정확도와 timing의 최강 baseline은 서로 다르다. 저자의 “66% 감소”는 0.35초 대비다. 모델은 Qwen2.5-VL-7B-Instruct 기반이며 1,461.2M, 즉 15.0%의 parameter를 학습한다. training set은 132,568 samples다. [원문](https://arxiv.org/html/2610.08713v1)

**해석·한계:** 500개 object-frame pair의 first-seen annotation human agreement는 84.4%라 response target 자체에 오차가 있다. offline model과 streaming timing은 직접 비교할 수 없다.

**최소 실험:** 같은 causal frame stream에서 geometry token 제거, response-time loss 제거, oracle first-visible frame을 비교한다. accuracy와 조기 응답률을 함께 보며 너무 빨리 답해 틀리는 비율을 guardrail로 둔다.

## 4. LLM / Agent / Reasoning / 학습 / 시스템 — 3편

### 4.1 Selective Transfer of RL Updates for Visual Reasoning

**문제·방법:** RL-tuned 모델의 전체 parameter delta를 base VLM에 섞으면 reasoning 개선과 perception 손상을 함께 옮길 수 있다. Selective-RL은 update의 일부만 선택적으로 전이한다.

**저자 결과:** 15개 비교 중 12개에서 full interpolation보다 낫고, Qwen MathVision 조건에서 +8.55 percentage points를 보고한다. POPE는 86.90에서 86.80으로 0.10 point 낮아지는 조건도 있다. error taxonomy는 selective-only success 83개를 분석하지만 reasoning/perception을 함께 묶은 범주가 65개라 세부 원인은 더 나눠야 한다. [원문](https://arxiv.org/html/2610.08659v1), [공식 익명 저장소](https://anonymous.4open.science/r/selective-rl)

**최소 실험:** full delta / layerwise norm selection / random matched-norm selection / proposed selection을 같은 interpolation norm에서 비교한다. reasoning gain과 POPE·grounding regression을 함께 기록한다.

### 4.2 GeoPID: Decomposing and Steering Visual Information in Vision-Language Models

**문제·방법:** VLM이 text에 과도하게 의존하는 문제를 representation geometry에서 redundant, vision-unique, text-unique, synergy 성분으로 분해한다. inference에서 vision-unique subspace만 증폭한다.

**저자 결과:** 22개 VLM·14개 benchmark 분석에서 평균 상대 정확도 7.63% 향상을 보고한다. 이는 absolute percentage point가 아니다. intervention은 parameter update가 없는 training-free 방식이다. [원문](https://arxiv.org/html/2610.08401v1)

**해석·한계:** batch-wise PCA reference와 rank/threshold 선택이 결과에 영향을 준다. vision-unique 방향이 실제 visual grounding인지 dataset-specific answer direction인지 검증해야 한다.

**최소 실험:** correct image / mismatched image / blurred image에서 같은 subspace intervention을 적용한다. 올바른 image에서만 개선되고 mismatched 조건에서 이득이 사라져야 시각 근거 증폭이라는 설명이 강해진다.

### 4.3 CtrlCache: Accelerating Interactive Video World Models with Control-Aware Caching

**문제·방법:** interactive video world model에서 제어가 바뀌는 transition 구간까지 무조건 residual을 재사용하면 품질이 손상될 수 있다. CtrlCache는 control sequence로 initial/transition/turning/steady chunk를 나누고 갱신을 조절한다.

**저자 결과:** Matrix-Game 2.0에서 WBench Overall은 original 0.6543, EasyCache 0.6625, CtrlCache 0.6786이다. DiT-backbone denoising latency는 14.99초에서 10.67초로 1.41배다. 단, KV-cache commit/update 시간은 제외된다. single A100, seed 42다. LingBot-World v1/v2에서도 각각 1.26배/1.21배를 보고한다. [원문](https://arxiv.org/html/2610.08777v1)

**해석·최소 실험:** 같은 control trace에서 cache update와 commit을 포함한 end-to-end latency, transition 직후의 physics/setting score를 분리한다. **가설:** 평균 chunk보다 action transition에서 계산을 보존하는 것이 품질에 더 중요하다.

## 5. 새 모델 / GitHub repo / dataset / benchmark / framework — 5건

1. **HSI leakage 코드:** random/spatial split과 overlap 계산 코드를 확인할 수 있다. 기본 patch size가 split마다 달라 직접 비교 전에 config를 맞춰야 한다. [저장소](https://github.com/mqalkhatib/Data_Leakage_in_HSI_Classification)
2. **Semantic Lifting 코드:** post-training lifting 구현이 공개되어 detector mask를 교체하는 진단 실험의 출발점으로 적합하다. [저장소](https://github.com/ivanver02/semantic-lifting-3dgs)
3. **QuAR 코드:** 논문은 모든 표·그림의 configuration을 공개했다고 명시한다. 우선 ImageNet-C W6A6의 single-pass cost와 continual state를 확인한다. [저장소](https://github.com/chahh9808/QuAR)
4. **StreamVSTI-Bench / StreamVSI-Bench:** response time을 평가하는 streaming adaptation이다. charitable/strict scoring과 miss를 video end까지의 시간으로 부과하는 규칙을 함께 읽어야 한다. [SpaTime 원문](https://arxiv.org/html/2610.08713v1)
5. **World Models’ Last Exam in Physics:** 40개 task·9개 물리 범주·8개 생성 모델·1,280개 영상을 대상으로 reference video 없이 관측량을 측정한다. best overall 57.76/100이라는 저자 결과가 있지만 consistency gate가 80 미만이면 physics score 기여를 0으로 만드는 설계를 함께 검토해야 한다. 오늘 상세 선정에서는 제외했지만 benchmark release로 추적한다. [원문](https://arxiv.org/html/2610.08791v1)

파일이나 링크 존재만 확인했으며 설치·weight load·논문 수치 재현 성공은 주장하지 않는다.

## 6. 중요한 Finding — 3개

1. **평가 protocol이 모델 순위를 만들 수 있다.** HSI의 spatial overlap과 video MCQ의 frame phase는 모델을 바꾸지 않고도 큰 차이나 예측 변동을 만든다.
2. **오류가 생기는 단계를 나누면 연구 우선순위가 바뀐다.** semantic lifting은 2D detector를, evidence readiness는 관측 충분성과 최종 correctness를, GeoPID는 vision/text subspace를 분리한다.
3. **평균 효율은 취약 구간을 숨긴다.** BASA는 attention kernel, CtrlCache는 steady/transition chunk, QuAR는 quantized inference harness가 핵심이다. 전체 latency와 transition 품질을 따로 측정해야 한다.

## 7. 과대평가 가능성 / 주의할 연구

- **QuAR:** PyTorch fake-quant/dequant harness의 절대 latency를 integer-only deployment 수치로 옮기지 않는다. Jetson의 상대 overhead는 유용하지만 실제 runtime별 검증이 필요하다.
- **GeoPID:** 평균 상대 정확도 7.63%를 7.63 percentage point로 쓰면 안 된다. reference batch와 subspace hyperparameter 민감도를 확인해야 한다.
- **SpaTime:** 66% timing 감소는 accuracy가 가장 높은 streaming baseline이 아니라 timing이 가장 빠른 Streamo와의 비교다. 두 축을 하나의 우월성으로 합치지 않는다.
- **BASA/CtrlCache:** 부분 모듈 latency와 end-to-end wall clock을 구분한다. cache bookkeeping, text encoder, VAE, decode 비용을 누락하면 배속을 과장할 수 있다.

## 8. 오늘 바로 읽을 Top 3

1. **HSI Data Leakage** — 현재 실험의 split·patch pipeline을 즉시 감사할 수 있다.
2. **Post-Training Semantic Lifting** — detector와 3D representation 병목을 나누는 방식이 다른 detection/grounding 연구에도 직접 적용된다.
3. **Stable Scores, Unstable Answers** — 영상 benchmark의 평균 점수에 stability 축을 추가하는 가장 작은 실험을 제시한다.

이 순위는 연구 유용성에 대한 판단이며 분야 전체의 우열이나 독립 재현 결과가 아니다.

## 9. Top 1 mini-review — HSI Data Leakage

**먼저 볼 부분:** random/spatial split 정의 → patch overlap 계산 → Pavia 결과 → 코드의 config 기본값 순서다.

**실제 contribution:** spatially 가까운 중심 pixel을 분리하는 것만으로 충분하지 않고, patch footprint가 train/test에서 겹치는지 측정해야 한다는 점을 수치로 만든다. patch가 클수록 spectral-spatial context가 늘지만 leakage 경로도 커진다.

**인정할 evidence:** 같은 scene에서 random과 spatial protocol의 큰 격차를 보여주고, patch 크기와 overlap 비율을 연결한다. 코드가 있어 split mask와 patch footprint를 직접 감사할 수 있다.

**주의할 부분:** 공식 스크립트의 기본 patch size가 random 5, spatial 19로 다르므로 headline accuracy 비교에는 patch-size confound가 있다. 한 scene 또는 제한된 model 결과를 모든 HSI 데이터셋으로 일반화할 수 없다. seed·class imbalance·buffer width·preprocessing을 맞춘 추가 실험이 필요하다.

**우리에게 주는 조치:** HSI뿐 아니라 remote sensing tile, UAV frame, 의료 영상 patch에서도 “sample ID가 다른가” 대신 “원 영상·공간 footprint·시간 이웃이 겹치는가”를 split validator가 검사하게 한다.

## 10. 후속 연구 씨앗 — 3개

아래 GO/KILL 기준은 실험 전 제안이며 예상 결과가 아니다. 비용 /5는 1이 가볍고 5가 무겁다.

### A. Patch footprint leakage audit를 범용 CV split validator로 확장

- **진단:** patch·tile·clip 단위 데이터는 ID가 달라도 원본 공간/시간이 겹칠 수 있다.
- **가설:** spatial/temporal footprint overlap을 제거하면 headline score는 낮아지지만 cross-scene generalization과 더 잘 정렬된다.
- **최소 실험:** HSI 한 scene에서 동일 patch size·seed·class count를 유지하고 random / spatial block / buffered spatial split을 비교한다.
- **측정:** OA, macro-F1, class별 recall, train-test footprint overlap, seed 3회, train time.
- **GO:** overlap 감소와 성능 하락이 seed 전반에 일관되고 cross-scene 성능과 순위 상관이 높아진다.
- **KILL:** patch size와 class imbalance를 맞춘 뒤 차이가 사라지면 leakage 일반화 주장을 축소한다.
- **비용:** 2/5. 기존 논문의 핵심 결론을 반복하는 데 그치지 않도록 validator와 cross-domain 적용이 필요하다.

### B. Video MCQ의 정확도-안정성 이중 리더보드

- **진단:** 같은 sampling rate에서도 phase와 option order가 답을 바꾸지만 평균 정확도는 거의 같을 수 있다.
- **가설:** 짧은 decisive event와 낮은 evidence readiness가 높은 answer flip rate를 예측한다.
- **최소 실험:** 한 공개 video MCQ subset에서 phase 4개와 option permutation 4개를 평가한다. frame 수와 decode resolution은 고정한다.
- **측정:** mean accuracy, worst-phase accuracy, flip rate, prediction entropy, decisive-event coverage, inference time.
- **GO:** flip rate가 error와 독립적인 failure signal을 제공하고 사건 길이별로 일관된 패턴이 나온다.
- **KILL:** variation이 API nondeterminism 또는 prompt formatting만으로 설명되면 sampling 안정성 주장을 중단한다.
- **비용:** 2/5. 모델 재학습 없이 가능하다.

### C. Detector recall ceiling을 고려한 3D semantic lifting

- **진단:** multi-view lifting이 2D noise를 완화해도 한 번도 검출되지 않은 class는 복구하지 못한다.
- **가설:** low-confidence detection을 바로 버리지 않고 cross-view consistency로 보존하면 3D recall을 높일 수 있다.
- **최소 실험:** annotation / standard threshold / low threshold / low threshold+cross-view consensus mask를 동일 frozen 3DGS에 lift한다.
- **측정:** 2D precision-recall, class별 3D IoU, never-detected class 수, view coverage, 추가 latency.
- **GO:** 2D false positive 증가를 제한하면서 never-detected class와 3D IoU가 개선된다.
- **KILL:** 개선이 annotation mask에만 있거나 false positive가 3D에서 증폭되면 방법 확장을 중단한다.
- **비용:** 3/5. detector 재학습보다 작은 post-training 실험부터 시작한다.

**오늘 가장 먼저 할 일:** A의 split validator를 한 HSI scene에 적용한다. **작은 GPU에서도 가능한 것:** B의 sampling stability audit. **4–8주 후보:** C의 detector–lifting joint calibration.

## 11. 오늘 안 읽어도 되는 것

- World Models’ Last Exam의 40개 task 세부식은 video generation 평가를 직접 시작할 때 읽는다. 오늘은 gate와 측정 구조만 추적한다.
- BASA의 distillation 전체 구현은 attention backend 실험 환경을 확정한 뒤 읽는다.
- CtrlCache는 interactive world model을 실제 운영하지 않는다면 평균 배속 수치만 보고 도입하지 않는다.
- GeoPID의 Rényi mutual information 유도 전체는 image-mismatch control에서 시각 근거 효과가 확인된 뒤 정독한다.
- 보류한 RenderBench·Sparse2comm·Forensic Reserve는 오늘 Top 3와 직접 실험을 끝낸 뒤 후속 radar로 넘긴다.

보고서의 수치와 조건은 공식 원문에 대한 확인이며 독립 재현 결과가 아니다. 빈 항목을 추정치로 채우지 않았고, 공개 여부를 확인하지 못한 code·weights·data는 공개됐다고 쓰지 않았다.
