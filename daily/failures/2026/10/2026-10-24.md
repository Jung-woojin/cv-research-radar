## 1. AgentVQA — 일반 VQA 성능과 agentic visual understanding이 어긋난다

**대상:** *AgentVQA: A Unified Benchmark for Agentic Visual Understanding*  
**실패 조건:** GUI navigation, egocentric video, game, spatial planning, robotics에서 현재 시각 상태와 action history를 이용해 다음 상태·행동·좌표를 판단할 때  
**모델·데이터·설정:** 23개 source dataset에서 수작업 검증한 1,000개 4-choice 문제, 5개 domain별 200개, open/closed 22개 model configuration, native-resolution input

### 확인된 사실

- 최고 모델 Gemini 3.7 Flash의 전체 accuracy는 58.5%였다. domain별로 Games 70.0%, Spatial Planning 62.5%, Robotics 52.5%, Web Agents 40.5%로 편차가 크다.
- 어떤 모델도 전 domain 1위가 아니었다. GPT-5.6-sol thinking-high는 Web Agents 47.0%로 Gemini보다 높고, Qwen3.7 Flash는 Egocentric Videos 72.5%로 가장 높았다.
- 전체 22개 모델 평균 관점에서 Web Agents가 29%, Robotics가 38%로 약했고, general VQA benchmark 순위와의 Spearman 상관은 MMMU-Pro 0.67, GPQA-Diamond 0.59, ChartQA-Pro 0.44였다.
- GPT-5.6-sol은 thinking-none 38.2%에서 thinking-high 55.0%로 16.8%p 상승했다. 반대로 GLM-4.1V-9B는 Base 36.3%, Thinking 35.4%로 하락했다.
- 저자들은 GLM thinking output에서 같은 관찰을 반복하는 “thinking loop”를 사례로 제시했다.
- Gemini 3.1 Pro의 오답을 분류한 분석에서 Web Agents 오답의 78%는 grounding error, Games는 71%가 visual miscomprehension, Robotics는 65%가 spatial confusion, Spatial Planning은 62%가 viewpoint gap으로 분류됐다.
- Web Agents의 trajectory 문제에서 action history를 제거하면 5개 모델 평균 성능이 AitW 9.5%p, MONDAY 10%p 하락했다.

### 저자 주장·인정

- **저자 주장:** offline AgentVQA의 matched Spatial Planning 순위는 online SpatialWorld Physical track과 높은 상관을 보이며, domain-specific agentic 평가가 일반 VQA보다 유용하다.
- **저자 인정:** reasoning 효과는 모델별로 다르고, perception과 state construction 실패를 긴 chain-of-thought만으로 해결하지 못한다.
- **분석 한계:** failure taxonomy의 대규모 분류는 Gemini 3.1 Pro가 수행했고 무작위 100개 assignment만 사람이 재검토했다. 오류 비율을 전체 모델에 일반화할 수 없다.

### 기존 주장과 충돌하는 지점

더 긴 추론과 높은 일반 VQA 점수가 agentic 능력으로 자동 전이된다는 기대와 충돌한다. 모델의 주 실패는 계획 논리 이전의 **UI/객체 grounding, motion reading, viewpoint-aware state construction**이었다. general benchmark의 순위가 agent 배치 선택을 대신할 수 없다.

### 진단 → 가설 → 최소 실험

- **진단:** 긴 reasoning이 부정확한 visual state를 반복 확신하게 만들며, perception error와 planning error가 한 decoder 안에서 섞인다.
- **가설:** 짧은 perception pass가 구조화된 state를 만들고 별도 planner가 이를 소비하는 two-stage interface가 thinking loop와 grounding error를 줄인다.
- **최소 실험:** Web Agents·Robotics에서 각 50문제를 뽑아 (a) direct answer, (b) free-form long CoT, (c) JSON state extraction→planner를 동일 모델로 비교한다. accuracy, grounding error, repeated-token ratio, latency를 기록한다.
- **GO:** (c)가 direct 대비 accuracy +8%p 이상, grounding error 20% 이상 감소, latency 2배 이하다.
- **KILL:** state JSON도 잘못된 대상을 고정해 planner accuracy가 direct와 같거나 낮다.

**평가:** 심각도 5/5 · 재현 신뢰도 4/5 · 연구 아이디어 가치 5/5

## 2. RetinaGroundBench — 병변 존재를 맞혀도 병변 위치를 찾지 못한다

**대상:** *A Visual Grounding Benchmark for Retinal OCT with Multimodal Large Language Models*  
**실패 조건:** OCT B-scan에서 13개 biomarker의 존재 여부를 답하는 것과 모든 병변 위치를 box로 localize하는 것을 함께 요구할 때  
**모델·데이터·설정:** 815 B-scan, 안과의사 annotation 4,537 boxes, 8개 질환, 27개 open-source MLLM(0.8B~38B), AggIoU 기반 macro F1

### 확인된 사실

- 최고 범용 모델 InternVL3.5-30B-A3B의 grounding macro F1은 23.7%, precision 47.9%, recall 16.5%였다.
- 27개 범용 모델 모두 precision이 recall보다 높았고, 대부분 평균 recall이 25% 미만이었다. Gemma-4-26B-A4B는 precision 55.0%지만 recall 12.4%였다.
- domain-tuned RetGrounder 8B는 grounding F1 33.9%, precision 48.0%, recall 27.5%였다. 범용 최고 대비 상대 F1 향상은 43%지만, 절대 recall은 여전히 낮다.
- VQA에서는 biomarker presence balanced accuracy가 최대 73.3%, recall은 최대 약 76%였지만 grounding과 순위가 분리됐다.
- drusen은 presence BAcc 82.7%인데 grounding F1 28.7%였고, fibrosis는 BAcc 50.9%인데 grounding F1 47.5%였다.
- 저자들은 일부 VQA 모델이 biomarker 존재를 거의 무차별적으로 예측해 recall을 높이고 precision을 낮췄다고 해석했다. balanced accuracy만 보면 배치 비용을 과소평가할 수 있다.
- 두 번째 annotation reading으로 전체 모델을 다시 채점해도 순위 Spearman ρ=0.956이었지만, epiretinal membrane의 annotator F1은 15.7%, presence κ는 0.37로 class 자체의 모호성이 컸다.

### 저자 주장·인정·artifact 상태

- **저자 주장:** image-level recognition과 spatial grounding은 다른 능력이며, 임상 사용에서는 둘을 독립 평가해야 한다.
- **저자 인정:** text coordinate format이 spatial information을 손실시키는 병목일 수 있지만, 표현 한계·architecture mismatch·task 난이도 중 어느 원인이 핵심인지는 열려 있다.
- **공개 재현 범위:** 논문은 annotation과 end-to-end evaluation pipeline이 `ronnief1/RetinaGroundBench`에 공개됐다고 명시한다. 그러나 2026-10-24 06:27 KST에 GitHub public repository API와 웹 URL을 확인했을 때 404였다. RetGrounder 학습에 사용한 일부 in-house data도 공유되지 않는다.
- **공동체 재현:** 독립 연구팀 재현은 확인되지 않았다.

### 기존 주장과 충돌하는 지점

의료 VQA accuracy가 높으면 모델이 실제 영상 근거를 사용한다는 가정과 충돌한다. 존재 분류는 global shortcut으로 맞힐 수 있지만, localization은 lesion extent와 개수를 복원해야 한다. 큰 모델이나 MoE의 VQA 향상이 grounding 향상으로 일관되게 이어지지 않았다.

### 진단 → 가설 → 최소 실험

- **진단:** autoregressive text coordinate 출력이 작은·다중 병변의 위치 정보를 압축하고, presence supervision은 global feature shortcut을 허용한다.
- **가설:** mask/heatmap token을 직접 예측하는 visual decoder와 presence-grounding consistency loss가 recall을 높인다.
- **최소 실험:** 공개 OCT subset 100장에 (a) text box decoder, (b) coordinate quantization을 2배 세밀화, (c) lightweight heatmap head를 비교한다. biomarker별 recall, macro F1, false boxes/image, presence-grounding consistency를 측정한다.
- **GO:** recall +10%p 이상이면서 precision 하락 5%p 이하, subtle biomarker 두 class 이상에서 개선된다.
- **KILL:** 전체 F1 상승이 macular-hole 같은 쉬운 class에만 집중되거나 false box가 두 배 이상 증가한다.

**평가:** 심각도 5/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 5/5

- 논문: https://arxiv.org/abs/2610.31205

## 3. WildFakeToolBench — detector query 없이 만든 일반 image processing이 생성 이미지 탐지를 무너뜨린다

**대상:** *WildFakeToolBench: Benchmarking AI-Generated Image Detectors with Web-Sourced Image Processing*  
**실패 조건:** 공개 forum·blog·도구 사이트의 편집 조언을 CPU executable tool로 변환하고 생성 이미지를 후처리한 뒤 fake detector에 입력할 때  
**모델·데이터·설정:** 220개 public source·142 domains에서 156 tools, 5개 generator의 105 images, 6개 detector, detector feedback 없이 tool 생성, candidate SSIM≥0.75

### 확인된 사실

- detector별 strongest single-tool ASR은 SIDA-13B 25.25%, FakeVLM 45.54%, FakeShield 46.88%, GPT-5.6-luna 66.67%, CommForensics 95.83%, AIDE 100%였다.
- 각 detector에서 strongest web-derived tool은 동일 candidate/distortion protocol의 6개 selected baseline 중 최고값을 넘었다.
- 8-tool candidate pool의 worst-case coverage는 모든 detector에서 80% 이상이었다. 다만 이는 attacker가 성공 후보를 고를 수 있다는 상한 성격이며 one-shot 성공률과 같지 않다.
- 네 개 tool의 최고 조합은 FakeVLM 92.08%, SIDA-13B 68.69%, FakeShield 79.69%, GPT-5.6-luna 87.32%, CommForensics/AIDE 100% ASR을 기록했다.
- tool을 더 많이 연쇄 적용한다고 계속 좋아지지 않았다. FakeVLM은 4개, SIDA-13B는 3개에서 peak였고 이후 ASR이 감소했다.
- 2-tool candidate는 약 5개 중 4개가 SSIM filter를 통과했지만 8-tool에서는 약 5개 중 2개만 통과했다. 누적 distortion과 tool 간 상쇄가 원인 후보로 제시됐다.
- SSIM 0.75 threshold는 구조 distortion만 통제하며 자연스러움이나 semantic preservation을 보장하지 않는다고 저자들이 명시했다.

### 저자 주장·인정·artifact 상태

- **저자 주장:** detector-specific weakness가 서로 달라 한 가지 academic baseline만으로 robustness를 평가하면 실제 웹 기반 공격 표면을 놓친다.
- **저자 인정:** 높은 candidate coverage가 신뢰할 수 있는 one-shot evasion을 의미하지 않으며, tool category는 의도한 동작이지 지각 품질 개선의 검증이 아니다.
- **공개 재현 범위:** 논문은 `TrustAIRLab/WildFakeToolBench`에 code와 benchmark를 제공한다고 적었지만, 점검 시 GitHub public repository API와 웹 URL은 404였다.
- **공동체 재현:** 독립 재현은 확인되지 않았다.

### 기존 주장과 충돌하는 지점

학술 공격이나 알려진 JPEG/blur/noise 변환에 대한 robustness가 실전 robustness를 대표한다는 가정과 충돌한다. detector feedback조차 없이 공개 편집 지식만으로 높은 ASR이 나왔으며, 각 detector의 취약 category가 달랐다. 단, SSIM-only 품질 필터 때문에 일부 성공이 사람이 보기에도 의미가 보존된 공격인지 별도 확인이 필요하다.

### 진단 → 가설 → 최소 실험

- **진단:** detector가 semantic forgery보다 generator-specific frequency·texture·capture artifact에 의존하며, 일반 후처리가 이 신호를 지운다.
- **가설:** semantic consistency와 provenance cue를 함께 학습하고, transform family별 worst-group risk를 최적화하면 단일 artifact 의존이 줄어든다.
- **최소 실험:** 공개 생성 이미지 200장에 resampling, color/white-balance, analog/capture, local-texture 변환을 하나씩 적용한다. detector AUC, TPR@1%FPR, human semantic-preservation pass rate, LPIPS/SSIM을 함께 기록한다.
- **GO:** adversarial augmentation 후 네 변환의 worst-group TPR이 +15%p 이상이며 clean TPR 하락은 3%p 이하다.
- **KILL:** robustness 향상이 이미지 품질 붕괴 사례에만 나타나거나 clean false-positive가 크게 증가한다.

**평가:** 심각도 5/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 5/5

- 논문: https://arxiv.org/abs/2610.31152

## 4. Long Caption Position Failure — 길이를 늘리면 중간은 환각, 끝은 일반론으로 바뀐다

**대상:** *Where Do Long Captions Fail? Position-Aware Diagnosis and Reinforcement Learning for Detailed Image Captioning*  
**실패 조건:** image caption을 길게 생성하고 전체 factuality/coverage 점수만 최적화할 때  
**모델·데이터·설정:** Qwen·InternVL·LLaVA 계열 6개 captioner, caption을 네 위치 quartile로 분해, claim-level supported/hallucinated/generic 판정

### 확인된 사실

- 6개 모델 모두 caption 중간 Q2/Q3에서 hallucination이 상승했다. `D_mid`의 모델 평균은 +0.101, 범위는 Qwen3-VL-8B +0.065부터 LLaVA-v1.5-7B +0.216이었다.
- 첫 quartile의 supported rate 평균은 0.527에서 마지막 quartile 0.333으로 하락했다.
- generic rate는 첫 quartile 0.103에서 마지막 quartile 0.281로 증가했다. 저자들은 이를 “tail generic escape”로 명명했다.
- 같은 pipeline을 dense human reference에 적용하면 supported rate는 Q1 0.933, Q4 0.945였고 generic rate는 0.066→0.053이었다. human `D_mid`는 -0.001로 near-zero였다.
- 위치별 reward를 쓰는 PAGER ablation에서 mid reward를 제거하면 `D_mid`가 +0.036→+0.103으로 악화됐다. tail reward를 제거하면 Q4 supported rate가 0.436→0.374로 떨어지고 generic rate가 0.329→0.378로 늘었다.
- 단순히 뒤쪽 position을 더 보상한 baseline은 tail genericity를 줄였지만 tail hallucination을 0.291로 높였다. 일반론을 줄이는 것과 사실성을 높이는 것이 같은 목표가 아니다.

### 저자 주장·인정

- **저자 주장:** long-caption failure는 뒤로 갈수록 동일하게 악화하는 monotonic decay가 아니라, 중간의 근거 없는 세부화와 끝의 generic escape가 교대하는 composition shift다.
- **저자 인정:** reference checklist는 실제로 맞는 미기재 세부를 놓치거나 false contradiction을 만들 수 있다. 일부 human study는 저자 개인 관계망의 무급 volunteer를 사용했고, scaling·reward overfitting은 더 넓은 평가가 필요하다.
- **재현 범위:** 논문은 judge prompt·training 설정·bootstrap 절차를 상세히 제시하지만, 본문에서 독립된 공식 code repository 링크는 확인되지 않았다.
- **공동체 재현:** 독립 연구팀 재현은 확인되지 않았다.

### 기존 주장과 충돌하는 지점

더 긴 caption이 더 많은 사실을 담으므로 detail benchmark에서 유리하다는 단순 가정과 충돌한다. global score는 같은 caption 안에서 중간 hallucination과 tail filler가 서로 상쇄되는 현상을 숨긴다. 또한 “genericity 감소” 보상만 강하게 주면 사실 없는 구체성을 유도할 수 있다.

### 진단 → 가설 → 최소 실험

- **진단:** autoregressive generation 중 visual evidence access가 약해지고, 길이 목표가 남은 token을 구체적 환각 또는 안전한 filler로 채우게 한다.
- **가설:** 문장마다 evidence pointer를 요구하고, 근거가 없으면 종료하도록 하는 adaptive stopping이 위치별 오류를 줄인다.
- **최소 실험:** 해양/해무 이미지 100장에 (a) 고정 150-token caption, (b) sentence-level evidence box, (c) evidence box+adaptive stop을 비교한다. quartile별 supported/hallucinated/generic rate와 평균 길이를 측정한다.
- **GO:** (c)가 Q2/Q3 hallucination 25% 이상, Q4 genericity 25% 이상 줄이면서 전체 supported claim 수가 유지된다.
- **KILL:** caption을 짧게 만드는 것만으로 지표가 좋아지고 실제 supported claim 수가 15% 이상 감소한다.

**평가:** 심각도 4/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 5/5

## 오늘의 실패 패턴 3개

1. **인식과 근거화는 분리돼 있다.** RetinaGroundBench의 presence VQA와 localization, AgentVQA의 task 이해와 UI/3D grounding이 어긋났다.
2. **추론·길이·후처리는 단조롭게 이롭지 않다.** long CoT는 thinking loop를 만들 수 있고, long caption은 중간 환각·tail filler를 만들며, 더 많은 image-processing tool chain은 누적 distortion 때문에 공격 성공을 오히려 낮췄다.
3. **“공개됨”과 “현재 재현 가능함”은 다르다.** 논문이 code 공개를 선언해도 연결 저장소가 404이거나 학습 data가 비공개이면 실질 재현 가능성은 낮다.

## 논문 아이디어로 연결 가능한 빈틈

### A. Perception-First Agentic VLM with Loop-Aware Inference

- 짧은 visual state extraction과 planner를 분리한다.
- 반복 reasoning token과 state 변화 없음이 동시에 발생하면 reasoning을 중단하고 perception을 재호출한다.
- **핵심 기여 후보:** agentic benchmark에서 긴 CoT의 비용과 실패를 동시에 제어하는 adaptive inference.

### B. Evidence-Linked Medical Grounding

- presence answer마다 heatmap/box evidence를 의무화하고 둘의 consistency를 학습한다.
- false-negative 비용을 biomarker별 clinical severity로 가중한다.
- **핵심 기여 후보:** 높은 VQA accuracy가 localisation failure를 가리지 못하게 하는 dual-axis clinical metric.

### C. Web-Transformation Robustness for Synthetic-Image Detection

- transform category별 worst-group risk와 semantic-preservation human check를 함께 사용한다.
- frequency fingerprint 대신 provenance·semantic inconsistency 신호를 보조 축으로 학습한다.
- **핵심 기여 후보:** academic attack list가 아닌 실제 공개 editing knowledge로 갱신되는 robustness suite.

### D. Evidence-Budgeted Long Multimodal Generation

- 매 문장에 evidence pointer와 remaining-evidence budget을 부여한다.
- 근거가 소진되면 길이 목표보다 종료를 우선한다.
- **핵심 기여 후보:** middle hallucination과 tail genericity를 동시에 줄이는 position-aware stopping policy.

## 출처와 해석 한계

- 네 논문은 모두 최근 공개본이라 장기 peer review와 독립 공동체 재현이 없다.
- AgentVQA code와 Hugging Face data는 현재 접근 가능함을 확인했다. 다른 두 논문의 GitHub 경로는 점검 시 404였고, 접근 가능해질 수 있으므로 이는 2026-10-24 06:27 KST의 상태다.

- RetinaGroundBench의 domain-tuned model은 일부 비공개 in-house training data를 사용하므로 범용 모델과 완전한 apples-to-apples 비교가 아니다.
