## Q1. 작은 동적 객체를 직접 최적화하면 데이터 10배 확장보다 object-dynamics fidelity를 더 효율적으로 높일 수 있는가?

### Observation

**확인된 사실:** [What 30,000 Hours of Ego-centric Video Does Not Teach](https://arxiv.org/html/2610.12464)는 300시간부터 30,000시간까지 Cosmos 3 계열 world model을 비교했다. OOD 평가는 150개 clip, 11,328개 instance mask, 17-frame prediction window로 agent와 manipulated object의 structural consistency를 분리했다. 논문은 skeleton conditioning으로 1,000시간 학습한 모델이 표준 conditioning의 30,000시간 agent fidelity를 넘어섰지만, object fidelity는 낮은 수준에서 더 빨리 포화한다고 보고한다.

**저자 주장:** pixel 중심 손실은 화면에서 작고 가려지는 조작 물체보다 배경과 신체처럼 면적이 큰 영역에 용량을 배분하며, 데이터 확장만으로 남은 object-dynamics gap을 닫기 어렵다. 저자들의 object-centric adaptive noise scheduling은 시험한 개입 가운데 object fidelity의 포화점을 올린 유일한 방법이지만 격차는 여전히 남았다.

### Gap

현재 근거는 대규모 비공개 학습 corpus와 4B 이상 모델에 의존한다. “동적 영역을 강조하면 좋아진다”는 결과가 **실제 접촉·상태변화 학습** 때문인지, 단순히 작은 foreground를 더 선명하게 생성했기 때문인지 분리되지 않았다.

### Hypothesis

접촉 전후의 **상태 변화량**과 **원인 행위에 대한 조건부 민감도**를 함께 최적화하면, mask reweighting만 한 모델보다 object SCS와 action-counterfactual consistency를 동시에 높일 수 있다. 개선이 선명도에만 기인한다면 counterfactual action을 바꿔도 예측된 object trajectory가 거의 변하지 않을 것이다.

### Experimental Design

- **MVP:** 공개 robot manipulation video에서 3–5개 object category와 8–16 frame horizon만 선택한다.
- **모델:** 작은 pretrained video prediction backbone 또는 latent video diffusion adapter를 동결하고 LoRA/adapter만 학습한다.
- **비교군:** 기본 pixel/latent loss, foreground mask reweighting, motion magnitude reweighting, 접촉 전후 state-change loss.
- **핵심 ablation:** 동일 mask에서 실제 action, shuffled action, zero action을 주고 object trajectory와 상태 변화의 민감도를 비교한다.
- **데이터:** 공개 robot/egocentric manipulation subset과 SAM2 기반 object track. 논문 benchmark가 공개되면 외부 검증으로만 추가한다.
- **평가:** object mask IoU/SCS, contact-region flow error, final-state correctness, action-counterfactual separation, LPIPS control.
- **GO 기준:** 동일 데이터·학습 step에서 foreground reweighting보다 object SCS가 일관되게 높고, shuffled-action separation도 함께 개선된다.
- **KILL 기준:** SCS만 개선되고 counterfactual separation 또는 final-state correctness가 개선되지 않는다.

### Expected Contribution

작은 물체를 “더 잘 그리는 것”과 “행위의 결과를 더 잘 예측하는 것”을 분리하는 진단 protocol, 그리고 대규모 재학습 없이 검증 가능한 object-dynamics supervision 설계다.

### Compute / Risk / 4–8주 가능성

- **Compute:** full world-model training은 비현실적이다. 8GB에서는 저해상도·짧은 clip·adapter 학습의 proxy만 가능하다.
- **Novelty risk:** object-centric loss와 motion weighting 자체는 이미 존재한다. 기여는 **action counterfactual과 state change를 함께 측정**하는 데 있어야 한다.
- **4–8주:** benchmark와 작은 adapter 실험은 가능하지만, 원 논문의 scaling 결론을 재현하는 것은 불가능하다.
- **음성 결과의 가치:** 어떤 weighting도 counterfactual consistency를 높이지 못한다면, appearance objective로는 causal dynamics를 학습하기 어렵다는 경계 조건을 제시할 수 있다.

## Q2. 정상 RGB-D와 안개·반사·희소 센서 조건을 같은 metric-depth 순위로 평가해도 되는가?

### Observation

**확인된 사실:** [Pumpire: Unified Benchmark for Metric Distance Estimation](https://arxiv.org/html/2610.12423)는 100개 scene, 6,400개 frame과 tape-measured point-pair distance를 사용한다. 원문 표에서 sensor normal 조건의 absolute error는 0.026, challenging 조건은 4.047이며 δ1.25는 98.66%에서 36.72%로 떨어진다. Metric3D는 normal 조건에서 가장 낮은 absolute error 0.073을 보이지만 challenging 조건에서는 1.126으로 악화된다. DepthPro와 MoGe-3의 challenging absolute error는 각각 0.171과 0.158로 보고됐다.

**저자 주장:** 기존 benchmark는 dense ground truth 또는 특정 센서 조건에 묶여 있어, 실제 거리 추정과 depth completion을 함께 비교하기 어렵다.

### Gap

센서가 불안정한 장면에서 “모델 depth가 틀린 것”과 “평가 기준으로 쓰인 sensor depth가 틀린 것”을 분리하는 신뢰도 계층이 부족하다. 또한 estimation 모델과 sensor-conditioned completion 모델의 입력 정보량이 달라 단일 leaderboard 순위가 과도하게 단순하다.

### Hypothesis

소수의 tape/laser distance anchor와 RGB 기반 sensor reliability map을 이용하면, adverse condition에서 센서 오류를 먼저 식별하고 모델의 metric scale error와 local geometry error를 분리할 수 있다. 모델 순위는 전체 평균보다 **신뢰도 구간별 error curve**에서 더 안정적으로 재현될 것이다.

### Experimental Design

- **MVP:** Pumpire 공개 데이터 중 normal/challenging pair를 사용하고 3–4개 공개 monocular metric-depth 모델만 비교한다.
- **비교군:** dense sensor depth 기준 평가, point-pair distance만 평가, sensor reliability weighting, anchor-calibrated scale 평가.
- **진단 변수:** 안개/반사/저조도, 거리 구간, 표면 재질, sensor missingness, anchor 수 2/4/8/16.
- **평가:** absolute distance error, relative scale error, rank correlation across conditions, confidence–error calibration, δ threshold.
- **GO 기준:** reliability-aware protocol이 반복 sampling에서 모델 순위를 더 안정적으로 유지하고, 실제 point-pair error와 더 높은 상관을 보인다.
- **KILL 기준:** reliability weighting이 결과를 바꾸지 않거나 anchor 선택에 따라 순위가 뒤집힌다.
- **최소 실험:** pretrained model inference만 수행하고, reliability model은 작은 CNN 또는 handcrafted fog/reflection feature로 제한한다.

### Expected Contribution

“어떤 모델이 가장 좋은가”보다 **어떤 조건에서 어떤 ground truth를 믿어야 하는가**를 답하는 metric-depth 평가 protocol이다. 해무·해상 영상으로 직접 확장할 수 있다.

### Compute / Risk / 4–8주 가능성

- **Compute:** RTX 5060 Ti 8GB에서 inference와 작은 reliability head 학습이 가능하다.
- **Novelty risk:** uncertainty weighting과 sparse anchor calibration은 개별적으로 알려져 있다. 실제 측정 distance를 이용해 sensor 오류와 model 오류를 분리하는 설계가 핵심이다.
- **4–8주:** 데이터 접근이 가능하면 가장 빠르게 완결할 수 있다.
- **음성 결과의 가치:** sparse anchor로도 평가 순위가 안정화되지 않는다면 adverse depth benchmark가 요구하는 최소 측정 밀도를 정량화할 수 있다.

## Q3. 스트리밍 VLM의 프레임 예산은 영상 전체가 아니라 질문 능력별로 배분해야 하는가?

### Observation

**확인된 사실:** [FastBench](https://arxiv.org/html/2610.12427)는 300개 video, 306개 QA와 고정 pixel budget 248,832,000을 사용한다. Qwen 계열 결과는 2 FPS 32.9에서 24 FPS 44.6으로 상승했지만, 논문은 프레임 증가의 포화와 history compression 문제를 함께 보고한다. ProactiveFrame은 Qwen 계열 전체 점수를 5.4점 높였으나 Gemini 계열에서는 predictive/causal이 5.9점, motion/spatiotemporal이 6.8점 하락했다. Qwen의 instant question도 2.2점 하락했다.

**저자 주장:** 고동적 streaming video는 균일 sampling보다 미래 frame 선택과 memory 관리가 중요하다.

### Gap

현재 frame selector는 모델·질문 유형에 따른 **음의 전이 위험**을 명시적으로 예측하지 않는다. 어떤 질의는 최근 고해상도 frame이 필요하고, 어떤 질의는 긴 history의 저해상도 요약이 필요하다.

### Hypothesis

질문을 instant, motion, causal, predictive로 분류하고 각 능력에 맞춘 frame budget과 memory policy를 선택하면, 단일 selector보다 worst-capability regression을 줄이면서 동일 pixel budget에서 평균 성능을 높일 수 있다.

### Experimental Design

- **MVP:** 한 개 3B–7B open VLM과 FastBench 공개 subset으로 시작한다.
- **비교군:** uniform FPS, recency-biased sampling, motion-score sampling, ProactiveFrame형 예측 sampling, oracle question-type routing.
- **제안:** 작은 router가 query embedding, optical-flow 통계, 최근 answer entropy로 sampling policy를 선택한다.
- **평가:** 전체 정확도, 능력별 정확도, worst-group accuracy, latency, peak VRAM, processed pixel, policy-switch frequency.
- **GO 기준:** 같은 pixel budget에서 평균 성능을 높이고 모든 능력군의 하락을 1점 이내로 제한한다.
- **KILL 기준:** 평균은 개선되지만 한 능력군이 반복적으로 3점 이상 하락하거나 router 비용이 latency 이득을 상쇄한다.
- **ablation:** query 없이 visual-only routing, query-only routing, oracle routing, 고정 policy.

### Expected Contribution

streaming VLM을 하나의 평균 점수로 최적화하지 않고 **능력별 계산 예산과 음의 전이**로 재정의하는 evaluation/training framework다.

### Compute / Risk / 4–8주 가능성

- **Compute:** 8GB에서는 2B–4B 양자화 모델과 짧은 subset이 현실적이다. 모든 상용 모델 재평가는 불가능하다.
- **Novelty risk:** adaptive frame sampling 연구가 빠르게 늘고 있다. 기여는 selector 구조보다 **worst-group guardrail과 능력별 negative transfer 측정**에 두어야 한다.
- **4–8주:** 한 모델과 제한된 question taxonomy에서는 가능하다.
- **음성 결과의 가치:** oracle routing도 uniform sampling을 이기지 못한다면, 병목이 frame selection이 아니라 representation/history compression에 있음을 보여준다.

## Q4. 세밀한 omni-video caption 평가는 LLM judge보다 구조화된 증거 단위에서 더 재현 가능한가?

### Observation

**확인된 사실:** [OmniCapBench](https://arxiv.org/html/2610.12458)는 786개 video, 총 12.8시간, 5,818개 reference, 6,537개 audio event, 11,419개 shot, 39,160개 subshot을 포함한다. 동일한 예측을 평가했을 때 약한 judge의 판정 일치율은 71.24%, 강한 judge는 93.92%로 보고된다. 어려운 subset에서 구조적 scoring과 사람 판정의 일치는 74.2%, 불일치는 25.8%였다.

**저자 주장:** 단일 문장 유사도나 자유형 LLM judge만으로는 audio-visual event, temporal order, fine-grained detail을 안정적으로 평가하기 어렵다.

### Gap

강한 judge가 높은 일치율을 보이더라도 비용·버전 변화·prompt 민감도 때문에 장기 benchmark의 재현성을 보장하지 않는다. 구조화 schema가 사람 판단과 어긋나는 25.8%가 annotation 문제인지, schema 누락인지, judge reasoning 실패인지 분류되지 않았다.

### Hypothesis

caption을 entity–event–time–modality–evidence tuple로 변환하고, tuple별 entailment와 temporal consistency를 별도로 측정하면 judge 모델이 바뀌어도 순위 변동이 줄어든다. 불일치 사례의 대부분은 “내용 누락”, “시간 순서 오류”, “audio/visual source 혼동” 중 하나로 설명될 것이다.

### Experimental Design

- **MVP:** 100–150개 video와 3개 caption model output을 표본화한다.
- **비교군:** BLEU/CIDEr 계열, 자유형 LLM judge, 원 benchmark structural scoring, 제안 tuple scoring.
- **annotation:** 두 명의 annotator가 tuple 사실성과 중요도를 독립 판정하고 disagreement를 기록한다.
- **평가:** human rank correlation, judge 교체 시 model-rank stability, category별 F1, 비용/1,000 caption, prompt sensitivity.
- **GO 기준:** tuple scoring이 두 개 이상의 judge에서 rank variance를 낮추고 human ranking 상관을 유지하거나 높인다.
- **KILL 기준:** tuple extraction error가 caption quality 차이보다 커서 사람 판정과의 상관이 하락한다.
- **ablation:** 자동 tuple extraction 대 수동 tuple, modality tag 제거, temporal edge 제거, importance weight 제거.

### Expected Contribution

caption 평가를 “한 번의 종합 판정”에서 **검사 가능한 evidence graph**로 바꾸고, 어떤 오류가 점수를 바꿨는지 설명하는 protocol을 제공한다.

### Compute / Risk / 4–8주 가능성

- **Compute:** caption 생성보다 기존 output 평가에 집중하면 8GB에서도 가능하다. 외부 judge 비용은 표본 수로 통제한다.
- **Novelty risk:** scene graph 기반 caption 평가와 LLM judge 안정성 연구가 존재한다. audio source와 temporal edge를 포함한 omni-video 구조가 차별점이어야 한다.
- **4–8주:** 작은 human study와 judge swap 실험은 가능하다.
- **음성 결과의 가치:** 구조화 방식도 judge 교체에 민감하다면, benchmark가 요구하는 최소 human audit 비율을 산정할 수 있다.

## Q5. 명시적 3D 단서와 합성 공간추론 SFT의 이득은 실제 OOD 예측 능력인가, benchmark 변환 언어 적응인가?

### Observation

**확인된 사실:** [SpaceCast-Bench](https://arxiv.org/html/2610.12402)는 182개 real scene, 3,862개 question, 16개 task type으로 predictive spatial reasoning을 평가한다. 최고 보고 성능은 58.0이고 human은 87.2이며, best open model은 39.3이다. 명시적 textual 3D metadata를 추가했을 때 proprietary model은 평균 30.7점, open model은 10.9점 개선됐다. Qwen3-VL-4B의 SFT는 in-domain 34.0에서 65.7로 증가했지만 OOD는 33.5에서 38.1로 4.6점만 증가했다. 일부 외부 benchmark에서는 0.3점 하락도 보고됐다.

**저자 주장:** 현재 VLM은 관찰된 장면에서 변화 이후의 배치와 관계를 예측하는 능력이 부족하며, explicit 3D representation이 큰 도움을 준다.

### Gap

큰 in-domain 상승이 3D world model을 학습한 결과인지, 질문 형식·변환 문구·답변 분포를 학습한 결과인지 알기 어렵다. textual 3D metadata 자체가 정답과 강하게 연결된 shortcut일 가능성도 있다.

### Hypothesis

진짜 3D 예측 능력이라면 좌표계 회전, 객체 이름 치환, paraphrase, unseen transformation composition에서도 성능이 유지돼야 한다. 반대로 언어 적응이라면 의미는 같고 표현만 바꾼 counterfactual split에서 이득이 급격히 감소할 것이다.

### Experimental Design

- **MVP:** 공개 scene/question 중 네 가지 counterfactual split을 만든다: coordinate rotation, object-label permutation, transformation paraphrase, two-step composition.
- **비교군:** zero-shot VLM, 원 SFT, 3D metadata only, metadata dropout SFT, equivariance consistency loss.
- **평가:** 원 test accuracy, 각 counterfactual accuracy, consistency under coordinate transform, calibration, shortcut probe accuracy.
- **GO 기준:** 제안 consistency training이 원 test를 유지하면서 OOD/counterfactual 평균을 5점 이상 높이고 label-permutation gap을 줄인다.
- **KILL 기준:** 원 test만 좋아지고 coordinate/object permutation에서 성능이 무작위 수준으로 떨어진다.
- **최소 실험:** 모델 재학습 전에 prompt-only perturbation과 linear probe로 shortcut 존재 여부를 판별한다.

### Expected Contribution

predictive spatial reasoning의 성능 상승을 **3D equivariance, 언어 적응, 답변 prior**로 분해하는 진단 benchmark다. 이후 embodied VLM과 world model을 연결하는 장기 연구 축이 된다.

### Compute / Risk / 4–8주 가능성

- **Compute:** prompt perturbation과 4B LoRA는 8GB에서도 축소 실행 가능하지만, 대규모 multi-model 비교는 어렵다.
- **Novelty risk:** compositional/OOD split은 익숙한 방법이다. 장면 변화 전후의 coordinate equivariance와 answer prior를 함께 분리해야 새롭다.
- **4–8주:** 진단 benchmark와 한 모델 LoRA까지는 가능하다.
- **음성 결과의 가치:** 모든 perturbation에서 이득이 유지되면 원 SFT가 실제로 강한 공간 표현을 학습했다는 독립 검증이 된다.

## Q6. 해상 소형 표적의 INT8 성능 하락은 backbone 전체 양자화보다 특정 scale/head의 분해능 손실에서 오는가?

### Observation

**확인된 사실:** [FPGA-Based Bandwidth-Limited Maritime Object Detection](https://arxiv.org/html/2610.12182)의 float 모델은 AP 86.1, recall 83.8이고 INT8은 AP 81.4, recall 76.1로 각각 4.7점과 7.7점 하락했다. 상위 10개 class의 mAP는 68.9에서 59.0으로 9.9점 감소했다. crop 전송은 원 영상 데이터의 2.8%만 쓰면서 full-quality vessel의 83%를 유지했지만 17%를 놓쳤고, tile 방식은 28.7%를 사용해 98%를 유지했다. 원문은 centered tile이 spatial block을 겹치게 해 같은 vessel이 서로 다른 split에 들어갈 가능성도 지적한다.

**저자 주장:** edge maritime detection에서는 정확도 하나보다 bandwidth, quantization, crop/tile 정책을 함께 최적화해야 한다.

### Gap

INT8 하락이 작은 box의 feature quantization, FPN scale fusion, classification margin, NMS 중 어디서 시작되는지 분해되지 않았다. 또한 frame-level 또는 겹치는 spatial split은 일반화 성능을 과대평가할 수 있다.

### Hypothesis

P2/high-resolution branch와 regression head만 higher precision으로 유지하고 나머지를 INT8로 두면, full mixed precision보다 적은 비용으로 small-vessel recall을 대부분 복구할 수 있다. 이 이득은 scene/vessel 단위 leakage-free split에서 더 정확히 측정된다.

### Experimental Design

- **MVP:** 공개 maritime/aerial small-object dataset과 소형 YOLO/RT-DETR 계열 한 모델을 사용한다.
- **비교군:** FP16, full INT8 PTQ, QAT, P2-only FP16, regression-head FP16, activation percentile calibration.
- **split:** image random split과 scene/vessel-group split을 모두 만들고 차이를 보고한다.
- **평가:** small-object AP/AR, miss rate, class confusion, per-scale activation clipping, latency, peak memory, transmitted byte당 recall.
- **GO 기준:** hybrid precision이 full INT8 대비 small-object recall의 절반 이상을 회복하고 latency/메모리 증가를 10% 이내로 제한한다.
- **KILL 기준:** recall 회복이 NMS threshold 조정으로도 동일하게 얻어지거나 hardware latency 이득이 사라진다.
- **ablation:** P2 제거, scale별 observer, class-agnostic calibration, crop/tile policy와의 상호작용.

### Expected Contribution

평균 AP가 아닌 **작은 표적 recall–정밀도–전송량**의 Pareto frontier와, 양자화 오류가 시작되는 scale/head를 추적하는 진단 방법이다.

### Compute / Risk / 4–8주 가능성

- **Compute:** 640–1024 해상도, batch 1–4, 소형 모델의 PTQ/QAT는 RTX 5060 Ti 8GB에서 가능하다.
- **Novelty risk:** mixed-precision quantization은 성숙한 분야다. 해상 소형 표적, leakage-free split, transmitted-byte metric을 결합해야 연구성이 생긴다.
- **4–8주:** 재현 가능한 첫 논문 범위로 적절하다.
- **음성 결과의 가치:** 특정 scale을 FP16으로 유지해도 회복되지 않으면 병목이 quantization보다 crop recall 또는 annotation granularity에 있음을 밝힐 수 있다.

## 오늘의 실행 선택

### 오늘 가장 먼저 테스트할 질문: Q2

**진단:** adverse condition에서 sensor depth 자체가 불안정하므로 모델 순위가 ground-truth 오류에 끌려갈 수 있다.  
**가설:** 소수의 실제 거리 anchor와 reliability bin이 모델 오류와 센서 오류를 분리한다.  
**최소 실험:** Pumpire에서 normal/challenging 각 20–30 scene을 뽑고 3개 pretrained metric-depth 모델의 point-pair error, sensor-depth error, reliability-weighted error 순위를 비교한다.  
**하루 종료 판정:** rank correlation과 error calibration이 전혀 나아지지 않으면 복잡한 reliability network를 만들지 않는다.

### RTX 5060 Ti 8GB에 가장 적합한 질문: Q6

- 작은 detector 한 개로 PTQ와 scale/head별 mixed precision을 비교할 수 있다.
- 학습보다 calibration·evaluation 비중이 커서 메모리 제약을 통제하기 쉽다.
- maritime/small-object 관심사와 직접 연결되며, 실패해도 quantization과 crop 중 실제 병목을 남길 수 있다.

### 장기 박사 주제로 가장 좋은 질문: Q5

- 2D VLM, explicit 3D representation, world model, embodied prediction을 연결한다.
- benchmark 점수 상승과 실제 공간 일반화를 분리하는 진단은 여러 모델 세대에 재사용 가능하다.
- 장기적으로 coordinate-equivariant representation, counterfactual scene transformation, robot planning까지 확장할 수 있다.

## 4–8주 제안 순서

1. **1주차:** Q2와 Q6 데이터·평가 pipeline을 만들고 leakage 및 sensor 신뢰도 audit.
2. **2주차:** Q2 baseline 3종과 Q6 FP16/full-INT8 baseline 확정.
3. **3–4주차:** reliability weighting과 scale/head mixed precision ablation.
4. **5주차:** negative result 포함 error taxonomy 작성.
5. **6주차:** 다른 dataset 또는 condition으로 외부 검증.
6. **7–8주차:** 재현 스크립트, 표, failure gallery, 논문 초안 정리.
