# Daily Benchmark Movement — 2026-10-31 (Asia/Seoul)

## 요약

- 이번 점검에서 **공식 leaderboard의 순위·점수 갱신 자체는 검증하지 못했다**. 아래는 10월 27일 공개된 저자 원문의 새 benchmark 주장으로, 공식 순위 변동으로 읽으면 안 된다.
- Honeycomb-Surfels는 Mip-NeRF 360의 memory-matched 조건에서 평균 24.82 dB와 peak training VRAM 0.90 GiB를 제시하지만, 동일 memory 조건이 핵심이므로 무제한/동일 primitive 수 결과와 섞어 비교할 수 없다.
- 같은 연구는 6개 Tanks and Temples 장면에서 F1 34.38% 대 2DGS 31.72%, 15개 DTU scan에서 memory-matched 2DGS 대비 error 28.9% 감소를 주장한다.
- TopoField는 SceneFun3D validation 30 scenes·561 GT instances에서 AP 28.286%, AP50 41.383%, AP25 47.558%를 보고했으며, 13회 test-time forward pass를 쓰므로 단일 패스 방법과의 효율 비교는 공정하지 않다.
- Soccer zero-shot 연구의 F1@5s 72.0%는 3개 수동 주석 경기·130 events의 cross-dataset 설정 결과다. SoccerNet 학습 모델과의 직접 leaderboard 비교에는 데이터·주석·허용 시간 차이가 남는다.
- FastBEVFusion은 nuScenes에서 deployment library 없이 50 FPS 초과를 주장하지만, 초록에는 동등 하드웨어·입력 해상도·정확도 수치가 없어 실시간 leaderboard 이동으로 확정할 근거가 없다.
- 이번 신호의 공통점은 정확도 단일 수치보다 **memory / test-time passes / annotation protocol / hardware**가 결과 해석을 좌우한다는 점이다.
- 최소 다음 단계는 각 방법을 같은 데이터 split·동일 input·단일/다중 pass·동일 GPU 조건으로 재실행해 Pareto 곡선을 다시 그리는 것이다.

## 1. Honeycomb-Surfels / Hexels — 3D novel-view synthesis와 surface reconstruction

**관측**

- **[사실]** 저자 원문은 34 scenes에서 memory-matched 2DGS 대비 PSNR이 4.53–7.38 dB 높고, lower training VRAM을 사용했다고 보고한다. [arXiv](https://arxiv.org/abs/2610.37668)
- **[사실]** 저자 프로젝트 페이지는 9개 Mip-NeRF 360 scenes의 matched-model-memory 비교에서 Hexels 평균 PSNR 24.82 dB, peak training VRAM 0.90 GiB를 제시한다. 같은 표기에서 Nexels는 22.49 dB/7.15 GiB, Triangle Splatting은 22.36 dB/1.12 GiB다. [project page](https://honeycomb-surfels.github.io/)
- **[사실]** 6개 Tanks and Temples surface scenes에서 mean F1 34.38% 대 2DGS 31.72%, 15개 DTU scans에서 memory-matched 2DGS 대비 error 28.9% 감소를 보고한다. [arXiv](https://arxiv.org/abs/2610.37668)
- **[저자 주장]** Hexels가 surface-aligned primitive의 quality–efficiency Pareto frontier를 확장한다.

**진단**

“memory-matched”, “per-primitive”, “unconstrained” 조건은 서로 다른 비교 축이다. 한 축의 PSNR/F1 우세를 다른 축의 절대 성능 우세로 합산하면 안 된다. peak training VRAM 역시 inference VRAM이나 end-to-end latency와 동일 지표가 아니다.

**가설**

동일 model-memory 제약에서는 넓은 hexagonal support와 first-order color field가 작은 2D Gaussian 다수보다 detail 보존에 유리할 수 있다. 다만 scene 종류와 primitive budget이 바뀌면 순서가 바뀔 가능성이 있다.

**최소 실험**

Mip-NeRF 360의 9개 scene에서 2DGS·Nexels·Triangle Splatting·Hexels를 (a) 동일 model memory, (b) 동일 primitive count, (c) 동일 training-time budget 세 조건으로 재실행한다. PSNR/SSIM/LPIPS, peak training VRAM, inference FPS를 분리 기록하고 scene별 결과와 평균을 함께 낸다.

**판정**

검증 우선순위 **높음**. 수치는 구체적이나, 설정별 비교 축이 명확히 분리돼야 한다.

## 2. TopoField — ECCV 2026 SceneFun3D functional segmentation challenge

**관측**

- **[사실]** 저자 원문은 validation 30 scenes, 561 ground-truth instances에서 IoU 0.5-valid candidate existence 67.2%, top-1 coverage 20.0%를 보고한다. [arXiv](https://arxiv.org/abs/2610.37218)
- **[사실]** 같은 원문은 AP 28.286%, AP50 41.383%, AP25 47.558%, ECCV 2026 SceneFun3D Challenge 2위를 보고한다.
- **[사실]** semantic consensus field를 만들기 위해 13회 test-time forward pass를 사용한다고 명시한다.
- **[저자 주장]** field-to-instance gap을 deterministic decoder와 class-aware ranking으로 줄였다고 주장한다.

**진단**

AP는 최종 순위 품질을, candidate existence와 top-1 coverage는 후보 생성과 ranking의 서로 다른 병목을 나타낸다. 따라서 AP 하나만으로 개선 원인을 확정할 수 없다. 또 13회 TTA는 단일 추론 대비 latency·compute budget을 변화시킨다.

**가설**

성능의 상당 부분은 decoder 자체보다 multi-pass consensus가 noisy fragment prediction을 안정화한 효과일 수 있다.

**최소 실험**

동일 VOLT backbone으로 1-pass, 4-pass, 13-pass를 고정하고 AP/AP50/AP25, candidate existence, top-1 coverage, wall-clock latency와 GPU-hours를 함께 측정한다. Decoder-only ablation도 분리한다.

**판정**

검증 우선순위 **높음**. challenge 성적 신호는 유효하지만, test-time budget을 명시한 Pareto 비교가 필요하다.

## 3. Zero-Shot Multimodal Event Spotting in Soccer Broadcasts

**관측**

- **[사실]** 저자 원문은 3개 수동 주석 경기의 130 events에서 best configuration F1@5s 72.0%를 보고한다. [arXiv](https://arxiv.org/abs/2610.37583)
- **[사실]** storyboard와 aligned commentary transcript를 함께 쓰며, individual frames 대비 inference cost 72% 감소를 보고한다.
- **[저자 주장]** SoccerNet-trained CALF 및 NetVLAD++를 cross-dataset 설정에서 능가한다고 주장한다.

**진단**

표본이 3 matches이고 cross-dataset 비교다. F1@5s는 event taxonomy, annotation policy, temporal tolerance, commentary availability에 민감하므로 SoccerNet leaderboard 숫자와 직접 합산할 수 없다. 72% cost 절감도 모델·hardware·clip segmentation 조건이 동등해야 해석 가능하다.

**가설**

storyboard 압축이 반복 프레임의 중복을 줄여 비용을 낮추지만, 빠른 event나 미세한 temporal boundary에서는 F1@5s 이득이 사라질 수 있다.

**최소 실험**

동일 3경기에 individual frames와 storyboard를 같은 multimodal model·prompt·clip stride로 비교한다. 1s/3s/5s tolerance별 F1, event class별 recall, frame 수, end-to-end latency를 기록하고 SoccerNet 표준 split 재평가 여부를 별도 표기한다.

**판정**

검증 우선순위 **중간**. 흥미로운 zero-shot baseline이지만 아직 표준 leaderboard 이동으로 판정하지 않는다.

## 4. FastBEVFusion — nuScenes real-time 3D detection

**관측**

- **[사실]** 저자 원문은 nuScenes에서 state-of-the-art real-time systems를 능가하고 deployment libraries 없이 50 FPS 초과를 달성한다고 기술한다. [arXiv](https://arxiv.org/abs/2610.37153)
- **[저자 주장]** calibration error에 강건한 real-time fusion system이라고 주장한다.
- **[사실]** 초록만으로는 mAP/NDS, GPU·CPU, batch size, camera resolution, LiDAR configuration, calibration corruption 크기를 확인할 수 없다.

**진단**

50 FPS는 정확도 점수와 동등한 benchmark 축이 아니며, 하드웨어와 preprocessing/postprocessing 포함 여부 없이는 다른 real-time 결과와 직접 비교할 수 없다.

**가설**

depth estimation을 피하고 semi-aligned BEV에서 fusion하는 설계가 latency를 낮출 가능성은 있으나, calibration robustness와 detection accuracy의 trade-off는 추가 표가 있어야 판단할 수 있다.

**최소 실험**

nuScenes validation에서 동일 GPU, batch 1, 같은 camera/LiDAR input과 동일 postprocessing으로 mAP·NDS·p50/p95 latency·FPS·VRAM을 측정한다. calibration perturbation 크기별 정확도 곡선도 함께 낸다.

**판정**

검증 우선순위 **중간**. 속도 신호는 명확하지만, 공개된 초록만으로 정확도–지연 Pareto 이동을 확정할 수 없다.
