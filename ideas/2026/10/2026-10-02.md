# CV 논문 아이디어 레이더 — 2026-10-02

## 핵심 요약

- 관측 범위는 **2026-09-25 ~ 2026-10-01**로 잡았다.
- 이번 주 CV/VLM에서 가장 눈에 띄는 변화는 “더 큰 backbone”보다 **필요한 visual evidence를 어디서·언제·얼마나 확보할 것인가**로 관심이 이동하고 있다는 점이다.
- **CoVisco / ACPruner / Atomizer-IO**는 dense visual processing을 고정적으로 수행하기보다 compact representation과 selective fine evidence를 조합한다.
- **EviRover**는 한 번 보고 답하는 perception을 넘어, evidence가 부족하면 추가 관측을 수행하는 **agentic perception**을 정식화했다.
- **Preference-Guided Adaptation**과 **When to Adapt**은 “항상 adapt”가 아니라 disagreement/shift를 보고 선택적으로 adapt하는 방향이다.
- **ReaLVR**는 최종 정답을 맞혀도 latent reasoning이 실제 visual evidence를 제대로 반영하지 않을 수 있는 **evidence-credit gap**을 보여준다.
- 이번 주 후속 연구 후보는 **① EvidenceBudget, ② Disagree-to-Adapt, ③ EvidenceCredit-VQA** 세 가지로 잡았다.
- 가장 먼저 권하는 것은 **Disagree-to-Adapt**다. “prompt disagreement가 실제 adaptation gain을 예측하는가?” 하나만 1~2주 내 검증해도 GO/KILL 판단이 가능하다.

### 1. Atomizer-IO: Beyond Pixels, Patches and Grids
9월 30일 공개. Regular raster/grid가 서로 다른 sensor 구성이나 missing channel, variable output density를 다루기 어렵다는 문제에서 출발해, measurement와 acquisition metadata를 atomic observation으로 만든 뒤 local cross-attention으로 arbitrary anchor에 투영한다. 동일 모델에서 raster 구성 변화와 non-raster input까지 다룬다는 점이 핵심이다. **“feature pyramid level을 미리 고정하는 대신 필요한 곳에 spatial representation을 만든다”**는 방향으로 읽으면 small-object 연구와 연결성이 높다.

### 2. Procedural Core: A Compact Recurrent Initialization for Vision Transformers
9월 29일 공개. 약 1M parameter 규모의 recurrent transformer core를 procedural data로 먼저 학습한 뒤 더 큰 transformer로 확장해 초기화한다. 저자들은 ViT-B에서 random initialization 대비 ImageNet top-1 **+2.2 pp**를 보고하고, zero-shot localization/segmentation도 개선된다고 보고한다. “CNN의 locality를 새로운 block으로 집어넣는 것”만이 inductive bias 연구가 아니라, **학습 시작점 자체에 spatial/compositional prior를 주입할 수 있다**는 게 흥미로운 포인트다.

### 3. CoVisco: Codec-Native Vision Encoder with Native Token Compression for Unified Image-Video Understanding
9월 30일 공개. 일반적인 “dense patch → 사후 token pruning” 대신 encoder 자체가 compact abstract token을 만들고, fine detail이 필요할 때만 selected patch token을 추가한다. 64-frame 설정에서 abstract-only representation을 **400 visual tokens**로 구성하면서 경쟁력 있는 video understanding 결과를 보고한다. 이는 tiny-object VLM에서 상당히 좋은 연구 단서다. **항상 P2/high-res를 넣는 대신 coarse semantic state로 시작하고 필요한 query에만 fine evidence를 추가**할 수 있기 때문이다.

### 4. EviRover: Reinforcing Agentic Perception Beyond a Glance
9월 30일 공개. 저자들은 문제를 **“perception under insufficient evidence”**로 정의한다. 한 번의 image observation과 모델 내부 지식으로 충분하지 않다면 agent가 추가 evidence를 확보하도록 SFT와 RL을 사용한다. 4B 모델에서 자체 EviLens benchmark에 대해 backbone 대비 평균 약 30-point 향상을 보고한다. Tiny-object나 remote-sensing에서는 이 “추가 evidence”를 웹 검색이 아니라 **crop, zoom, alternative resolution, neighboring tile 재관측**으로 치환할 수 있다.

### 5. Rethinking Latent Visual Reasoning: Grounding Latent Reasoning in Visual Evidence
9월 28일 공개. 정답을 바꾸는 visual perturbation을 줘도 latent reasoning token이 충분히 변하지 않는 **latent evidence-credit gap**을 분석한다. ReaLVR는 correct/wrong answer와 relevant/mismatched evidence를 contrast해 latent trajectory에 visual evidence를 직접 연결한다. 즉 **정답 reward만 높다고 해서 reasoning state가 실제 image를 보고 있다는 보장이 없다**는 얘기다.

### 6. Preference-Guided Adaptation for Open-Vocabulary Semantic Segmentation via Prompt Disagreement
9월 28일 공개된 NeurIPS 2026 accepted work. 서로 다른 prompt template이 같은 image에 서로 다른 segmentation을 만들 때 그 **prompt disagreement**를 high-value preference query로 사용한다. 이 연구 자체는 OV segmentation이지만, OVD에서는 한 단계 더 밀어 **“disagreement가 실제 adaptation utility를 예측하는가?”**를 물을 수 있다.

### 7. When to Adapt: Multi-Signal Domain Shift Detection for Efficient Training-Free Adaptation in Open-Vocabulary Segmentation
9월 29일 공개. Visual change, adapter mismatch, semantic drift를 함께 추적해 domain shift가 감지된 경우에만 adaptation을 수행한다. 저자들은 accuracy를 유지하면서 adaptation 횟수를 크게 줄이는 방향을 보고한다. 중요한 변화는 TTA의 질문이 **“어떤 loss로 update할까?”에서 “이번 sample에 update 자체가 필요한가?”**로 이동했다는 점이다.

### 8. AerialDojo-200K
9월 28일 공개. **42개 simulation scene, 2,099 target objects, 205,732 task instances**를 포함한 open-world aerial object-goal search benchmark다. ID/OOD split도 제공한다. Aerial vision을 단순 bounding-box detection이 아니라 **어디를 탐색하고 어느 evidence를 추가로 취득할지 결정하는 문제**로 확장하기 좋은 최근 benchmark다.

## 후보 1 — EvidenceBudget
### Query-Conditioned Evidence Acquisition for Tiny/Open-World Aerial Grounding

**문제 정의**  
Tiny/aerial object는 high-resolution feature가 중요하지만, fixed P2 / full-resolution / tiling을 모든 image와 query에 적용하면 계산량을 상시 지불한다. 질문은 **“현재 coarse representation으로 이 query를 해결할 수 있는가? 부족하다면 어디를 더 자세히 봐야 하는가?”**다.

**기존 연구의 빈틈**  
Fixed P2와 SAHI는 query와 무관하게 spatial compute를 쓴다. Token pruning은 이미 생성한 token 중 무엇을 버릴지 결정하므로 처음부터 사라진 tiny evidence를 되살리지 못한다.

**핵심 가설**  
coarse global state로 추가 high-resolution evidence가 필요한 sample/query를 예측할 수 있고, query + current evidence 기반 sufficiency score가 object-size heuristic보다 실제 high-res intervention gain을 더 잘 예측한다.

**제안 방법 구조**  
Image + Query → Coarse Global Encoder → Evidence Sufficiency Head → 필요 시 Spatial Acquisition Policy → selected tile/anchor → Fine Evidence Encoder → Evidence Merger → Grounding.

**Baseline**  
Grounding DINO류/OVG baseline, fixed high-res, fixed P2, SAHI/fixed tiling, random tile, image-only saliency selector, ACPruner-style coverage selector, GT-location oracle, sample-wise best-resolution oracle.

**Dataset / Metric**  
RefCOCO / RefCOCO+ / RefCOCOg로 MVP 후 aerial/remote-sensing external validation. IoU/Acc@0.5, APsmall/tiny recall, average visual tokens, refined-area ratio, latency/FLOPs, **Recovery per Extra Token**, same-query target consistency.

**필수 Ablation**  
Query-conditioned vs image-only, object-size gate vs learned gate, 1-step vs multi-step, tile vs arbitrary anchor, 5/10/20/40% budget, global-only vs fine-only, local CNN vs ViT fine encoder.

**실패 모드**  
Coarse branch가 tiny object 위치를 전혀 포착하지 못하면 어디를 다시 볼지 못 정한다. selector가 단순 objectness heatmap과 같아질 수도 있다.

**Novelty 방어**  
post-encoding token selection이 아니라 **pre-encoding evidence acquisition under a budget**이라는 formulation으로 가야 한다.

**4~8주 MVP**  
Week 1 multiple resolution/tile + Oracle Best Resolution, Week 2 high-res gain predictor. predictor가 object-size/random보다 낫지 않으면 KILL. Week 3~4 tile selector+budget loss, Week 5~6 aerial transfer, Week 7~8 Pareto ablation.

**Contribution 3개**
1. Query-conditioned visual evidence acquisition formulation.
2. Additional-resolution value를 예측하는 evidence-sufficiency mechanism.
3. Evidence recovery per token 중심의 budgeted grounding evaluation.

**제목 후보**
- EvidenceBudget: Query-Conditioned Visual Acquisition for Tiny Object Grounding
- Look Again, But Only Where It Pays: Budgeted Evidence Acquisition for Aerial Grounding
- Beyond Fixed Pyramids: Language-Guided Spatial Evidence Allocation

**Abstract 개요**  
Low-resolution은 tiny evidence를 잃고 fixed high-resolution은 비싸다 → 기존 token pruning은 이미 획득한 evidence 압축 문제 → query-conditioned evidence sufficiency로 추가 spatial evidence를 선택적으로 획득 → 동일 compute에서 tiny-object grounding 향상.

**Introduction 흐름**

## 후보 2 — Disagree-to-Adapt
### Predicting Adaptation Benefit to Prevent Negative Transfer in Open-Vocabulary Detection

**문제 정의**  
OVD가 domain shift를 만나면 adaptation이 도움 될 수 있지만 adaptation 자체가 negative transfer를 만들 수 있다. 질문은 **“Can we predict whether adaptation will help or hurt before we adapt?”**

**빈틈**  
Entropy/confidence TTA는 uncertainty와 adaptation utility를 동일시한다. Prompt disagreement도 adaptation signal로 쓰였지만 실제 update 전후 gain을 얼마나 예측하는지는 별도 문제다.

**핵심 가설**  
Prompt-logit variance, rank disagreement, box localization disagreement, augment-view inconsistency, visual/semantic shift를 함께 보면 **realized adaptation gain**을 예측할 수 있다.

**방법 구조**  
Frozen OVD → multiple prompt templates → Disagreement Extractor → visual/semantic shift score → Adaptation Benefit Predictor → Adapt / Abstain. Adapt 시 lightweight adapter update + base-class retention constraint.

**Baseline**  
Frozen, always-adapt TTA, entropy trigger, confidence trigger, prompt ensemble only, disagreement-only trigger, multi-signal shift trigger, random matched-frequency adaptation, oracle positive-gain adaptation.

**Dataset / Metric**  
공식 base/novel split → ODinW류 cross-domain → aerial/remote-sensing transfer. 평균 AP 외에 **Negative Transfer Rate (NTR)**, APbase/APnovel, realized vs predicted gain, gain calibration, adaptation frequency, update FLOPs, base-class retention.

**필수 Ablation**  
Prompt disagreement only / shift only / combined, prompt 수, classification-vs-localization disagreement, class-level-vs-region-level gate, hard gate-vs-LR scaling, base/novel threshold 분리.

**실패 모드**  
Prompt disagreement가 단순 difficulty일 뿐 adaptation gain과 무관할 수 있다. One-step realized gain이 noisy할 수 있고 continual adaptation 누적 drift가 생길 수 있다.

**Novelty 방어**  
핵심 target을 **counterfactual adaptation utility**로 잡는다. 질문은 “어려운가?”가 아니라 **“지금 업데이트하면 실제로 좋아지는가?”**

**4~8주 MVP**  
Week 1 OVD baseline + prompt 5~10개, sample별 짧은 adapter update 후 realized gain 기록. Week 2 class-logit variance/rank disagreement/localization disagreement와 realized gain의 Spearman, ROC-AUC. 추가 정보가 없으면 KILL. Week 3 MLP predictor, Week 4 selective adapter, Week 5 NTR, Week 6 aerial/cross-domain, Week 7~8 continual.

**Contribution 3개**
1. OVD adaptation benefit prediction 문제 정의.
2. Prompt disagreement + shift 기반 selective update.
3. NTR / gain-calibration protocol.

**제목 후보**
- Disagree-to-Adapt: Predicting When Test-Time Updates Help Open-Vocabulary Detectors
- Uncertainty Is Not Utility: Preventing Negative Transfer in Open-Vocabulary Adaptation
- Before You Adapt: Forecasting Update Gain for Open-Vocabulary Detection

**Abstract 개요**  
TTA는 domain shift에 유효하지만 indiscriminate adaptation은 harmful → disagreement/uncertainty가 곧 utility는 아님 → counterfactual realized gain predictor → positive-gain subset만 update → NTR 감소.

**Introduction 흐름**  
OVD deployment → domain shift → TTA → harmful update → prompt disagreement/shift detection → **shift와 utility는 다름** → adaptation gain 사전 예측.

**Related Work**  
Open-Vocabulary Detection / Test-Time Adaptation / Negative Transfer / Prompt Sensitivity and Disagreement / Selective Prediction / Calibration

## 후보 3 — EvidenceCredit-VQA
### Counterfactual Visual Credit Assignment for Maritime VLM Reasoning

**문제 정의**  
정답을 맞혔다고 해서 실제 visual evidence를 근거로 생성했다고 볼 수는 없다. 질문은 **“Can we make latent VLM reasoning receive credit from the visual region that causally supports its answer?”**

**빈틈**  
Answer-only SFT/RL은 shortcut을 허용한다. Grounding auxiliary loss는 region을 찾게 할 수 있지만 그 region이 실제 answer generation에 causally 사용됐는지는 보장하지 않는다.

**핵심 가설**  
정답을 바꾸는 counterfactual region perturbation으로 causal visual evidence를 근사할 수 있고, reasoning hidden state가 causal region 제거에는 민감하고 distractor 변화에는 안정적이도록 학습하면 hallucination과 visual shortcut이 감소한다.

**방법 구조**  
Evidence Candidate Generator → Counterfactual Perturbation → Causal Evidence Score → Latent Credit Loss.

**Baseline**  
Vanilla VLM SFT, answer-only SFT/RL, attention/CAM supervision, grounding-token loss, textual CoT, ReaLVR-style evidence contrast, random region intervention, oracle evidence region.

**Dataset / Metric**  
기존 maritime VQA + 일부 region-level evidence annotation. Accuracy/macro-F1 외에 Evidence pointing/IoU, hallucination rate, **Counterfactual Faithfulness**, **Distractor Invariance**, event category별/evidence-size별 결과.

**필수 Ablation**  
Mask/blur/swap, causal-vs-random intervention, latent layer, answer-only-vs-credit loss, small-vs-large evidence, fog/no-fog, single-vs-multi-object, hard negative.

**실패 모드**  
Perturbation artifact가 OOD signal이 될 수 있다. hidden-state alignment가 높아져도 causal faithfulness는 안 좋아질 수 있다.

**Novelty 방어**  
핵심은 **counterfactual region intervention으로 latent visual credit을 정의**하는 것.

**4~8주 MVP**  
Week 1 region candidate 500~1000 sample, Week 2 mask/blur 후 answer log-prob delta, Week 3 hidden-state probe, Week 4 LoRA + evidence-credit loss, Week 5 hallucination/faithfulness, Week 6 actor-object binding, Week 7~8 external benchmark. Human evidence와 정렬 안 되면 KILL.

**Contribution 3개**
1. Maritime VQA counterfactual evidence-faithfulness formulation.
2. Region intervention 기반 latent visual credit assignment.
3. Answer accuracy와 causal faithfulness 분리 evaluation.

**제목 후보**
- EvidenceCredit-VQA: Counterfactual Visual Credit Assignment for Maritime Reasoning
- Right Answer, Right Evidence: Faithful Maritime VQA through Counterfactual Grounding
- What Made the Model Say That? Causal Visual Evidence for Maritime VLMs

**Abstract 개요**  
Correct answer ≠ correct visual evidence → region-level counterfactual로 causal evidence 추정 → latent reasoning state에 credit supervision → accuracy + faithfulness/hallucination 평가.

**Introduction 흐름**  
VLM reasoning 성능 향상 → answer-only metric 한계 → maritime event의 visual-evidence 중요성 → grounding만으로 causal use 보장 안 됨 → counterfactual evidence credit.

## 이번 주 최우선 추천 — Disagree-to-Adapt

이걸 먼저 하는 이유는 핵심 연구 가설을 매우 싸게 죽일 수 있기 때문이다.

첫 실험은:
1. Frozen OVD baseline 하나
2. Dataset subset 1~2k images
3. Prompt template 5개
4. class-logit variance / rank disagreement / box localization disagreement 계산
5. 같은 sample에서 lightweight adapter를 짧게 update
6. update 전후 realized Δloss 또는 ΔAP proxy 계산
7. Disagreement → positive adaptation gain prediction의 Spearman correlation + ROC-AUC 측정

**GO 기준:** disagreement + shift signal이 simple confidence/entropy보다 positive-gain sample을 확실히 잘 구분하고, 동일 update 횟수에서 selective adaptation이 NTR을 낮춘다.

**KILL 기준:** disagreement가 adaptation gain과 거의 무관하고 confidence/entropy보다 추가 정보를 주지 않는다.

핵심은:
- Prompt disagreement: 어디가 불안정한가?
- Shift detection: 언제 환경이 달라졌는가?
- Disagree-to-Adapt: **그래서 지금 업데이트하면 실제로 좋아지는가, 나빠지는가?**

OVD negative transfer를 성능이 떨어진 뒤 분석하는 문제에서 **update 직전 의사결정 문제**로 전환한다는 점이 가장 강한 포인트다.
