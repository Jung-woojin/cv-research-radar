# CV/DL 데일리 브리핑 — 2026-09-18

최근 24~72시간의 CV/VLM/DL 연구를 넓게 스캔한 뒤, 실제 연구 질문과 재현성 관점에서 중요도가 높은 항목만 남겼다.

## 오늘의 전체 DL 트렌드 5줄

1. Ultra-high-resolution vision에서는 detector forward보다 **tiling, fusion, loading, streaming latency**가 실제 병목으로 올라오고 있다.
2. Tiny-object 문제는 단순 P2/해상도 문제가 아니라 **representation, readout, temporal identity, pipeline allocation**으로 분해되는 중이다.
3. Video VLM은 single-frame 성능 향상이 cross-frame identity reasoning으로 그대로 이어지지 않는다.
4. Representation 연구는 “정보가 없는가?”와 “정보는 있는데 못 쓰는가?”를 분리하는 진단 관점으로 이동하고 있다.
5. 시스템 연구에서는 headline speedup보다 **실제 end-to-end measurement와 baseline audit**이 중요해지고 있다.

## CV / DL-CV 핵심

### Understanding Dynamic Scenes at Gigapixel Scale: Wide-Area Spatio-Temporal Perception from UAVs
**v1: 2026-09-16**

HARD benchmark를 제안.

- 해상도: 12,768 × 9,564, 약 122MP
- 3,549 frames
- 21 sequences
- 138,830 boxes + cross-frame IDs
- 1,565 VQA pairs
- annotation의 약 98.7%가 tiny + small object

Detection, tracking, VQA를 한 benchmark에 넣고 **latency-aware streaming HOTA(s-HOTA)**까지 제안한다.

중요한 finding:
- model forward 시간만 보면 빠른 detector라도 full 122MP pipeline에서는 tiling/fusion 때문에 latency가 크게 늘어남
- offline HOTA ranking과 streaming ranking이 달라질 수 있음
- VLM들은 single-frame perception 차이는 크지만 cross-frame identity binding에서는 차이가 작고 전반적으로 약함

이 논문은 aerial perception을 “detector AP”가 아니라 **wide-area perception system**으로 보는 좋은 전환점이다.

---

### SparseQID
Multi-camera 3D tracking에서 sparse query를 recurrent하게 유지한다.

핵심은 dense multi-view feature를 매번 새로 계산하는 대신 **persistent sparse object query**를 시간에 걸쳐 전달하는 것.

보고된 HOTA는 약 29.63 → 38.01 개선.

공식 repo는 이전부터 공개돼 있었고:
- QUICKSTART
- tests
- reproduction scripts
- checkpoints

까지 비교적 잘 갖춰져 있다.

---

### GeoCond
Geospatial domain shift에서 단순 accuracy가 아니라 **reliability/calibration-aware adaptation**을 다루는 흐름.

Remote sensing에서 domain transfer를 할 때 target performance뿐 아니라 confidence validity를 같이 봐야 한다는 메시지가 중요하다.

---

### CRAFT
Coarse-first self-supervised multi-scale vision.

모든 위치를 동일한 high-resolution token으로 처리하지 않고 coarse attention이 중요한 영역을 선택해 fine representation으로 refine한다.

핵심 연결:
- gigapixel
- histopathology
- aerial imagery
- selective high-resolution compute

---

### GeoCueFormer
Underwater segmentation에서 high-frequency detail이 항상 유용하지 않음을 지적.

물속에서는 high-frequency component가 실제 edge가 아니라 scattering/noise일 수 있다.

즉:
> high-frequency preservation = 항상 좋은 inductive bias

가 아니라 domain별 frequency reliability를 따져야 한다.

Maritime/fog vision에서도 직접 연결 가능한 관점.

---

### Unified Response Geometry Pruning
Pruning을 parameter magnitude가 아니라 representation response geometry로 보는 방향.

핵심은 “어떤 weight가 작은가?”보다 “어떤 computation이 실제 response diversity를 만들고 있는가?”를 진단하는 것.

## VLM / Video / Multimodal

### SVMemAgent: A Streaming Video Memory Agent for Query-Agnostic Online Frame Selection

future query와 future frame을 모르는 streaming setting에서 제한된 memory에 어떤 frame을 보존할지 학습.

이 논문의 중요한 점은 long-video QA를:
```
more frames
```
가 아니라
```
better memory policy
```
로 바꾼 것이다.

---

### Using OCR Heads to Verbalize Image Semantics

VLM/LLM 내부에서 OCR에 중요했던 attention head가 사실 OCR 전용이 아니라 **general visual semantic verbalization head**로 작동할 수 있음을 보인다.

중요 finding:
- language-readable visual semantics가 매우 이른 layer부터 존재할 수 있음
- downstream failure가 representation 생성 실패보다 **readout/routing 실패**일 가능성

---

### Decodable but Misrouted: Sparse Features Uncover a Readout Gap in Vision-Language Models for Harmful Meme Detection

이번 배치의 핵심 진단 논문 중 하나.

예시:
- Qwen native macro-F1 ≈ 0.432
- sparse feature readout ≈ 0.740
- calibration/routing만으로 gap의 약 93.3% 회수

Gemma에서도 native 0.532 → sparse 0.714 수준.

핵심 메시지:
```
Model output failure
≠ representation failure
```

즉 모델 내부에는 필요한 정보가 있는데 output pathway가 잘못된 방향으로 읽을 수 있다.

사용자 small-object 연구에 연결하면:
> P3/P4에 tiny-object 정보가 실제로 남아 있는데 detection head가 못 읽는가?

라는 질문이 자연스럽게 나온다.

## LLM / Systems / Efficiency

### AutoTuneBench

시스템 성능 논문에서 headline speedup이 baseline/measurement condition에 따라 얼마나 크게 왜곡될 수 있는지 보여준다.

예시로 어떤 10.6× speedup claim이 stricter baseline/measurement에서 약 2.03× 수준으로 줄어드는 사례를 분석.

메시지:
- 동일 hardware
- 동일 precision
- 동일 batching
- 동일 warmup
- end-to-end 포함 여부

를 맞추지 않은 speedup은 연구적으로 약하다.

---

### OBC-Prune
Compression/pruning을 단순 weight magnitude가 아니라 output behavior preservation 관점에서 다룸.

### Zing-0.5
작은 real-time world model 계열.

대형 generative world model의 품질 경쟁과 별개로 실제 online latency를 맞추는 small model 흐름이 커지고 있음을 보여준다.

# 오늘의 중요한 Finding 3개

## 1. High-resolution small object는 architecture 문제이면서 동시에 system allocation 문제
HARD를 보면 122MP에서는 model forward보다 full pipeline이 훨씬 중요하다.

따라서 앞으로 tiny-object 연구는:
- APs
- recall
- tile coverage
- latency
- memory
를 함께 봐야 한다.

## 2. Representation / Readout / Reliability를 분리해야 한다
Decodable but Misrouted, OCR-head 분석, GeoCond 흐름을 묶으면:
```
정보가 있는가?
→ 그 정보를 head가 읽는가?
→ confidence를 믿을 수 있는가?
```
를 별도 문제로 봐야 한다.

## 3. Temporal memory는 frame accumulation보다 persistent state로 이동
SparseQID, SVMemAgent, HARD가 모두 “더 많은 frame”보다:
- object query
- persistent ID
- selective memory
를 강조한다.

# 후속 연구 씨앗

### 1. Where Did Tiny Object Information Go?
P2/P3/P4/P5별 objectness / class / localization recoverability probe를 붙여 representation loss와 readout failure를 분리.

### 2. Identity Is the Missing Modality
Video VLM에 raw frame만 주지 않고 explicit track ID / bbox / velocity / trajectory state를 추가해 cross-frame reasoning bottleneck을 검증.

### 3. Selective High-Resolution with Recall Guarantee
Coarse scout가 high-res tile을 선택하되 tiny-object miss를 explicit risk constraint로 관리.

### 4. Evidence-Calibrated VQA
정답 confidence와 evidence quality를 별도로 calibration.

### 5. Relation Distillation under Modality Mismatch
RGB↔event, RGB↔thermal에서 feature equality보다 relation structure 보존이 더 robust한지 검증.
