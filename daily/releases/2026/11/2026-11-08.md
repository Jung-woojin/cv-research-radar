## 핵심 release

### 1. Hugging Face Transformers v5.22.2

- **사실:** `v5.22.2`는 2026-11-06 15:43 UTC에 발행된 patch release다. release body는 NCCL일 때만 `device_id`를 설정하는 distributed 수정과 Jinja sandbox hardening을 명시한다.
- **artifact:** GitHub release asset은 0개다. 모델 weight, dataset, benchmark table, checksum, 별도 evaluator script의 새 배포는 release 원문에서 확인되지 않았다.
- **license / install surface:** repository license는 Apache-2.0이다. Python package update surface이며 `pip install --upgrade transformers==5.22.2`가 설치 후보지만 실제 설치는 수행하지 않았다.
- **hardware/VRAM:** framework patch라 정해진 GPU·VRAM 요구량은 없다. NCCL 수정은 multi-GPU job에서만 관련될 수 있다.
- **논문/claim 대비:** 새 모델 또는 수치 주장과 연결할 근거가 없다. sandbox hardening은 모델 품질 변화가 아니라 template/rendering attack surface 변화로 분리해야 한다.
- **진단 → 가설 → 최소 실험:** 분산 job의 device context 설정과 template sandbox 경계를 보강한 patch다. 2-GPU 최소 job에서 v5.22.1/5.22.2의 init·NCCL error·동일 seed loss를 비교하고, benign template와 sandbox-escape regression fixture를 별도 실행한다.
- **GO/KILL:** distributed CI가 v5.22.1에서 재현하던 device error를 v5.22.2에서 제거하고 loss가 동등하면 GO; 단일 GPU만 통과하면 distributed fix의 채택 근거는 KILL/보류다.
- **source:** https://github.com/huggingface/transformers/releases/tag/v5.22.2  
  https://github.com/huggingface/transformers

### 2. Ultralytics v8.4.207

- **사실:** `v8.4.207`은 2026-11-07 21:30 UTC에 발행됐다. release notes는 fresh environment의 Paddle export를 막던 `x2paddle`의 `six` dependency를 추가하고, 설치된 Paddle GPU build가 CPU build로 교체되지 않도록 setup check를 바꿨으며 export와 exported-model inference CI를 재활성화했다고 밝힌다.
- **artifact:** release asset은 `sbom.spdx.json` 하나다. 새 YOLO weight, dataset, evaluator dataset은 배포되지 않았다.
- **license / install surface:** repository license는 AGPL-3.0이다. Python package update와 Docker image base refresh가 surface이며, release note는 AMD image Ubuntu 26.04/Python 3.14 및 NVIDIA ARM64 image CUDA 13.4/TensorRT 11.4도 언급한다.
- **hardware/VRAM:** 일반적인 fixed VRAM 요구량은 선언되지 않았다. Paddle export/inference target, NVIDIA ARM64 및 Jetson/TensorRT 호환성은 runtime 조합에 종속된다. TensorRT 11은 JetPack을 지원하지 않는다고 release note가 명시한다.
- **논문/claim 대비:** model architecture change가 아니며, release note도 이를 명시한다. 이전 Paddle export benchmark와 새 export/inference 결과는 dependency/CI 변화 때문에 같은 실행 조건을 확인하기 전 **not strictly apples-to-apples**다.
- **진단 → 가설 → 최소 실험:** export support가 아니라 fresh-install dependency resolution이 failure cell이었다는 신호다. clean venv에서 같은 small model을 `Paddle export → exported-model inference`로 연결하고, GPU Paddle가 있는/없는 환경에서 installed package 목록과 output parity를 기록한다.
- **GO/KILL:** fresh CPU/GPU 두 환경에서 export·load·1-image prediction이 성공하고 prior baseline과 class/box parity가 확인되면 GO; CI만 green이고 local exported runtime이 실패하면 KILL이다.
- **source:** https://github.com/ultralytics/ultralytics/releases/tag/v8.4.207  
  https://github.com/ultralytics/ultralytics

### 3. Roboflow Supervision 0.31.5

- **사실:** `0.31.5`는 2026-11-05 18:35 UTC에 발행됐다. `LineZone`은 occluded track의 side state 기본 보존을 `max(2, threshold+1)`에서 `max(30, threshold+1)`로 변경했고, OpenCV install에서 oriented-box IoU/NMS/metric은 exact clipper를 사용하도록 바뀌었다.
- **artifact:** PyPI wheel `supervision-0.31.5-py3-none-any.whl`와 source tarball이 release asset으로 있다. 모델 weight나 dataset snapshot은 없다.
- **license / install surface:** repository license는 MIT다. Python package release이며 `pip install --upgrade supervision==0.31.5`가 설치 surface다. 새로운 `rtl` extra는 `khatt`를 설치한다.
- **hardware/VRAM:** CPU annotation/evaluation library라 release가 GPU·VRAM 요구량을 선언하지 않는다. 다만 release note는 exact OBB clipper가 OpenCV call보다 candidate pair당 약 10배 느려 crowded scene에서 seconds가 걸릴 수 있다고 밝힌다.
- **논문/claim 대비:** OBB precision/recall/F1/mAR와 line count가 같은 input에서도 바뀔 수 있다. 이는 모델이 좋아진 증거가 아니라 evaluator/state-policy 변화다.
- **진단 → 가설 → 최소 실험:** crossing count와 OBB metric의 drift가 annotation/model change가 아니라 runtime policy change에서 온다. 0.31.4/0.31.5에 occlusion 2·5·30 frame sequence와 near-collinear OBB fixtures를 동일하게 넣어 count, IoU, NMS survivor, runtime을 비교한다.
- **GO/KILL:** expected occlusion count와 analytic OBB IoU가 맞고 production latency budget 안이면 GO; stored benchmark가 drift하고 migration 기준이 없으면 version pin을 유지하며 KILL/보류다.
- **source:** https://github.com/roboflow/supervision/releases/tag/0.31.5  
  https://github.com/roboflow/supervision
