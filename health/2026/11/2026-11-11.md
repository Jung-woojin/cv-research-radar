## 진단 → 가설 → 최소 실험

**진단:** health script는 실제 원격 상태가 아니라 10월 28일에 멈춘 local checkout을 기준으로 누락을 계산한다. 이 때문에 원격에 존재하고 SHA까지 확인된 파일도 `missing`으로 표시된다.

**가설:** health script의 repository source를 GitHub 파일 API 결과 또는 최근 성공 ledger의 원격 SHA 검증으로 전환하면 false-positive backlog가 크게 줄어든다.

**최소 실험:** 오늘 원격 확인된 6개 path를 fixture로 두고, local-clone mode와 API mode의 existence/SHA 결과를 비교한다. API mode가 존재·SHA를 모두 맞히고 local mode만 `missing`이면 local-only 판정을 차단한다.

## 필요한 후속 조치

- `recovery-queue.json`에 local health divergence와 Paper Code/Weight ledger reconciliation을 pending으로 기록했다.
- 스크립트 수정 전에는 false-positive missing 목록을 backfill 대상으로 취급하지 않는다.
- 새 Issue 생성, disabled 재활성화, 과거 보고서 내용 보강은 수행하지 않았다.
