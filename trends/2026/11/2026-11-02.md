# 격주 CV 트렌드 맵 — 2026년 11월 2일

> 관찰: 2026-10-19 ~ 2026-11-02 (KST) · 비교: 2026-10-05 ~ 2026-10-19 · 기준: 논문 최초 공개일/공식 구현. 수치는 저자 보고값이며 독립 재현 결과가 아님. [사실] / [해석] / [전망]을 구분한다.

## 1. 한 문장 요약

이번 2주 CV·DL의 핵심은 **“무엇이 보이는가”를 예측하는 모델에서, “그것이 실제 어떤 객체인지, 시간이 지나도 같은 객체인지, 어떤 정보가 보존됐는지, 얼마의 계산으로 검증했는지”를 확인하는 시스템으로 이동**했다는 것이다.

직전 기간의 active evidence acquisition → object/state memory → budget-aware inference 흐름은 이번에 physical identity binding, memory information retention, dynamic query/token budgets, representation–readout diagnosis로 구체화됐다. 다만 일주일 단위의 신호로 분야 전체의 방향이 확정됐다고 단정하지 않는다.

## 2. 핵심 트렌드 8개와 대표 근거

### T1. Video VLM: 객체 인식에서 장기 identity 유지로 — 강한 상승

**[사실]** [Ask About the Right Moment](https://arxiv.org/abs/2610.31471, 10월 22일)는 컵 섞기와 유사한 비디오에서 VLM의 identity 지속성을 분석한다. **Track, Then Bind**는 관찰 가능한 순간에 정체성을 바인딩하고 나머지 구간은 tracker의 ID로 상태를 유지한다. 저자 보고에서 어려운 컵 게임 정답률 55.4%로 비교 대상 41.5%보다 높았다. [VideoMemBench](https://arxiv.org/abs/2610.40131, 10월 29일)는 326개 비디오, 2,476개 대화 턴, 1,387개 과거 턴 의존 질문을 수록하며, 평가된 20여 모델 중 최고 모델 전체 점수도 저자 보고 45.7%였다.

**[해석]** visual recognition과 temporal entity persistence는 다른 기능이다. perception → entity binding → tracking/state updating → readout으로 병목을 분리할 필요가 있다. **주의:** tracker 자체가 ID switch를 내면 VLM memory도 일관되게 잘못된 정체성을 유지한다. 영상 길이를 늘리는 것만으로 해결됐다고 보기 어렵다.

### T2. VLM의 평가 대상이 appearance에서 physical entity로 확장 — 강한 상승

**[사실]** [PhysCount](https://arxiv.org/abs/2610.40530, 10월 29일)는 거울·반사 등의 시각적 중복을 물리적으로 동일한 객체와 구분하도록 평가한다. 546개 이미지, 4,595개 질문, 651개 그룹이며 40개 MLLM 평가에서 최고 모델의 그룹 전체 정답률이 13.36%였다. [Probing Spatial State Representations in Visual Foundation Models](https://arxiv.org/abs/2610.40636, 10월 29일)는 10개 표현에서 현재 보이는 장면을 복원하는 능력, 가려진 객체 지속성, 미래 상태 예측, 행동에 활용되는 정보를 구분한다.

**[해석]** 텍스트에 해당하는 box를 찾는 grounding과 “여러 appearance가 하나의 물리적 entity인가”를 판단하는 것은 다르다. 해양 CCTV의 선박 반사, 가림, 재등장, 동일 berth 재점유 같은 문제에 직접 연결될 수 있다.

### T3. Video memory의 평균 정확도보다 질문별 정보 손실·총비용 — 강한 상승

**[사실]** [REEL: Same Frames, Different Answers and Different Costs](https://arxiv.org/abs/2610.38158, 10월 28일)는 같은 관찰 프레임을 Text/Visual/Prefix State memory로 보존했을 때 6개 VLM, 2개 벤치마크에서 질문별 정오가 20~29% 바뀔 수 있지만 평균 accuracy는 비슷할 수 있다고 보고했다. Prefix State는 정보 보존·GPU 시간에서 유리한 설정이 있었지만, 비디오당 최대 약 21GiB 저장 공간을 요구했다.

**[해석]** FramePack-U와 BudgetPix가 “어느 정보를 선택할 것인가”를 다뤘다면 REEL은 “버린 정보 때문에 어떤 질문이 더는 풀리지 않는가”를 묻는다. paired answer-flip rate, rare-event recall, evidence retention, storage, decode 포함 wall-clock을 함께 보고해야 한다.

### T4. Tiny Detection과 VLM에서 균일 계산 대신 입력별 query/token 예산 — 상승

**[사실]** [Dynamic Query as Budgeting for Tiny Object Detection (BUTR)](https://arxiv.org/abs/2610.33430, 10월 24일)는 query의 종류와 수를 분리해 encoder 신뢰도로 K를 결정한다. 800×800, T4 GPU에서 AI-TOD-v2 35.7 AP·47.8 FPS, VisDrone 29.8 AP·42.1 FPS라는 저자 보고 수치와 [공식 코드](https://github.com/zhangyi-magic/BUTR)가 있다. [Don't Ask the LLM / ST-Pruner](https://arxiv.org/abs/2610.38303, 10월 28일)는 시각 토큰을 LLM 입력 이전에 선별해 최대 11.1% 토큰으로 원성능의 95% 이상을 보존하고 LLaVA-NeXT에서 3.2배 end-to-end 속도를 보고했다([코드](https://github.com/sejong-rcv/ST-Pruner)).

**[해석]** 여러 과제에서 같은 방향, 즉 계산을 정보 가치에 따라 배분하는 정책이 반복된다. 그러나 낮은 객체 밀도는 작은 위험 객체의 부재를 뜻하지 않는다. adaptive budget은 **tiny recall 하한**과 selection overhead를 함께 검증해야 한다. 토큰 감소율은 지연·전력 감소율과 다르다.

### T5. OVD의 한계: 의미 지식보다 작고 세밀한 영역의 시각적 증거 — 상승

**[사실]** [FocusOVD](https://arxiv.org/abs/2610.27479, 10월 20일)는 frozen VLM에 cross-scale fusion, high-resolution geometry, RoI discrimination을 적용하며, COCO-OVD novel AP 36.3%, LVIS-OVD overall AP 33.7%를 저자 보고했다.

**[해석]** 언어공간에서 클래스 개념을 아는 것과 영상의 작은 RoI에서 구분 증거를 추출하는 것은 다르다. 소형 객체 P2/high-frequency 보존과 OVD negative transfer 연구가 만나는 지점이다. 복수 모듈의 효과 귀속은 ablation으로 재확인해야 하며 COCO novel AP와 LVIS overall AP를 직접 비교하지 않는다.

### T6. Foundation model: 사전학습 표현 보존과 readout 손상 진단 — 상승

**[사실]** [GIFT](https://arxiv.org/abs/2610.35374, 10월 26일)는 무제약 fine-tuning이 pretrained geometry를 훼손할 수 있음을 논의하고 Householder reflection/경량 scaling으로 추가 학습 파라미터를 backbone의 1% 미만으로 제한한다. 저자 보고 Cityscapes-C·Diverse Weather Dataset에서 mPC +7.9 / +2.9이며 [공식 코드](https://github.com/zhangyin1996/GIFT)를 공개했다. [RePAIR](https://arxiv.org/abs/2610.37015, 10월 27일)는 semantic segmentation backdoor 상황에서 feature에 남은 정보와 훼손된 classifier 출력의 불일치로 예측을 보정한다.

**[해석]** 둘은 목적이 다르지만 “encoder가 몰라서 실패한 것인지, head/readout이 잘못 읽는지”를 분리한다는 진단적 관점이 일치한다. 이는 frozen backbone이 모든 도메인에 우월하다는 결론은 아니다.

### T7. Segmentation: 불확실한 영역의 선택적 고해상도 처리와 구조적 layer — 상승

**[사실]** [MatAnyone-E](https://arxiv.org/abs/2610.35724, 10월 26일)는 저해상도 불확실 영역을 탐지해 관련 부분만 고해상도로 계산한다. 저자 보고 약 7.4배 가속, 4K peak GPU memory를 MatAnyone 2의 7.6% 수준으로 축소, H200 컴파일 추론 28.62FPS다. [The Power Watershed as a Differentiable Segmentation Layer](https://arxiv.org/abs/2610.38516, 10월 28일)는 differentiable watershed로 PanNuke instance F1을 비교 U-Net 구성의 0.656에서 0.795로 개선했다고 보고한다.

**[해석]** 하나는 계산 위치, 다른 하나는 출력의 구조적 제약을 다룬다. 둘 모두 단순 backbone 확대 외의 기여다. H200 실시간 결과가 Jetson 효율을 보장하지 않으며, 조직 segmentation 결과를 일반 객체 segmentation으로 바로 일반화해서도 안 된다.

### T8. Maritime·UAV Vision: 특성·동작·환경을 함께 보는 평가 — 상승 신호지만 표본 제한

**[사실]** [MarineLife-16K](https://arxiv.org/abs/2610.33478, 최초 10월 24일/수정 29일)는 2,000개 해양 비디오, 13개 시각 속성, 16,080개 질문을 수록하며 조명·시간·행동·카메라 운동 조건을 포함한다. 평가된 VLM들은 일부 환경과 camera motion 조건에서 여전히 실패했다. GIFT는 악천후 shift, BUTR은 항공 tiny object의 비용을 연구한다.

**[해석]** 환경·시간·속성·비용을 합친 도메인별 평가가 필요하다는 신호다. 단, MarineLife-16K는 해양 생물·수중 비디오 연구이며 **항만 CCTV·해무 데이터셋이 아니다**. UAV와 해양 전반의 새로운 패러다임이라고 과도하게 확장하지 않는다.

## 5. Benchmark·데이터셋 이동

- **PhysCount:** 시각적으로 보이는 사본 수와 실제 물리 객체 수의 차이 평가.
- **VideoMemBench:** multi-turn 의존성과 비디오의 episodic memory 평가.
- **REEL:** 동일 관찰 프레임을 저장 형식만 바꾸었을 때 정오 변동과 계산·저장 비용 비교.
- **MarineLife-16K:** 해양 객체 속성·행동·환경·camera motion을 포함한 도메인 영상 QA.
- **AI-TOD-v2 / VisDrone:** 객체 크기·밀도에 따른 detector query budget과 tiny-object recall.
- **Cityscapes-C / Diverse Weather Dataset:** 사전학습 표현 보존과 악천후 강건성.
- **PanNuke:** segmentation 경계·instance partition 제약의 검증.

**[해석]** 평가 메타데이터에 entity ID, occlusion/reentry, past-turn dependency, sampling offset, evidence survival, decode+GPU cost, risk-weighted FN을 기록해야 한다. 지난 2주 사이 COCO·LVIS·VisDrone 공식 리더보드 규칙이 일괄 개편됐다는 검증된 근거는 없다. **‘benchmark 이동’은 주로 새로운 문제 정의와 측정 축의 증가**다.

## 6. 아키텍처·학습·추론 변화

**아키텍처:** 범용 backbone 하나를 키우는 전략 외에 frozen visual encoder + spatial refinement + tracker/identity memory + task readout + budget controller의 역할 분리가 나타났다. CNN은 국소 디테일·경계 복원, ViT는 대규모 사전학습 의미 표현, SSM은 긴 순서·상태 처리를 담당하는 식의 과제별 조합이다. LayoutMamba는 문서 레이아웃이라는 제한된 예시이며 CNN 대 ViT 대 SSM 전체 승부를 결정하지 않는다.

**학습:** full fine-tuning 대안으로 geometry-constrained adaptation이 부상한다. 표현의 존재와 readout의 성공을 각각 probe해야 원인을 알 수 있다. 구조적 segmentation layer는 후처리 규칙을 학습 가능한 출력을 구성하는 방법으로 변환한다.

**추론:** uniform high-resolution, fixed query K, full visual tokens에서 uncertainty·density·관심 영역에 따른 적응형 배분으로 이동한다. 단일 모델 FLOPs 외 decode, selection, peak memory, storage, actual wall-clock, edge energy를 모두 봐야 한다.

## 7. 반복되는 미해결 문제

1. **Identity persistence:** tracker ID switch·가림·재등장 상황에서 같은 entity를 유지하기 어렵다.
2. **Physical vs visual entity:** 반사·투명 표면의 여러 appearance를 하나의 객체로 세지 못한다.
3. **Memory compression:** 평균 QA가 안정적이어도 특정 위험 이벤트 증거는 소실될 수 있다.
4. **Representation/readout:** encoder 지식 손실인지 head suppression인지 fine-tuning 실패 원인 귀속이 불충분하다.
5. **Tiny-object recall:** 효율화 정책이 고위험 작은 객체를 제거할 수 있다.
6. **Domain shift:** 날씨·항만·카메라·월별 조건에 따른 source retention과 worst-domain 성능의 충돌.
7. **Domain validity:** generic VQA/OVD 점수가 실제 해양·항공 감시의 장기 상태·위험을 대표하는지 불명확하다.
8. **Deployment realism:** T4/H200 수치의 Jetson/edge 전이가 입증되지 않았다.

## 8. 앞으로 1~3개월의 성장 가능성 [전망]

- **Entity-aware grounding:** box/time grounding에 physical ID와 장기 state consistency를 포함한 평가 증가.
- **Memory fidelity × cost:** raw/text/prefix memory 사이 질문별 정보 손실·저장 비용을 동시에 최소화.
- **Recall-constrained adaptive compute:** 효율화 정책의 tiny recall 하한을 명시한 query/token/resolution budgeting.
- **Representation-preserving adaptation:** foundation encoder의 정보/기하 구조 보존과 negative transfer 진단을 연결.
- **Domain-native video benchmarks:** 해양·항공·의료 영상에 특화된 identity, risk, temporal evaluation.

전망은 현재 관측의 연구적 추론이지 향후 채택/성공이 확인된 사실이 아니다.

## 9. Hype에 비해 검증이 필요한 주장

- **Long context가 temporal identity를 자동으로 해결한다:** tracker·object binding의 독립 검증이 필요하다.
- **평균 accuracy 유지 = 정보 무손실:** REEL의 질문별 20~29% 정오 전환 가능성에 반한다.
- **큰 FM을 더 많이 fine-tune하면 항상 개선:** GIFT가 geometry damage 가능성을 제시한다.
- **CNN/ViT/SSM hybrid는 무조건 우수:** 역할별 ablation과 동일 조건 latency 없는 stacking은 기여가 약하다.
- **토큰 90% 감소 = end-to-end 비용 90% 감소:** decode·selection·memory·energy 비용이 별개다.
- **MarineLife 벤치마크로 항만 CCTV 안전을 검증 가능:** 수중 생물 비디오와 항만 CCTV는 과제·관찰 조건이 다르다.

## 10. 사용자 연구와 연결되는 기회 5개

### A. OVD negative transfer의 representation vs readout 진단

**문제:** novel/rare class의 fine-tuning 후 성능 저하가 표현 소실인지 readout 억제인지 불명확하다.

**가설:** 시각 특징에 novel 정보가 남았다면 encoder 고정 상태에서도 oracle RoI/prototype/linear probe로 성능 회복 가능하다.

**MVP:** 동일 backbone의 pre/post adaptation features, frozen linear probe, oracle crop, prototype classifier, original head 비교. GIFT식 geometry preservation 1개 비교군.

**지표:** base/novel/small-novel AP, representation drift, prototype margin, calibration. **GO:** readout 교정만으로 novel AP 손실의 30% 이상 회복. **KILL/수정:** oracle probe에서도 구별 정보가 없으면 표현 재학습 방향으로 전환.

### B. Tiny recall을 보장하는 adaptive query budget

**문제:** density-only budgeter가 희귀 소형 객체를 가진 이미지에서 K를 과하게 줄일 위험.

**가설:** P2 불확실도·high-frequency tiny prior를 budgeter 입력에 추가하면 효율과 recall을 함께 지킬 수 있다.

**MVP:** AI-TOD-v2/VisDrone에서 fixed-K, BUTR, uncertainty-aware-K 비교.

**지표:** AP_tiny, Recall_tiny, FN/image, T4/edge latency, K 분포. **GO:** tiny recall 저하 ≤1%p, latency ≥15% 감소. **KILL:** budgeter overhead가 절감의 절반 이상.

### C. 항만 CCTV의 appearance–identity–state 벤치마크

**문제:** 같은 berth, 가림, 반사, 재등장에서 선박 ID와 상태가 잘못 결합될 수 있다.

**가설:** detector+tracker+explicit memory가 frame-only VLM보다 장기 identity를 안정적으로 유지한다.

**MVP:** 적법하게 사용 가능한 항만 sequence 100~200개에 vessel ID, reentry, occlusion, state change 주석. tracker-only, video-VLM, track-then-bind 비교.

**지표:** IDF1, ID switches, stale-state rate, QA accuracy, latency. **GO:** ID switches 상대 20% 이상 감소, QA 비열화. **KILL:** tracker 오류와 annotation inconsistency가 더 큰 병목일 때 먼저 데이터/평가 수정.

### D. 해무·항만 CCTV의 representation-preserving adaptation

**문제:** 악천후 domain 적응이 정상 조건·다른 항만 성능을 떨어뜨릴 수 있다.

**가설:** representation geometry 보존 또는 제한된 adapter 학습은 source retention과 worst-port F1을 개선한다.

**MVP:** 항만×월별 split 고정, full FT vs frozen+head vs LoRA vs geometry-preserving FT, 3~5 seeds.

**지표:** macro F1, worst-port/month F1, source retention, representation drift. **GO:** worst-domain F1과 source retention 동시 개선. **KILL:** split leakage나 sampling 차이보다 개선이 작은 경우 구조 복잡화 보류.

### E. Video memory의 rare-event evidence retention

**문제:** 평균 QA를 유지하는 memory 압축이 짧은 위험 사건·작은 선박 증거를 제거할 수 있다.

**가설:** object/event-aware memory가 generic summary보다 고위험 evidence를 보존한다.

**MVP:** raw frames, text summary, selected keyframes, object-event memory를 동일 영상·질문에서 비교.

**지표:** paired answer flip, rare-event recall, high-risk FN, storage MB/video, GPU time. **GO:** 저장량 50% 감소하면서 high-risk event recall 저하 ≤1%p. **KILL/수정:** annotation cost가 효과를 초과하면 keyframe baseline으로 축소.

**실행 우선순위:** A/D는 기존 해무 분류와 연구 코드 재사용이 가능해 단기 실행성이 높다. B는 작은 객체 설계 논문으로, C는 일본 박사과정의 장기 연구 주제로 확장 가능하다. GO/KILL 숫자는 사전등록 실험 가정이지 검증된 과학적 임계값이 아니다.

## 12. 텍스트 기반 트렌드 맵

    [Perception → Grounding → Stateful VLM]
    closed-set detection
       └→ open-vocabulary detection
            └→ fine-grained / small-object grounding (FocusOVD)
                 └→ physical entity binding (PhysCount)
                      └→ identity persistence (Track, Then Bind)
                           └→ multi-turn state memory (VideoMemBench)

    [Large Foundation Model → Specialized / Efficient Model]
    large-scale pretrained vision encoder
       └→ frozen / geometry-preserving adaptation (GIFT)
            └→ task-specific spatial readout
                 └→ budget-conditioned compute
                      ├→ detector query K (BUTR)
                      ├→ VLM visual tokens (ST-Pruner)
                      └→ segmentation HR regions (MatAnyone-E)
                           └→ memory fidelity & total cost audit (REEL)

    [CNN ↔ ViT ↔ SSM: 역할별 재평가]
    CNN = locality, detail, segmentation boundaries
    ViT = broad pretrained global representation
    SSM = sequence / memory efficiency
       └→ task-specific hybrids (LayoutMamba)
            └→ measure each module with controlled ablations

    [Evaluation]
    mean mAP / QA accuracy
       └→ evidence timestamp / RoI
            └→ entity ID + state consistency
                 └→ information retention + risk-sensitive FN
                      └→ actual wall-clock / storage / energy

    [Research intersection]
    maritime CCTV × UAV tiny objects × severe weather
       × representation-readout diagnosis
       × physical identity
       × recall-constrained computation

## 결론과 실행 순서

**[해석]** “VLM이 CV를 대체한다” 또는 “CNN·SSM이 ViT를 이겼다”는 결론은 과장이다. 이번 기간에 보다 명확해진 것은 **기존 시각 표현에서 객체 identity·상태·정보 보존·예산·일반화의 어느 단계가 실패했는지 진단하고 그 단계에 최소 개입을 하는 연구**다.

**이번 주:** 기존 해무·항만 데이터에서 feature vs head probe 설계와 tiny-object recall/budget baseline을 먼저 구축한다. **다음 주:** 도메인별 worst-case 및 장기 identity/evidence 보존을 작은 고정 평가 세트로 검증한다. 무엇보다 average metric 외 데이터 split, paired flip, wall-clock, risk FN을 실험 로그에 함께 저장한다.
