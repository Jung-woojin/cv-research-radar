### V1. When Does Reusing Layers Help Multimodal Embeddings?

**날짜·방법:** v1 11월 15일 06:16 UTC. 하나의 vision-language architecture의 세 checkpoint에서 11개 loop·학습 변형을 조사한다. 반복 계산 사용, query-sensitive image state, 실제 retrieval 이득을 구분한다.

**저자 보고:** MMEB-V2 78개 dataset에서 단순 추가 loop는 학습한 control보다 0.46점 낮고, generative 중간 학습 뒤에는 +0.36점이다. recurrence로 사전학습한 모델의 자체 loop 제거 대조는 +4.23점 차이다. 서로 다른 학습 조건의 수치를 직접 순위화하면 **not strictly apples-to-apples**다. [논문](https://arxiv.org/abs/2611.19827)

**진단·제안:** causal image-before-query 순서에서는 단순 반복만으로 image state가 query를 볼 수 없다. 경로를 열어도 later visual update를 동결했을 때 성능이 유지되는 조건이 있다. query 민감성 자체가 기여는 아니다. 이미 수행한 freeze ablation을 반복하는 데 그치지 말고 count·spatial·grounding slice에서 유효한 update 범위를 찾는다. [실험 논리](https://arxiv.org/html/2611.19827v1)

### V2. FAVR: Flow-Aware Visual Residual Alignment for Vision-Language-Action Policies

**날짜·방법:** v1 11월 16일 UTC. frozen VLA에 compact temporal visual state와 flow step에 따른 visual gate를 넣는다. affine action head의 구조를 이용해 채널 선택을 최적화한다.

**저자 보고:** trainable parameter 1.74~2.19M, adaptation 5,000 step이다. RoboTwin 2.0의 LingBot-VLA가 clean 87.12%→90.04%, randomized 86.88%→89.38%로 개선됐다. 다섯 task의 controlled ablation에서는 shared gate 72.0% 대비 flow-aware gate 82.0%를 보고한다. [논문](https://arxiv.org/abs/2611.20971)

**진단·제안:** gate의 시점 의존성이 필요한지, 단지 추가 visual state가 유리한지 분리한다. 같은 checkpoint·추론 길이에서 gate 고정/step shuffle/학습 gate를 비교한다. 작은 trainable parameter 수가 작은 전체 모델이나 저렴한 adaptation을 뜻하지 않는다. HTML 접근은 오류였으며 code·weight·전체 VRAM·실제 robot 전이는 미확인이다.

**진단·제안:** 필드별 성능과 완전한 기록 성공률을 함께 보고, 독립 필드 가정 대비 오류 공발생을 검사한다. 원문에 이미 independence baseline·human judge 검증이 있으므로 그것 자체는 새 기여가 아니다. maritime object의 상태·위치·행동 동시 정답 평가로 확장하려면 별도 annotation이 필요하다. dataset 배포·license는 미확인이다. [평가·한계](https://arxiv.org/html/2604.07338v3)

## 6) 연구적으로 중요한 Finding 3개

1. **정보를 잃는 단계와 잘못 읽는 단계를 구분할 수 있다.** UAV의 같은 crop 재채점과 loop 연구의 visual-update freeze는 후보·정보를 고정한 채 readout 기여를 검사한다. 서로 같은 기전임을 입증한 것은 아니다. [UAV](https://arxiv.org/html/2611.20127v1), [Loop](https://arxiv.org/html/2611.19827v1)
2. **평균 보존은 취약 slice 보존을 보장하지 않는다.** event pruning의 작은 객체 손실과 문화 metadata의 완전 기록 성공률은 각각 압축과 다중 필드 평가의 함정을 보여준다. [Event](https://arxiv.org/abs/2611.19746), [Appear2Meaning](https://arxiv.org/abs/2604.07338)
3. **probe 성공은 제어 성공과 다르다.** viewing direction의 decodability와 query-sensitive image state는 내부 변화가 task에 쓰이는지 별도 개입이 필요함을 시사한다. [Viewing direction](https://arxiv.org/abs/2611.19642), [Loop](https://arxiv.org/abs/2611.19827)

이 세 연결은 보고서의 **추론**이다.

## 7) 과대평가 가능성 / 주의할 연구

- **UAV ground verifier:** 같은 crop에서 recall 이득을 보여도 오경보 감소의 paired interval은 0을 포함한다. post hoc 분석, 한 번의 실행, inferred block, 자체 비행 영상 미공개를 함께 읽어야 한다. 탐색 성공 확률이나 일반적인 SAR 신뢰도 보증은 아니다. [한계](https://arxiv.org/html/2611.20127v1)
- **AGPF attention·loop 성능:** attention mass를 곧 원인으로 읽거나 다른 pretraining의 loop 효과를 결합하면 과장이다. AGPF는 token 수 보정이 필요하고 loop는 학습 regime별 자체 control이 기준이다. [AGPF](https://arxiv.org/html/2611.19836v1), [Loop](https://arxiv.org/html/2611.19827v1)

## 9) 1위 논문 5~10분 미니 리뷰

**왜 중요한가:** 이 논문의 유용한 기여는 작은 보드 detector가 표준 detector를 이긴다는 이야기가 아니다. thermal에서는 오히려 YOLO11n이 훨씬 강하다. 평가 분할과 장소 전이, 계산 제약을 함께 공개하면서 어떤 단계에서 성능을 잃는지 보여준다. [논문](https://arxiv.org/abs/2611.20127)

**실험의 blind spot:** 인접 frame이 train/test에 섞이면 새 recording에 대한 일반화를 과대평가할 수 있다. 또 validation에서 고른 threshold가 새로운 장소에서도 같은 오경보율을 만들지는 않는다. frame별 false detection과 실제 operator alert 수 역시 다르다.

**핵심 논리:** HERIDAL의 같은 16 crop을 유지하고 YOLO 점수와 ground 점수를 비교한다. validation location에서 threshold를 고정한 뒤 15개 test location을 평가하므로 후보 생성과 최종 채점의 효과를 분리한다. target 0.5 false alarms/frame 조건의 recall은 44.9%→53.7%다. 장소 단위 paired bootstrap의 차이는 +8.8 points [2.4, 12.5]지만, 오경보 변화 −0.22의 구간은 [−0.75, +0.30]이다. **recall 이득과 오경보 감소의 확실성은 다르다.** [결과표](https://arxiv.org/html/2611.20127v1)

**진짜 contribution과 한계:** 사전 선언 평가와 post hoc 분석을 구별하고, 각 수치와 결과 파일의 연결을 설명한다. 하지만 paired 분석은 반복 실행되지 않았고 recording block은 metadata에서 추론했으며 자체 영상은 배포되지 않는다. 코드 링크도 이번에는 404였다. 완전 재현 가능으로 판정할 수 없다.

**사용자 연구에 가져올 점:** UAV·해양 tiny-object에서 먼저 candidate recall ceiling과 같은 후보의 oracle 선택 여지를 측정한다. 후보 자체가 정답을 포함하지 않으면 head 교체 실험의 상한이 낮다. 후보가 충분한데 점수만 실패하면 calibration·readout이 더 작은 개입이다. 이것은 제안이며 논문이 해당 해양 조건을 검증한 것은 아니다.

## 10) 후속 연구 씨앗 3개

### 씨앗 1. 새 장소에서 UAV verifier의 이득은 후보 정보인가, 점수 보정인가?

- **Observation→Diagnosis:** 같은 후보 재채점은 개선되지만 장소별 threshold 전이는 불안정하다. 근거는 C1이다.
- **가설:** feature를 바꾸지 않은 calibration만으로 설명되는 부분과 crop 표현의 추가 정보가 분리된다.
- **최소 개입·baseline:** 동일 detector의 저장된 top-K crop을 고정하고 원 점수/validation-only calibration/작은 verifier/oracle 후보 상한을 비교한다.
- **Dataset·ablation:** 접근 가능한 HIT-UAV·HERIDAL의 recording·location group split. random-frame split은 leakage 민감도 대조로만 쓰며 K·객체 크기·정지/이동을 나눈다.
- **Metric·GO/KILL:** validation threshold 고정 후 장소별 recall·false alarms/frame·candidate recall ceiling·장소 bootstrap. verifier 이득이 새 장소·반복 seed에서 남으면 GO. calibration만으로 같아지면 새 representation 주장을 KILL하고 점수 전이 진단으로 축소한다.
- **비용·novelty:** 저장 출력 감사는 cost 1/5, verifier 학습은 계획상 2/5이며 실측이 아니다. 고정 후보 재채점은 이미 원문에 있어, 신규성은 여러 장소·센서에서 원인 분리와 실패 경계에 있어야 한다. negative result도 verifier 불필요 조건을 제시할 수 있다.

### 씨앗 2. Event pruning의 tiny-object 손실은 event 수 부족인가, fine-scale 처리 실패인가?

- **Observation→Diagnosis:** 평균 정확도를 보존하면서 작은 객체 recall이 손상된다. 근거는 C3이다.
- **가설:** 같은 총 event budget에서도 작은 영역의 signal을 보존하면 특정 크기·motion slice를 복구할 수 있다.
- **최소 실험:** PEOD의 고정 checkpoint에 random/input pruning/작은 영역 보호를 적용한다. 배포 정책은 GT를 사용하지 않고 event density 등 관측량만 사용한다. GT 보호는 진단용 oracle 상한으로 별도 표기한다.
- **Ablation·판정:** event count와 noise를 분리하고 fine/coarse feature patching을 대조한다. recall-by-size·AP·latency·event budget을 함께 기록한다. 동일 budget에서 개선이 남으면 GO. oracle만 좋아지면 배포 개입 주장은 KILL하고 evidence 부족을 결론으로 남긴다.
- **비용·위험:** 추론·feature 감사 cost 2/5의 계획 추정. 원문이 pruning·patching을 이미 수행했으므로 단순 재현은 novelty가 낮다. 새 조건의 실패 예측이나 실행 가능한 budget 정책까지 검증해야 4~8주 연구 후보가 된다.

### 씨앗 3. Query-sensitive visual update는 어느 task에서만 유용한가?

- **Observation→Diagnosis:** query가 image state를 바꿔도 일부 조건에서는 update 동결로 성능이 떨어지지 않는다. 근거는 V1이다.
- **가설:** 단순 category retrieval보다 counting·spatial relation·text grounding에서 update의 기여가 커지지만 pretraining regime에 의존한다.
- **최소 실험·baseline:** MMEB-V2의 사전 고정 task slice에서 matched checkpoint의 one-pass/loop/visual-update freeze/query shuffle을 비교한다. 가능한 범위에서 executed compute도 맞춘다.
- **판정:** slice별 retrieval·grounding 정확도, latency, update 제거의 paired 효과를 기록한다. 유효한 query 정보에만 효과가 남으면 GO. query shuffle에도 유지되거나 text state만으로 설명되면 visual refinement 주장을 KILL한다.
- **비용·novelty:** frozen inference 진단 cost 2/5의 계획 추정. 원문의 freeze·순서 대조가 선행연구이므로 새 task slice 하나만으로 충분하지 않다. 여러 학습 regime에서 유용한 update를 예측하는 기준이 필요하다. negative result는 안전하게 loop를 생략할 조건을 제시한다.

**오늘 첫 실험:** 씨앗 1의 group split·candidate ceiling·저장 점수 재평가. 공개 artifact 접근이 막혀 있으면 보유한 적법한 데이터와 detector 출력으로 시작한다. **작은 GPU 우선:** 학습 전 CPU 기반 분할·점수 감사. **장기 주제:** 정보 존재→정보 접근→예측 기여의 세 단계를 vision·multimodal·agent에 공통 적용하는 진단.

## 11) 오늘 안 읽어도 되는 것 / 보류 후보

19편의 개별 공식 초록 중 위 12편을 선정했다. 나머지 7편은 다음 이유로 보류했다.

- [VidEngram](https://arxiv.org/abs/2611.18578), [Read, Route, Patch](https://arxiv.org/abs/2611.18585): 새 목록에 등장하지만 abs의 v1은 각각 7월 28일·8월 9일이다. 최근 실제 변경을 확인하지 못했다.
- [ReMoVe](https://arxiv.org/abs/2611.18666), [Speaking-Clock Mamba](https://arxiv.org/abs/2611.18667): abs v1은 모두 10월 25일이며 최근 release 근거가 부족하다.
- [Is It Still There?](https://arxiv.org/abs/2611.18734): 진단 가치는 높지만 v1 11월 10일, 새 revision은 확인하지 못했다.
- [I Am Not a Kiddo!](https://arxiv.org/abs/2611.18583): v1 8월 5일이고 오늘의 CV 실험 우선순위가 낮다.
- [Image Rotation Angle Estimation](https://arxiv.org/abs/2603.25351): new 목록은 JPEG trace를 제거한 v2·변경 제목을 설명하지만 조회된 abs는 v1 제목·수치만 반환하고 v2는 cache miss였다. 수정 후 수치를 구버전에서 가져오지 않았다.

**실행 경계:** 위 실험은 모두 제안이다. 새 모델·모듈을 바로 추가하기 전에 분할, 후보 상한, score, 정보 경로를 먼저 고정하는 것이 오늘의 권고다.
