## Q1. 오프라인 Agent VQA는 모델군·정책이 바뀌어도 온라인 에이전트 순위를 보존하는가?

### Research Question

도메인에 맞춘 오프라인 VQA slice가 작은 온라인 rollout의 모델 순위를 예측할 때, 모델 크기·open/closed 여부·thinking·행동 이력·도구 정책이 달라져도 그 상관이 유지되는가? 유지되지 않는다면 어떤 shift에서 온라인 평가를 생략하면 안 되는가?

### Observation

- **확인된 사실:** AgentVQA는 23개 원천 데이터셋의 1,000문항과 5개 agent domain을 포함하며, 22개 모델 중 최고 정확도도 58.5%였다.
- **확인된 사실:** 12개 공통 모델에서 Spatial Planning slice와 온라인 SpatialWorld Physical track의 Spearman 순위 상관은 ρ=0.895였다. 일반 benchmark의 상관은 MMMU-Pro 0.67, GPQA-Diamond 0.59, ChartQA-Pro 0.44였다.
- **확인된 사실:** Web Agents에서 action history를 제거하면 5개 모델 평균 성능이 두 원천 데이터셋에서 각각 9.5%, 10% 감소했다.
- **저자 주장:** 대응 도메인의 오프라인 평가가 비싼 온라인 rollout의 보완재가 될 수 있지만, 영역이 다르면 상관이 낮다.
- **레이더 추론:** 한 영역·12개 모델에서 높은 상관이 나왔다는 사실은 새로운 모델군이나 agent policy에서도 순위가 보존된다는 보장이 아니다.

직접 근거: [AgentVQA arXiv](https://arxiv.org/abs/2610.31494) · [AgentVQA HTML](https://arxiv.org/html/2610.31494) · [공식 코드](https://github.com/zlab-princeton/AgentVQA)

### Gap

현재는 오프라인 점수와 온라인 성공률의 단일 상관을 보고한다. 모델군 외삽, action-history ablation, prompt/policy 변화, 비용 대비 순위 신뢰구간을 함께 평가하는 surrogate-validity protocol은 부족하다.

### Hypothesis

오프라인 slice는 같은 perception stack과 행동 이력을 쓰는 모델군 안에서는 순위를 보존하지만, tool policy나 state representation이 바뀌면 상관이 급락한다. 10~20개의 calibration rollout으로 surrogate의 불확실성을 보정하면 전체 온라인 평가의 상당 부분을 줄일 수 있다.

### Experimental Design

1. open VLM 3개와 closed VLM 2개를 선택하고 direct, thinking, action-history 조건을 고정한다.
2. AgentVQA Spatial Planning 100문항과 작은 online environment 50 episode를 실행한다.
3. 20 episode로 rank calibration을 학습하고 나머지 30 episode에서 순위·성공률 예측을 검증한다.
4. 모델 크기, open/closed, history 유무, policy 유형별 leave-one-group-out 평가를 한다.
5. 전체 online rollout 대비 평가 비용과 잘못된 모델 선택 확률을 함께 기록한다.

### Baseline·Metric·GO/KILL

- Baseline: 일반 VQA 평균, AgentVQA 전체 평균, 대응 domain slice, 소량 rollout-calibrated surrogate.
- Metric: Spearman/Kendall 순위 상관, top-1 model selection regret, calibration interval coverage, 평가 비용.
- **GO:** leave-one-model-out ρ≥0.7, top-1 regret≤5%p, 온라인 비용 70% 이상 절감.
- **KILL:** policy shift 한 번으로 ρ<0.4가 되거나 calibration interval이 실제 성공률을 80% 미만으로 포함.

### Expected Contribution

오프라인 agent benchmark를 “싸고 정확한 대체물”로 선언하는 대신, 사용할 수 있는 범위와 반드시 online rollout이 필요한 조건을 판정하는 실용적 평가 규약을 제안한다.

### Risk·Compute·논문화

- Risk: 특정 환경의 reward noise가 상관을 지배할 수 있다. seed와 episode bootstrap이 필요하다.
- Compute 난이도: **2/5**. 오프라인 100문항과 250개 내외 episode로 시작할 수 있다.
- 4~8주 논문화 가능성: **4/5**. 작은 진단 연구로 빠르지만 두 번째 online environment가 있으면 설득력이 커진다.
- Negative result 가치: surrogate가 불안정하면 오프라인 leaderboard가 agent 배포 결정을 대체하면 안 된다는 직접 증거가 된다.

**평가:** 새로움 4/5 · 실행 가능성 5/5 · 계산 효율 5/5 · 논문화 가능성 4/5

## Q2. 원영상과 구조화된 추적 상태가 충돌할 때 VLM은 언제 외부 상태를 신뢰해야 하는가?

### Research Question

외부 tracker가 제공한 ID·좌표·가림 상태와 VLM의 원영상 해석이 다를 때, uncertainty와 검증 가능한 사건을 이용한 arbitration이 항상 원영상 우선 또는 항상 tracker 우선보다 객체 정체성 추론을 안정화하는가?

### Observation

- **확인된 사실:** Ask About the Right Moment에서 8B~235B open model, thinking variant, RL tool agent, 세 training-free tool agent는 실제 셸 게임에서 대체로 우연 수준 ±10%p 안에 머물렀다.
- **확인된 사실:** `Track, Then Bind`는 Qwen3-VL-32B로 VET-Bench 두 과제 100%, PT-65 55.4%, TOC-Bench 48.6%를 기록했다. 같은 모델 직접 응답은 TOC-Bench 37.1%였다.
- **확인된 사실:** 올바른 tracked fact와 원영상을 함께 제시하면 모델이 영상을 다시 해석해 합성 컵 성능이 8B 38%, 32B 76%로 하락했다. 반대로 tracker도 동일 물체 교차에서 ID switch를 낼 수 있다.
- **저자 주장:** semantic identity는 증거가 보이는 순간에 결속하고, 이후에는 추적 상태에서 읽어야 한다.
- **레이더 추론:** 실제 배포에서는 tracker도 오류를 내므로 “영상을 보지 말라”는 고정 규칙보다 두 신호의 충돌을 감지하고 재검증하는 정책이 필요하다.

직접 근거: [Ask About the Right Moment arXiv](https://arxiv.org/abs/2610.31471) · [HTML 원문](https://arxiv.org/html/2610.31471) · [AgentVQA](https://arxiv.org/abs/2610.31494)

### Gap

기존 방법은 tracking state가 맞다고 가정해 readout에서 원영상을 차단한다. tracker 오류와 VLM 재해석 오류를 함께 넣고, 어느 신호를 신뢰해야 하는지 평가하는 controlled conflict benchmark는 없다.

### Hypothesis

tracker confidence, ID-switch detector, evidence-moment visibility를 결합한 arbitration은 clean tracking에서는 text-state readout을 유지하고, 의심 구간에서만 국소 video recheck를 호출해 두 오류원을 동시에 줄인다.

### Experimental Design

1. 셸 게임과 해양 crossing clip 각각 50개를 준비한다.
2. tracker state에 ID swap, 누락, 좌표 jitter를 통제된 비율로 주입한다.
3. video-only, state-only, fixed recheck, uncertainty-gated recheck를 비교한다.
4. recheck는 전체 영상을 다시 넣지 않고 충돌 전후 3~5 frame crop만 사용한다.
5. confidence calibration과 비용을 별도 측정한다.

### Baseline·Metric·GO/KILL

- Metric: identity accuracy, ID-switch recovery, clean-state regression, expected calibration error, recheck rate, latency.
- **GO:** 10% injected swap에서 state-only 대비 accuracy +10%p, clean tracking 성능 하락≤2%p, recheck rate≤30%.
- **KILL:** gate가 tracker confidence만 복제하거나, 원영상 재검증이 정확한 상태까지 자주 뒤집어 clean regression>5%p.

### Expected Contribution

Video-LM과 tracker를 단순 결합하는 대신, 두 모듈의 모순을 명시적으로 다루는 state-trust protocol과 오류 주입 benchmark를 제안한다. 해양 선박·부표의 장기 identity 유지로 바로 확장할 수 있다.

### Risk·Compute·논문화

- Risk: 합성 ID swap이 실제 tracker 오류와 다를 수 있다. 실제 실패 로그 subset을 반드시 포함해야 한다.
- Compute 난이도: **2/5**. frozen tracker와 저장된 VLM 응답으로 대부분 평가 가능하다.
- 4~8주 논문화 가능성: **5/5**. 진단 benchmark와 간단한 gate만으로 명확한 논문 구조가 된다.
- Negative result 가치: arbitration이 실패하면 VLM readout보다 tracker 신뢰도 모델링 또는 multi-object representation이 우선 병목임을 보여준다.

**평가:** 새로움 5/5 · 실행 가능성 5/5 · 계산 효율 4/5 · 논문화 가능성 5/5

## Q3. Object-level radar metric anchor는 해양 tiny target 거리 추정에서 calibration shift를 견디는가?

### Research Question

원거리 선박·부표의 monocular depth를 radar range로 object 단위 보정하면 scene-level 보정보다 거리·3D track 오차를 줄일 수 있는가? 해면 반사, 수직 외부보정 오차, 부분 가림을 uncertainty로 모델링하면 잘못된 anchor를 거부할 수 있는가?

### Observation

- **확인된 사실:** WildDepth-v2는 37개 RGB–LiDAR–4D radar sequence와 19,716개 동기 frame을 추가했다.
- **확인된 사실:** 48,723 animal frame에서 object-level radar range로 monocular depth를 보정한 AbsRel은 0.120으로 scene-level LiDAR calibration의 0.198보다 낮았다. animal 위 LiDAR를 inference에 쓰면 0.052로 더 정확했다.
- **확인된 사실:** 431개 track에서 track당 한 번 radar로 scale을 맞추면 3D position error가 2.20m에서 0.58m로 감소했다.
- **저자 주장:** radar는 sparse하지만 값싼 metric anchor와 motion cue가 될 수 있다.
- **레이더 추론:** 야생동물과 해양 target은 모두 작은 원거리 객체지만, 물 표면 multipath와 표적 재질은 다르다. 직접 전이를 주장할 수 없고 reject option을 포함한 검증이 필요하다.

직접 근거: [WildDepth-v2 arXiv](https://arxiv.org/abs/2610.31123) · [HTML 원문](https://arxiv.org/html/2610.31123)

### Gap

해양 monocular distance 연구는 camera calibration이나 horizon prior에 의존하는 경우가 많고, radar anchor의 품질·연결 오류·불확실성을 object track 수준에서 공개적으로 평가하는 protocol이 부족하다.

### Hypothesis

track-level median radar range와 calibration uncertainty를 함께 쓰면 single-frame anchor보다 outlier에 강하며, uncertainty-gated rejection이 잘못된 radar association으로 인한 catastrophic distance error를 줄인다.

### Experimental Design

1. radar와 RGB가 동기화된 항만 clip 20개에서 선박·부표 track 100개를 주석한다.
2. monocular depth, horizon calibration, single-frame radar anchor, track-median radar anchor, uncertainty-gated anchor를 비교한다.
3. 거리 0–50m, 50–100m, 100m 이상과 clear/fog, calm/wave 조건으로 층화한다.
4. extrinsic pitch·height와 radar association에 통제된 perturbation을 넣는다.
5. LiDAR 또는 측량 가능한 기준 target으로 일부 거리 GT를 확보한다.

### Baseline·Metric·GO/KILL

- Metric: AbsRel, RMSE(m), 3D track error, catastrophic error rate(상대오차>50%), anchor rejection AUROC, distance-bin calibration.
- **GO:** monocular 대비 모든 거리 bin에서 AbsRel 감소, catastrophic error 30% 이상 상대 감소, 정상 anchor 유지율≥80%.
- **KILL:** fog/wave 조건에서 radar association 오류가 이득을 상쇄하거나, GT가 부족해 95% CI가 baseline과 겹침.

### Expected Contribution

RGB–radar 융합의 평균 성능보다 “어떤 anchor를 믿을 수 있는가”를 밝히고, 해양 small-object 거리 추정의 sensor-error budget과 거부 규칙을 제안한다.

### Risk·Compute·논문화

- Risk: 동기화 RGB–radar 데이터 확보와 거리 GT가 가장 큰 병목이다.
- Compute 난이도: **3/5**. 학습보다 sensor alignment와 주석 비용이 크다.
- 4~8주 논문화 가능성: **3/5**. 기존 항만 센서가 있으면 가능하지만 새 수집이 필요하면 지연된다.
- Negative result 가치: object-level radar anchor가 해양에서 실패하면 물 표면 multipath와 association error의 정량적 operating envelope가 기여가 된다.

**평가:** 새로움 4/5 · 실행 가능성 3/5 · 계산 효율 4/5 · 논문화 가능성 4/5

## Q4. 정적 정확도 없이도 architecture의 프레임 스킵 취약성을 예측할 수 있는가?

### Research Question

CNN, pyramid Transformer, global-attention Transformer의 intermediate feature drift, effective receptive field, motion-alignment sensitivity를 짧은 calibration clip에서 측정하면 K-frame skipping 시 Dice/IoU 손실을 사전에 예측할 수 있는가?

### Observation

- **확인된 사실:** Lightweight Frame Compensation 연구는 K=3에서 Polyp-PVT의 세 데이터셋 Dice가 6.51~8.37%p 하락하고, ResNet-UNet은 4.20~11.84%p, TransUNet은 확인된 두 데이터셋에서 6.27%p와 9.00%p 하락했다고 보고했다.
- **확인된 사실:** 약 77K parameter의 보상 모듈은 2.05×~2.55× throughput gain을 유지하면서 여러 설정에서 손실 대부분을 회복했다.
- **저자 주장:** 전역 attention 모델은 높은 정적 정확도를 보이지만 misaligned input을 넓게 집계해 프레임 스킵에 더 민감할 수 있다.
- **레이더 추론:** 배포 전에 전체 video benchmark를 돌리지 않고도 feature-level probe로 취약 모델과 적절한 K를 고를 수 있다면 architecture 비교가 더 실용적이 된다.

직접 근거: [LFC arXiv](https://arxiv.org/abs/2610.31228) · [HTML 원문](https://arxiv.org/html/2610.31228)

### Gap

현재 결과는 특정 세 backbone과 K=3에서 나온 사후 설명이다. temporal feature drift가 실제 손실을 예측하는지, 정적 Dice·parameter 수·FLOPs보다 설명력이 높은지는 검증되지 않았다.

### Hypothesis

optical-flow로 정렬한 연속 frame의 layer-wise feature drift와 ERF spread를 함께 쓰면 모델별 skip loss를 예측할 수 있고, drift가 큰 layer 앞에만 경량 보상을 넣는 것이 입력 보상보다 효율적이다.

### Experimental Design

1. CNN 2개, pyramid Transformer 2개, global-attention model 2개를 frozen 상태로 준비한다.
2. 100개 짧은 clip에서 K=1/2/3/4의 segmentation loss와 layer-wise drift를 측정한다.
3. predictor는 정적 Dice, FLOPs, ERF, aligned feature drift를 입력으로 한 선형 또는 tree model로 제한한다.
4. leave-one-architecture-family-out으로 skip loss 예측을 평가한다.
5. 가장 예측력이 높은 layer에만 작은 compensation adapter를 붙이는 ablation을 한다.

### Baseline·Metric·GO/KILL

- Metric: skip-loss prediction R²/MAE, rank correlation, Dice/IoU, temporal jitter, FPS, adapter parameter.
- **GO:** unseen architecture family에서 loss-rank ρ≥0.7, MAE≤2%p, 선택적 adapter가 원 손실 60% 이상 회복하며 speedup≥2×.
- **KILL:** predictor가 정적 Dice만 못하거나 dataset 이동에서 rank가 뒤집힘.

### Expected Contribution

“CNN 대 Transformer”의 평균 성능 논쟁을 temporal deployment sensitivity라는 측정 가능한 축으로 바꾸고, 모델 선택과 보상 위치를 연결하는 저비용 진단 probe를 제안한다.

### Risk·Compute·논문화

- Risk: pseudo-label과 데이터별 motion 분포가 architecture 효과처럼 보일 수 있다. 동일 영상·동일 preprocessing이 필수다.
- Compute 난이도: **3/5**. 6개 frozen model inference가 필요하지만 대규모 학습은 없다.
- 4~8주 논문화 가능성: **4/5**. prediction이 가족 외삽에서 유지되면 architecture analysis 논문으로 강하다.
- Negative result 가치: 공통 predictor가 실패하면 skip robustness가 architecture label이 아니라 task·motion·training recipe 상호작용임을 밝힌다.

**평가:** 새로움 5/5 · 실행 가능성 4/5 · 계산 효율 4/5 · 논문화 가능성 5/5

## Q5. 해무·주야·항적의 다봉 정상 분포를 보존하면 이상 탐지의 희귀 정상 오탐을 줄일 수 있는가?

### Research Question

해양 CCTV의 정상 상태를 하나의 feature bank로 합치지 않고 위치·시간·기상 조건부 normality로 모델링하면, 드문 정상 선박·반사·짙은 해무를 이상으로 오인하는 비율을 줄이면서 실제 위험 물체의 recall을 유지할 수 있는가?

### Observation

- **확인된 사실:** LACToS는 산업 이상 탐지 방식이 정상 분포가 다봉인 의료 CT, 얼굴, X-ray에서 크게 흔들릴 수 있다고 보고한다.
- **확인된 사실:** FFHQ에서 PatchCore의 AUROC/AP/AUPRO는 0.8491/0.0798/0.4094, LACToS는 0.8515/0.1177/0.5320이었다. DVXray에서는 PatchCore AUROC 0.9640이 LACToS 0.9607보다 높았지만 AP와 AUPRO는 LACToS가 소폭 높았다.
- **확인된 사실:** 공식 저장소는 코드, 환경, 7.5GB 자산, 기준 score map과 Table 1 재생성 스크립트를 제공한다.
- **저자 주장:** pixel이 주변 문맥과 조건부로 얼마나 typical한지 평가하면 복잡한 inlier variation을 더 잘 다룰 수 있다.
- **레이더 추론:** 해양 정상 분포는 clear/fog, day/night, wake, glare, berth별 배경이 섞여 있어 industrial single-mode 가정이 특히 위험하다.

직접 근거: [LACToS arXiv](https://arxiv.org/abs/2610.31538) · [HTML 원문](https://arxiv.org/html/2610.31538) · [공식 코드·재현 자산](https://github.com/voilalab/LACToS)

### Gap

이상 탐지 연구는 전체 AUROC/AP를 주로 보고하며, 희귀하지만 정상인 하위집단의 false-positive rate와 위험 anomaly recall을 동시에 제한하는 평가는 부족하다.

### Hypothesis

시간대·기상·공간 위치를 조건으로 한 local typicality는 pooled PatchCore보다 rare-normal FPR을 낮춘다. 다만 정상 학습에 위험 물체와 유사한 패턴이 섞이면 false negative가 늘므로 contamination sensitivity를 함께 측정해야 한다.

### Experimental Design

1. 정상 해양 frame 500장을 clear/fog, day/night, glare/wake, camera zone으로 층화한다.
2. 위험 anomaly 100장과 rare-normal 100장을 별도 test로 만든다.
3. PatchCore, condition-specific PatchCore, DDAD, LACToS-style local typicality를 비교한다.
4. 정상 학습 세트에 anomaly-like pattern을 0/1/5% 섞는 contamination ablation을 한다.
5. 평균 metric 외에 하위집단별 threshold와 worst-group 결과를 보고한다.

### Baseline·Metric·GO/KILL

- Metric: pixel AP/AUPRO, image AUROC, rare-normal subgroup FPR, anomaly recall@fixed-FPR, contamination slope, latency.
- **GO:** worst subgroup FPR 30% 이상 상대 감소, 위험 anomaly recall 하락≤2%p, 1% contamination에서도 성능 유지.
- **KILL:** 조건 분할이 표본 부족으로 overfit하거나, rare-normal FPR 감소가 anomaly recall 5%p 이상 손실과 교환됨.

### Expected Contribution

평균 AUROC 중심의 이상 탐지를 배포 관점의 `rare-normal safety` 문제로 재정의하고, 다봉 정상 분포에서 하위집단 오탐과 오염 민감도를 함께 평가하는 protocol을 제안한다.

### Risk·Compute·논문화

- Risk: rare-normal과 anomaly 정의가 주관적일 수 있다. 두 명 이상 주석과 운영 기준이 필요하다.
- Compute 난이도: **3/5**. PatchCore는 가볍지만 diffusion posterior sampling은 비용이 크다.
- 4~8주 논문화 가능성: **4/5**. 데이터 층화가 완료되면 진단 결과만으로도 현장 가치가 있다.
- Negative result 가치: 조건부 모델이 이득이 없으면 feature extractor가 이미 normal modes를 분리하거나, 오류가 threshold calibration에서 생긴다는 근거가 된다.

**평가:** 새로움 4/5 · 실행 가능성 4/5 · 계산 효율 3/5 · 논문화 가능성 4/5

## 오늘의 우선순위

| 순위 | 질문 | 이유 | 첫 1주 실험 |
|---|---|---|---|
| 1 | Q2 상태 충돌 arbitration | 사용자 관심인 video memory·temporal reasoning에 직접 연결되고 데이터 규모가 작다 | 셸/해양 각 20 clip에 ID swap 주입 |
| 2 | Q4 skip 취약성 예측 | CNN/ViT inductive bias를 배포 실패와 연결한다 | 3개 frozen backbone, K=1/3 probe |
| 3 | Q1 offline→online surrogate | 에이전트 평가 비용을 직접 줄일 수 있다 | 3모델×30 episode calibration |
| 4 | Q5 다봉 정상성 | 해무 CCTV의 희귀 정상 오탐에 직접 연결된다 | 정상 200장 subgroup audit |
| 5 | Q3 radar metric anchor | 잠재 기여는 크지만 센서·GT 확보가 병목이다 | 기존 동기 clip의 calibration audit |

## 공통 실행 원칙

1. 첫 주에는 모델을 새로 학습하지 않고 frozen model과 오류 주입으로 가설의 방향을 확인한다.
2. 평균 성능과 함께 worst-group, calibration, 비용, 실패율을 보고한다.
3. 같은 모델·입력·prompt·sampling budget을 고정해 비교한다. 조건이 다르면 `not strictly apples-to-apples`로 표시한다.
4. GO/KILL 기준은 결과를 본 뒤 바꾸지 않는다.
5. 직접 재현 전까지 논문 수치는 저자 보고로 표기한다.
