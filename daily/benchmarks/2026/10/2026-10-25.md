## 1. AgentVQA — 온라인 에이전트 평가의 오프라인 선별기

### 확인된 사실

- 23개 원천 데이터셋에서 수작업으로 선별한 1,000개 객관식 문항이며 Web Agents, Egocentric Videos, Robotics, Games, Spatial Planning의 5개 영역을 포함한다.
- 22개 VLM 중 최고 정확도는 58.5%였다. 영역별 최고 수준의 평균 성능은 Egocentric Videos 59%, Games 51.5%, Spatial Planning 46%, Robotics 38%, Web Agents 29%로 보고됐다.
- Web Agents에서 action history를 제거하면 5개 모델 평균 성능이 AitW에서 9.5%, MONDAY에서 10% 감소했다.
- 12개 공통 모델에서 AgentVQA Spatial Planning과 온라인 SpatialWorld Physical track의 순위 상관은 Spearman ρ=0.895였다. 반면 일반 벤치마크와의 순위 상관은 MMMU-Pro 0.67, GPQA-Diamond 0.59, ChartQA-Pro 0.44였다.

### 저자 주장

저자들은 영역이 맞는 경우 AgentVQA가 반복 rollout과 환경 설치가 필요한 온라인 평가의 저비용 보완재가 될 수 있다고 주장한다. 동시에 다른 영역의 낮은 상관은 하나의 오프라인 점수를 범용 agent capability로 해석하면 안 된다는 근거로 제시한다.

### 진단과 가설

- **진단:** 일반 VQA 점수는 UI grounding, 상태 변화 추적, 3D 공간 상태 구성 같은 에이전트 실패를 충분히 예측하지 못한다.
- **가설:** 배포 영역과 대응하는 AgentVQA 하위 점수는 전체 평균보다 실제 온라인 성공률의 모델 순위를 더 안정적으로 예측한다.
- **추론:** ρ=0.895는 12개 모델과 한 대응 영역에서 나온 결과다. 새로운 모델군이나 다른 온라인 환경에 그대로 일반화된다고 볼 수 없다.

### 최소 실험

후보 모델 4개를 골라 AgentVQA Spatial Planning 100문항과 작은 폐루프 환경 50 episode를 같은 prompt 정책으로 실행한다. Spearman 순위 상관, episode당 평가 비용, 오류 유형 일치율을 기록한다. **통과 기준:** 순위 상관 ρ≥0.7이고 오프라인 평가 비용이 온라인의 20% 이하이며, 상위 두 오류 유형이 일치할 것.

## 2. WildFakeToolBench — 웹 유래 편집 도구로 보는 탐지기 취약성

### 확인된 사실

- 142개 도메인의 220개 공개 출처에서 156개 실행 가능한 CPU 이미지 처리 도구를 만들었다. 도구는 10개 처리 범주를 포함하고 출처 근거를 보존한다.
- 평가는 7개 콘텐츠 범주의 21개 prompt를 5개 생성기로 만든 105개 이미지와 6개 탐지기에 대해 수행됐다. 각 도구·이미지 조합에 5개 파라미터 후보를 만들고 SSIM≥0.75인 출력만 유지했다.
- 단일 도구의 최대 ASR은 탐지기별 25.25%에서 100%였다. FakeVLM 45.54%, SIDA-13B 25.25%, FakeShield 46.88%, GPT-5.6-luna 66.67%, CommForensics 95.83%, AIDE 100%였다.
- 8개 도구 후보군의 조합을 탐색한 stacked ASR은 4개 가용 도구에서 FakeVLM 92.08%, SIDA-13B 68.69%, FakeShield 79.69%, GPT-5.6-luna 87.32%, 두 분류기는 100%였다.
- 저자들은 stacked ASR가 서로 다른 이미지마다 다른 부분집합을 허용하는 oracle worst-case coverage이며, one-shot 성공률이나 실제 도구 선택 정책을 뜻하지 않는다고 명시했다. 모든 도구를 순차 적용하면 더 긴 체인이 오히려 성능을 낮출 수 있었다.

### 저자 주장

저자들은 공개 웹 지식을 LLM으로 실행 가능한 처리 도구로 변환하는 것만으로도 기존 학술 baseline보다 강한 스트레스 테스트가 가능하며, detector별 취약성이 희소하고 다르다고 주장한다.

### 진단과 가설

- **진단:** 고정된 JPEG 압축·blur 같은 소수 변환은 실제 웹 편집 생태계의 조합 공간을 과소평가한다.
- **가설:** 탐지기 학습에 detector-specific 단일 공격보다 출처와 메커니즘을 층화한 도구 묶음을 넣으면 미지 도구에 대한 worst-group 성능이 더 좋아진다.
- **추론:** 105개로 구성된 선별 이미지 집합은 분포 대표성이 제한적이다. ASR 절대값보다 “어떤 처리 범주가 어느 탐지기에 반복적으로 실패를 만드는가”가 더 이식 가능한 신호다.

### 최소 실험

자체 탐지기와 공개 탐지기 1개를 대상으로 원본 200장, 학술 baseline 6종, 웹 유래 도구 20종을 평가한다. 도구는 범주별 2개씩 고정하고 parameter search 없이 1회 적용한다. AUROC, TPR@1%FPR, perceptual-quality 통과율, 범주별 최악 성능을 보고한다. **통과 기준:** 웹 유래 도구의 worst-group TPR이 학술 baseline 대비 10%p 이상 낮고, 동일 취약 범주가 두 탐지기에서 재현될 것.

- 공식 원문: https://arxiv.org/abs/2610.31152

## 3. WildDepth-v2 — 야생동물 비전을 거리·속도·3D 궤적으로 평가

### 확인된 사실

- 새 Longleat radar subset은 RGB·LiDAR·radar가 모두 있는 37개 sequence, 19,716 frame을 포함한다. 전체 radar frame은 22,348개다.
- T1 animal distance, T2 depth completion, T3 radar metric scale, T4 motion segmentation, T5 metric 3D tracking의 5개 과제를 정의했다. T1·T2는 미공개 영상으로 만든 체크섬 고정 hidden test를 사용한다.
- T1 hidden test는 13 scene, 352 frame, 510 animal detection이다. MoGe-2가 LC AbsRel 0.094, RMSE 3.25m, δ<1.25 0.97로 가장 강한 공개 baseline이었다.
- T2는 902 frame이다. 동물 영역 RMSE는 nearest-neighbour fill 6.10m, MoGe-2 scale-shift 5.33m였고 배경 RMSE는 각각 4.51m, 4.52m였다.
- radar range로 monocular depth를 보정했을 때 20,869개 test animal frame에서 AbsRel 0.120으로, scene-level LiDAR calibration 0.198보다 낮았다. track당 한 번 radar로 scale을 맞춘 3D 위치 오차는 0.58m, LiDAR는 0.52m였다.
- hidden set은 공개 frame과 최소 301 frame 떨어져 있지만 session-disjoint가 아니며, 48%가 공개 snippet과 1분 이내다. 저자도 이를 in-domain 평가로 한정한다.

### 저자 주장

저자들은 radar가 값싼 metric anchor와 motion sensor가 될 수 있고, 야생동물 데이터에서도 거리·속도·tracking의 계측 평가를 가능하게 한다고 주장한다. 동시에 radar의 수직 외부보정 잔차, vegetation 투과 실패, Doppler 속도 과소측정 등 부정 결과를 운용 한계로 공개했다.

### 진단과 가설

- **진단:** RGB-only wildlife benchmark는 탐지·분류가 맞아도 생태학적 의사결정에 필요한 거리와 속도가 틀릴 수 있다.
- **가설:** 전체 scene을 보정하는 방식보다 animal mask 안의 radar anchor를 쓰는 방식이 원거리·부분 가림 조건에서 metric error를 안정적으로 줄인다.
- **추론:** in-domain hidden test는 leakage를 줄이지만 site/session 일반화를 검증하지 않는다. 성능 표에는 거리 구간과 session 단위 bootstrap이 필수다.

### 최소 실험

공개 Longleat sequence 중 개발/시험 sequence를 분리해 RGB-only, scene-LiDAR calibration, animal-radar calibration 세 조건을 비교한다. 10–20m, 20–30m, 30–50m 구간별 AbsRel·RMSE와 track position error를 측정한다. **통과 기준:** radar 조건이 RGB-only 대비 모든 거리 구간에서 AbsRel을 낮추고, 30–50m 구간 개선이 bootstrap 95% CI에서 0을 넘지 않을 것.

## 4. OmniDR-Bench — 동영상 중심 장문 연구 보고서 평가

### 확인된 사실

- 중국어·영어 50개 task, 19개 실제 하위 범주, 6,414개 원자 기준으로 구성된다. 한 source video를 중심으로 외부 text·image·video evidence를 연결한 보고서를 요구한다.
- Omni-ART는 content, citation, presentation의 3개 상위 차원과 23개 공통 진단 방향, task-specific binary criteria로 구성된다.
- 18개 agent configuration 중 최고 점수는 63.3/100이었다. 전체적으로 presentation 평균은 81.8이지만 content와 citation은 45.4, 47.8에 그쳤다.
- 생성 보고서 30개를 3명이 평가한 검증에서 인간 간 일치율은 93.0%, 자동 채점과 인간 다수결 일치율은 91.0%였다. Omni-ART와 holistic rating의 Spearman 상관은 ρ=0.64였다.
- 공식 코드와 데이터가 공개됐다.

### 저자 주장

저자들은 동영상 deep research를 짧은 QA가 아니라 출처 영상의 시청각·시간 근거와 외부 자료를 함께 추적할 수 있는 보고서 생성 문제로 재정의하며, 원자 기준이 오류 위치를 더 잘 드러낸다고 주장한다.

### 진단과 가설

- **진단:** 장문 에이전트는 보기 좋은 보고서를 만들 수 있어도 핵심 내용 범위와 인용 지지가 약하다. 단일 총점은 이 격차를 숨긴다.
- **가설:** 생성 중 “주장-영상 시점-외부 출처” 표를 강제하면 presentation을 해치지 않고 citation과 content 점수를 동시에 올릴 수 있다.
- **추론:** 자동 채점과 인간 일치율이 높아도 holistic 상관 0.64는 중간 수준이다. 작은 점수 차이로 시스템 순위를 확정하기보다 방향별 신뢰구간을 봐야 한다.

### 최소 실험

5개 task에 동일 모델·동일 검색 budget을 쓰고 기본 workflow와 claim-evidence table workflow를 각각 3회 실행한다. content, citation, presentation, unsupported-claim 수, 영상 timestamp 정확도, 총 비용을 비교한다. **통과 기준:** citation과 content가 각각 5점 이상 상승하고 unsupported claim이 25% 이상 감소하며 비용 증가는 20% 이내일 것.

## 5. RetinaGroundBench — 임상 답변과 시각 근거를 분리 평가

### 확인된 사실

- 안과 전문의가 815개 retinal OCT B-scan에 8개 질환, 13개 biomarker, 4,537개 bounding box를 주석했다. 두 명의 junior ophthalmologist가 나눠 주석하고 senior retina specialist가 전부 검토·수정·승인했다.
- 0.8B–38B의 open-weight MLLM 27개를 평가했다. 일반 모델 최고 grounding macro F1은 InternVL3.5-30B-A3B의 23.7%(precision 47.9%, recall 16.5%)였다.
- OCT 특화 RetGrounder 8B는 macro F1 33.9%(precision 48.0%, recall 27.5%)로 일반 모델 최고보다 상대 43% 개선됐다.
- 반면 biomarker 존재 여부 VQA의 balanced accuracy는 최고 약 73%까지 올라갔다. 즉 텍스트 판정과 위치 근거 사이에 큰 격차가 있었다.
- AggIoU는 한 병변을 여러 작은 box로 나누는 MLLM 출력에 맞춰, 겹치는 prediction의 기하학적 합집합과 GT의 IoU를 계산한다. RetGrounder도 macular hole에서만 AggIoU 55.0%로 50%를 넘었고 hard exudates 7.1%, epiretinal membrane 11.6%는 낮았다.

### 저자 주장

저자들은 임상 신뢰성을 위해 병변 존재 답변만으로는 부족하며, 모델이 실제 병리 위치를 가리키는지를 별도 평가해야 한다고 주장한다. 또한 공개 가중치와 단일 GPU 운용 가능성을 환자 데이터의 로컬 처리와 재현성 조건으로 삼았다.

### 진단과 가설

- **진단:** VQA balanced accuracy가 높아져도 spatial grounding recall이 낮으면 임상의가 모델 근거를 확인할 수 없다.
- **가설:** biomarker classification과 grounding을 함께 학습하되 작은 병변을 과대표집하면 전체 F1보다 hard-class recall과 AggIoU가 더 크게 개선된다.
- **추론:** box 경계의 관찰자 간 차이가 AggIoU의 상한을 낮출 수 있다. 모델 개선과 annotation ambiguity를 분리하려면 일부 표본에 이중 독립 주석 또는 segmentation mask가 필요하다.

### 최소 실험

공개 평가 표본에서 일반 8B 모델과 OCT 특화 모델을 비교하되, 흔한 IRF/SRF와 작은 병변 hyperreflective foci/hard exudates를 각각 50개 양성 사례로 층화한다. VQA BAcc, grounding recall/F1, AggIoU, box area ratio를 함께 기록한다. **통과 기준:** 특화 모델이 두 어려운 class 모두에서 recall을 10%p 이상 높이고 AggIoU도 상승하며 VQA BAcc 하락이 2%p 이내일 것.

## 오늘의 benchmark signal 3개

1. **대리평가에는 영역 일치 검증이 필요하다.** AgentVQA의 높은 온라인 상관은 대응 Spatial Planning에서 나왔고, 다른 영역 상관은 낮았다. “offline이 online을 대체한다”가 아니라 “어떤 offline slice가 어떤 online outcome을 예측하는가”를 검증해야 한다.
2. **평균 점수보다 운용 조건의 실패면이 중요해졌다.** 웹 편집 도구, 원거리 동물, 장문 인용, 작은 OCT 병변은 기존 평균에서 가려지던 실패를 드러낸다. worst-group, 거리 구간, citation support, hard-class recall이 공통 보조 지표다.
3. **새 지표는 출력 형식의 실제 오류를 반영한다.** stacked ASR는 oracle임을 밝혀야 하고, AggIoU는 분절된 box를 합치며, Omni-ART는 보고서를 원자 기준으로 분해한다. 지표 값만 비교하기 전에 그 지표가 허용하는 선택권과 매칭 규칙을 고정해야 한다.

## 내 연구에 바로 연결되는 포인트

- VLM 또는 agent 평가 파이프라인에는 **일반 능력 점수 + 목표 도메인 slice + 작은 online 확인 실험**의 3단계를 적용한다.
- 해무·저시정·원거리 CV에서는 전체 평균과 함께 거리·가시도·객체 크기별 worst-group를 보고하고, sensor calibration error를 모델 error와 분리한다.
- 보고서 생성 에이전트는 claim 단위로 source URL, 영상 timestamp, 근거 유형을 구조화해 citation recall을 측정한다.
- 의료·산업 검사처럼 설명 가능성이 중요한 과제는 classification 성능과 localization recall/AggIoU를 분리해 배포 gate를 둔다.

## 검증 메모

- 모든 수치는 2026-10-25 확인한 저자 공식 arXiv 원문에서 옮겼다. 논문의 실험 결과는 독립 재현된 사실이 아니라 **저자 보고 수치**다.
- AgentVQA의 온라인 상관, OmniDR의 자동 채점 일치도, RetinaGroundBench의 임상 주석 품질은 각 논문 내부 검증이며 외부 재현을 기다려야 한다.
- WildFakeToolBench의 stacked ASR는 one-shot 공격 성공률이 아니고, WildDepth-v2 hidden test는 cross-site 일반화 시험이 아니다.
- 공개 코드 링크가 확인된 WildFakeToolBench와 OmniDR-Bench는 저장소를 교차 확인했다. 나머지는 공식 arXiv 원문을 기준으로 삼았다.
