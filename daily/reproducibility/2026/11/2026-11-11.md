## 핵심 사례 1 — Grounding DINO position embedding 정수 절단은 main에 병합

- **확인된 사실:** Transformers PR #49886은 Grounding DINO integration test 8개가 `output_mismatch`로 실패한 것을 다루며 2026-11-10에 `main`으로 병합됐다. PR 설명은 `text_position_ids`가 `int64`인 채 sinusoidal embedding 마지막 cast에 전달되어 값이 정수화되는 경로를 지목한다.
- **재현 조건/관찰된 gap:** PR 기록상 `test_cross_attention_mask`는 patch 전 single-GPU에서 21/21회 mismatch였고, 최대 absolute/relative 차이는 각각 2.36/0.96이었다. patch 전/후 targeted slow tests를 GPU runner에서 각각 5회 실행했다는 것은 PR 작성자의 검증 기록이다.
- **가능 mechanism:** text position id의 dtype이 embedding dtype과 다르면 sinusoidal 값이 int64로 잘리며 text feature가 거의 0이 되어 cross-attention output이 바뀐다.
- **한계:** PR 자체가 자동 생성 도구로 제안된 뒤 병합된 것이며, release tag에서 사용 가능한지와 모든 Grounding DINO checkpoint/processor 조합의 benchmark 효과는 확인하지 않았다.
- **반증 가능한 최소 실험:** 동일 image·prompt·checkpoint에서 병합 전/후를 비교하고 `text_position_ids.dtype`, position embedding nonzero ratio, logits max-diff, boxes/phrase score를 함께 저장한다.
- **GO/KILL:** fixed integration fixture가 병합 후 reference tolerance를 통과하면 GO한다. dtype이 이미 float인데 score drift가 남으면 이 patch만을 원인으로 삼지 않고 tokenizer·processor branch를 분리 조사한다(KILL: 단일 dtype fix로 모든 mismatch를 설명한다는 주장).

## 핵심 사례 2 — cache 뒤 새 image/video를 넣는 VLM generation path

- **확인된 사실:** PR #50427은 Qwen2-VL source와 이 method를 상속하는 14개 모델에서, cache를 가진 다음 `generate()` call에 새 image/video token이 오면 과거 text-only `rope_deltas`를 재사용해 새 3D position을 생략하던 경로를 수정했고 2026-11-10에 병합됐다.
- **재현 조건/검증:** PR은 cached text prefix → image, cached image prefix → new image/video, left padding, full/suffix-only input IDs, precomputed vision feature를 full-history reference와 position/delta/logits/generated token으로 비교한다. 작성자는 Qwen2/2.5/3-VL 및 Ernie4.5-VL suites에서 631 tests와 5,668 subtests pass(561 skip, 9 xpass)를 보고했다.
- **가능 mechanism:** cache state의 `rope_deltas`는 이전 call의 modality layout만 반영한다. 새 vision token이 들어온 continuation에 이를 그대로 적용하면 multimodal absolute/relative position이 full-history run과 달라진다.
- **한계:** merged source 변경은 확인했지만, 특정 published package release로의 포함 여부와 실제 long-video QA/grounding metric 변화는 원문에 제시되지 않았다.
- **반증 가능한 최소 실험:** 고정 text prefix에 서로 다른 resolution의 image 또는 video를 뒤이어 넣고, cache reuse와 full-history 두 경로의 position ids, logits, decoded token, vision grounding score를 비교한다.
- **GO/KILL:** full-history parity와 decoded-token parity가 유지되면 cache reuse를 GO한다. parity failure가 남으면 cache transition이 있는 result를 standard single-call result와 합쳐 benchmark claim을 내는 것을 KILL한다.

## 핵심 사례 3 — Step-3.7 Vision RoPE W/H channel order: 수정안은 있으나 미병합

- **확인된 사실:** issue #50492는 Transformers 5.17.0, Python 3.12.3, PyTorch 2.11 CUDA/H20 환경 정보를 제공하지만 핵심 parity reproduction은 weights 없이 CPU에서 수행한다. 동일 synthetic FP32 Q/K, head dimension 96, 2×3 grid에서 original StepFun과 Megatron-Bridge는 bitwise equal이고 HF implementation은 W/H swap 전 불일치한다고 보고한다.
- **관찰된 gap:** 이슈의 minimal assertion에서 HF sine vector는 `[0.0, 0.8414709568, 0.0, 0.8414709568]`, original channel permutation 후 기대값은 `[0.8414709568, 0.0, 0.8414709568, 0.0]`으로 제시된다. 이는 full-checkpoint quality 평가가 아니라 class-level parity다.
- **후속 상태:** PR #50547은 spatial band swap patch와 regression을 제시하며 CPU 152 pass/157 skip, CUDA 159 pass/150 skip을 작성자가 보고했지만 아직 open이다.
- **가능 mechanism:** shared position id는 H/W 순서인데 Step-3.7 checkpoint의 converted Q/K layout은 contiguous W/H frequency band를 기대해, flatten 과정에서 spatial channel band가 뒤바뀐다.
- **반증 가능한 최소 실험:** non-square grid와 non-diagonal coordinate에서 original encoder/Bridge/HF/PR branch의 sin/cos, post-RoPE Q/K, image-conditioned logits를 한 fixture로 비교한다.
- **GO/KILL:** PR 병합과 official checkpoint fixture parity가 확인될 때만 update를 GO한다. class-level sine parity만으로 downstream accuracy가 개선됐다고 말하는 것은 KILL한다.

## 핵심 사례 4 — BatchNorm momentum convention이 작은 마지막 batch에 민감

- **커뮤니티 재현:** contributor가 연 issue #50473은 Transformers main `a6f5c8676b`, torch 2.15에서 EfficientNet/ALIGN/MobileNetV1/V2가 Keras식 momentum(0.99, 0.9997, 0.997 등)을 PyTorch `nn.BatchNorm2d(momentum=...)`에 그대로 전달한다고 보고한다.
- **재현 조건/관찰된 gap:** 200개의 normal batch 뒤 average가 shift된 크기 3 마지막 batch를 넣는 script에서, MobileNetV2 running mean은 earlier batches 평균과의 max difference 0.387, 마지막 batch와는 0.001; EfficientNet-B0은 각각 0.465와 0.005라고 보고됐다. 작성자의 CIFAR-10 96px, AdamW 5e-4, batch 32, 1 epoch, 3-seed / 2,000 test image 결과는 training image 수 1,984(마지막 32) 대 1,987(마지막 3)에서 MobileNetV2 71.6% 대 42.8%, EfficientNet-B0 76.9% 대 57.4%였다.
- **가능 mechanism:** Keras의 momentum은 old running average 비중, PyTorch의 momentum은 new batch 비중이다. 값을 그대로 쓰면 마지막 batch가 running stats 대부분을 덮는다.
- **한계:** 숫자는 issue author의 fine-tuning 결과이며 maintainer는 아직 Keras convention 보존(`1-m`)과 PyTorch conventional value 중 정책 결정을 하지 않았다. 수정 PR/릴리스는 확인되지 않았다.
- **반증 가능한 최소 실험:** `drop_last` on/off × final-batch size × current/`1-m` momentum의 2×2×2 run에서 train/eval BN mean/variance, accuracy, seed dispersion을 기록한다.
- **GO/KILL:** running stats가 batch partition에 불변이고 seed range가 baseline 내이면 GO한다. train-mode metric만 개선되고 eval-mode 변동이 남으면 momentum correction의 성능 claim은 KILL한다.

## 진단 → 가설 → 최소 실험

- **관찰:** 병합된 두 수정은 cache transition 또는 dtype state가 바뀔 때만 실패하며, 열려 있는 두 사례도 spatial ordering·BN state처럼 stateful conversion contract를 겨냥한다.
- **가설:** CV/VLM 재현 실패의 큰 일부는 checkpoint weight가 아니라 `input/position/state → output` transition을 artifact로 저장하지 않아 발생한다.
- **최소 실험:** 한 image–prompt fixture에 대해 (a) no-cache/cached continuation, (b) int/float position ids, (c) H/W non-square grid, (d) `drop_last` on/off BN 조건을 분리하고 input ids, position ids, processor config, running stats, logits/boxes/tokens를 versioned JSON/NPZ로 저장한다.
- **성공:** 같은 environment에서 full-history와 continuation의 tolerance·token parity가 유지되고 batch partition이 eval output을 바꾸지 않는다.
- **실패:** state transition 하나라도 fixture checksum을 벗어나면 해당 output은 checkpoint-only 비교표에서 제외하고 runtime/configuration-specific result로 격리한다.
