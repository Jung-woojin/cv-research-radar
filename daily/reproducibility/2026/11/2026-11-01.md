## 1. AVPS-360 — spatial audio·identity association

**[사실]** 저자 원문은 STARSS23 기반 230 recordings(10.5시간, 평균 164초)에 first-order Ambisonics와 synchronized 360° video를 결합하고, source identity·sound-event label과 연결된 31,678 manually reviewed instance mask를 쓴다. public split, code/checkpoint hash, evaluator release는 원문에서 확인되지 않았다.  
출처: https://arxiv.org/abs/2610.40480

**[저자 주장]** 기존 AVIS 방법은 긴 녹화의 intermittent sound production에서 detection과 identity association에 취약하고, spatial-audio baseline이 이를 개선한다.

**[해석]** mono 대 spatial-audio, identity matching threshold, recording-level partition 가운데 하나만 달라도 성능 차이를 모델 기여로 단정하기 어렵다.

**진단 → 가설 → 최소 실험:** 같은 frame/mask·visual backbone에서 mono/spatial audio만 바꾸고 detection, identity association, recording-length subgroup을 기록한다. audio preprocessing, channel ordering, split manifest와 evaluator revision을 함께 저장한다.

## 2. InfantNet — 2D/3D subset·label filtering

**[사실]** 저자 원문은 6–18개월 영아의 108,902 RGB 이미지에 2D keypoint를, 11,642-image curated subset에 SMIL parameters를 포함한 3D pose/shape label을 제공한다고 쓴다. multi-view rendering과 reprojection-error filtering, iterative annotation pipeline을 사용했다고 밝혔지만 public split, training recipe, checkpoint는 확인되지 않았다.  
출처: https://arxiv.org/abs/2610.40467

**[저자 주장]** adult pose estimator는 영아로 잘 일반화되지 않고 InfantNet fine-tuning이 개선을 낸다.

**[해석]** 2D-only/3D subset 비율, age distribution, self-occlusion, filtering threshold가 다르면 fine-tuning 결과의 비교 기준이 달라진다.

**진단 → 가설 → 최소 실험:** 공개 split 후 2D-only/3D subset과 age·occlusion bucket을 고정해 seed 3회로 PCK/MPJPE류 결과와 분산을 기록한다. label filtering threshold와 excluded sample count를 manifest에 넣는다.

## 3. KITScenes Aerial — class·resolution·geographic split

**[사실]** 저자 원문은 synchronized onboard sensors, vehicle poses, Lanelet2 annotations에 aerial imagery와 higher-resolution neural representations를 결합한다. 53 map class 평가와 3-class setting 호환성을 함께 제시하며, resolution·spatial range·geographically disjoint localization 조건을 구분한다. evaluator/code hash와 public split 세부는 확인되지 않았다.  
출처: https://arxiv.org/abs/2610.40455

**[저자 주장]** aerial context는 큰 mapping extent에서 53-class mAP를 두 배 이상 높이고, higher-resolution imagery는 추가 4.3 mAP(+24%)를 낸다.

**[해석]** 53-class/3-class, aerial coverage, spatial range, geography가 동일하지 않으면 mAP를 단일 기준선과 직접 대조할 수 없다.

**진단 → 가설 → 최소 실험:** 같은 geographic split·map extent에서 ground-only/aerial paired run을 실행하고 3-class·53-class per-class metric을 병기한다. imagery timestamp, Lanelet2 version, resampling method를 고정한다.

## 4. PhysCount — group construction·joint answering

**[사실]** 저자 원문은 546 real-world images, 4,595 human-written questions, 651 target-specific groups를 제공하며, relevant appearances, observation mode, same-entity linkage를 주석한다. 40 MLLM 중 strongest model의 complete-group accuracy는 13.36%라고 보고한다. official split, evaluation repository, checkpoint·prompt release는 원문에서 확인되지 않았다.  
출처: https://arxiv.org/abs/2610.40530

**[저자 주장]** visible appearance counting보다 physical entity identity recovery가 어렵고, related question을 jointly answer하면 개선된다.

**[해석]** group unit과 joint-answer prompt policy가 달라지면 single-question accuracy와 complete-group accuracy 사이의 차이를 모델 능력으로만 볼 수 없다.

**진단 → 가설 → 최소 실험:** 동일 image/group에서 independent 대 joint answering만 바꾸고, observation mode·appearances-per-entity별 complete-group accuracy를 비교한다. prompt template, image resolution, group-level partition을 저장한다.

## 결론

이번 창에 공식 재현 실패가 확인된 것은 아니다. 다만 네 연구 모두 재현을 좌우하는 data/modality/evaluator policy를 명시한다. 다음 단계는 release artifact가 확인되는 즉시 environment, split, checkpoint hash, evaluator commit, seed를 고정한 작은 paired audit으로 시작하는 것이다.
