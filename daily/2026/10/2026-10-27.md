### 3.1 SPOOK: Sparse Pixel Optimization for Off-Manifold Knowledge in Vision Encoders

- **상태:** [사실] arXiv:2610.32835 v1은 2026-10-23 제출, 10월 26일 cs.CV 신규 목록에 노출됐다.
- **문제:** 자연 이미지 manifold 밖에서 vision embedding similarity가 사람이 보는 의미와 같은지를 묻는다.
- **방법:** [사실] 빈 캔버스에서 소수 픽셀만 hill-climbing으로 바꾸고, 목표 class prompt 또는 prototype과의 embedding 유사도를 black-box 방식으로 최대화한다.
- **저자 주장:** [저자 주장] OpenCLIP에서는 class prompt targeted retrieval, DINOv3에서는 class prototype alignment가 높은 수준까지 올라간다.
- **핵심 해석:** [분석] encoder가 자연 이미지에서는 유용한 의미 구조를 보여도 입력 공간 전체에서 semantic metric으로 작동한다는 보장은 없다. adversarial robustness보다 더 넓은 **representation validity domain** 문제다.
- **데이터·모델:** [사실] ImageNet, Flickr30k, OpenCLIP, DINOv3를 사용한다.
- **공개성:** 초록 페이지에서 공식 code link는 확인되지 않았다. 설치·재현은 수행하지 않았다.
- **미확인:** 정확한 pixel budget별 성공률, seed variance, 다른 preprocessing·resolution에 대한 민감도는 본 실행에서 검증하지 못했다.
- **의심 지점:** blank canvas가 실제 분포와 너무 멀기 때문에 실사용 위험을 과장할 수 있다. 반대로 간단한 probe만으로 여러 encoder에서 재현된다면 geometry 진단 도구로 가치가 있다.
- **진단→가설→최소 실험:** 해무 분류 encoder가 저시정 입력에서 class-relevant 정보를 유지하는지 확인한다. 같은 pixel budget으로 clean/blank/fog texture에서 목표 class embedding을 최적화하고, top-k retrieval·LPIPS·frequency spectrum·pixel sparsity를 비교한다. **통과 기준:** 자연 의미 변화 없이 목표 rank가 안정적으로 상승하면 off-manifold shortcut 가능성이 높다.
- **Woojin 연결:** representation bottleneck과 readout bottleneck을 나눌 때 “feature가 있다”는 판정을 linear probe 하나에 맡기지 않고, 입력·표현 양쪽에서 최소 개입을 비교할 수 있다.
- **출처:** https://arxiv.org/abs/2610.32835

### 3.2 LoCA: Enabling Multi-Modality in Geospatial Location Encoders

- **상태:** [사실] arXiv:2610.32894 v1, 2026-10-23 제출·10월 26일 신규 노출.
- **문제:** 위도·경도 두 좌표를 고차원 embedding으로 보내는 location encoder가 실제로 고차원 의미 공간을 얼마나 표현할 수 있는가.
- **이론 진단:** [저자 주장] Lipschitz location encoder의 output intrinsic dimension은 architecture나 bandwidth와 관계없이 최대 2이며, contrastive loss의 asymptotic optimum에 도달하지 못한다.
- **실험 진단:** [저자 주장] joint training은 embedding covariance를 low rank로 붕괴시키고, frozen image encoder는 사실상 high-rank target을 제공하는 covariance regularizer처럼 작동한다.
- **방법:** LoCA는 modality를 먼저 co-align한 뒤 high-effective-rank target에 location encoder를 정렬하는 2단계 pipeline을 제안한다.
- **새로움:** architecture block보다 target spectrum과 modality alignment를 병목으로 본 점이 중요하다.
- **일반화 위험:** [분석] 지역·계절·sensor가 다른 EO modality를 co-align하면 semantic overlap보다 dataset geography를 정렬할 수 있다.
- **공개성:** 초록에서 공식 code·checkpoint 링크를 확인하지 못했다.
- **미확인:** downstream task별 absolute 수치, continent-held-out split, 좌표 정밀도·privacy 영향은 본 실행에서 확인되지 않았다.
- **진단→가설→최소 실험:** Sentinel-2와 SAR의 image encoder를 각각 고정하고, no regularizer/frozen single-modal/co-aligned multimodal target에서 location embedding effective rank와 cross-region retrieval을 비교한다. **성공 기준:** rank 증가가 seen-region 성능만이 아니라 continent-held-out recall에도 동반된다.
- **Woojin 연결:** 해양·원격탐사에서 좌표 prior가 시각 정보를 보완하는지, 단순 지역 shortcut인지 분리하는 데 직접적이다.
- **출처:** https://arxiv.org/abs/2610.32894

### 3.3 FlexGlue: Sparse-to-Dense Feature Matching and Visual Disambiguation

- **상태:** [사실] arXiv:2610.32976 v1, 2026-10-23 제출·10월 26일 신규 노출.
- **문제:** sparse matching은 빠르지만 keypoint repeatability에 약하고, dense matching은 강하지만 비싸다. 두 방식 모두 대칭적인 unrelated pair를 잘못 연결할 수 있다.
- **방법:** 첫 이미지의 sparse query coordinate를 받아 두 번째 이미지의 dense pixel grid에서 correspondence를 찾고, pair 자체가 non-match인지 동시에 예측한다.
- **저자 주장:** [저자 주장] sub-pixel dense accuracy와 sparse speed를 결합하며 relative pose, SfM, localization Pareto frontier를 개선한다.
- **핵심 가치:** matching과 pair rejection을 분리된 후처리로 두지 않고 같은 representation에서 학습한다.
- **재현성:** arXiv 초록에서 공식 code link를 확인하지 못했다. 정확한 runtime, GPU, memory, training pair 구성은 미확인이다.
- **공정 비교 위험:** sparse query 수, 이미지 해상도, candidate pair retrieval quality가 다르면 기존 dense matcher와 strictly apples-to-apples가 아니다.
- **negative test:** repetitive facade, 해수면 반사, 안개 속 horizon처럼 구조가 반복되거나 texture가 빈약한 pair에서 rejection calibration이 무너질 수 있다.
- **최소 실험:** MegaDepth 계열 일반 장면과 maritime 반복 texture를 섞어 query 수 128/512/2048에서 pose AUC, false-pair rejection AUROC, latency를 함께 측정한다.
- **Woojin 연결:** 해상 영상 registration·UAV localization에서 “match 정확도”보다 잘못된 pair를 거부하는 능력이 더 중요할 수 있다.
- **출처:** https://arxiv.org/abs/2610.32976

### 3.4 Flownomaly: Single-Step Conditional-Mean Recovery for Few-Shot Anomaly Detection

- **상태:** [사실] WACV 2027 accepted, arXiv v1은 2026-10-23 제출. 공식 코드가 공개됐다.
- **문제:** few-shot normal sample만으로 category-specific normality를 학습할 때 exemplar memory 의존, 선형 subspace 제약, anomaly 복원 위험이 생긴다.
- **방법:** frozen DINOv2 patch token에서 conditional flow matching으로 normal feature 방향을 배우고, trajectory integration 대신 한 번의 conditional-mean recovery를 사용한다.
- **calibration:** anomaly validation sample 없이 normal support의 Jacobian gain-to-noise criterion으로 operating time을 고른다.
- **정량 결과:** [저자 보고] 1-shot MVTec-AD image/pixel AUROC 97.8±0.9/98.0±0.1, VisA 95.3±0.7/98.7±0.0, Real-IAD 1-sample 5-view 88.2/99.2다. 3개 seed가 기본 protocol이다.
- **코드·환경:** Python 3.11, `uv sync --frozen`, NVIDIA CUDA GPU가 필요하며 저자 실험은 H100에서 수행됐다. Apache-2.0이다.
- **재현성 강점:** MVTec-AD/VisA/Real-IAD loader, 1/2/4-shot, seed 42/43/44, metrics JSON/Markdown 경로가 공개됐다.
- **주의:** frozen DINOv2와 category-specific velocity network의 비용을 exemplar 기반 method와 같은 계산 조건으로 비교해야 한다. H100 사용은 method 자체의 필수 VRAM을 뜻하지 않는다.
- **최소 실험:** MVTec-AD 3개 texture·3개 object class만 골라 single-step, multi-step, nearest-neighbor reconstruction을 같은 DINOv2 feature로 비교한다. **판정:** 3-seed AUROC뿐 아니라 calibration time, train time, false localization 면적을 함께 본다.
- **Woojin 연결:** 해무·센서 오염·선박 표면 결함에서 정상 샘플만으로 domain-specific normality를 복원하는 baseline으로 가치가 있다.
- **출처:** https://arxiv.org/abs/2610.32964, https://github.com/b-rbmp/Flownomaly

### 3.5 SceneBloom: Agentic Indoor Environment Generation with Realistic and Diverse Layouts for Embodied Learning

- **상태:** [사실] arXiv v1 2026-10-23, 공식 Apache-2.0 저장소 공개.
- **문제:** text-guided scene generation은 semantics는 맞아도 collision·out-of-bounds·물리적 배치가 깨질 수 있다.
- **방법:** diffusion prior로 functional zone별 layout을 제안하고, relation extraction·geometric fitting·local pose correction을 거쳐 simulation-ready 3D scene으로 compile한다.
- **저자 주장:** 5개 room type에서 비교법보다 visual quality와 physical stability가 높고, detected mesh collision과 out-of-bounds object가 0이었다. 생성 장면으로 학습한 navigation policy가 같은 수의 real training scan으로 학습한 정책보다 held-out real scan에서 높은 성공률을 보였다고 주장한다.
- **공개 구현:** bedroom/living room/dining room/office/bathroom, Habitat export, `scene.glb`, layout JSON, render를 제공한다.
- **비용:** third-party model 약 42GB, asset 약 3GB이며 전체 pipeline은 한 GPU에서 돈다고 README가 명시한다. GPU 종류·시간은 미확인이다.
- **외부 의존:** zoning·relation extraction·completion에 OpenRouter의 Qwen3-VL-8B-Instruct API key, gated FLUX.1-dev용 HF token이 필요하다.
- **재현성 위험:** 저장소 history가 조사 시점 1 commit이며, 외부 API model revision과 gated backbone 변화가 결과를 바꿀 수 있다.
- **최소 실험:** 방 20개를 seed 고정으로 생성해 collision, out-of-bounds, support relation violation, navigation success를 측정한다. visual preference만으로 성공 판정하지 않는다.
- **Woojin 연결:** 실제 maritime scene 대신 합성 공간의 물리적 제약을 검증하는 benchmark design 참고 사례로 유용하다.
- **출처:** https://arxiv.org/abs/2610.32978, https://github.com/Tinaliu0123/scenebloom

### 3.6 OpenStripe supports open-set identification and spatial stripe profiling in wild Amur tigers

- **상태:** [사실] arXiv v1 2026-10-23. code와 비공간 data가 공개됐다.

- **Woojin 연결:** small-data open-world re-ID에서 해석 가능한 local structure가 foundation feature보다 언제 강한지 연구할 수 있다.

## 4. VLM·멀티모달·비디오 핵심 4건

### 4.1 UniAction: Unified Action Conditioning for World Models

- **상태:** [사실] arXiv v1 2026-10-23. project, code, model adapter, train/eval dataset이 공개됐다.
- **문제:** force, camera, hand pose, robot pose의 action representation이 서로 달라 data와 model이 분절된다.
- **방법:** action을 discrete semantic identity와 continuous spatiotemporal coordinate를 가진 sparse element 집합으로 통일하고, video backbone의 native positional space에 직접 배치한다. element 수 차이는 cardinality-calibrated attention으로 보정한다.
- **저자 주장:** 하나의 joint model이 action별 expert보다 낫고, training에서 단일 action만 본 경우에도 여러 action을 동시에 조합할 수 있다.
- **공개 자산:** Wan2.2-I2V-A14B 기반 stage1/stage2 adapter, Apache-2.0 code·adapter, 40,000-sample train set을 제공한다.
- **데이터 조건:** force/hand/robot/camera 각 10,000 sample이며 81 frames, 832×480으로 preprocess한다. source-specific license이고 전체 file size는 약 70.7GB다.
- **주의:** shared model의 이득이 representation sharing인지 단순 data pooling인지 분리해야 한다. 14B backbone과 source-specific data는 재현 비용·배포 제약이 크다.
- **최소 실험:** 동일 4만 sample에서 joint/shared, joint without cardinality calibration, four experts를 비교하고 seen action, unseen combination, shifted scene의 action-following metric을 따로 측정한다.
- **출처:** https://arxiv.org/abs/2610.32977, https://uniaction.github.io/, https://huggingface.co/BowenXue/UniAction

### 4.2 MiD-VLM: Detecting and Grounding Global Semantic Misinformation in Image-Caption Pairs

- **상태:** [사실] arXiv v1 2026-10-23.
- **문제:** 실제 image에 pixel 조작이 없어도 caption이 narrative를 왜곡하면 기존 image-forensics detector가 놓친다.
- **방법:** SigLIP image-text representation과 DINOv2 scene feature를 projection MLP로 결합하고 Qwen2-VL-7B를 LoRA로 적응한다. authenticity, manipulation type, misleading token grounding을 공동 예측한다.
- **정량 결과:** [저자 보고] DGM4+ validation binary authenticity F1 0.9679.
- **핵심 한계:** validation 수치만 제시돼 있으며 test/generalization, unseen manipulation, publisher/source shift는 확인되지 않았다.
- **leakage 위험:** caption style, 생성 pipeline, token annotation 관례가 label shortcut이 될 수 있다. scene understanding 향상과 dataset artifact 분리를 해야 한다.
- **공개성:** 공식 code·checkpoint·data release link는 초록에서 확인하지 못했다.
- **최소 실험:** image를 고정한 채 human paraphrase, entity swap, temporal swap, sentiment reframing을 만들고 source-held-out split에서 binary F1과 token IoU를 같이 본다.
- **출처:** https://arxiv.org/abs/2610.32967

### 4.3 Beyond Discrete Tokens: Preserving Numerical Continuity in Medical Vision-Language Models

- **상태:** [사실] arXiv v1 2026-10-23.
- **문제:** 연속 측정값을 문자열 token으로 생성하면 인접 수치의 연속성·좌표와 길이의 consistency가 사라진다.
- **방법:** shared backbone에서 text는 autoregressive generation, caliper endpoints와 measurement length는 5-component diffusion representation으로 예측한다. coordinate-length consistency와 ensemble 후처리를 추가한다.
- **데이터:** EchoNet-LVH 4개 심초음파 측정, medical QA, X-ray vertebral measurement.
- **정량 결과:** [저자 보고] IVSd/LVIDd/LVIDs/LVPWd MAE 1.36/2.77/3.05/1.16mm, Vicuna 기반 autoregressive baseline보다 21.4–37.6% 감소. X-ray는 11.4→6.7 pixel.
- **주의:** task-specific continuous head의 이득과 diffusion 자체의 이득을 direct regression·ordinal/binning·Gaussian NLL과 같은 조건에서 비교해야 한다.
- **임상 위험:** 단일 dataset 평균 오차만으로 calibration·failure tail·reader variability를 알 수 없다. 외부 병원·device shift가 필요하다.
- **최소 실험:** 동일 encoder에서 text token, MLP regression, heteroscedastic regression, diffusion head를 비교하고 평균 MAE뿐 아니라 95th percentile, calibration, endpoint-length consistency를 측정한다.
- **출처:** https://arxiv.org/abs/2610.32948

### 4.4 Video-MemComp: Taylor-Guided Sensitivity-Aware Memory Management for Streaming Video Understanding

- **상태:** [사실] arXiv v1 2026-10-23, ACM MM 2026 accepted 표기.
- **문제:** streaming video의 KV cache를 줄이면 local approximation error와 layer-wise error propagation이 누적된다.
- **방법:** token aggregation을 pre-RoPE 구간에서 수행하고 attention-conserving logit bias를 더한다. offline gradient prior와 online context entropy로 layer별 cache budget을 동적으로 배분한다.
- **정량 결과:** [저자 보고] Qwen2.5-VL-3B에서 MLVU·VideoMME·EgoSchema를 평가했으며, cache를 layer당 6,000-token 상당으로 줄여 90% 이상 KV memory를 절감하면서 overall accuracy를 62.3%에서 64.1%로 높였다.
- **해석:** [분석] 압축이 full-cache보다 좋아진 것은 redundancy 제거일 수도 있지만 evaluation variance 또는 hyperparameter tuning 효과일 수도 있다.
- **재현성:** code·checkpoint 공식 공개는 초록에서 확인하지 못했다. offline gradient prior 계산 비용과 transfer 범위도 미확인이다.
- **최소 실험:** uniform eviction, attention-score eviction, Video-MemComp를 같은 token budget에서 비교하고, event가 초반/중반/후반에 있는 synthetic long video로 위치별 recall을 측정한다.
- **출처:** https://arxiv.org/abs/2610.32784

## 5. LLM·에이전트·시스템 핵심 2건

### 5.1 When Agents Fail: Model or Harness—Who's to Blame?

- **상태:** [사실] arXiv v1 2026-10-23, under review.
- **문제:** agent benchmark score는 model과 execution harness의 공동 산물인데 실패 원인을 model 능력으로만 귀속한다.
- **평가 축:** valid completion rate, model–harness fit, cross-model fit, interaction residual, token load.
- **규모:** [사실] OpenCode, Codex CLI, Pi CLI, DeepAgents의 4 general-purpose harness와 4 core model, 2 native system을 6 benchmark에서 평가했다. stress condition을 포함해 111 setting, 52,168 trajectory다.
- **저자 결과:** harness ranking은 model·benchmark에 따라 달라졌고, task performance와 valid completion이 다른 pairing을 선호할 수 있다. shared panel에서 OpenCode가 cross-model performance 1위였다고 보고한다.
- **핵심 가치:** 같은 task score라도 failure profile과 token cost가 다를 수 있음을 대규모 trajectory로 보인다.
- **주의:** harness version, prompt wrapper, tool policy, timeout, retry가 ranking을 크게 바꾼다. “어느 harness가 최고”로 일반화하면 안 된다.
- **공개성:** 초록 페이지에서 code/data link를 확인하지 못했다.
- **최소 실험:** 같은 repo task 30개를 model 2종×harness 2종으로 실행해 correctness, VCR, timeout, tool error, token load를 기록하고 two-way interaction effect를 추정한다.
- **출처:** https://arxiv.org/abs/2610.32483

### 5.2 Frontier-OPD: Discovering the Edge of Agent Capability and Teaching Agents to Go Beyond

- **상태:** [사실] arXiv v1 2026-10-23.
- **문제:** on-policy distillation에서 teacher가 개입할 지점이 너무 쉽거나 너무 어렵다면 student가 이어서 행동하지 못한다.
- **방법:** shared-state trajectory graph에서 teacher–student disagreement를 모으고, 짧은 teacher bridge 뒤 student가 자율적으로 continuation할 수 있는 지점을 learning frontier로 고른다.
- **저자 주장:** ALFWorld, WebShop, ScienceWorld에서 비교 distillation baseline보다 평균 autonomous performance가 높고 candidate selection과 guidance filtering의 효과가 상보적이다.
- **가치:** teacher 정답을 복사하는 대신 **도움 뒤 스스로 이어갈 수 있는가**를 supervision 선택 기준으로 삼는다.
- **주의:** benchmark simulator와 teacher quality에 frontier가 종속될 수 있다. teacher bridge의 추가 inference 비용도 포함해야 한다.
- **공개성:** code·trajectory data 공식 공개는 초록에서 확인하지 못했다.
- **최소 실험:** CV experiment agent가 data bug·metric mismatch·OOM 중 어디에서 짧은 hint 뒤 회복하는지 기록하고, random hint·highest disagreement·frontier filter를 비교한다.
- **출처:** https://arxiv.org/abs/2610.32802

## 7. 오늘의 중요한 발견 3가지

### Finding 1 — representation에 “목표가 가까이 있다”는 사실과 사람이 볼 수 있는 의미는 다르다

SPOOK의 sparse blank-canvas probe와 LoCA의 rank limitation은 서로 다른 방식으로 같은 문제를 가리킨다. embedding의 유사도·선형 분리·contrastive loss가 좋더라도 입력 manifold 밖의 geometry나 target covariance가 잘못되면 실제 의미·일반화와 분리된다. 다음 단계는 더 큰 encoder가 아니라 **validity domain, rank, readout causal use**를 함께 측정하는 것이다.

### Finding 2 — 연속량과 시간 구조를 무조건 token으로 만들면 정보 구조가 깨진다

HAD-VLM은 좌표·길이를 continuous diffusion head로, Video-MemComp는 RoPE 이전 구간과 layer sensitivity를 고려해 처리한다. 둘 다 “모든 것을 동일한 token pipeline에 넣으면 편하다”는 설계가 수치 연속성·시간 geometry를 해칠 수 있음을 보여준다.

### Finding 3 — agent 성능은 model 이름이 아니라 model×harness×task의 상호작용이다

When Agents Fail과 Frontier-OPD는 실패율·teacher 도움·continuation을 trajectory 수준에서 본다. 모델 교체만으로 성능을 설명하면 invalid completion, retry, prompt wrapper, tool policy의 영향을 놓친다. CV 연구 자동화도 논문 요약 정확도보다 file handoff, metric extraction, 실패 복구를 별도로 계측해야 한다.

## 8. 과대평가·주의 신호

1. **MiD-VLM의 0.9679 validation F1**  
   test/source-held-out 근거가 없고 DGM4+ 생성·caption style shortcut을 배제하지 못했다. headline F1보다 unseen manipulation·token grounding을 봐야 한다.

2. **SceneBloom의 “real scan보다 synthetic scene training이 더 좋다”는 주장**  
   equal scene count가 equal diversity·frame count·interaction count를 뜻하지 않는다. collision 0도 detector와 object set 정의에 종속된다. 공식 code는 공개됐지만 외부 API와 gated model revision을 고정해야 한다.

## 9. 오늘 바로 읽을 Top 3

1. **SPOOK** — 사용자 연구의 representation-vs-readout 진단과 가장 직접적으로 맞는다. 간단한 black-box probe라 작은 GPU에서도 반증 가능하다.
2. **LoCA** — architecture보다 target covariance와 intrinsic dimension을 병목으로 본 이론·실험 연결이 강하다.
3. **Video-MemComp** — 긴 video VLM에서 cache memory와 정확도 trade-off를 실제 최소 실험으로 옮기기 쉽다.

## 10. Top 1 미니 리뷰 — SPOOK

### 왜 중요한가

vision foundation model을 semantic feature extractor로 사용할 때 우리는 embedding distance가 “시각적 의미 거리”라고 암묵적으로 가정한다. SPOOK은 이 가정이 자연 이미지 manifold 밖에서도 유지되는지 묻는다. 빈 화면에 극소수 pixel만 조정했는데 특정 class prompt나 prototype의 가까운 이웃이 된다면, encoder 내부의 semantic basin은 사람이 인지하는 의미보다 훨씬 넓고 예상 밖의 방향으로 열린다.

### 기존 연구의 blind spot

일반 adversarial attack은 자연 이미지에 작은 perturbation을 더해 분류를 바꾼다. SPOOK의 핵심은 natural carrier image가 없어도 sparse edit만으로 목표 representation에 진입한다는 점이다. 따라서 문제는 classifier boundary만이 아니라 encoder geometry 자체다.

### 핵심 experimental logic

1. blank canvas에서 시작한다.
2. gradient 없이 pixel-level hill climbing을 수행한다.
3. OpenCLIP은 class text prompt, DINOv3는 class prototype을 목표로 한다.
4. ImageNet·Flickr30k retrieval에서 목표 rank를 측정한다.

이 구조는 공격 성공률보다 “어떤 encoder가 어떤 off-manifold basin을 갖는가”를 비교하는 probe로 읽는 편이 낫다.

### 진짜 contribution

- contrastive language-aligned encoder와 self-supervised encoder 모두에서 같은 종류의 failure를 확인했다는 점.
- 복잡한 generator나 white-box gradient 없이 적용 가능한 최소 probe를 제시했다는 점.
- representation quality 평가에 natural-image accuracy 외의 validity test가 필요함을 보여준 점.

### 과장될 수 있는 부분

blank canvas는 deployment input과 매우 다르다. 이 결과만으로 자연 이미지 robustness가 낮다고 말할 수 없다. pixel search budget, preprocessing, resolution, prototype construction이 결과에 얼마나 영향을 주는지도 확인해야 한다.

### Woojin 연구에 가져오는 방법

해무·저시정 encoder에서 clean/fog/blank texture를 각각 carrier로 사용하고 같은 sparse optimization을 수행한다. 목표 class rank가 fog에서 특히 쉽게 상승한다면 representation이 의미보다 저주파·texture shortcut에 열려 있을 수 있다. 이후 linear probe, nearest prototype, nonlinear head를 비교하면 representation 정보와 readout 취약성을 분리할 수 있다.

## 11. 후속 연구 씨앗

### 씨앗 A — Visibility-Manifold Stress Test for Maritime Encoders

- **질문:** 저시정에서 encoder가 보존하는 정보는 semantic인가, off-manifold shortcut인가?
- **가설:** fog severity가 커질수록 sparse pixel probe가 적은 edit로 목표 embedding basin에 진입한다.
- **최소 실험:** ImageNet-pretrained DINOv3/OpenCLIP와 해무 fine-tuned encoder에 clean/fog/blank carrier, pixel budget 8/32/128을 적용한다.
- **데이터:** SeaFog 또는 기존 해상 visibility dataset + 통제된 synthetic fog.
- **baseline:** random sparse edit, FGSM류 자연 이미지 attack, linear probe.
- **판정:** targeted rank, edit budget, perceptual distance, cross-head transfer. negative result여도 encoder별 validity domain 비교가 남는다.

### 씨앗 B — Rank-Aware Geolocation Without Coordinate Shortcut

- **질문:** 좌표 embedding의 rank를 높이면 cross-region EO 인식이 좋아지는가, 지역 shortcut만 강화되는가?
- **가설:** modality co-alignment와 high-rank regularization은 random split보다 continent-held-out에서 더 큰 이득을 준다.
- **최소 실험:** 좌표 MLP, Fourier location encoder, LoCA-style target regularization을 optical/SAR 두 modality에서 비교한다.
- **데이터:** Sentinel-2/Sentinel-1 paired subset.
- **판정:** effective rank, seen/unseen region retrieval, class accuracy, coordinate perturbation sensitivity. unseen에서 이득이 없으면 regularizer는 shortcut일 가능성이 높다.

### 씨앗 C — Causal Cache Allocation for Small Objects in Long Video

- **질문:** Video-MemComp식 layer sensitivity가 작은·짧은 객체 사건을 보존하는가?
- **가설:** global accuracy를 유지해도 short-lived small-object recall은 uniform cache보다 나쁠 수 있다.
- **최소 실험:** 긴 해상 감시 영상에 짧은 선박·부표 event를 삽입하고 uniform eviction, attention eviction, sensitivity-aware allocation을 같은 KV budget에서 비교한다.
- **baseline:** full cache, sliding window, token pooling.
- **판정:** event recall by temporal position/size, answer accuracy, KV memory, latency. 평균 accuracy가 같아도 small-event recall이 떨어지면 실패로 본다.

### 씨앗 D — Harness-Aware Reproducibility Agent for CV Papers

- **질문:** 논문 재현 실패가 model reasoning 실패인지 harness/file/tool 실패인지 분리할 수 있는가?
- **가설:** valid completion, tool error, artifact handoff를 별도로 최적화하면 더 큰 model 교체보다 재현 성공률이 높아진다.
- **최소 실험:** 20개 small CV repo의 install→sample inference→metric extraction task를 2 model×2 harness로 실행한다.
- **판정:** correctness, VCR, timeout, wrong-file rate, token load, human repair minutes. interaction residual이 크면 model leaderboard만으로 agent를 고르면 안 된다.

## 12. 오늘 굳이 읽지 않아도 되는 것

- **NgramRL:** RL rollout system을 직접 운영하지 않는다면 오늘 CV 연구 결정을 바꾸지 않는다. throughput claim은 중요하지만 별도 systems note로 충분하다.
- **On-Policy Self-Training:** 합성 curriculum과 VQA self-improvement가 흥미롭지만 prompt distribution·evaluation contamination을 더 확인한 뒤 읽어도 늦지 않다.
- **Consommé:** edge split inference를 당장 구현하지 않는다면 absolute network latency와 device benchmark가 공개될 때까지 보류할 수 있다.
- **일반 의료 생성 논문:** 임상 외부 검증·prospective study가 없는 headline metric은 우선순위를 낮춘다.
