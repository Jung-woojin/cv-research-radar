## 1. Sequential Thermal Anti-UAV — tiny-target 적응 뒤 large-target 능력이 즉시 붕괴

**자료:** [arXiv 제출 이력](https://arxiv.org/abs/2610.08315) · [공식 HTML 원문](https://arxiv.org/html/2610.08315v1)  
**공개 시각:** 2026-10-06 22:18 KST  
**모델·구성:** motion channel을 0으로 둔 YOLOMG 기반 단일 thermal stream  
**학습 순서:** Anti-UAV-RGBT → Anti-UAV410 → CST Anti-UAV

### 관측과 공식 인정

- Stage 2 checkpoint를 CST Anti-UAV로 naive fine-tuning하자 이전 Anti-UAV-RGBT의 mAP@0.5가 0.640에서 best Stage 3 checkpoint의 0.068로, 마지막 epoch에는 0.017로 내려갔다.
- Stage 1 ceiling 대비 Forgetting Measure는 -0.605로, 저자 환산 기준 약 90% capability loss다. 이 중 -0.572가 Stage 3에서 발생했다.
- large-target stratum mAP는 Stage 1의 0.461, Stage 2의 0.494에서 Stage 3 첫 epoch에 0.000으로 떨어진 뒤 회복하지 않았다.
- 반면 Stage 3 데이터 CST Anti-UAV는 87.9% tiny, 11.9% small, 0% large target으로 구성된다. Stage 2에서도 tiny-target mAP는 0.001로 사실상 획득되지 않았다.
- 저자는 이 결과를 직접 catastrophic forgetting으로 보고했다. 독립 community reproduction과 공식 실행 저장소는 확인하지 못했다.

### 진단과 의심 메커니즘

**저자 근거:** Stage 2→3의 gradient-updated weight cosine similarity는 0.987로 높았고, Stage 3 forgetting은 Stage 2보다 훨씬 컸다. CST batch의 box-regression loss는 T1 batch보다 약 5배 컸으며, CST에는 large-target positive gradient가 없다. 이 조합은 단순 weight overwrite보다 scale-conditioned gradient imbalance 또는 gradient starvation과 일치한다.

**대안 원인:** Stage 2와 Stage 3는 보호 기법부터 다르다. Stage 2는 knowledge distillation, Stage 3 headline baseline은 naive fine-tuning이다. batch size도 64 대 16, learning rate도 1e-3 대 5e-4로 다르다. 따라서 “scale shift가 Stage 2보다 18배 더 큰 forgetting을 만들었다”는 비교는 **not strictly apples-to-apples**다.

Stage 2의 KD 결과는 세 seed에서 FM -0.033±0.004였지만 no-KD 대조군이 없다. 이는 KD 조건에서 retention이 높았다는 사실이지, KD의 인과 효과를 분리한 결과는 아니다. Stage 3와 replay는 seed 42 한 번뿐이다.

### 기존 주장과 충돌

“새로운 tiny-object 환경에 적응하면 기존 detector 능력을 유지한 채 범위를 넓힌다”는 누적 학습 기대와 충돌한다. 이 실험에서는 tiny-target 자체의 최고 Stage 3 mAP도 0.083에 그치면서 기존 large-target 능력까지 잃었다. plasticity와 stability가 모두 충분하지 않았다.

### 가설 → 최소 개입 → 실험

**가설:** forgetting의 주원인은 큰 parameter 이동이 아니라 새 task에 없는 scale bin의 positive gradient 소실이다.

**최소 개입:** herding 없이 scale-stratified random replay 300장을 섞는다. 원 논문 단일-seed 결과에서도 random-stratified replay는 T1 mAP 0.451, FM -0.221, large-target mAP 0.129로 naive보다 나았고, SSH의 FM -0.311보다도 좋았다. 다만 이 우열은 단일 seed라 확정할 수 없다.

**검증 실험:**

1. 동일 Stage 2 checkpoint에서 naive / flat-random replay / scale-stratified random replay를 각각 3 seeds로 실행한다.
2. batch size, learning rate, epoch budget, augmentation, resolution을 모두 고정한다.
3. tiny·small·normal·large bin별 mAP, gradient norm, BatchNorm buffer drift, 전체 FM을 매 epoch 기록한다.
4. large replay를 제거하는 leave-one-stratum-out 조건을 추가해 scale coverage의 인과성을 확인한다.

**GO:** scale-stratified random replay가 세 seed 모두에서 large-target collapse를 막고, flat replay보다 FM을 개선하며 T3 mAP 손실을 사전 정의한 범위 안에 유지한다.  
**KILL/수정:** 학습 조건을 맞추면 naive collapse가 재현되지 않거나, scale coverage가 아니라 BatchNorm 고정만으로 대부분 회복한다.

**점수:** 심각도 5/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 5/5

## 2. Video MCQ — 안정적인 평균 점수가 불안정한 문항 예측을 숨김

**자료:** [arXiv 제출 이력](https://arxiv.org/abs/2610.08649) · [공식 HTML 원문](https://arxiv.org/html/2610.08649v1)  
**공개 시각:** 2026-10-07 01:36 KST  
**모델·데이터:** Qwen2.5-VL-7B, Qwen3-VL-8B, InternVL2.5-8B; EgoSchema, MVBench, Video-MME  
**규모:** 9개 model×benchmark cell, cell당 500문항×10 option order와 별도 phase sweep을 포함한 289,000회 inference

### 관측과 공식 인정

- 같은 8-frame rate에서 시작점만 반 step 옮긴 두 sampler가 consensus answer의 23.6%에서 불일치했지만 accuracy 차이는 0.7%p였다.
- 네 가지 배포형 uniform sampler는 Qwen2.5-VL의 같은 598문항에서 pairwise 11.7–23.6% 불일치를 보였고, accuracy는 51.1–52.3% 범위였다. 동일 조건 재실행의 floor는 3.67%였다.
- frame phase만 통제해 비교한 네 release에서도 약 15–20%의 답이 바뀌었다.
- option ordering을 열 번 바꾼 실험은 cell별 40.8–66.4%, pooled 54.0%의 answer flip을 보였다. 같은 ordering 변화가 score를 최대 5.8%p 움직였다.
- 저자가 failure mode를 직접 보고했다. corpus와 audit code는 “출판 시 공개” 예정으로 적혀 있으며 현재 공개 저장소는 확인하지 못했다. 독립 reproduction도 확인하지 못했다.

### 진단과 의심 메커니즘

**확인된 사실:** frame count와 sampling rate를 고정해도 phase가 달라지면 모델이 보는 순간이 달라진다. 짧은 사건이 grid 경계 사이에 놓이면 증거가 빠질 수 있다. Option letter와 위치 prior는 영상 증거와 별개로 선택을 흔든다.

**저자 해석:** 평균 accuracy는 perturbation에 둔감해 보이지만 per-item prediction은 불안정하다. 따라서 leaderboard score만 보면 재현 실패를 놓친다.

**추론:** 낮은 confidence margin, 순간적 사건, option position bias가 결합될 가능성이 크다. 다만 공개 corpus가 없어 현재 어떤 문항 특성이 phase 민감성을 예측하는지 독립 검증할 수 없다.

### 기존 주장과 충돌

“동일 모델·동일 frame budget이면 video benchmark 결과가 재현 가능하다”는 암묵적 가정과 충돌한다. accuracy가 1%p 안에서 같다는 사실은 같은 판단을 했다는 뜻이 아니다. 모델 family 간 절대 flip rate 비교와 3-pass PhaseFusion 대 single-pass 비교는 **not strictly apples-to-apples**다.

### 가설 → 최소 개입 → 실험

**가설:** 짧은 evidence event가 frame grid 경계에 있을수록 phase disagreement가 커지고, posterior averaging이 이를 줄인다.

**최소 개입:** 기존 8-frame evaluator에 phase 0과 0.5-step 조건만 추가하고, option order는 고정한다.

**검증 실험:**

1. 같은 video·prompt·decoding·option order에서 두 phase를 paired 평가한다.
2. accuracy와 함께 item disagreement, confidence margin, evidence duration을 기록한다.
3. 동일 phase 재실행으로 nondeterminism floor를 먼저 측정한다.
4. phase disagreement가 floor보다 클 때만 3×8-frame posterior fusion을 추가한다.

**GO:** phase disagreement가 재실행 floor보다 명확히 크고, fusion이 disagreement를 낮추면서 accuracy 손실을 2.5%p 이내로 유지한다.  
**KILL/수정:** disagreement 대부분이 decoding nondeterminism이나 option order로 설명되거나, fusion 이득이 긴 영상의 특정 subset에만 남는다.

**점수:** 심각도 4/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 4/5

## 3. Patch-Based HSI — random split이 spatial model의 성능을 최대 40.97%p 부풀림

**자료:** [arXiv 제출 이력](https://arxiv.org/abs/2610.08770) · [공식 HTML 원문](https://arxiv.org/html/2610.08770v1) · [저자 GitHub 저장소](https://github.com/mqalkhatib/Data_Leakage_in_HSI_Classification)  
**공개 시각:** 2026-10-07 02:55 KST  
**데이터·구성:** Pavia University HSI, random pixel sampling 대 connected-region 기반 non-random spatial sampling, 10회 실행  
**모델:** SVM, MLP, 2D-CNN, 3D-CNN, ViT, MorpMamba

### 관측과 공식 인정

| 모델 | Random OA | Non-random OA | 하락 |
|---|---:|---:|---:|
| SVM | 62.15% | 51.25% | -10.90%p |
| MLP | 69.50% | 50.15% | -19.35%p |
| 2D-CNN | 86.97% | 48.16% | -38.81%p |
| 3D-CNN | 96.17% | 55.20% | -40.97%p |
| ViT | 91.78% | 51.07% | -40.71%p |
| MorpMamba | 81.07% | 48.45% | -32.62%p |

- patch size 5×5에서 19×19로 커질 때 random split의 overlap percentage는 23.28%에서 77.02%로, affected test patch의 average overlap ratio는 47.29%에서 79.91%로 증가했다.
- non-random split의 overlap percentage는 같은 범위에서 0.83%→4.66%였다. 완전한 zero-overlap은 아니며, 겹친 소수 patch의 local overlap은 약 39–45%였다.
- 저자는 random sampling의 same-class train–test spatial dependency가 deep spectral-spatial model의 성능을 낙관적으로 만든다고 공식 보고했다.
- 독립 community reproduction은 확인하지 못했다.

### 코드 감사와 재현 위험

공식 저장소에서 `Leakage_with_Overlap.py`는 random split, 10개 seed, `patch_size=5`를 사용한다. `Leakage_No_Overlap.py`는 connected region split을 사용하지만 기본값은 `patch_size=19`다. README는 저장소 제목 한 줄뿐이며 설치법·데이터 위치·실행 명령·license가 없다.

논문은 두 sampling protocol에서 같은 training configuration을 썼다고 설명하지만, 공개된 leakage 측정 script 두 개의 기본 patch size가 다르다. 따라서 script를 그대로 실행해 얻은 차이를 split 효과로만 해석하면 안 된다. 논문 표와 코드의 정확한 실행 entry point·commit·설정 연결도 문서화되지 않았다.

### 진단과 의심 메커니즘

**저자 해석:** spatial model은 인접 patch의 공유 pixel과 비슷한 local structure를 활용해 random split에서 과대평가된다.

**대안 원인:** connected-region split은 중첩만 줄이는 동시에 train/test의 geographic distribution을 바꾼다. 성능 하락에는 실제 spatial domain shift, class별 region 난도, 경계 효과도 포함될 수 있다. 그러므로 random 대 non-random OA는 의도적으로 엄격한 stress test이지만, leakage 하나의 순수 효과로는 **not strictly apples-to-apples**다.

### 기존 주장과 충돌

random split의 3D-CNN 96.17%를 배포 가능한 일반화 성능으로 읽는 주장과 충돌한다. 또한 random split에서의 deep model 순위는 non-random 조건에서 크게 압축돼, architecture 우위 자체가 split artifact일 수 있다.

### 가설 → 최소 개입 → 실험

**가설:** 해양·위성 patch model의 높은 점수 중 상당 부분은 같은 tile 안의 spatial autocorrelation과 receptive-field overlap에서 온다.

**최소 개입:** model·train count·patch size를 고정하고 split만 random pixel에서 geographic block/group으로 바꾼다.

**검증 실험:**

1. patch size 5, 9, 19를 각각 별도 실험으로 고정한다.
2. random / zero-overlap buffered / leave-one-tile-out split을 비교한다.
3. pixel overlap, receptive-field overlap, train–test 최소 거리, class별 IoU/OA를 함께 기록한다.
4. 같은 spatial split에서 spectral-only baseline과 spatial model을 비교해 context 의존성을 분리한다.

**GO:** spatial model의 하락이 spectral-only baseline보다 크고 overlap·buffer distance와 단조 관계를 보이며, 두 개 이상의 지역에서도 반복된다.  
**KILL/재명명:** zero-overlap 이후에도 지역 ID만 바꾸면 같은 하락이 유지된다. 이 경우 핵심 실패를 leakage보다 geographic domain shift로 재정의한다.

**점수:** 심각도 5/5 · 재현 신뢰도 3/5 · 연구 아이디어 가치 5/5

## 오늘의 실패 패턴 3개

1. **새 task에 없는 scale은 첫 epoch부터 사라질 수 있다.** 전체 weight similarity가 높아도 stratum별 능력은 보존되지 않는다.
2. **평균 점수 안정성은 예측 안정성이 아니다.** phase·option order perturbation과 item disagreement를 별도 측정해야 한다.
3. **공간 분할은 architecture gain보다 큰 변수다.** random patch split에서는 receptive-field overlap과 geographic autocorrelation을 먼저 감사해야 한다.

## 논문 아이디어로 연결 가능한 빈틈

가장 가치 있는 빈틈은 **scale-conditioned replay와 spatially separated evaluation을 결합한 thermal/maritime continual detection protocol**이다.

현재 Anti-UAV 결과는 scale coverage가 forgetting을 줄일 가능성을 보였지만, 단일 seed와 다른 optimizer 설정 때문에 인과성이 부족하다. HSI 결과는 spatial separation의 중요성을 보였지만 classification 한 데이터셋에 한정된다. 이를 연결해 다음 질문을 만들 수 있다.

> 새로운 해무·tiny-target 도메인에 적응할 때, 과거 데이터의 scale-stratified replay가 geographic holdout에서도 기존 크기별 성능을 보존하는가?

신규성은 replay 알고리즘 이름보다 **scale별 gradient coverage, spatial separation, BatchNorm drift를 한 protocol에서 분해하는 것**에 있다. 단일 random split의 mAP 개선만으로는 논문 가치가 낮다.

## 직접 재현해볼 최소 실험

**1순위, 학습 전 진단:**

1. 기존 thermal/maritime detection 데이터의 bbox area를 tiny·small·normal·large로 나눈다.
2. train/val의 tile·sequence·camera ID 중복과 최소 공간·시간 거리를 계산한다.
3. 각 split에서 scale histogram과 객체 수를 표로 만든다.
4. 현재 checkpoint의 scale-bin별 AP와 false negative를 재집계한다.

**2순위, 작은 학습 실험:**

- 기존 checkpoint 하나에서 새 tiny-target subset을 1 epoch만 fine-tune한다.
- naive와 scale-stratified random replay를 동일 optimizer·batch·resolution로 비교한다.
- 이전 validation의 large AP, 새 validation의 tiny AP, BatchNorm 고정/학습 두 조건을 기록한다.

**GO:** naive에서 반복 가능한 large-AP 급락이 나타나고, scale-stratified replay가 세 seed 중 같은 방향으로 이를 줄이면서 tiny AP를 유지한다.  
**KILL/수정:** split 중복을 제거하면 기존 효과가 사라지거나, BatchNorm 고정만으로 회복한다. 이 경우 replay보다 evaluator/split 또는 normalization adaptation을 주제로 전환한다.
