## Q1. 실제 DICOM spacing을 사용하면 index gap 기반 연속시간 의료 복원의 외부 일반화가 개선되는가?

### Observation

**[확인된 사실]** [ContiLNN](https://arxiv.org/html/2610.12337)은 2D restoration backbone에 bidirectional closed-form continuous-time module을 붙여 CT denoising, MRI super-resolution, reduced-count PET restoration을 평가했다. Restore-RWKV 대비 5개 seed 평균 PSNR 증가는 CT 0.1907 dB, MRI 1.0176 dB, PET 1.2482 dB다.

**[확인된 사실]** contiguous training 뒤 \(g=3\) gap으로 평가하면 \(g=1\) 대비 Bi-CfC PSNR은 1.9216 dB, Bi-GRU는 1.9881 dB 감소했다. 두 번째 DASMamba backbone에서는 PSNR이 올랐지만 CT/MRI SSIM은 각각 0.0051/0.0050 낮아졌다.

**[저자 주장]** 원 데이터에 물리적 slice spacing metadata가 없어 해부학적 millimeter 거리 대신 index-defined gap만 시험했다고 한계를 명시한다.

### Gap / Diagnosis

**[추론]** 연속시간 모델의 시간 변수 자체가 scanner protocol과 환자 해부학을 반영하지 않는다. 동일한 index gap도 1 mm와 5 mm slice에서 다른 물리적 의미를 갖기 때문에, in-domain PSNR 향상이 다른 기관·scanner에서 유지된다는 보장이 없다.

### Hypothesis

DICOM의 `ImagePositionPatient`, `SliceThickness`, `SpacingBetweenSlices`로 실제 z-distance를 계산해 gate에 넣으면 index-only 모델보다 scanner 이동에서 calibration과 구조 보존이 개선된다. 개선이 단순 parameter 증가 때문이 아니라면, parameter-matched index embedding보다 spacing-aware model의 외부기관 성능 하락이 작아야 한다.

### Experimental Design

- **데이터:** DICOM spacing을 보존하는 공개 CT/MRI volume 두 기관 또는 두 scanner subset
- **비교군:** 2D baseline, index-gap Bi-GRU, index-gap Bi-CfC, millimeter-spacing Bi-CfC, spacing-shuffled control
- **분할:** patient-level split 후 scanner/vendor를 외부 test로 분리
- **평가:** PSNR, SSIM, RMSE, lesion/organ boundary Dice, spacing-bin별 calibration, scanner 간 성능 하락
- **핵심 ablation:** spacing을 실제값·정규화값·shuffle·고정값으로 바꿔 gate가 물리 좌표를 실제로 쓰는지 확인
- **GO:** 외부 scanner에서 PSNR 또는 boundary Dice가 일관되게 개선되고 spacing shuffle에서 이득이 사라짐
- **KILL:** index baseline과 차이가 없거나 scanner별 normalization에 지나치게 민감함
- **최소 실험:** pretrained 2D backbone을 동결하고 작은 cross-slice module만 학습

### Expected Contribution

“continuous-time”이라는 이름과 실제 물리적 연속성을 분리해 검증하는 진단 논문이다. 의료영상 restoration에서 slice-index benchmark가 감추는 protocol shift를 정량화할 수 있다.

### Risk / Compute / 4–8주 가능성

- **Compute cost:** 2/5. 작은 module과 2D backbone freeze로 8GB GPU에서도 축소 실험 가능
- **위험:** DICOM metadata 정합성과 patient privacy로 usable volume 수가 줄 수 있음
- **4–8주:** 데이터 확보 시 가장 현실적
- **음성 결과 가치:** 물리 spacing이 도움이 되지 않으면 국소 anatomy feature가 이미 간격을 암묵적으로 추정하거나, spacing보다 reconstruction kernel 차이가 지배적이라는 경계 조건을 남긴다.

## Q2. 비보상식 fog/vessel rubric은 평균 화질 점수가 놓치는 해무 편집·복원 실패를 더 잘 찾는가?

### Observation

**[확인된 사실]** [Rubric-CEPR](https://arxiv.org/html/2610.12469)은 편집 실현, 이전 상태 제거, 보존 조건을 별도 gate로 평가하고 하나라도 실패하면 후보를 학습 표적으로 쓰지 않는다. 같은 Qwen-Image-Edit-2509 base와 단발 생성 조건에서 ImgEdit overall은 4.36→4.60, object extraction은 3.41→4.26으로 상승했다.

**[확인된 사실]** 세 seed의 overall 결과는 4.58, 4.60, 4.62였으며, 저자들은 다른 논문의 score는 judge와 protocol이 달라 직접 비교할 수 없다고 명시한다.

**[저자 주장]** scalar reward는 unchanged source, partial edit, 시각적으로 매력적이지만 지시를 위반한 결과를 높게 평가할 수 있다.

### Gap / Diagnosis

**[추론]** 해무 제거·합성에서도 PSNR, SSIM, LPIPS 하나로는 fog density 변화, 선박 보존, 수평선·배경 보존, 색 왜곡을 상쇄해 버린다. 특히 작은 선박이 사라져도 넓은 배경이 잘 복원되면 평균 점수가 높을 수 있다.

### Hypothesis

`fog change`, `vessel preservation`, `background geometry preservation`, `color validity`를 비보상식 gate로 두면 scalar metric top-k보다 실제 작업 실패율이 낮은 결과를 고른다. 작은 선박이 있는 장면에서는 vessel gate가 최종 ranking을 가장 많이 바꿀 것이다.

### Experimental Design

- **데이터:** 해무 제거 또는 합성 결과 100–200쌍, 선박 있음/없음·크기·안개 농도별 층화
- **비교군:** PSNR/SSIM/LPIPS, 가중합 scalar, geometric mean, non-compensatory gate
- **gate:** fog density 방향, vessel box/contour 유지, horizon/background 구조, global color shift
- **평가:** blind human failure rate, gate별 precision/recall, small-vessel miss rate, acceptance coverage, ranking stability
- **ablation:** vessel gate 제거, background gate 제거, threshold sweep, detector confidence bin
- **GO:** gate top-20의 실제 위반율이 scalar top-20보다 30% 이상 낮고 acceptance coverage가 40% 이상
- **KILL:** threshold에 따라 ranking이 크게 뒤집히거나 detector 오류가 gate 이득을 설명함
- **최소 실험:** 기존 출력만 사용하고 새 generator는 학습하지 않음

### Expected Contribution

해무 연구를 “복원 평균점수”에서 **필수 계약을 모두 충족하는가**로 바꾸는 평가 protocol이다. 작은 해상 표적 보존을 화질 개선과 동등한 필수조건으로 만들 수 있다.

### Risk / Compute / 4–8주 가능성

- **Compute cost:** 2/5. 기존 출력과 frozen detector/segmenter로 가능
- **위험:** 자동 gate 자체의 domain bias
- **4–8주:** human audit까지 포함해 가능
- **음성 결과 가치:** gate가 human judgment와 맞지 않으면 해무 평가에 필요한 최소 사람 검수 비율과 자동지표의 한계를 제시할 수 있다.

## Q3. 해양 VLM의 정답을 visual anchor–공식 출처–연산 graph로 감사하면 hallucination을 분리할 수 있는가?

### Observation

**[확인된 사실]** [OneSearch-VL](https://arxiv.org/html/2610.12419)은 visual anchor, 외부 사실, source provenance, answer-producing operation을 Visually Grounded Evidence Graph로 연결한다. OneSearch-MI-Bench 301문항과 OneSearch-Video-Bench 307문항을 공개했고, 총 608문항 중 555문항(91.3%)이 multi-hop, count, join, arithmetic, comparison을 포함한다.

**[확인된 사실]** 공식 [GitHub 저장소](https://github.com/appletea233/OneSearch-VL)는 dataset, 약 110K SFT trajectory, 약 10K RL task, inference/evaluation entry point를 공개한다.

**[저자 주장]** 정답 정확도만 보상하는 대신 evidence traceability와 visual grounding을 분리해 감독하면, 단일 이미지·다중 이미지·비디오 deep research를 하나의 dependency graph로 통합할 수 있다.

### Gap / Diagnosis

**[추론]** 해양 VLM은 “선박이 보인다”, “해무가 짙다”, “운항 위험이 높다”를 한 문장에 섞기 쉽다. 첫 두 주장은 영상 근거, 마지막 주장은 공식 기상·해양 정보와 규칙을 필요로 하는데 현재 benchmark는 오류가 visual grounding, retrieval, source mismatch, arithmetic 중 어디서 생겼는지 분리하지 않는다.

### Hypothesis

질문마다 `key frame/region → vessel·fog entity → KHOA/KMA 등 공식 사실 → join/count/threshold operation → answer` graph를 기록하면, answer accuracy가 같은 모델 사이에서도 unsupported claim과 잘못된 frame grounding을 구분할 수 있다. graph-constrained answering은 정확도 손실을 작게 유지하면서 unsupported claim을 줄일 것이다.

### Experimental Design

- **MVP:** 해양·해무 영상 20–30개, 질문 40–60개
- **질문 유형:** visual lookup, 시간 변화, vessel count, visibility threshold, 외부 관측 결합
- **비교군:** direct answer, citation-only answer, free-form chain-of-thought, evidence-graph answer
- **평가:** answer accuracy, anchor recall, region IoU, source precision, unsupported-claim rate, operation correctness, 비용·latency
- **오류 taxonomy:** perception, temporal grounding, retrieval, source, join/count, final verbalization
- **GO:** answer accuracy 하락 3 point 이하에서 unsupported claim 25% 이상 감소
- **KILL:** graph schema annotation 비용이 높고, 정확도·근거성 모두 개선되지 않음
- **최소 실험:** 학습 없이 prompt와 post-hoc graph validation만 적용

### Expected Contribution

해양 안전 VLM을 “정답을 맞혔는가”에서 **어떤 영상 영역과 공식 사실을 어떤 연산으로 결합했는가**로 확장하는 진단 benchmark다.

### Risk / Compute / 4–8주 가능성

- **Compute cost:** 2/5. 소형 open VLM inference와 소규모 annotation 중심
- **위험:** graph schema가 너무 강하면 schema에 맞는 답만 유리해질 수 있음
- **4–8주:** 40–60문항 pilot과 오류 taxonomy는 가능
- **음성 결과 가치:** graph가 hallucination을 줄이지 못하면 병목이 reasoning보다 base perception 또는 공식 source retrieval에 있음을 보여준다.

## Q4. streaming 3D reconstruction의 실제 병목은 decoder readout인가, persistent storage·encoder인가?

### Observation

**[확인된 사실]** [Slot3R](https://arxiv.org/html/2610.12282)은 training-free set-associative spatial memory와 640-token bounded readout으로 600–1,000 sampled frame 평가를 약 19 FPS로 완료했다고 보고한다. 비교 protocol에서 Point3R과 InfiniteVGGT는 800프레임 이상에서 OOM이었다.

**[확인된 사실]** 논문은 decoder와 memory update가 causal이지만 평가 harness가 recurrent decoding 전에 전체 입력 sequence를 인코딩한다고 명시한다. FPS는 data loading과 metric computation을 제외하며, readout budget은 decoder-visible token만 제한하고 persistent storage 크기는 제한하지 않는다.

### Gap / Diagnosis

**[추론]** 현재 “streaming” 결과는 decoder 단계의 bounded memory를 잘 측정하지만 sensor ingestion부터 map update까지의 online system cost를 완전히 측정하지 않는다. 장기 운용에서는 encoder, CPU storage, revisit lookup, garbage collection, loop closure가 병목이 될 수 있다.

### Hypothesis

새 영역만 계속 탐색하는 trajectory에서는 persistent storage의 증가율이, loop revisit가 많은 trajectory에서는 lookup·collision·pose correction이 p95 latency를 지배한다. decoder readout을 고정해도 end-to-end latency와 host memory는 sequence length에 따라 증가할 것이다.

### Experimental Design

- **데이터:** 7Scenes/NeuralRGBD의 재생 stream과 2,000–10,000 frame synthetic traversal
- **비교군:** Point3R, Slot3R, fixed-state recurrent baseline
- **실행:** 전체 sequence 사전 인코딩 제거, frame-by-frame camera ingestion
- **평가:** encoder/retrieval/decoder/write별 p50·p95 latency, GPU·CPU·host memory, storage slope, Acc/Comp/NC, ATE drift
- **trajectory:** new-area dominant, loop-heavy, stationary revisit, abrupt viewpoint change
- **GO:** 병목이 trajectory 유형별로 재현 가능하게 분리되고, 논문 headline FPS와 end-to-end FPS 사이 차이가 설명됨
- **KILL:** 구현 차이가 모델 차이보다 커서 공정한 비교가 불가능함
- **최소 실험:** 먼저 Slot3R 하나만 2,000프레임 replay하고 component profiler를 공개

### Expected Contribution

장기 3D reconstruction을 model FPS가 아니라 **sensor-to-map latency, persistent memory growth, reconstruction drift**의 세 축으로 평가하는 benchmark protocol이다.

### Risk / Compute / 4–8주 가능성

- **Compute cost:** 3/5. 학습은 필요 없지만 24 GB 기준 코드를 8GB에 맞추려면 해상도·길이 축소가 필요
- **위험:** 코드 공개 상태와 GPU 차이로 논문 수치 직접 재현이 어려움
- **4–8주:** 한 모델 2,000-frame audit는 가능, 다중 baseline 10K는 어려움
- **음성 결과 가치:** 사전 인코딩 제거 후에도 비용이 안정적이면 Slot3R의 online 주장에 대한 강한 독립 검증이 된다.

## Q5. long-horizon gradient가 visual consistency를 높이면서 motion을 억제하지 않게 만들 수 있는가?

### Observation

**[확인된 사실]** [Connected Self Forcing](https://arxiv.org/html/2610.12156)은 기존 Self Forcing이 historical cache를 detach해 future-to-history gradient를 끊는 문제를 지적하고 Shortcut Gradient Replay로 일부 경로를 복원한다.

**[확인된 사실]** 60초 Causal CD에서 Avg.(6)은 SF 0.8537, SGF 0.8563, CSF 0.8589지만 Dynamic Degree는 각각 0.4435, 0.6113, 0.5976이다. TF initialization에서 CSF Avg.(6)은 0.8780으로 가장 높지만 Dynamic Degree는 0.4960으로 SF 0.6992와 SGF 0.8653보다 낮다. Avg.(6)은 Dynamic Degree를 제외한다.

**[확인된 사실]** CSF 학습 시간은 chunk-wise에서 SF의 1.27배, frame-wise stress test에서 1.41배다. 저자들은 replay가 exact full-sequence backpropagation을 재현하지 않는다고 명시한다.

### Gap / Diagnosis

**[추론]** 미래 consistency gradient가 큰 움직임을 오류 위험으로 간주해 motion amplitude를 줄이는 방향으로 작동할 수 있다. headline 평균에서 Dynamic Degree가 빠져 있어 quality 향상과 motion suppression이 동시에 일어나도 성공처럼 보인다.

### Hypothesis

cross-chunk gradient를 appearance/identity consistency 성분과 motion-sensitive 성분으로 분해하고, 직접 DMD gradient와 충돌하는 성분만 투영하면 Avg.(6)을 유지하면서 Dynamic Degree와 optical flow amplitude를 회복할 수 있다.

### Experimental Design

- **MVP:** full video generator 대신 작은 autoregressive latent-video model 또는 공개 short-video subset
- **비교군:** SF, detached rollout, CSF proxy, gradient projection, motion auxiliary loss
- **prompt strata:** static, camera motion, articulated motion, object translation, texture-only change
- **평가:** Avg.(6), Dynamic Degree, RAFT flow magnitude, action recognizer consistency, identity drift, gradient cosine
- **GO:** 품질 평균 하락 0.5% 이내에서 motion 지표가 SF/SGF 수준으로 회복
- **KILL:** motion 회복이 flicker·identity drift를 크게 악화시키거나 gradient conflict와 motion 감소의 상관이 없음
- **최소 실험:** 모델 학습 전에 공개 생성 결과에서 prompt별 Dynamic Degree와 flow를 재평가해 trade-off가 실제로 안정적인지 확인

### Expected Contribution

long-horizon video 학습을 “gradient를 더 멀리 보낸다”에서 **어떤 미래 신호를 과거에 보내야 하는가**로 바꾸는 연구다.

### Risk / Compute / 4–8주 가능성

- **Compute cost:** 4/5. 원 규모 재현은 불가능하며 작은 proxy가 필요
- **위험:** proxy model의 failure가 대형 diffusion model과 다를 수 있음
- **4–8주:** metric audit와 작은 gradient-conflict 실험만 가능
- **음성 결과 가치:** motion 감소가 재현되지 않으면 원 수치는 metric/prompt variance일 가능성을 보여준다.

## Q6. dynamic 3D alignment에서 불확실한 frame을 shared latent에서 격리하면 오류 전파가 줄어드는가?

### Observation

**[확인된 사실]** [GenIA](https://arxiv.org/html/2610.12388)는 frozen SAM3D의 generative prior를 depth·visibility·rendering guidance로 입력에 정렬한다. 저자들은 ActionBench의 큰 inter-frame motion에서 coarse geometry 또는 pose 오류가 전파되어 재구성을 크게 악화한다고 명시한다.

**[확인된 사실]** CO3D 단일 입력에서 peak GPU memory는 TTR 미사용 19.7 GB, SAM3D 18.0 GB이며 TTR은 Gaussian decoder 역전파 때문에 31.8 GB까지 증가한다. ActionBench에서 HiMoR가 training-view PSNR/co-PSNR을 앞서고, GenIA는 held-out LPIPS가 가장 좋지만 per-frame SAM3D와 비슷한 수준이라고 보고한다.

### Gap / Diagnosis

**[추론]** 모든 frame의 appearance·pose evidence를 shared representation에 비슷한 강도로 쓰면 초기 depth·mask·pose 오류가 공통 상태를 오염시킨다. 큰 motion은 frame overlap을 줄여 잘못된 정렬을 찾아낼 관측 일관성도 약하게 만든다.

### Hypothesis

frame별 pose/depth/visibility uncertainty를 추정하고 confidence가 낮은 frame의 write를 지연하거나 별도 hypothesis slot에 격리하면, 단순 visibility weighting보다 오류 전파와 appearance drift가 줄어든다.

### Experimental Design

- **데이터:** ActionBench 10–20 clip과 작은 synthetic motion set
- **비교군:** uniform fusion, visibility weighting, uncertainty weighting, hard quarantine, multi-hypothesis slots
- **factorization:** GT pose/predicted geometry, predicted pose/GT geometry, 둘 다 predicted
- **오류 주입:** pose rotation, depth scale, mask erosion/dilation, frame drop
- **평가:** held-out LPIPS, reprojection error, pose drift, frame-to-frame appearance variance, recovery time, peak memory
- **GO:** 큰 motion·오류 주입 구간에서 평균 품질을 유지하며 worst-quartile drift를 20% 이상 감소
- **KILL:** uncertainty score가 실제 오류와 calibration되지 않거나 quarantine이 usable observation까지 버려 completeness를 악화
- **최소 실험:** GenIA 전체 TTR 대신 frozen outputs에 post-hoc uncertainty gating만 적용

### Expected Contribution

dynamic reconstruction의 실패를 “더 강한 optimizer”가 아니라 **오염된 관측을 언제 공통 상태에 기록할지**의 문제로 재정의한다. streaming memory와 VLM evidence accumulation에도 일반화할 수 있다.

### Risk / Compute / 4–8주 가능성

- **Compute cost:** 4/5. full GenIA/TTR 재현은 무겁고 공개 코드·체크포인트 의존
- **위험:** uncertainty가 pose와 appearance 오류를 함께 설명하지 못할 수 있음
- **4–8주:** post-hoc gating 진단은 가능, full model 개선은 어려움
- **음성 결과 가치:** gating이 실패하면 병목이 fusion보다 coarse geometry prior 자체에 있다는 강한 근거가 된다.
