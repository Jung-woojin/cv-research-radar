# CV/VLM Daily Brief — 2026-10-29 (Asia/Seoul)

- 오늘 확인된 최신 공식 원문은 “더 좋은 최종 답”보다 **중간 표현과 증거가 실제로 충실한가**를 문제로 만든다.

## 1) CV / DL-CV 핵심

### PerceptRL: Making Visual Perception Rewardable in MLLMs from Answers to Interactions

- **상태**: 오늘 신규가 아닌 2026-10-27 v1; 2026-10-29 기준 최근 72시간의 공식 원문.
- **문제 정의**: reasoning 중심 post-training 뒤 fine-grained visual perception이 약해지고, dense caption을 그대로 reward로 쓰기 어렵다.
- **핵심 방법**: caption error를 fixed-answer QA로 바꾸는 Perception RL과 visual tool을 쓰는 multi-turn Perception Agentic RL을 결합한다. Coordinate Injection과 grounding-aware process reward로 중간 공간 충실도를 감독한다.
- **정량 결과**: **저자 주장** — 동일 tool-use protocol의 7 benchmark 평균 71.6%, 같은 tools의 base model 및 평가한 frontier VLM보다 각각 15.7, 5.2 percentage point 높다고 보고한다.
- **데이터·공개성**: 원문은 multi-agent caption-error conversion을 설명한다. 공식 code, weights, dataset release는 이번 조사에서 확인하지 못했다.
- **재현성/계산**: multi-turn tools·cold-start SFT·RL이 포함돼 compute/trajectory format 영향이 크다. parameter, FLOPs, VRAM, seed variance, exact split은 abstract에서 확인되지 않았다.
- **주의점**: final answer gain이 crop/box가 진짜 근거를 가리킨다는 보장은 아니다. shared protocol도 동일 tool configuration의 조건부 비교다.
- **연결점**: aerial/grounded VQA에서 answer accuracy와 evidence IoU를 분리해 VLM Answer–Region Gap을 측정하는 출발점이다.
- **후속 씨앗**: answer-only reward와 process-aware reward를 같은 answer set에서 비교하고 correct-but-misgrounded rate를 기록한다.

### ImagiRep: Representing the Unseen — Rethinking Visual Imagination for Spatial Reasoning

- **상태**: 2026-10-27 v1, 공식 프로젝트 링크가 원문에 포함됨.
- **문제 정의**: unseen state의 RGB 생성이 공간추론에 적절한 표현인지 분리한다.
- **핵심 방법**: simulator-grounded ImagiRep에서 같은 state에 oracle RGB와 depth·panorama·top-down 등 여섯 대안 표현을 제공하고, question type별 representation effect를 비교한다. GEARS는 test-time adaptive selection이다.
- **정량 결과**: **확인된 사실** — 922 questions, 7 question types, Viewpoint Imagination/Cross-view Integration 두 setting. **저자 주장** — GEARS가 기존 spatial imagination method를 능가한다.
- **데이터·공개성**: benchmark와 공식 project page는 확인했지만 code, checkpoint, data download 조건은 이번 실행에서 확인하지 못했다.
- **재현성/계산**: generated RGB 품질과 reasoning accuracy를 같은 것으로 취급하지 않아야 한다. model size, FLOPs, VRAM, seed variance, per-type split은 abstract에서 확인되지 않았다.
- **주의점**: simulator의 oracle/estimated state 조건은 real-world perception noise와 다르다. 표현 간 input cost도 동일하다고 가정하면 안 된다.
- **연결점**: remote sensing 또는 maritime VQA에서 RGB, depth proxy, map-like context 중 무엇이 실제 uncertainty를 줄이는지 묻는 실험으로 확장 가능하다.
- **후속 씨앗**: answer flip 자체가 error predictor인지, representation selector가 state-estimation error가 큰 경우에도 안전한지 평가한다.

### CodeCap-Bench: Can Code Serve as a Good Video Caption?

- **상태**: 2026-10-27 v1.
- **문제 정의**: 자연어 video caption이 fine-grained spatial layout과 temporal dynamics를 길고 모호하게 표현하는 한계를 다룬다.
- **핵심 방법**: graphic primitive, layout rule, time function으로 이루어진 code caption을 natural-language caption과 QA·reconstruction에서 비교한다.
- **정량 결과**: **확인된 사실** — 323 videos, five structured-2D categories, fine-grained annotation, multi-level evaluation. **저자 주장** — code caption이 QA와 reconstruction fidelity에서 우수하지만 복잡한 temporal dynamics에서 leading proprietary MLLM도 어려움을 겪고 open-source가 더 뒤처진다.
- **데이터·공개성**: benchmark 원문은 확인했지만 code, weights, data package의 공식 release는 이번 조사에서 확인되지 않았다.
- **재현성/계산**: code generation parser와 evaluator가 결과를 크게 좌우할 수 있다. model size, inference cost, seed variance, open-source model exact list는 abstract에서 확정하지 않았다.
- **주의점**: syntax-valid code가 temporal faithfulness를 뜻하지는 않는다. QA improvement가 code format prior나 evaluator bias에서 왔는지 분리해야 한다.
- **연결점**: video VLM의 temporal evidence를 natural-language rationale가 아니라 perturbable structured trace로 평가할 길을 연다.
- **후속 씨앗**: time-shuffled code와 same-length pseudo-code를 대조해 temporal causal structure가 실제 이득의 원인인지 시험한다.

## 5) 오늘의 중요한 Finding 3개

1. **정답과 증거를 분리해야 한다.** PerceptRL의 coordinate drift는 answer accuracy만으로 visual tool policy를 평가하면 위험하다는 신호다.
2. **RGB는 default이지 oracle interface가 아니다.** ImagiRep은 state가 동일해도 question type별 최적 표현이 다르다고 보인다.
3. **시간 구조는 format보다 검증이 중요하다.** Code caption이 압축적으로 보이더라도 temporal primitive가 실제 video event와 맞는지를 따로 검사해야 한다.

## 6) 과대평가 가능성 / 주의

- **PerceptRL**: 71.6%는 shared tool-use protocol의 저자 보고다. tool set, prompt, multi-turn budget, process reward annotation 비용이 바뀌면 같은 차이가 유지될지 확인되지 않았다.
- **ImagiRep**: simulator-grounded representation benefit을 sensor noise·occlusion·imperfect depth가 있는 real CV로 바로 일반화하면 안 된다.
- **CodeCap-Bench**: structured 2D video의 code caption 결과를 자연 video 전체로 일반화하면 안 된다. syntax validity와 temporal correctness도 별개다.

## 7) 오늘 바로 읽을 Top 3

1. **PerceptRL** — visual tool trajectory의 answer–evidence gap을 직접 다뤄 grounded VQA 연구에 가장 즉시 연결된다.
2. **ImagiRep** — spatial reasoning에서 visual generation 품질과 task representation을 분리하는 통제가 명확하다.
3. **CodeCap-Bench** — temporal reasoning을 explanation 문장이 아니라 executable/perturbable representation으로 평가할 출발점이다.

## 8) Top 1 미니 리뷰 — PerceptRL

- **왜 중요한가**: post-training의 reasoning gain이 visual perception 손실을 가릴 수 있다는 문제를 reward 설계로 정면에서 다룬다.
- **blind spot**: answer-only reward는 우연히 맞은 답을 강화할 수 있으며, crop·annotation이 진짜 evidence와 어긋난 경우를 감춘다.
- **실험 논리**: dense caption error를 verifiable QA로 바꾸고, single-turn 실패는 visual tools를 쓰는 multi-turn route로 넘긴다. coordinate injection과 process reward가 final answer 외 중간 spatial operation을 감독한다.
- **진짜 기여**: 평균 score 자체보다 coordinate drift를 독립 failure mode로 이름 붙이고 중간 evidence를 reward 대상에 넣은 점이다.
- **과장될 수 있는 부분**: 7 benchmark 평균은 tool protocol·budget·model 비교 조건을 고정한 결과다. raw vision encoder 개선 또는 domain transfer를 뜻하지 않는다.
- **정우진 연구 연결**: CCTV·항공·maritime VQA에서 정답/근거 region/perturbation stability를 함께 로그하면 tool-use hallucination을 object scale·occlusion별로 분석할 수 있다.

## 9) 후속 연구 씨앗

### Seed A — Correct-but-misgrounded audit

- **질문/가설**: answer-only reward는 final answer가 맞아도 evidence IoU가 낮은 trajectory를 남긴다.
- **최소 실험**: question–region 정답 50개에서 predicted/oracle/random crop과 ±5%, ±10% crop shift를 비교.
- **dataset/baseline**: RefCOCO+ 또는 공개 grounded VQA; frozen base VLM과 process-aware variant.
- **판정**: answer loss 1 point 이내에서 evidence IoU와 perturbation stability가 같이 오르면 GO; 변화가 없으면 UI/encoder 병목으로 전환.

### Seed B — Representation-flip uncertainty

- **질문/가설**: RGB/depth/top-down answer flip은 softmax confidence보다 spatial error를 잘 예측한다.
- **최소 실험**: 동일 state의 60 question에 네 representation을 넣고 flip rate·error AUROC·risk–coverage를 기록.
- **dataset/baseline**: ImagiRep 공개 가능 subset 또는 simulator; RGB-only, random selection, majority vote.
- **판정**: 같은 coverage에서 flip-based selection risk가 낮으면 GO; 아니면 question-conditioned verifier가 필요.

### Seed C — Temporal-code causal ablation

- **질문/가설**: code caption의 QA 이득은 temporal function 보존에서 온다.
- **최소 실험**: 60 video에서 natural language, original code, time-shuffled code, same-length pseudo-code를 temporal/spatial/appearance QA로 비교.
- **dataset/baseline**: CodeCap-Bench 공개 가능 split; length·answer model·prompt 고정.
- **판정**: temporal QA에서만 original code의 paired gain이 남고 shuffle에서 사라지면 GO; 유지되면 format prior/evaluator bias를 우선 의심.

## 10) 오늘 안 읽어도 되는 것

- 공식 원문과 구현 세부를 교차검증하지 못한 나머지 후보는 headline만으로 추천하지 않는다.
- PerceptRL을 당장 대규모 RL 재현 대상으로 읽을 필요는 없다. 먼저 50문항 coordinate audit로 reward 간극이 실제로 있는지 확인하는 편이 비용 효율적이다.
- ImagiRep을 world-model capability 순위표로 읽지 않는다. 이 논문의 직접 가치는 representation control이다.
