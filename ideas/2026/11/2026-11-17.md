### P1. V-JEPA-LM: Video-Language Models That Read Dynamics Beyond Static, Text-Aligned Representations

- **v1:** 2026-11-13 07:05:22 UTC. 확인한 submission history에는 v1만 있다.
- **문제·방법:** 동역학 표현이 답변으로 읽히지 않는 문제에 대해 frozen video encoder와 counterfactual supervision을 연결한다.
- **저자 결과:** 동일 항목에서 frozen feature의 speed probe는 약 87%이나 VLM 답변은 chance 수준이라고 보고한다. 이는 “정보가 없다”와 “사용되지 않는다”를 구분할 동기다.
- **한계:** clip-level 32-frame 조건이며 장시간 비디오로의 일반화는 입증되지 않았다. probe가 높다고 모든 오류가 readout 원인이라는 뜻은 아니다.
- **공개:** 공식 README와 추론 파일·모델 링크를 확인했다. 학습 코드·counterfactual generator·training manifest는 추후 추가한다고 명시한다. weight 다운로드나 실행은 검증하지 않았다.
- **연결:** P2와 결합해 readout 실패에 불필요한 재관측을 하고 있는지 검증한다.

출처: [공식 논문](https://arxiv.org/abs/2611.17831), [v1 본문](https://arxiv.org/html/2611.17831v1), [공식 코드·공개 범위](https://github.com/kkt94/Llama-V-JEPA-LM).

## 3. Proposal A — Acquire-or-Read

1. **문제·시의성:** 영상 오답에 무조건 frame을 추가하면 readout 문제에 관측 비용을 낭비할 수 있다. P1의 표현/답변 분리와 P2의 관측 비용 분석을 연결한다.
2. **Gap:** 두 연구만으로 개별 오답에 필요한 intervention을 사전에 고르는 능력이 입증되지는 않는다.
3. **가설:** 기본 실행에서 추출한 answer margin·시간 구간 coverage·feature 변화량이 추가 관측과 readout 교정의 이득 차이를 예측한다.
4. **구조:** frozen encoder → 고정 기본 답변 → 작은 utility gate → 중단/추가 구간 관측/캐시 feature readout. 진단에서는 세 intervention을 모두 실행해 oracle utility를 만들고, 배포 gate에는 oracle·정답·추가 관측 결과를 넣지 않는다.
5. **Baseline:** uniform sampling, 항상 재관측, 항상 readout, confidence threshold, random budget-matched routing. readout은 probe 및 작은 temporal pooling head로 시작한다.
6. **데이터·지표:** TempCompass와 PerceptionTest의 이용 가능한 speed/order 문항에서 source video별 분리. 정확도, paired improvement, harmful intervention rate, cost당 정답 증가, gate regret, 실측 GPU 시간·peak VRAM.
7. **Ablation:** margin/coverage/feature 변화량 각각 제거; readout head 용량; frame 수 고정과 token 비용 고정; unseen video·질문 유형 전이.
8. **실패 모드:** gate가 질문 표현을 암기하거나 oracle leak를 이용할 수 있다. probe 우세는 head 용량·학습량 차이일 수도 있으므로 frozen 동일 feature와 held-out source를 고정한다.
9. **Negative result:** 두 intervention의 이득이 구별되지 않으면 routing을 중단한다. 그래도 오답의 acquisition/readout 분해와 비용 경계는 진단 결과로 남는다.
10. **Novelty·방어:** adaptive compute·selective prediction·counterfactual supervision과 경쟁한다. 새 controller 자체보다 동일 문항의 intervention crossover와 out-of-source utility 예측을 기여로 삼는다. 동일한 선행 연구가 확인되면 축소한다.
11. **4~8주 MVP:** 1주 데이터/답변 검증, 2주 crossover·GO/KILL, 3~4주 작은 gate, 5~6주 두 번째 모델·전이, 7~8주 통계·실패 분석.
12. **기여 3개:** 원인 분해 protocol; utility 예측의 가능/불가능 경계; 동일 예산에서의 최소 routing.
13. **제목 2개:** *Acquire or Read? Diagnosing the Value of More Video Evidence*; *When More Frames Cannot Fix the Answer*.
14. **Abstract 개요:** 추가 frame의 비효율 문제 → 문항별 intervention matrix → 사전 utility gate → 비용·오류 결과와 전이 한계.
15. **Introduction:** 평균 점수의 모호함 → 관측 부족/사용 실패 분리 필요 → P1/P2 이후 남은 의사결정 문제 → 검증 가능한 기여.
16. **Related Work:** video representations; temporal readout; active video exploration; selective computation와 oracle leakage.
17. **Method:** 데이터 분할 → crossover utility 정의 → 기본 관측만 사용하는 gate → 비용 제약 최적화.
18. **표·그림:** intervention별 오류 이동표, 정확도–GPU시간 Pareto, utility calibration, acquisition/readout 대표 실패 사례.

**첫 실험:** Llama-V-JEPA-LM-Qwen3-1.7B와 frozen encoder를 사용한다. source video가 겹치지 않는 최대 300문항을 pilot으로 확보하고, 부족하면 실제 확보 수와 class 분포를 보고한다. 원본 문항을 우선하며 합성 speed 정답은 만들지 않는다. 기본 32-frame 입력을 고정하고, 추가 구간 32-frame branch와 캐시 feature readout branch를 비교한다. probing 학습과 평가는 source video로 분리한다.

**1~2주 GO/KILL:** test를 보기 전 dev에서 비용 상한을 고정한다. acquisition/readout 중 유리한 branch가 갈리는 문항이 있고, held-out gate가 비용을 맞춘 confidence routing보다 좋아 paired 95% bootstrap CI 하한이 0을 넘으면 GO. crossover가 없거나 비용 정합 후 이득이 사라지면 KILL. 300문항에서 CI가 넓으면 성공으로 포장하지 않고 미결로 남긴다. 모델 로딩이 가능한지 먼저 peak VRAM을 측정하며 특정 GPU에서의 실행 가능성을 보장하지 않는다.

## 4. Proposal B — Transition-Lag Audit

1. **문제·시의성:** 조건이 해제된 뒤 mask가 남는 오류는 sampling 누락, state memory, mask propagation 중 어디서 발생하는가?
2. **Gap:** P3는 명시적 상태를 모델링한다. 같은 상태 head를 다시 제안하는 것은 부족하다. P1의 시간 readout 관점을 이용해 지연 원인을 분리한다.
3. **가설:** sampling phase에 따라 달라지는 지연과 충분한 관측 후에도 남는 memory 지연은 서로 다른 intervention에 반응한다.
4. **구조:** 고정 video decoder → sampling phase sweep → 상태 예측 → 고정 mask propagation. dense oracle-frame 조건은 진단용으로만 두고, 최소 개입은 전환 의심 구간 재샘플링 또는 state reset 하나씩이다.
5. **Baseline:** 동일 frame budget uniform sampling, confidence gate, 단순 hysteresis, oracle transition-frame condition.
6. **데이터·지표:** PS-Bench 공개 여부를 먼저 확인한다. 미배포면 허가된 짧은 영상 100개에 독립적으로 active/vacant 전환을 수작업 표기한다. onset/offset 오차(초), vacant false emission, active miss, J&F를 함께 측정한다.
7. **Ablation:** fps, sampling phase, propagation on/off, reset on/off, interval duration, occlusion, 정적 질의 대 동적 질의.
8. **실패 모드:** 애매한 predicate와 annotation 지연이 모델 지연으로 보일 수 있다. 두 annotator 불일치 구간을 별도 보고하고 제외 전후 결과를 병기한다.
9. **Negative result:** dense-frame에서도 지연이 같으면 단순 resampling 가설을 기각한다. reset이 active recall을 해치면 교정 방법은 폐기한다.
10. **Novelty·방어:** P3의 직접 후속이며 중복 위험이 높다. state token 추가가 아니라 phase·memory·propagation의 factorial diagnosis가 차별점이다.
11. **4~8주 MVP:** 1주 annotation·공개 확인, 2주 phase audit, 3주 propagation 분리, 4주 최소 개입, 5~6주 모델 전이, 7~8주 검수.
12. **기여 3개:** 전환 지연의 원인 taxonomy; phase-sensitive evaluation; 부작용을 포함한 최소 교정의 경계.
13. **제목 2개:** *Why Does the Mask Stay?*; *Separating Sampling and State Lag in Video Predicate Grounding*.
14. **Abstract:** vacant 오출력 → 원인 분해 실험 → sampling/reset의 상이한 반응 → 평균 mask 점수가 놓치는 지연.
15. **Introduction:** 객체 identity와 predicate 성립의 차이 → 지연의 실제 비용 → 기존 평균 지표의 한계 → 진단 질문.
16. **Related Work:** video reasoning segmentation; state tracking; temporal sampling; annotation uncertainty.
17. **Method:** transition annotation → phase intervention → lag decomposition → selective correction.
18. **표·그림:** phase×fps 지연 heatmap, transition 정렬 mask timeline, vacant FP–active recall 곡선, annotator 불일치 사례.

**첫 실험·GO/KILL:** 고정 Qwen3-VL-2B 상태 판독과 고정 SAM2 pipeline을 사용할 계획이며 이는 PSG 재현이라고 부르지 않는다. 먼저 20개 영상의 전환 검수가 가능한지 확인하고 100개로 확장한다. 같은 frame 수에서 sampling phase만 4조건으로 바꾼다. phase 효과가 video별 bootstrap에서 확인되고 최소 개입이 active miss를 악화시키지 않으면 GO. 주된 변동이 annotation 불일치이거나 두 개입 모두 placebo와 구별되지 않으면 KILL. 데이터나 모델 이용 조건을 충족하지 못하면 학습 대신 annotation feasibility 결과에서 멈춘다.

## 5. Proposal C — Independent-Witness Consensus

1. **문제·시의성:** 다중 시점의 “합의 수”는 실제로 독립 증거 수인가? 가까운 카메라 프레임의 중복이 잘못된 pseudo box의 신뢰도를 부풀릴 수 있다.
2. **Gap:** P4의 consensus와 P5의 표본/차원 진단을 연결한다. P5가 이 3D 문제의 이론적 보장을 제공한다는 뜻은 아니다.
3. **가설:** 같은 view 수라도 baseline·가시 영역이 다양한 관측이 단순 중복 관측보다 precision을 잘 예측한다.
4. **구조:** 고정 2D 후보·camera pose → 동일 candidate graph → raw view count와 pose/feature diversity weight 비교 → calibration/acceptance. 새 detector 학습은 첫 단계에 필요 없다.
5. **Baseline:** raw count, singleton 제거, pose-only diversity, feature-only diversity, random downsampling, 동일 unique-view 수 조건.
6. **데이터·지표:** 사용 권한을 확보한 ScanNet의 30 scene pilot, scene 단위 분리. box precision/recall@IoU 0.25/0.5, false acceptance, calibration, 전처리 시간. ARKitScenes 전이는 후속이다.
7. **Ablation:** 복제 frame, 인접 frame 추가, 넓은 baseline 추가, pose noise, texture 반복, 가림. 후보 집합 고정 실험과 전체 pipeline 실험을 분리한다.
8. **실패 모드:** 넓은 baseline이 작은 객체 visibility를 낮출 수 있다. diversity가 category·size prior일 수 있어 해당 층별 결과를 함께 제시한다.
9. **Negative result:** raw count로 충분하면 diversity weighting을 폐기한다. 인위적 복제에서만 실패하면 실제 운영 문제로 일반화하지 않는다.
10. **Novelty·방어:** multi-view selection·correlated sensor fusion과 중복 위험이 크다. “독립 증거량”의 보편적 추정이라 주장하지 않고 재방문/인접 시점의 calibration 실패와 반례에 범위를 한정한다.
11. **4~8주 MVP:** 1주 데이터·pose 확인, 2주 graph 고정 복제/다양성 개입, 3~4주 calibration, 5~6주 실제 인접 시점 검증, 7~8주 전이.
12. **기여 3개:** 중복 관측 stress test; count와 diversity의 신뢰도 분해; recall 손실을 제한하는 최소 acceptance 규칙.
13. **제목 2개:** *Many Views, Few Witnesses*; *Does Multi-View Consensus Count Independent Evidence?*
14. **Abstract:** 합의와 독립성의 차이 → 고정 후보 개입 → calibration-aware acceptance → 회복과 실패 조건.
15. **Introduction:** 다중 시점 pseudo-label의 가치 → 중복 관측 위험 → controlled duplication/novel-view 실험 → 제한된 주장.
16. **Related Work:** open-vocabulary 3D detection; multi-view fusion; sensor correlation; confidence calibration.
17. **Method:** candidate 고정 → pose/appearance redundancy → acceptance calibration → scene-wise 평가.
18. **표·그림:** 동일 view 수 precision/recall, redundancy–confidence 곡선, novel-view/duplicate intervention 비교, 반복 texture 실패 사례.

**첫 실험·GO/KILL:** 저자 구현의 공개 여부를 재확인하고, 미공개면 고정 공개 2D proposal과 pose 기반 graph로 진단 harness를 만든다. 이는 See and Detect 재현이 아니다. 30 scene에서 unique view와 candidate를 고정한 채 복제 관측만 더한다. 이후 같은 수의 실제 인접/넓은 baseline frame으로 대체한다. 실제 인접 시점에서도 count의 false acceptance가 증가하고 diversity rule이 matched recall에서 이를 줄이면 GO. 인위적 복제에서만 나타나거나 pose noise가 설명하면 KILL/진단 범위를 축소한다.

## 6. 우선순위·이번 주 실행 결정

평가는 이번 레이더의 판단이며 실측치나 채택 확률이 아니다. Compute cost는 **1이 가볍고 5가 무겁다**.

| 순위 | 후보 | Novelty /5 | Feasibility /5 | Compute cost /5 | Publication potential /5 |
|---:|---|---:|---:|---:|---:|
| 1 | Acquire-or-Read | 4 | 4 | 2 | 4 |
| 2 | Transition-Lag Audit | 3 | 3 | 3 | 3 |
| 3 | Independent-Witness Consensus | 3 | 3 | 3 | 3 |

**이번 주 먼저 할 연구는 Acquire-or-Read다.** 작은 모델의 추론·캐시 feature 분석으로 시작하고, 대규모 재학습 전 1~2주 안에 crossover 자체가 존재하는지 반증할 수 있다. 실패해도 acquisition과 readout의 구분이 언제 무의미한지 남는다. 작은 GPU에서 우선 시도할 후보도 A이며 메모리는 실측 후 결정한다. 장기 주제로는 B의 predicate state와 persistent world state의 연결을 남기되, 이번 MVP에 넣지 않는다.

논문화 판단은 개선 점수 하나보다 source-disjoint 진단의 재현성, 경쟁 연구와의 구별, 부정 결과의 설명력을 우선한다. 모든 subset 크기·GO/KILL 조건은 제안이며 실험 완료를 의미하지 않는다.
